## 1. sort() 方法的默认行为与缺陷 *Content-[00:00]

在前端开发中，我们经常使用 `Array.prototype.sort()` 方法来对数组进行排序。然而，如果不了解其底层原理，很容易在实际应用中踩坑。

- **默认排序算法**：`sort()` 方法默认使用原地算法，它会将数组中的元素**转换为字符串**，然后按照 **UTF-16 码元值**（逐位）进行比较和排序。
- **默认行为导致的缺陷**：
  这种按字符串逐位比较的方式，在处理纯数字数组时会产生不符合直觉的结果。
  - **示例数组**：`[3, 15, 8, 22, 29, 102]`
  - **预期升序结果**：`3, 8, 15, 22, 29, 102`
  - **实际 `sort()` 结果**：`102` 会被排在 `15` 前面。
  - **原因分析**：在字符串比较中，`102` 和 `15` 的首位字符都是 `'1'`，接着比较下一位，`'0'` 小于 `'5'`，因此算法判定 `102` 比 `15` 小。这显然违背了我们按数字实际大小排序的需求。

## 2. sort() 的 compareFn 参数解析 *Content-[02:18]

为了解决默认排序的问题，`sort()` 方法提供了一个可选参数 `compareFn`（比较函数），允许我们自定义排序规则。

- **参数结构**：`compareFn` 是一个回调函数，接收两个参数，通常命名为 `a` 和 `b`。
- **参数代表的元素**：
  通过在实际代码中使用 `console.log(a, b)` 进行打印调试，可以观察到比较函数被调用时参数的传递规律（以特定浏览器引擎如 V8 的表现为例）：
  - 第一次调用：`a` 是第二个数（15），`b` 是第一个数（3）。
  - 第二次调用：`a` 是第三个数（8），`b` 是第二个数（15）。
  - 第三次调用：`a` 是第四个数（29），`b` 是第三个数（8）。
  - **规律总结**：在比较过程中，`b` 通常代表**当前元素（前一位）**，而 `a` 代表**后一个元素**。

## 3. compareFn 返回值与排序逻辑探究 *Content-[04:48]

理解了参数含义后，核心在于如何设置 `compareFn` 的返回值。官方 MDN 文档说明，返回值必须是一个数字，其符号（正、负、零）决定了两个元素的相对顺序。

- **官方规则**：
  - 返回值 $< 0$（负数）：`a` 排在 `b` 前面。
  - 返回值 $> 0$（正数）：`a` 排在 `b` 后面。
  - 返回值 $= 0$：`a` 和 `b` 位置不变。

- **视频中的通俗理解与实验**：
  为了更直观地理解，视频中通过不断修改返回值来观察数组的变化：
  - **返回负数（或 false 转换后的逻辑）**：观察到元素发生了**交换位置**（顺序颠倒）。
  - **返回正数**：观察到元素**保持原位不变**。
  - **结论转化**：如果希望两个元素交换位置（调整顺序），就返回负数；如果希望保持原位，就返回正数。

- **实现降序的复杂逻辑**：
  已知 `sort` 默认是升序，若要实现降序（大的数往前放），即当后面的数 `a` 大于前面的数 `b` 时，需要交换它们的位置（返回负数）。
  ```javascript
  arr.sort((a, b) => {
      if (a > b) {
          return -1; // 后面比前面大，返回负数，交换位置（大的往前放）
      } else if (a < b) {
          return 1;  // 后面比前面小，返回正数，不交换
      } else {
          return 0;  // 相等，不交换
      }
  });
  ```

## 4. 实现升序与降序的简化写法 *Content-[08:29]

上述使用 `if-else` 判断的写法虽然逻辑清晰，但代码较为繁琐。利用数学减法的特性，可以极大地简化代码。

- **降序简化推导**：
  - 需求：当 $a > b$ 时，返回负数；当 $a < b$ 时，返回正数；相等时返回 $0$。
  - 数学运算：$b - a$ 完美契合此需求。
    - 若 $a > b$，则 $b - a < 0$（负数）。
    - 若 $a < b$，则 $b - a > 0$（正数）。
    - 若 $a = b$，则 $b - a = 0$。
  - **降序最终代码**：`return b - a`

- **升序简化推导**：
  - 反之，若需要升序排列，直接反转减法顺序即可。
  - **升序最终代码**：`return a - b`

- **最终代码示例**：
  ```javascript
  const arr = [3, 15, 8, 22, 29, 102];

  // 降序排列：102, 29, 22, 15, 8, 3
  arr.sort((a, b) => b - a);

  // 升序排列：3, 8, 15, 22, 29, 102
  arr.sort((a, b) => a - b);
  ```
