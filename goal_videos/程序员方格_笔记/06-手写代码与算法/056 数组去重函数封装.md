## 题目介绍与边界处理 *Content-[00:00]
- **题目要求**：封装一个数组去重函数 `function show(arr)`。
  - 接收一个数组作为参数。
  - 返回一个去重后的新数组。
- **边界条件处理**：
  - 在函数开头首先进行判空处理。
  - 如果传入的数组为空（如 `arr.length === 0`）或没有元素，直接 `return`。
  - 避免对空数组进行无意义的去重操作，提升代码健壮性。

## 传统方法：ES5 遍历与判断 *Content-[00:46]
- **核心思路**：创建一个新数组，遍历原数组，判断元素是否已存在于新数组中，不存在则放入。
- **具体实现步骤**：
  1. 定义一个空数组 `let newArr = []` 用于存放去重后的结果。
  2. 使用 `arr.forEach()` 遍历传入的原数组。
  3. 在遍历过程中，判断新数组是否包含当前元素。判断方式主要有两种：
     - 使用 `indexOf`：判断索引是否不等于 `-1`（即 `newArr.indexOf(element) !== -1` 表示存在）。
     - 使用 `includes`：直接判断是否包含该元素（即 `newArr.includes(element)`）。
  4. 如果新数组**不包含**该元素，则使用 `newArr.push(element)` 将其放入新数组中。
  5. 遍历结束后，`return newArr` 返回结果。
- **代码示例**：
  ```javascript
  function show(arr) {
    // 边界条件判断
    if (!arr || arr.length === 0) return;
    
    let newArr = [];
    arr.forEach(element => {
      // 判断新数组是否不包含当前元素
      if (!newArr.includes(element)) {
        newArr.push(element);
      }
    });
    
    return newArr;
  }
  ```

## 进阶方法：ES6 Set 集合去重 *Content-[02:59]
- **核心思路**：利用 ES6 引入的 `Set` 数据结构。`Set` 类似于数组，但其成员的值都是唯一的，自带自动去重功能。
- **实现方式一：分步转换**
  1. 将数组转换为 `Set` 集合：`let s = new Set(arr)`。
  2. 将 `Set` 集合再转换回数组（可通过 `Array.from(s)` 或扩展运算符实现）。
- **实现方式二：一行代码搞定（推荐）**
  - 结合扩展运算符 `...` 和 `Set`，直接在一行内完成转换与去重，是实际开发中最简便、最常用的方式。
  - **代码示例**：
    ```javascript
    function show(arr) {
      return [...new Set(arr)];
    }
    ```
  - **原理解析**：
    1. `new Set(arr)`：将传入的数组转换为 `Set` 集合，`Set` 会自动过滤掉重复的元素。
    2. `...`（扩展运算符）：将 `Set` 集合内部的元素展开。
    3. `[]`：将展开后的元素重新组合成一个新的数组并返回。

## AI 总结
本题主要讲解了前端面试中经典的“数组去重”问题。视频展示了两种实现思路：
1. **ES5 传统方法**：通过创建新数组并结合 `forEach` 循环，利用 `indexOf` 或 `includes` 方法判断元素是否存在，逻辑清晰，适合考察基础编程思维。
2. **ES6 现代方法**：利用 `Set` 数据结构的唯一性特征，配合扩展运算符 `...`，仅需一行代码 `[...new Set(arr)]` 即可优雅、高效地完成去重。在实际开发和面试中，强烈建议掌握并优先使用 ES6 的 `Set` 方案。
