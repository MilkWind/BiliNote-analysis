## 什么是函数组合 (Compose) *Content-[00:10]
- **基本概念**：函数组合（Compose）顾名思义，就是将多个函数串联起来进行执行。
- **执行机制**：将一个函数的输出结果作为另一个函数的输入参数。一旦第一个函数开始执行，就会像多米诺骨牌一样一直推导执行下去。
  - 例如：$f$ 函数调用 $g$ 函数，$g$ 函数调用 $t$ 函数。
  - 传入参数 $x$ 后，先执行 $t(x)$，其结果作为入参给到 $g$ 函数执行，$g$ 函数的执行结果再给到 $f$ 函数执行，最终得到结果。
- **核心目的**：将已分解的简单任务组合成复杂的任务。
- **数学特性**：函数组合满足**结合律**（Associativity）。
  - 公式表示：$(f \circ g) \circ t = f \circ (g \circ t)$
  - 即 $compose(f, g, t)(x)$ 等效于先执行 $t(x)$，再执行 $g$，最后执行 $f$。

## 函数组合的示例与优势 *Content-[03:06]
- **传统嵌套写法**：
  - 假设有两个方法：`add`（加法）和 `multiply`（乘法，视频转录中音译为 muted/music）。
  - 传统方式通过函数嵌套进行计算，例如 `multiply(add(x))`。
  - **缺点**：如果涉及多个函数，层层嵌套的写法会导致代码可读性变差，不够友好。
- **使用 Compose 组合写法**：
  - 将函数作为 `compose` 的入参，例如 `compose(multiply, add)(x)`。
  - 最后传入初始参数 $x$（例如 $x = 10$）。
  - **优势**：即使有多个其他方法，也可以直接通过组合的方式将它们作为 `compose` 的入参，代码结构更加扁平、清晰，避免了深层嵌套。

## Compose 的手动实现原理 *Content-[05:01]
- **固定参数场景**：
  - 如果传入的函数参数是固定的（例如已知只有 $f$ 和 $g$），实现相对简单。
  - 直接返回一个接收参数 $x$ 的函数，内部执行 $f(g(x))$ 即可。
- **未知参数场景（通用实现）**：
  - 实际开发中，传入的函数参数往往是未知的（即不定长参数 `...fns`）。
  - **执行顺序**：函数组合的执行顺序是**从右往左**执行。
  - **核心方法**：利用 JavaScript 数组的 `reduceRight` 方法。
  - `reduceRight` 可以从右向左遍历数组，完美契合函数组合从右向左执行的逻辑。
  - 最终返回一个函数，接收初始入参 $x$，并通过 `reduceRight` 完成所有函数的串联调用。

## Compose 的简化实现 *Content-[07:10]
- 在理解基本原理后，可以对 `compose` 进行代码简化。
- **简化版代码逻辑**：
  ```javascript
  const compose = (...fns) => {
    return (x) => {
      return fns.reduceRight((acc, fn) => fn(acc), x);
    }
  }
  ```
- **逻辑解析**：
  - 接收多个函数参数 `...fns`。
  - 返回一个新函数，接收初始值 $x$。
  - 使用 `fns.reduceRight`，回调函数中调用当前的 `fn` 并传入上一次的结果 `acc`。
  - 初始值设置为 $x$，从而实现从右向左的函数执行与结果传递。

## Compose 的实际应用场景 *Content-[08:04]
- **Redux 中间件**：
  - 在前端状态管理库 Redux 中，中间件（Middleware）的机制大量使用了 `compose` 函数组合。
  - 通过 `compose`，可以将多个中间件函数优雅地串联起来，实现如日志记录、异步请求处理等复杂逻辑的组合与分发。
