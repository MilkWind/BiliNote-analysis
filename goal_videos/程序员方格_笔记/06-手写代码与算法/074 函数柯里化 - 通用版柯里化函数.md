## 通用版柯里化函数简介 *Content-[00:00]
- **基础版的局限性**：基础版柯里化函数只能处理固定参数个数的函数（例如固定为 2 个、3 个或 5 个参数），缺乏灵活性。
- **通用版的优势**：通用版柯里化函数能够处理**任意参数个数**的函数。
- **面试价值**：这是前端面试中的一个进阶考点，掌握通用版柯里化的手写能力可以直接加分，有效提升求职核心竞争力。

## 核心思路解析 *Content-[00:29]
- **定义工具函数**：首先定义一个柯里化工具函数，该函数接收需要被柯里化的原函数作为第一个参数。
- **定义内层函数**：在工具函数内部定义一个内层函数，用于接收每次传入的单个或多个参数。
- **利用闭包收集参数**：通过闭包机制，将每次传入的参数收集并保存起来。
- **参数个数判断与执行**：
  - 如果收集的参数个数 **大于等于** 原函数的参数个数，则调用原函数并返回最终结果。
  - 如果参数个数不够，则返回内层函数，继续接收下一个参数，直到参数收集完毕。

## 代码实现详解 *Content-[01:16]
- **定义柯里化函数 `currify(fn)`**：
  - 参数 `fn` 代表需要被柯里化的原函数（如求和函数 `add`）。
- **内部收集函数 `collect(...args)`**：
  - 使用 ES6 的扩展运算符 `...args` 来收集每次传入的参数（注：虽然 `arguments` 是伪数组，但使用扩展运算符可以直接得到真正的数组，更为方便）。
- **核心判断逻辑**：
  - **判断条件**：`args.length >= fn.length`。通过 `fn.length` 可以获取原函数的形参个数。
  - **满足条件时**：使用 `apply` 方法调用原函数。代码为 `return fn.apply(this, args)`。这里不需要特意修改 `this` 指向，直接传递当前的 `this` 和参数数组 `args` 即可立即执行并返回结果。
  - **不满足条件时**：返回一个新的匿名函数继续收集参数。代码为 `return function(...nextArgs) { return collect(...args, ...nextArgs) }`。将之前收集的参数 `args` 与新传入的参数 `nextArgs` 合并，再次调用 `collect` 函数。

**核心代码示例：**
```javascript
function currify(fn) {
  return function collect(...args) {
    // 判断收集的参数个数是否大于等于原函数的参数个数
    if (args.length >= fn.length) {
      // 参数够了，调用原函数并返回结果
      return fn.apply(this, args);
    } else {
      // 参数不够，返回新函数继续收集
      return function(...nextArgs) {
        // 合并已收集的参数和新传入的参数，递归调用 collect
        return collect(...args, ...nextArgs);
      }
    }
  }
}
```

## 代码测试与验证 *Content-[05:20]
- **测试一：处理三个参数的加法函数**
  - 定义原函数：`function add(a, b, c) { return a + b + c; }`
  - 柯里化转换：`const currAdd = currify(add);`
  - 传参方式验证：
    - 一次性传入：`currAdd(1, 2, 3)` -> 结果为 `6`。
    - 分次传入：`currAdd(1)(2)(3)` -> 结果为 `6`。
    - 混合传入：`currAdd(1, 2)(3)` -> 结果为 `6`。
- **测试二：处理两个参数的减法函数**
  - 定义原函数：`function sub(a, b) { return a - b; }`
  - 柯里化转换：`const currSub = currify(sub);`
  - 传参方式验证：
    - 分次传入：`currSub(5)(3)` -> 结果为 `2`。
    - 一次性传入：`currSub(5, 3)` -> 结果为 `2`。
- **测试结论**：无论原函数包含多少个参数（2个、3个、4个甚至10个），通用柯里化函数都能完美处理。它同时支持分多次传参和一次性传参，具有极高的灵活性。

## 总结与核心逻辑回顾 *Content-[08:31]
- **函数本质**：`currify` 是一个工具函数，专门用于将普通函数转换为柯里化函数。
- **内部逻辑拆解**：
  - `collect` 函数负责收集参数并保存在 `args` 中。
  - 通过判断 `args.length` 和 `fn.length` 来决定是执行原函数还是返回新函数。
- **核心互动问题**：通用版柯里化函数的核心是收集参数，直到参数个数够了再执行原函数。（结论：**正确**）
- **学习建议**：通用版柯里化函数初看可能觉得复杂，但底层逻辑其实非常简单。建议课后一定要自己动手编写、调试和练习，以加深理解。
