## 数组去重：for + indexOf 核心逻辑 *Content-[00:00]

- **核心思想**：
  - 类似于“点名”逻辑：依次叫每个同学的名字，先查看名单里面有没有这个人。
  - 如果名单里没有，就把这个名字写进去；如果已经有，就跳过。
  - 最终名单里的人都是唯一的。

- **具体实现逻辑**：
  - 新建一个空数组（相当于“空名单”），用来存放唯一的元素。
  - 使用 `for` 循环遍历原数组。
  - 在每次循环中，使用 `indexOf` 方法检查当前元素是否存在于新建的空数组中。
  - 如果 `indexOf` 返回 `-1`，说明元素不存在，则将其 `push` 进空数组中。
  - 遍历结束后，返回这个包含唯一元素的新数组。

## 代码实现与测试结果 *Content-[02:21]

- **代码实现步骤**：
  - 定义一个空数组：`let resultArr = []`，用于存放去重后的唯一名单。
  - 使用 `for` 循环遍历原数组：`for (let i = 0; i < arr.length; i++)`。
  - 判断条件：`if (resultArr.indexOf(arr[i]) === -1)`。
    - `indexOf` 方法返回元素在数组中第一次出现的下标，如果没找到则返回 `-1`。
    - 当返回值为 `-1` 时，说明 `resultArr` 中没有当前元素，执行 `resultArr.push(arr[i])`。
  - 最后返回结果：`return resultArr`。

- **测试结果与缺陷分析**：
  - **测试数组包含**：数字 `1`、字符串 `'1'`、`true`、`NaN`、空对象等。
  - **成功去重**：数字 `1` 去除了一个，字符串 `'1'` 和 `true` 正常处理。
  - **去重失败**：`NaN`（两个 `NaN` 都保留了）和空对象（两个空对象都保留了）未能去重。
  - **原因剖析**：
    - `indexOf` 方法的底层是使用**全等（`===`）** 来判断元素是否存在的。
    - 在 JavaScript 中，`NaN === NaN` 的结果是 `false`。
    - 因此，`indexOf` 找不到数组里已有的 `NaN`，会导致 `NaN` 被重复加入，从而去重失败。
    - 同理，两个空对象的引用地址不同，全等判断也为 `false`，导致对象也无法去重。

## 方法特点与适用场景 *Content-[06:30]

- **优点**：
  - **逻辑简洁**：相比双层 `for` 循环，少了一层嵌套，代码更容易理解。
  - **效率稍高**：由于减少了一层循环嵌套，执行效率相对双层循环有所提升。

- **缺点**：
  - 无法去重 `NaN` 和引用类型（如对象）。

- **适用场景**：
  - **面试手写**：逻辑简单好理解，适合在面试中快速写出。
  - **小数组处理**：适用于数据量较小，且明确不需要处理 `NaN` 和对象的场景。

## 改进方案：处理 NaN 去重 *Content-[07:28]

- **改进目标**：
  - 通过修改判断条件，将数组中的 `NaN` 全部去除。

- **代码修改**：
  - 将原有的判断条件 `resultArr.indexOf(arr[i]) === -1` 
  - 修改为：`arr.indexOf(arr[i]) === i`
  - **核心变化**：从原数组 `arr` 中查找当前元素 `arr[i]`，判断其返回的**第一次出现的下标**是否等于**当前的索引 `i`**。如果相等，则 `push` 进结果数组；如果不相等，则跳过。

- **改进后的结果**：
  - 数字、字符串、`true` 等正常去重。
  - 所有的 `NaN` 全部被成功去除（一个都不保留）。

## 改进方案原理详细推导 *Content-[08:02]

- **推导过程（以原数组 `arr` 为例）**：
  - **第一轮（`i = 0`）**：
    - 当前元素 `arr[0]` 是数字 `1`。
    - `arr.indexOf(1)` 返回第一次出现的下标 `0`。
    - 判断 `0 === 0`，结果为 `true`，将数字 `1` `push` 进结果数组。
  - **第二轮（`i = 1`）**：
    - 当前元素 `arr[1]` 是数字 `1`（重复元素）。
    - `arr.indexOf(1)` 依然返回第一次出现的下标 `0`。
    - 判断 `0 === 1`，结果为 `false`，不执行 `push`，成功过滤重复项。
  - **第三轮（`i = 2`）**：
    - 当前元素 `arr[2]` 是字符串 `'1'`。
    - `arr.indexOf('1')` 返回下标 `2`。
    - 判断 `2 === 2`，结果为 `true`，将字符串 `'1'` `push` 进结果数组。
  - **第四轮（`i = 3`）**：
    - 当前元素 `arr[3]` 是 `true`。
    - `arr.indexOf(true)` 返回下标 `3`。
    - 判断 `3 === 3`，结果为 `true`，将 `true` `push` 进结果数组。
  - **第五轮（`i = 4`）**：
    - 当前元素 `arr[4]` 是 `true`（重复元素）。
    - `arr.indexOf(true)` 返回第一次出现的下标 `3`。
    - 判断 `3 === 4`，结果为 `false`，不执行 `push`。
  - **第六轮（`i = 5`）**：
    - 当前元素 `arr[5]` 是 `NaN`。
    - 因为 `indexOf` 底层使用全等，不识别 `NaN`，所以 `arr.indexOf(NaN)` 返回 `-1`。
    - 判断 `-1 === 5`，结果为 `false`，不执行 `push`。
  - **第七轮（`i = 6`）**：
    - 当前元素 `arr[6]` 是 `NaN`。
    - `arr.indexOf(NaN)` 依然返回 `-1`。
    - 判断 `-1 === 6`，结果为 `false`，不执行 `push`。

- **推导结论**：
  - 因为 `indexOf` 底层只用全等（`===`）实现比较，不识别 `NaN`，找不到时永远返回 `-1`。
  - 而当前的索引 `i` 始终大于等于 `0`。
  - 因此，`-1 === i` 永远为 `false`，导致所有的 `NaN` 都不会被 `push` 进结果数组，从而实现了将 `NaN` 全部去除的效果。
