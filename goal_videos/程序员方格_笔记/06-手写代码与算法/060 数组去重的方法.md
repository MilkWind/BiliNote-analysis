## 1. ES6 Set 去重法（推荐） *Content-[00:20]

这是目前最新且在实际开发中非常推荐的方式，代码极其简洁高效。

**实现代码：**
```javascript
const arr = [1, 2, 2, 3, 4, 4, 5];
const uniqueArr = [...new Set(arr)];
console.log(uniqueArr);
```

**原理解析：**
1. `new Set(arr)`：创建一个 `Set` 集合，并将数组元素放入其中。`Set` 集合本身的特性是不包含重复元素，因此在放入的过程中会自动剔除重复项。
2. `[...new Set(arr)]`：使用 ES6 的扩展运算符（`...`）将 `Set` 集合中的元素展开，并重新放入一个新的数组中。
3. 整体逻辑相当于：先转换为 `Set` 去除重复，再从 `Set` 转换回数组。

## 2. for 循环结合 includes 去重法 *Content-[01:41]

这是以前比较熟知且经典的一种去重方式，主要依赖传统的循环和数组方法。

**实现代码：**
```javascript
const arr = [1, 2, 2, 3, 4, 4, 5];
const newArr = [];
for (let i = 0; i < arr.length; i++) {
    // 判断新数组中是否已包含当前元素
    if (!newArr.includes(arr[i])) {
        newArr.push(arr[i]);
    }
}
console.log(newArr);
```

**原理解析：**
1. 创建一个空数组 `newArr` 用于存放去重后的结果。
2. 使用 `for` 循环遍历原数组 `arr`。
3. 在循环内部，使用 `newArr.includes(arr[i])` 判断当前元素是否已经存在于新数组中。
4. 如果不存在（即返回 `false`），则使用 `push` 方法将该元素添加到 `newArr` 中；如果已存在，则跳过不处理。

## 3. 其他去重方法及复杂度分析 *Content-[03:03]

除了上述两种常见方法外，前端面试和实际开发中还有更多的数组去重方式（如 `filter` + `indexOf`、`reduce`、`Map`、利用 `Object` 键值对等）。

**复杂度考量与学习建议：**
