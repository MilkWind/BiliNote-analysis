## 核心原理 *Content-[00:00]
定时器版节流函数的核心原理主要通过控制定时器的状态来限制函数的执行频率，具体步骤如下：
- **初始化定时器**：首先定义一个定时器变量，初始值设置为空（`null`）。
- **状态判断**：每次触发事件时，判断该定时器是否为空。
  - 如果为空，说明当前没有定时器在运行，此时需要创建一个新的定时器。
- **延迟执行与重置**：
  - 定时器延迟指定时间后，执行事件处理函数。
  - 事件处理函数执行完毕后，将定时器变量重新置为空，以便下次触发时可以再次运行。
- **阻止重复执行**：在延迟时间内，如果定时器不为空，则阻止后续代码的执行，从而实现节流效果。

## 代码实现 *Content-[01:18]
根据核心原理，我们可以通过闭包来封装一个完整的节流函数，具体代码逻辑如下：

- **函数封装与参数接收**：
  - 定义节流函数 `throttle`，接收两个参数：事件处理函数 `fn` 和间隔时间 `interval`。
  - 在函数内部初始化定时器变量 `let timer = null`，用于跟踪是否有定时器正在运行。
  - 使用闭包返回一个新的函数，并接收展开参数 `...args`，以支持传递任意数量的参数。
- **核心逻辑判断**：
  - 检查 `timer` 是否为 `null`：
    - **如果为 `null`**：表示当前没有定时器运行，可以开启新的定时器。
      - 使用 `setTimeout` 设置定时器。
      - 在定时器的回调函数中，使用 `fn.apply(this, args)` 来执行事件处理函数，确保 `this` 指向正确，并传入参数。
      - 执行完毕后，将 `timer` 赋值为 `null`，以便下次触发时能够再次创建定时器。
    - **如果不为 `null`（`else` 分支）**：表示当前已有定时器在运行，直接 `return` 退出，不做任何操作。

```javascript
function throttle(fn, interval) {
    let timer = null;
    return function (...args) {
        if (timer === null) {
            timer = setTimeout(() => {
                // 使用 apply 保持 this 指向，并传递参数
                fn.apply(this, args);
                // 执行完毕后将定时器置为空，以便下次运行
                timer = null;
            }, interval);
        } else {
            // 定时器不为空，说明已有定时器在运行，直接返回
            return;
        }
    };
}
```

  - 使用 `window.addEventListener` 绑定窗口的 `resize`（缩放）事件。
  - 将封装好的节流函数作为事件处理函数传入。
- **参数设置**：
  - 在节流函数内部打印提示信息（如“窗口大小改变了”）。
  - 设置间隔时间（例如代码中设置的 `500ms`，演示时为了效果明显可调整为 `5000ms`）。
- **效果验证**：
  - `resize` 事件在窗口大小改变时会极其频繁地触发。
  - 使用节流函数后，无论在这段间隔时间内如何频繁缩放窗口，控制台都只会按照固定的频率（如每隔 500ms 或 5s）打印一次信息。
  - 成功实现了控制事件触发频率、保留固定频率执行的目的。

```javascript
window.addEventListener('resize', throttle(() => {
    console.log('窗口大小改变了');
}, 500)); // 间隔时间设置为 500ms
```

## 核心逻辑总结 *Content-[07:00]
无论使用的是时间戳版还是定时器版的节流函数，其本质和核心逻辑都是一致的：
- **节流的核心逻辑**：无论事件被触发多少次，都只按照**固定的频率**来执行事件处理函数。即“多次触发，固定频率执行”。
