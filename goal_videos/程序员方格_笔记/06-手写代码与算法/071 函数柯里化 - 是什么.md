## 2. 什么是函数柯里化？ *Content-[03:30]

### 大白话定义
函数柯里化就是把一个**接收多个参数的函数**，拆分成一系列**接收单个参数的函数**，并且**每调用一次就返回一个新的函数**，直到接收完所有参数才返回最终的结果。

### 生活案例理解：买奶茶
假设去奶茶店买奶茶需要三个参数：**口味**、**甜度**、**温度**。

- **普通函数模式**：一次性把三个要求（如：珍珠、少糖、去冰）都告诉店员，店员直接做好奶茶给你。
- **柯里化模式**：分步骤传递参数。
  1. 先告诉店员要“珍珠”，店员返回一个“选甜度”的函数。
  2. 再告诉店员要“少糖”，店员返回一个“选温度”的函数。
  3. 最后告诉店员要“去冰”，店员返回最终的奶茶（结果）。

**核心概念**：分步骤传参，逐步得到结果，而不是一次性传递所有参数。

### 伪代码对比
- **原始函数**：`f(a, b, c)` -> 直接得到结果。
- **柯里化函数**：`f(a)(b)(c)` -> 逐步得到结果。

## 3. 代码实战：普通函数 vs 柯里化函数 *Content-[06:51]

通过具体的代码对比，可以更清晰地理解两者的区别。

### 普通函数示例
功能：接收三个数字，返回它们的和。一次性传入所有参数，直接得到结果。

```javascript
// 普通函数：一次性接收 a, b, c 三个参数
function add(a, b, c) {
  return a + b + c;
}

// 调用方式：一次性传入所有参数
console.log(add(1, 2, 3)); // 输出: 6
```

### 柯里化函数示例
功能：和上面的普通函数一样，接收三个数字求和，但要求分三次传参。

```javascript
// 柯里化函数：分步骤传参
function curriedAdd(a) {
  // 第一次传参 a，返回一个新函数接收第二个参数 b
  return function(b) {
    // 第二次传参 b，返回一个新函数接收第三个参数 c
    return function(c) {
      // 第三次传参 c，接收完所有参数，返回最终结果
      return a + b + c;
    }
  }
}

// 调用方式：分三次传参，每次传一个，逐步调用
const add1 = curriedAdd(1); // 传第一个参数 1，得到接收 b 的函数
const add2 = add1(2);       // 传第二个参数 2，得到接收 c 的函数
const result = add2(3);     // 传第三个参数 3，得到最终结果

console.log(result);        // 输出: 6
```

**执行过程解析**：
1. `curriedAdd(1)`：传入 `a=1`，返回的函数“记住”了 `a` 的值。
2. `add1(2)`：传入 `b=2`，返回的函数“记住”了 `a` 和 `b` 的值。
3. `add2(3)`：传入 `c=3`，此时所有参数接收完毕，计算并返回 `a + b + c` 的最终结果。

## 4. 核心总结与本质特点 *Content-[12:51]

### 普通函数与柯里化函数的区别
- **普通函数**：一次性接收所有参数，直接返回计算结果。
- **柯里化函数**：分步骤传参，每次接收一个参数并返回一个新函数。新函数能够记住之前传入的参数（利用闭包特性），直到所有参数接收完毕，才返回最终结果。

### 柯里化的核心本质
1. **分步骤传参**：把多参数函数拆分成单参数函数，每次只传一个参数。
2. **参数缓存（记忆）**：通过返回新函数来缓存和记住已经传递的参数。
3. **延迟计算**：不立即执行最终逻辑，直到传完所有参数后再返回最终结果。

掌握“分步骤传参，把多参数拆成单参数”这一本质特点，就能轻松理解后续所有的柯里化进阶知识点和面试题。
