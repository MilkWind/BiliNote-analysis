## 1. 题目要求与限制条件 *Content-[00:00]
- **题目描述**：实现一个函数 $y = f(x, a, b)$，接收三个参数 $x$、$a$、$b$。
- **功能需求**：
  - 当 $x > 100$ 时，返回 $a$ 的值。
  - 当 $x \le 100$ 时，返回 $b$ 的值。
- **限制条件**（禁止使用以下语法）：
  - 条件判断语句：`if...else`、`switch`
  - 三元表达式：`? :`
  - 逻辑运算符：`&&`（逻辑与）、`||`（逻辑或）
  - 逗号运算符：`,`

## 2. 解题思路与核心逻辑 *Content-[00:45]
- **核心思想**：既然不能使用逻辑控制语句，可以通过**纯数学算式**来实现条件分支的效果。
- **目标转换**：
  - 构造一个中间变量（例如 `temp`），使其在 $x > 100$ 时值为 $1$，在 $x \le 100$ 时值为 $0$。
  - 利用该变量对 $a$ 和 $b$ 进行加权求和，从而在 $x > 100$ 时结果为 $a$，在 $x \le 100$ 时结果为 $b$。

## 3. 状态变量 temp 的计算 *Content-[01:30]
- **利用 `Math.max` 和 `Math.min` 构造状态变量**：
  - 定义公式：$temp = \min(1, \max(0, x - 100))$
- **逻辑推导**：
  - **当 $x > 100$ 时**（例如 $x = 110$）：
    - $x - 100 = 10$
    - $\max(0, 10)$ 返回 $10$
    - $\min(1, 10)$ 返回 $1$
    - 结论：$temp = 1$
  - **当 $x \le 100$ 时**（例如 $x = 99$ 或 $x = 100$）：
    - 若 $x = 99$，$x - 100 = -1$。$\max(0, -1)$ 返回 $0$，$\min(1, 0)$ 返回 $0$。
    - 若 $x = 100$，$x - 100 = 0$。$\max(0, 0)$ 返回 $0$，$\min(1, 0)$ 返回 $0$。
    - 结论：$temp = 0$
- **总结**：通过嵌套的 `Math.max` 和 `Math.min`，成功将 $x$ 的范围映射为二值状态（$0$ 或 $1$）。

## 4. 最终结果计算与代码实现 *Content-[04:40]
- **数学表达式**：
  - 最终返回值可以通过公式 $a \times temp + b \times (1 - temp)$ 计算得出。
- **效果验证**：
  - 当 $x > 100$ 时，$temp = 1$：$a \times 1 + b \times (1 - 1) = a \times 1 + b \times 0 = a$
  - 当 $x \le 100$ 时，$temp = 0$：$a \times 0 + b \times (1 - 0) = a \times 0 + b \times 1 = b$
- **完整代码实现**：
```javascript
function f(x, a, b) {
    let temp = Math.min(1, Math.max(0, x - 100));
    return a * temp + b * (1 - temp);
}
```
*(注：此解法的前提是传入的参数均为数字类型)*

## 5. 测试用例验证 *Content-[06:40]
- **测试用例 1**：`f(105, 9, 8)`
  - $x = 105$，大于 $100$。
  - 预期返回 $a$ 的值，即 `9`。实际运行结果正确。
- **测试用例 2**：`f(65, 9, 8)` 或 `f(-65, 9, 8)`
  - $x = 65$ 或 $x = -65$，均小于等于 $100$。
  - 预期返回 $b$ 的值，即 `8`。实际运行结果正确。
- **结论**：在不使用 `if...else` 等逻辑控制语句的前提下，利用数学函数和代数运算完美实现了条件分支逻辑。
