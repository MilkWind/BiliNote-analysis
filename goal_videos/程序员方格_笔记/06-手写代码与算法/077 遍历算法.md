## 深度优先遍历 (DFS) 详解 *Content-[02:11]

1\. **基本概念**：
   - 深度优先遍历（Depth-First Search, 简称 DFS）从根节点出发，尽可能地去遍历树状结构的所有分支。
   - 它会一直向下深入，直到达到最底层的叶子节点，然后再进行回溯，返回上一层继续遍历其他未访问的分支。

2\. **核心特征**：
   - 核心在于“深度”，即尽可能深入到树的最底层分支。
   - 适用于解决**连贯性问题**，例如路径查找（寻找从起点到终点的最深路径或特定路径）。

3\. **实现方式**：
   - 通常使用**递归 (Recursion)** 或 **栈 (Stack)** 来实现。递归天然契合 DFS 深入再回溯的特性。

4\. **实例演示**：
   - 假设有一棵树，结构如下：
     - 根节点 A
     - A 的子节点：B、C
     - B 的子节点：D、E
     - C 的子节点：F
   - **DFS 遍历顺序**：`A -> B -> D -> E -> C -> F`
   - **执行过程解析**：
     - 首先访问根节点 A。
     - 接着访问 A 的第一个子节点 B。
     - 为了“深入”，不直接访问 C，而是继续深入 B 的子节点，先访问 D。
     - D 是叶子节点，回溯到 B，访问 B 的另一个子节点 E。
     - 此时 B 的所有子节点遍历完毕，回溯到 A，访问 A 的第二个子节点 C。
     - 继续深入 C 的子节点 F。
     - 遍历结束。

## 广度优先遍历 (BFS) 详解 *Content-[07:06]

1\. **基本概念**：
   - 广度优先遍历（Breadth-First Search, 简称 BFS）同样从根节点出发，但它的策略是先遍历**当前层**的所有节点。
   - 它不考虑立即深入，而是先把当前层级能触及的所有节点都访问一遍，然后再进入下一层继续遍历。

2\. **核心特征**：
   - 核心在于“广度”和“层级”，即一层一层地按顺序遍历。
   - 适用于解决**最短路径问题**以及**层级遍历问题**。

3\. **实现方式**：
   - 通常使用**队列 (Queue)** 来实现。利用队列先进先出（FIFO）的特性，可以完美契合按层遍历的需求。

4\. **实例演示**：
   - 使用与 DFS 相同的树结构（A 为根，子节点 B/C，B 的子节点 D/E，C 的子节点 F）。
   - **BFS 遍历顺序**：`A -> B -> C -> D -> E -> F`
   - **执行过程解析**：
     - 第一层：访问根节点 A。
     - 第二层：访问 A 的所有子节点，即 B 和 C。
     - 第三层：访问 B 和 C 的所有子节点，即 D、E 和 F。
     - 遍历结束。

## DFS 与 BFS 的对比及适用场景 *Content-[10:50]

1\. **数据结构与实现对比**：
   - **DFS**：使用**栈 (Stack)** 或**递归**。执行顺序是“先深入到底，然后再回溯”。
   - **BFS**：使用**队列 (Queue)**。执行顺序是“先遍历当前层，然后再进入到下一层”，严格按层级推进。

2\. **适用场景对比**：
   - **DFS 适用场景**：
     - **目标路径查找**：需要挖到所有通道的最深处。由于它第一次就会直接深入到底，因此在某些特定路径查找中速度非常快。
     - **连通性问题**：判断节点之间是否连通。
   - **BFS 适用场景**：
     - **最短路径问题**：因为它是按层扩展的，第一次遇到目标节点时，所经过的层数一定是最少的，即最短路径。
     - **层级遍历**：例如遍历 DOM 树、文件目录树等需要按层级处理的场景。
