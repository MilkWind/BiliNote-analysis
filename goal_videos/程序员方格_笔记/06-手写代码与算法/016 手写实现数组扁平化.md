## 2. flat 方法的基本概念与核心特点 *Content-[01:02]
- **官方定义**：`flat` 方法会创建一个新的数组，其中所有子元素会按照指定的深度，被递归地提升到父数组中。
- **核心关键点**：
  1. **非破坏性**：不会修改原数组，而是返回一个全新的数组。这在函数式编程场景中非常重要。
  2. **递归处理**：能够处理一层、两层甚至多层的嵌套结构。
  3. **深度控制**：可以通过参数指定到底需要展开多少层。
  4. **兼容性**：作为 ES2019 引入的特性，目前主流浏览器和 Node.js 环境都支持得非常好。
- **典型应用场景**：处理树状结构或多维数组。例如，后端返回了按类别分组的数据，但前端需要一个扁平的列表来进行展示，此时 `flat` 可以快速完成数据清洗和转换。

## 3. flat 方法的具体用法与示例 *Content-[02:44]
- **基本用法（默认深度）**：
  - 当不传入任何参数时，`flat` 默认只展开深度为 1 的子数组。
  - 示例：`[1, 2, [3, 4]].flat()` 结果为 `[1, 2, 3, 4]`。
- **指定深度展开**：
  - 如果数组有多层嵌套，默认情况下只会展开第一层，更深层的嵌套保持原样。
  - 示例：对于两层嵌套的数组，调用 `arr.flat(2)` 传入参数 `2`，即可成功展开前两层，将数据完全铺平。
- **完全展开（无限深度）**：
  - 如果不知道具体有多少层，或者希望将所有层级全部展开，可以传入 `Infinity`（无穷大）。
  - 此时 `flat` 会一直递归，直到所有子数组都被展开为止。
- **其他重要特性**：
  1. **`depth` 参数**：深度参数默认值为 `1`；完全拍平需使用 `Infinity`。
  2. **自动移除空槽**：如果数组中存在空项（empty slots / 空槽），`flat` 会自动将其移除，不会保留在结果中。

## 4. 手写 flat 的核心思路：递归 vs 迭代 *Content-[05:23]
在面试中手写 `flat`，通常有两种方案来处理具有层级结构的问题：

- **方案一：递归（Recursion）**
  - **思想**：遍历数组，遇到普通元素直接放入新数组；遇到子数组，则对该子数组再次执行相同的操作。
  - **优点**：逻辑非常清晰，代码易于理解，能很好地体现对问题本质的理解。
  - **缺点**：容易导致**栈溢出（Stack Overflow）**。如果数组嵌套极深（如几千上万层），每次函数调用都会在调用栈中增加一层，最终可能撑爆栈空间。

- **方案二：迭代（Iteration）**
  - **思想**：用循环代替递归，手动维护一个数据结构（通常也是栈 Stack）来模拟递归过程。
  - **优点**：没有栈溢出的风险，性能和健壮性更好，特别适合处理嵌套极深的“变态”数组。
  - **缺点**：代码实现相对复杂，需要手动管理栈，将子元素逐个推入栈中再处理。

> **面试建议**：在面试时，建议将这两种思路都讲出来，并分析它们各自的优劣，这会让面试官刮目相看。本节课将重点讲解更经典、更能体现本质的**递归实现**。

## 5. 基于 reduce 的递归实现解析 *Content-[07:43]
这里采用了一种巧妙的实现方式：结合 `reduce` 方法来进行递归。

- **防御性编程与终止条件**：
  - 如果传入的 `arr` 根本不是数组，或者 `depth < 0`（说明不需要再展开），则直接返回当前 `arr`。这是递归的终止条件。
- **核心逻辑（使用 reduce）**：
  - `reduce` 接收两个参数：一个箭头回调函数，以及一个初始值（空数组 `[]`）。这个空数组将作为累加器 `acc` 的起点，也是最终返回的扁平化数组。
  - 在回调函数中，对当前遍历到的元素 `cur` 进行判断：
    1. **如果是数组且深度大于 0**：条件成立，将累加器 `acc` 与递归调用 `flat(cur, depth - 1)` 的结果进行合并（使用 `concat`），并返回。注意：在递归调用时，深度 `depth` 需要减 1，以消耗掉一层深度。
    2. **如果不是数组或深度已用完（为 0）**：直接将当前元素 `cur` 使用 `concat` 添加到累加器 `acc` 中。
- **核心思想总结**：
  - `reduce` 的累加器 `acc` 承载最终结果。
  - 遍历过程中，遇到数组就递归进入并将深度减 1；遇到非数组就直接收集结果。
  - 使用 `concat` 来合并每次处理的结果。
- **测试验证**：通过定义复杂的测试数组，分别测试深度为 1、深度为 2 以及无限深度（`Infinity`）的场景，控制台输出结果均完全正确，证明该基于 `reduce` 和递归的 `flat` 函数在功能上是完备的。

## 6. 将方法挂载到 Array.prototype *Content-[11:10]
为了让自定义的 `flat` 方法能够像原生方法一样通过 `arr.myFlat()` 的形式调用，需要将其挂载到 `Array.prototype` 上。

- **不推荐的做法**：
  - 直接赋值：`Array.prototype.myFlat = function() {...}`。
  - **原因**：在团队协作和维护大型项目时，直接修改原生对象的原型会污染全局原型链，甚至可能覆盖掉其他人或第三方库的实现，存在安全隐患。
- **专业且安全的做法**：
  - 使用 `Object.defineProperty` 进行挂载。
  - **参数解析**：
    1. **目标对象**：`Array.prototype`。
    2. **属性名**：自定义名称，例如 `'myFlat'`（为了与原生的 `flat` 区分）。
    3. **配置对象**：包含 `value` 属性，其值为具体的函数体。
  - **关键点**：在函数体内部，`this` 关键字将正确指向调用 `myFlat` 的那个数组实例。
