## 基础面试题解析：变量、类型与隐式转换 *Content-[00:00]

1\. **变量声明与报错机制**
- 如果变量声明不规范（例如没有使用 `var`、`let` 或 `const`），则**不存在变量提升**。
- 不存在提升意味着不能提前使用该变量，如果在声明前访问，会直接抛出 `ReferenceError`（即 `not defined` 报错）。

2\. **`undefined` 的产生场景**
- 变量已声明但未被赋值。
- 访问对象中不存在的属性或方法。
- 数组中未被赋值的空位元素。
- **注意区别**：`undefined` 表示值未被定义（是一个具体的值），而 `not defined` 是引擎抛出的报错信息。

3\. **`typeof null` 的返回值**
- 虽然 `null` 是基本数据类型，但 `typeof null` 会返回 `"object"`。
- 原因：`null` 在底层表示一个空指针对象，因此被检测为 `object`。

4\. **隐式类型转换与“邪恶六兄弟”**
- 在布尔类型转换（如 `if` 判断或逻辑运算）中，有六个特殊值会被当作 `false` 处理，被称为“邪恶六兄弟”：
  - `0`
  - `false`
  - `""`（空字符串）
  - `undefined`
  - `null`
  - `NaN`
- **特例说明**：`NaN` 非常特殊，它与任何值都不相等，**包括它自己**（`NaN === NaN` 为 `false`）。

## 引用数据类型与数组基础操作 *Content-[02:30]

1\. **引用数据类型的赋值**
- 引用数据类型在相互赋值时，传递的是**内存地址**。
- 当两个变量指向同一个地址时，修改其中一个变量的属性，另一个变量也会同步改变（即“一改全改”）。
- 示例：`let a = { y: 1 }; let b = a; b.y = 2;` 此时 `a.y` 也会变成 `2`。

2\. **数组的基础操作**
- **数组转字符串**：将数组转换为字符串时，可以在元素中间加入空格或逗号（如使用 `join(' ')`）。
- **数组倒序**：直接实现数组元素的翻转。
- **数组排序**：使用 `sort()` 方法配合回调函数。
  - **降序**：`return b - a`
  - **升序**：`return a - b`

## 逻辑运算符与短路特性 *Content-[04:06]

1\. **逻辑或 (`||`) 与逻辑与 (`&&`) 的短路特性**
- 当使用逻辑运算符进行条件判断时，会触发隐式类型转换。
- 如果左侧表达式的值是“邪恶六兄弟”之一（即转换为 `false`），则逻辑或 (`||`) 会返回右侧的值；如果左侧为 `true`，则返回左侧的值。
- 这种特性常用于代码中的**简单默认值赋值**或**条件短路判断**。

## 变量提升与作用域分析 *Content-[04:47]

1\. **变量提升的核心规则**
- **全局变量**：声明会被提升到全局作用域的第一行。
- **局部变量**：声明会被提升到局部作用域（函数内部）的第一行。
- **注意**：只有**声明部分**会被提升，**赋值操作**依然保留在代码执行的原位置。

2\. **作用域与变量覆盖**
- 当全局变量和局部变量同名时，局部变量会在其作用域内覆盖全局变量。
- 在分析代码输出时，必须先在脑海中补齐代码，画出变量提升后的结构，然后按顺序执行赋值和输出语句，才能得出正确结果（例如局部变量先被提升为 `undefined`，后续再被赋予具体数值）。

## 核心算法：生成指定范围的随机数 *Content-[06:09]

1\. **题目需求**
- 用 JavaScript 实现随机选取 10~100 之间的十个数字，存入数组并进行排序。

2\. **`Math.random()` 基础解析**
- `Math.random()` 不需要参数，返回一个 $[0, 1)$ 之间的浮点数（包含 0，不包含 1）。

3\. **随机数公式推导**
- **0 到 N 的随机整数**：
  - 如果直接 `Math.random() * 10`，结果是 $[0, 10)$。
  - 为了包含 10，需要乘以 11，即 `Math.random() * 11`，结果范围是 $[0, 11)$。
  - 使用 `Math.floor()` 向下取整，即可得到 0~10 的整数。公式：`Math.floor(Math.random() * (N + 1))`。
- **N 到 M 的随机整数（包含 N 和 M）**：
  - 需要计算跨度：$M - N$。为了包含 $M$，跨度需要 $+1$，即 $M - N + 1$。
  - 基础偏移量：$N$。
  - **最终通用公式**：
    $$ \lfloor \text{Math.random()} \times (M - N + 1) \rfloor + N $$
  - 代码实现：`Math.floor(Math.random() * (M - N + 1)) + N`。
  - 示例（10~100）：`Math.floor(Math.random() * (100 - 10 + 1)) + 10`。

## 核心算法：数组排序的封装与实现 *Content-[14:19]

1\. **自定义排序函数设计**
- 封装一个 `customSort(arr, rule)` 方法，接收数组和排序规则。
- 规则参数 `rule` 支持传入字符串：`'desc'` 表示降序，`'asc'` 表示升序。

2\. **排序逻辑实现**
- 首先将传入的规则统一转换为小写：`let r = rule.toLowerCase()`。
- 调用数组的 `sort()` 方法，在回调函数中判断规则：
  - 如果 `r === 'desc'`，则返回 `b - a`（降序）。
  - 否则返回 `a - b`（升序）。
- 代码示例：
  ```javascript
  function customSort(arr, rule) {
      let r = rule.toLowerCase();
      return arr.sort((a, b) => {
          return r === 'desc' ? b - a : a - b;
      });
  }
  ```
