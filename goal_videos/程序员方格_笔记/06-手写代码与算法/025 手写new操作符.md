## new 操作符的核心步骤 *Content-[00:17]

在面试中遇到手写 `new` 操作符的题目时，思路先行是关键。`new` 操作符本质上主要完成了以下三件事：

1\. **对象的创建**：首先需要创建一个全新的空对象。但光秃秃的对象是不够的，关键在于它的原型链必须正确连接到构造函数的原型对象上，这是实现继承的核心机制。
2\. **`this` 绑定**：对象创建完成后，需要让构造函数在这个新对象上执行一遍，从而为对象绑定各种属性。实现这一步的关键是通过 `apply` 或 `call` 方法，强制改变构造函数内部 `this` 的指向，使其指向刚刚创建的新对象，同时将调用时传入的参数一并交给构造函数。
3\. **返回值处理**：这是很多人容易忽略的一点，`new` 操作符有自己严格的返回规则。如果构造函数内部自己 `return` 了一个对象，那么 `new` 就必须返回这个 `return` 的对象；如果构造函数没有返回值，或者返回的是数字、字符串等基本类型，那么 `new` 必须返回第一步中创建并加工好的新对象。

## 代码实现：创建对象与原型链连接 *Content-[01:32]

理解了核心思路后，代码实现只是将思路翻译为代码。

- **定义函数与参数**：首先定义一个 `myNew` 函数，它接收两个参数。第一个是构造函数 `constructor`，第二个是使用剩余参数语法 `...args` 收集到的所有即将传入构造函数的参数。
- **创建空对象**：在函数内部，首先使用对象字面量 `{}` 创建一个空对象 `obj`。
- **连接原型链**：这是实现继承的关键一步。将 `obj` 的 `__proto__` 属性直接指向构造函数的原型对象（即 `constructor.prototype`）。这样一来，`obj` 就继承了构造函数原型上的所有属性和方法。例如，如果 `constructor` 是一个数组相关的构造函数，`obj` 现在就能使用数组的 `push` 和 `pop` 等方法。

## 代码实现：this 绑定与返回值处理 *Content-[02:30]

这一步是整个实现中最核心的部分，涉及构造函数的执行和返回值的处理。

- **执行构造函数与绑定 `this`**：使用 `apply` 方法来调用构造函数，这个方法同时完成了两件事：
  - `apply` 的第一个参数传入 `obj`，这会强制将构造函数内部的 `this` 指向我们刚刚创建的 `obj` 对象。因此，当构造函数内部执行 `this.xxx = xxx` 这样的赋值语句时，实际上就是在给 `obj` 添加属性。
  - `apply` 的第二个参数传入 `args` 数组，它会将之前收集到的所有参数原封不动地传递给构造函数。
- **接收返回值**：执行完 `apply` 后，构造函数可能会有返回值，因此使用一个变量 `result` 来接收它，这个结果直接关系到下一步的返回值处理。
- **返回值判断**：使用三元表达式来检查上一步构造函数返回的 `result`。
  - 通过 `result instanceof Object` 来判断 `result` 是否为对象类型。这个方法非常安全，因为如果 `result` 是 `null`，它也会返回 `false`。
  - 如果判断为对象，则遵循 `new` 的规则，直接返回 `result`。
  - 否则（即构造函数没有返回值，或者返回的是数字、字符串、布尔值等基本类型），则忽略该返回值，直接返回最初创建并且加工好的 `obj`。

## 代码优化：使用 Object.create *Content-[04:04]

虽然前面的代码已经实现了一个功能完整的 `myNew`，但在实际面试中，我们还可以对代码进行优化，使其更加专业和优雅。

- **避免直接操作 `__proto__`**：在第一步中，我们直接操作了 `__proto__` 这个非标准属性。不推荐这样做的原因是，它在不同的浏览器上可能有不同的判断标准和兼容性表现。
- **使用 `Object.create`**：我们可以使用更符合规范的 `Object.create` 方法，将“创建空对象”和“连接原型链”这两步合并为一行代码：`const obj = Object.create(constructor.prototype)`。
  - `Object.create` 的作用正是创建一个新对象，并且让这个新对象的原型链指向传入的第一个参数。
  - 使用 `Object.create` 代替对象字面量和 `__proto__` 赋值，不仅功能完全一样，而且代码显得更专业、逼格更高，在面试中绝对是加分项。

## 面试总结与核心要点 *Content-[05:07]

在面试中回答这道题时，本质上考察的是你对 JavaScript 对象创建过程的深刻理解。只需要牢记以下核心要点：

- **核心步骤**：创建对象并连接原型链 -> `this` 执行绑定 -> 返回值判断。
- **核心 API 组合**：
  - `Object.create`：负责创建新对象和实现原型链继承。
  - `apply`：负责执行构造函数、绑定 `this` 指向并传递参数。
- **区分普通与优秀答案的关键**：最后一步的返回值判断。很多人会忽略构造函数返回对象或基本类型时的不同处理规则，大家一定要记住并准确答出这个关键点。只要把这些要点都清晰地表达出来，面试就能稳拿高分。
