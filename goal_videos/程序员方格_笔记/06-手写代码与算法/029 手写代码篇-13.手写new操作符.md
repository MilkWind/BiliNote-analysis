## 核心思路：new 操作符的三个步骤 *Content-[00:15]

在动手写代码之前，首先需要理清 `new` 操作符在底层到底执行了哪些操作。核心可以拆解为以下三个步骤：

1\. **对象的创建与原型链连接**
- 首先，创建一个全新的空对象。
- 关键在于，必须将该对象的 `__proto__` 属性正确连接到构造函数的原型对象（`prototype`）上，这是实现继承的核心。

2\. **`this` 绑定与属性初始化**
- 创建好对象后，需要让构造函数在这个新对象上执行一遍，以初始化各种属性。
- 核心操作是通过 `apply` 或 `call` 方法，强制改变构造函数内部 `this` 的指向，使其指向刚创建的新对象。
- 同时，需要将调用时传入的参数一并交给构造函数。

3\. **返回值处理**
- 这是一个容易被忽略的细节，`new` 操作符有自己特定的返回规则：
  - 如果构造函数内部自己 `return` 了一个**对象**，那么 `new` 操作符必须返回这个被 `return` 的对象。
  - 如果构造函数没有返回值，或者返回的是数字、字符串、布尔值等**基本类型**，那么 `new` 操作符必须忽略该返回值，直接返回第一步创建的那个新对象。

## 代码实现：逐步手写 myNew *Content-[01:32]

理解了核心思路后，就可以将思路翻译为具体的代码实现。

### 1. 函数定义与参数接收
- 定义一个 `myNew` 函数。
- 接收两个参数：第一个是构造函数 `constructor`，第二个是使用剩余参数语法 `...args` 收集的所有即将传入构造函数的参数。

### 2. 第一步：创建对象与连接原型
- 使用对象字面量 `{}` 创建一个空对象 `obj`。
- 将 `obj.__proto__` 直接指向 `constructor.prototype`。
- 这样 `obj` 就继承了构造函数原型上的所有属性和方法（例如，如果 `constructor` 是 `Array`，`obj` 就能使用 `push` 和 `pop` 等方法）。

### 3. 第二步：`this` 绑定与执行构造函数
- 使用 `constructor.apply(obj, args)` 调用构造函数。
- `apply` 的第一个参数 `obj` 强制将构造函数内部的 `this` 指向新创建的对象，此时构造函数内的 `this` 赋值语句实际上就是在给 `obj` 添加属性。
- `apply` 的第二个参数 `args` 是一个数组，将之前收集的参数原封不动地传递给构造函数。
- 使用变量 `result` 接收构造函数执行后的返回值，为下一步的返回值处理做准备。

### 4. 第三步：返回值处理
- 使用三元表达式对 `result` 进行判断。
- 通过 `result instanceof Object` 来检查 `result` 是否为对象类型。这是一个非常安全的检查方法，因为如果 `result` 是 `null`，该方法也会返回 `false`。
- 如果判断为对象，则遵循 `new` 的规则，直接返回 `result`。
- 否则（即没有返回值或返回基本类型），则忽略 `result`，直接返回最初创建并加工好的 `obj`。

## 代码优化：使用 Object.create 提升专业度 *Content-[04:04]

在面试中，写出基础版本后，还可以对代码进行优化，以展现更高的专业度。

- **避免直接操作 `__proto__`**：不推荐直接操作 `__proto__` 这个非标准属性，因为不同浏览器对其判断和实现标准可能存在差异。
- **使用 `Object.create`**：更优雅且符合规范的方法是使用 `Object.create`。
- **代码合并**：可以将“创建空对象”和“连接原型链”这两步合并为一行代码：
  ```javascript
  const obj = Object.create(constructor.prototype);
  ```
- **优势**：`Object.create` 的作用正是创建一个新对象，并让该新对象的原型链指向传入的第一个参数。使用这种方法不仅功能完全一致，而且代码更简洁、规范，在面试中绝对是加分项。

## 面试总结与核心要点 *Content-[05:07]

最后，对 `new` 操作符的手写实现进行总结，牢记以下核心要点：

- **考察本质**：本质上考察的是对 JavaScript 对象创建过程的深入理解。
- **核心口诀**：创建对象并连接原型 -> `this` 执行绑定 -> 返回值判断。
- **核心 API 组合**：
  - `Object.create`：负责创建对象和实现继承。
  - `apply`：负责执行构造函数和绑定 `this`。
- **拉开差距的关键**：区分普通答案与优秀答案的关键在于**最后一步的返回值判断**，务必记住处理构造函数返回对象与返回基本类型的不同逻辑。
