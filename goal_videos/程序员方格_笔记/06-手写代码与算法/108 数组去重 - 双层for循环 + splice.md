## 1. 面试题解析与数组去重概念 *Content-[00:00]

### 面试常见问题
在找前端工作或跳槽时，数组去重是大厂面试官必问的高频操作题，也是开发中处理列表数据筛选时的常见需求。面试官通常会问以下 5 个问题：
1. 你知道哪些数组去重的方法？
2. 如何手写实现数组去重？要求处理 `NaN`。
3. `indexOf` 和 `includes` 去重的区别是什么？
4. `Set` 去重的原理是什么？为什么不能去掉空对象？
5. 不同去重方法的性能如何？开发中你会选哪种？

### 数组去重的概念
- **定义**：把数组中重复出现的元素删掉，多余的只保留一个。例如将 `[1, 1, 2, 2, 3]` 去重后变成 `[1, 2, 3]`。
- **通俗比喻**：就像整理衣柜，把两件一模一样的衣服只留一件，剩下的丢掉，让衣柜里的衣服都是唯一的。

## 2. 数组去重的核心难点 *Content-[02:38]

去重并非所有重复元素都能轻松去掉，以下三种情况是面试必考的坑点，必须重点关注：

- **`NaN` 的去重**：
  - `NaN` 有一个特殊特性：它与自己本身都不相等（即 `NaN === NaN` 返回 `false`）。
  - 因此，普通的比较方法无法识别并去除重复的 `NaN`。
- **类型区分**：
  - 需要区分不同类型的数据，例如数字 `1` 和字符串 `'1'`。
  - 去重时应保留各自类型唯一的一个，不能将不同类型但值相似的元素误删。
- **引用类型去重**：
  - 例如两个空对象 `{}` 和 `{}`，虽然内容看起来相同，但它们在内存中的地址不同，属于两个不同的对象。
  - 不能将它们当作重复元素去掉。

## 3. 去重方法的选择逻辑 *Content-[04:49]

根据不同的应用场景，选择合适的去重方法：
- **开发快速实现**：优先使用 ES6 的 `Set` 方法，一行代码即可搞定。
- **面试手写实现**：优先选择 `for` 循环 + `includes`，或者 `reduce` + `includes`。逻辑简单好理解，且不容易产生 bug。
- **特殊场景**：需要使用对象或 `Map` 进行去重，以处理复杂的数据（如引用数据类型）。
- **性能敏感场景**：使用 `Set` 或 `Map`，在处理大数据量时速度更快。

## 4. 方法一：双层 for 循环 + splice *Content-[05:32]

### 核心逻辑
- **通俗比喻**：全班同学排队，每个人依次和后面的人核对，发现和自己一模一样的人就让对方离开队伍，直到所有人都核对完，队伍里剩下的都是唯一的人。
- **实现思路**：
  - **外层循环**：遍历数组的每一个基准元素（原数组中的值）。
  - **内层循环**：拿基准元素和后面的元素一一对比。
  - **删除操作**：找到重复元素后，使用 `splice` 方法删掉后面的重复项。

### 代码实现细节
1. **复制数组（加分项）**：
   - 首先使用扩展运算符 `...` 复制数组（如 `let newArr = [...arr]`），断开引用地址，避免修改原数组。在面试中考虑到这一点是绝对的加分项，体现了编程的全面性。
2. **外层循环控制**：
   - `for (let i = 0, len = newArr.length; i < len - 1; i++)`。
   - 遍历到倒数第二个即可，最后一个元素无需比较。
3. **内层循环控制**：
   - `for (let j = i + 1; j < len; j++)`。
   - 类似九九乘法表，当前元素与后面的元素进行比较。
4. **比较与删除**：
   - 使用严格相等 `===` 来判断，以区分类型。
   - 如果 `newArr[i] === newArr[j]`，则使用 `newArr.splice(j, 1)` 删除第 `j` 位的元素。
5. **索引回退（关键细节）**：
   - 删除元素后，数组长度会发生变化，因此需要同步更新 `len`（`len--`），使后续循环少一次。
   - 同时，内层循环的索引 `j` 也需要回退一步（`j--`）。因为删除元素后，后面的元素会往前移，如果不回退 `j`，就会跳过下一个元素的比较，导致漏删。

### 测试验证
- **测试数组**：包含数字 `1`、字符串 `'1'`、布尔值 `true`、`NaN`（两个）、空对象 `{}`（两个）。
- **运行结果**：成功去除了重复的数字 `1`，保留了字符串 `'1'`、`true`、两个 `NaN` 和两个空对象。
- **结论**：该方法能处理类型区分和引用类型（空对象不去重），但**无法处理 `NaN`**（因为 `NaN === NaN` 为 `false`）。
