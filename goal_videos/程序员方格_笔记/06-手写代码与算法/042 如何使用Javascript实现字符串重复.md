## 1. 使用 repeat() 方法 *Content-[00:01]

实现字符串重复最直接的方式是使用 JavaScript 字符串的原生方法 `repeat()`。该方法可以直接对当前字符串进行指定次数的重复操作。

- **实现思路**：直接调用字符串的 `repeat(times)` 方法，传入需要重复的次数。
- **代码示例**：
  ```javascript
  const str = 'hello';
  // 将字符串重复 3 次
  const result = str.repeat(3); 
  console.log(result); // 输出: 'hellohellohello'
  ```
- **特点**：实现非常简单、直观，是首选的原生 API 方案。

## 2. 使用 Array 与 join() 组合 *Content-[01:05]

除了原生字符串方法，还可以巧妙地结合数组的创建与 `join()` 方法来实现字符串重复。

- **实现思路**：创建一个指定长度的空数组，然后通过 `join(str)` 方法，以目标字符串作为分隔符将数组元素拼接起来。
- **代码示例**：
  ```javascript
  const str = 'hello';
  const times = 3;
  // 创建长度为 times + 1 的空数组，使用 join 以 str 进行拼接
  const result = new Array(times + 1).join(str);
  console.log(result); // 输出: 'hellohellohello'
  ```
- **特点**：思路比较巧妙，利用了数组 `join()` 方法在元素之间插入分隔符的特性。

## 3. 使用 for 循环拼接 *Content-[02:02]

这是最常规、最基础的编程思路，适合用来展示对基础语法的掌握。

- **实现思路**：初始化一个空字符串变量，利用 `for` 循环执行指定的次数，每次循环将目标字符串拼接到结果变量中。
- **代码示例**：
  ```javascript
  const str = 'hello';
  const times = 3;
  let result = '';
  
  // 使用 for 循环进行常规拼接
  for (let i = 0; i < times; i++) {
      result += str;
  }
  console.log(result); // 输出: 'hellohellohello'
  ```
- **特点**：逻辑简单易懂，属于最基础的算法实现方式。

## 4. 使用 Array.fill() 与 join() 组合 *Content-[03:08]

这种方法结合了 ES6 的数组方法，体现了更现代的函数式编程思维。

- **实现思路**：首先通过 `Array(times)` 创建对应长度的数组，然后使用 `fill(str)` 将数组的每一项都填充为目标字符串，最后通过 `join('')` 将数组无缝合并成字符串。
- **代码示例**：
  ```javascript
  const str = 'hello';
  const times = 3;
  
  // 创建数组 -> 填充内容 -> 拼接字符串
  const result = Array(times).fill(str).join('');
  console.log(result); // 输出: 'hellohellohello'
  ```
- **特点**：代码简洁，链式调用，展现了良好的 API 熟练度。

## 5. 核心方法论与总结 *Content-[03:55]

在面试中回答此类场景题时，不仅要给出代码，还要展现出思维的广度和对底层逻辑的理解。
