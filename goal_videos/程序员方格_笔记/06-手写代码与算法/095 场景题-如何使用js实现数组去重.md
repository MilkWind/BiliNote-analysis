## 2. 方法一：使用 Set 数据结构 *Content-[00:35]
- **核心原理**：利用 ES6 引入的 `Set` 数据结构，其内部成员具有唯一性，会自动过滤重复值。
- **实现思路**：
  - 将原数组传入 `new Set()` 中进行去重处理。
  - 通过扩展运算符（解构）或 `Array.from()` 将 `Set` 结构重新转换回数组格式。
- **代码示例**：
  ```javascript
  const arr = [1, 2, 2, 3, 4, 4];
  // 方式一：使用扩展运算符
  const uniqueArr1 = [...new Set(arr)];
  // 方式二：使用 Array.from
  const uniqueArr2 = Array.from(new Set(arr));
  ```
- **特点**：代码最简洁，是 ES6 中最常用、最推荐的去重方式之一。

## 3. 方法二：使用 filter 方法 *Content-[01:36]
- **核心原理**：利用数组的 `filter()` 方法结合 `indexOf()` 进行条件过滤。
- **实现思路**：
  - `indexOf()` 方法始终返回元素在数组中**第一次**出现的索引。
  - 在 `filter` 的回调函数中，判断当前元素的下标 `index` 是否等于 `arr.indexOf(item)`。
  - 如果相等，说明是第一次出现，保留该元素；如果不等，说明是重复元素，将其过滤掉。
- **代码示例**：
  ```javascript
  const arr = [1, 2, 2, 3, 4, 4];
  const uniqueArr = arr.filter((item, index) => {
      return arr.indexOf(item) === index;
  });
  ```
- **特点**：逻辑清晰，巧妙利用了原生数组方法的特性，代码可读性较好。

## 4. 方法三：使用 reduce 方法 *Content-[02:35]
- **核心原理**：利用 `reduce()` 方法累加结果，结合 `includes()` 判断元素是否已存在。
- **实现思路**：
  - 设置一个空数组作为累加器的初始值。
  - 遍历原数组，使用 `includes()` 判断当前元素是否已经存在于累加器数组中。
  - 如果已存在，则直接返回原来的累加器；如果不存在，则将当前元素添加到累加器中并返回。
- **代码示例**：
  ```javascript
  const arr = [1, 2, 2, 3, 4, 4];
  const uniqueArr = arr.reduce((acc, cur) => {
      return acc.includes(cur) ? acc : [...acc, cur];
  }, []);
  ```
- **特点**：展现了函数式编程的思想，通过累加器一步步构建最终结果。

## 5. 方法四：使用 forEach 遍历 *Content-[03:51]
- **核心原理**：最基础、最普通的遍历实现方式，通过外部变量存储结果。
- **实现思路**：
  - 首先创建一个用于存放最终结果的空数组 `result`。
  - 使用 `forEach`（或 `for` 循环）遍历原数组。
  - 在遍历过程中，判断 `result` 数组中是否**不存在**当前元素（`!result.includes(item)`）。
  - 如果不存在，说明是唯一的，将其 `push` 存入 `result` 中；如果存在则直接跳过。
  - 遍历结束后返回 `result`。
- **代码示例**：
  ```javascript
  const arr = [1, 2, 2, 3, 4, 4];
  const result = [];
  arr.forEach(item => {
      if (!result.includes(item)) {
          result.push(item);
      }
  });
  ```
- **特点**：逻辑最直白，适合初学者理解去重的本质，但代码相对冗长。

## 6. 方法五：对象数组去重与 Map 应用 *Content-[05:10]
- **核心原理**：针对复杂的对象数组，利用对象的特定属性或 `Map` 数据结构进行去重。
- **实现思路**：
  - **基于对象属性**：通过对象的某个唯一属性（如 `id`）来判断是否重复。
  - **基于 Map 数据结构**：使用 `new Map()` 来存储唯一的相关内容及对应的 `value`。将对象的唯一标识作为 `key`，对象本身作为 `value` 存入 `Map` 中，最后提取所有的 `value` 组成新数组。
- **代码示例（Map 方式）**：
  ```javascript
  const arr = [{id: 1, name: 'A'}, {id: 2, name: 'B'}, {id: 1, name: 'C'}];
  
  // 方式一：利用 Map 和 filter
  const map = new Map();
  const uniqueArr1 = arr.filter(item => {
      if (!map.has(item.id)) {
          map.set(item.id, item);
          return true;
      }
      return false;
  });

  // 方式二：直接利用 Map 的 values
  const uniqueArr2 = Array.from(new Map(arr.map(item => [item.id, item])).values());
  ```
- **特点**：解决了基本数据类型去重无法处理的引用数据类型（对象数组）去重问题，是进阶面试中常考的扩展点。
