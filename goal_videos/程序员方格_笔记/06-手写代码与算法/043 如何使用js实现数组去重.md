## 1. Set 数据结构去重 *Content-[00:35]
- **背景说明**：数组去重是历年前端面试中考察频次非常高的场景题，也是实际工作中经常遇到的高频场景。面试时建议多思考并使用多种思路进行解答。
- **核心思路**：利用 ES6 引入的 `Set` 数据结构，其特性是成员都是唯一的，没有重复的值。
- **实现方式**：将原数组传入 `new Set()` 中，利用其自动去重的特性，然后再通过扩展运算符或 `Array.from` 将其转换回数组。
- **代码示例**：`[...new Set(array)]` 或 `Array.from(new Set(array))`。
- **优势**：代码极其简洁，是 ES6 中最常用、最简单的数组去重实现方式。

## 2. filter 方法去重 *Content-[01:39]
- **核心思路**：利用数组的 `filter` 方法结合 `indexOf` 进行条件过滤。
- **实现方式**：遍历数组，判断当前元素 `item` 在数组中第一次出现的索引（即 `indexOf` 返回的值）是否等于当前遍历的下标 `index`。
- **逻辑判断**：
  - 如果 `array.indexOf(item) === index`，说明是第一次出现，保留该元素。
  - 如果 `indexOf` 返回的索引不等于当前下标，说明该元素已经重复，将其过滤掉。
- **优势**：逻辑简单，代码可读性好，也是常用的去重方式之一。

## 3. reduce 方法去重 *Content-[02:35]
- **核心思路**：使用数组的 `reduce` 方法进行累加，结合 `includes` 方法判断元素是否已存在。
- **实现方式**：
  - 初始化一个空数组作为累加器的初始值。
  - 在 `reduce` 的回调函数中，使用 `includes` 判断当前元素是否已经存在于累加结果数组中。
  - 如果已存在，说明重复，直接返回原来的累加结果数组。
  - 如果不存在，则将该元素添加到累加结果数组中并返回新数组。
- **优势**：展示了函数式编程的思想，通过累加和条件判断实现去重，体现了对数组高阶函数的深入理解。

## 4. forEach 遍历去重 *Content-[03:51]
- **核心思路**：使用最基础的 `forEach`（或普通 `for` 循环）遍历数组，手动维护一个结果数组。
- **实现方式**：
  - 创建一个空数组（如 `result`）用于存放最终去重后的结果。
  - 遍历原数组，判断当前元素是否存在于 `result` 数组中。
  - 如果不存在，则将其 `push` 到 `result` 中；如果已存在，则直接跳过。
  - 遍历结束后，返回 `result` 数组。
- **优势**：这是一种比较普通、基础的实现方式，逻辑非常直观，适合展现扎实的编程基本功。

## 5. 对象与 Map 属性去重 *Content-[05:10]
- **核心思路**：针对包含对象的数组，利用对象的属性唯一性或 `Map` 数据结构来进行去重。
- **实现方式**：
  - 使用 `new Map()` 来存储对象中用于判断唯一性的相关属性（作为 key）以及对应的对象本身（作为 value）。
  - 遍历对象数组，将唯一标识存入 Map 中。
  - 最后提取 Map 中的 values，组成去重后的对象数组。
- **优势**：专门解决了对象数组无法直接使用基本数据类型去重方法的问题，通过键值对映射实现精准去重，是处理复杂数据结构的必备技能。
