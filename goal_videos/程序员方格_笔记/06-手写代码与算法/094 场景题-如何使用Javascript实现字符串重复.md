## 使用 String.prototype.repeat 方法 *Content-[00:00]
- **方法说明**：利用 JavaScript 字符串内置的 `repeat` 方法，这是实现字符串重复最简单、最直接的方式。
- **代码示例**：
  ```javascript
  const str = 'hello';
  const result = str.repeat(3); 
  // 输出结果: 'hellohellohello'
  ```
- **特点**：语法简洁，易于理解，是首选的原生 API 解决方案。

## 使用 Array 与 join 组合 *Content-[01:05]
- **方法说明**：通过创建指定长度的数组，然后利用数组的 `join` 方法将目标字符串进行拼接。
- **实现思路**：
  1. 根据重复次数创建一个对应长度的空数组。
  2. 使用 `join(str)` 方法，以目标字符串作为分隔符将数组元素连接起来。
- **特点**：这是一种非常巧妙的思路，避开了显式的循环，利用了数组的高阶方法来完成字符串的重复。

## 使用 for 循环拼接 *Content-[02:02]
- **方法说明**：使用最常规的 `for` 循环，通过累加的方式拼接字符串。
- **实现思路**：
  1. 初始化一个空的结果字符串 `result`。
  2. 使用 `for` 循环遍历指定的重复次数 `times`。
  3. 在每次循环中，将目标字符串拼接到 `result` 中。
- **代码示例**：
  ```javascript
  let result = '';
  for (let i = 0; i < times; i++) {
      result += str;
  }
  ```
- **特点**：逻辑最为基础和常规，适合初学者理解，展现了最底层的实现逻辑。

## 使用 Array.from 与 fill、join 组合 *Content-[03:08]
- **方法说明**：结合 `Array.from`（或 `Array` 构造函数）、`fill` 以及 `join` 方法来生成重复字符串。
- **实现思路**：
  1. 使用 `Array.from` 或 `new Array(length)` 创建指定长度的数组。
  2. 使用 `fill(str)` 方法将数组的每一项都填充为目标字符串 `str` 作为默认值。
  3. 最后使用 `join('')` 方法将数组中的所有元素合并成一个完整的字符串。
- **代码示例**：
  ```javascript
  // 方式一：使用 new Array 和 fill
  const result = new Array(times).fill(str).join('');
  
  // 方式二：使用 Array.from
  const result2 = Array.from({ length: times }, () => str).join('');
  ```
- **特点**：充分利用了 ES6 的数组方法，代码表达力强，体现了对数组操作手段的熟练掌握。
