## new 操作符的基础概念 *Content-[01:23]
- **语法定义**：`new` 是 JavaScript 的一个内置操作符，它不是一个函数，因此不能像调用函数一样去调用它。
- **主要用途**：用于创建对象的实例。
- **适用场景**：
  - **内置构造函数**：例如 `new Date()`、`new Array()`、`new Promise()`、`new Object()`、`new Error()` 等。
  - **自定义构造函数**：使用 `function` 关键字或 `class` 定义的构造函数。
- **执行过程**：`new` 操作符会调用提供的构造函数，并在这一过程中完成一系列关键的初始化工作，最终基于构造函数创建出一个该类型的新对象。

## 为什么要手写 new 操作符 *Content-[02:22]
既然 `new` 是内置的，直接使用即可，但手写实现它具有以下重要原因：
1\. **深入理解原型与继承**：手写过程要求开发者思考新创建的对象如何与构造函数的 `prototype` 属性关联，从而继承原型链上的方法和属性。这是理解 JavaScript 面向对象编程的基础。
2\. **揭示 `this` 绑定的特殊机制**：普通函数调用时 `this` 指向全局对象，但当函数被 `new` 调用时，`this` 会被绑定到新创建的对象上。手写过程需要模拟这一特殊的 `this` 绑定行为。
3\. **面试常考点**：许多公司喜欢通过这个问题来考察开发者对 JavaScript 基础概念的掌握深度。如果能流畅写出并解释 `new` 的实现，能够证明基础非常扎实。
- **核心意义**：手写 `new` 不仅是为了重复造轮子，更是为了“知其然，知其所以然”。

## new 操作符的底层核心步骤 *Content-[03:49]
根据 ES 规范，`new` 操作符在底层主要执行以下四个核心步骤：

1\. **创建新对象**：在内存中凭空创建一个全新的、空的普通 JavaScript 对象，就像写一个空的对象字面量 `{}` 一样。
2\. **设置原型链**：将新创建对象内部的 `[[Prototype]]` 属性（即通过 `__proto__` 访问的属性）设置为构造函数的 `prototype` 属性值。通过这一步，新对象就继承了构造函数原型上的所有属性和方法。
3\. **绑定 `this` 并执行构造函数**：JavaScript 引擎会将新创建的对象作为构造函数调用时的 `this` 值，并携带传递给 `new` 操作符的参数，去执行构造函数内部的代码。构造函数内通过 `this.property = value` 这样的语句为新对象添加属性。
4\. **处理返回值**：构造函数执行完毕后，`new` 会检查构造函数的返回值：
  - 如果返回了一个**非原始值**（例如对象、数组或函数），那么 `new` 的结果就是这个返回值，而不是最开始创建的那个新对象。
  - 如果返回了一个**原始值**（例如字符串、布尔值、数字、`null` 或 `undefined`），注意 `null` 在这里作为原始值处理，那么 `new` 操作符的返回值就是第一步创建的那个新对象。

## 手写 myNew 函数的代码实现 *Content-[06:45]
根据上述四个步骤，使用 JavaScript 代码模拟实现一个 `myNew` 函数：

- **参数接收**：`myNew` 至少接收一个参数 `constructor`（构造函数），后续跟着的是传递给构造函数的参数（使用剩余参数 `...args` 收集）。
- **步骤 1 & 2 实现（创建对象与设置原型链）**：
  - 最直观且推荐的方式是使用 `Object.create(constructor.prototype)`。
  - 该方法会创建一个新对象，并使用现有的对象（构造函数的 `prototype`）作为新对象的原型，从而同时完成创建新对象和设置原型链这两步，语义更加简洁且符合规范。
  - 将新对象存储在 `instance` 变量中。（注：也可以先创建空对象再手动设置 `__proto__`，但 `Object.create` 更优雅）。
- **步骤 3 实现（绑定 `this` 并执行构造函数）**：
  - 使用 `constructor.apply(instance, args)` 调用构造函数。
  - `apply` 的第一个参数 `instance` 作为构造函数的 `this` 值。
  - 第二个参数使用扩展运算符 `...args` 把所有剩余参数收集成一个数组传进去。
  - 将构造函数的返回值保存在 `result` 变量中。
- **步骤 4 实现（处理返回值）**：
  - 判断 `result` 是否为非原始值（对象或函数）。
  - 判断条件：`(typeof result === 'object' && result !== null) || typeof result === 'function'`。
  - 如果满足条件（即返回了非原始值），直接返回 `result`；否则返回最初创建的 `instance` 对象。

## 手写 myNew 的核心要点解析 *Content-[11:25]
在实现 `myNew` 时，需要重点关注以下几个核心细节：
1\. **原型链的设置**：必须确保新对象的原型正确指向构造函数的原型属性，推荐使用 `Object.create` 这一标准且优雅的实现方式。
2\. **`this` 的绑定**：正确实现 `this` 绑定逻辑，在执行构造函数时，必须保证函数体内的 `this` 指向创建的新对象。通常通过 `Function.prototype.call` 或 `apply` 实现，此处使用 `apply` 是因为它更方便传递参数数组。
3\. **返回值的判断**：这是模拟 `new` 操作符完整行为的关键细节。一定要区分构造函数返回的是原始值还是非原始值，因为这直接影响 `new` 的最终结果。牢记原则：**非原始值优先，原始值忽略**。
4\. **参数的传递**：考虑到构造函数可能需要参数进行初始化，`myNew` 函数需要能接收这些参数并准确转发给构造函数，因此使用扩展运算符配合 `apply` 来实现。
