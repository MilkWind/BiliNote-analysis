## 手写 bind 的基本特性与用法 *Content-[00:00]

在 JavaScript 中，`bind` 方法与 `call` 和 `apply` 在整体逻辑上有很大的不同。理解 `bind` 的核心特性是手写实现的前提。

- **核心特点**：
  - **返回新函数**：`bind` 不会立即执行原函数，而是返回一个新的函数。
  - **改变 `this` 指向**：能够永久性地改变返回函数内部的 `this` 指向。
  - **支持传参**：允许在绑定和调用时传入参数。

- **使用示例**：
  ```javascript
  const foo = { a: 1 };
  
  function bar() {
      console.log(this.a);
  }
  
  // 调用 bind 返回一个新函数，此时并未执行 bar
  const bindFoo = bar.bind(foo); 
  
  // 执行返回的新函数，此时 this 指向 foo
  bindFoo(); // 输出: 1
  ```

## 最简版 bind 的实现 *Content-[02:05]

由于 `bind` 改变 `this` 指向和传参的特性与 `call`/`apply` 类似，我们可以借助原生的 `apply` 或 `call` 方法来实现最简版的 `bind`。

- **实现思路**：
  1. 在 `myBind` 方法内部，保存当前调用该方法的原始函数引用。
  2. 返回一个新的函数。
  3. 在返回的新函数内部，使用 `apply` 执行原始函数，并传入指定的 `this` 上下文。

- **基础代码结构**：
  ```javascript
  Function.prototype.myBind = function(context) {
      // 保存原始函数引用
      const originFn = this; 
      
      // 返回一个新的函数
      return function() {
          // 使用 apply 改变 this 指向并执行原始函数
          originFn.apply(context);
      }
  }
  ```

## bind 参数传递的模拟实现 *Content-[04:40]

原生 `bind` 支持**分两次传递参数**：第一次在调用 `bind` 时传入，第二次在调用返回的新函数时传入。最终执行时，需要将这两次参数合并。

- **实现思路**：
  1. 在 `myBind` 中获取第一次传入的参数（除 `context` 外的参数）。
  2. 在返回的函数中获取第二次传入的参数。
  3. 将两次参数合并成数组后，传递给 `apply`。

- **代码实现**：
  ```javascript
  Function.prototype.myBind = function(context, ...args1) {
      const originFn = this;
      
      return function(...args2) {
          // 合并两次传入的参数
          const finalArgs = [...args1, ...args2];
          
          // 使用 apply 执行并传入合并后的参数
          originFn.apply(context, finalArgs);
      }
  }
  ```
  *注：也可以使用 `arguments` 对象结合 `Array.prototype.slice.call` 或 `concat` 来实现参数的获取与合并。*

## bind 返回函数作为构造函数使用的特性 *Content-[08:13]

`bind` 还有一个非常重要且容易被忽略的特性：**返回的新函数可以作为构造函数使用（即被 `new` 操作符调用）**。

- **构造函数特性表现**：
  - **`this` 指向失效**：当使用 `new` 调用返回的函数时，`bind` 绑定的 `this` 会失效，`this` 会指向 `new` 创建的新实例对象。
  - **参数依然生效**：虽然 `this` 绑定失效，但之前通过 `bind` 和调用时传入的参数依然有效。
  - **原型链继承**：新实例能够正常访问原始函数原型链（`prototype`）上的属性和方法。

- **示例分析**：
  ```javascript
  let name = 'global';
  const foo = { name: 'foo' };
  
  function bar(hobby) {
      this.hobby = hobby;
  }
  bar.prototype.friend = '李四';
  
  const bindBar = bar.bind(foo, 'shopping');
  
  // 使用 new 操作符调用
  const obj = new bindBar(); 
  
  console.log(obj.name);    // undefined (this 失效，指向新实例，实例上无 name)
  console.log(obj.hobby);   // 'shopping' (参数传入依然生效)
  console.log(obj.friend);  // '李四' (成功获取原型链上的属性)
  ```

- **进阶实现思考**：
  要让手写 `bind` 完美支持 `new` 操作符，还需要解决以下问题：
  1. 如何判断返回的函数是否被 `new` 调用？
  2. 如果被 `new` 调用，如何忽略绑定的 `context`，将 `this` 正确指向新实例？
  3. 如何处理原型链的继承，确保新实例的原型正确指向原始函数的原型？
  *(这些进阶逻辑将在后续的深入课程中详细讲解)*
