## 2. 方法一：split、reverse 与 join 组合 *Content-[00:27]
这是最基础也是最常用的“三板斧”方法，利用数组的内置方法来实现翻转。
- **实现步骤**：
  1. 使用 `split('')` 将字符串分割并转换为字符数组。
  2. 调用数组的 `reverse()` 方法进行元素位置的翻转。
  3. 使用 `join('')` 将翻转后的数组重新拼接为字符串。
- **代码示例**：
  输入 `"hello"`，经过 `split` 变为 `['h', 'e', 'l', 'l', 'o']`，`reverse` 后变为 `['o', 'l', 'l', 'e', 'h']`，最后 `join` 输出 `"olleh"`。

## 3. 方法二：扩展运算符结合数组方法 *Content-[02:08]
利用 ES6 的扩展运算符（`...`）替代 `split` 方法，是方法一的一种语法扩展，代码更加简洁。
- **实现步骤**：
  1. 使用扩展运算符 `[...str]` 将字符串直接解构为字符数组。
  2. 调用 `reverse()` 翻转数组。
  3. 使用 `join('')` 拼接成最终字符串。

## 4. 方法三：使用 for 循环倒序遍历 *Content-[03:02]
不依赖数组的内置翻转方法，通过原生循环逻辑来实现，适合考察基础编程能力。
- **实现步骤**：
  1. 定义一个变量（如 `reversed`）用于存储翻转后的结果。
  2. 使用 `for` 循环从字符串末尾开始倒序遍历。
  3. 每次遍历将当前字符拼接到 `reversed` 变量中，最终完成翻转效果。

## 5. 方法四：使用递归实现翻转 *Content-[04:11]
通过递归思想开阔解题视野，展示对算法逻辑的理解。
- **实现步骤**：
  1. **终止条件**：判断当前字符串 `str` 是否为空，如果为空则返回空字符串 `""`。
  2. **递归逻辑**：使用 `substring` 方法获取字符串的最后一个字符，并将其与剩余部分的递归调用结果进行拼接。
  3. 通过一层层递归找到字符串末尾，再逐步向上完成拼接操作。

## 6. 方法五：使用 reduce 方法 *Content-[05:27]
利用数组的高阶函数 `reduce` 来实现，进一步展示对 JS 数组方法的掌握程度。
- **实现步骤**：
  1. 先使用 `split('')` 将字符串转为字符数组。
  2. 调用 `reduce` 方法，传入一个回调函数。
  3. 在回调函数中，将当前遍历到的字符拼接到累加器的前面（即 `current + accumulator`），通过这种位置交换的方式完成字符串反转。
