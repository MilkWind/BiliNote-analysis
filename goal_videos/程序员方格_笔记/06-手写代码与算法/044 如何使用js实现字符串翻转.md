## 2. 方法一：内置方法组合 (split + reverse + join) *Content-[00:27]
- **核心思路**：利用 JavaScript 字符串和数组的内置方法，通过经典的“三板斧”实现翻转。
- **实现步骤**：
  1. 使用 `split('')` 将字符串转换为字符数组。例如，将 `"hello"` 转换为 `['h', 'e', 'l', 'l', 'o']`。
  2. 调用数组的 `reverse()` 方法对数组进行原地翻转，得到 `['o', 'l', 'l', 'e', 'h']`。
  3. 使用 `join('')` 将翻转后的数组重新拼接成字符串，最终输出 `"olleh"`。
- **代码示例**：
  ```javascript
  function reverseString(str) {
      return str.split('').reverse().join('');
  }
  ```

## 3. 方法二：扩展运算符结合数组方法 *Content-[02:08]
- **核心思路**：使用方法一的变种，利用 ES6 的扩展运算符（Spread Operator）将字符串直接解构为数组。
- **实现步骤**：
  1. 使用扩展运算符 `[...str]` 将字符串展开为字符数组。
  2. 调用数组的 `reverse()` 方法进行翻转。
  3. 使用 `join('')` 拼接成最终的字符串。
- **代码示例**：
  ```javascript
  function reverseString(str) {
      return [...str].reverse().join('');
  }
  ```

## 4. 方法三：for 循环倒序遍历 *Content-[03:02]
- **核心思路**：不依赖数组的内置翻转方法，通过原生 `for` 循环手动实现倒序遍历和拼接，考察基础逻辑。
- **实现步骤**：
  1. 定义一个空变量（如 `reversed`）用于存储翻转后的结果。
  2. 使用 `for` 循环，从字符串的最后一个字符（索引为 `str.length - 1`）开始，倒序遍历到第一个字符（索引为 `0`）。
  3. 在每次循环中，将当前遍历到的字符拼接到 `reversed` 变量中。
- **代码示例**：
  ```javascript
  function reverseString(str) {
      let reversed = '';
      for (let i = str.length - 1; i >= 0; i--) {
          reversed += str[i];
      }
      return reversed;
  }
  ```

## 5. 方法四：递归实现 *Content-[04:11]
- **核心思路**：通过递归的思想，将大问题拆解为更小的子问题，有助于在面试中开阔解题视野。
- **实现步骤**：
  1. **终止条件**：如果当前字符串 `str` 为空，则直接返回空字符串。
  2. **递归逻辑**：如果不为空，则使用 `substring(1)` 获取除第一个字符外的剩余子串，将其传入递归函数，并在返回结果后拼接上当前的第一个字符（`str[0]`）。
- **代码示例**：
  ```javascript
  function reverseString(str) {
      if (str === '') {
          return '';
      }
      return reverseString(str.substring(1)) + str[0];
  }
  ```

## 6. 方法五：使用 reduce 方法 *Content-[05:31]
- **核心思路**：结合数组的高阶函数 `reduce`，通过累加器实现字符位置的交换与拼接。
- **实现步骤**：
  1. 首先使用 `split('')` 将字符串转换为数组。
  2. 调用数组的 `reduce` 方法，传入一个回调函数和初始值 `''`。
  3. 在回调函数中，将当前遍历到的字符（`curr`）拼接到累加器（`acc`）的前面（即 `curr + acc`），从而实现位置反转。
- **代码示例**：
  ```javascript
  function reverseString(str) {
      return str.split('').reduce((acc, curr) => curr + acc, '');
  }
  ```
