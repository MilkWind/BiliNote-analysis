## 1. 核心思路解析 *Content-[00:00]
- **面试高频考点**：手写基础版柯里化（Currying）函数是前端面试中的高频考题。
- **核心实现思路**：
  - 定义一个外层函数，用于接收第一个参数。
  - 外层函数返回一个内层函数，用于接收第二个参数。
  - 该内层函数再返回下一个内层函数，用于接收第三个参数。
  - 最后一个内层函数在接收完所有参数后，返回最终的计算结果。
  - **核心机制**：利用闭包（Closure）来记住并保存所有的参数。

## 2. 手写基础版柯里化函数代码 *Content-[00:46]
- **需求描述**：将三参数的加法函数 `add(a, b, c)` 柯里化为 `curryAdd(a)(b)(c)` 的调用形式。
- **代码实现步骤与逻辑**：
  ```javascript
  // 基础版柯里化函数（以三个参数的加法为例）
  function curryAdd(a) {
      // 外层函数接收第一个参数 a，利用闭包保存 a 在内存中
      return function(b) {
          // 第一个内层函数接收第二个参数 b，利用闭包保存 a 和 b
          return function(c) {
              // 第二个内层函数接收第三个参数 c
              // 接收完所有参数后，返回最终结果
              return a + b + c;
          }
      }
  }
  ```

## 3. 函数测试与验证 *Content-[03:09]
- **连续传参测试**：
  - 调用 `console.log(curryAdd(1)(2)(3))`，预期结果应为 `6`。
  - 调用 `console.log(curryAdd(2)(3)(4))`，预期结果应为 `9`。
  - 验证结果：保存并刷新后，输出结果均正确。
- **分步传参测试**：
  - 第一步：`const step1 = curryAdd(1);` （传入参数 1）
  - 第二步：`const step2 = step1(6);` （传入参数 6）
  - 第三步：`const step3 = step2(7);` （传入参数 7）
  - 最终结果：`step3` 的值为 `18`（即 1 + 6 + 7）。
  - 验证结果：分步调用同样可以正确得到结果，证明基础版柯里化函数逻辑完全正确。

## 4. 基础版柯里化函数要点总结 *Content-[04:58]
- 外层函数负责接收第一个参数。
- 每个内层函数负责接收一个参数，且参数总个数必须与原函数保持一致（例如原函数有 3 个参数，柯里化后就是 3 层函数嵌套）。
- 每个内层函数都必须返回下一个内层函数，直到最后一个内层函数返回最终结果。
- **核心原理**：利用闭包（Closure），让每个内层函数都能访问到之前累积的所有参数。

## 5. 扩展练习：两参数柯里化函数 *Content-[05:35]
- **互动问题**：如果原函数是两参数加法 `add(a, b)`，柯里化函数应该怎么写？
- **解决思路**：将原本的三层嵌套减少为两层嵌套，删除最内层的一层，直接将结果返回。
- **代码实现逻辑**：
  ```javascript
  // 两参数版本的柯里化函数
  function curryAddTwo(a) {
      return function(b) {
          return a + b;
      }
  }
  ```
- **测试验证**：
  - 连续调用：`curryAddTwo(1)(2)` 结果为 `3`。
  - 分步调用：`const step1 = curryAddTwo(5); const result = step1(6);` 结果为 `11`（5 + 6）。
  - 验证结果：两参数版本的柯里化函数测试通过，逻辑与三参数版本一致。
