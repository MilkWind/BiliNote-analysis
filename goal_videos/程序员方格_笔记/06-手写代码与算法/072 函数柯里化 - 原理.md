## 函数柯里化的关键特性 *Content-[00:00]

函数柯里化（Currying）是 Web 前端开发中的高频面试题，其关键特性主要包括以下几个方面：

- **参数复用**：通过固定部分参数，生成一个新的函数，从而实现参数的复用。
- **延迟执行**：分步骤接收参数，不需要一次性把所有参数配置好。直到所有的参数收集完毕，它才会真正执行函数。
- **函数组合**：便于创建可组合的高阶函数，非常适合用于管道式（Pipeline）的数据处理。
- **代码复用**：可以创建部分配置好的函数，在不同的地方进行复用（此特性与“参数复用”较为类似）。

**重点记忆**：在面试中，重点需要记住**参数复用**、**延迟执行**和**函数组合**这三大核心特性。

## 柯里化的核心原理：依赖闭包 *Content-[00:54]

很多同学会疑问：柯里化函数为什么能记住之前传递的参数？例如在执行 `curryAdd` 函数后，返回的函数还能记住 `a = 1`。这背后的核心原理就是**闭包（Closure）**。

- **闭包的定义**：内部函数能够访问外部函数的变量，即使外部函数已经执行完毕，内部函数依然能记住这些变量的值。
- **在柯里化中的应用**：在柯里化过程中，每次返回的新函数（即内部函数）都能记住之前传递的参数（即外部函数的变量），直到所有参数传递完毕后再进行计算。
- **内存与垃圾回收（GC）机制**：因为内部函数引用了外部函数的变量（例如参数 `a`），所以即使外部函数执行完毕，变量 `a` 也不会被垃圾回收机制回收，而是长期驻扎在内存当中。

## 结合案例拆解闭包在柯里化中的作用 *Content-[03:02]

为了让大家零基础也能理解，我们通过 `curryAdd` 累加函数的案例，结合注释来拆解闭包在柯里化中的具体作用。

### 1. 函数结构拆解
- **外部函数**：接收参数 `a`，并返回第一个内部函数。
- **第一个内部函数**：接收参数 `b`，并返回第二个内部函数。此时，该内部函数能够访问外部函数的 `a` 和当前的 `b`，形成闭包。
- **第二个内部函数**：接收参数 `c`，能够记住 `a` 和 `b` 的值，并与 `c` 一起计算最终结果（即 $a + b + c$）。因为 `a` 和 `b` 都被引用，即使外部函数和第一个内部函数执行完毕，它们也不会被垃圾回收。

### 2. 调用过程与闭包的作用
- **第一步**：调用外部函数 `curryAdd(1)`。外部函数执行，`a = 1`。外部函数执行完毕后，按照正常逻辑 `a` 应该被销毁，但因为内部函数还能访问 `a`，所以 `a = 1` 被**闭包记住**。
- **第二步**：调用第一个内部函数并传入 `2`。此时 `b = 2`。该内部函数执行完毕后，`a = 1` 和 `b = 2` 都被**闭包记住**。
- **第三步**：调用第二个内部函数并传入 `3`。此时拿到 `a = 1`、`b = 2`、`c = 3`，返回最终的累加结果 `6`。

### 3. 核心结论
柯里化依赖闭包的原因在于：**没有闭包，柯里化就无法记住之前传递的参数**。闭包使得内部函数能够跨越外部函数的生命周期，持续保存并访问历史参数。

## AI 总结

函数柯里化（Currying）是一种将接收多个参数的函数转换成一系列接收单一参数的函数的技术。它的核心特性包括参数复用、延迟执行和函数组合。而柯里化之所以能够实现“分步接收参数并记住历史参数”，其底层完全依赖于**闭包（Closure）** 机制。闭包使得内部函数能够持久化访问外部函数的变量，避免了变量被垃圾回收，从而实现了参数的记忆与最终的延迟计算。理解闭包是掌握函数柯里化原理的关键。
