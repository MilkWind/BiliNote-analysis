## 雪碧图（CSS Sprites）的作用与原理 *Content-[00:00]
- **概念**：雪碧图实际上是将多个小图标通过工具（如 Webpack、Gulp 等）合成一张大图。
- **原理**：在使用时，通过 CSS 的 `background-position`（或 `position` 相关属性）控制背景图片的显示位置，从而精准展示所需的局部图像。
- **作用**：核心作用是减少 HTTP 网络请求的数量，从而提升页面的加载性能。

## display: none 与 visibility: hidden 的区别 *Content-[00:21]
- `visibility: hidden`：元素在页面中隐藏，但**仍然占据**原有的布局空间。
- `display: none`：元素在页面中隐藏，且**不占据**任何布局空间。

## CSS 伪元素的作用与常见类型 *Content-[00:29]
- **概念**：伪元素也是页面中的具体元素，主要用于在元素的前面或后面插入内容，或者选择元素的特定部分。
- **常见伪元素**：
  - `::before` / `::after`：在元素内容的前面或后面插入内容。
  - `::first-letter`：选择文本的首字母。
  - `::first-line`：选择文本的首行。
  - `::selection`：选择用户当前选中的文本。

## Flex 布局中调整子元素顺序 *Content-[01:07]
- 在 Flex 布局中，可以通过 `order` 属性来设置子元素的展示顺序。
- `order` 的值越小，优先级越高，元素排列越靠前。
- 可以通过选择器配合 `order` 属性，灵活调换 Flex 子元素的展示顺序。

## background-size 属性详解及 cover 与 contain 的区别 *Content-[01:30]
- **常用属性值**：`cover`、`contain`、保持原始尺寸、`px`（指定具体宽高）、百分比。
- **contain 与 cover 的核心区别**：
  - `contain`：核心是让背景图片**完全展示**在背景区域内。如果图片与容器比例不一致，背景区域将会**留白**。
  - `cover`：背景图片将被**裁剪**以适应背景区域。核心是图片会**占满**整个容器，可能会牺牲部分图片的显示。
- *建议*：在实际开发中，可以通过调试来直观感受两者的差异。

## 伪元素与伪类的核心区别 *Content-[02:56]
- **伪类**：本质上是一种**选择器**（如 `:hover`、`:checked`），用于选择文档树中**已经存在**的元素的特定状态。
- **伪元素**：会在文档中**创建新的虚拟元素**（如 `::before`），可以将其理解为页面中实际存在的具体元素。

## Flex 子元素浮动问题 *Content-[03:40]
- Flex 的子元素**不可以**设置浮动（`float`）。
- 浮动与 Flex 布局会产生冲突，最终渲染效果依然以 Flex 布局的规则为准。

## CSS 实现 0.5 像素细线 *Content-[03:47]
- 浏览器最小只支持 1px 的边框宽度。
- **解决方案**：使用 `transform: scale(0.5)` 属性，将 1px 的线缩小一半，从而实现 0.5px 的视觉效果。

## Shadow DOM 的概念、特性与应用场景 *Content-[04:10]
- **概念**：在浏览器中生成一个隐藏的 DOM 树，并添加到常规 DOM 树中。以 `shadow root` 节点为起始根节点，其下方可以是任意元素。
- **特性**：创建一个独立的 DOM 树，与主文档**完全隔离**，拥有自己独立的样式和脚本，隔离性极强。
- **缺点**：API 设计较为复杂（反人类），开发体验不佳，日常原生开发使用较少。
- **应用场景**：
  - **Web Components**：浏览器原生标准，主要用于组件的封装。
  - **微信小程序**：底层使用 Shadow DOM 实现组件隔离（注：并非市面上所有小程序如支付宝、百度、头条都采用此方案，但微信小程序底层依赖此技术，这也是小程序开发有时较为繁琐的原因之一）。

## CSS 动画性能优化方案 *Content-[06:07]
- **开启 GPU 加速**：使用 `transform` 属性（如 `translate`）来改变元素位置，代替修改 `position: absolute` 的 `top/left` 值，避免引起重排（Reflow）导致动画卡顿。
- **使用 `requestAnimationFrame`**：当使用 JS 修改元素位置时，推荐使用此 API 代替 `setTimeout` 或 `setInterval`。
  - **原因**：定时器时间不准确，且可能被 JS 主线程阻塞导致执行延迟；而 `requestAnimationFrame` 始终在浏览器渲染的当前帧最后执行，能保证动画的流畅和同步。

## 场景题：固定高度容器内自适应填满剩余高度 *Content-[07:51]
- **场景**：一个固定高度的 `div` 内包含两个子 `div`，第一个高度固定为 100px，第二个需要填满剩余高度。
- **解决方案**：使用 CSS 的 `calc()` 计算属性，将第二个子元素的高度设置为 `height: calc(100% - 100px);`。

## line-height 百分比与数值的继承区别 *Content-[08:13]
- `line-height: 120%`（百分比）：基于**元素自身**的字体大小计算出具体的像素值（如字体 14px，行高计算为 16.8px），子元素**继承的是这个计算后的具体像素值**。
- `line-height: 1.2`（无单位数值）：子元素**继承的是比例（1.2）**。子元素会根据**自身的字体大小**重新计算行高（如子元素字体 18px，行高则重新计算为 18 * 1.2 = 21.6px）。
