## Grid 布局轨道尺寸的“四大家族” *Content-[01:30]

在 Grid 布局中，设置轨道尺寸有四大类主要单位，各有其用武之地：

- **固定单位**：如 `px`、`em`、`rem`。
  - **特点**：固定、稳定，能提供精确且可预测的尺寸。
  - **场景**：适用于需要“雷打不动”固定宽度的区域，例如固定为 200px 的网站侧边栏。
- **相对单位**：如 `%`、`vw`、`vh`。
  - **特点**：其值相对于某个参照物计算（如父容器宽度、浏览器视口宽高）。
  - **场景**：非常适合创建随外部容器大小等比缩放的响应式布局。
- **自动单位**：`auto`。
  - **特点**：轨道大小由内部内容决定（内容多则宽，内容少则窄）。
  - **场景**：体现了 Grid 布局“内容优先”的设计哲学。
- **分数单位**：`fr`（fraction 的缩写，意为分数或一份）。
  - **特点**：代表网格容器中**剩余可用空间**的一份。
  - **场景**：Grid 布局独有且最强大的单位之一，用于弹性分配剩余空间。

## 传统单位的局限与 fr 单位的核心优势 *Content-[03:28]

为了深刻理解 `fr` 的价值，我们先看一个没有 `fr` 时会遇到的经典痛点。

**痛点场景**：实现经典的三列等宽布局，且列间距（`gap`）为 20px。
- **传统方案（百分比）的局限**：
  - 若设置 `grid-template-columns: 33.33% 33.33% 33.33%`，加上 2 个 20px 的 gap 后，总宽度会超过 100%，导致出现非预期的横向滚动条。
  - 解决方案需借助 `calc()` 函数：`calc((100% - 40px) / 3)`。
  - **缺点**：计算极其繁琐，且一旦 `gap` 属性改变，必须重新计算，维护成本极高。
- **fr 单位的优雅解决**：
  - 代码：`grid-template-columns: 1fr 1fr 1fr`。
  - **优势 1：自动计算**。无需关心具体像素值，浏览器会自动处理分配。
  - **优势 2：间距友好**。计算时会自动扣除 `gap` 的空间，保证布局永远不会超出容器。
  - **优势 3：比例清晰**。`1fr 1fr 1fr` 直观地表达了“三列等宽”的布局意图。
  - **意义**：将开发者从繁琐的数学计算中彻底解放，让我们能真正专注于布局的逻辑与语义。

## fr 单位的工作原理与计算过程 *Content-[07:06]

通过一个具体示例来拆解 `fr` 背后的工作原理。

**示例场景**：容器总宽度为 800px，三列定义为 `200px 1fr 2fr`，`gap` 为 20px。

**浏览器计算步骤：**
1. **优先处理非 fr 轨道**：第一列是固定宽度，优先分配 200px。
2. **计算间距总和**：3 列之间有 2 个 gap，总和为 $20\text{px} \times 2 = 40\text{px}$。
3. **计算剩余空间**：用总宽度减去固定宽度和间距总和。
   $$ \text{剩余空间} = 800\text{px} - 200\text{px} - 40\text{px} = 560\text{px} $$
4. **统计 fr 总份数**：$1\text{fr} + 2\text{fr} = 3$ 份。
5. **计算单份 fr 的像素值**：
   $$ 1\text{fr} = \frac{560\text{px}}{3} \approx 186.67\text{px} $$
6. **得出最终列宽**：
   - 第一列（固定）：$200\text{px}$
   - 第二列（1fr）：$186.67\text{px}$
   - 第三列（2fr）：$186.67\text{px} \times 2 = 373.33\text{px}$
   - **验证总和**：$200\text{px} + 186.67\text{px} + 373.33\text{px} = 800\text{px}$。

**核心精髓**：`fr` 总是先满足其他单位（如固定单位、gap）的需求，然后再将剩下的空间按照你指定的比例进行分配。理解了这个过程，就掌握了 `fr` 的精髓。

## 高效简化代码：repeat 函数 *Content-[09:45]

`repeat` 函数是减少代码量、提升可维护性的利器，专门用于处理网格中重复性的轨道模式。

- **基础用法**：
  - 创建 5 列等宽网格，传统写法需写 5 个 `1fr`（12 列则写 12 个），非常啰嗦。
  - 使用 `repeat`：`grid-template-columns: repeat(5, 1fr)`，代码瞬间清爽。
- **重复复杂模式**：
  - `repeat` 不仅能重复单个值，还能将一组轨道作为整体进行重复。
  - 示例：`repeat(3, 100px 1fr)`。
  - 效果：将 `100px` 和 `1fr` 作为一个组合重复 3 次，在创建有固定套路的布局时极其好用。
- **混合使用**：
  - 可以与其他单位灵活混合。例如创建一个 5 列布局：首尾列固定像素，中间 3 列为等分弹性列。
  - 示例：`grid-template-columns: 100px repeat(3, 1fr) 100px`。
- **核心优势**：代码更短，可读性和可维护性大幅提高。修改时只需调整一个数字，无需手动增删长串代码。

## 最佳实践与注意事项 *Content-[11:51]

在实际项目中使用 Grid 布局和 `fr` 单位时，需注意以下几点：

- **性能问题**：
  - `fr` 单位的计算由浏览器原生支持，且经过了高度优化，性能开销极小，完全可以放心使用。
  - **注意**：避免过度嵌套。任何布局系统嵌套层级过深都会增加浏览器渲染复杂度，务必保持合理的 HTML 结构。
- **浏览器兼容性**：
  - CSS Grid 在所有现代浏览器（Chrome、Firefox、Safari）及移动端均已全面支持。
  - 唯一需要注意的是 IE11，需要添加前缀进行兼容（但目前大部分项目已不再将兼容 IE 作为主要目标）。
- **调试技巧**：
  - 所有主流浏览器的开发者工具都内置了强大的 **Grid 检查器**。
  - 在 Elements 面板中找到 Grid 容器，开启可视化面板，即可清晰查看网格线、行号、轨道尺寸和 gap。建议课后多利用此工具进行调试和验证。
