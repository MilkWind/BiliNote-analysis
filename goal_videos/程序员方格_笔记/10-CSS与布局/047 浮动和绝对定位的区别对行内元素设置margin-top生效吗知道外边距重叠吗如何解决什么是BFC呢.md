## 浮动和绝对定位的区别 *Content-[00:00]
- **浮动（Float）**：
  - 浮动元素在特定条件下会撑开父元素。
  - 前提条件：必须正确清除浮动（Clearfix），否则会导致父元素高度塌陷。
- **绝对定位（Absolute Positioning）**：
  - 绝对定位元素会直接脱离标准文档流。
  - 因此，它不会撑开父元素，父元素在计算高度时会完全忽略绝对定位的子元素。

## 行内元素的 margin-top 生效问题 *Content-[00:18]
- **核心问题**：对行内元素（如 `<span>`）设置 `margin-top` 是否生效？
- **结论**：**不生效**。
- **详细说明**：
  - 行内元素在垂直方向上的 `margin-top` 和 `margin-bottom` 设置是无效的，不会产生实际的垂直间距。
  - 行内元素的 margin 属性只对水平方向生效，即 `margin-left` 和 `margin-right` 是有效的。

## 外边距重叠及解决方案 *Content-[00:29]
- **现象描述**：
  - 当两个垂直方向相邻的块级元素发生外边距重叠（Margin Collapse）时，它们之间的实际间距并不是两者外边距之和。
  - **具体示例**：
    - 上方元素设置 `margin-bottom: 30px`。
    - 下方元素设置 `margin-top: 20px`。
    - 按常理计算：$30 + 20 = 50$。
    - 实际渲染结果：间距为 $30px$（取两者外边距中的最大值）。
- **解决方案**：
  - 触发并创建一个 **BFC**（Block Formatting Context）即可解决外边距重叠问题。

## BFC（块级格式化上下文）详解 *Content-[01:02]
- **官方定义**：
  - BFC 是 Web 页面中可视 CSS 渲染的一部分。
  - 它是块盒子（Block Box）布局过程中发生的区域。
  - 它也是浮动元素与其他元素交互的限制区域。
- **通俗理解**：
  - BFC 实际上就是页面上的一个**隔离的独立容器**。
  - 容器内部的子元素布局不会影响到外部的元素，反之亦然，实现了内部与外部的隔离。
- **如何创建 BFC**：
  1\. **浮动**：设置 `float` 属性（除 `none` 外）。
  2\. **绝对定位**：设置 `position: absolute` 或 `position: fixed`。
  3\. **特定的 display 值**：如 `display: inline-block`、`display: flex`、`display: grid` 等。
  4\. **overflow 属性**：设置 `overflow` 为 `hidden`、`auto` 或 `scroll`（除 `visible` 外）。
- **最佳实践**：
  - 在实际开发中，最常用且副作用最小的创建 BFC 的方法是设置 `overflow: hidden`。
  - 通过创建 BFC，可以完美解决上述的外边距重叠问题。

## AI 总结
本次视频主要讲解了 Web 前端面试中关于 CSS 布局的四个高频核心问题：
1. **浮动与绝对定位的区别**：浮动需清除浮动才能撑开父元素，而绝对定位直接脱离文档流，不撑开父元素。
2. **行内元素的 margin 特性**：行内元素的垂直 margin（`margin-top` / `margin-bottom`）不生效，仅水平 margin 生效。
3. **外边距重叠（Margin Collapse）**：相邻块级元素的垂直外边距会合并，取最大值而非相加（如 $30px$ 和 $20px$ 合并后为 $30px$）。
4. **BFC（块级格式化上下文）**：BFC 是一个隔离的独立容器，可通过浮动、绝对定位、特定 display 值或 `overflow: hidden` 等方式触发，常用于解决外边距重叠、清除浮动等复杂布局问题。
