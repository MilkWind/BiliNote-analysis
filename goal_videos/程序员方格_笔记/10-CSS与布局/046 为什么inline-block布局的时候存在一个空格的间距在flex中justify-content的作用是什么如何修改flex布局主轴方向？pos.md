## 1. inline-block 布局的空格间隙问题 *Content-[00:01]*

在 Web 前端面试中，关于 `inline-block` 布局的经典问题之一是：**为什么 `inline-block` 布局的时候元素之间会存在一个空格的间隙？**

### 产生原因
- **排列特性**：`inline-block` 元素会在水平方向上横着排列成一排。
- **HTML 源码解析**：如果在 HTML 代码中，两个 `inline-block` 元素（例如两个 `li` 标签）之间存在换行符或空格，浏览器在解析时会将这些空白字符渲染为一个实际的文本空格。
- **视觉表现**：由于 `inline-block` 兼具行内元素的特性，这个被解析出来的空格就会在两个元素之间产生一个可见的间隙。

### 解决方案
- **核心方法**：给父元素设置 `font-size: 0;`。
- **原理**：通过将父元素的字体大小设置为 0，可以消除父元素内部空白字符（空格/换行）所占据的物理空间，从而完美解决间隙问题。（注：实际开发中，若子元素内有文本内容，需为子元素重新指定合适的 `font-size`）。

## 2. Flex 布局中 justify-content 与主轴方向 *Content-[00:49]*

### justify-content 的作用
在 Flexbox 弹性布局中，`justify-content` 属性主要用于**设置主轴（Main Axis）上子元素的对齐方式**。

常用的属性值包括：
- `start` (标准中常表述为 `flex-start`)：元素向主轴起点对齐。
- `end` (标准中常表述为 `flex-end`)：元素向主轴终点对齐。
- `center`：元素在主轴居中对齐。
- `space-between`：元素之间间距相等，首尾元素贴近主轴边缘。
- `space-around`：元素之间间距相等，且首尾元素与边缘的间距是元素之间间距的一半。

### 如何修改 Flex 布局的主轴方向
要修改 Flex 布局的主轴方向，需要使用 **`flex-direction`** 属性。

- **核心作用**：决定主轴是 X 轴还是 Y 轴，以及主轴的起点和终点方向。
- **方向控制**：
  - 控制 X 轴方向：从左向右（默认） 或 从右向左。
  - 控制 Y 轴方向：从上到下 或 从下到上。
- 通过灵活配置 `flex-direction`，可以轻松实现各种复杂的二维页面布局。

## 3. CSS position 定位属性详解 *Content-[01:37]*

在面试中被问到 `position` 有几个属性时，建议采用 **“基础属性 + 亮点属性”** 的结构来回答，以展现知识的深度和广度。

### 基础属性（5个）
面试时首先回答以下五个最常见的定位属性：
1. `static`：默认值，无定位，元素遵循正常的文档流。
2. `relative`：相对定位，相对于元素自身正常位置进行偏移，不脱离文档流。
3. `absolute`：绝对定位，相对于最近的非 `static` 定位祖先元素进行偏移，脱离文档流。
4. `fixed`：固定定位，相对于浏览器视口（Viewport）进行定位，不随页面滚动而移动，脱离文档流。

### 面试亮点属性（第6个）
为了体现技术亮点，一定要补充第 6 个属性：**`sticky`（粘性定位）**。

- **概念纠正**：视频中提到的“连线定位”实为语音识别误差，正确专业术语为**粘性定位（Sticky Positioning）**。
- **运行机制**：`sticky` 定位可以看作是 `relative` 和 `fixed` 的结合体。元素在跨越特定阈值（如 `top: 0`）前表现为相对定位，一旦达到阈值则表现为固定定位。
- **实际场景演示**：在页面滚动时，当元素滚动到视口顶部，它就好像“被吸住了一样”固定在顶部，不再随页面继续向上滚动。这种 **“顶吸效果”** 非常适合用于实现移动端或 PC 端的吸顶导航栏、侧边栏目录吸附等交互场景。
