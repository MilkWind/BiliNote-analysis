## 课程简介与学习路线 *Content-[00:00]

主讲人方格带来了前端面试系列课程的第 8 课，重点讲解 CSS Grid 的基础概念与心智模型。

- **常见痛点**：很多同学在面试遇到复杂布局问题时，总想着用 Flexbox，导致代码写得非常复杂。实际上，当遇到**二维布局**需求时，Grid 才是最佳选择。
- **学习目标**：不局限于复杂的语法，而是帮助大家建立正确的心智模型。一旦理解了 Grid 的本质，后续学习将非常通畅。

  2\. **建立完整的心智模型**：理清 Grid 容器、轨道、网格线等众多概念之间的关联，建立清晰的认知。

  4\. **夯实基础**：Grid 的学习可能无法一蹴而就，但必须首先搞清楚基础概念。

## Flexbox 与 Grid 的核心区别 *Content-[01:44]

在深入学习 Grid 之前，需要明确为什么在 Flexbox 已经非常强大的情况下，我们还要学习 Grid。

- **Flexbox 的强项**：
  - 擅长**一维布局**，可以沿着单轴（水平或垂直）排列元素。
  - 提供非常灵活的空间分配机制。
  - 对响应式设计非常友好。
- **Flexbox 的局限**：
  - 当遇到复杂的布局需求时（如仪表盘需要精确控制每个组件在第几行第几列，或者包含头部、侧边栏、主内容区、底部的复杂页面），Flexbox 会力不从心。
  - 如果强行使用 Flexbox，代码会变得非常复杂，需要大量的嵌套和各种 hack 技巧。
- **Grid 的优势**：
  - 天生就是为了解决**二维布局**问题而设计的。

## 一维布局与二维布局深入解析 *Content-[02:53]

理解一维布局和二维布局的概念是掌握这两种布局方式的基础。

### Flexbox（一维布局）
- **排列方式**：一次只能沿着一个方向排列元素。设置 `flex-direction: row` 为水平排列，`column` 为垂直排列。
- **轴向机制**：存在主轴和交叉轴。元素过多时会自动换行。
- **形象类比**：**书架**。就像把书一本本放在书架上，书太多会自动换到下一层。这个过程是自动的，你无法精确控制某本书一定要放在“第二层第三个位置”。
- **核心驱动**：**内容驱动（Content-driven）**。放什么内容，它就怎么自动排列。

### Grid（二维布局）
- **排列方式**：可以同时定义行和列（例如定义一个三列两行的网格结构）。
- **控制能力**：行列双向控制，可以创建精确的网格单元格，且元素可以跨越多个格子。
- **形象类比**：**定制书柜**。就像预先定制好了一个多行多列的书柜，每个格子都有明确的坐标系。你可以精确指定某本书放在第几行第几列。
- **核心驱动**：**结构驱动（Structure-driven）**。用于精准定位元素。

## Grid 布局的三个核心要素 *Content-[05:00]

这三个概念是 Grid 的基础，必须彻底搞清楚。

1\. **Grid 容器（Grid Container）**
  - 给一个元素设置 `display: grid`，该元素就变成了 Grid 容器。
  - 声明后，其**直接子元素**会自动成为 Grid 项（Grid items）。注意：孙子元素不会成为 Grid 项，也不受 Grid 容器影响。

2\. **网格轨道（Grid Tracks）**
  - 网格线划分出的空间，分为**列轨道**（垂直方向）和**行轨道**（水平方向）。
  - 形象类比：就像走廊一样，内容就在这些走廊（轨道）里面排列。

3\. **网格线（Grid Lines）**
  - 分割轨道的坐标系。
  - **核心数学关系**：
    - 如果有 $N$ 列网格，那么就有 $N + 1$ 条垂直的网格线。
    - 如果有 $M$ 行网格，那么就有 $M + 1$ 条水平的网格线。
    - *解释*：例如 3 列网格，需要 4 条垂直线来形成这 3 列的边界。

### 核心要素的协同工作流程
- **Grid 容器**负责创建网格轨道系统（通过声明 `display: grid`）。
- 轨道系统包含行轨道和列轨道。
- 轨道被**网格线**分割，最终形成我们的**网格单元格（Grid Cells）**。
- 这是一个层层递进的层次关系，是理解 Grid 布局的基础。

## 定义网格结构的核心属性 *Content-[07:55]

在动手实战前，需要掌握定义网格结构最核心的几个基础属性，这就像盖房子前要先画图纸、搭骨架。

1\. **`grid-template-columns`**
  - 用于定义网格的**列轨道**，决定网格有多少列以及每一列的宽度。
  - 示例：`grid-template-columns: 200px 1fr 100px;`（定义了 3 列，第一列 200px，第二列 `1fr`，第三列 100px）。
  - **`fr` 单位**：代表分数（fraction）。它会自动计算并占据剩余空间的比例（例如 `1fr` 代表占据剩余空间中的一份）。这对于响应式网格设计非常有用。

2\. **`grid-template-rows`**
  - 用于定义**行轨道**的高度，用法与 `grid-template-columns` 完全一致，可以精确控制每一行的高度。

3\. **`gap`**
  - 用于设置轨道之间的**间距**，让布局看起来更舒适、不拥挤。
  - 可以用一个值同时设置行和列的间距，也可以用两个值分别设置行间距和列间距。

## 实战：创建第一个 Grid 布局 *Content-[09:53]

通过代码将理论落地，创建一个基础的 Grid 布局。

- **HTML 结构**：一个容器（`.grid-container`）内包含 5 个子元素（`.item`）。
- **CSS 实现步骤**：
  1. **声明 Grid 容器**：给容器设置 `display: grid`。此时如果没有定义行列，子元素会默认垂直排列。
  2. **定义网格结构**：
     - `grid-template-columns: 200px 100px 200px;` （定义 3 列）
     - `grid-template-rows: 100px 100px;` （定义 2 行，高度均为 100px）
     - `gap: 10px;` （行和列之间的间距均为 10px）
- **布局效果与特性**：
  - 前 3 个元素自动占据第一行的 3 个格子。
  - 第 4、5 个元素自动换到第二行，并占据前两个格子。
  - 定义好结构后，内容会自动按顺序填充。
  - 第 6 个格子为空是完全正常的。
  - **隐式网格（Implicit Grid）**：如果定义的元素数量超过了显式定义的格子数（例如有 7 个元素），Grid 会自动创建新的隐式行来接纳多余的元素。

## 学习心得与思维转变 *Content-[12:05]

学习 Grid 不仅仅是语法的变化，更重要的是思维方式的转变。

1\. **从“内容驱动”到“结构驱动”**
  - Flexbox 是内容驱动的，你放什么内容，它就怎么排列。
  - Grid 是结构驱动的，你需要先规划好蓝图和图纸，然后往里面填充内容。就像盖房子，页面布局是按照预先规划好的图纸去施工的。

2\. **从“一维”到“二维”**
  - 使用 Flexbox 时，主要考虑一个方向（单轴）。
  - 使用 Grid 时，需要同时考虑行和列。要把网格想象成一个**画布**，元素可以在这个画布上进行精确定位。

- **实际应用场景**：
  - **仪表盘**：需要多个组件精确定位。
  - **响应式网格**：需要适配不同的屏幕尺寸。
  - **复杂表单**：需要标签和输入框完美对齐。
  - 掌握 Grid 后，复杂的页面布局将不再是难题。
