## 引言与经典问题引入 *Content-[00:01]
- **经典问题**：如何让一个元素在它的容器里实现完美居中？
- **没有 Flexbox 的时代**：
  - 实现方式复杂且不够稳定，通常需要：
    - 使用绝对定位（`position: absolute`）配合 `transform` 属性。
    - 使用 `display: table-cell` 等稍微 Hack 的技巧。
    - 手动计算并设置负外边距（negative margin）。
- **Flexbox 时代**：
  - 布局变得非常直观且简单，仅需三行代码即可搞定：
    1. 给父容器设置 `display: flex` 开启 Flex 布局。
    2. 设置 `justify-content: center`。
    3. 设置 `align-items: center`。

## Flexbox 核心工作模型概述 *Content-[01:54]
- 要理解 Flexbox 为什么能如此简单地实现居中，必须理解其核心工作模型。
- Flex 布局建立在**三个核心概念**之上：
  1. **方向（Direction）**：由 `flex-direction` 控制，决定项目是水平排列还是垂直排列，定义了整个布局的坐标系。
  2. **主轴对齐（Main Axis Alignment）**：由 `justify-content` 控制，负责管理所有项目在主轴方向上的对齐和分布。
  3. **交叉轴对齐（Cross Axis Alignment）**：由 `align-items` 控制，负责管理项目在交叉轴（与主轴垂直的轴）上的表现。

## 核心概念一：方向与两大轴线 *Content-[02:50]
- Flex 布局中存在两条看不见的轴：**主轴（Main Axis）**和**交叉轴（Cross Axis）**。
- **默认情况（`flex-direction: row`）**：
  - **主轴**：水平方向，从左到右。所有子项目（items）会沿着这条主轴依次排列。
  - **交叉轴**：垂直方向，从上到下（与主轴垂直）。
- **修改方向（`flex-direction: column`）**：
  - 主轴和交叉轴会发生 90 度的翻转。
  - **主轴**：变为垂直方向，从上到下。
  - **交叉轴**：变为水平方向，从左到右。
- **核心逻辑**：`flex-direction` 属性的作用就是定义主轴的方向。主轴一旦确定，交叉轴自然也就确定了，这是理解一切 Flex 布局的基础。

## 核心概念二：主轴对齐属性 justify-content *Content-[04:29]
- `justify-content` 负责控制项目在主轴上的对齐和分布，其属性值主要分为两大类：

### 1. 对齐类（决定所有项目作为整体在主轴上的位置）
- `flex-start`：默认值。所有项目紧靠着主轴的起点对齐。
- `flex-end`：所有项目作为一个整体，移动到主轴的终点对齐。
- `center`：所有项目在主轴上整体居中对齐。

### 2. 分布类（决定容器有剩余空间时，空间如何被分配）
- `space-between`：**两端对齐**。两端的项目会贴住容器的边缘，剩余的空间被平均分配到项目之间的间隙中。
- `space-around`：**环绕对齐**。确保每个项目的两侧间距完全相等。视觉上，项目与项目之间的间距正好是项目与容器边缘间距的两倍（即边缘间距为 $X$，项目间距为 $2X$）。
- `space-evenly`：**均匀对齐**。最公平的分配方式，让所有的间距（无论是项目之间，还是项目与容器边缘之间）都变得完全相等，布局看起来非常规整和谐。

## 核心概念三：交叉轴对齐属性 align-items *Content-[09:11]
- `align-items` 负责管理项目在交叉轴上的对齐表现。
- **默认值 `stretch`**：
  - 只要项目在交叉轴方向上没有设置固定尺寸（例如主轴是横向时，项目没有设置 `height`），项目就会被自动拉伸，填满整个容器在交叉轴方向上的尺寸。
- **其他属性值**：
  - `flex-start`：所有项目向交叉轴的起点对齐。
  - `flex-end`：所有项目向交叉轴的终点（例如容器底部）对齐。
  - `center`：所有项目以自身的中线为基准，在交叉轴方向上整体居中。

## 解决经典问题：实现完美居中 *Content-[11:56]
- 回到视频开头的问题：如何让一个元素在容器里同时实现水平和垂直居中？
- **原理解析**（基于默认的 `flex-direction: row`）：
  - 此时**主轴是水平的**，**交叉轴是垂直的**。
  - **水平居中**：在主轴上做文章，使用 `justify-content: center` 让元素在主轴方向上居中。
  - **垂直居中**：在交叉轴上做文章，使用 `align-items: center` 让元素在交叉轴方向上居中。
- **最终方案**：通过 `display: flex`、`justify-content: center` 和 `align-items: center` 这三行代码，完美解决了居中问题。

## 核心知识点总结与回顾 *Content-[13:05]
- `display: flex`：开启弹性布局的大门（开关），让普通容器变成 Flex 容器。
- `flex-direction`：定义整个布局的坐标系，决定主轴是横着还是竖着。
- `justify-content`：负责主轴上元素的排兵布阵（排列与分布）。
- `align-items`：负责在交叉轴上整理元素的队形（对齐方式）。
- **学习建议**：只要牢牢记住这些逻辑，搞清楚哪些属性属于主轴、哪些属性管交叉轴，绝大部分单行单列的布局问题都能迎刃而解。
