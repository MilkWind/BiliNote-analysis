## 1. 场景介绍与优势分析 *Content-[00:00]
- **应用场景**：
  - 限制标题或摘要展示为 2~3 行。
  - 长评论折叠展示。
  - 在有限的容器空间内展示更多的对应内容。
- **为什么使用 CSS 而非 JS 裁剪文本**：
  - **CSS 优势**：性能更好（浏览器原生支持），代码编写更加简洁。
  - **JS 劣势**：需要动态判断文本长度，处理各种兼容性问题；遇到特殊字符（如 emoji、中英文混合）时长度不可控，需要编写大量正则表达式进行判断，计算非常不便。

## 2. 单行文本省略实现 *Content-[01:41]
- **实现原理**：
  - 设定容器的对应宽度。
  - `white-space: nowrap`：禁止文本换行。
  - `overflow: hidden`：超出容器宽度的部分隐藏。
  - `text-overflow: ellipsis`：文本超出时展示省略号（...）。

## 3. 多行文本省略方案一：WebKit 内核方案 *Content-[02:05]
- **适用环境**：云端 iOS/Android，以及其他 WebKit 内核的浏览器。
- **核心属性**：
  - `display: -webkit-box`：使用 WebKit 内核的弹性盒模型（Box）作为布局方式。
  - `-webkit-box-orient: vertical`：设置盒模型为垂直方向排列。
  - `-webkit-line-clamp: 3`：限制显示行数（可设置为 3、5、7 等任意行数 $N$）。
  - `overflow: hidden`：超出部分隐藏。
  - `text-overflow: ellipsis`：超出部分展示省略号。
- **浏览器兼容性**：
  - Chrome：全版本支持。
  - Safari：全版本支持。
  - 移动端 iOS/Android：均支持。
  - Firefox：68 版本以上支持。
  - IE：不支持。

## 4. 多行文本省略方案二：伪类元素方案 *Content-[03:38]
- **实现原理**：
  - 容器设置为相对定位（`position: relative`）。
  - 设定行高（如 `line-height: 1.5em`，`em` 相当于父级字体大小的倍数）。
  - 设定最大高度（如限制 3 行，则 `max-height: 4.5em`）。
  - `overflow: hidden`：超出隐藏。
  - `padding-right: 1em`：在右侧留出一个字体大小的空间。
  - 使用绝对定位（`position: absolute`）在 `padding-right` 预留的空间内添加三个点（省略号），并配合背景色进行展示。
- **缺点与优化**：
  - **缺点 1**：无论内容是否溢出，都会强制展示省略号。
  - **缺点 2**：需要背景色配合。因为截断文字和省略号之间存在过渡态，需要添加一个从透明色到背景色（如白色）的 50% 渐变过渡，以保证视觉体验更好。

## 5. 多行文本省略方案三：line-clamp 与降级处理 *Content-[06:22]
- **实现原理**：
  - 使用弹性盒，设置垂直方向，限定行数（如 3 行），`overflow: hidden`。
  - 结合 `-webkit-line-clamp` 属性。
  - **注意**：部分低版本浏览器（如旧版 Chrome、Firefox）如果不显式设置该属性，可能会导致失效，无法达到预期效果。
- **降级处理**：
  - 设定 `max-height`（固定高度）。
  - **作用**：即使在不支持省略号展示的浏览器中，也能通过最大高度限制，防止容器因内部内容过多而无限增高。

## 6. 最佳实践：综合方案与动态配置 *Content-[07:51]
- **基础样式**：相对定位，行高 `1.5em`。
- **WebKit 内核逻辑**：垂直方向，限制 3 行，超出隐藏，展示省略号。
- **细节优化（断行处理）**：
  - 添加 `word-break: break-all`。
  - **原因**：在实际超出时，如果涉及英文单词，单词可能会因为空格换行。当剩余空间不足以展示整个单词时，单词会默认整体跳到下一行，导致省略号跟着单词掉到第四行最前面。使用 `word-break: break-all` 可以强制对单词进行断行，确保省略号准确在限定的第三行展示。
- **降级处理**：针对不支持 WebKit 内核的浏览器，设定 `max-height` 进行固定高度降级。
- **动态配置行数**：
  - **方案 A（DOM 属性）**：在 DOM 元素上添加 `data-line` 属性（如 `data-line="2"`），通过 CSS 属性选择器动态设置 `-webkit-line-clamp` 的值。
  - **方案 B（CSS 变量）**：使用 CSS 变量（如 `--line`），在样式中通过变量处理行数，同时 `max-height` 也可通过变量进行计算（如 `calc(var(--line) * 1.5em)`）。

## 7. 核心总结 *Content-[10:27]
- **优先方案**：优先使用 WebKit 内核弹性盒的 `line-clamp` 属性进行处理。
- **降级方案**：提供 `max-height` 等降级方案，防止在不支持的浏览器中因内容过多导致容器过高。
- **灵活配置**：使用 CSS 变量或 DOM 的 `data-*` 属性动态控制显示行数。
- **细节处理**：使用 `word-break: break-all` 或 `word-wrap: break-word` 确保省略号在指定的行数上正确展示，避免单词换行导致的排版错乱。
