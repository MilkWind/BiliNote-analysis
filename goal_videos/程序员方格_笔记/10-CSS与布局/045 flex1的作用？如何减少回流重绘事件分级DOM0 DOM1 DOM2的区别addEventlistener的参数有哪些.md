## flex: 1 的作用 *Content-[00:00]

`flex: 1` 是前端面试中关于 Flex 布局的一道常见考题。它实际上是一个简写属性，等同于同时设置了以下三个属性：

- `flex-grow: 1`：定义项目的放大比例。
- `flex-shrink: 1`：定义项目的缩小比例。
- `flex-basis: 0`：定义在分配多余空间之前，项目占据的主轴空间（初始大小）。

因此，`flex: 1` 的完整写法等同于 `flex: 1 1 0`。它的主要作用是让元素自动填充剩余的可用空间，并且当多个元素都设置了 `flex: 1` 时，它们会平分这些剩余空间。

## 如何减少回流和重绘 *Content-[00:22]

回流（Reflow）和重绘（Repaint）是影响页面渲染性能的重要因素。为了减少回流和重绘事件，通常可以采用以下 6 种优化策略（视频重点讲解了 5 种）：

1\. **使用 CSS 属性简写**：在编写 CSS 时，尽量使用简写属性。例如，使用 `border` 来代替分别设置 `border-width`、`border-style` 和 `border-color`，这样可以减少浏览器的解析和渲染次数。
2\. **批量修改元素样式**：避免通过 JS 频繁直接修改元素的内联样式。建议通过 JS 直接操作 `class`（如切换类名）来批量修改样式。
3\. **避免使用 table 布局**：`table` 元素在计算布局时往往需要多次回流，性能较差，应尽量使用 Flex 或 Grid 等现代布局方式。
4\. **使用 DocumentFragment 创建 DOM 节点**：在 JS 中动态创建大量 DOM 节点时，不要直接插入页面。应先通过 `DocumentFragment` 在内存中创建并组装好节点，最后一次性插入到 DOM 树中，从而大幅减少页面回流。
5\. **避免在 for 循环中获取元素几何属性**：获取元素的位置或大小属性（如 `offsetWidth`、`clientHeight` 等）会强制浏览器刷新队列并触发回流。如果在 `for` 循环中频繁获取，会导致严重的性能问题。如果确实需要多次获取，建议将获取到的值缓存到变量中，避免重复触发回流。

## 事件分级：DOM0、DOM1、DOM2 的区别 *Content-[01:38]

DOM 事件处理机制随着标准的发展经历了不同的分级，主要分为 DOM0、DOM1 和 DOM2 级事件：

- **DOM0 级事件**：
  - **绑定方式**：直接在 HTML 标签中使用 `onclick` 等属性，或者在 JS 中通过 `element.onclick = function() {}` 进行绑定。
  - **特点**：同一个事件只能注册一次。如果多次绑定同一个事件，后面的绑定会覆盖前面的绑定。
- **DOM1 级事件**：
  - 由于历史原因和标准废弃，DOM1 级事件在现代开发中基本没有使用，了解即可。
- **DOM2 级事件**：
  - **绑定方式**：使用 `addEventListener` 方法绑定事件，这是目前最主流、最推荐的事件绑定方式。
  - **特点**：不会发生事件覆盖。为同一个元素绑定多少个监听器，就会触发多少次。
- **共存关系**：DOM0 级事件和 DOM2 级事件可以共存，它们不会互相覆盖；但是，DOM0 级事件之间会互相覆盖。

## addEventListener 的参数详解 *Content-[02:44]

`addEventListener` 是 DOM2 级事件的核心方法，它接收三个参数。需要特别注意的是，调用该方法的 DOM 元素本身（如 `el`）是方法的主体，而不是参数。其标准语法为 `element.addEventListener(type, listener, options)`，具体参数如下：

1\. **第一个参数 `type`**：
   - 事件类型（字符串），例如 `'click'`、`'scroll'` 等。
2\. **第二个参数 `listener`**：
   - 事件触发时执行的回调函数。
3\. **第三个参数 `options` / `useCapture`**（面试重点）：
   - 这个参数**可以是布尔值**，也**可以是一个对象**（很多初学者会忽略它作为对象的情况，这是大厂面试常考点）。
   - **当为布尔值时**：表示 `useCapture`，即是否在事件捕获阶段触发监听器（`true` 为捕获，`false` 为冒泡，默认 `false`）。
   - **当为对象时**：可以配置更细粒度的控制属性，常见的属性包括：
     - `capture`：布尔值，等同于 `useCapture`，表示是否在捕获阶段触发。
     - `once`：布尔值，表示是否只监听一次。如果设置为 `true`，事件触发一次后会自动移除监听器。
     - `passive`：布尔值，表示是否设置为被动监听。如果设置为 `true`，意味着监听器不会调用 `preventDefault()` 来阻止默认行为（常用于优化移动端滚动性能，防止滚动卡顿）。

*面试经验提示*：在腾讯等互联网大厂的面试中，非常喜欢考察“`addEventListener` 的第三个参数可以是对象”这一细节，建议结合 MDN 文档深入理解 `options` 对象中各个属性的具体作用。
