## 课程概述与学习路线 *Content-[00:00]
- **系列目标**：本系列课程旨在带领学习者系统地学习 CSS 布局知识，彻底攻克前端布局难题。
- **学习路径**：
  - 首先从一维布局 **Flex**（弹性盒子）开始学习。
  - 随后过渡到二维布局的常用工具 **Grid Layout**（网格布局）。

## 学习资源与参考工具 *Content-[00:12]
- **权威文档参考**：课程将严格参考 **MDN Web Docs** 文档，讲师会将复杂的知识点“掰开了、揉碎了”进行详细讲解，确保学习者能够透彻理解底层逻辑。
- **交互式学习游戏**：
  - 推荐 **Grid Garden** 小游戏。
  - 学习者可以在该平台上通过交互式、游戏化的方式练习和掌握 **Grid** 布局，降低学习门槛。
- **优质技术博客推荐**：
  - 推荐前端大神 **Josh Comeau** 的个人博客。
  - **博客亮点**：包含大量实用的前端开发知识，并且提供交互式的演练（Interactive exercises），对提升前端技能和理解布局原理有极大帮助。
