## 案例背景与准备 *Content-[00:00]
- **回顾旧案例**：回顾此前使用 Vue 2 编写的提交订单防抖案例。
- **本节课目标**：使用 Vue 3 重新实现该防抖功能，整体思路与 Vue 2 相似，但语法和钩子名称有所调整。
- **指令定义**：采用局部自定义指令的方式进行封装，指令命名为 `v-debounce`。

## 自定义指令防抖逻辑实现 *Content-[00:35]
- **核心钩子**：在 Vue 3 中，自定义指令主要使用 `mounted` 钩子（对应 Vue 2 的 `bind`），函数签名为 `mounted(el, binding)`。
- **防抖核心逻辑**：
  - **清除旧定时器**：在事件触发时，首先清除上一个定时器，防止重复执行。代码体现为 `clearTimeout(timer)`。
  - **开启新定时器**：重新开启一个定时器并赋值给变量 `timer`。代码体现为 `timer = setTimeout(() => { ... }, time)`。
  - **获取延迟时间**：通过 `binding.arg` 获取指令传递的参数（如 `500`），作为定时器的延迟时间。
  - **执行回调方法**：通过 `binding.value` 获取传入的回调函数（如 `submit`），并在定时器到期后调用该方法。代码体现为 `binding.value()`。

## 模板绑定与参数传递 *Content-[01:28]
- **模板指令绑定**：在按钮元素上绑定自定义指令，格式为 `<button v-debounce:500="submit">登录</button>`。
- **参数解析机制**：
  - **`arg` 参数**：冒号后面的 `500` 会被解析为指令的参数，在指令内部通过 `binding.arg` 获取，用于控制防抖的延迟时间（500ms）。
  - **`value` 参数**：等号后面的 `"submit"` 会被解析为指令的值，在指令内部通过 `binding.value` 获取。由于 `submit` 是一个方法引用，因此可以直接通过 `binding.value()` 来执行该提交逻辑。
- **业务方法定义**：在组件的 `methods`（或 `setup`）中定义 `submit` 方法，内部包含 `alert('登录成功')` 用于直观测试防抖效果。

## 效果测试与原理验证 *Content-[03:03]
- **数据验证**：通过在 `mounted` 钩子中打印 `binding` 对象，可以清晰看到：
  - `binding.arg` 成功获取到数值 `500`。
  - `binding.value` 成功获取到 `submit` 函数引用。
- **防抖效果验证**：
  - **连续快速点击**：如果每次点击的间隔时间小于 500ms，定时器会被不断重置，不会触发 `alert` 弹窗。
  - **停止点击后触发**：当停止点击，且最后一次点击距离当前时间超过 500ms 后，定时器到期，成功弹出 `alert('登录成功')`。
  - **结论**：完美符合防抖的核心原理（在事件触发 n 秒后再执行回调，若 n 秒内再次触发则重新计时）。

## Vue 2 与 Vue 3 自定义指令差异总结 *Content-[04:00]
- **整体一致性**：Vue 3 的自定义指令在核心逻辑、参数传递（`binding.arg`、`binding.value`）以及防抖实现思路上，与 Vue 2 保持完全一致。
- **语法与钩子差异**：
  - Vue 3 对自定义指令的钩子名称进行了调整，使其与 Vue 3 组件的生命周期钩子名称保持对齐。
  - 例如：Vue 2 中的 `bind` 钩子在 Vue 3 中变更为 `mounted`，`update` 变更为 `updated` 等。
- **核心含义不变**：虽然钩子函数的名称发生了改变，但各个钩子函数的触发时机和底层含义在 Vue 2 和 Vue 3 中是没有任何变化的。
