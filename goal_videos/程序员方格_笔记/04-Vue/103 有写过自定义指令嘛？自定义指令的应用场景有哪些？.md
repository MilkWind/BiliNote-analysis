## 1. 指令系统与自定义指令概述 *Content-[00:00]

### 1.1 什么是指令系统
- 在计算机底层，指令系统指的是硬件系统的语言（机器语言），决定了计算机的基本功能和能力。
- 在 **Vue** 生态中，“指令系统”提供了一套**数据驱动视图**的便捷操作方式。这些操作被视为 Vue 的指令系统。

### 1.2 内置指令与自定义指令
- **内置指令**：以 `v-` 开头的行内属性，如 `v-if`、`v-show`、`v-model`、`v-html` 等。不同的指令用于实现不同的视图控制功能。
- **自定义指令**：除了核心内置指令外，**Vue** 允许开发者注册自定义指令，以满足特定的底层 DOM 操作需求。

### 1.3 指令的使用方式
- **无参数使用**：`v-xxx`，直接实例化一个指令。
- **传递值**：`v-xxx="value"`，将具体的值（如字符串、表达式计算结果）传递到指令中。例如 `v-html` 用于渲染 HTML 标签。
- **传递参数**：`v-xxx:arg="value"`，通过冒号后传递参数。例如 `v-bind:class="className"`。
- **使用修饰符**：`v-xxx.modifier`，通过点号传递修饰符以改变指令的行为。

## 2. 自定义指令的注册与实现 *Content-[04:18]

### 2.1 全局注册
- 使用 **Vue** 的全局方法 `Vue.directive(id, [definition])` 进行注册。
- **参数说明**：
  - 第一个参数：指令的名字（**不需要**加 `v-` 前缀）。
  - 第二个参数：对象数据（包含生命周期钩子）或指令函数。
- **实战示例（v-focus）**：
  - 注册一个名为 `focus` 的全局指令。
  - 在 `inserted`（元素插入 DOM 时）钩子函数中，获取当前节点 `el`，并调用 `el.focus()` 方法让输入框自动获取焦点。
  - 这种方式非常适合在多个组件中复用“自动聚焦”功能。

### 2.2 局部注册
- 在组件的 `options` 选项中的 `directives` 属性进行注册。
- **实战示例**：
  - 在组件的 `directives` 对象中定义 `focus` 指令。
  - 内部逻辑与全局注册相同，在 `inserted` 钩子中调用 `el.focus()`。
  - 局部注册的指令仅在当前组件的模板中可用。

## 3. 钩子函数与参数详解 *Content-[08:30]

### 3.1 钩子函数的核心参数
自定义指令的钩子函数（如 `bind`、`inserted`、`update` 等）会接收以下核心参数：
- **`el`**：指令所绑定的元素，可直接用于操作 DOM。
- **`binding`**：一个包含指令相关信息的对象，其内部属性包括：
  - **`name`**：指令的名字（不包含 `v-` 前缀）。
  - **`value`**：指令绑定的值。例如 `v-my-directive="1 + 1"`，则 `value` 为 `2`。
  - **`oldValue`**：指令绑定的前一个值。仅在 `update` 和 `componentUpdated` 钩子中可用。
  - **`expression`**：字符串形式的指令表达式。例如 `v-my-directive="1 + 1"`，则 `expression` 为 `"1 + 1"`。
  - **`arg`**：传给指令的参数（可选）。例如 `v-my-directive:foo`，则 `arg` 为 `"foo"`。
  - **`modifiers`**：包含修饰符的对象。例如 `v-my-directive.foo.bar`，则 `modifiers` 为 `{ foo: true, bar: true }`。
- **`vnode`**：**Vue** 编译生成的虚拟节点。
- **`oldVnode`**：上一个虚拟节点。仅在 `update` 和 `componentUpdated` 钩子中可用。

### 3.2 参数使用示例
- 假设模板中使用 `v-demo="{ color: 'red', text: 'hello' }"`。
- 在钩子函数中，可以通过 `binding.value.color` 获取到 `'red'`，通过 `binding.value.text` 获取到 `'hello'`。

## 4. 自定义指令的应用场景与实战案例 *Content-[14:54]

### 4.1 常见应用场景
自定义指令非常适合封装底层的 DOM 操作，常见场景包括：
- **表单防止重复提交**（高频面试与实战场景）。
- **图片懒加载**。
- **一键复制**功能。

### 4.2 实战案例：表单防止重复提交
通过自定义指令（如 `v-prevent-resubmit`）实现防抖/节流，防止用户快速点击导致表单重复提交。
- **实现逻辑**：
  1. 使用 `Vue.directive` 注册指令（如命名为 `preventResubmit`）。
  2. 在 `bind` 钩子中，获取绑定的值（作为节流/延迟时间），若未传入则设置默认时间。
  3. 为元素添加点击事件监听器（`addEventListener`）。
  4. 在点击回调函数中：
     - 判断是否处于节流状态。
     - 若未处于节流状态，则执行回调，并使用 `setTimeout` 设置延迟，将当前状态标记为节流中，并在时间结束后恢复。
     - 若处于节流状态，则调用 `event.stopPropagation()` 和 `event.preventDefault()` 阻止事件冒泡和默认行为，从而拦截重复提交。
- **使用方式**：在组件的按钮上结合 `@click` 事件与该自定义指令使用，即可优雅地实现防重复提交功能。
