## Vue 自定义指令简介与应用场景 *Content-[00:00]
- 在 Vue 开发中，常遇到需要重复进行常见 DOM 操作的场景，如输入框自动聚焦、给元素添加防抖/节流，或为 HTML 元素添加 Vue 本身没有的特殊交互功能。
- 自定义指令能够将这些 DOM 操作很好地封装并复用，是解决上述问题的有效方案。

## 自定义指令的注册方式 *Content-[00:44]
Vue 提供了两种注册自定义指令的方式：

1\. **全局注册**
- 使用 `app.directive` 方法进行注册。
- 注册后，可以在项目中任何组件的模板中直接使用该指令。

2\. **局部注册**
- 在单个组件内部的 `directives` 选项中进行定义。
- 该指令仅在当前组件内部生效。

> **注意**：无论是全局还是局部注册，其基本语法都是一个包含钩子函数的对象。

## 核心钩子函数与参数 *Content-[01:30]
### 常用钩子函数
在自定义指令的钩子函数中，有三个最常用且最重要：

1\. **`mounted`**
- **调用时机**：指令绑定的元素被挂载到 DOM 上之后调用。
- **适用场景**：最适合用来做初始化操作。

2\. **`updated`**
- **调用时机**：组件更新导致指令绑定的元素也更新之后调用。
- **适用场景**：用于处理元素更新时的逻辑。

3\. **`unmounted`**
- **调用时机**：组件被卸载（即从 DOM 中移除）时调用。
- **适用场景**：非常适合做组件的清理工作。

### 钩子函数参数
钩子函数执行时会接收有用的参数，主要有三个：
- **`el`**：指令所绑定的真实 DOM 元素。后续所有的 DOM 操作基本都围绕 `el` 展开。
- **`binding`**：一个对象，包含指令的很多信息，如传给指令的值、参数、修饰符等。
- **`vnode`**：代表底层的虚拟节点（Virtual Node），一般使用较少。

> **重点**：日常开发中最常打交道的是 `el` 和 `binding` 这两个参数。

## 代码示例解析 *Content-[03:18]
### 示例 1：`v-focus` 自动聚焦指令
- **实现逻辑**：在 `mounted` 钩子函数中，获取指令绑定的 DOM 元素 `el`，直接调用其 `focus()` 方法。
- **效果**：当指令所在元素被挂载到页面时，立刻让其获得焦点。
- **使用方式**：全局注册后，在模板标签中直接使用 `v-focus` 即可实现页面加载时自动聚焦。

### 示例 2：`v-color` 动态颜色指令
- **实现逻辑**：
  - 在 `mounted` 和 `updated` 钩子中编写相同的逻辑：`el.style.color = binding.value`。
  - 在 `mounted` 中设置是为了保证元素首次加载时应用指定的初始颜色。
  - 在 `updated` 中设置是为了在绑定值变化时，颜色能跟着实时更新。
- **传值方式**：通过 `v-color="动态值"` 的方式传递动态值（类似 `v-bind` 或 `v-on`）。
- **响应式更新**：在指令内部通过 `binding.value` 获取外部传递的值。如果该值来自组件的响应式数据（如 `ref` 或 `reactive` 定义的数据），当数据变化时，会自动触发 `updated` 钩子，实现响应式更新。

## 自定义指令的典型应用场景 *Content-[06:06]
自定义指令的应用场景非常广泛，常见例子包括：

1\. **权限控制**
- 例如编写 `v-permission` 指令，根据当前用户权限决定按钮的显示、隐藏或禁用状态。
- **优势**：将权限逻辑与业务组件解耦，代码结构更清晰。

2\. **实现复杂动画效果**
- 例如页面滚动时让某个元素渐显或渐隐。
- **优势**：直接操作样式的场景非常适合用指令进行封装。

3\. **集成第三方库**
- 对于基于原生 DOM 操作的优秀 JavaScript 库（如拖拽库、图表库等）。
- **优势**：将这些库的初始化和销毁逻辑封装在自定义指令的钩子函数中，即可在 Vue 项目中方便地使用。

## 最佳实践与注意事项 *Content-[07:10]
编写自定义指令时，需注意以下几点：

1\. **遵循单一职责原则**
- 一个指令最好只专注做一件事（如 `v-focus` 只管聚焦，`v-debounce` 只管防抖）。
- 保持指令的纯粹性，使其更容易被理解和复用。

2\. **合理使用钩子函数**
- 不需要把每个钩子函数都写满，按需实现即可（如 `v-focus` 只需要 `mounted` 钩子）。

3\. **注意内存泄漏（非常重要）**
- 如果在 `mounted` 钩子中绑定了事件监听或创建了定时器，**务必**在 `unmounted` 钩子中将它们清理干净（如移除事件监听、清除定时器）。
- 这是一个非常好的编程习惯，能有效避免内存泄漏。

## 课程总结 *Content-[08:08]
- **核心思想**：自定义指令本质上是对底层 DOM 操作的一种抽象和封装。
- **优势**：让我们能够以一种更加声明式、更加 Vue 的方式来处理那些不得不做的 DOM 操作。
- **学习重点**：务必掌握 `mounted`、`updated`、`unmounted` 这几个核心钩子函数的调用时机，并在实际项目中灵活运用。
- 自定义指令是 Vue 生态中非常强大的工具，尤其在处理可复用的 DOM 行为时，能大幅提升开发效率。
