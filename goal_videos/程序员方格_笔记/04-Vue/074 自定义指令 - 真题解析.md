## 题1：什么是 Vue 自定义指令及其核心作用 *Content-[01:12]

**什么是 Vue 自定义指令？**
Vue 自定义指令是开发者自定义的、可绑定在 HTML 标签上的特殊指令。

**核心作用与用途：**
- **核心作用**：直接操作 DOM，用于封装和复用复杂的 DOM 操作逻辑。
- **主要用途**：解决 Vue 基础指令（如 `v-if`、`v-for`）无法满足的 DOM 操作需求。
- **常见使用场景**：输入框自动聚焦、限制输入格式、按钮防抖、滚动监听、表单验证等。由于使用场景丰富，简历项目中通常会有很多自定义指令的实战应用。

**答题重点**：突出“操作 DOM”的核心本质，以及明确区分 Vue2 和 Vue3 的版本差异。

## 题2：Vue2 自定义指令的钩子及执行时机 *Content-[02:05]

Vue2 中的自定义指令共有 5 个钩子函数，各自的执行时机如下：

1\. **`bind`**：指令第一次绑定到元素时执行。
   - **用途**：用于初始化操作（如绑定事件）。
   - **注意**：此时元素**尚未**插入到 DOM 中，因此**不能**进行 DOM 操作。
2\. **`inserted`**：绑定指令的元素插入父 DOM 节点时执行。
   - **用途**：用于操作 DOM（如自动聚焦）。
   - **注意**：此时元素**已经**插入到页面 DOM 中，**可以**进行 DOM 操作。
3\. **`update`**：元素所在组件的数据（VNode）更新时执行。
   - **用途**：用于同步状态。
   - **注意**：此时数据已更新，但 DOM **尚未**更新完毕。
4\. **`componentUpdated`**：元素所在组件及其子组件全部更新后执行。
   - **用途**：用于后续的 DOM 操作。
   - **注意**：此时数据不仅更新完毕，DOM 也**已经**渲染处理完毕。
5\. **`unbind`**：指令与元素解绑时执行。
   - **用途**：用于清理操作（如移除事件监听、清除定时器等），防止内存泄漏。

## 题3：Vue2 中全局与局部自定义指令的注册 *Content-[03:31]

在 Vue2 中，自定义指令分为全局注册和局部注册两种方式：

**全局注册**
- **特点**：所有组件均可使用。
- **语法**：`Vue.directive('指令名', { /* 配置对象 */ })`。注意 `directive` 方法**没有 `s`**。
- **适用场景**：整个项目通用的指令。例如项目中多处 input 框需要自动聚焦，可封装为全局指令。

**局部注册**
- **特点**：仅在当前组件内生效。
- **语法**：在 Vue 实例的选项对象中定义 `directives: { /* 指令名: 配置对象 */ }`。注意这里的选项名 `directives` **有 `s`**。
- **适用场景**：仅当前组件需要的指令。例如某个特定的下单表单数量输入框需要限制只能输入数字，其他地方不需要，注册为局部指令最为合适。

## 题4：Vue3 自定义指令的变化（钩子与注册方式） *Content-[04:40]

Vue3 中自定义指令执行的核心逻辑不变（依旧是操作 DOM），主要变化体现在钩子函数名称和注册方式上：

**1. 钩子函数名称优化**
Vue3 的指令钩子名称与组合式 API 的生命周期钩子保持对齐，功能不变：
- `bind` 变更为 `beforeMount`
- `inserted` 变更为 `mounted`
- `update` 变更为 `beforeUpdate`
- `componentUpdated` 变更为 `updated`
- `unbind` 变更为 `unmounted`
*(注：组件生命周期在 setup 中通常带 `on` 前缀如 `onMounted`，但指令钩子本身不带 `on` 前缀。)*

**2. 注册方式的变化**
- **全局注册**：Vue3 移除了全局 Vue 构造函数，需要先创建 `app` 实例，再通过 `app.directive('指令名', { ... })` 进行注册。
- **局部注册**：支持 `setup` 语法（组合式 API），可直接定义指令函数，无需使用 `directives` 选项，语法更加简洁。

## 题5：Vue2 与 Vue3 代码实现示例 *Content-[06:01]

针对“实现输入框自动聚焦”或“限制输入为数字”的功能，Vue2 和 Vue3 的核心实现逻辑是一致的，均是通过钩子函数获取 `el`（DOM 元素）并执行相应的 DOM 操作（如 `el.focus()` 或监听 `input` 事件过滤非数字字符）。两者的区别仅在于上述提到的钩子名称和 `setup` 语法的差异。

## 题6：钩子函数参数解析与修饰符传递 *Content-[06:20]

自定义指令的钩子函数接收多个参数，其中最常用的前三个参数为 `el`、`binding` 和 `vnode`：

**1. `el`**
- 绑定指令的真实 DOM 元素，可以直接对其进行 DOM 操作。指令绑定在哪个元素上，`el` 就指向哪个元素。

**2. `binding`**
- 包含指令相关信息的对象，常用属性包括：
  - `arg`：指令的参数。例如 `v-myDemo:length` 中，`arg` 的值为 `'length'`。
  - `value`：指令绑定的值。例如 `v-myDemo="10"` 中，`value` 的值为 `10`。
  - `modifiers`：修饰符对象。例如 `v-myDemo.trim` 中，`modifiers` 包含 `{ trim: true }`。

**3. `vnode`**
- Vue 编译生成的虚拟节点。通过 `vnode.context` 可以访问到组件实例的数据和方法。

**参数与修饰符的传递语法：**
标准语法为 `v-指令名:参数.修饰符="值"`。
- 示例：`v-myDemo:length.trim="10"`
- 解析：指令名为 `myDemo`，参数（`arg`）为 `length`，修饰符（`modifiers`）为 `trim`，值（`value`）为 `10`。

## 题7：Vue2 与 Vue3 自定义指令核心差异总结 *Content-[07:45]

1\. **钩子名称**：Vue3 的钩子名称进行了优化，与组合式 API 的生命周期钩子完全对齐。
2\. **全局注册方式**：Vue3 需要依赖 `app` 实例进行注册（`app.directive`），而 Vue2 直接通过 `Vue.directive` 注册。
3\. **局部注册方式**：Vue2 仅支持在 `directives` 选项中注册；Vue3 不仅支持选项式 API，还支持在 `setup` 中直接定义指令函数（组合式 API）。
4\. **语法风格**：Vue2 适配选项式 API，Vue3 适配组合式 API，代码更加简洁。
5\. **核心逻辑**：两者底层核心逻辑**完全一致**，都是为了操作 DOM 和封装复用 DOM 操作。

## 题8：自定义指令与计算属性、methods 的区别 *Content-[08:24]

这三者在 Vue 中扮演着不同的角色，适用场景各有侧重：

**1. 自定义指令 (Custom Directives)**
- **核心操作**：直接操作 DOM。
- **触发方式**：自动触发（由绑定的钩子函数决定触发时机）。
- **适用场景**：需要直接操作底层 DOM 时（如自动聚焦、绑定第三方库的 DOM 实例）。

**2. 计算属性 (Computed)**
- **核心操作**：依赖响应式数据，计算并派生出新的数据状态。
- **触发方式**：自动触发（只要其依赖的 `data` 中的数据状态发生变化，就会重新计算）。
- **适用场景**：基于响应式数据计算新数据。例如购物车的总价（单价 × 数量累加）和总数量（各商品数量相加），使用计算属性最为方便高效。

**3. 方法 (Methods)**
- **核心操作**：执行复杂的业务逻辑或数据操作（如数据的增删改查）。
- **触发方式**：手动触发（通常由用户交互或事件调用）。
- **适用场景**：需要执行复杂逻辑或手动触发操作时。例如提交表单、点击按钮发送验证短信等。其用法类似于原生 JavaScript 中的函数。
