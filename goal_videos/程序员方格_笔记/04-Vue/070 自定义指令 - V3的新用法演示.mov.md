## 1. Vue 3 自定义指令概述与实例创建 *Content-[00:00]
- **引入 Vue 3**：在 Vue 3（V3）版本中，自定义指令的钩子名称和注册方式相比 Vue 2 发生了显著变化。
- **创建应用实例**：Vue 3 不再直接使用 `new Vue()`，而是通过 `Vue.createApp()` 来创建应用实例。
  ```javascript
  const app = Vue.createApp({
      // 配置对象
  })
  ```
- **配置对象内容**：
  - `data`：定义响应式数据，例如 `inputValue: ''`。
  - `methods`：定义方法，例如 `unmountApp` 方法用于卸载应用，内部调用 `app.unmount()`。
- **挂载应用**：使用 `app.mount('#app')` 将创建的 Vue 实例与 DOM 中的 `#app` 元素进行关联，完成应用的挂载。

## 2. 局部注册自定义指令与 beforeMount 钩子 *Content-[01:56]
- **局部注册**：在 `createApp` 的配置对象中定义 `directives` 属性，用于局部注册自定义指令。
  ```javascript
  directives: {
      hookDemo: {
          // 钩子函数
      }
  }
  ```
- **模板中使用**：在 HTML 中通过 `v-hook-demo` 绑定指令，例如 `<input v-hook-demo placeholder="请输入内容">`。
- **第一个钩子 `beforeMount`**：
  - 对应 Vue 2 中的 `bind` 钩子。
  - **参数解析**：
    - `el`：指令所绑定的元素（如 `input`）。
    - `binding`：一个对象，包含 `value`、`arg`、`modifiers` 等属性。其中 `binding.value` 获取的是绑定变量的值（即 `data` 中的 `inputValue`）。
  - **执行时机**：在指令绑定到元素时触发，但此时元素尚未插入到 DOM 中。

## 3. mounted 钩子与 DOM 操作 *Content-[04:49]
- **`beforeMount` 的局限性**：在 `beforeMount` 钩子中，虽然可以通过 `el` 获取到元素，但此时元素“菜做好了但没上桌”，即**尚未插入到 DOM 中**。因此，执行如 `el.focus()` 等 DOM 操作是无效的，输入框不会出现光标闪烁。
- **第二个钩子 `mounted`**：
  - 对应 Vue 2 中的 `inserted` 钩子。
  - **执行时机**：元素已经成功插入到页面 DOM 中。
  - **DOM 操作**：在 `mounted` 钩子中执行 `el.focus()` 是有效的，输入框会成功获取焦点并出现光标闪烁。

## 4. beforeUpdate 与 updated 钩子 *Content-[06:29]
- **第三个钩子 `beforeUpdate`**：
  - 对应 Vue 2 中的 `update` 钩子。
  - **执行时机**：数据发生更新，但是组件或视图**尚未渲染完毕**。
  - **触发方式**：通过在页面上修改输入框的值（如改变 `inputValue` 的数据），可以触发此钩子。
- **第四个钩子 `updated`**：
  - 对应 Vue 2 中的 `componentUpdated` 钩子。
  - **执行时机**：数据更新且组件/视图**已经更新完毕**。
  - **表现**：当数据改变并触发视图重新渲染完成后，会依次执行 `beforeUpdate` 和 `updated`。

## 5. unmounted 钩子与应用卸载 *Content-[09:22]
- **第五个钩子 `unmounted`**：
  - 对应 Vue 2 中的 `unbind` 钩子。
  - **执行时机**：指令与元素解绑时触发。
  - **操作示例**：在钩子函数中可以执行清理工作，例如 `alert('解绑完毕')`。
- **触发卸载**：
  - 在页面添加一个按钮，绑定 `unmountApp` 方法。
  - 点击按钮调用 `app.unmount()`，触发 Vue 3 应用的卸载。
  - 卸载时，`unmounted` 钩子被触发，元素与自定义指令彻底解绑，页面上的相关元素被清空。

## 6. Vue 3 与 Vue 2 自定义指令钩子对比总结 *Content-[10:55]
Vue 3 中的自定义指令钩子逻辑与 Vue 2 基本一致，主要是为了与组件的生命周期钩子名称保持统一，对钩子名称进行了调整。具体对应关系如下：

- `bind` $\rightarrow$ `beforeMount`（指令第一次绑定到元素时）
- `inserted` $\rightarrow$ `mounted`（被绑定元素插入父节点时）
- `update` $\rightarrow$ `beforeUpdate`（组件 VNode 更新前）
- `componentUpdated` $\rightarrow$ `updated`（组件 VNode 及子 VNode 更新后）
- `unbind` $\rightarrow$ `unmounted`（指令与元素解绑时）
