## Pinia 简介与核心概念概览 *Content-[00:00]

Pinia 是目前 Vue 官方首选推荐的状态管理库。它最大的优点是非常轻量，并且对 TypeScript 的支持特别友好，编写起来非常安全。

Pinia 的核心概念主要包含以下三个部分：
- **State**：专门用来存数据的地方，可以把它理解为一个“仓库”。
- **Getters**：仓库数据的“计算器”，可以根据现有的数据计算并派生出一些新的值。
- **Actions**：负责处理各种业务逻辑，例如点击按钮之后具体要执行的操作。

## State：状态存储与响应式核心 *Content-[00:46]

State 可以说是 Pinia 的心脏，应用中所有需要共享的数据都应该存放在这里。

- **核心特点（响应式）**：一旦 State 里面的数据发生变化，页面上所有用到该数据的地方都会被自动更新，完全不需要手动去操作 DOM，非常方便。
- **定义方式**：在 Store 里面找到 `state` 函数，让它返回一个对象，这个对象里面包含的就是需要管理的数据。
- **使用方式**：
  - 可以通过 Store 实例直接访问（例如：`store.count`）。
  - 如果想一次性修改多个数据，可以使用 `$patch` 方法，这样执行效率会更高。

这种结构非常清晰简单，特别适合存放一些基础的、需要全局共享的数据。

## Getters：计算属性与缓存机制 *Content-[02:07]

如果你用过 Vue，可以把 Getters 理解为 Store 里面的 `computed`（计算属性）。

- **主要作用**：基于 State 里面的数据进行计算，派生出一些新的状态。例如，想知道任务列表中有多少个已完成的任务，这种计算就特别适合放在 Getters 里面。
- **核心优势（缓存机制）**：
  - 只要依赖的 State 数据没有发生变化，即使访问该 Getter 100 次，它也只会计算一次，后续直接返回缓存的结果，性能极佳。
  - 只有当依赖的 State 发生变化时，才会触发重新计算。
- **定义与使用**：定义方式与 Vue 的 `computed` 很像。在 Getters 内部，还可以访问其他的 Getters。
- **使用场景**：过滤数据，或者根据现有的状态派生新的状态。

**代码示例（任务管理 Store）**：
在 `getters` 对象中定义了以下几个计算属性：
- `doneTodos`：从 State 的 `todos` 数组中，过滤出 `done` 属性为 `true` 的任务（即已完成的任务）。
- `activeTodos`：正好相反，过滤出未完成的任务。
- `doneCount`：直接统计已完成任务的数量。
这几个 Getters 都是基于 State 里的 `todos` 数组进行计算的，得益于缓存机制，性能得到了极大的优化。

## Actions：业务逻辑与异步操作 *Content-[04:00]

如果 State 是存放数据的地方，Getters 是计算数据的地方，那么 Actions 就是处理业务逻辑的地方。

- **主要职责**：处理用户点击按钮、提交表单等操作背后的具体逻辑。
- **核心特点（支持异步）**：Actions 支持异步操作。例如需要请求服务器接口拿数据，可以在 Actions 中使用 `async/await` 语法来轻松处理异步请求。
- **定义方式**：就像定义普通对象方法一样，在 `actions` 对象中定义所有的方法。
- **状态修改**：
  - 在 Action 内部，可以通过 `this` 来访问定义的状态。
  - 可以直接修改 `this` 上的 State 值（例如往数组里 `push` 一个对象）。
- **与 Getters 的最大区别**：Getters 只能读取和计算数据，而 Actions 是可以直接修改状态的。

## 核心概念总结回顾 *Content-[05:06]

本节课主要学习了 Pinia 的三大核心概念，它们的职责分工如下：

1\. **State**：数据的核心，专门用来存储应用的状态，并且具备响应式特性。
2\. **Getters**：相当于 Store 的计算属性，负责对 State 的数据进行计算和派生，并且带有缓存功能，可以有效优化性能。
3\. **Actions**：负责处理所有的业务逻辑，特别是异步操作（如调用 API）。讲师特别强调，在 Store 内部主要通过 Actions 来修改 State。

**最佳实践建议**：
牢记这三个概念，明确它们的分工并合理使用，就可以构建出高效、清晰且易于维护的状态管理系统。

## AI 总结

Pinia 作为 Vue 官方推荐的状态管理库，以其轻量和优秀的 TypeScript 支持成为前端开发的首选。其核心架构由三部分组成：**State** 负责集中存储响应式数据；**Getters** 提供类似计算属性的派生状态与缓存优化；**Actions** 则专注于处理同步或异步的业务逻辑及状态修改。掌握这三者的明确分工与协作机制，是构建高质量 Vue 应用状态管理系统的基石，也是前端面试中的高频核心考点。
