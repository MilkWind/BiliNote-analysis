## Vue 单文件组件 (SFC) 概述 *Content-[00:00]
在 Vue 应用开发中，单文件组件（Single-File Component，简称 SFC，即 `.vue` 文件）是最常用且最核心的组件结构。它将组件的模板、逻辑和样式封装在一个文件中，极大地提升了开发体验。

## 1. 结构层级 *Content-[00:16]
单文件组件在结构上通常由以下三个核心部分组成：

* **`<template>`**：用于定义组件的 HTML 结构，全面支持 Vue 的模板语法（如数据绑定、指令等）。
* **`<script>`**：用于包含组件的业务逻辑和数据状态。通常使用 JavaScript 或 TypeScript 进行编写。
* **`<style>`**：用于定义组件的样式。支持普通的 CSS，也支持 CSS 预处理器（如 Sass/SCSS、Less）以及 CSS Modules，以实现更强大的样式处理能力。

## 2. 样式作用域 (Scoped) *Content-[00:51]
为了解决样式冲突问题，Vue 提供了样式作用域隔离机制：

* 通过在 `<style>` 标签中添加 `scoped` 属性，可以限制样式的作用范围。
* 这确保了该标签内的样式只应用于当前组件，从而有效避免全局样式污染和组件间的样式冲突。

## 3. 组件复用 *Content-[01:10]
单文件组件具备高度的可复用性：

* 编写好的 `.vue` 文件可以被其他组件轻松导入（import）并使用。
* 这种机制完美支持了组件的复用与灵活组合，是构建大型前端应用的基础。

## 4. 生命周期钩子 *Content-[01:24]
在组件的 `<script>` 部分，开发者可以使用 Vue 提供的生命周期钩子函数来管理组件在不同阶段的行为：

* 常用钩子包括 `created`、`mounted` 等。
* 通过这些钩子，可以精确控制组件在创建、挂载、更新和销毁等生命周期节点执行的特定逻辑（如发起网络请求、操作 DOM 等）。

## 5. 组合式 API (Composition API) *Content-[01:41]
在 Vue 3 中，组合式 API 成为了组织组件逻辑的重要方式：

* 通过 `setup` 函数（或 `<script setup>` 语法糖）来组织和聚合相关的业务逻辑。
* 相比于传统的选项式 API，组合式 API 能够将同一业务逻辑的代码集中在一起，显著提高了代码的可读性和可维护性。

## 6. 模块化设计 *Content-[01:56]
单文件组件天然契合模块化开发思想：

* 它将视图、逻辑和样式封装在独立的文件中，使得组件的结构更加模块化。
* 这种高内聚、低耦合的设计，极大地便于了项目的整体管理和后续的迭代维护。

## 总结 *Content-[02:11]
总而言之，单文件组件（SFC）是 Vue 应用的核心构建块。它通过清晰的三段式结构（Template、Script、Style）和模块化的设计理念，不仅规范了代码组织方式，还大幅提升了前端的开发效率与代码的可维护性。
