## 1. 面试背景与常见痛点 *Content-[00:01]

### 大厂面试高频考点
根据近一年一线大厂的 Vue 面试真题统计，**自定义指令**相关面试题的出现频率高达 **95.1%**。
涉及的大厂包括：阿里、腾讯、字节、百度、美团、京东、拼多多、网易、快手、滴滴、小红书、携程等十几家头部互联网企业。

### 候选人常见错误与痛点
在实际面试中，许多候选人在这道题上容易失分，主要存在以下问题：
- **版本认知局限**：只懂 Vue 2 的自定义指令，说不出 Vue 3 的变化。
- **注册方式混淆**：分不清全局注册和局部注册的区别与用法。
- **概念混淆**：把自定义指令和计算属性（Computed）搞混。
- **核心本质不清**：连自定义指令的核心是**操作 DOM** 都不知道。

## 2. 自定义指令的核心价值与应用场景 *Content-[00:43]

### 面试官考察意图
自定义指令是 Vue 的拓展技能，也是面试官筛选潜力学员的关键指标。特别是 Vue 2 和 Vue 3 的差异，以及相关的钩子函数，是大厂考察候选人**版本迁移能力**的核心考点。

### 核心应用场景
自定义指令主要用于直接操作 DOM，常见的实际业务场景包括：
- 输入框自动聚焦
- 限制输入格式（如仅允许输入数字）
- 按钮防抖 / 节流
- 滚动监听

## 3. 大厂高频面试真题汇总 *Content-[01:28]

以下是根据大厂真实面试整理的 9 道高频真题，涵盖了概念、钩子、注册、版本差异及实战应用：

1\. **什么是 Vue 的自定义指令？它的核心用途是什么？**
   - *考察重点*：基础概念理解，字节、百度高频题。

2\. **Vue 2 中自定义指令有哪些钩子函数？各自的执行时间是什么时候？**
   - *考察重点*：Vue 2 的 5 个钩子函数（`bind`, `inserted`, `update`, `componentUpdated`, `unbind`）及其生命周期触发时机。

3\. **如何在 Vue 中注册全局和局部自定义指令？语法是什么？**
   - *考察重点*：全局注册（`Vue.directive`）与局部注册（组件内的 `directives` 选项）的代码实现。

4\. **Vue 3 中自定义指令有哪些变化？钩子函数和注册方式有何不同？**
   - *考察重点*：Vue 3 钩子函数与组件生命周期对齐（如 `created`, `mounted` 等），以及 `app.directive` 的全局注册方式。

5\. **请分别用 Vue 2 和 Vue 3 实现输入框自动聚焦或限制输入为数字的功能。**
   - *考察重点*：实际代码编写能力，考察对两个版本钩子函数和 DOM 操作的熟练度。

6\. **自定义指令中 `el`, `binding`, `vnode` 的三个参数分别代表什么？如何传递参数和修饰符？**
   - *考察重点*：钩子函数参数的深层理解。`el`（指令绑定的元素）、`binding`（包含指令名称、参数、修饰符、值等）、`vnode`（虚拟节点）。

7\. **Vue 2 和 Vue 3 自定义指令的核心差异在哪里？**
   - *考察重点*：宏观版本差异对比，重点在于钩子函数命名的变更及与组件生命周期的统一。

8\. **自定义指令和计算属性（Computed）/ 侦听器（Watch）设置值的区别是什么？适用的场景有哪些？**
   - *考察重点*：概念辨析。自定义指令侧重于**底层 DOM 操作**和**第三方库集成**；而计算属性/侦听器侧重于**数据状态的计算与响应式更新**。

9\. **自定义指令如何实现防抖、节流的功能？**
   - *考察重点*：结合 JS 基础（防抖/节流函数）与 Vue 指令（如 `bind`/`mounted` 中绑定事件，`unbind`/`unmounted` 中移除事件）的综合实战能力。
