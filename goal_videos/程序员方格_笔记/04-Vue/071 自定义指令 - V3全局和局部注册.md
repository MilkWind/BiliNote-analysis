## Vue 3 全局注册自定义指令 *Content-[00:00]
- **注册方式**：在 Vue 3 中，全局自定义指令通过 `app.directive()` 方法进行挂载。
- **语法结构**：
  - 第一个参数：自定义指令的名称（如 `focus`，在模板中使用时为 `v-focus`）。
  - 第二个参数：一个包含钩子函数的对象。
- **示例：自动聚焦指令 (`v-focus`)**
  - **需求**：在输入框插入页面后自动获取焦点。
  - **钩子选择**：必须使用 `mounted` 钩子。因为需要获取真实的 DOM 元素，只有在元素插入页面（挂载）后才能执行聚焦操作。不能使用 `beforeMount`。
  - **核心代码**：
    ```javascript
    app.directive('focus', {
      mounted(el) {
        el.focus();
      }
    });
    ```
- **作用域**：全局注册意味着在整个 Vue 应用实例中，任何组件都可以使用该指令，类似于全局函数，没有作用域限制。

## Vue 3 局部注册自定义指令 (Options API) *Content-[02:49]
- **注册方式**：在组件内部的 `directives` 选项中进行注册，仅在当前组件内有效。
- **示例：限制只能输入数字 (`v-only-number`)**
  - **需求**：在输入框中过滤非数字字符。
  - **核心逻辑**：
    1. **封装事件处理函数**：定义一个具名函数 `handleInput`，使用正则表达式 `/[^0-9]/g` 将非数字字符全局替换为空。
       ```javascript
       const handleInput = (e) => {
         e.target.value = e.target.value.replace(/[^0-9]/g, '');
       };
       ```
    2. **绑定事件 (`mounted`)**：在元素挂载时，使用 `el.addEventListener('input', handleInput)` 绑定输入事件。
    3. **移除事件 (`unmounted`)**：在元素解绑时，使用 `el.removeEventListener('input', handleInput)` 移除事件。
- **关键细节与防坑指南**：
  - **必须使用具名函数**：在调用 `addEventListener` 和 `removeEventListener` 时，回调函数必须是具名函数（如 `handleInput`），不能是匿名函数，否则无法正确移除事件。
  - **防止内存泄漏**：在 `unmounted` 钩子中移除事件监听器非常重要。如果不移除，事件处理函数会一直被引用，导致内存无法被垃圾回收，进而引发内存泄漏或无故占用内存。

## Vue 3 与 Vue 2 自定义指令钩子差异 *Content-[07:49]
- **钩子名称统一**：Vue 3 中自定义指令的钩子函数名称与组件的生命周期钩子名称保持了一致（例如使用 `mounted` 和 `unmounted`）。
- **对比 Vue 2**：Vue 2 中自定义指令的钩子名称与组件生命周期不同（如 `inserted`、`unbind`）。Vue 3 的改动降低了学习成本，更加方便理解和记忆。
- **效果一致性**：虽然钩子名称和 API 有所变化，但实现的最终业务效果与 Vue 2 是完全一致的。

## Vue 3 局部注册自定义指令 (Script Setup) *Content-[08:45]
- **推荐写法**：在 Vue 3 的 `<script setup>` 语法糖中，局部注册自定义指令有更加简洁的写法，这也是实际开发（脚手架项目）中最推荐的用法。
- **语法特点**：
  - 不需要将指令嵌套在 `directives` 等 Options 配置对象中。
  - 直接定义一个以 `v` 开头的指令对象（如 `vOnlyNumber`），并在其中编写钩子函数。
- **示例代码**：
  ```javascript
  <script setup>
  // 直接定义指令对象，变量名需以 v 开头
  const vOnlyNumber = {
    mounted(el) {
      const handleInput = (e) => {
        e.target.value = e.target.value.replace(/[^0-9]/g, '');
      };
      el.addEventListener('input', handleInput);
    },
    unmounted(el) {
      // 移除事件监听器以防止内存泄漏
    }
  };
  </script>
  ```
- **优势**：代码结构更扁平，无需理解 Options 的嵌套层级，书写更加简洁高效。
