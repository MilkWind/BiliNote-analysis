## Vue 响应式系统核心概念 *Content-[00:35]
- 响应式系统是 Vue 的核心特点之一。
- 其核心工作机制主要依赖于以下两点：
  - **数据劫持**：拦截数据的读取和修改操作。
  - **依赖追踪**：记录哪些视图或计算属性依赖于特定的数据。
- 通过上述机制，Vue 能够实现**视图与数据的实时联动**，即数据变化自动驱动视图更新。

## Vue 2 响应式原理详解 *Content-[01:07]
Vue 2 的响应式系统主要基于 `Object.defineProperty` 实现，具体工作流程如下：

- **数据劫持**：
  - 使用 `Object.defineProperty` 为对象的每个属性定义 `get` 和 `set` 拦截器。
  - 通过拦截属性的访问（读取）和修改（赋值）来实现数据的响应式。

- **依赖收集（get 拦截）**：
  - 当读取数据时，触发 `get` 拦截器。
  - 在此阶段进行**依赖收集**，将当前正在执行的 `Watcher`（观察者）添加到依赖中。

- **通知更新（set 拦截）**：
  - 当修改数据时，触发 `set` 拦截器。
  - 在此阶段通知之前收集到的依赖进行更新。

- **依赖收集器（dep）**：
  - 每个响应式属性都拥有一个 `dep`（依赖）对象。
  - `dep` 用于存储所有依赖该属性的 `Watcher`。
  - 当属性被访问时，将当前的 `Watcher` 添加到对应的 `dep` 当中。

- **触发更新流程**：
  - 属性发生变化 -> 触发 `set` -> `dep` 通知其保存的所有 `Watcher` -> `Watcher` 执行对应的更新逻辑。

- **模板更新与性能优化**：
  - `Watcher` 负责最终的 DOM 更新。
  - 结合**虚拟 DOM** 和 **Diff 算法**，Vue 2 能够精确计算出需要更新的最小 DOM 节点，只更新必要的部分，从而大幅提升渲染性能。

## Vue 3 响应式原理详解 *Content-[05:09]
Vue 3 使用 ES6 的 `Proxy` 替代了 `Object.defineProperty`，解决了 Vue 2 中的诸多局限性，其核心特点与优势如下：

- **Proxy 的核心优势**：
  - **监听动态属性**：能够监听对象属性的动态添加和删除。解决了 Vue 2 中新增属性无法被响应式系统捕获（需要使用 `$set`）的问题。
  - **支持复杂数据结构**：原生支持对数组、`Map`、`Set` 等复杂数据结构的深度监控，而无需像 Vue 2 那样重写数组原型方法。

- **核心 API 响应式包装**：
  - `reactive`：用于将对象（引用类型）包装成响应式对象。
  - `ref`：用于将基础数据类型（如数字、字符串）包装成单个值的响应式数据。

- **依赖追踪与触发更新**：
  - 内部使用 `effect` 函数来进行依赖收集。
  - 当数据发生变化时，自动触发对应的 `effect` 更新逻辑，实现精准的响应式追踪。

## 数据的双向绑定实现 *Content-[08:18]
数据的双向绑定主要通过 `v-model` 指令来实现，Vue 2 和 Vue 3 在实现细节上有所不同：

- **Vue 2 中的 v-model**：
  - 本质上是一个**语法糖**。
  - 相当于在元素上绑定了 `value` 属性（或其他对应属性）以及 `input` 事件（或其他对应事件），即 `:value` + `@input`。

- **Vue 3 中的 v-model**：
  - 得到了增强，**支持绑定多个值**。
  - 可以通过 `v-model:propName` 的语法来指定绑定的属性名和事件名，提供了更高的灵活性。

- **数据驱动的双向流程**：
  - **数据到视图**：数据发生变化 -> 触发 `setter` -> 通知依赖 -> 更新视图。
  - **视图到数据**：用户输入 -> 触发事件监听 -> 更新数据 -> 完成双向绑定的闭环。

## 响应式系统总结 *Content-[09:59]
- Vue 的响应式系统通过**劫持数据的访问和修改**，完美实现了视图与数据的同步更新。
- **Vue 2** 奠定了响应式的基础，通过 `Object.defineProperty` 实现了数据劫持与依赖收集。
- **Vue 3** 则通过引入 `Proxy`，彻底解决了 Vue 2 在动态属性和复杂数据结构监听上的痛点，大幅提升了系统的**性能**与**灵活性**，使得响应式系统更加高效且易用。
