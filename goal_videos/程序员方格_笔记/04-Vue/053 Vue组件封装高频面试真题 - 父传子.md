## 组件通信概述 *Content-[00:01]

- **组件封装的核心**：组件封装后，不同的组件之间是相互独立的（就像两个独立的房间）。它们之间要传递数据、触发事件，就必须依赖**组件通信**，这是组件封装的核心，也是面试必考、大厂高频询问的知识点。
- **组件关系**：组件之间最常见的是**父子关系**（如同家庭中的父母与孩子）。父组件可以给子组件传值，子组件可以给父组件触发事件。
- **面试技巧**：
  - 当面试官问及“组件封装”时，可以简单提一句兄弟组件等复杂的通信方式。
  - 但如果直接问及“组件通信”，则不能只简单提一句，必须详细掌握并能够列举出各种组件通信方式。重点需要掌握父子组件通信。

## 父传子核心机制：Props *Content-[01:13]

- **基本概念**：父组件向子组件传值使用 `props`。`props` 就像是父组件给子组件送东西的“快递”，子组件接收后就能使用这些数据。
- **核心要点**：在使用子组件时，通过**自定义属性**的方式把数据传递给子组件。例如 `<ChildComponent title="欢迎学习" />`，其中 `title` 是自定义属性，`"欢迎学习"` 是要传递的数据。
- **关键细节（v-bind 的使用）**：
  - 如果传递的是字符串本身（如直接传 `"欢迎学习"`），**不要**加冒号，也**不要**加 `v-bind`。
  - 如果传递的是一个变量，**必须**加上 `v-bind`（或简写为 `:`），例如 `:title="myTitle"`。
- **数据接收与使用**：子组件通过 `props` 选项接收父组件传递过来的数据，然后在组件内部直接使用插值语法（如 `{{ title }}`）进行展示。
- **单向数据流**：`props` 是单向的，只能父组件给子组件传值。子组件**不能直接修改**父组件传递过来的数据。如果需要修改，只能让父组件修改后再重新传递过来。

## 实战：封装用户信息卡片组件 *Content-[03:40]

本环节通过封装一个用户信息卡片 `UserCard`，来实战回顾父传子的应用。该组件用于接收并展示父组件传递的用户姓名、年龄和头像。

- **创建组件文件**：新建 `user-card.vue`。
- **HTML 结构设计**：
  - 外层容器：`<div class="user-card">`
  - 头像展示：`<img>` 标签。
  - 用户信息容器：`<div class="user-info">`，内部包含两个 `<p>` 标签，分别用于展示姓名和年龄。
- **组件命名**：在组件选项中定义 `name: 'UserCard'`，养成良好的命名习惯。
- **CSS 样式编写**（使用 `scoped` 进行样式隔离）：
  - `.user-card`：宽度 300px，`display: flex` 弹性盒子布局，`align-items: center` 垂直居中，添加边框、圆角 8px、内边距 `padding: 15px`，外边距 `margin: 0 auto 20px`（水平居中，底部留白）。
  - `img`：宽高均为 80px，`border-radius: 50%` 实现圆形，`margin-right: 20px` 与右侧姓名保持距离。
  - `.user-info p`：外边距 `margin: 5px 0`，字体大小 16px，颜色 `#333`。

## 父组件使用与 Props 校验 *Content-[08:01]

- **在父组件中使用**：在 `App.vue`（父组件）中导入、注册并使用 `<UserCard>` 组件。
- **传递数据**：
  - 头像 `avatar`：传入提前准备好的图片 URL。
  - 姓名 `name`：传入 `"张三"`。
  - 年龄 `age`：传入 `"22"`（注意：此处初始传入为字符串格式）。
- **子组件 Props 接收与类型校验**（良好习惯）：
  - `avatar`：`type: String`，`required: true`（必填项）。
  - `name`：`type: String`，`required: true`（必填项）。
  - `age`：`type: Number`，`default: 18`（设置默认值为 18 岁）。
- **模板数据绑定**：
  - 头像动态绑定：`<img :src="avatar">`。
  - 文本插值绑定：`{{ name }}` 和 `{{ age }}`。

## 常见报错与 Debug 解析 *Content-[10:23]

在运行和调试过程中，遇到了几个典型的前端开发问题，解析如下：

- **问题 1：语法错误**。
  - **原因**：`props` 配置对象中属性之间少了一个逗号。
  - **解决**：补全逗号，修复语法。
- **问题 2：头像图片不显示**。
  - **原因**：在子组件模板中，`<img src="avatar">` 没有使用动态绑定，导致 Vue 将其解析为普通字符串路径。
  - **解决**：加上冒号改为 `<img :src="avatar">`，使其能够正确解析变量中的 URL。
- **问题 3：Props 类型校验报错**。
  - **原因**：子组件要求 `age` 的类型为 `Number`，但父组件传入的是字符串 `"22"`，导致类型不匹配。
  - **解决**：在父组件传值时加上冒号进行动态绑定，改为 `:age="22"`，使其在 JavaScript 中成为数字类型。
- **问题 4：`main.js` 路由报错**。
  - **原因**：项目中引入了未正确配置的路由代码（如找不到 `home` 路由）。
  - **解决**：注释掉当前用不上的路由相关代码，消除控制台报错。

## 组件复用与总结 *Content-[12:53]

- **组件复用演示**：在父组件中第二次使用 `<UserCard>`，传入不同的数据（如女生头像、姓名 `"张小衫"`、年龄 `:age="20"`），验证组件的复用性。刷新页面后，数据正确渲染（头像未显示仅为网络延迟问题）。
- **核心总结**：
  - `App.vue` 作为父组件（使用方），`UserCard` 作为被复用的公共子组件。
  - 整个数据传递过程全程使用了“父传子”的 `props` 机制，完美实现了组件的数据驱动与高复用性。
