## 1. Vue 修饰符概述 *Content-[00:02]
在编程世界中，修饰符通常用于限定类型或类型相关的成员声明。在 Vue 中，修饰符主要用于处理 DOM 事件相关的细节。它让开发者无需花费大量精力去处理琐碎的 DOM 操作，从而能够专注于复杂的业务逻辑。

Vue 的修饰符主要分为以下五大类：
- 表单修饰符
- 事件修饰符
- 鼠标按键修饰符
- 键值（键盘）修饰符
- v-bind 修饰符

## 2. 表单修饰符 *Content-[01:51]
表单修饰符主要用于 `<input>` 等表单标签，通常配合 `v-model` 指令使用，以简化表单数据的处理。

- `.lazy`：默认情况下，`v-model` 会在 `input` 事件中同步数据。使用 `.lazy` 后，数据同步会推迟到 `change` 事件（即光标离开输入框时）才触发。
- `.trim`：自动过滤用户输入的首尾空格，中间的空格不会被过滤。这避免了在 JS 中手动调用 `trim()` 方法。
- `.number`：自动将用户的输入值转换为数值类型（类似 `parseFloat`）。如果转换失败，则返回原始值。常用于年龄（age）等需要数值类型的表单字段。

## 3. 事件修饰符 *Content-[05:38]
事件修饰符用于处理事件冒泡、默认行为等 DOM 事件细节，替代了原生 JS 中繁琐的事件对象方法调用。

- `.stop`：阻止事件冒泡。等同于原生 JS 中的 `event.stopPropagation()`。
- `.prevent`：阻止默认事件。等同于原生 JS 中的 `event.preventDefault()`。常用于 `<form>` 提交时，阻止默认的页面刷新行为，直接执行自定义的提交逻辑。
- `.self`：只有当 `event.target` 是当前元素自身时才触发处理函数，即事件不是从内部子元素冒泡上来的。
- `.once`：限制事件只触发一次。绑定后，第二次点击将不再触发该事件。
- `.capture`：改变事件触发顺序，使事件从包含该元素的顶层开始往下触发（捕获阶段），而不是默认的冒泡阶段。
- `.passive`：主要用于移动端滚动事件（如 `scroll`）的性能优化。相当于给事件加了 `.lazy`，告诉浏览器不会阻止默认行为，从而避免频繁触发 `onscroll` 导致的页面卡顿。
- `.native`：将组件变成像原生 HTML 标签一样，监听组件的原生 DOM 事件。如果不加此修饰符，在组件上使用 `v-on` 只会监听自定义事件。

## 4. 鼠标按钮修饰符 *Content-[15:57]
鼠标按钮修饰符用于限制监听特定的鼠标按键点击事件，使事件处理更加精准。

- `.left`：仅监听鼠标左键点击。
- `.right`：仅监听鼠标右键点击。
- `.middle`：仅监听鼠标中键（滚轮）点击。

使用示例：`@click.left="handleLeftClick"`。

## 5. 键盘修饰符 *Content-[17:20]
键盘修饰符用于修饰键盘事件（如 `@keyup`、`@keydown` 等），Vue 为常用的按键提供了便捷的别名。

- **普通键别名**：包含 `enter`、`tab`、`delete`（捕获“删除”和“退格”键）、`space`、`esc`、`up`、`down`、`left`、`right` 等。
- **系统修饰符**：用于配合鼠标或键盘事件使用，包含 `ctrl`、`alt`、`meta`（Mac 下的 Command 键，Windows 下的 Win 键）、`shift`。
- **自定义键盘别名**：可以通过 `Vue.config.keyCodes` 全局定义自定义键码别名。例如：`Vue.config.keyCodes.f2 = 113`，然后在模板中直接使用 `@keyup.f2` 来监听 F2 键。

## 6. v-bind 修饰符 *Content-[20:03]
v-bind 修饰符主要用于对 `v-bind`（简写为 `:`）绑定的属性进行特殊操作。

- `.sync`：实现 `props` 的双向绑定。它是 `:prop="value" @update:prop="value = $event"` 的语法糖。
  - 注意：子组件触发更新时，事件名必须是 `update:propName` 格式，且 `propName` 必须与 `props` 名称完全一致。
  - 注意：`.sync` 不能和表达式一起使用（例如 `v-bind:title.sync="doc.title + '!'"` 是无效的）。
- `.prop`：强制将绑定作为 DOM property（属性）而不是 HTML attribute（特性）来设置。常用于自定义标签属性，避免暴露数据或污染 HTML 结构。
- `.camel`：将 kebab-case（短横线命名）的属性名转换为 camelCase（驼峰命名）。例如 `v-bind:view-box.camel="viewBox"`。因为在 HTML 模板中 attribute 名称不区分大小写，使用 `.camel` 可以正确绑定 SVG 等需要驼峰命名的属性。
