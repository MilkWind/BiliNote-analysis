## 创建组件文件与目录规范 *Content-[00:01]
- **新建组件文件**：在项目中创建一个新的 Vue 组件文件，建议使用连字符中划线命名，例如 `welcome-card.vue`。
- **目录存放规范**：封装的组件必须放置在 `components` 目录下，这是 Vue 项目的标准规范。
- **实际开发建议**：在真实的企业项目开发中，根据公司的具体要求，通常会在 `components` 目录下再新建一个 `common`（公共）文件夹，专门用于存放全局或公共的组件。

## 编写组件的 Template 结构 *Content-[01:00]
- **基础 HTML 结构**：在 `<template>` 标签中编写组件的视图结构。
- **外层容器**：使用一个 `div` 作为外层容器，并赋予类名，例如 `class="welcome-card"`。
- **内部内容**：
  - 添加一个 `<h2>` 标签，文本内容为“欢迎学习Vue组件封装”。
  - 添加一段文本或 `<p>` 标签，内容为“好好学习，面试必过”。

## 编写组件的 CSS 样式与隔离 *Content-[01:44]
- **样式隔离**：使用 `<style scoped>` 标签编写样式。`scoped` 属性至关重要，它表示样式仅作用于当前组件内部，不会影响外部其他组件，有效避免样式冲突。
- **具体样式设置**（针对 `.welcome-card` 类）：
  - **尺寸**：宽度 `width: 300px`，高度 `height: 200px`。
  - **背景与边框**：背景色设置为浅蓝色 `background: skyblue`，边框设置为红色 `border: 1px solid red`（便于视觉区分）。
  - **圆角与内边距**：圆角 `border-radius: 8px`，内边距 `padding: 20px`。
  - **对齐方式**：外边距 `margin: 0 auto` 实现组件的水平居中；文本对齐 `text-align: center` 实现内部文本的居中显示。

## 编写组件的 JS 逻辑 *Content-[03:04]
- **逻辑规范**：即使当前组件没有复杂的交互逻辑，也需要保持代码结构的完整性。
- **导出组件**：在 `<script>` 标签中使用 `export default` 导出组件对象。
- **组件命名**：为组件指定一个名称，例如设置 `name: 'WelcomeCard'`，这有助于在 Vue Devtools 中进行调试和识别。

## 在页面中引入与使用组件 *Content-[04:22]
- 以 `App.vue`（或 `Home.vue` 页面）为例，演示如何在父组件中使用封装好的子组件。整个过程分为三个标准步骤：
- **第一步：引入组件**。在 `<script>` 标签中使用 `import` 语法引入封装好的组件文件：
  ```javascript
  import WelcomeCard from './components/welcome-card.vue'
  ```
- **第二步：注册组件**。在 `export default` 的 `components` 选项中注册引入的组件：
  ```javascript
  components: {
    WelcomeCard
  }
  ```
- **第三步：使用组件**。在 `<template>` 模板中，通过自定义标签的形式使用组件，例如 `<welcome-card />` 或 `<WelcomeCard />`。

## 组件的复用与封装意义 *Content-[06:27]
- **组件复用演示**：在页面模板中多次编写 `<welcome-card />` 标签，即可轻松渲染出多个相同的欢迎卡片实例，直观展示了组件的复用能力。
- **封装的核心意义**：组件封装的本质是**抽离重复的代码，形成可复用的模块**。
- **开发优势**：后续在其他页面需要使用该功能时，只需引入并注册即可，无需重复编写 HTML、CSS 和 JS 代码，极大地提升了开发效率和代码的可维护性。
- **学习建议**：建议初学者不要直接复制粘贴代码，而是手动在 Vue 项目中敲击一遍并运行。如果遇到报错，尝试自行排查解决或在评论区交流，通过实践加深对组件封装流程的理解。
