## Vue 指令的本质与场景化分类 *Content-[03:36]

### 指令的本质
Vue 指令的本质就是给 HTML 标签添加的特殊命令，主要用来简化 DOM 操作。每个指令都有其明确的操作目的。

### 场景化分类（超市购物模型）
为了便于理解和记忆，不需要死记硬背，可以将 Vue 常用指令按照用途分为四类，并对应“超市购物”的具体场景：

1\. **数据绑定类**
   - **核心用途**：处理数据（Vue 中的 `data`）和页面的关联，将数据显示在页面上或关联表单输入。
   - **超市场景**：显示商品名称、填写购物数量。
2\. **条件循环类**
   - **核心用途**：控制内容的显示与隐藏，或重复渲染列表。
   - **超市场景**：展示或隐藏促销商品、将商品陈列到货架上。
3\. **绑定操作类**
   - **核心用途**：绑定点击、提交等用户交互操作。
   - **超市场景**：点击加入购物车、在收银台结算付款（如自助扫码支付）。
4\. **特殊指令类**
   - **核心用途**：文本渲染、HTML 渲染、控制编译等。
   - **超市场景**：显示商品详细说明、展示促销海报、固定商品价格。

## 数据绑定类指令详解：v-text *Content-[07:17]

### 数据绑定类指令概述
数据绑定类指令主要包括 `v-text`、`v-html`、`v-bind` 和 `v-model`。其核心用途是处理 Vue 实例中 `data` 数据与页面展示的关联，就像超市展示商品信息和记录购物需求一样。

### v-text 指令详解
- **定义**：将 Vue 实例中的数据以**纯文本**的形式渲染到页面标签中。
- **核心特性**：**不会解析 HTML 标签**。即使数据中包含 HTML 标签，也会被当作普通文本原封不动地输出，不会进行格式解析。

#### 代码示例与演示
```javascript
// 实例化 Vue
new Vue({
  el: '#app',
  data: {
    goodsName: '叉叉牌原味牛奶',
    // 描述中包含 <br> 换行标签
    goodsDesc: '蛋白质含量3.2克<br>净含量250ml' 
  }
})
```

```html
<!-- 使用 v-text 渲染数据 -->
<h3 v-text="goodsName"></h3>
<p v-text="goodsDesc"></p>
```

#### 运行结果分析
- `goodsName` 会正常显示为“叉叉牌原味牛奶”（`<h3>` 的样式由 HTML 标签本身决定，与 `v-text` 无关）。
- `goodsDesc` 中的 `<br>` **不会**被解析为换行符。页面会直接输出纯文本内容：“蛋白质含量3.2克<br>净含量250ml”，`<br>` 会被当作普通字符显示，不会发生换行效果。

#### 简写形式
`v-text` 的简写形式是**插值表达式**（Mustache 语法）：`{{ }}`。
```html
<!-- 插值表达式写法，效果与 v-text 类似 -->
<h3>{{ goodsName }}</h3>
```
在实际开发中，插值语法的使用频率更高。需要注意的是，虽然插值表达式和 `v-text` 看起来用法一样，但两者在某些底层细节和表现上存在区别。
