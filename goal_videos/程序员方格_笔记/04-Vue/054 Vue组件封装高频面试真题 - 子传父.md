## 1. 父传子 (props) 易错点回顾 *Content-[00:01]

- **类型校验严格**：`props` 的类型必须写对。例如 `age` 是数字类型，父组件传递时需要注意类型转换。
- **数字类型传递陷阱**：
  - 如果直接写 `age="22"`，Vue 不一定会自动将其转换为数字类型（实践中发现未自动转换）。
  - **正确做法**：加上冒号进行动态绑定，即 `:age="22"`，这样明确告诉 Vue 这是一个数字类型（JavaScript 表达式）。
  - 如果子组件 `props` 定义的是数字类型，而父组件传递的是字符串，控制台会报错。

## 2. 子传父 ($emit) 核心原理 *Content-[01:00]

- **核心方法**：子组件向父组件传递数据或反馈事件，核心使用的是 `$emit`。就像子组件给父组件“打电话”，通知父组件发生了某事。
- **语法结构**：`this.$emit(eventName, data)`
  - **第一个参数**：自定义的事件名。
    - 可以是完全自定义的名称（如 `view-detail`）。
    - 也可以使用 JS 内置的事件名（如 `click`, `mouseover`），但**建议尽量使用自定义名称**，避免与内置事件冲突。
  - **第二个参数**：需要传递给父组件的数据。
    - 可以传递任意类型的数据（如对象、数组等）。
    - 如果没有数据传递，该参数可以省略（就像骚扰电话响一声就挂断，只触发事件不传数据）。
- **父组件监听**：
  - 在父组件中，找到子组件的标签。
  - 通过 `@自定义事件名="处理函数"` 的语法来监听子组件触发的事件。
  - 处理函数中接收子组件传递来的数据，并进行相应的逻辑处理。
- **注意事项**：
  - 子组件 `$emit` 的事件名和父组件监听的事件名**必须完全一致**，否则父组件无法接收。
  - `$emit` 的底层原理是基于 JavaScript 的自定义事件实现的。如果对 JS 自定义事件不熟悉，可能无法深刻理解其底层原理。

## 3. 实战案例：子组件点击查看详情，父组件接收并展示 *Content-[04:18]

**场景需求**：子组件包含一个“查看详情”按钮，点击后，父组件接收事件并展示该用户的详细信息。

### 3.1 子组件改造 (UI 与逻辑)
- **添加按钮与样式**：
  - 在子组件模板中添加 `<button>查看详情</button>`。
  - 编写基础样式：`margin-top: 10px`, `padding: 6px 12px`, `background: skyblue`, `color: white`, `border: none` (去除默认边框), `border-radius: 5px`, `cursor: pointer` (鼠标悬浮变小手)。
- **解决样式布局问题**：
  - 发现按钮样式“飘”了（位置不符合预期），通过将按钮包裹在 `<p>` 标签中，利用 `<p>` 标签的默认块级特性将其顶到下方，完美解决布局问题。
- **绑定点击事件与触发 $emit**：
  - 给按钮绑定 `@click="handleClick"`。
  - 在 `methods` 中定义 `handleClick` 方法：
    ```javascript
    handleClick() {
      // 触发自定义事件 'view-detail'，并传递包含用户信息的对象
      this.$emit('view-detail', {
        name: this.name,
        age: this.age,
        avatar: this.avatar
      });
    }
    ```
  - *注：这里将原本父组件通过 `props` 传过来的 `avatar`、`name`、`age` 再次打包成对象传递给父组件。*

### 3.2 父组件接收与展示
- **监听自定义事件**：
  - 在父组件的子组件标签上绑定事件：`@view-detail="handleView"`。
- **定义数据处理逻辑**：
  - 在 `data` 中定义 `detailData: {}` (用于存储接收到的用户详情对象) 和 `showDetail: false` (用于控制详情区域的显示/隐藏)。
  - 定义 `handleView(obj)` 方法接收数据：
    ```javascript
    handleView(obj) {
      // 将接收到的对象赋值给 detailData
      this.detailData = obj;
      // 将显示状态改为 true，触发视图更新
      this.showDetail = true;
    }
    ```
- **模板渲染**：
  - 在父组件模板中添加详情展示区域，使用 `v-if="showDetail"` 控制显隐。
  - 通过 `detailData` 渲染具体信息：
    ```html
    <div class="detail" v-if="showDetail">
      <h3>用户详情</h3>
      <img :src="detailData.avatar" />
      <p>姓名：{{ detailData.name }}</p>
      <p>年龄：{{ detailData.age }}</p>
    </div>
    ```

### 3.3 调试与排错
- **报错排查**：初次运行点击“张三”时，控制台报错 `obj is not defined` (或类似变量未定义错误)。检查发现是回调函数参数命名或作用域问题，修正后刷新页面。
- **功能验证**：
  - 点击“张三”的查看详情，成功展示张三的详情信息。
  - 点击“张小三”没有反应，原因是**没有做事件的监听**（在 `v-for` 循环渲染多个子组件时，可能漏绑定了 `@view-detail` 事件），补全监听后功能正常。

## 4. 面试总结与核心要点 *Content-[13:10]

- **核心通信方式**：`$emit` 是子组件给父组件传递信息的核心方式。
- **面试必答点**：只要面试官提到“组件通信”或“组件封装”，**必须**回答 `props` (父传子) 和 `$emit` (子传父)。
