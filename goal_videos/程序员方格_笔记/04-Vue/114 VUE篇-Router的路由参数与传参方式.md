## 引言与 Vue Router 传参概述 *Content-[00:01]

在开发 Vue 应用时，经常需要在不同的页面之间传递数据。由于传参方式多种多样且容易混淆，如果选择不当会直接影响开发效率。为了系统掌握这一知识点，本节重点讲解 Vue Router 提供的三种主要传参方式：

1\. **动态路由传参**：通过 URL 路径传递参数。
2\. **Query 查询字符串**：通过 URL 问号后的键值对传递参数。
3\. **Props 传参**：通过组件属性进行传参。

每种方式都有其独特的特点和专属的使用场景，合理选择能够大幅提升代码的优雅度与可维护性。

## 动态路由参数 (Params) *Content-[00:35]

动态路由参数是 Vue Router 中最常用的传参方式之一，主要用于在 URL 路径中直接嵌入参数。

- **路由路径格式**：在定义路由时，使用冒号 `:` 来标识动态参数。例如：`/user/:id`。
- **参数获取方式**：在组件内部，可以通过 `$route.params` 对象来获取传递的参数。例如，获取 `id` 参数的方式为 `$route.params.id`。
- **核心特点**：
  - **URL 美观**：参数直接作为 URL 路径的一部分，结构清晰优雅。
  - **参数必填**：动态路由参数通常被视为必填项，如果缺少该参数，路由匹配将会失败。
- **代码示例与演示**：
  - 在 `UserDetail` 组件的路由配置中，定义 `path: '/user/:id'`。
  - 在页面示例中，当从“用户一”切换到“用户二”时，可以观察到 URL 结构中的 ID 值会随之动态变化（如 `/user/1` 变为 `/user/2`）。

## 查询字符串 (Query) *Content-[01:40]

查询字符串传参方式类似于传统的 GET 请求传参，参数以键值对的形式附加在 URL 的末尾。

- **路由路径格式**：参数跟在问号 `?` 后面，格式如 `/search?keyword=vue`。
- **参数获取方式**：在组件内部，通过 `$route.query` 对象来获取携带的参数。例如，获取 `keyword` 参数的方式为 `$route.query.keyword`。
- **核心特点**：
  - **参数可选**：查询字符串参数不是必填项，即使不传参，路由也能正常匹配。
  - **支持多值**：支持传递多个参数，参数之间用 `&` 连接。
  - **直观可见**：URL 中会明确显示问号及其后面的参数内容。
- **代码示例与演示**：
  - 在搜索页面中，初始 URL 可能为 `/search?keyword=vue`。
  - 当修改搜索关键词（例如将 `vue` 改为 `react`）并更新搜索时，URL 问号后面的参数会实时更新为 `?keyword=react`。这种方式非常适合在 URL 上添加和展示筛选条件。

## 适用场景与实际开发建议 *Content-[03:08]

在实际开发中，针对不同的业务需求，应选择最合适的传参方式。以下是三种方式的具体适用场景及实战建议：

- **动态路由参数 (Params)**：
  - **适用场景**：适合传递**资源标识符**。例如：用户 ID (`userId`)、产品 ID (`productId`)、文章 ID 等具有唯一标识性质的数据。
  - **开发建议**：在进行 URL 传参时，如果参数是资源的核心标识，**优先使用动态路由**。

- **查询字符串 (Query)**：
  - **适用场景**：适合传递**筛选条件**或**状态参数**。例如：搜索关键词 (`keyword`)、分页信息 (`page`, `pageSize`)、排序规则等。
  - **开发建议**：当需要传递非必填的、可选的过滤条件时，**使用查询字符串**。

- **Props 传参**：
  - **适用场景**：适合**复杂逻辑的组件间传参**。当传递的数据结构复杂，或者不希望将数据暴露在 URL 中时，使用 Props 更为合适。
  - **开发建议**：在处理复杂的组件通信或非 URL 相关的状态传递时，**考虑使用 Props**。

## AI 总结 *Content-[04:00]

本节课系统梳理了 Vue Router 的三种核心传参方式及其应用场景。**动态路由参数**通过路径传递，URL 美观且参数必填，适用于资源 ID 标识；**Query 查询字符串**通过问号传递，参数可选且支持多值，适用于搜索和分页等筛选条件；**Props 传参**则适用于复杂组件间的数据传递。在实际前端开发中，遵循“资源标识用动态路由，筛选条件用 Query，复杂组件用 Props”的原则，能够有效提升代码的规范性与开发效率，是应对大厂前端面试和实际项目开发的必备基础技能。
