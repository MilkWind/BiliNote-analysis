## 用途的区别 *Content-[00:11]
从用途的角度来看，`computed` 和 `watch` 在 Vue 中扮演着完全不同的角色：

- **computed（计算属性）**：
  - **核心作用**：用于依赖数据的派生值计算。
  - **应用场景**：
    - **过滤列表**：例如在 To-Do List 中，可以根据不同的状态（如已完成、未完成）衍生出不同的 `computed` 属性来过滤和展示列表。
    - **格式化数据**：对现有数据进行格式化处理，生成用于视图展示的新数据。

- **watch（侦听器）**：
  - **核心作用**：监听相关数据的变化，并在数据变化时执行副作用（Side Effects）。
  - **应用场景**：
    - **异步请求**：当数据变化时发起网络请求。例如，监听用户的 `userId`，当 `userId` 发生变化时，重新向服务端发起请求获取最新的用户信息。
    - **复杂逻辑**：处理一些不直接产生派生值，但需要响应数据变化而执行的复杂业务逻辑。

## 缓存机制的区别 *Content-[01:38]
在缓存机制方面，两者的表现截然不同，这也是决定性能差异的关键：

- **computed（结果缓存）**：
  - **缓存特性**：具有结果缓存机制。
  - **触发条件**：只有当其依赖的数据项发生变化时，才会触发重新计算。
  - **性能优势**：如果依赖项没有发生变化，组件在使用该派生值时，会直接读取缓存的当前值，而不会重新执行计算逻辑，从而有效避免不必要的性能开销。

- **watch（无缓存）**：
  - **缓存特性**：没有缓存机制。
  - **触发条件**：每次被监听的数据发生变化时，都会无条件触发对应的回调函数。

## 异步支持的区别 *Content-[02:38]
针对异步操作的支持，两者也有明确的界限：

- **computed（不支持异步）**：
  - **异步支持**：不支持异步操作。
  - **使用规范**：在 `computed` 中不应进行异步操作，它的职责是纯粹地派生相关状态，必须同步返回计算结果。

- **watch（支持异步）**：
  - **异步支持**：完全支持异步操作。
  - **使用规范**：常用于数据变化后执行异步请求（如 Fetch 数据），并且需要开发者手动处理异步逻辑（如使用 Promise 或 async/await）。

## 语法形式的区别 *Content-[03:25]
在语法形式和配置项上，两者提供了不同的对象属性支持：

- **computed**：
  - **基本形式**：可以使用简写的函数形式，或者完整的对象形式。
  - **对象形式属性**：在对象形式中，主要使用 `get` 和 `set` 方法来分别处理读取和赋值逻辑。

- **watch**：
  - **基本形式**：同样支持函数形式或对象形式。
  - **对象形式属性**：在对象形式中，通过配置特定的属性来控制监听行为，主要包括：
    - `handler`：定义数据变化时执行的具体回调函数。
    - `deep`：布尔值，用于开启深度监听，能够监听对象内部属性的变化。
    - `immediate`：布尔值，用于在侦听器创建时立即执行一次回调函数。

## 代码示例演示 *Content-[04:00]
通过具体的代码示例，可以更直观地理解两者的实际用法：

- **computed 示例（状态派生）**：
  - **场景**：拼接用户全名。
  - **实现**：在 `data` 中定义 `firstName` 和 `lastName`，通过 `computed` 派生出 `fullName`。
  - **逻辑**：`fullName` 的值直接由 `firstName + ' ' + lastName` 计算得出。当 `firstName` 或 `lastName` 改变时，`fullName` 会自动更新并应用缓存机制。

- **watch 示例（数据监听与深度监听）**：
  - **场景**：监听用户 ID 变化并重新获取数据。
  - **实现**：使用对象形式监听 `userId`。
  - **逻辑**：当 `userId` 发生变化时，触发回调函数，传入新的 `userId` 值，并重新执行 `fetch user` 操作以获取最新数据。
  - **深度监听**：如果需要监听一个对象内部属性的变化，可以在 `watch` 配置中使用 `deep: true` 修饰符，开启深度监听模式，确保对象内部任何层级的修改都能被捕获。

## AI 总结 *Content-[05:20]
Vue 中的 `computed` 和 `watch` 虽然都用于响应数据变化，但核心定位截然不同：`computed` 专注于基于依赖的**同步派生计算**，具备**缓存机制**以提升性能，适用于数据过滤和格式化；而 `watch` 则侧重于**监听数据变化并执行副作用**，无缓存机制，**支持异步操作**，适用于发起网络请求或处理复杂逻辑。在语法上，两者均支持函数与对象形式，但对象配置项各有侧重（如 `computed` 的 `get/set` 与 `watch` 的 `handler/deep/immediate`）。在开发中，合理区分并选用二者，是编写高效、可维护 Vue 代码的关键。
