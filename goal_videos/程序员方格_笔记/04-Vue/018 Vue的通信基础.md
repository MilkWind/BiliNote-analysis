## 课程引入与核心问题 *Content-[00:00]
- **组件化开发背景**：在实际项目中，页面几乎不可能由单一组件撑起，而是像搭积木一样，将众多小组件组合成复杂的组件树。
- **核心问题**：这些独立的组件之间如何互相传递信息、协同工作？
- **本节课重点**：聚焦最常用、最核心的三种父子组件通信方式：`props`、`emit` 和 `v-model`。

## 父传子：Props 机制 *Content-[00:38]
- **父组件传递数据**：
  - 使用 `ref` 定义响应式数据（例如 `aMessage`）。
  - 在模板中使用子组件时，通过 `:message="message"` 将数据传递给子组件。
  - `:` 是 `v-bind` 的简写，其作用是告诉 Vue 双引号内的内容是一个需要动态计算的 JS 表达式，而非普通字符串。
- **子组件接收数据**：
  - 在子组件的 `script` 部分，通过 `props` 选项声明需要接收的属性（如 `message`），这相当于一个“收件声明”。
  - 声明后，Vue 会自动将父组件传递的值赋给该 `props`。
  - 在子组件模板中，可直接使用双花括号 `{{ message }}` 将数据显示在页面上。
- **单向数据流原则**：
  - 数据流向是单向的，只能从父组件流向子组件（自上而下）。
  - 子组件不能直接修改父组件传过来的 `props` 值。
  - **设计优势**：确保数据来源清晰，一旦出现数据错误，可以 easily 追溯到源头，对维护复杂应用非常有帮助。

## 子传父：Emit 机制 *Content-[04:21]
- **子组件触发事件**：
  - 当子组件发生特定交互（如用户点击按钮）时，需要通知父组件。
  - 在事件处理函数中调用 `emit` 方法。
  - `emit` 接收两个参数：
    1. 事件名称：自定义事件名（如 `increment`）。
    2. 传递数据（可选）：需要传给父组件的数据（如数字 `1`）。
- **父组件监听事件**：
  - 在父组件使用子组件的地方，使用 `@increment` 监听子组件发出的自定义事件。
  - `@` 是 `v-on` 的简写。
  - 监听到事件后，会触发父组件中的处理函数（如 `handleIncrement`），该函数通过参数（如 `value`）接收子组件 `emit` 出来的数据，从而完成父组件的状态更新。
- **通信方向**：
  - 事件从子组件冒泡到父组件，是一个自下而上的通信过程，与 `props` 的方向正好相反。

## 父子通信要点总结 *Content-[07:02]
- **Props**：
  - 核心作用：实现父向子传递数据。
  - 关键特点：遵循单向数据流，数据如河水般只能从上游流向下游，子组件不应也不能直接修改 `props`。
- **Emit**：
  - 核心作用：子组件向父组件传递消息或数据的标准方式。
  - 工作流程：子组件通过 `emit` 方法触发自定义事件，父组件通过 `v-on`（`@`）监听事件并做出响应。

## 双向绑定：v-model 在自定义组件中的应用 *Content-[07:53]
- **v-model 的本质**：
  - 除了常用于原生表单元素（如 `input`、`textarea`），`v-model` 也可以用在自定义封装的组件上。
  - 它实质上是一个**语法糖**，底层依然依赖 `props` 和 `emit` 在工作。
- **自定义组件实现 v-model 的步骤**：
  1. **接收数据**：子组件通过 `props` 选项接收一个名为 `modelValue` 的属性，并在模板中通过 `:value` 将其绑定到原生 `input` 元素上。
  2. **触发更新**：监听原生 `input` 元素的 `input` 事件，当内容变化时，调用 `emit` 触发更新事件（视频口述为 `input` 事件，Vue3 标准中通常为 `update:modelValue`），并将最新的值（`event.target.value`）作为参数传出。
- **父组件使用体验**：
  - 父组件只需像使用原生 `input` 一样，直接写 `v-model="inputValue"`。
  - 这样即可将父组件的值与子组件的输入状态双向绑定，无需手动编写 `:value` 和 `@input` 等繁琐语法，极大提升了开发便利性。

## 新手避坑指南与最佳实践 *Content-[10:30]
- **严禁直接修改 Props**：
  - 千万不要在子组件中直接修改 `props`。这会破坏 Vue 的单向数据流设计，导致应用数据状态变得混乱且难以追踪。
- **规范声明 Emits 选项**：
  - 强烈建议在子组件的 `emits` 选项中明确声明所有触发的自定义事件（与 `props` 声明类似）。
  - **好处**：
    1. 提高代码可读性和可维护性，让其他开发者一眼看懂组件会触发哪些事件。
    2. 帮助 Vue 更好地进行事件代理和性能优化。

- **课后实践作业**：建议动手构建一个“用户表单组件”，综合运用本节课学到的父子通信知识。
