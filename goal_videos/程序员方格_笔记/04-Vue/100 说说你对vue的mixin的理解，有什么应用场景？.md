## Vue Mixin 的概念与核心作用 *Content-[00:00]
- **面向对象设计中的 Mixin**：在面向对象语言设计中，Mixin 提供了一种方法的实现机制。
- **非继承方式**：与传统的继承（成为子类）不同，Mixin 允许将通用的方法进行抽取并混入到目标类中，而不需要访问或依赖子类的具体功能。
- **核心优势**：
  - 有利于代码的复用。
  - 有效避免了多继承带来的复杂性和潜在问题。

## Vue Mixin 的本质与包含的选项 *Content-[00:45]
- **官方定义**：Vue 中的 Mixin 提供了一种非常灵活的方式，用来分发 Vue 组件中的可复用功能。
- **本质**：本质上是一个普通的 JavaScript 对象。
- **包含的选项**：可以包含 Vue 组件中任意功能的选项，例如：
  - `data`
  - `components`
  - `methods`
  - 生命周期钩子（如 `created`）
  - `computed`
- **合并机制**：当组件使用 Mixin 对象时，Mixin 对象的所有选项将被“混入”到该组件本身的选项当中。如果存在同名选项，Vue 会按照特定的合并策略进行合并。

## Vue Mixin 的使用方式：局部与全局混入 *Content-[02:20]
Vue 中提供了两种使用 Mixin 的方式：局部混入和全局混入。

### 局部混入
- **定义 Mixin 对象**：首先定义一个包含所需选项（如 `created`、`methods` 等）的 JS 对象。例如，在 `created` 钩子中调用 `hello` 方法，并在 `methods` 中定义 `hello` 方法进行打印。
- **在组件中引入**：在组件的配置对象中，通过 `mixins` 数组引入定义好的 Mixin 对象（如 `mixins: [myMixin]`）。
- **执行效果**：组件在创建时，会自动合并 Mixin 中的生命周期钩子。原本组件中没有 `created` 调用 `hello` 的逻辑，通过 Mixin 注入后，组件实例化时就会自动执行该方法并输出对应内容。

### 全局混入
- **使用全局 API**：通过 Vue 提供的全局方法 `Vue.mixin()` 进行注册。
- **传入对象**：将定义好的 Mixin 对象作为参数传入（如 `Vue.mixin({ created: function() { ... } })`）。
- **影响范围**：全局混入会影响之后创建的每一个 Vue 实例和组件，需慎用，通常用于插件开发或全局基础逻辑注入。

## Vue Mixin 的典型应用场景与代码重构示例 *Content-[06:27]
- **核心场景**：在日常开发中，不同的组件经常会遇到相同或相似的代码，且这些代码的功能相对独立。此时可以使用 Mixin 将相同或相似的代码提取出来，实现逻辑复用。
- **具体示例：Modal（模态框）与 Tooltip（提示框）**
  - **痛点**：Modal 和 Tooltip 组件内部都有控制显示/隐藏的状态（如 `isShowing`），以及切换当前状态的方法。两者的逻辑非常相似，导致代码冗余。
  - **重构方案**：
    1. 编写一个名为 `windowMixin`（窗口混入）的对象。
    2. 将共用的 `data`（如 `isShowing` 状态）和 `methods`（如切换状态的方法）提取到该 Mixin 中。
    3. 在 Modal 和 Tooltip 组件中引入并使用该 Mixin（通过 `mixins: [windowMixin]`）。
    4. 删除组件内部原本重复定义的 `data` 和 `methods` 代码。
  - **结果**：组件功能依然保持正常，但代码量大幅减少，逻辑更加清晰，体现了 Mixin 在封装可复用方法时的方便性与实用性。
