## 面试真题盘点 *Content-[01:45]
根据近一年阿里、腾讯、字节、百度、美团、京东、拼多多、网易、快手、滴滴、小红书、携程等 12 家大厂的 Vue 面试真题统计，`v-if` 和 `v-show` 的区别及适用场景出现概率高达 95.7%。这是面试官筛选候选人是否具备实际开发思维的关键题目。

以下是 6 道大厂高频面试真题：
1\. **核心区别**：Vue 中 `v-show` 和 `v-if` 的核心区别是什么？（字节跳动、百度必考题）
2\. **适用场景**：实际开发中，`v-show` 和 `v-if` 分别适用于什么场景？为什么？（阿里、腾讯高频题）
3\. **渲染机制与性能**：`v-show` 和 `v-if` 的渲染机制有什么不同？切换值的性能哪个消耗更大？（美团、京东追问真题）
4\. **连用与混用**：`v-if` 和 `v-else-if`、`v-else` 连用时有什么注意事项？`v-if` 和 `v-show` 能混用吗？
5\. **频繁切换**：当条件频繁切换时，用 `v-show` 还是 `v-if`？为什么？（滴滴、小红书面试真题）
6\. **DOM 状态**：`v-if` 的条件为 `false` 时，元素会被完全移除吗？`v-show` 的条件为 `false` 时，元素还在 DOM 中吗？（快手、携程进阶题）

## 核心逻辑通俗解析 *Content-[02:51]
理解这两个指令的核心逻辑，可以通过“开关灯”和“收纳家电”的日常类比来快速区分。本质都是控制元素的显示或隐藏，但处理方式截然不同。

### 1. v-if：收纳家电（彻底移走）
- **类比**：把家里的电风扇收进储物间。
- **机制**：当条件为 `false` 时，元素会被**彻底从 DOM 中移除**，完全不占用页面空间（就像电风扇收进储物间，客厅看不到也不占地）。当条件为 `true` 时，元素会被重新创建并渲染到 DOM 中（就像夏天到了，把电风扇重新拿出来摆放在客厅）。
- **特点**：有更高的切换开销，因为每次都会触发真实的 DOM 操作（创建/销毁）。

### 2. v-show：开关灯（原地关闭）
- **类比**：关掉客厅的灯。
- **机制**：当条件为 `false` 时，元素**依然存在于 DOM 中**，只是通过 CSS 样式（`display: none`）将其隐藏（就像灯关了不发光，但灯依然吊在天花板上）。当条件为 `true` 时，只是改变 CSS 样式让其显示（就像打开开关，无需把灯拆下来重装）。
- **特点**：有更高的初始渲染开销，因为无论条件真假，元素都会被渲染并保留在 DOM 中，但切换开销极小。

**一句话总结**：
- `v-if` 是彻底移走，东西不在原地。
- `v-show` 是原地关闭，东西还在。

## v-if 代码案例与 DOM 演示 *Content-[08:25]
通过一个控制“夏日家电（电风扇）”显示与隐藏的案例，详细演示 `v-if` 的实际应用及 DOM 结构的变化。

### 1. 基础结构与样式
构建 HTML 结构，包含标题、控制按钮和电风扇展示区，并添加基础 CSS 样式。
```html
<div id="app">
  <h3>我家的夏日家电</h3>
  <button @click="showFan = !showFan">收纳或取出电风扇</button>
  
  <!-- 使用 v-if 控制电风扇的显示 -->
  <div class="fan-app" v-if="showFan">
    三档风速、摇头送风的电风扇
  </div>
</div>

<style>
  .fan-app {
    border: 1px solid gray;
    padding: 10px;
    margin: 10px 0;
    border-radius: 5px;
    width: 200px;
  }
</style>
```

### 2. Vue 实例逻辑
创建 Vue 实例，定义响应式数据 `showFan` 初始值为 `true`（默认取出电风扇）。
```javascript
new Vue({
  el: '#app',
  data: {
    showFan: true // 初始状态：电风扇摆放在客厅
  }
})
```

### 3. DOM 结构变化演示
通过浏览器的开发者工具（F12 -> Elements/审查元素）观察真实 DOM 的变化：
- **初始状态**：`showFan` 为 `true`，页面显示电风扇，DOM 树中可以找到对应的 `div` 元素。
- **点击收纳（切换为 `false`）**：
  - 页面上的电风扇消失。
  - **关键点**：在开发者工具的 DOM 结构中，刚才的电风扇 `div` 元素**完全不见了**，相当于被收纳到了储物间。
- **再次点击取出（切换为 `true`）**：
  - 页面重新显示电风扇。
  - DOM 结构中**重新出现**了电风扇的 `div` 元素，相当于重新摆放到了客厅。

## AI 总结
`v-if` 和 `v-show` 是 Vue 中最常用的条件渲染指令，核心区别在于对 DOM 的处理方式：`v-if` 是真正的条件渲染，条件为假时会彻底销毁和重建 DOM 元素，适用于运行时条件很少改变的场景；`v-show` 则是基于 CSS 的 `display` 属性进行切换，元素始终保留在 DOM 中，适用于需要频繁切换显示状态的场景。在面试中，结合具体的业务场景（如频繁切换用 `v-show`，条件不变用 `v-if`）并理解其底层 DOM 操作差异，是拿下面试官的关键。
