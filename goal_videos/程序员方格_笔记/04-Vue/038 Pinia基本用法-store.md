## Pinia 简介与应用场景 *Content-[00:00]

在日常项目开发中，经常会遇到需要多个组件共享某些数据的场景，例如用户的登录信息。如果让每个组件自己去请求数据，或者通过 `props` 一层一层往下传递，会导致代码非常繁琐且难以维护。此时，我们需要一个专门的地方来存放和管理这些共享状态，这就是所谓的**全局状态**。

- **Pinia 的定位**：Pinia 是 Vue3 官方推荐的状态管理库。
- **核心特点**：API 设计非常简洁，极易上手，能够高效解决全局状态管理的痛点。

## 创建 Store 的核心方法 *Content-[00:50]

创建 Store 是 Pinia 最基础的操作，整个过程非常简洁。

- **导入核心函数**：首先需要从 `pinia` 包中导入 `defineStore` 函数，所有 store 的创建都是由它来完成的。
- **调用 `defineStore`**：调用该函数时需要传递两个核心参数：
  1\. **第一个参数（Store ID）**：
  - 类型为一个字符串（例如 `'counter'`）。
  - 这是该 store 的**唯一 ID**，Pinia 内部依靠此 ID 来标识和管理不同的 store。
  - 命名必须独一无二，通常建议直接使用 store 的名称来命名。
  2\. **第二个参数（配置对象）**：
  - 包含两个非常重要的属性：`state` 和 `actions`。
  - **`state`**：是一个函数，该函数必须返回一个对象。返回的对象即为该 store 需要管理的数据。例如返回 `{ count: 0 }`，意味着定义了一个名为 `count` 的状态，初始值为 0。
  - **`actions`**：是一个对象，用于定义专门修改 `state` 数据的方法。例如定义一个 `increment` 方法，用于将 `count` 的值加 1。在 action 内部，可以通过 `this` 关键字直接访问 `state` 里面的数据（如 `this.count`）。

## 在组件中使用 Store *Content-[02:24]

定义好 store 后，在 Vue 组件中使用它主要分为两步：

- **第一步：导入 Store**
  在组件的脚本标签（如 `<script setup>`）中，将之前创建并导出的 store 函数（例如 `useCounterStore`）通过 `import` 导入进来。
- **第二步：获取实例并使用**
  - 直接调用导入的 `useCounterStore` 函数，它会返回一个 store 的实例。使用一个变量（如 `const store = useCounterStore()`）将其接收。
  - **获取状态**：拿到实例后，可以像操作普通对象一样直接获取数据，例如访问 `store.count`。
  - **调用方法**：直接调用 action 修改数据，例如调用 `store.increment()`。
- **响应式特性**：
  Pinia 中的所有操作都是**响应式**的。当调用 `store.increment()` 导致 `store.count` 的值发生变化时，模板中所有引用 `store.count` 的地方都会自动触发更新，无需手动干预。

## Pinia 核心逻辑与全局共享 *Content-[03:27]

Pinia 能够实现全局状态管理，其核心逻辑在于**实例的唯一性**。

- **全局唯一实例**：无论你在哪个组件中调用 `useCounterStore`，Pinia 都会根据之前定义的 ID（如 `'counter'`），返回**同一个** store 实例。
- **数据全局共享**：这种机制保证了数据在所有组件之间是全局共享的。例如，在 A 组件中调用方法将 `count` 修改为 1，那么在 B 组件中获取到的 `store.count` 值也会立刻变成 1。这就是 Pinia 工作的核心逻辑。

## Pinia 基本工作流程总结 *Content-[04:11]

掌握 Pinia 最核心的用法，其实就是掌握两个关键函数和基本的工作流程：

- **关键函数 1：`defineStore`**
  用于定义 store。通过 `state` 定义需要管理的数据，通过 `actions` 定义修改数据的方法。
- **关键函数 2：`useXxxStore`（如 `useCounterStore`）**
  在组件中调用该函数，即可拿到全局唯一的 store 实例，进而自由访问状态和调用方法。
- **基本工作三步曲**：
  1\. **创建 store**：使用 `defineStore` 定义数据结构与操作方法。
  2\. **获取实例**：在组件中调用 composable 函数获取全局实例。
  3\. **使用状态**：读取 state 数据并触发 actions 修改状态。

只要掌握了上述流程，就可以在项目中使用 Pinia 进行高效的全局状态管理。
