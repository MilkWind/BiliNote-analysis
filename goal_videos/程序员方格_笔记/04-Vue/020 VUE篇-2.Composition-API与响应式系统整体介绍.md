## 1. 为什么需要 Composition API *Content-[00:00]
- **核心特性**：Composition API（组合式 API）是 Vue 3 中非常核心且强大的特性。
- **核心认知**：Composition API 带来的不只是语法的变化，更是组织组件逻辑的一种全新方式。
- **设计初衷**：它的出现不是为了炫技，而是为了实实在在地解决大型复杂组件开发中的实际问题。

## 2. Options API 的痛点：逻辑打散 *Content-[00:44]
- **Options API 的特点**：代码按 `data`、`methods`、`computed` 等选项分门别类。这种方式简单清晰，对于小型、功能单一的组件非常友好。
- **核心痛点**：当组件变得越来越复杂、功能越来越多时，相关逻辑会被打散。为了实现一个完整功能，需要在 `data`、`methods`、`computed`、`watch` 甚至生命周期钩子之间来回跳转。
- **具体案例**：假设开发一个包含“获取验证码倒计时”和“校验用户名”的组件。
  - 在 `data` 中：需要定义倒计时的 `count`，以及表单的 `username` 和 `usernameError`。
  - 在 `methods` 中：需要包含控制倒计时的 `startCountdown` 和校验用户名的 `validateUsername`。
  - 在 `computed` 中：可能有 `isUsernameValid` 的结果判断函数。
- **结果**：倒计时逻辑和用户名校验逻辑像麻花一样拧在一起，被强行拆散分布在不同“篮子”里。修改某一功能需在文件不同地方来回翻找，在大型组件中维护困难。

## 3. Composition API 的优势：逻辑聚合 *Content-[03:44]
- **解决方案**：使用 Composition API 改写后，代码变得非常清爽。
- **逻辑集中**：倒计时相关的 `count` 变量和 `increment` 方法被写在同一个代码块中。表单校验相关的逻辑也可以聚合在另一个代码块中。
- **三大核心优势**：
  1. **逻辑聚合**：相关功能代码内聚在一起，可读性和可维护性大幅提升。
  2. **类型推导更强**：由于代码是函数式编写，其 TypeScript 类型推导能力比 `this` 指向不明确的 Options API 强很多。
  3. **逻辑复用**：可以非常轻松地将一整块逻辑（如倒计时）抽离成一个独立的可复用函数（即“组合式函数”），这是逻辑复用的神器。
- **形象比喻**：
  - **Options API** 像一个大书架，所有的书按小说、历史、科学分类，逻辑分散。
  - **Composition API** 则允许自由组合，比如把《三体》和《物理学史》放在一个书架上，因为它们都与“物理”主题相关，逻辑高度聚合，更加灵活强大。

## 4. Composition API 的核心入口与语法糖 *Content-[06:10]
- **核心入口：`setup` 函数**
  - 在 Vue 2 的 `export default` 中新增的 `setup` 函数。
  - 可以把 `setup` 函数理解成一个“舞台”，所有关于响应式数据、方法、生命周期的表演都会在这个舞台上进行。
  - 在 `setup` 中定义数据（如 `count`），然后通过 `return` 暴露给模板使用。这里写的是组合函数的逻辑本身，而不再是配置项。
- **语法糖：`<script setup>`**
  - 每次写 `export default { setup() {} }` 较为繁琐，Vue 团队提供了 `<script setup>` 语法糖。
  - 使用语法糖后，无需写 `setup` 函数和 `return` 语句。
  - 标签内定义的所有顶层变量和函数都会自动暴露给模板使用。
  - 这是社区最推荐、目前最主流的写法，让编码变得非常简洁优雅。

## 5. 与 React Hooks 的对比 *Content-[07:48]
- **设计思想**：Composition API 的设计思想与 React Hooks 有异曲同工之妙。本质上，Composition API 就是 Vue 版本的 Hooks，核心都是通过函数组合的方式来构建和复用组件逻辑。
- **API 对应关系**：
  - Vue 的 `ref` 类似于 React 的 `useState`（用于创建响应式数据）。
  - Vue 的 `computed` 类似于 React 的 `useMemo`（用于创建计算属性）。
  - Vue 的 `watch` 对应 React 的 `useEffect`（用于监听数据变化并执行副作用）。

## 6. 课程总结与下节预告 *Content-[08:47]
- **核心要点回顾**：
  1. Composition API 是 Vue 3 提供的一种全新逻辑组织方式，旨在解决大型复杂组件中逻辑分散、难以复用的痛点，而非单纯替代 Options API。
  2. 核心入口是 `setup` 函数或更简洁的 `<script setup>` 标签，通过搭配 `ref`、`reactive` 等响应式 API 进行逻辑组合。
  3. 相比 Options API，它更具逻辑聚合性和抽象能力，使代码更加健壮且易于维护。
- **下节预告**：将正式进入核心 API 的世界，详细讲解 `ref`、`reactive`、`computed`、`watch` 等响应式 API 的特点、使用场景、区别与联系。
