## Fragments (多根节点) *Content-[00:34]

- **特性说明**：在 Vue 3 中，组件的 `template` 支持包含多个根节点，打破了 Vue 2 中必须只有一个根节点的限制。
- **代码示例**：
  ```html
  <template>
    <demo-header></demo-header>
    <demo-main></demo-main>
    <demo-footer></demo-footer>
  </template>
  ```
- **核心优势**：使得组件的结构更加扁平化，减少了不必要的包裹 `div`，优化了最终的 DOM 结构，使代码更加语义化。

## Teleport (传送门) *Content-[01:54]

- **特性说明**：`Teleport` 能够将组件的模板内容“传送”到 DOM 中 Vue 应用之外的任意指定位置。可以将其理解为“任意门”，组件不再仅仅局限于挂载到 `#app` 节点下。
- **解决的痛点**：在开发模态框（Modals）、提示框（Toasts）等全局组件时，如果嵌套在 Vue 的某个深层组件内部，处理其 CSS 定位、层级（`z-index`）以及样式覆盖会变得非常困难。
- **解决方案**：使用 `Teleport` 可以将这些组件的逻辑位置或模板代码写在 Vue 应用范围之外（例如直接渲染在 `body` 或指定的 `div` 下），从而轻松解决层级和定位问题。
- **代码示例**：
  ```html
  <template>
    <button @click="showToast">Open Toast</button>
    
    <!-- 使用 Teleport 将内容传送到 id 为 toast-marker 的节点下 -->
    <teleport to="#toast-marker">
      <div class="toast" v-if="visible">
        Hello toast
      </div>
    </teleport>
    
    <!-- 目标挂载节点，可以放在 body 下的任何位置 -->
    <div id="toast-marker"></div>
  </template>
  ```

## createRenderer (自定义渲染器) *Content-[05:13]

- **特性说明**：通过 `createRenderer` API，开发者可以创建自定义渲染器，从而将 Vue 的开发模型和响应式系统扩展到其他非 DOM 平台（例如 Canvas 画布、WebGL 或原生移动端等）。
- **核心实现**：需要引入 `createRenderer`，并传入一系列底层节点操作的自定义实现函数。
- **代码示例**：
  ```javascript
  import { createRenderer } from 'vue'

  const { render, createApp } = createRenderer({
    patchProp,      // 处理属性更新
    insert,         // 插入节点
    remove,         // 移除节点
    createElement   // 创建元素
    // ... 其他底层操作函数
  })

  // 暴露出 render 和 createApp 方法供后续自定义平台使用
  export { render, createApp }
  ```

## Composition API (组合式 API) *Content-[06:51]

- **特性说明**：Composition API 是 Vue 3 的核心特性之一。它允许开发者按照逻辑功能（如状态、计算属性、方法、生命周期等）来组织代码，而不是按照选项（data, methods, mounted 等）来组织。这使得相同功能的代码能够集中式管理，极大地提升了代码的可维护性和复用性。
- **核心用法**：在 `setup` 函数中使用，结合 `ref`、`computed` 以及生命周期钩子进行逻辑编写。
- **代码示例**：
  ```javascript
  import { ref, computed, onMounted } from 'vue'

  export default {
    setup() {
      // 1. 使用 ref 创建基本类型的响应式引用
      const count = ref(0)
      
      // 2. 使用 computed 派生计算属性（响应式状态）
      const double = computed(() => count.value * 2)
      
      // 3. 定义事件处理函数
      const increment = () => {
        count.value++
      }
      
      // 4. 使用组合式生命周期钩子
      onMounted(() => {
        console.log('Component mounted, current count:', count.value)
      })
      
      // 5. 返回需要在模板中消费的内容
      return {
        count,
        double,
        increment
      }
    }
  }
  ```

## AI 总结

本视频详细讲解了 Vue 3 的四个核心新增特性，旨在帮助前端开发者应对大厂面试：
1. **Fragments**：支持多根节点，优化 DOM 结构，减少冗余标签。
2. **Teleport**：提供“传送门”能力，完美解决模态框、弹窗等组件的 DOM 层级和定位痛点。
3. **createRenderer**：开放底层渲染接口，支持将 Vue 扩展至 Canvas 等非 DOM 平台，实现跨平台渲染。
4. **Composition API**：通过 `setup` 函数及 `ref`、`computed` 等 API，实现逻辑代码的集中式管理，大幅提升复杂项目的可维护性与代码复用率。

掌握这些特性及其底层原理，是进阶高级前端工程师、获取互联网大厂 Offer 的关键基础。
