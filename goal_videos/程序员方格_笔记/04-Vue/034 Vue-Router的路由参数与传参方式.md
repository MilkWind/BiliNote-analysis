## Vue-Router 传参方式概述 *Content-[00:00]
在开发 Vue 应用时，经常需要在不同的页面之间传递数据。Vue-Router 提供了多种传参方式，合理选择能显著提高开发效率。
Vue-Router 主要提供以下三种传参方式：
- 动态路由传参 (Dynamic Route Params)
- 查询字符串 (Query String)
- Vue 应用的 props 传参

每种方式都有其独特的特点和使用场景，下面将逐一进行详细拆解。

## 动态路由参数 (Dynamic Route Params) *Content-[00:35]
动态路由参数是将参数直接嵌入到路由路径中，是 Vue-Router 最基础的传参方式之一。

### 1\. 路由配置与格式
- **路径格式**：例如 `/user/:id`，其中 `:id` 是动态参数部分。
- **组件配置**：在 `UserDetail` 等组件中定义 `path` 时，使用冒号 `:` 声明动态参数。

### 2\. 参数获取方式
- 在组件内部，通过 `$route.params` 对象来获取参数。
- **示例**：通过 `$route.params.id` 拿到具体的 `id` 值。

### 3\. 特点与示例
- **URL 美观**：参数直接体现在 URL 路径中，结构优雅。例如，用户 ID 会直接显示在 URL 上（如从 `/user/1` 切换到 `/user/2` 时，URL 中的 id 会随之变化）。
- **必填项**：动态路由参数通常是必填的，如果路径不匹配则无法完成路由跳转。

## 查询字符串 (Query String) *Content-[01:40]
查询字符串传参是将参数附加在 URL 的问号 `?` 后面，常用于传递非核心的状态数据。

### 1\. 路由配置与格式
- **路径格式**：例如 `/search?keyword=vue`。
- 路由路径（如 `/search`）旁边带有问号 `?`，问号后面跟随键值对形式的参数。

### 2\. 参数获取方式
- 在组件内部，通过 `$route.query` 对象来获取参数。
- `$route.query` 对象上携带了所有附加在路由问号后面的参数。

### 3\. 特点与示例
- **可选参数**：参数是非必填的（可选项）。
- **支持多值**：支持传递多个参数值。
- **URL 展示**：URL 会明确显示问号后面的参数内容。
- **示例**：在搜索页面，URL 表现为 `/search?keyword=react`。当修改搜索关键词（如从 vue 改为 react）并点击更新时，URL 问号后的参数会实时变化，非常适合在 URL 上添加筛选条件。

## 传参方式适用场景分析 *Content-[03:08]
在实际开发中，应根据业务需求选择合适的传参方式，以达到最佳的代码结构和用户体验：

- **动态路由参数**：适合用于**资源标识**。例如用户的 `id`、产品的 `id` 等具有唯一标识性质的数据。
- **查询字符串**：适合用于**筛选条件**。例如搜索的关键词、分页信息（page）、排序方式等。

## Props 传参与实际开发建议 *Content-[03:27]
### 1\. Props 传参
- **适用场景**：适合一些**复杂逻辑的组件**，在组件之间进行传参时使用 `props` 会比较多。
- 它主要用于组件级别的数据传递，关注组件内部的逻辑解耦，而不是直接体现在 URL 上。

### 2\. 实际开发建议总结
- **URL 传参**：优先使用**动态路由**来传递核心资源标识。
- **筛选条件**：使用**查询字符串**来传递搜索、分页等可选条件。
- **复杂组件**：对于复杂的组件间数据传递，优先考虑使用 **props**。

## AI 总结 *Content-[04:04]
本视频系统讲解了 Vue-Router 的三种核心传参方式：动态路由参数、查询字符串和 props 传参。动态路由参数将参数嵌入路径，URL 美观且参数必填，适用于资源 ID 标识；查询字符串通过 `?` 拼接参数，支持可选和多值传递，适用于搜索和分页等筛选条件；props 传参则适用于复杂组件间的数据传递。在实际开发中，应根据数据性质（如唯一标识、筛选条件或复杂组件状态）合理选择传参方式，以提升代码的可维护性和 URL 的语义化。
