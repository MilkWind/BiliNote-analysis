## 1. Vue 3 自定义指令概述 *Content-[00:00]
- **核心逻辑未变**：Vue 3 并没有改变自定义指令的核心逻辑，其本质依然是用来做 DOM 操作的，这一点与 Vue 2 完全一致。
- **主要优化点**：
  - 优化了钩子名称和注册方式。
  - 更贴合 Vue 3 中的组合式 API（Composition API）。
  - 学习成本更低，使用方式更接近于原生 JavaScript。

## 2. Vue 3 与 Vue 2 自定义指令钩子名称对比 *Content-[00:47]
- Vue 3 的构造函数和 Vue 2 在自定义指令上的功能完全一致，最大的变化是**钩子名称与组件的生命周期完全对齐**，大大降低了记忆成本。
- **Vue 2 的 5 个钩子**：`bind`、`inserted`、`update`、`componentUpdated`、`unbind`。
- **Vue 3 的钩子名称变更**：
  - `bind` 替换为 `beforeMount`
  - `inserted` 替换为 `mounted`
  - `update` 替换为 `beforeUpdate`
  - `componentUpdated` 替换为 `updated`
  - `unbind` 替换为 `unmounted`

## 3. 自定义指令钩子执行时机详解 *Content-[01:31]
虽然钩子名称发生了改变，但它们的执行时机和核心功能与 Vue 2 保持一致：

- **`beforeMount` (原 `bind`)**：
  - 第一次绑定到元素时执行。
  - **通俗理解**：相当于“做好了这盘菜，但还没有上桌”，即**未插入到 DOM** 中。
- **`mounted` (原 `inserted`)**：
  - 元素插入到 DOM 时执行。
  - **通俗理解**：相当于“做好了这盘菜，已经上桌了”，即**真实插入到了页面**中。
- **`beforeUpdate` (原 `update`)**：
  - 数据发生变化，但页面还没有重新渲染。
- **`updated` (原 `componentUpdated`)**：
  - 输入内容更新，且页面渲染完成。
  - **通俗理解**：加了 `ed` 表示过去时/已完成，意味着数据改变后，页面已经得到了真实的渲染。
- **`unmounted` (原 `unbind`)**：
  - 关闭自定义指令与元素解绑，断开连接。

## 4. Vue 3 自定义指令代码演示与 el 访问 *Content-[02:05]
- **代码结构示例**：
  ```javascript
  new Vue({
    el: '#app',
    directives: {
      color: {
        // 在这里定义 beforeMount, mounted 等钩子函数
      }
    }
  })
  ```
- **使用自定义指令**：在模板中通过 `v-color` 来使用该指令。
- **关于 `el` (DOM 节点) 的访问**：
  - 在 `beforeMount` (原 `bind`) 和 `mounted` (原 `inserted`) 钩子中，都可以访问并打印出 `el`。
  - 从打印结果来看，两者都能访问到对应的 DOM 节点（如 `<p>` 元素），表面上看没有区别。
  - **核心区别**：`beforeMount` 时元素虽然存在但**未插入 DOM 树**，而 `mounted` 时元素**已经真实插入到了页面 DOM 中**。
