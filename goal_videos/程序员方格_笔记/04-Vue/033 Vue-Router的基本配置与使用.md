## 单页应用痛点与路由简介 *Content-[00:08]
- **单页应用（SPA）的痛点**：
  - 页面切换时需要刷新整个页面，导致用户体验非常差。
  - URL 不会随着页面内容的变化而更新。
- **解决方案**：需要引入强大的路由工具来解决上述问题，这正是 **Vue-Router** 的作用所在。

## 路由的核心概念与优势 *Content-[00:29]
- **路由的定义**：简单来说，路由就是 **URL 到组件的映射关系**。
  - 例如：访问 `/home` 显示首页组件，访问 `/about` 显示关于页面组件。
- **路由的优势**：
  - **无需刷新**：无需刷新整个页面，用户体验非常流畅。
  - **URL 同步**：URL 和内容保持同步，方便用户进行分享和收藏。
  - **过渡动画**：能实现丰富的页面过渡动画。
- **Vue-Router**：Vue 官方推荐的路由管理器，能够帮助开发者轻松实现上述路由功能。

## Vue-Router 基础配置详解 *Content-[01:15]
基础配置主要分为三个核心部分：路由配置的格式、路由组件的注册、`router-view` 的使用。

- **路由配置格式**：
  - 定义一个 `routes` 数组。
  - 每个路由对象包含两个核心属性：
    - `path`：URL 的路径。
    - `component`：对应的 Vue 组件。
- **路由实例创建与注册**：
  - 传入 `routes` 配置创建路由实例。
  - 在 Vue 的应用中，使用 `use` 方法（如 `app.use(router)`）将路由实例注册进去。
- **运行效果演示**：
  - 页面顶部为导航链接，点击“关于”时 URL 变为 `/about`，点击“联系我们”时 URL 相应切换。
  - 切换不同页面时 URL 随之变化，但页面整体不会刷新，实现了流畅的单页应用体验。

## 路由的两种跳转方式 *Content-[02:37]
Vue-Router 提供了两种页面跳转方式，在实际开发中都非常常用：

- **声明式导航**：
  - 使用 `<router-link>` 组件。
  - 类似于 HTML 中的 `<a>` 标签，用于在模板中声明导航的结构。
  - 语法简单直观。
- **编程式导航**：
  - 通过 `router.push()` 等 JavaScript 方法实现。
  - 适合在业务逻辑中动态控制页面跳转。
- **使用建议**：根据具体的业务场景选择合适的跳转工具。

## 实际配置的关键注意事项 *Content-[03:27]
在实际项目配置中，需确保以下几个关键点以避免常见错误：

- **正确注册路由**：必须确保路由已正确注册在 Vue 应用中，严格使用 `use` 方法进行挂载。
- **放置 `router-view`**：确认 `<router-view>` 组件放置在模板中的正确位置，它是路由匹配后组件渲染的唯一出口。
- **检查配置完整性**：确保 `routes` 数组和 `createRouter` 创建的实例配置完整无误。按照这些要点进行排查，基本就能保证路由的正常运行。
