## Vue 2 与 Vue 3 自定义指令核心差异对比 *Content-[00:00]

在 Vue 的前端面试中，Vue 2 与 Vue 3 自定义指令的核心差异是高频考点。两者的核心逻辑（操作 DOM、封装复用的 DOM 操作）是完全一致的，主要差异体现在以下几个方面：

- **钩子函数名称**：Vue 2 和 Vue 3 都有 5 个核心钩子函数，功能没有变化，但 Vue 3 对钩子函数的名称进行了修改，使其与组件的生命周期钩子名称保持一致。
- **全局注册方式**：
  - **Vue 2**：直接通过 `Vue.directive` 进行全局注册。
  - **Vue 3**：需要先创建 app 实例，然后在 app 实例上使用 `app.directive` 进行注册。
- **局部注册方式**：
  - **Vue 2**：在组件的 `directives` 选项中进行定义。
  - **Vue 3**：既可以使用类似 Vue 2 的 `directives` 选项，也支持在组合式 API 的 `setup` 语法中进行定义（开发中更推荐 `setup` 方式）。
- **语法风格**：Vue 2 属于选项式 API（Options API），而 Vue 3 属于组合式 API（Composition API）。

## 核心知识点速记 *Content-[01:25]

为了应对面试，可以通过以下三句话快速记忆自定义指令的核心要点：

1. **核心作用**：自定义指令是用来操作 DOM 的拓展命令。一旦遇到需要直接操作 DOM 的场景，首先想到的就应该是自定义指令。其核心价值在于**封装和复用** DOM 操作逻辑（例如封装一个 `v-focus` 指令，让多个 input 输入框都能实现自动聚焦的效果）。
2. **Vue 2 关键点**：掌握全局与局部注册方式，以及 5 个核心钩子函数（如 `bind`、`inserted` 等）。
3. **Vue 3 关键点**：重点记忆钩子函数名称的变化、全局注册需要依赖 app 实例，以及局部注册支持 `setup` 语法。

## 自定义指令核心基础定义与用途 *Content-[02:15]

- **核心基础定义**：自定义指令是绑定在 HTML 标签上的特殊命令，由开发者自定义。它的核心用途是**操作 DOM** 以及**封装复用的 DOM 操作逻辑**。
- **核心用途**：用于解决 Vue 内置指令（如 `v-if`、`v-show` 等）无法满足的 DOM 操作需求。例如：页面打开时自动聚焦、限制输入框只能输入数字等。
- **核心逻辑**：通过自定义指令直接操作 DOM 元素，**不改变数据**，仅仅用作**优化交互效果**。常见的交互效果包括选项卡切换、轮播图动画、打开页面自动聚焦等。

## Vue 2 自定义指令详解 *Content-[04:11]

### 钩子函数（5个）
Vue 2 的自定义指令提供了 5 个钩子函数，用于在不同阶段执行逻辑：
- **`bind`**：指令首次绑定到元素时调用，此时元素**未插入 DOM**，一般用于执行初始化操作。
- **`inserted`**：被绑定元素**插入 DOM 后**调用，这是**操作 DOM 的核心**钩子。
- **`update`**：组件数据更新时调用，注意此时**视图尚未渲染完成**。
- **`componentUpdated`**：组件及其子组件**更新完成**（即视图更新完成）后调用。
- **`unbind`**：指令与元素**解绑**时调用，通常用于执行清理操作，如清除定时器、移除事件监听等。

### 注册方式（2种）
- **全局注册**：使用 `Vue.directive`（注意没有 `s`）。注册后，整个应用中的每个组件都可以使用该指令。
- **局部注册**：在组件的 `directives` 选项中定义（注意带 `s`）。注册后，仅在当前组件内可用。

### 参数与修饰符
在钩子函数中，通过核心形参对象 `binding` 来获取指令的参数和修饰符：
- **`binding.arg`**：获取冒号 `:` 右边的参数。
- **`binding.value`**：获取等号 `=` 右边的参数（即指令绑定的值）。
- **`binding.modifiers`**：获取修饰符，即点 `.` 右边的内容（例如 `v-my-directive.abc` 中的 `abc`）。

### 命名注意事项
- 如果自定义指令的名称包含**中划线（连字符）**，在 JS 中定义时必须用引号括起来，或者直接使用**小驼峰命名法**。
- 在 HTML 模板中使用时，统一使用 `v-` 前缀加上指令名称（例如 `v-my-directive`）。

## Vue 3 自定义指令详解 *Content-[10:26]

### 钩子函数变化
Vue 3 的自定义指令在逻辑上依然用于操作 DOM 节点，但钩子函数的名称发生了改变，使其与组件的生命周期钩子对齐。功能作用与 Vue 2 完全一致，5 个钩子分别为：
- **`beforeMount`**（对应 V2 的 `bind`）
- **`mounted`**（对应 V2 的 `inserted`）
- **`beforeUpdate`**（对应 V2 的 `update`）
- **`updated`**（对应 V2 的 `componentUpdated`）
- **`unmounted`**（对应 V2 的 `unbind`）

### 注册方式
- **全局注册**：必须先创建 app 实例，然后使用 `app.directive` 进行定义。
- **局部注册**：
  - **Options API 方式**：与 Vue 2 类似，在 `directives` 选项中配置。
  - **`setup` 语法方式**：在组合式 API 中通过 `setup` 函数定义（**开发中强烈推荐，面试中也是重点**）。

### 核心差异总结
- **钩子函数**：名称改变（最明显的差异）。
- **注册语法**：全局和局部的注册语法均有所不同。
- **语法风格**：从选项式 API 转变为组合式 API。
- **核心逻辑**：完全一致，依然是操作 DOM。

## 自定义指令与 computed、methods 的区别 *Content-[13:59]

在实际开发中，自定义指令、计算属性（`computed`）和方法（`methods`）容易混淆，它们的核心区别如下：

- **自定义指令**：
  - **定位**：专门用来**操作 DOM**。
  - **触发方式**：**自动触发**。只要将指令绑定到元素上，就会自动执行。
  - **适用场景**：适用于 DOM 交互特效（如项目中的各种交互效果）。
- **计算属性（computed）**：
  - **定位**：用来**操作数据**。
  - **触发方式**：依赖 `data` 中数据的变化而**自动触发**。
  - **适用场景**：适用于响应式数据计算。
- **方法（methods）**：
  - **定位**：用来**操作数据和逻辑**。
  - **触发方式**：需要**手动调用**触发。
  - **适用场景**：适用于复杂的业务逻辑和手动触发的事件操作。
