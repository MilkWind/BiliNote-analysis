## 概念引入：全局注册与局部注册 *Content-[00:00]

在 Vue 中，自定义指令的注册方式分为**全局注册**和**局部注册**。这类似于 JavaScript 中的全局变量和局部变量，主要区别在于**规则适用的范围**（即作用域）：
- **全局注册**：指令可以在任何组件或页面中使用。
- **局部注册**：指令仅在当前注册的组件或页面中可用，其他组件无法使用。

## 全局注册自定义指令 *Content-[00:55]

全局注册是指将自定义指令直接挂载到 Vue 实例上，使得整个应用（APP）的任何组件都能使用该指令。

- **语法**：
  使用 `Vue.directive` 方法（注意关键字 `directive` **没有 `s`**）。
  ```javascript
  Vue.directive('指令名', {
      // 钩子函数对象
  })
  ```
- **适用场景**：
  所有页面或组件都需要使用的规则。例如：多个页面都需要 input 框自动获取焦点，建议将其定义为全局自定义指令。
- **钩子函数**：
  全局注册的第二个参数是一个包含钩子函数的对象。Vue 2 中自定义指令共有 **5 个**钩子函数，不需要全部编写，根据实际需求选择即可：
  1. `bind`：只调用一次，指令第一次绑定到元素时调用。
  2. `inserted`：被绑定元素插入父节点时调用。
  3. `update`：所在组件的 VNode 更新时调用。
  4. `componentUpdated`：指令所在组件的 VNode 及其子 VNode 全部更新后调用。
  5. `unbind`：只调用一次，指令与元素解绑时调用。

## 全局注册案例：手机号输入框自动聚焦 *Content-[02:26]

本案例实现一个功能：当页面加载时，手机号输入框自动获取焦点（`v-focus`）。

- **代码实现**：
  ```html
  <!-- HTML 模板 -->
  <input type="text" placeholder="请输入手机号码" v-focus>
  ```
  ```javascript
  // JavaScript 逻辑
  // 1. 注册全局自定义指令
  Vue.directive('focus', {
      inserted(el) {
          // el 代表绑定该指令的 DOM 元素（此处为 input）
          el.focus();
      }
  });

  // 2. 实例化 Vue
  new Vue({
      el: '#app'
  });
  ```
- **钩子函数选择分析**：
  - 不使用 `bind`：因为在 `bind` 阶段元素还未正式插入 DOM，无法执行获取焦点的操作。
  - 不使用 `update` / `componentUpdated`：此处没有涉及数据更新导致的 DOM 更新。
  - 不使用 `unbind`：此处不需要解绑操作。
  - **选择 `inserted`**：此时元素已插入父节点，可以获取到真实的 DOM 并执行 `el.focus()`。

- **⚠️ 重要注意点（CDN 引入方式）**：
  如果不使用 Vue 脚手架，而是通过 CDN 引入 Vue，**自定义指令的代码必须放在 Vue 实例化代码的上方**。如果顺序颠倒（先实例化后注册指令），会导致指令注册失败。在使用脚手架开发时通常不会遇到此问题，但了解此底层逻辑依然重要。

## 局部注册自定义指令 *Content-[06:51]

局部注册意味着该指令仅在定义它的当前组件或页面内有效，其他组件无法使用。

- **语法**：
  在 Vue 实例的 `directives` 选项中进行定义（注意关键字 `directives` **带有 `s`**）。
  ```javascript
  new Vue({
      el: '#app',
      directives: {
          '指令名': {
              // 钩子函数对象
          }
      }
  })
  ```
- **全局与局部的关键字对比**：
  - 全局注册：`Vue.directive`（无 `s`）
  - 局部注册：`directives`（有 `s`）
- **适用场景**：
  只有当前组件或页面才需要使用的特定规则，没有必要暴露给全局，使用局部注册即可。

## 局部注册案例：限制输入框只能输入数字 *Content-[07:56]

本案例实现一个功能：限制输入框只能输入 0-9 的数字，输入字母、符号等非数字字符时会自动过滤消失（`v-only-number`）。

- **代码实现**：
  ```html
  <!-- HTML 模板 -->
  <input type="text" placeholder="请输入手机号码" v-only-number>
  ```
  ```javascript
  // JavaScript 逻辑
  new Vue({
      el: '#app',
      directives: {
          'only-number': {
              bind(el) {
                  // 绑定 input 事件，实时监听输入
                  el.addEventListener('input', function() {
                      // 使用正则表达式替换非数字字符为空
                      el.value = el.value.replace(/[^0-9]/g, '');
                  });
              }
          }
      }
  });
  ```
- **钩子函数选择分析**：
  - 选择 `bind`：因为这里不需要操作真实的 DOM 结构，只需要在指令绑定到元素时，为元素添加一个 `input` 事件监听器即可。
- **正则表达式解析**：
  - `/[^0-9]/g`：匹配所有非 0-9 的字符。
  - `replace(..., '')`：将匹配到的非数字字符全局（`g`）替换为空字符串，从而实现过滤效果。

## AI 总结

本视频详细讲解了 Vue 2 中自定义指令的两种注册方式：**全局注册**与**局部注册**。
1. **全局注册**使用 `Vue.directive`（无 `s`），适用于全项目通用的指令（如自动聚焦 `v-focus`），通过 `inserted` 钩子操作真实 DOM。需注意在 CDN 模式下指令代码需置于 Vue 实例之前。
2. **局部注册**使用 `directives` 选项（有 `s`），作用域仅限当前组件，适用于特定组件的专属逻辑（如限制只能输入数字 `v-only-number`），通过 `bind` 钩子绑定事件监听。
掌握这两种注册方式及 5 个核心钩子函数的适用场景，是应对前端面试和实际开发中 DOM 操作需求的重要基础。
