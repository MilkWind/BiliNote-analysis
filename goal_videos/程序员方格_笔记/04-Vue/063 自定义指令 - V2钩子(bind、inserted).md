## 自定义指令核心逻辑 *Content-[00:00]
- **业务场景类比**：以电商 App 下单为例，自定义指令相当于开发者自己设置的一些表单规则（如用户名、手机号、收货地址的校验规则）。
- **操作对象**：主要操作 DOM 元素，如表单里的输入框（input）和按钮。
- **钩子函数概念**：
  - 钩子函数决定了**规则生效的时间节点**，即“什么时间做什么事”。
  - 类比前端常见事件：如 JS 中的 `onload`（页面及 DOM、CSS 加载完毕后执行）、`scroll`（鼠标滚轮移动时触发）。
  - 类比小程序生命周期：如 `onShow`（小程序显示时执行）、`onHide`（小程序隐藏时执行）。

## 自定义指令的作用与交互效果 *Content-[02:40]
- **核心逻辑总结**：通过自定义规则（指令）来操作表单元素（DOM）。
- **核心原则**：自定义指令**不改变数据本身**，仅用来**优化交互效果**。
  - 交互效果示例：为元素添加红色背景、点击时触发动画特效等。
- **应用场景**：当涉及 DOM 操作、制作动画或特效时，应优先考虑使用自定义指令，因为它是 Vue 中专门规定用来操作 DOM 的机制。
- **面试重点**：Vue2 中的自定义指令是基础版本，用法经典，是前端面试必考的核心知识点。

## Vue2 自定义指令钩子函数概述 *Content-[04:24]
- **钩子函数的地位**：钩子函数是自定义指令的**灵魂**，决定了指令在什么时机执行（例如：一进入页面就生效、用户输入时生效、或关闭页面时生效）。
- **注册方式**：通过 `Vue.directive` 可以注册全局自定义指令（本视频案例采用全局注册方式进行演示）。

## bind 钩子函数详解与案例 *Content-[05:00]
- **代码定义与命名规范**：
  - 使用 `Vue.directive('hook-demo', { bind(el, binding) { ... } })` 定义全局指令。
  - **命名转换**：在 JS 中定义时使用驼峰命名法（如 `hookDemo`），但在 HTML 模板标签上使用时，必须转换为 kebab-case（短横线连字符）写法，即 `v-hook-demo`。
- **`bind` 钩子执行时机**：
  - 打开或进入某个页面时。
  - 规则**第一次绑定到元素**（如输入框或按钮）时。
- **核心特点与限制**：
  - 指令绑定到元素，但**未插入 DOM**。
  - 此时通过 `el` 获取到的虽然是目标元素（如 input），但**不是真实的 DOM 节点**，还没有真正插入到页面结构中。
- **核心用途**：主要用于**初始化操作**（如绑定事件、设置初始样式）。**此时绝对不能操作真实 DOM**，因为获取不到真实的 DOM 节点。

## inserted 钩子函数详解与案例 *Content-[09:00]
- **`inserted` 钩子执行时机**：元素**插入 DOM 后**触发。此钩子的使用场景比 `bind` 更多。
- **核心特点**：此时**可以获取并操作真实的 DOM 节点**。
- **案例演示**：
  - **自动获取焦点**：在 `inserted` 钩子中执行 `el.focus()`，页面刷新后，光标会自动在输入框内闪烁，实现自动获焦。
  - **修改属性**：执行 `el.placeholder = '输入框已聚焦'`，可以成功修改输入框的提示文本。
- **效果验证**：页面刷新后，无需手动点击，输入框自动获取焦点，且 placeholder 文本被成功更新。

## bind 与 inserted 钩子对比总结 *Content-[11:39]
- **DOM 操作测试**：
  - 如果在 `bind` 钩子中尝试执行 `el.focus()`，是**无效的**，因为此时获取不到真实的 DOM 节点。
  - 在 `inserted` 钩子中执行 `el.focus()` 则**完全有效**。
- **核心区分记忆**：
  - **`bind` 钩子**：获取不到真实 DOM，仅用于初始化绑定和事件监听。
  - **`inserted` 钩子**：可以获取到真实 DOM，用于执行具体的 DOM 操作（如聚焦、修改样式、获取尺寸等）。

## AI 总结
本节视频详细讲解了 Vue2 自定义指令的核心逻辑及两个最关键的钩子函数：`bind` 和 `inserted`。自定义指令的核心价值在于**不改变数据本身，仅通过操作 DOM 来优化交互效果**（如动画、特效等）。在面试和实际开发中，必须严格区分 `bind` 和 `inserted` 的执行时机：`bind` 发生在元素未插入 DOM 前，仅适合做初始化配置；而 `inserted` 发生在元素插入 DOM 后，是执行真实 DOM 操作（如 `focus()`、获取 DOM 尺寸等）的正确时机。掌握这两个钩子函数的区别，是应对 Vue 前端面试和编写高质量自定义指令的基础。
