## 封装可复用按钮组件概述 *Content-[00:01]
- **核心目标**：手写封装一个可复用的按钮组件（类似 Element UI 或 Web UI 中的按钮），这是大厂前端面试中高频考查的手写组件实战题。
- **功能需求**：
  - 支持自定义按钮颜色。
  - 支持自定义按钮尺寸。
  - 支持自定义按钮文字。
  - 支持点击事件。
  - 支持禁用状态（disabled）。

## 组件基础结构与样式准备 *Content-[00:29]
- **基础结构搭建**：
  - 新建组件文件 `MyButton.vue`。
  - 编写基础 HTML 结构：`<button class="my-btn">`。
  - **外观控制**：颜色和尺寸等外观属性主要依靠 CSS 控制，因此需要使用**动态 class** 进行绑定。
  - **属性与事件**：
    - 添加 `disabled` 属性以支持禁用状态。
    - 绑定点击事件。
  - **插槽（Slot）**：添加默认插槽并设置默认文本为“默认按钮”。这遵循了组件封装“留口子”的原则，方便父组件自定义传入文本。
- **样式准备**：
  - **固定样式**：按钮的基础样式类（如 `my-btn`）。
  - **主题颜色**：定义了四种颜色类型，包括 `primary`（默认颜色，类似 Element UI 和 Bootstrap 的命名）、`success`（绿色）、`danger`（红色）、`warning`（橙色/粉色）。
  - **尺寸大小**：定义了三种尺寸，包括 `large`（大按钮）、`medium`（中等按钮）、`small`（小按钮）。
  - **状态样式**：包含禁用状态的专属样式。

## 组件引入与基础使用 *Content-[03:13]
- **引入与注册**：在父组件中引入 `MyButton.vue`，并在 `components` 选项中注册为 `my-button`。
- **基础使用（默认状态）**：
  - 直接使用 `<my-button></my-button>` 标签，不传递任何属性和插槽内容。
  - **渲染效果**：页面渲染出默认颜色、默认尺寸的按钮。由于未向插槽传递内容，按钮自动显示插槽内预设的默认文本“默认按钮”。

## 自定义颜色与文字及 Props 校验 *Content-[04:42]
- **自定义文字**：通过插槽直接传入文本内容，例如 `<my-button>成功的按钮</my-button>`，按钮文本即可动态更新。
- **自定义颜色**：
  - 在父组件中通过 `color` 属性传入颜色类型，例如 `color="success"`。
  - **子组件接收 Props**：
    - 定义 `color` prop，类型限制为 `String`。
    - 设置默认值 `default: 'primary'`，若父组件不传值则使用默认颜色。
    - **自定义校验（Validator）**：限制 `color` 的值必须是 `['primary', 'success', 'danger', 'warning']` 数组中的一项。这在概念上非常类似 TypeScript 中的联合类型或枚举类型，若传入其他非法值则校验失败并报错。
- **动态绑定 Class 实现颜色关联**：
  - 仅仅接收 prop 不会自动改变样式，必须将 prop 值与 CSS 类名进行关联。
  - 使用 `:class` 动态绑定，通过模板字符串拼接类名：`` :class="`btn-${color}`" ``。
  - 当传入 `color="success"` 时，动态生成的类名为 `btn-success`，从而应用对应的绿色样式；传入 `danger` 则生成 `btn-danger` 应用红色样式。

## 自定义尺寸及动态 Class 绑定 *Content-[11:41]
- **自定义尺寸**：
  - 在父组件中通过 `size` 属性传入尺寸类型，例如 `size="large"`。
  - **子组件接收 Props**：
    - 定义 `size` prop，类型限制为 `String`。
    - 设置默认值 `default: 'medium'`，若父组件不传值则使用中等尺寸。
    - **自定义校验（Validator）**：限制 `size` 的值必须是 `['large', 'medium', 'small']` 数组中的一项。
- **动态绑定 Class 实现尺寸关联**：
  - 同样使用 `:class` 动态绑定，拼接尺寸类名。
  - 可以在 `:class` 中使用数组或逗号分隔的模板字符串，同时绑定颜色和尺寸类名，例如：`` :class="`btn-${color}, btn-${size}`" ``。
  - 当传入 `size="large"` 时，类名包含 `btn-large`，应用大按钮样式（具体 CSS 参数如：字号 18，左右内边距 12，上下内边距 24）；传入 `small` 则应用小按钮样式。若不传 `size`，则走默认的 `medium` 中等尺寸样式。
