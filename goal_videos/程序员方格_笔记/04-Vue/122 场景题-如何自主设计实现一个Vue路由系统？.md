## 核心设计思路 *Content-[00:00]
针对“如何自主设计实现一个 Vue 路由系统”这一面试题，核心在于考察对 Vue Router 底层原理的深入理解。设计一个完整的路由系统，核心思想包含以下五个关键步骤：

1\. **监听 URL 变化**
- 路由系统的核心是监听浏览器地址栏 URL 的变化，从而触发组件的切换。
- **Hash 模式**：通过监听 `hashchange` 事件来感知 URL 中 hash 值的变化。
- **History 模式**：通过监听 `popstate` 事件来感知浏览器的前进/后退操作。
- **主动修改**：通过调用 `pushState` 或 `replaceState` 主动修改 URL，此时可以直接获取到最新的 `path`。

2\. **路由表与路由匹配**
- 需要维护一份路由配置表（`config` / `routes`），在初始化 Router 实例时传入。
- 路由表中的每一项是一个对象，包含 `path`（路径）和 `component`（对应的组件）。
- 当 URL 发生变化时，遍历路由表，将最新的 URL `path` 与路由表中的 `path` 进行匹配，找到对应的 `component`。

3\. **响应式路由状态**
- 需要一个响应式的状态（如使用 Vue 的 `reactive` 或 `ref`）来存储当前的路由状态（`current` path）。
- 当 URL 变化时，自动更新这个响应式状态，从而驱动视图的自动更新。

4\. **视图渲染 (router-view)**
- 实现一个 `router-view` 组件，作为路由匹配到的组件的渲染出口。
- 将匹配到的最新 `component` 渲染在 `router-view` 区域范围内（通常通过动态组件 `<component :is="...">` 实现）。

5\. **实现导航方法**
- 实现编程式导航方法，如 `push`、`replace` 等，支持通过代码主动进行路由跳转。

## 具体代码实现细节 *Content-[05:19]
理清设计思路后，具体的代码实现步骤如下：

1\. **定义路由配置表**
- 在使用路由时，首先需要提供一份路由表，包含根路径及对应的组件。
- 示例配置：提供 `home` 和 `about` 两个路由，每个路由对象包含 `path` 和 `component`。

2\. **定义 MyRouter 类核心逻辑**
- 创建一个 `MyRouter` 类，接收 `options` 参数。
- 从 `options` 中获取路由表 `routes` 和当前模式 `mode`（Hash 或 History，默认 Hash）。
- 使用 `reactive` 处理当前的路径状态 `current`，使其具备响应式能力。

3\. **获取当前路径与事件监听**
- **获取路径 (`getCurrentPath`)**：
  - 如果是 Hash 模式：通过 `window.location.hash` 获取，并使用正则表达式提取 `#` 后面的路径内容；如果没有则兜底返回 `/`。
  - 如果是 History 模式：直接返回 `window.location.pathname`。
- **初始化事件监听**：
  - Hash 模式：通过 `addEventListener` 监听 `hashchange` 事件，在回调中获取最新 `path` 并赋值给响应式状态 `current`。
  - History 模式：监听 `popstate` 事件，同理在回调中更新 `current` 状态。

4\. **实现编程式导航 (push)**
- 提供 `push` 方法接收最新的 `path`。
- 判断当前模式：
  - Hash 模式：直接修改 `window.location.hash`。
  - History 模式：调用 `history.pushState` 修改当前路径。
- 无论哪种模式，最后都需要更新响应式状态 `current`，以触发视图更新。

5\. **视图组件 (router-view) 渲染逻辑**
- 在 `template` 中，使用动态组件 `<component :is="currentComponent">` 来渲染当前匹配到的组件。
- 在 `setup` 函数中引入 `MyRouter` 实例。
- 使用 `computed` 计算属性，遍历 `router.routes`，根据当前的响应式路径 `current` 找到需要渲染的 `component`。
- 每次路由变化时，`current` 更新，`computed` 重新计算获取最新的 `component`，进而驱动动态组件完成视图渲染。

## AI 总结 *Content-[13:37]
本题通过手写 Vue 路由系统，全面考察了候选人对前端路由核心原理的掌握程度。设计的关键在于**URL 监听**（Hash/History 模式的事件差异）、**状态管理**（利用响应式系统驱动视图）以及**组件渲染**（动态组件匹配）。在实际实现中，需重点处理好路径解析、事件绑定以及编程式导航的兼容性，这是构建现代前端单页应用（SPA）路由基石的核心能力。
