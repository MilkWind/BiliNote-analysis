## 2. 常见实现方案对比 *Content-[00:54]

针对一键切换主题的功能，主要有以下两种常见的实现思路：

- **方案一：切换 CSS 变量（Custom Properties）**
  - **原理**：在 CSS 中定义自定义变量，通过 JS 或修改 CSS 类名/属性来动态切换这些变量的值。
  - **特点**：这是目前的**主流方案**。具有极好的浏览器兼容性，且代码维护非常方便，样式与逻辑解耦较好。
- **方案二：动态加载不同的样式表**
  - **原理**：预先编写好不同主题的 CSS 文件（如 `light.css` 和 `dark.css`），通过 JS 动态创建 `<link>` 标签或修改现有 `<link>` 的 `href` 属性来加载不同的样式表。
  - **特点**：适合主题差异极大、样式文件非常庞大的项目，但会增加网络请求，且维护多套 CSS 文件成本较高。

## 3. 主流方案实现：CSS变量结合JS *Content-[01:54]

采用主流的 CSS 变量结合 JS 的方案，完整的实现步骤如下：

### 3.1 定义主题变量
- 在 CSS 中定义一套基础的主题变量。
- 在根选择器 `:root` 中设置**默认主题**（如浅色模式）的变量值。
  - 例如定义：`--primary-color`（主色调）、`--bg-color`（背景色）、`--text-color`（文本颜色）等。
- 针对不同主题（如 `dark` 暗黑模式），通过属性选择器重写这些变量的值。
  - 例如：`[data-theme="dark"]` 选择器下，将 `--bg-color` 改写为黑色，`--text-color` 改写为白色。

### 3.2 在样式中使用变量
- 定义好变量后，必须在具体的 CSS 样式中使用它们，否则切换变量不会生效。
- 所有需要跟随主题切换的样式属性，都需要使用 `var()` 函数来调用对应的 CSS 变量。
  - 例如 `body` 标签：`background: var(--bg-color);`，`color: var(--text-color);`。
  - 例如按钮组件：`background: var(--primary-color);`。

### 3.3 通过 JS 修改节点属性实现切换
- **核心逻辑**：通过 JS 修改外层容器（通常是 `<html>` 或 `<body>` 节点）的 `data-theme` 自定义属性，从而触发 CSS 中对应属性选择器的样式生效。
- **编写切换函数（如 `toggleTheme`）**：
  1. 获取当前节点的 `data-theme` 属性值。
  2. 判断当前状态：如果当前是 `dark`，则将其置为空或 `light`；否则将其设置为 `dark`。
  3. 使用 `document.documentElement.setAttribute('data-theme', newTheme)` 更新外层节点的属性。
- **绑定事件**：在页面的切换按钮上绑定点击事件，触发上述切换函数。

## 4. 主题状态的持久化处理 *Content-[07:26]

为了提升用户体验，需要保证用户切换主题后，刷新页面或下次访问时依然保持其选择的主题，而不是恢复为默认主题。

- **实现方式**：使用浏览器的 `localStorage` 来记录用户的主题选择。
- **具体逻辑**：
  - **初始化应用**：在页面加载初始化时，读取 `localStorage` 中保存的 `theme` 值。如果存在该值，则直接调用设置主题的函数，将页面应用到用户上次选择的主题。
  - **同步更新**：在用户点击按钮触发主题切换的 JS 函数中，除了修改 DOM 属性，还要同步将新的主题值写入 `localStorage` 中（如 `localStorage.setItem('theme', newTheme)`）。

## AI 总结

实现网站一键切换主题功能的核心在于**样式与逻辑的解耦**。面试中应优先推荐**CSS 变量（Custom Properties）结合 JS 修改 DOM 属性**的主流方案，该方案兼容性好且易于维护。完整的实现流程包括：在 `:root` 定义默认变量、在特定属性选择器（如 `[data-theme="dark"]`）下覆盖变量、在 CSS 中使用 `var()` 函数引用变量，最后通过 JS 动态修改 `data-theme` 属性触发切换。此外，结合实际业务需求，还需利用 `localStorage` 进行主题状态的持久化，以确保用户体验的连贯性。回答此题时，展现出多方案对比和完整的工程化思考是获取高分的关键。
