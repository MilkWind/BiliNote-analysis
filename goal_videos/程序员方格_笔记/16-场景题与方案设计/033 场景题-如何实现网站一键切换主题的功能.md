## 引言与面试考察重点 *Content-[00:00]
- 网站一键切换主题（如黑白模式切换、换肤等）是前端开发中非常常见且重要的功能，几乎所有现代网站都具备此特性。
- 在面试中，这是一个重点考察的场景题。
- **面试答题策略**：回答此题时，重点在于展示**多种实现思路**，而不是仅仅局限于一两种方案。需要理清各种思路及其各自的特点，以体现技术广度与深度。

## 常见实现思路概述 *Content-[00:54]
实现网站一键切换主题，常见的有以下两种主要思路：
1. **切换 CSS 变量（CSS Custom Properties）**：定义自定义变量，在切换时通过 JS 修改对应的变量值。这是目前的主流方案，兼容性好且维护方便。
2. **动态加载不同的样式表**：通过 JS 动态引入或切换不同的 CSS 样式表文件。

## 主流方案：CSS 变量结合 JS 切换 *Content-[01:54]
主流方案是利用 CSS 变量结合 JS 来实现当前主题的切换。具体实现步骤如下：

### 第一步：定义主题变量
- 在 CSS 中定义一套基础变量，并在根选择器 `:root` 中设置默认主题。
- **定义默认主题变量**：
  ```css
  :root {
    --primary-color: #1890ff; /* 主题色 */
    --bg-color: #ffffff;      /* 背景色 */
    --text-color: #333333;    /* 文本颜色 */
  }
  ```
- **定义暗黑（Dark）模式变量**：
  通过属性选择器（如 `[data-theme="dark"]`）覆盖默认变量，实现暗黑模式下的颜色映射。
  ```css
  [data-theme="dark"] {
    --bg-color: #141414;      /* 暗黑模式背景色 */
    --text-color: #ffffff;    /* 暗黑模式文本变白 */
  }
  ```

### 第二步：在样式中使用变量
- 定义好变量后，必须在具体的样式中使用这些变量，否则切换变量将无法生效。
- 使用 `var()` 函数调用定义的 CSS 变量。
  ```css
  body {
    background: var(--bg-color);
    color: var(--text-color);
  }
  
  .button {
    background: var(--primary-color);
  }
  ```

### 第三步：通过 JS 切换主题
- 通过 JavaScript 修改根节点（如 `document.documentElement`）的 `data-theme` 属性来实现主题切换。
- **编写切换逻辑**：
  ```javascript
  function toggleTheme() {
    // 获取当前的主题属性
    const currentTheme = document.documentElement.getAttribute('data-theme');
    
    // 判断并切换主题
    if (currentTheme === 'dark') {
      document.documentElement.setAttribute('data-theme', ''); // 切回默认/亮色
    } else {
      document.documentElement.setAttribute('data-theme', 'dark'); // 切换为暗黑
    }
  }
  ```
- **绑定按钮事件**：
  为切换主题的按钮绑定点击事件，触发上述 `toggleTheme` 函数。

## 主题状态持久化 *Content-[07:16]
为了提升用户体验，需要实现主题的持久化，确保用户下次访问时能自动应用其之前选择的主题，而不是每次都重置为默认主题。
- **使用 `localStorage` 记录用户选择**：
  - 在切换主题时，同步更新 `localStorage` 中的主题状态。
  - 在页面初始化加载时，读取 `localStorage` 中的值，如果存在则直接应用该主题。
- **实现逻辑**：
  ```javascript
  // 页面加载时初始化主题
  const savedTheme = localStorage.getItem('theme');
  if (savedTheme) {
    document.documentElement.setAttribute('data-theme', savedTheme);
  }

  // 切换主题时保存状态
  function toggleTheme() {
    // ... 执行上述的切换逻辑 ...
    
    // 同步更新 localStorage
    const newTheme = document.documentElement.getAttribute('data-theme');
    localStorage.setItem('theme', newTheme);
  }
  ```

## AI 总结
实现网站一键切换主题的核心在于**状态管理**与**样式映射**。面试时建议以“CSS 变量 + JS 控制根节点属性”为主打方案进行详细阐述，该方案具有低耦合、易维护、高性能的优点。同时，补充“动态加载样式表”作为备选方案以展现技术视野。最后，务必提及使用 `localStorage` 进行状态持久化，这能体现出对用户体验和实际工程落地的全面思考。
