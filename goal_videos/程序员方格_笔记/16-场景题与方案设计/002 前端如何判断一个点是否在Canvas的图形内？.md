## 前端判断点是否在 Canvas 图形内的方法概述 *Content-[00:00]
- **场景说明**：在前端开发中，经常需要判断一个点是否在 Canvas 绘制的图形（如圆形、三角形、矩形等）内部。这是一个典型的面试场景题。
- **面试技巧**：在面试中回答此类问题时，建议尽可能多地列举不同的实现手段（至少 3 种以上）。这能向面试官展示你对 Canvas API 及其底层原理有全面且深入的了解，而不仅仅是停留在基础使用层面。

## 方法一：使用 isPointInPath 检测路径内 *Content-[00:33]
- **API 介绍**：Canvas 提供了 `isPointInPath()` 方法，可以直接检测指定的点是否在当前绘制的路径（Path）内部。
- **代码示例**：
  ```javascript
  // 1. 获取 Canvas 元素及 2D 上下文
  const canvas = document.getElementById('myCanvas');
  const ctx = canvas.getContext('2d');

  // 2. 绘制图形（例如矩形）
  ctx.rect(50, 50, 100, 100); // x: 50, y: 50, width: 100, height: 100

  // 3. 判断点是否在路径内
  const pointX = 60;
  const pointY = 60;
  if (ctx.isPointInPath(pointX, pointY)) {
      console.log('点在矩形路径内部');
  }
  ```

## 方法二：使用 isPointInStroke 检测描边上 *Content-[03:44]
- **API 介绍**：Canvas 提供了 `isPointInStroke()` 方法，用于检测指定的点是否在当前图形的描边（Stroke）路径上。
- **使用场景**：当业务需求只需要判断点是否命中图形的边缘轮廓，而不是填充区域时使用。
- **代码示例**：
  ```javascript
  // 1. 绘制并描边矩形
  ctx.rect(50, 50, 100, 100);
  ctx.stroke(); // 必须进行描边操作

  // 2. 判断点是否在描边路径上
  const pointX = 60;
  const pointY = 60;
  if (ctx.isPointInStroke(pointX, pointY)) {
      console.log('点在矩形描边路径上');
  }
  ```

## 方法三：自定义几何算法检测规则图形 *Content-[05:05]
- **适用场景**：针对一些复杂的图形，或需要脱离 Canvas 上下文进行纯数学计算的场景，可以通过自定义几何算法来实现。
- **矩形检测算法**：
  - **参数提供**：点的坐标 `(x, y)`，矩形的起点坐标 `(rectX, rectY)`，矩形的宽度 `width` 和高度 `height`。
  - **判断逻辑**：点的 X 坐标需在矩形 X 范围内，Y 坐标需在矩形 Y 范围内。
  - **数学公式**：
    $$ x \ge rectX \quad \text{且} \quad x \le rectX + width $$
    $$ y \ge rectY \quad \text{且} \quad y \le rectY + height $$
- **圆形检测算法**：
  - **参数提供**：点的坐标 `(x, y)`，圆心的坐标 `(circleX, circleY)`，圆的半径 `radius`。
  - **判断逻辑**：计算点到圆心的距离的平方，判断其是否小于等于半径的平方。
  - **数学公式**（基于勾股定理）：
    $$ (x - circleX)^2 + (y - circleY)^2 \le radius^2 $$
  - 如果上述等式成立，则说明该点在圆形内部。

## 方法四：使用像素检测不规则图形 *Content-[08:28]
- **适用场景**：针对不规则图形（如通过贝塞尔曲线绘制的复杂形状、导入的图片等），无法使用简单的几何公式计算时，可以采用像素级检测。
- **实现原理**：通过获取 Canvas 上指定坐标的像素数据，检查该像素的透明度（Alpha 通道）。如果不透明，则说明该点位于图形内部。
- **代码示例**：
  ```javascript
  // 1. 获取指定坐标的像素数据
  // getImageData(x, y, width, height)
  const imageData = ctx.getImageData(pointX, pointY, 1, 1);
  const data = imageData.data; // 返回包含 RGBA 值的 Uint8ClampedArray

  // 2. 检查 Alpha 通道（透明度）
  // RGBA 数组中，索引 3 代表 Alpha (A) 通道
  const alpha = data[3]; 

  // 3. 判断是否在不规则图形内
  if (alpha !== 0) {
      console.log('点在不规则图形范围内（像素不透明）');
  }
  ```

## AI 总结 *Content-[09:50]
- 在前端面试中，解答“判断点是否在 Canvas 图形内”的场景题时，应展现多维度的解决思路。
- **Canvas API 方案**：直接使用 `isPointInPath()` 判断填充区域，或使用 `isPointInStroke()` 判断描边区域，这是最原生、最简便的方法。
- **数学算法方案**：对于规则图形（如矩形、圆形），可以通过自定义几何算法（边界值判断、勾股定理）进行纯数学计算，性能高且不依赖 Canvas 渲染上下文。
- **像素检测方案**：对于不规则或复杂图形，利用 `getImageData()` 获取像素的 RGBA 数据，通过判断 Alpha 通道是否为 0 来识别命中区域，是处理复杂形状的通用兜底方案。
- 掌握这四种方法并能结合具体业务场景（如性能要求、图形复杂度）给出合理的选型建议，是面试拿高分的关键。
