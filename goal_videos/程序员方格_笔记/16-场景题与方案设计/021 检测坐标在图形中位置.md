## 面试背景与题目解析 *Content-[00:00]

在前端面试中，算法题虽然出现频率不如基础八股文高，但依然会考察一些基础算法以检验候选人对逻辑和代码编写的理解能力。

**核心题目**：前端如何判断一个坐标点是否在 Canvas（画布）绘制的图形内部？
- **考察重点**：
  - 对 Canvas 画布机制的理解。
  - 如何计算和判断图形的边界。
  - 点坐标与图形边界之间的位置关系计算。
  - 算法类代码的编写能力。
- **实际应用场景**：在前端交互中，经常需要获取用户鼠标点击的坐标，并判断该点击区域是否落在了特定的 Canvas 图形上，从而触发相应的交互逻辑。

## 方法一：几何算法（适用于规则图形） *Content-[02:32]

对于规则的几何图形，可以通过数学几何算法直接计算点与图形边界的关系。这种方法计算效率高，适用于有明确坐标、宽度和高度的图形。

### 1\. 矩形/正方形判断
判断点 $(x, y)$ 是否在矩形内部，只需判断该点的坐标是否同时满足 X 轴和 Y 轴的范围条件。

- **已知条件**：
  - 矩形左上角坐标：$(shapeX, shapeY)$
  - 矩形宽度：$width$
  - 矩形高度：$height$
  - 目标点坐标：$(x, y)$
- **判断逻辑**：
  点的 X 坐标必须大于矩形左边界，且小于右边界；Y 坐标必须大于上边界，且小于下边界。
- **数学公式**：
  $$ shapeX < x < shapeX + width $$
  $$ shapeY < y < shapeY + height $$
- **示例**：若矩形起点为 $(10, 10)$，宽高为 $100 \times 50$。点 $(30, 30)$ 满足条件，在图形内；点 $(150, 150)$ 超出范围，在图形外。

### 2\. 圆形判断
判断点 $(x, y)$ 是否在圆形内部，可以通过计算该点到圆心的距离，并与半径进行比较。

- **已知条件**：
  - 圆心坐标：$(cx, cy)$
  - 圆形半径：$r$
  - 目标点坐标：$(x, y)$
- **判断逻辑**：
  利用勾股定理计算点到圆心的距离平方，判断其是否小于或等于半径的平方。
- **数学公式**：
  $$ (x - cx)^2 + (y - cy)^2 \le r^2 $$
- **示例**：若圆心在 $(50, 50)$，半径为 $30$。通过上述公式即可快速判断任意点是否落在圆形面积内。

## 方法二：Canvas 上下文自带方法 *Content-[08:40]

除了纯数学计算，Canvas 的上下文环境（Context）自身也提供了用于路径检测的 API，适用于通过 Canvas 绘制的图形。

- **核心 API**：`isPointInPath(x, y)`
- **实现流程**：
  1. 获取 Canvas 元素及其上下文对象 `ctx`。
  2. 使用 `ctx` 绘制形状（如 `rect`、`arc` 等）。
  3. 调用 `ctx.fill()` 进行填充。
  4. 调用 `ctx.isPointInPath(x, y)`，传入目标点坐标。
  5. 该方法会返回一个布尔值：`true` 表示点在路径内，`false` 表示在路径外。
- **重要局限性**：
  - 该方法**只能判断当前路径（Current Path）**。
  - 如果在绘制过程中调用了 `beginPath()`，或者画布被清空、图形被重新绘制（如动画刷新、尺寸动态变化），之前的路径就会被重置。
  - 此时再调用 `isPointInPath()` 将无法检测到旧路径，仅对最近一次未重置的路径有效。
  - **适用场景**：仅适用于一次性绘制且后续没有调用 `beginPath()` 重置路径的简单场景。

## 方法三：像素检测法（适用于不规则图形） *Content-[12:23]

当面对无法用几何公式计算面积或边界的不规则图形时（例如用户随意绘制的复杂多边形），可以采用像素检测法。该方法适用于任何形状的图形。

- **核心原理**：
  通过读取 Canvas 特定位置的像素数据，判断该位置是否被图形渲染过。
- **实现步骤**：
  1. 在需要检测的目标坐标位置，绘制（或获取）一个极小的矩形区域（例如 $1 \times 1$ 像素）。
  2. 使用 `getImageData()` 获取该微小区域的像素数据。
  3. 提取像素数据中的 **Alpha（透明度）通道值**。
- **判断逻辑**：
  - 如果 Alpha 值 $> 0$，说明该位置有像素被绘制，即目标点在图形内部。
  - 如果 Alpha 值 $= 0$，说明该位置透明，即目标点在图形外部。
- **优势**：无视图形复杂程度，只要图形在 Canvas 上被实际渲染出来，就能精准检测。

## 方法总结 *Content-[14:11]

判断坐标点是否在 Canvas 图形内部，主要有以下三种解决方案，需根据具体业务场景选择：

1\. **几何算法**：通过数学公式计算。适用于规则图形（矩形、圆形等），性能最好，但无法处理不规则图形。
2\. **上下文方法 (`isPointInPath`)**：利用 Canvas 原生 API。适用于规则或不规则图形，但受限于“当前路径”，路径重置后失效。
3\. **像素检测法**：通过读取 Alpha 通道值判断。适用于任何不规则图形，通用性最强，但涉及像素读取，性能开销相对较大。
