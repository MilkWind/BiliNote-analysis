## 方法一：使用 Canvas API isPointInPath *Content-[01:01]
- **核心原理**：通过 Canvas 提供的原生 API `isPointInPath`，直接检测指定的点是否在当前绘制的路径（填充区域）内。这是最标准且简便的 Canvas 内置方法。
- **实现步骤**：
  - 获取 Canvas 元素：使用 `document.getElementById` 获取对应的 Canvas 节点。
  - 获取 2D 上下文：调用 `getContext('2d')` 获取 2D 画布实例。
  - 绘制图形：使用 `rect(x, y, width, height)` 等方法绘制目标图形（如矩形）。
  - 执行检测：调用 `ctx.isPointInPath(x, y)`，传入需要检测的坐标点。
- **代码示例**：
  ```javascript
  const canvas = document.getElementById('myCanvas');
  const ctx = canvas.getContext('2d');
  // 绘制一个矩形路径
  ctx.rect(50, 50, 100, 100);
  // 判断点 (60, 60) 是否在路径内
  if (ctx.isPointInPath(60, 60)) {
      console.log('点在矩形范围内');
  }
  ```

## 方法二：使用 Canvas API isPointInStroke *Content-[03:44]
- **核心原理**：与 `isPointInPath` 类似，但 `isPointInStroke` 专门用于检测点是否在图形的**描边路径**上，而不是填充区域内。
- **实现步骤**：
  - 获取 Canvas 及 2D 上下文。
  - 绘制图形并执行描边操作（调用 `stroke()`）。
  - 调用 `ctx.isPointInStroke(x, y)` 进行判断。
- **应用场景**：适用于需要精确判断鼠标是否悬停在图形边缘（描边）上的交互场景，例如线条的点击事件触发。

## 方法三：自定义几何算法检测 *Content-[05:05]
- **核心原理**：对于一些基础规则图形，可以通过数学几何公式，传入图形和点的坐标参数，自行编写判断逻辑。这种方式不依赖 Canvas 上下文，计算效率高，适合高频碰撞检测。
- **矩形检测算法**：
  - 需要参数：点的坐标 `(x, y)`，矩形的左上角坐标 `(rectX, rectY)`，矩形的宽度 `width` 和高度 `height`。
  - 判断条件：点的 X 坐标在矩形 X 轴范围内，且 Y 坐标在矩形 Y 轴范围内。
  - 数学公式：
    $$ x \ge rectX \land x \le rectX + width $$
    $$ y \ge rectY \land y \le rectY + height $$
- **圆形检测算法**：
  - 需要参数：点的坐标 `(x, y)`，圆心的坐标 `(circleX, circleY)`，圆的半径 `radius`。
  - 判断条件：计算点到圆心的距离的平方，判断其是否小于等于半径的平方。（注：视频中口述为“差值的乘积小于等于圆的面积”，实际数学原理为勾股定理计算距离平方与半径平方比较）。
  - 数学公式：
    $$ (x - circleX)^2 + (y - circleY)^2 \le radius^2 $$

## 方法四：像素级检测（针对不规则图形） *Content-[08:28]
- **核心原理**：对于复杂或不规则的图形（如通过贝塞尔曲线绘制的复杂形状），数学计算过于复杂。此时可以通过读取 Canvas 对应坐标点的像素数据，判断该像素是否透明来进行检测。
- **实现步骤**：
  - 使用 `ctx.getImageData(x, y, 1, 1)` 获取指定坐标点（宽和高均为 1 像素）的像素数据。
  - 解析返回的 `ImageData` 对象中的 `data` 数组，该数组包含 RGBA 四个通道的值。
  - 检查 Alpha 通道（透明度，即数组的第四个值）。如果 Alpha 值不等于 0，说明该点有像素渲染，即点在图形内。
- **代码示例**：
  ```javascript
  // 获取 (x, y) 坐标的像素数据
  const pixelData = ctx.getImageData(x, y, 1, 1).data;
  // pixelData[3] 代表 Alpha (透明度) 通道
  if (pixelData[3] !== 0) {
      console.log('点在不规则图形范围内');
  }
  ```
