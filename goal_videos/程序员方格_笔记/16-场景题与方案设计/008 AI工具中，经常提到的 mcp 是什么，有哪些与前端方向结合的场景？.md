## 引言：AI 与前端开发的结合 *Content-[00:00]

- **AI 发展现状**：当前 AI 发展如火如荼，不仅局限于大模型阶段，还广泛延伸至 AI 应用和 AI 产品层面，各大厂都在 all in AI。
- **前端与 AI 的关联**：前端开发者与 AI 息息相关，不应认为 AI 仅仅是大模型或算法层面的工作。前端同学同样需要学习和掌握 AI 相关知识。
- **面试与简历亮点**：
  - 在面试中，除了扎实的前端基础知识，如果在 AI 方向有了解和实战经验，将成为巨大的加分项。
  - 将传统技术、研发工具接入 AI 进行升级，或借助 AI 能力进行工程化实践，能显著提升简历的含金量。
  - 简历中若体现出“工程化实践”、“AI + 工程化结合”以及“AI 应用产品的迭代”，能向面试官展示候选人乐于接受新知识，并能将 AI 与原有生态链路打通，极大提高面试通过率。
- **核心建议**：求职者一定要把握好 AI 这一赛道，将 AI 能力融入日常开发与面试准备中。

## 什么是 MCP（模型上下文协议） *Content-[02:32]

- **全称与定义**：MCP 全称为 Model Context Protocol（模型上下文协议），是一个开放标准。
- **产生背景**：AI 发展迅速，各大厂各自为政，缺乏统一的通用协议。如果没有通用协议，某个厂商的通用能力只能局限于特定模型或客户端，导致生态割裂。MCP 的出现使得不同厂商、不同 IDE 都可以通过统一的方式调用工具。
- **核心作用**：
  - 允许 AI 模型（如 ChatGPT、Claude 等）安全、结构化地与外部工具、数据源或服务进行通信。
  - 弥补模型训练数据的局限性（模型仅了解训练截止前的历史知识），通过与外部交互获取实时数据并执行具体操作。
  - **工作流程**：模型调用 MCP -> MCP 获取对应数据或执行工具 -> 将信息注入上下文 -> 模型学习理解并输出最终结果。
- **形象比喻**：
  - **AI 模型**：相当于大脑，自身功能强大但受限于历史数据。
  - **MCP**：相当于 USB 接口或应用商店。
  - **MCP 工具**：相当于外设（如计算器、数据库查询工具、智能家居控制工具等）。通过 MCP，模型突破内置工具的限制，完成更复杂的任务。
- **组成部分**：
  1. **MCP 客户端**：通常指 AI 应用本身（如 ChatGPT 桌面版、Claude 等），负责发出请求。
  2. **MCP 服务器**：提供具体功能的独立程序（如专门用于读取文件系统的服务器、执行 SQL 查询的服务器）。
  3. **协议**：定义客户端和服务器之间通信的规则，包括如何发现可用工具、如何调用工具、如何传递参数及返回结果。
- **重要性**：解决了 AI 模型的“孤岛”问题，使 AI 从静态的知识库转变为能够主动与数字世界交互的智能体（Agent）。

## MCP 与前端方向结合的场景 *Content-[08:24]

前端开发者是连接用户与数字世界的关键角色，MCP 为前端带来了巨大的创新空间，主要分为以下两个结合方向：

### 场景一：使用 MCP 增强前端开发流程
- **AI 辅助开发提效**：
  - 使用 Cursor 等 IDE，或配置了 MCP 的 Claude Code 等集成工具，全面提升开发效率。
  - **上下文感知**：通过 MCP 连接文件系统，让 AI 读取项目中的文件结构、代码组织和配置文件，从而给出精准的代码建议和修改方案，避免泛泛而谈。
- **API 集成助手**：
  - 通过 MCP 连接公司内部的 API 文档工具。
  - 在前后端联调时，AI 可查询最新的接口文档，根据接口协议和返回结构，自动生成正确的 API 调用代码，辅助完成联调工作。
- **设计稿转代码**：
  - 通过 MCP 连接 Figma 插件工具。
  - AI 读取 Figma 面板，分析设计稿的布局、颜色、字体，自动生成高质量的 HTML、CSS 代码，甚至 Vue/React 等组件代码。
  - 衍生场景包括：图转代码、设计稿转代码、PRD 转代码、技术方案转代码等。

### 场景二：构建 AI 原生的前端应用
- 这是一个前瞻性的方向，旨在开发集成了 MCP 客户端的前端应用，使应用本身具备强大的 AI 交互能力。
- **智能数据仪表盘**：
  - 传统方式需要编写各种数据源的连接逻辑和固定的图表渲染代码。
  - 通过集成 MCP 客户端，用户可以使用自然语言进行提问（例如：“显示过去一周销量最高的三个产品以及趋势”）。
  - AI 理解意图后，通过 MCP 调用数据查询工具获取数据，再调用数据可视化工具生成合适的图表类型。
  - 前端应用只需负责渲染 MCP 返回的结果，从而将传统的仪表盘改造为灵活、智能化的系统。

## 面试与简历建议 *Content-[14:20]

- **挖掘业务场景**：参考上述 MCP 与前端结合的思路，挖掘公司实际业务中可以通过 AI 进行改造、升级和迭代的场景。
- **沉淀与输出**：将实践过程、所做的具体事情以及最终取得的成果更新到简历中。
- **凸显个人亮点**：通过展示“AI + 前端”的落地能力，凸显个人在新技术栈上的敏锐度与实战能力，从而有效提高面试成功率。

## AI 总结

本次视频主要讲解了前端面试中高频的 AI 场景题——MCP（Model Context Protocol，模型上下文协议）。MCP 作为一个开放标准，解决了 AI 模型与外部工具、数据源通信的“孤岛”问题，使 AI 从静态知识库进化为主动交互的智能体。对于前端开发者而言，MCP 带来了两大核心结合场景：一是利用 MCP 增强日常开发流程（如上下文感知、API 联调、设计稿转代码）；二是构建集成 MCP 客户端的 AI 原生前端应用（如智能数据仪表盘）。建议求职者在实际工作中积极挖掘 AI 改造场景并沉淀至简历中，以此作为面试的核心亮点。
