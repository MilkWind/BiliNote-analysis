## CSS3 新增特性 *Content-[00:06]

CSS3 在前端开发中引入了大量强大的样式和布局属性，面试中常被问及。以下是核心新增特性：

- **圆角与阴影**：
  - `border-radius`：用于设置圆角，支持对四个角分别进行独立设置。
  - `box-shadow`：为元素添加盒子阴影效果。
  - `text-shadow`：为文字添加阴影效果。
- **渐变效果**：
  - `gradient`：实现渐变背景，包括线性渐变 `linear-gradient` 等。
- **2D 与 3D 变形**：
  - `transform`：用于对元素进行 2D 或 3D 变换。
  - `rotate`：实现元素的旋转效果，是 transform 中常用的属性之一。
- **选择器与伪元素**：
  - 新增了大量 CSS3 选择器，使元素定位更加灵活。
  - 增强了伪元素选择器的功能。
- **边框与媒体查询**：
  - `border-image`：使用图像来绘制元素的边框。
  - `@media`：媒体查询，是实现响应式布局的核心技术。
- **现代布局**：
  - Flexbox（弹性盒子）布局。
  - 多列布局（Multi-column layout）等。

## HTML5 新增特性 *Content-[00:55]

HTML5 极大地丰富了 Web 的表现力和功能，重点新增特性包括：

- **拖放 API**：提供 `drag` 及相关事件，轻松实现元素的拖拽功能。
- **语义化标签**：引入 `header`、`nav`、`footer`、`aside`、`section`、`main`、`article` 等标签，使网页结构更加清晰。
- **多媒体支持**：原生支持 `video`（视频）和 `audio`（音频）标签，无需依赖 Flash 等插件。
- **图形与绘图**：支持 `Canvas`（画布）和 `SVG`（可缩放矢量图形）。
- **地理定位**：`Geolocation` API，用于获取用户的地理位置信息。
- **本地与离线存储**：提供 `localStorage` 和 `sessionStorage`，实现前端数据的本地化存储。
- **表单增强**：新增了大量表单控件和验证属性，提升了表单开发效率。
- **多线程与网络通信**：
  - `Web Worker`：允许在后台子线程中运行 JavaScript，避免阻塞主线程。
  - `WebSocket`：实现浏览器与服务器之间的全双工通信。

## 本地存储机制对比 *Content-[01:45]

在面试中，`localStorage`、`sessionStorage` 和 `cookie` 的区别是高频考点：

- **localStorage**：
  - 直接存储在浏览器本地。
  - 属于**永久存储**，只要用户不手动清除，数据就会一直存在。
- **sessionStorage**：
  - 同样存储在浏览器本地。
  - 仅在**一次会话（Session）** 期间有效，关闭浏览器标签页或浏览器后数据即被清除。
- **Cookie**：
  - **工作机制**：每次浏览器向服务器后端发起请求时，都会自动将 Cookie 数据携带并发送给服务器。
  - **存储限制**：存储空间大小有严格限制（通常为 4KB 左右）。
  - **核心区别**：`localStorage` 和 `sessionStorage` 是纯粹的前端存储，不会自动发送给服务器；而 Cookie 主要用于与服务器进行状态交互。

## HTML5 音视频控制与其他 API *Content-[02:30]

- **音视频 DOM 控制**：
  - 在 HTML5 中嵌入 `audio` 和 `video` 标签后，建议通过 JavaScript 获取对应的 DOM 对象。
  - 通过 JS 可以对媒体进行精细化控制，如播放、暂停、快进、快退等操作。
- **文档格式与基础 API**：
  - HTML5 采用了更简洁的文档类型声明（`<!DOCTYPE html>`）。
  - 新增的 API 和 CSS3 选择器内容相对基础，建议自行动手编写代码以实现和巩固。
- **表单属性**：
  - HTML5 新增了许多表单属性和内置验证机制，需结合文档自行查阅掌握。

## HTML5 语义化的理解与优势 *Content-[03:38]

语义化是 HTML5 的核心理念之一，面试中常要求阐述对其的理解：

- **概念理解**：语义化是指使用具有明确含义的 HTML 标签来构建网页，让代码本身就能表达内容的结构。
- **核心优势**：
  - **便于解析**：使浏览器和搜索引擎能够更准确、高效地解析网页内容。
  - **结构清晰**：让网页的文档结构更加清晰明了，提升代码的可读性和可维护性。
  - **利于 SEO 优化**：让搜索引擎的爬虫（蜘蛛）更好地识别和理解网页内容，从而提升网页在搜索引擎结果中的排名。
