## 1. 面试题背景与考察重点 *Content-[00:00]
- **面试题目**：如果要实现一个 Vue3 的弹窗组件，你会如何进行设计？（2025年某公司面试题）
- **考察核心**：重点考察候选人的**设计能力**。设计能力直接决定了后续代码的编写质量和架构合理性。
- **综合能力要求**：现代应用开发要求程序员具备综合能力，包括开发、设计、后端、调试等全栈思维。虽然开发是主项，但懂设计和全局架构是进阶必备。
- **关键考察点**：
  - **组件结构设计**：是否有规范的设计流程？是否合理使用插槽（Slot）？样式是否具备通用性？
  - **组件逻辑设计**：如何控制显示与隐藏？如何设计按钮点击等交互事件？是否为外部调用预留了扩展空间（如留出写代码的地方）？

## 2. 弹窗组件的结构与样式设计 *Content-[02:21]
- **独立封装的必要性**：弹窗在项目中多处使用，必须封装为独立组件。统一样式和文件便于全局维护、修改和调用，避免代码冗余和“按需复制”带来的维护灾难。
- **结构划分**：
  - **外围遮罩层**：用于阻挡底层交互并提供视觉聚焦。
  - **弹窗主体**：承载核心内容的容器。
  - **头部区域**：包含动态标题，通过状态变量（Props）控制。
  - **内容区域（核心）**：**必须使用插槽（Slot）**。允许父组件自定义传入复杂的 HTML 结构或业务组件，而不是仅仅传递纯文本变量。
  - **底部操作区**：包含取消、确定等按钮，用于触发相应的事件。
- **面试加分项**：在回答结构设计时，**必须主动提及“使用插槽来分发内容”**。如果只通过 Props 传递内容字符串，会显得设计被动且无法实现复杂样式。提及插槽是重要的加分项，否则面临扣分。

## 3. 子组件的逻辑设计 *Content-[05:50]
- **属性定义（Props）**：
  - `visible`：控制弹窗的显示与隐藏状态（布尔值）。
  - `title`：弹窗标题。对于变化不大的基础文本内容，可通过 Props 直接传递。
- **事件定义（Emits）**：
  - `update:visible`：用于更新弹窗的可见性状态，支持 Vue3 的 `v-model` 双向绑定。
  - `confirm`：点击确定按钮时触发。
  - `cancel`：点击取消或关闭按钮时触发。
- **逻辑实现流程**：遵循 Vue3 Composition API 的最佳实践，先通过 `defineProps` 和 `defineEmits` 声明属性和事件接口，然后再在 UI 层和交互逻辑中具体实现并触发。先声明要做什么，再具体实现，逻辑非常清晰。

## 4. 父组件的逻辑设计与调用 *Content-[08:09]
- **引入与注册**：在父组件中导入弹窗子组件。
- **状态与回调定义**：
  - 定义控制弹窗显示/隐藏的响应式变量（如 `isVisible`）。
  - 定义确定、取消操作的具体回调函数。
- **UI 层调用规范**：
  - 按照子组件提供的逻辑流程进行配置。
  - 通过 `v-model`（或 `:visible` 结合 `@update:visible`）绑定可见性状态。
  - 绑定 `@confirm` 和 `@cancel` 等自定义事件。
  - 使用插槽语法在标签内部腾出一块地方，填充具体的业务内容。插槽功能强大，比单纯传递变量方便且灵活得多。

## 5. 面试题总结与代码演示 *Content-[09:06]
- **核心考察点总结**：该题看似简单，实则深度考察候选人对独立组件（尤其是父子组件通信与插槽应用）的架构设计能力。有实际项目经验的开发者会自然考虑到组件拆分、插槽复用和事件通信；而缺乏经验者往往只会把代码写死在页面中，缺乏抽象思维。
- **代码效果演示**：
  - 点击页面按钮，触发弹窗显示。
  - 弹窗内部内容通过父组件的插槽进行动态渲染。
  - 点击确定、取消或关闭按钮，正确触发对应的回调函数，并平滑关闭弹窗。
