## 技术栈书写的三大核心原则 *Content-[00:07]
在简历策划中，技术栈部分的书写至关重要。为了提升简历的专业度和竞争力，技术栈的书写需要严格遵循三个核心原则，避免陷入常见的书写误区。

## 技术栈书写原则一：不写基础且非核心的基础 *Content-[00:18]
- **避免罗列基础工具**：像 Git、npm、VS Code 这类基础且非核心的工具，通通不要出现在简历的技术栈中。
- **原因分析**：只要做过哪怕一个项目的前端工程师，肯定都会使用这些工具。如果把它们写在简历上，不仅会拉低你的技术水平，还会给 HR 或面试官留下“没得写、硬凑数”的负面印象。

## 技术栈书写原则二：不堆砌技术，精准设置关键词 *Content-[00:51]
- **精准设置关键词**：你想重点突出什么技术，就要设置更多、更精准的关键词，以提升简历被系统或 HR 搜索到的概率。
- **错误示例**：只写“掌握 Vue 技术栈”。如果用人单位搜索的是 Vue2 或 Vue3，虽然系统能模糊匹配到 Vue，但不是精准匹配，会导致你的简历排序靠后，甚至被翻不到。
- **正确改造**：
  - 改为：“掌握 Vue 技术栈（Vue2, Vue3, Vue Router, Vuex/Pinia, Axios 等 Vue 技术生态）”。
  - 补充核心原理：“Diff 算法、响应式原理、虚拟 DOM、模板编译、路由模式”。
  - **效果**：这样无论 HR 搜索 Vue、Vue2、Vue3、Vuex 还是 Pinia，都能精准搜索到你的简历。
- **注意事项**：关键字尽量多一些，但绝不能影响阅读体验，避免给人刻意堆砌的感觉。
- **反面教材**：“熟练掌握 HTML、HTML5、CSS、CSS3，可以实现页面的 100% 还原及良好的适配”。HTML5 已经包含了 HTML，且自 2014 年发布至今已是前端必会的基础技能，这种描述纯属画蛇添足。

## 技术栈书写原则三：列出核心技术点和成果，客观描述 *Content-[03:02]
- **拒绝单薄与主观**：
  - 错误示例：“熟练掌握 Vue 技术栈、Vue2、Vue3、Vue Router、Vuex、Pinia、Axios”。这种写法显得单薄，给人感觉仅停留在应用层面。
  - 避免使用“精通”、“掌握”、“了解”等主观性描述。每个人对这些词的评价标准不同（例如：有人认为熟知所有 API 就是精通，而专业人士认为能用原生 JS 实现大部分 API 和内置组件才算精通）。主观描述容易在面试中引发尴尬，让人觉得你在说大话。
- **多用事实说话**：主观信息不如客观事实，少写空洞词句，多摆数据、量和结果。
- **正确改造示例**：
  - “使用 Vue 技术栈（Vue2、Vue3、Vue Router、Vuex/Pinia、Axios）完成 APP 及后台管理系统的开发。”
  - “熟知 Diff 算法、响应式原理、虚拟 DOM、模板编译、路由模式原理。”
- **改造目的**：
  1. **突出技术水平**：前半句表明你能使用该技术栈开发具体项目（如 APP 和后台管理系统）；后半句表明你熟知底层原理，做到了“知其然，更知其所以然”。
  2. **运用面试技巧**：为面试中的“链式问法”埋下伏笔，引导面试官顺着简历上的亮点进行提问，让面试技巧发挥到极致。
- **排版建议**：不需要把所有基础知识点（如 HTML5/CSS3 的所有知识点）都列出来，只需列出亮点、核心、高阶的知识点。遵循“一行一个技术点”的原则，保持简历整洁。

## 优秀技术栈案例详细解析 *Content-[05:55]
以下是完善后的技术栈模块逐条解析，展示了如何将上述原则落地：

1\. **HTML5/CSS3/Sass 布局**
- **基础写法**：“使用 HTML5、CSS3、Sass 完成 PC、移动、响应式布局”（缺乏竞争力，人人都会写）。
- **进阶写法**：突出 CSS3 新增特性的业务应用。例如：“使用 CSS3 变量（Custom Properties）实现主题定制功能”；“使用 Sass/Script 提高样式封装性”。

2\. **ES6/TS/jQuery 开发**
- **优秀写法**：“使用 ES5、ES6、TypeScript、jQuery 完成项目开发；使用 ES6 class 面向对象思想封装自己的 jQuery 库（包括选择器、动画、事件绑定、链式调用）”。
- **亮点**：通过展示封装自定义库的实战经验，证明你的 ES6 和面向对象编程水平扎实。

3\. **Vue 技术栈深度**
- **优秀写法**：“使用 Vue 技术栈（Vue2、Vue3、Vue Router、Vuex/Pinia、Axios）完成 APP 及后台管理系统开发；熟知 Diff 算法、响应式原理、虚拟 DOM、模板编译、路由模式原理”。
- **亮点**：前半句展示应用开发能力，后半句展示底层原理掌握程度，用客观描述代替主观形容词，让面试官对你的技术水平有初步且更高的判断。

4\. **UI 组件库封装**
- **优秀写法**：“使用 Element Plus / Ant Design / Vant 快速搭建 UI 界面及进行二次组件封装；不断完善自己的 UI 组件库（附上 GitHub 地址）”。
- **亮点**：展示你不仅会使用第三方 UI 框架，还有意识地沉淀和完善自己的组件库，体现良好的组件封装能力。

5\. **微信小程序开发**
- **优秀写法**：“使用小程序 API 完成微信小程序开发；在项目中解决授权登录、不同设备兼容处理、分包优化加载等常见问题”。
- **亮点**：不仅会调用 API，还能展示解决实际项目痛点和难点的能力。

6\. **uni-app 跨端开发**
- **优秀写法**：“使用 Vue2/Vue3 结合小程序 API，使用 uni-app 完成跨端开发；打包过 iOS、安卓、微信小程序应用”。
- **亮点**：前半段描述使用的技术，后半段透露跨端开发及多端打包的实战经验。

7\. **前端工程化与架构**
- **优秀写法**：“熟练使用 Gulp / Webpack / Vite，从 0 到 1 搭建前端架构”。

8\. **自动化部署与服务器**
- **优秀写法**：“使用 Jenkins 自动化部署项目到 Nginx 服务器，及配置 Nginx 反向代理”。

按照以上方式书写技术栈模块，不仅能让你的简历从众多求职者中脱颖而出，还能为后续的面试技巧（如链式问法）完美埋下伏笔。

## AI 总结
前端简历中的“技术栈”部分是展示个人核心竞争力的第一窗口。书写时应坚决摒弃基础工具凑数，拒绝盲目堆砌技术名词和滥用“精通/掌握”等主观词汇。正确的策略是：**精准设置关键词以提升搜索命中率，采用“技术栈 + 实际项目成果 + 底层原理”的客观描述结构，并重点突出高阶、核心的技术亮点**。通过事实说话，既能展现扎实的工程实践能力，又能体现对底层原理的深入理解，从而为面试中的深度交流打下良好基础。
