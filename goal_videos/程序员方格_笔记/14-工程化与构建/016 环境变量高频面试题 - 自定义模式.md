## 环境变量名称的自定义修改 *Content-[00:00]
- 环境变量文件的默认名称通常是固定的（如 `.env.development`、`.env.production`），但实际上是支持自定义修改的。
- **修改原则**：只需要保证配置文件名与启动命令中指定的 mode 名称保持一致即可。
- **开发环境（Development）修改示例**：
  - 将 `.env.development` 文件重命名为 `.env.dev`。
  - 在 `package.json` 的启动命令中，将 `--mode development` 修改为 `--mode dev`。
  - 重新运行启动命令后，即可成功读取到自定义名称的环境变量。
- **生产环境（Production）修改示例**：
  - 将 `.env.production` 重命名为 `.env.prod`。
  - 将打包命令（如 `build`）中的 `--mode production` 修改为 `--mode prod`（甚至可以直接将命令名改为 `prod`）。
  - 重新打包后，检查生成的 JS 文件，可以搜索到对应的环境变量内容（如项目标题、接口地址），证明修改生效。
  - **注意事项**：自定义模式名（如改为 `prod`）后，打包出来的代码可能不再默认进行压缩（原本 `production` 模式默认会压缩），这是正常现象。

## 公司常见的前端环境划分 *Content-[03:42]
在公司实际开发中，通常会划分以下四种环境，并使用简写命名以方便配置：
1. **开发环境（DEV）**：开发人员日常编写代码和调试使用的环境。
2. **测试环境（TEST）**：供测试人员进行功能、接口和集成测试的环境。
3. **预发环境（PRE）**：预备发布环境，即将发布到正式版前的最后验证环境。
4. **生产环境（PRD / PROD）**：正式上线、面向真实用户的环境。

## 预发环境（PRE）的详细解析 *Content-[04:16]
- **预发环境的定义**：预备发布环境，其核心特点是数据与生产环境完全一致，用于上线前的最终真实场景验证。
- **与测试环境的区别**：
  - 测试环境的数据通常是模拟的或构造的假数据（例如电商平台上商品标价 0.17 元，方便测试人员频繁下单测试）。
  - 预发环境连接的是**真实的数据库和接口**，使用真实数据（例如商品标价为真实的 9999 元），可以真实走通下单购买流程。
- **与生产环境的区别**：
  - 预发环境和生产环境的数据完全一模一样，都是正式数据。
  - 主要区别在于**域名和对外访问权限**：预发环境的域名通常不是最终正式的对外域名（可能仅限内部或特定网络访问），而生产环境使用的是正式对外的域名。

## 新增预发环境（PRE）的配置实战 *Content-[06:08]
- **创建配置文件**：在项目根目录下新建 `.env.pre` 文件。
- **配置环境变量**：
  - 设置环境变量标识（如 `VUE_APP_ENV=pre`）。
  - 配置预发环境的接口地址（如 `VUE_APP_BASE_API=https://pre.xxx.com`）。
  - 设置项目标识（如 `VUE_APP_TITLE=我的Vue项目预发版`）。
- **配置启动命令**：
  - 在 `package.json` 的 `scripts` 中新增 `pre` 命令。
  - 命令内容示例：`vue-cli-service serve --mode pre`（或对应的打包构建命令）。
- **运行与验证**：
  - 执行 `npm run pre` 启动预发环境。
  - 在页面或控制台中检查，确认成功读取到预发环境的专属变量（如“预发版”标识和 PRE 域名）。
- **规范建议**：环境名称使用全称（如 development）还是简写（如 dev），应“入乡随俗”，严格遵循所在公司的具体开发规范要求。

## Vue CLI 与 Vite 环境变量配置差异 *Content-[08:41]
虽然 Vue 3 + Vite 与 Vue CLI 的环境变量配置逻辑完全一致，但在具体细节上存在以下重要区别，面试时需准确区分：
- **变量前缀不同**：
  - Vue CLI：使用 `VUE_APP_` 前缀（如 `VUE_APP_BASE_API`）。
  - Vite：使用 `VITE_` 前缀（如 `VITE_BASE_API`）。
- **读取方式不同**：
  - Vue CLI：在组件中使用 `process.env.VUE_APP_XXX` 读取。
  - Vite：在组件中使用 `import.meta.env.VITE_XXX` 读取。
