## Vite 环境变量核心命名规范 *Content-[00:00]

在面试中，环境变量配置是一个高频易错点。很多候选人因为不熟悉命名规范而被面试官淘汰。需要注意的是，Vite 和 Vue CLI 的环境变量命名规范是有区别的。以下重点讲解 Vite 环境变量的三个核心命名规范（缺一不可）：

1\. **文件名规范**
- 必须以 `.env` 开头，后跟环境标识，固定格式为 `.env.环境标识`。
- 环境标识通常指 `development`（开发环境）、`test`（测试环境）或 `production`（生产环境）。
- **避坑指南**：不能写成 `.env.dev` 等非标准格式。虽然部分项目配置后也能生效，但不符合规范，面试时强烈建议按照标准命名。

2\. **内部变量命名规范**
- 变量名必须以 `VITE_` 开头（如果是 Vue CLI 项目，则以 `VUE_APP_` 开头）。
- 后面跟随自定义名称，**严格大小写敏感**，且必须全部使用大写字母（类似常量命名）。
- **正确示例**：`VITE_APP_BASE_API`（表示接口地址）。
- **错误示例**：
  - `APP_BASE_API`：缺少 `VITE_` 前缀，Vite 无法识别。
  - `VITE_APP_base_api`：包含小写字母，Vite 无法识别，导致环境变量不生效（这是最常见的错误）。

3\. **值格式规范**
- 如果环境变量的值是**字符串**，建议必须使用单引号 `''` 或双引号 `""` 包裹，以避免特殊字符导致配置解析失败。
- 如果环境变量的值是**数字**，则可以直接书写，无需引号包裹。

**正确与错误示范对比：**
- ✅ **正确**：`VITE_APP_BASE_API='http://localhost:8080/api'`（字符串加引号），`VITE_APP_PORT=8080`（数字不加引号）。
- ❌ **错误**：`APP_BASE_API='...'`（无 `VITE_` 前缀），`VITE_APP_base_api='...'`（未全大写），`VITE_APP_BASE_API=http://...`（字符串未加引号）。

## 环境变量配置实战步骤 Vite 与 Vue3 *Content-[04:33]

面试官经常会要求候选人手写或口述环境变量的具体配置步骤。以下以 Vite + Vue3 项目为例，详细拆解实战配置流程：

**第一步：创建项目**
- 使用 Vite 创建一个 Vue3 项目（若已有项目则直接跳过此步）。

**第二步：创建环境变量文件并写入内容**
- 在项目根目录下创建三个环境变量文件，分别对应开发、测试和生产环境，并写入相应的配置：
  - **开发环境 (`.env.development`)**：
    ```env
    VITE_APP_BASE_API='http://localhost:8080/api'
    VITE_APP_ENV='development'
    VITE_APP_PROJECT_NAME='我的VUE项目'
    VITE_APP_VERSION='开发版'
    ```
  - **测试环境 (`.env.test`)**：
    ```env
    VITE_APP_BASE_API='http://test接口地址'
    VITE_APP_ENV='test'
    VITE_APP_PROJECT_NAME='我的VUE项目'
    VITE_APP_VERSION='测试版'
    ```
  - **生产环境 (`.env.production`)**：
    ```env
    VITE_APP_BASE_API='http://www.正式接口地址'
    VITE_APP_ENV='production'
    VITE_APP_PROJECT_NAME='我的VUE项目'
    VITE_APP_VERSION='正式版'
    ```

**第三步：配置 `package.json` 命令实现一键切换**
- 这是实现环境一键切换的关键步骤，如果不配置命令，将无法切换对应环境。
- 在 `package.json` 的 `scripts` 中添加不同环境的启动或打包命令，核心是使用 `--mode` 参数指定模式：
  ```json
  "scripts": {
    "dev": "vite --mode development",
    "test": "vite --mode test",
    "build": "vite build --mode production",
    "preview": "vite preview"
  }
  ```
  - `dev`：启动开发环境。
  - `test`：启动测试环境。
  - `build`：打包生产环境。
  - `preview`：生产环境打包后的本地预览命令（用于在打包前预览生产环境效果）。

**第四步：验证环境变量配置成果**
- **在代码中读取环境变量**：
  - 在组件（如 `src/App.vue`）中，通过 `import.meta.env` 对象来读取环境变量。
  - 示例代码：
    ```javascript
    // 读取项目名称
    const projectName = import.meta.env.VITE_APP_PROJECT_NAME;
    // 读取环境标识
    const env = import.meta.env.VITE_APP_ENV;
    // 读取接口前缀
    const baseAPI = import.meta.env.VITE_APP_BASE_API;
    ```
- **验证开发环境**：
  - 终端执行 `npm run dev` 启动项目，页面应正确渲染开发版信息（如显示 `development` 标识和 `localhost:8080` 接口地址）。
- **验证测试环境**：
  - 终端执行 `npm run test` 启动测试环境。此时**无需修改任何业务代码**，页面会自动加载并渲染测试版信息。
- **验证生产环境**：
  - 终端执行 `npm run build` 进行生产环境打包。
  - 打包完成后进入 `dist` 目录，在生成的 JS 文件中搜索 `production` 关键字以及正式环境的接口前缀，确认环境变量已成功注入且生效。
