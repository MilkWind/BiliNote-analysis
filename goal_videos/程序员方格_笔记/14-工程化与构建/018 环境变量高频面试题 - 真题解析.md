## 第一题：Vite 环境变量的概念与作用 *Content-[00:04]

### 1\. 什么是 Vite 的环境变量？
简单来说，Vite 环境变量就是在 Vite 项目中，为不同的环境提前定义的**可复用配置值**（如接口地址、环境标识等）。这些配置值被统一管理，切换环境时 Vite 会自动匹配对应的环境变量。其核心机制就是**统一配置，自动切换**。

### 2\. 实际开发中为什么要使用环境变量？
在实际开发中，使用环境变量主要有以下四个核心原因：

1\. **提高开发效率**：避免手动修改代码。例如，开发时使用本地接口测试，需要切换为测试的接口前缀；上线时需要使用正式的接口前缀。提前定义好环境变量，切换环境时自动生效，不仅节省时间，还能避免手动改错代码。
2\. **区分环境差异，保障代码稳定性**：不同环境的配置不一样（例如开发环境的接口仅自己访问，生产环境的接口供所有用户使用）。使用环境变量能清晰地区分环境，避免把开发环境的配置误用到生产环境导致项目出错。
3\. **保护敏感信息，提高项目安全性**：实际开发中有些配置是敏感的（如接口的密钥），这些信息不能暴露在代码中，也不能提交到 Git 仓库。使用环境变量单独存放能避免敏感信息泄露。（注：更建议将敏感信息放在后端接口中，安全性更高）。
4\. **方便团队协作，统一配置标准**：团队里的每一个人都使用相同的环境变量配置，不需要每个人手动修改，避免因配置不一致导致代码错误，使协作更加高效。

## 第二题：在 Vite 项目中配置环境变量的步骤 *Content-[02:10]

以最常用的 **Vite3 + Vue** 项目为例，具体的配置步骤如下（步骤清晰，代码可直接运行）：

### 1\. 具体配置步骤
1\. **新建环境变量文件**：通常需要新建 3 个文件（如 `.env.development`、`.env.test`、`.env.production`）。具体数量视实际开发环境而定，例如如果需要预发环境，则需要新建 4 个文件。
2\. **配置 `package.json` 命令**：在 `package.json` 文件中配置不同的启动/打包命令，保障不同的命令对应不同的环境变量文件。
3\. **测试验证**：运行配置好的命令，测试环境变量是否按预期生效。

### 2\. Vite2 与 Vue 的区别补充
在配置和使用环境变量时，需要注意以下两个细节差异：
- **前缀区别**：Vue2（Vue CLI）的环境变量是以 `VUE_APP_` 开头的；而在 Vite 中，环境变量是以 `VITE_` 开头的。
- **使用方式区别**：在 Vue2 中，获取环境变量使用的是 `process.env.XXX`；而在 Vite3 中，使用的是 `import.meta.env.XXX`。

## 第三题：开发与生产环境变量的区别及区分方法 *Content-[03:40]

### 1\. 核心区别
开发环境和生产环境的环境变量核心区别主要体现在以下三个方面：

1\. **使用场景不同**：开发环境的环境变量是程序员在本地电脑上开发调试代码时使用的；生产环境的环境变量是项目上线后，供普通用户使用的配置。
2\. **配置内容不同**：最主要的区别是**接口地址**。开发环境的接口地址通常是本地的（如 `localhost` 前缀），仅自己访问，方便本地调试；生产环境则是正式的接口（正规域名开头），所有用户都能访问，保证服务器的稳定。此外，开发环境可能会有一些调试相关的配置（如 `console.log` 打印），而生产环境不希望看到这些日志，可以针对不同的环境配置不同的插件来处理。
3\. **核心作用不同**：开发环境的核心作用是方便调试代码，修改后立即生效，不用担心影响用户；生产环境的核心作用是保证服务器的稳定与安全，供用户正常使用，不能做随意的修改。

### 2\. 实际开发中如何区分使用？
在实际开发中，区分和使用环境变量主要有以下两点方法：

1\. **通过环境变量文件区分**：创建不同的环境变量文件，例如 `.env.development` 对应开发环境，`.env.production` 对应生产环境，在里面配置不同的内容（如不同的接口地址）。
2\. **通过启动/打包命令区分**：
   - 开发时：一般使用 `npm run dev`（Vue2 一般是 `npm run serve`），启动开发环境，自动使用开发环境的变量。
   - 上线时：一般使用 `npm run build` 打包生产环境的代码，自动使用生产环境的变量，无需手动切换配置。

### 3\. 补充说明：测试环境
测试环境是介于开发和生产之间的。测试人员使用测试环境的变量，测试功能没有问题后，再切换到生产环境，确保上线后不会出现问题。
