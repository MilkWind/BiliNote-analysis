## 面试背景与考察重点 *Content-[00:00]
- **面试题目**：如何从 0 到 1 构建一个 Vue3 项目？
- **考察目的**：
  - **框架掌握度**：考察对主流前端框架（特别是 Vue3）的了解与熟练程度，确认是否具备独立执行项目构建任务的能力。
  - **工程化思维**：很多开发者在日常工作中只负责局部模块或业务功能，项目框架和基础配置由他人搭建。此问题旨在筛选出真正理解框架底层、具备完整项目搭建能力的候选人。
  - **技术栈更新**：Vue 框架发展已久，早期版本为 Vue2。企业要求候选人掌握最新的 Vue3 及其配套的新插件和生态，而非停留在旧版本。

## 项目目录结构设计 *Content-[04:24]
- **脚手架选择**：目前主流且流行的方案是使用 **Vite** 脚手架来创建 Vue3 项目。
- **基础目录扩展**：Vite 生成的初始目录非常基础，需要在此基础上手动添加业务场景和逻辑目录：
  - `router`：路由配置与定义文件目录。
  - `store`：状态管理目录。需创建一个文件夹，并在内部配置 `index.ts` 作为 **Pinia** 的主文件。
  - `styles`：样式目录。用于存放全局样式（global）和局部变化样式，将不同类型的样式分类管理。
  - `utils`：工具函数目录。存放如日期格式化、数据查询等通用方法。
  - `views` / `components`：视图页面与组件目录。存放页面级组件和复用组件。

## 必要插件安装 *Content-[08:13]
- Vue3 生态丰富，许多功能可通过插件快速实现。在构建项目时，需安装以下必要插件：
  - **路由管理**：安装 `vue-router`。
  - **状态管理**：安装 `pinia`。
  - **UI 组件库**：Vue3 需要搭配对应的 UI 库，如 **Element Plus**（Element UI 的 Vue3 版本），或根据团队偏好选择其他 UI 库（如 Ant Design Vue 等），以实现页面视觉效果。
  - **数据请求**：安装网络请求库（如 `axios`）用于处理接口数据交互。
- **面试技巧**：在回答时，清晰地列出这些基础且必要的插件，能够向面试官证明你了解如何搭建完整的项目生态。

## 项目开发配置 *Content-[10:24]
- 安装完插件后，需对 Vite 配置文件（如 `vite.config.ts`）进行配置，以提升开发效率：
  - **路径别名**：配置 `@` 符号指向 `src` 目录。在模块化开发中，组件导入导出频繁，使用别名可避免书写冗长的相对路径。
  - **开发服务器配置**：指定开发端口；配置自动打开浏览器（`open: true`）和热更新/自动刷新功能，减少手动刷新页面的操作。
  - **构建配置**：配置编译后的输出目录；设置是否生成 `source map`（通常建议开启，以便于生产环境的错误调试）。

## 具体代码开发与主入口配置 *Content-[12:22]
- **路由配置（Router）**：
  - 定义路由集合，包含路径（`path`）和对应的组件（`component`）。
  - 通过 `import` 方式导入所需组件。
  - 实例化路由对象并导出，以便在主入口文件中挂载。
- **状态管理配置（Pinia）**：
  - 导入 `defineStore` 方法。
  - 定义 Store（仓库），并指定唯一的名称。
  - 配置 `state`：定义状态变量（如 `count`），分配状态空间。
  - 配置 `actions`：定义修改状态的方法（如增加、减少、查询等动作逻辑）。
- **主入口文件（`main.ts`）**：
  - 导入并创建 Vue 应用实例（`createApp`）。
  - 使用 `use` 方法挂载配置好的 Router 和 Pinia。
  - 调用 `mount` 方法将应用挂载到 DOM 节点，启动整个项目。
