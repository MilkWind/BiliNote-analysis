## HTTP 版本分布 *Content-[00:14]
- HTTP 协议的发展主要经历了以下五个核心版本：
  - HTTP/0.9
  - HTTP/1.0
  - HTTP/1.1
  - HTTP/2.0
  - HTTP/3.0
- 目前市面上最常见、使用最广泛的版本是 **HTTP/1.1** 和 **HTTP/2.0**。

## 当前主流使用的 HTTP 版本 *Content-[00:33]
- **互联网大厂**：目前基本上都已经全面普及并主要使用 **HTTP/2.0**。
- **中小型企业**：可能由于服务器配置、成本或历史遗留等原因，使用 **HTTP/1.1** 的情况依然占据相当一部分市场。

## 查看 HTTP 版本的方法一：浏览器 Network 面板 *Content-[00:53]
通过浏览器的开发者工具（Developer Tools）查看网络请求的 Headers 信息，是最直观的查看方式。
- **操作步骤**：
  1. 打开浏览器的控制台（开发者工具）。
  2. 切换到 **Network**（网络）面板。
  3. 刷新页面，选择任意一个请求，查看其 **Request Headers**（请求头）。
- **判断依据**：
  - 如果请求头呈现特定的伪头部格式（如 `:authority`、`:method`、`:path` 等），则代表该网站使用的是 **HTTP/2.0**。
    - **示例**：飞书（Feishu）网站的请求头格式代表其使用的是 HTTP/2.0。
  - 如果请求头是传统的标准格式（如 `Host`、`GET` 等），则代表使用的是 **HTTP/1.1**。
    - **示例**：hao123 网站的请求头格式代表其使用的是 HTTP/1.1。
- **局限性**：
  - 在某些情况下，由于后台服务器配置的不同，HTTP/1.1 的请求可能不会在 Network 面板中给出明确的 HTTP 版本标识，导致无法直接通过请求头看出具体版本。

## 查看 HTTP 版本的方法二：控制台 API *Content-[02:39]
当第一种方法无法明确显示版本时，可以通过浏览器提供的特定 API 来查询，这种方法更加稳定可靠。
- **操作步骤**：
  1. 在浏览器控制台（Console）中输入以下代码并回车：
     ```javascript
     window.chrome.loadTimes()
     ```
     *(注：视频转录中的 `window.chrome.node times` 为语音识别错误，正确的 Chrome 浏览器 API 为 `window.chrome.loadTimes()`)*
  2. 该代码会返回一个包含页面加载详细信息的对象。
  3. 在返回的对象中找到 **`npn`**（Next Protocol Negotiation，下一协议协商）字段。
- **判断依据**：
  - 如果 `npn` 字段的值为 **`h2`**，则表示当前页面使用的是 **HTTP/2.0**。
    - **示例**：在飞书网站打印该对象，`npn` 返回 `h2`。
  - 如果 `npn` 字段的值为 **`http/1.1`**，则表示当前页面使用的是 **HTTP/1.1**。
    - **示例**：在 hao123 网站打印该对象，`npn` 返回 `http/1.1`。
- **优势**：
  - 相比于 Network 面板，使用 `window.chrome.loadTimes().npn` 的方式获取 HTTP 版本信息更加稳定，能够准确识别并显示 HTTP/1.1 和 HTTP/2.0，不受后台配置隐藏标识的影响。
