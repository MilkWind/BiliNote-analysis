## 1. HTTP 状态码概述 *Content-[00:00]
- 常见的 HTTP 状态码一般分为五大类，分别以 1、2、3、4、5 开头。
- 1 开头的状态码在面试中一般很少被问到。

## 2. 2xx 状态码：请求成功 *Content-[00:11]
- 2 开头的状态码基本上代表请求成功。
- 比较有代表性的状态码是 `200`。

## 3. 3xx 状态码：重定向与缓存 *Content-[00:21]
3 开头的状态码主要包含以下两种常见情况：
- **304**：触发协商缓存。
- **302**：重定向。
  - **应用场景**：当后台希望用户访问某一个地址时，将其跳转到一个新的地址，这就是 302 重定向。

## 4. 4xx 状态码：客户端错误 *Content-[00:41]
4 开头的状态码一般常见的有以下三种：`401`、`403` 和 `404`。

### 401 与 403 的区别（面试高频考点）
- **401**：代表用户完全没有登录，或者登录状态已经过期。
- **403**：代表用户已经登录，但是对于当前访问的模块或功能没有权限。
  - **应用场景**：在某些系统中，部分功能只对特定用户可见（有的用户能看到，有的用户看不到），如果无权限的用户访问该功能，就会返回 403。

### 404 Not Found
- 代表用户访问了一个根本不存在的地址或资源，因此一般会返回 404。

## 5. 5xx 状态码：服务器错误 *Content-[01:40]
- **500**：
  - 在前端项目中，如果发生 500 错误，一般是后端代码出现了 Bug。
  - **处理建议**：前端开发人员无需处理，看到 500 错误直接找后端排查问题即可。

## AI 总结
本次视频主要讲解了 Web 前端面试中常见的 HTTP 状态码。HTTP 状态码分为 1xx 到 5xx 五大类，其中 1xx 较少涉及。2xx 代表请求成功（如 200）；3xx 主要涉及重定向（302）和协商缓存（304）；4xx 为客户端错误，重点考察 401（未登录/过期）与 403（已登录但无权限）的区别，以及 404（资源不存在）；5xx 为服务器错误，如 500 通常由后端 Bug 引起，前端遇到时直接交由后端处理即可。掌握这些状态码的含义及实际应用场景，是应对前端社招面试的基础。
