## 1. 前端页面创建：Login 与 Register *Content-[00:00]*

本节课的核心目标是通过 Node.js 的文件读取模块（FS），结合 HTTP 路由配置，实现不同路径访问不同页面的功能（如登录页、注册页、首页、图标及 404 页面）。

### 1.1 创建登录页面 (`login.html`)
- **基础结构**：使用 `<h1>` 标签显示“我是登录页面”。
- **表单元素**：
  - 使用 `<form>` 标签创建表单（`action` 属性暂时留空）。
  - 使用 `<label>` 标签添加“用户名”和“密码”输入提示。
  - 添加登录按钮（`<button>`）。
- **页面美化**：为了提升表单的视觉效果，使用 `<fieldset>` 标签包裹表单内容，并使用 `<legend>` 标签设置标题为“用户登录”或“登录”。

### 1.2 创建注册页面 (`register.html`)
- **基础结构**：使用 `<h1>` 标签显示“我是注册页面”。
- **表单元素**：
  - 使用 `<form>` 标签创建表单。
  - 包含“用户名”、“密码”（`password1`）和“确认密码”（`password2`）输入框。
  - 添加注册按钮。
- **页面美化**：同样使用 `<fieldset>` 和 `<legend>`（标题为“用户注册”）对表单进行包裹和美化。

## 2. 后端服务器与路由配置 *Content-[03:39]*

前端页面准备完毕后，开始编写后端路由逻辑，新建 `index7.js` 文件。

### 2.1 初始化服务器
- 引入核心模块：使用 `require('http')` 引入 HTTP 模块，引入 `fs` 模块用于文件读取。
- 创建服务器：调用 `http.createServer()`，监听 3000 端口，并在控制台输出“服务器启动成功”。

### 2.2 路由分发逻辑
在请求回调函数中，通过解构获取 `req` (request) 和 `res` (response)，并根据 `req.url` 进行路由判断：
- **首页 (`/`)**：
  - 设置响应状态码为 200。
  - 使用 `fs.readFile` 读取 `index4.html` 文件，并通过 `res.end()` 返回给客户端。
- **网站图标 (`/favicon.ico`)**：
  - 设置响应头 `Content-Type` 为 `image/x-icon`。
  - 读取并返回对应的 `.ico` 图标文件。
- **登录页 (`/login`)**：
  - 使用 `fs.readFile` 读取 `login.html` 并返回。
- **注册页 (`/register`)**：
  - 使用 `fs.readFile` 读取 `register.html` 并返回。（注：视频中口误拼写为 `resister`，实际代码和路径应为 `register`）。
- **404 页面 (默认 `else`)**：
  - 当访问的路径不匹配上述任何条件时，读取并返回 404 错误页面。

## 3. 路由调试与 Bug 修复 *Content-[07:43]*

### 3.1 错误排查
- **现象**：启动服务器并访问首页时，控制台报错 `res is not defined`。
- **原因**：在编写路由逻辑时，不小心将响应对象 `res` 误写成了大写 `RES` 或其他拼写错误，导致变量未定义。
- **修复**：修正代码中的变量名，确保统一使用小写的 `res`。

### 3.2 路由测试
- 修复 Bug 后重启服务器，依次访问以下路径进行测试：
  - `http://localhost:3000/`：成功显示首页。
  - `http://localhost:3000/login`：成功显示登录页面。
  - `http://localhost:3000/register`：成功显示注册页面。
- **注意事项**：URL 路径必须严格匹配，例如多写一个斜杠（如 `//register`）会导致无法匹配路由，从而返回 404 页面。

## 4. 页面跳转与服务器根路径 *Content-[08:48]*

### 4.1 实现页面跳转
- **需求**：在首页 (`index4.html`) 添加链接，允许用户直接跳转到登录和注册页面。
- **实现方式**：在 `index4.html` 中使用 `<a>` 标签，将 `href` 属性设置为 `/login` 和 `/register`。

### 4.2 服务器根路径解析
- **概念**：在服务器环境下，以 `/` 开头的路径表示**服务器根路径**。
- **访问限制**：配置了服务器根路径后，不能直接双击 HTML 文件在本地浏览器打开（本地文件协议 `file://` 无法识别服务器路由）。必须通过启动服务器后的 HTTP 地址（如 `http://localhost:3000`）进行访问，才能正确触发路由跳转。

## AI 总结

本节课详细讲解了如何使用 Node.js 的 `http` 和 `fs` 模块构建一个简单的 Web 服务器，并通过解析 `req.url` 实现基础的路由分发。内容涵盖了前端 `login.html` 和 `register.html` 表单页面的构建与美化，后端多路径（首页、图标、登录、注册、404）的条件判断与文件读取逻辑。同时，课程还演示了实际开发中常见的变量拼写 Bug 排查过程，并深入解释了“服务器根路径”的概念及其在页面 `<a>` 标签跳转中的正确应用，为后续实现复杂的表单数据交互打下了坚实基础。
