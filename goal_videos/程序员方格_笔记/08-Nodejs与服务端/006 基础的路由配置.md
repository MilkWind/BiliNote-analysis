## 1. 回顾与多条数据发送 *Content-[00:00]

- **回顾 `response` 对象基础**：
  - 通过设置响应头部信息（如 `Content-Type`）可以防止中文乱码。
  - 使用 `response.end()` 方法可以结束本次访问并返回指定数据。

- **发送多条数据的需求与误区**：
  - **误区**：尝试多次调用 `response.end()` 来发送多条数据。
  - **错误现象**：控制台报错 `write after end`。
  - **原因解析**：`end()` 的作用是结束**本次访问**（而不是关闭整个服务器）。一旦调用 `end()`，当前请求的响应流即被关闭，无法再进行任何写入操作。

- **正确发送多条数据的方法**：
  - 使用 `response.write()` 方法可以多次向客户端发送数据。
  - **代码示例**：
    ```javascript
    response.write('我是数据一');
    response.write('我是数据二');
    response.write('我是数据三');
    ```
  - **关键注意**：在使用多次 `write()` 后，**必须**在代码结尾调用 `response.end()` 来结束本次访问。`end()` 可以不传递数据，但必须被调用以关闭响应流。

- **页面换行处理**：
  - 直接拼接字符串在浏览器中不会自动换行。
  - 在 HTML 页面中实现换行，需要手动追加 `<br>` 标签（而不是使用 `\r\n`）。

## 2. 路由的概念与核心对象 *Content-[03:14]

- **路由的需求场景**：
  - 实现根据用户访问的不同路径返回不同的资源。例如：访问 `/login` 显示登录页，访问 `/register` 显示注册页，默认访问 `/` 显示首页。

- **路由的核心概念**：
  - **定义**：用对应的路径访问对应的资源。
  - **通俗理解**：类比生活中的路由器，路由器通过分配内网 IP（如 `192.168.x.x`）将一根宽带分配给多台设备，从而定位到具体的电脑或资源。在 Web 开发中，路由就是通过 URL 路径找到并返回对应资源的过程。

- **核心对象解析**：
  - **`request`（请求对象）**：封装了客户端发送给服务器的数据，以及客户端的相关请求信息。
  - **`response`（响应对象）**：封装了服务器需要返回给客户端的数据，以及服务器的相关响应信息。
  - **数据流向**：客户端 -> 服务器（通过 `request`）；服务器 -> 客户端（通过 `response`）。

## 3. 基础路由配置实战 *Content-[08:00]

- **获取访问路径**：
  - 通过 `request.url` 属性可以获取客户端请求的具体路径。

- **浏览器的默认请求行为**：
  - 在控制台打印 `request.url` 会发现，当访问首页时，浏览器实际上发起了**两次请求**：
    1. 请求路径 `/`（代表首页）。
    2. 请求路径 `/favicon.ico`（代表网页标签的图标）。
  - 如果服务器不处理 `/favicon.ico`，浏览器会显示默认的图标或忽略。

- **基础路由逻辑实现**：
  - 使用 `if...else if...else` 语句对 `request.url` 进行判断，并返回对应内容。
  - **代码示例**：
    ```javascript
    if (request.url === '/') {
        response.end('我是首页');
    } else if (request.url === '/login') {
        response.end('我是登录页');
    } else if (request.url === '/register') {
        response.end('我是注册页');
    } else {
        response.end('404 页面走丢了');
    }
    ```
  - **优化建议**：在实际开发中，可以结合 ES6 语法（如 `switch` 语句或解构）来简化路由判断代码。

## 4. 解决乱码与完善路由逻辑 *Content-[11:46]

- **中文乱码问题排查与解决**：
  - **现象**：配置路由后，返回的中文内容在浏览器中显示为乱码。
  - **原因**：未正确设置响应头的字符集编码。
  - **解决方案**：在返回数据前，必须设置 `Content-Type` 响应头，指定内容类型为 HTML 并设置字符集为 `utf-8`。
    ```javascript
    response.setHeader('Content-Type', 'text/html;charset=utf-8');
    ```

- **完善后的路由体验**：
  - 访问 `/` 正常显示首页。
  - 访问 `/login` 正常显示登录页（此时控制台会打印 `/login` 和 `/favicon.ico` 两次请求记录）。
  - 访问 `/register` 正常显示注册页。
  - 访问其他未配置的路径，正常显示 404 提示。

- **后续开发预告**：
  - 当前路由仅返回简单的字符串。在实际的服务器开发中，不应直接在代码中拼接大段的 HTML 代码。
  - 下节课将讲解如何通过路由读取并返回真实的 HTML 页面文件，以及如何优雅地处理 `/favicon.ico` 请求。

## 5. AI 总结 *Content-[14:20]

本节课深入讲解了 Node.js 中基础服务的响应处理与路由配置。核心要点包括：
1. **响应流控制**：明确了 `response.write()` 用于多次发送数据，而 `response.end()` 用于结束本次访问，切忌重复调用 `end()` 导致 `write after end` 错误。
2. **请求与响应对象**：理清了 `request`（接收客户端数据）与 `response`（返回服务器数据）的职责与数据流向。
3. **路由基础实现**：通过 `request.url` 获取路径，结合条件判断实现基础路由分发；同时了解了浏览器默认请求 `/favicon.ico` 的特性。
4. **乱码处理**：强调了在返回中文内容时，必须通过 `response.setHeader` 设置 `text/html;charset=utf-8` 以防止乱码。
这些知识为后续学习读取真实文件、构建完整 Web 服务器打下了坚实基础。
