## 1. 引入 HTTP 模块 *Content-[00:00]

在 Node.js 中启动一个简单的服务器，首先需要利用内置的 `HTTP` 模块。

- **引入方式**：通过 `const http = require('http');` 引入系统自带的 HTTP 模块。
- **对比前端**：这相当于前端 HTML 中的 `<script src="http.js"></script>`，但 Node.js 后端使用的是 `require` 语法。
- **Node.js 的轻量级特性**：
  - 与浏览器环境不同，浏览器自带 `window` 等全局对象，拿来即用；而 Node.js 环境中，即使是内置对象，也必须先通过 `require` 引入才能使用。
  - 这种“按需引入”的设计使得 Node.js 服务器非常轻量级。它不像 Java 需要庞大的配置文件，Node.js 仅用一个 JS 文件即可搞定基础服务。
  - 轻量级意味着基础配置较低，如果需要更多功能，可以通过引入更多的模块或配置来实现。

## 2. 创建服务器对象与监听端口 *Content-[02:24]

引入模块后，需要创建服务器实例并指定其运行的端口。

- **创建服务器对象**：
  - 调用 `http.createServer()` 方法创建一个服务器对象。
  - 该方法接收一个回调函数作为参数，回调函数包含两个核心参数：
    - `request`：请求对象（代表客户端发来的请求，可简写为 `req`）。
    - `response`：响应对象（代表服务器返回给客户端的数据，可简写为 `res`）。
  - 代码示例：`const server = http.createServer((request, response) => { ... });`
- **监听端口**：
  - 使用 `server.listen()` 方法设置服务器运行的监听端口。
  - 端口号建议选择 1000 以后的数字（如习惯使用 `3000`）。
  - `listen` 方法的第二个参数是一个回调函数，当服务器启动成功时会触发，通常用于打印启动成功的提示信息。
  - 代码示例：
    ```javascript
    server.listen(3000, () => {
        console.log('服务器启动成功，运行在3000端口');
    });
    ```

## 3. 本地测试与访问服务器 *Content-[05:06]

服务器启动后，需要在浏览器中进行访问测试。

- **启动与停止**：
  - 在终端运行 `node index2`（可省略 `.js` 后缀）启动服务器。
  - 服务器启动后，控制台不会自动结束，表示程序正在持续运行。
  - 若要停止服务器，需在终端按下 `Ctrl + C`。
- **本地访问地址**：
  - **IP 地址版**：使用 `127.0.0.1`。这是每台电脑默认的内网测试 IP，**不需要连接任何网络**即可访问本机。
  - **域名版**：使用 `localhost`。这是域名形式的本地回环地址，**前提是电脑必须连接网络**（如连接路由器或 WiFi），否则无法解析访问。
- **访问注意事项**：
  - 访问时必须带上端口号，例如：`http://127.0.0.1:3000`（注意使用英文冒号）。
  - 如果不加端口号，浏览器默认会访问 80 端口，导致无法连接到我们的 3000 端口服务。

## 4. 响应客户端请求 *Content-[08:14]

当在浏览器中访问服务器时，如果页面一直“转圈”无法加载，说明服务器接收到了请求，但没有给客户端返回任何响应数据。

- **重启服务器**：
  - **重要提示**：每次修改 Node.js 代码后，**必须**在终端按 `Ctrl + C` 停止当前服务，然后重新运行命令启动服务器，否则修改不会生效。
- **处理请求与响应**：
  - 每当有客户端访问服务器时，就会触发 `createServer` 中的回调函数。
  - 服务器必须在心里“想”（控制台打印）的同时，真正给客户端返回数据，否则浏览器会一直等待。
- **返回数据**：
  - 使用 `response` 对象的 `end()` 方法来结束本次访问，并向客户端返回指定数据。
  - 代码示例：`response.end('hello world');`
  - 调用 `end()` 后，浏览器停止转圈，成功接收到数据。

## 5. 处理中文乱码与设置响应头 *Content-[12:30]

在使用 `response.end()` 返回数据时，会遇到数据格式和编码问题。

- **返回 HTML 标签**：
  - 如果返回纯文本，浏览器会默认将其放入 `<pre>` 预编译标签中显示。
  - 如果返回 HTML 标签（如 `<h1>hello world</h1>`），浏览器会正常解析并渲染为标题样式。
- **中文乱码问题**：
  - 当返回中文（如“欢迎您来”）时，浏览器可能会出现乱码。
  - **原因**：Node.js 运行环境默认编码（如 GBK）与浏览器默认解析编码（UTF-8）不一致，且返回的网页头部缺少编码标识。
- **设置响应头解决乱码**：
  - 使用 `response.writeHead()` 方法在数据头部加入编码格式和类型标识。
  - **参数说明**：
    - **第一个参数（响应码）**：表示本次请求是否成功。`200` 表示 OK（访问成功）。
    - **第二个参数（配置对象）**：用于设置响应头信息。
  - **代码示例**：
    ```javascript
    response.writeHead(200, {
        'Content-Type': 'text/html;charset=utf-8'
    });
    ```
  - **原理解析**：`Content-Type` 告诉浏览器本次返回的是 `text/html` 格式的数据，并且指定使用 `utf-8` 编码进行解析，从而彻底解决中文乱码问题。
  - *注意*：方法名是 `writeHead`，拼写时需注意不要写错（如误写为 `red hand` 或 `right hand`）。

## 6. 最精简版服务器代码总结 *Content-[23:20]

将上述所有步骤整合，形成一个最精简、最基础的 Node.js 服务器启动代码模板。建议初学者熟记并多次练习。

```javascript
// 1. 引入 HTTP 模块
const http = require('http');

// 2. 创建服务器对象
const server = http.createServer((request, response) => {
    // 3. 设置响应头，防止中文乱码
    response.writeHead(200, {
        'Content-Type': 'text/html;charset=utf-8'
    });
    
    // 4. 结束响应并返回数据
    response.end('我是服务器数据');
});

// 5. 监听端口并启动服务器
server.listen(3000, () => {
    console.log('服务器启动成功，运行在端口:3000');
});
```

**操作提醒**：
- 切换文件或修改代码后，务必先 `Ctrl + C` 停止旧服务，再重新运行 `node 文件名`。
- 在终端中可以使用键盘的 `上下方向键` 快速切换之前输入过的命令，提高重启效率。
