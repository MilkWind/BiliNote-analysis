## Node.js 环境下载与安装 *Content-[00:00]

在深入学习 Node.js 之前，需要反复咀嚼和回顾之前学习的服务器概念，这些概念在日常学习和后续开发中都会频繁用到。虽然 Node.js 是使用 JavaScript 语言开发的，但我们仍然需要配置专门的 Node.js 环境才能运行 Node 程序。

**下载与安装步骤：**
- **下载地址**：直接访问 Node.js 中文网进行下载。
- **版本选择**：目前最新版本为 25，但推荐下载长期支持版（LTS，即稳定版，视频中提及为 24 版本），以保证环境的稳定性。
- **系统选择**：Windows 系统选择 64 位安装文件。
- **安装注意事项**：双击安装时，**一定要确保安装路径为纯英文路径**，避免后续出现因中文路径导致的未知错误。

## 命令行基础与版本查看 *Content-[00:54]

Node.js 安装完成后，可以通过命令行来运行单个 JS 文件。首先需要掌握如何打开命令行以及验证安装是否成功。

**打开命令行与验证：**
- **打开运行窗口**：使用快捷键 `Win + R`（Windows 键 + R 键）打开“运行”对话框。
- **打开控制台**：在运行窗口中输入 `cmd` 并回车，即可打开 Windows 命令行控制台。
- **查看 Node 版本**：在控制台中输入 `node -v`（node 空格 -v），如果正确输出版本号，说明 Node.js 环境已成功安装并配置到系统环境变量中。

## 运行本地 Node.js 程序 *Content-[01:42]

验证环境无误后，即可开始运行本地的 JavaScript 文件。这里介绍一个快速在当前文件夹打开命令行的技巧。

**运行步骤：**
- **快速打开当前路径控制台**：在本地代码文件夹的顶部地址栏中，直接清空路径并输入 `cmd`，然后按回车键。这样可以直接以当前文件夹路径打开命令行控制台，无需手动使用 `cd` 命令切换目录。
- **创建测试文件**：在当前目录下新建一个 JS 文件，例如命名为 `index.js`（可通过 VS Code 或右键新建）。
- **编写基础代码**：在 `index.js` 中写入简单的输出代码，例如：`console.log('hello world')`。
- **运行文件**：在命令行中输入 `node index.js`（node 空格 文件名），按下回车即可在控制台看到 `hello world` 的输出结果。

**注意**：此时的操作仅仅是利用 Node.js 环境运行了一个普通的 JS 文件，**尚未构成一个真正的服务器**。

## Node.js 与浏览器环境的区别 *Content-[02:54]

从这节课开始，需要建立一个核心认知：**必须区分浏览器环境与 Node.js 环境**。

**环境差异详解：**
- **浏览器专属对象不可用**：以前在网页中挂载在 `window` 对象下的 JS 代码（例如 `alert()` 弹窗），在 Node.js 中是**无法使用**的。
- **原因分析**：`window`、`document` 等属于宿主对象，是由浏览器提供并受浏览器控制的。Node.js 运行在独立的命令行环境中，**完全脱离了浏览器**，因此这些浏览器特有的对象在 Node.js 中是不存在的。
- **报错验证**：如果在 `index.js` 中直接打印 `window` 对象（即 `console.log(window)`），运行 `node index.js` 后，控制台会报错：`ReferenceError: window is not defined`。
- **学习建议**：在后续的学习中，需要慢慢扭转思维，逐渐理解并分辨哪些 Web API 在 Node.js 中可用，哪些不可用，建立起清晰的环境边界意识。

## 在 VS Code 中运行 Node.js *Content-[04:16]

在实际的日常开发中，我们不需要每次都通过系统的 `cmd` 命令行去运行代码。

**VS Code 终端运行法：**
- 直接在 VS Code 编辑器中打开**终端（Terminal）**。
- VS Code 的终端默认路径就是当前打开的项目文件夹路径。
- 直接在 VS Code 终端中输入 `node index.js` 即可运行代码，这种方式更加高效、便捷，是后续开发中最常用的运行方式。
