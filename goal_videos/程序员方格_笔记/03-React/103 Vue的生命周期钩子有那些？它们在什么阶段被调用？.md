## 面试答题思路与核心要点 *Content-[00:00]
- **区分 Vue2 与 Vue3**：在面试中回答 Vue 的生命周期钩子时，必须明确区分 Vue2 和 Vue3 的差异。
- **避免片面回答**：不要仅仅只回答 Vue2 或只回答 Vue3，这样显得比较片面。需要全面阐述两个版本的生命周期钩子及其差异，以展现对 Vue 底层和版本迭代的深入理解。
- **核心概念**：生命周期钩子是指在 Vue 实例的不同阶段（如创建、挂载、更新、销毁）触发的特定函数。

## Vue2 生命周期钩子详解 *Content-[00:28]
Vue2 的生命周期钩子主要分为以下几个阶段：

### 1\. 创建阶段
- **`beforeCreate`**：在实例初始化之后调用。此时数据观测（data observer）和事件配置尚未设置。
- **`created`**：在实例创建完成之后调用。此时数据观测和事件配置已经完成，但 DOM 尚未生成。通常在此阶段进行初始数据的获取。

### 2\. 挂载阶段
- **`beforeMount`**：在挂载开始之前调用。此时模板已经编译成渲染函数（render function），但尚未生成真实 DOM。
- **`mounted`**：在挂载完成之后调用。此时真实的 DOM 已经生成并挂载到页面上，可以在此阶段进行 DOM 操作或第三方库的初始化。

### 3\. 更新阶段
- **`beforeUpdate`**：在数据更新之后，视图更新之前调用。适合在视图更新前访问现有的 DOM 状态。
- **`updated`**：在视图更新完成之后调用。此时 DOM 已经根据最新的数据进行了重新渲染。

### 4\. 销毁阶段
- **`beforeDestroy`**：在实例销毁之前调用。此时实例仍然完全可用，可以在此阶段清理定时器或解绑全局事件。
- **`destroyed`**：在实例销毁之后调用。此时所有的事件监听器已被移除，所有的子实例也均被销毁。

### 5\. `keep-alive` 特有钩子
当组件被 `<keep-alive>` 包裹时，会触发以下两个特有的生命周期钩子：
- **`activated`**：在组件被激活（从缓存中读取）时调用。
- **`deactivated`**：在组件被停用（移入缓存）时调用。

## Vue3 生命周期钩子详解 (Composition API) *Content-[05:24]
Vue3 引入了 Composition API，其生命周期钩子的命名和调用方式与 Vue2 的 Options API 有所不同，但整体阶段划分是一致的。

### 1\. 创建/挂载阶段
- **`onBeforeMount`**：等价于 Vue2 的 `beforeMount`。
- **`onMounted`**：等价于 Vue2 的 `mounted`。

### 2\. 更新阶段
- **`onBeforeUpdate`**：等价于 Vue2 的 `beforeUpdate`。
- **`onUpdated`**：等价于 Vue2 的 `updated`。

### 3\. 销毁/卸载阶段
- **`onBeforeUnmount`**：等价于 Vue2 的 `beforeDestroy`。
- **`onUnmounted`**：等价于 Vue2 的 `destroyed`。

### 4\. 新增的调试钩子
Vue3 新增了用于调试响应式系统的钩子：
- **`onRenderTracked`**：在响应式依赖被收集时触发。
- **`onRenderTriggered`**：在响应式依赖更新并触发重新渲染时触发。

### 5\. `keep-alive` 特有钩子
- **`onActivated`**：等价于 Vue2 的 `activated`。
- **`onDeactivated`**：等价于 Vue2 的 `deactivated`。

## 总结与面试建议 *Content-[09:04]
- **整体一致性**：Vue2 和 Vue3 的生命周期整体阶段（创建、挂载、更新、销毁）是一致的。
- **Vue3 的灵活性**：Vue3 的 Composition API 提供了更灵活的钩子函数，允许开发者在 `setup` 函数中按需组织逻辑，而不是分散在多个选项中。
- **实际应用场景**：使用生命周期钩子可以在不同阶段执行相应的逻辑，例如：
  - 数据初始化（通常在 `created` / `onMounted`）
  - 事件绑定与 DOM 操作（通常在 `mounted` / `onMounted`）
  - 资源释放与清理（通常在 `beforeDestroy` / `onBeforeUnmount`）
- **面试要求**：在面试中，必须对 Vue2 和 Vue3 的生命周期钩子“如数家珍”，清晰地知道它们之间的差异以及各自适用的场景。
