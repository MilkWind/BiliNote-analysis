## 1. Props 校验的作用与意义 *Content-[00:01]

在 Vue 组件封装中，Props 校验是至关重要的一环。它主要用于校验父组件传递过来的数据是否符合子组件的要求。

**为什么要进行 Props 校验？**
- **避免组件报错**：防止传递错误的数据类型导致组件显示异常甚至直接报错。例如，子组件需要一个数字类型的 `age`，而父组件却传递了一个字符串类型的 `abc`，就会引发错误。
- **提前发现错误**：在开发阶段就能通过控制台警告提前发现数据传递的问题，极大地方便了调试。
- **提升组件健壮性**：确保组件在任何数据输入下都能保持稳定的运行状态。
- **体现专业素养**：在面试中提及 Props 校验，能够向面试官展现你严谨的编程习惯和专业的组件封装思维。

## 2. 基础校验属性配置 *Content-[00:53]

在进行 Props 校验时，除了使用内置的基础属性，还可以结合自定义校验来满足复杂的业务需求。

**常用的基础校验属性包括：**
- **`type`**：用于限制传递数据的数据类型（例如规定 `avatar` 必须是字符串类型）。
- **`required`**：用于限制该属性是否为必填项（例如规定 `avatar` 必须传递）。
- **`default`**：用于设置当父组件未传递该属性时的默认值。

## 3. 自定义校验规则 (validator) 实战 *Content-[01:45]

以 `UserCard` 组件为例，演示如何使用 `validator` 函数进行自定义规则校验。`validator` 接收一个参数 `value`（即父组件传递过来的值），并需要返回一个布尔值来判断是否符合规则。

### 3.1 头像 (avatar) 链接校验
- **需求**：头像必须是在线的图片链接，不能是本地图片，即必须以 `http://` 或 `https://` 开头。
- **实现逻辑**：使用 JavaScript 字符串的 `startsWith()` 方法进行判断。
  ```javascript
  validator: (value) => {
    return value.startsWith('http://') || value.startsWith('https://');
  }
  ```
- **演示效果**：
  - 传入合规的 `https` 链接时，校验通过，无警告。
  - 若传入不合规的链接（如去掉了 `https` 前缀），控制台会抛出 `Custom validator failed for prop "avatar"` 警告。
- **补充知识**：`startsWith()` 用于判断字符串开头，相对应的 `endsWith()` 用于判断字符串结尾（具体用法可参考 MDN 文档）。

### 3.2 名字 (name) 长度校验
- **需求**：用户名字的长度必须大于等于 2 个字符。
- **实现逻辑**：
  ```javascript
  validator: (value) => {
    return value.length >= 2;
  }
  ```
- **演示效果**：
  - 传入“张三”、“张小三”时，校验通过。
  - 传入单字“张”时，由于长度小于 2，控制台抛出 `Custom validator failed for prop "name"` 警告。

### 3.3 年龄 (age) 范围校验
- **需求**：年龄必须在一个正常的合理范围内，即大于等于 18 岁且小于等于 100 岁。
- **实现逻辑**：
  ```javascript
  validator: (value) => {
    return value >= 18 && value <= 100;
  }
  ```
- **演示效果**：
  - 传入 2 岁（不符合正常范围）时，控制台抛出 `Custom validator failed for prop "age"` 警告。
  - 传入 22 岁时，校验通过，无警告。

## 4. 面试核心要点总结 *Content-[07:13]

在面试中回答 Vue 组件 Props 校验相关问题时，为了展现回答的全面性和专业性，务必牢记并提及以下四个核心属性：

1\. **`type`**：基础的数据类型校验。
2\. **`required`**：必填项校验。
3\. **`default`**：默认值配置。
4\. **`validator`**：自定义校验规则（重点加分项，能结合实际业务场景如 URL 格式、长度、数值范围等编写逻辑）。
