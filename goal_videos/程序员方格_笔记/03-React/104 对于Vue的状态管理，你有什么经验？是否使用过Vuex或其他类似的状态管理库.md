## 2. Vuex 简介与核心概念 *Content-[00:24]
- Vuex 是 Vue 官方提供的状态管理库。虽然在 Vue 3 时代目前更推荐使用 Pinia，但 Vuex 作为重要的历史产物，依然是面试和实际开发中需要了解的内容。
- **核心概念**：Vuex 提供了集中式的存储，用于管理应用的所有组件的相关状态。

## 3. Vuex 的使用步骤与 Store 创建 *Content-[00:59]
- **第一步：安装 Vuex**。
- **第二步：创建对应的 Vuex Store**。
  - 一般通过创建一个单独的文件来实现。
  - 在该单独文件中，定义状态（State）、变更动作（Mutations）以及获取器（Getters）。
  - 通过引入 `createStore` 方法来创建当前的 Store 实例。

## 4. Store 核心模块详解 *Content-[01:55]
- **State（状态）**：
  - 用于存储全局维护的状态变量，例如定义一个 `count` 变量。
- **Mutations（突变/同步操作）**：
  - 用于修改 State 中的状态。
  - 主要处理同步操作。例如为 `count` 提供增加（increment）和减少（decrement）的操作，通过 `state.count++` 或 `state.count--` 来修改状态。
- **Actions（动作/异步操作）**：
  - 用于处理异步行为。
  - 在 Actions 中定义异步逻辑，并通过 `commit` 提交对应的 Mutation。例如提交 `increment` 或 `decrement`，从而与 Mutation 关联，实现状态的修改。
- **Getters（获取器）**：
  - 用于对当前的 State 做一些衍生状态的计算。
  - 提供获取状态的方法，例如 `getCount`。
- 最终将配置好的对象暴露为 Store 实例。

## 5. 在 Vue 实例中挂载 Vuex *Content-[04:32]
- 在主文件（如 `main.js`）中引入创建好的 Vuex Store。
- 通过 `createApp` 创建当前的 Vue 实例，并引入根组件和 Store。
- 使用 `app.use(store)` 的方式将 Vuex 作为插件注入到当前的 Vue 生态中（Vue Router 等插件也是采用同样的注入方式）。
- 最后通过 `mount` 方法将实例挂载到对应的 DOM 节点。

## 6. 在组件中使用 Vuex 与辅助函数 *Content-[06:02]
- 在组件中访问和修改状态。
- 使用 Vuex 提供的辅助函数来简化状态与动作的访问：
  - `mapState`：用于快速映射和获取 Store 中 State 的值（如 `count`）。
  - `mapActions`：用于映射 Store 中的 Actions 方法到组件的 `methods` 中。
- 在模板（`<template>`）中绑定数据和方法，通过 `@click` 等事件触发行为，从而实现状态的获取与修改。

## 7. 其他状态管理库简介 *Content-[10:33]
