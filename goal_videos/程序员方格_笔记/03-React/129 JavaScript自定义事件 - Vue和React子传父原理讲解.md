## 1. 视频背景与核心概念 *Content-[00:00]
本节主要讲解前端面试中的高频考点：**JavaScript 自定义事件（带冒泡与参数）**。
- **核心目标**：实现子元素触发自定义事件，父元素监听并获取传递的参数。
- **应用场景**：模拟原生开发中的组件通信，这也是 Vue 中 `$emit` 和 React 子传父的底层原理。
- **面试重要性**：大厂面试必问知识点，理解其底层逻辑有助于应对各种组件通信相关的面试题。

## 2. 页面布局与需求分析 *Content-[00:24]
在开始编码前，首先明确页面的 DOM 结构与具体需求：
- **页面布局**：
  - **父组件**：灰色区域（对应 DOM 元素 `parent`）。
  - **子组件**：橙色色块，是一个 `button` 元素（对应 DOM 元素 `child`）。
- **业务需求**：
  - 点击橙色块（子组件）。
  - 将子组件内部的数据传递给父组件。
  - 父组件接收到数据后，通过 DOM 操作将数据渲染到灰色的父组件区域中，从而实现“子传父”的通信效果。

## 3. 核心实现步骤：自定义事件三部曲 *Content-[01:00]
实现该需求的核心在于原生 JavaScript 的自定义事件机制，主要分为以下几个关键步骤：

### 3.1 第一步：获取 DOM 元素
首先需要获取父子组件对应的 DOM 元素，以便后续绑定和触发事件。
```javascript
const parent = document.getElementById('parent');
const child = document.getElementById('child');
```

### 3.2 第二步：创建带参数与冒泡的自定义事件
使用 `CustomEvent` 构造函数创建一个自定义事件。*(注：转录中口误为 `new event`，但在配置 `detail` 和 `bubbles` 时，标准 API 应为 `CustomEvent`)*。
- **事件名称**：例如命名为 `sMsg` (Send Message)。
- **携带参数**：通过 `detail` 属性传递数据，如 `name: '你好'` 和 `type: '子组件传值'`。
- **开启冒泡**：将 `bubbles` 设置为 `true`，确保子元素触发的事件能够冒泡到父元素被监听到。

```javascript
// 定义事件常量
const child2parentEvent = 'sMsg';

// 创建自定义事件
const customEvent = new CustomEvent(child2parentEvent, {
  detail: {
    name: '你好',
    type: '子组件传值'
  },
  bubbles: true // 开启冒泡，允许子元素触发，父元素监听
});
```

### 3.3 第三步：父元素绑定监听事件
父组件需要监听子组件冒泡上来的自定义事件，并从中提取参数。
- **无需给子元素直接绑定该自定义事件**，只需在父元素上监听即可，利用事件冒泡机制。
- 通过事件对象 `e` 的 `e.detail` 属性获取子组件传递过来的参数。

```javascript
// 父元素监听自定义事件
parent.addEventListener(child2parentEvent, (e) => {
  // 接收子组件传递的参数
  const name = e.detail.name;
  const type = e.detail.type;
  
  console.log('父组件接收到数据:', name, type);
  
  // 后续可通过 DOM 操作将数据渲染到父组件（灰色区域）中
});
```

### 3.4 第四步：子元素触发自定义事件
最后，给子元素（如 button）绑定一个原生的 `click` 事件，在点击回调中触发自定义的 `sMsg` 事件。

```javascript
// 子元素绑定点击事件
child.addEventListener('click', () => {
  // 触发自定义事件，事件会冒泡到父元素
  child.dispatchEvent(customEvent);
});
```

## 4. 运行效果与原理总结 *Content-[05:54]
- **运行效果**：
  - 点击子组件（橙色按钮）。
  - 控制台成功打印出父组件接收到的数据（如 `你好` 和 `子组件传值`）。
  - 证明子组件的数据成功通过自定义事件和冒泡机制传递给了父组件。
- **原理总结**：
  - 数据原本在子组件中，通过 `dispatchEvent` 触发自定义事件，利用 `bubbles: true` 开启事件冒泡。
  - 父组件通过 `addEventListener` 监听到冒泡上来的事件，并通过 `e.detail` 获取数据。
  - 最终通过 DOM 操作将获取到的数据渲染到父组件的视图中，完美实现了原生环境下的“子传父”通信。
  - **框架映射**：在 Vue（如 `$emit`）和 React 的底层实现中，组件间的通信逻辑本质上也是基于这种自定义事件与事件冒泡/委托的机制。
