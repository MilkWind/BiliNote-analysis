## JSX 简介与本质 *Content-[00:01]

- **JSX 定义**：JSX 是 JavaScript XML 的缩写，它是 JavaScript 语法的一种扩展。
- **核心作用**：允许开发者在 JavaScript 代码中编写类似 HTML 的结构，从而将 UI（用户界面）和逻辑紧密耦合在组件内部。
- **编译本质**：浏览器无法直接识别 JSX 语法，它本质上需要被编译。常见的编译结果包括以下两种：
  - **传统编译**：被编译成 `React.createElement` 函数调用的方式。
  - **新编译方式**：被编译成 `_jsx_runtime`（React 17 及以上版本引入的新 JSX 转换机制）。

## JSX 核心语法规则 *Content-[01:47]

### 基本结构 *Content-[02:09]
- JSX 允许使用标准的 HTML 标签（如 `div`、`button`、`h1` 等），也支持使用自定义组件。
- **代码示例**：
  ```javascript
  const element = <h1>hello world</h1>;
  ```
- 在 JS 代码中直接编写类似 HTML 的结构，这就是 JSX 语法的最直观体现。

### 属性命名规则 *Content-[02:54]
- JSX 中的属性命名规则与原生 HTML 不同，**必须使用驼峰命名法（CamelCase）**。
- **常见转换示例**：
  - HTML 中的 `class` 属性，在 JSX 中必须写为 `className`。
  - HTML 中的 `tabindex` 属性，在 JSX 中必须写为 `tabIndex`。

### 标签闭合规则 *Content-[03:46]
- 在 JSX 中，**所有标签都必须严格闭合**。
- 对于原生 HTML 中的单标签（如 `<img>`、`<br>` 等），必须使用自闭合语法。
- **正确示例**：`<img />`。
- **错误示例**：`<img>`（未闭合会导致语法错误）。

### 表达式与花括号 *Content-[04:16]
- 在 JSX 中嵌入 JavaScript 变量或表达式时，**必须使用花括号 `{}`** 进行包裹。
- **变量渲染示例**：定义了变量 `name` 后，在标签中使用 `{name}` 来动态渲染其值。
- **多行表达式**：如果需要编写多行 JavaScript 表达式或逻辑，同样必须使用花括号 `{}` 将其完整包裹。

## AI 总结

本视频详细讲解了 React 开发中高频使用的 JSX 模板语法及其底层编译原理。首先明确了 JSX 作为 JavaScript 语法扩展的本质，它允许在 JS 中编写类 HTML 结构，并最终被 Babel 等工具编译为 `React.createElement` 或 `_jsx_runtime`。其次，梳理了 JSX 的四大核心语法规则：支持 HTML 标签与自定义组件的基本结构、强制使用驼峰命名的属性规则、必须严格闭合的标签要求，以及使用花括号 `{}` 嵌入 JS 表达式的规范。掌握这些细节是编写规范 React 组件和应对前端面试的基础。
