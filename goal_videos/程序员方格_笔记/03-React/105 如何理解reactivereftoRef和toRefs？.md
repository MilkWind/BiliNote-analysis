## 1. Vue 3 响应式 API 概述 *Content-[00:00]
- 本节主要探讨 Vue 3 中几个常用的响应式 API：`ref`、`reactive`、`toRef` 和 `toRefs`。
- 这些 API 名称虽然读起来有些绕口，但各自具有不同的特性。理解它们之间的区别与适用场景，是掌握 Vue 3 响应式系统以及应对前端面试的关键。

## 2. ref 与 reactive 的核心区别 *Content-[00:12]
### `ref` 函数
- **接收数据类型**：既可以接收**原始数据类型**（如 String、Number、Boolean 等），也可以接收**引用数据类型**（如 Object、Array 等）。
- **使用方式**：
  - 在**模板**中：创建的响应式数据可以被**直接使用**，无需额外操作。
  - 在 **JS/TS** 中：必须通过 `.value` 的方式来获取和修改里面的响应式数据。

### `reactive` 函数
- **接收数据类型**：**只能接收引用数据类型**（如 Object、Array 等），不能接收原始数据类型。
- **本质**：与 `ref` 一样，本质都是将当前的数据变成响应式数据。
- **核心区别**：`ref` 支持原始类型和引用类型，而 `reactive` 仅支持引用类型，这是两者在数据类型限制上最大的区别。

## 3. toRef 与 toRefs 的转换机制 *Content-[01:17]
### `toRef` 函数
- **作用对象**：针对一个**响应式对象**的**某一个具体属性**。
- **功能**：为该属性创建一个对应的 `ref`，使得该属性具有响应式特性。
- **引用关系**：新创建的 `ref` 与原响应式对象的属性之间保持**引用关系**，修改其中一个，另一个也会同步更新。

### `toRefs` 函数
- **作用对象**：针对整个**响应式对象**。
- **功能**：将一个响应式对象转换为**普通对象**，并且该普通对象的**每一个属性**都是对应的 `ref`。
- **引用关系**：转换后的普通对象中的每个 `ref` 属性，与原响应式对象的对应属性之间依然保持**引用关系**，确保数据的一致性。

## 4. 四大 API 特性总结 *Content-[02:30]
- **`ref`**：可接收原始数据类型和引用类型；在 JS 中需通过 `.value` 获取响应式数据。
- **`reactive`**：只能接收引用数据类型；用于将对象或数组等引用类型转为响应式。
- **`toRef`**：针对响应式对象的单个属性创建 `ref`，使其具备响应式，并保持引用关系。
- **`toRefs`**：将整个响应式对象转为普通对象，其内部每个属性均为 `ref`，且与原对象保持引用关系。
