## 什么是高阶组件 (HOC) *Content-[04:00]

- **定义**：HOC 全称 Higher Order Component（高阶组件），在 Vue 和 React 中均有对应概念。
- **本质**：
  - 本质上是一个**函数**，并不复杂。
  - **入参**：接收一个**组件**作为参数（这是与其他函数的核心差异点）。
  - **返回值**：返回一个**新的组件**。
- **特性**：
  - 它是一个**纯函数**。
  - 不会修改传入的原组件本质，而是通过组合、继承或修改属性等方式，返回一个增强后的新组件。
  - 核心目的：更好地进行组件逻辑的复用。

## HOC 的核心使用场景 *Content-[05:30]

- **抽取复用代码**：将通用逻辑封装在 HOC 的 Wrapper 层，避免在每个组件中重复实现。
- **条件渲染**：在大部分组件中需要根据特定条件（如权限）动态渲染组件。
- **捕获/劫持生命周期**：用于组件性能追踪、统一事件上报等。
- **数据获取**：统一处理多个组件中相同的数据获取逻辑，简化组件代码，使组件专注于 UI 渲染。
- **状态管理**：抽取状态逻辑，注入全局状态或上下文（如管理后台的主题切换），通过 Wrapper 层统一获取并透传给内部组件。
- **日志与监控**：在中间层进行日志记录、性能监控等处理。

## HOC 使用方式一：属性代理 (Props Proxy) *Content-[08:45]

- **概念**：HOC 组件控制被包裹组件 (WrappedComponent) 的 `props`，可以对其进行修改、增加、删除等操作，从而控制组件行为。
- **核心公式**：`HOC(WrappedComponent) -> NewComponent`
- **实现示例 (`withExternalInfo`)**：
  - **Class 组件实现**：继承 `React.Component`，在 `render` 中对 `props` 进行修改（如添加 `externalInfo` 字段），然后渲染传入的组件。
  - **Function 组件实现**：返回一个函数组件，内部可使用 `useEffect` 监听生命周期，并生成新的 `props` 传递给被包裹组件。
- **效果**：实现对被包裹组件生命周期的监听以及对 `props` 的增强。

## 属性代理进阶：抽象 State 与受控组件转换 *Content-[13:15]

- **核心思想**：通过操作 `props` 来模拟操作 `state`，将**非受控组件**转换为**受控组件**。
- **优势**：实现 UI 与逻辑的经典分离。
- **实现示例 (`withChange`)**：
  - 针对 `input` 标签，在 HOC 内部的 `state` 中定义 `value`（初始值）。
  - 定义 `handleChange` 方法，当输入变化时触发 `setState` 更新 `value`。
  - 将 `value` 和 `onChange` 作为 `props` 传递给被包裹的 `input` 组件。
- **效果**：原本没有 `state` 管理状态的非受控 `input` 组件，经过 HOC 包裹后，其值完全由 HOC 内部的 `state` 控制，变成了受控组件。逻辑写在 HOC 中，UI 写在原组件中。

## 属性代理应用：条件渲染与权限控制 *Content-[18:10]

- **权限控制 (`withAuthorization`)**：
  - 获取当前用户角色，判断是否满足组件所需权限。
  - 若满足，渲染被包裹组件；若不满足，返回登录组件 (Sign In) 或提示无权限。
  - 统一封装权限判断逻辑，简化业务组件代码。
- **Loading 状态控制 (`withLoading`)**：
  - 根据当前的 `loading` 状态进行判断。
  - 若正在加载，展示 Loading 组件；否则渲染被包裹的业务组件。

## 属性代理应用：全局状态注入与上下文 *Content-[20:55]

- **场景**：全局状态管理，如整个工程的管理后台主题 (Theme) 切换。
- **实现方式**：
  - 使用 `createContext` 创建上下文，分为 `Provider` 和 `Consumer`。
  - 在 HOC 的 `Consumer` 中获取全局上下文（如最新的 `theme`）。
  - 将获取到的 `theme` 作为属性传入被包裹组件。
- **效果**：当主题发生变化时，HOC 能够拿到最新主题并触发被包裹组件的重新渲染，实现全局状态的统一管理与透传。

## 属性代理应用：日志记录、性能监控与 UI 增强 *Content-[23:00]

- **日志记录与性能监控**：
  - 在 HOC 中监听组件的生命周期变化。
  - 计算渲染耗时：在渲染开始时记录 `start time`，在挂载完成后（如 `useEffect` 中）记录 `end time`。
  - 将计算出的组件 render 耗时数据上报给监控服务。
- **UI 增强与样式注入**：
  - 在 HOC 返回的新组件中，使用一个外层 `div` 包裹被包裹组件。
  - 在外层 `div` 上注入特定的样式（如 `border`、`padding`）。
  - 实现对原组件 UI 样式的统一增强和封装。
