## 面试背景与考察核心 *Content-[00:00]

在前端面试中，设计类问题不仅限于单一组件、功能或页面，还会考察应聘者对**整个组件库（集群/系统）** 的设计能力。

- **核心面试题**：如何设计实现一款 Vue 的组件库？
- **考察重点**：
  - 考察应聘者对项目整体的控制能力。
  - 评估应聘者是否具备系统性工程的开发经验。
  - 即使没有直接开发过组件库，也需要展现出基于过往项目经验的系统性设计思考与判断能力。
- **回答策略**：组件库是一个系统性工程，回答时应从**架构设计、组件开发、文档编写、打包发布**这四个核心维度进行系统性阐述，展现出全面且周全的考虑。

## 架构设计 *Content-[03:07]

架构设计是组件库最基础、最关键的一步（Base），决定了后续的执行方向。在进行架构设计时，需要明确以下几个关键维度：

### 1. 明确三大定位
- **目标用户**：明确组件库是面向外部开发者、企业内部使用，还是开源社区。
- **功能范围**：确定是开发“通用型组件库”还是“垂直领域/特定业务（如金融、数据分析）专用组件库”。功能范围直接决定了组件库的开发内容。
- **设计风格**：确定 UI 设计风格。建议参考或沿用成熟的设计规范（如 Ant Design 风格），以积累经验并少走弯路。

### 2. 确定技术栈
- **框架与语言**：强烈推荐使用 **Vue 3 + TypeScript**。Vue 3 支持 Composition API，结合 TypeScript 能够提供更好的类型支持和主流的开发体验。
- **单元测试框架**：可选择 **Jest** 或 **Mocha** 等主流测试框架来保障代码质量。

### 3. 目录结构设计
合理的目录结构是组件库清晰度的体现，通常包含以下部分：
- **单个组件目录**：每个独立组件（如 Button）应包含：组件源码、单元测试代码、组件入口文件（Entry）、组件使用文档。
- **核心代码目录**：包含全局入口、全局样式、工具函数（Utils）、自定义指令（Directives）等公共核心代码。
- **文档目录**：用于存放组件库的说明文档。
- **其他配置**：包含构建脚本（Scripts）及各类配置文件。

## 组件开发原则 *Content-[08:59]

在具体开发单个组件时，需要严格把握以下两个核心原则：

- **单一职责**：
  - 每个组件只做一件事情，将功能细分到最小颗粒度。
  - **反面案例**：不要将用户名、密码、按钮等多个功能耦合在一个“登录组件”中。
  - **正确做法**：将其拆分为独立的文本框、按钮等基础组件。这样在后续其他场景（如注册页面）中调用时，无需修改原有组件，极大提升复用性。
- **可控性（受控组件）**：
  - 组件的动态状态（数据）必须由父组件控制，切忌在组件内部将状态写死。
  - 通过父组件传递状态（即受控组件模式），保证组件在不同业务场景下的灵活性和可复用性。

## 文档编写 *Content-[10:30]

组件开发完成后，必须编写清晰、易懂的文档，让使用者能够快速了解组件的功能与调用方式。

- **推荐工具**：强烈推荐使用 **VitePress** 来构建和配置文档网站。
- **优势**：VitePress 轻量、高效，非常适合用于说明和展示组件库的功能与用法。

## 打包与发布 *Content-[10:45]

组件库开发完成后，需要进行规范的打包和发布，并建立持续维护的机制。

- **发布流程**：
  1. 使用 **npm** 更新版本号（Version）。
  2. 指定相应的 Tag（标签）。
  3. 将代码 push 到 **Git** 仓库并完成发布。
- **持续维护**：组件库不是一次性工作，发布后必须具备持续更新的能力与可操控性，不能发布后就停止迭代和维护。

## 组件库设计最佳实践总结 *Content-[11:44]

在构建 Vue 组件库时，遵循以下最佳实践可以显著提升组件库的质量与专业度：

- **组件命名**：尽量使用统一的前缀（如公司名或特定业务名），避免与其他库产生命名冲突。
- **Props 设计**：传入参数需合理，单一功能组件的 Props 尽量控制在 **5 个以内**，避免参数过多导致组件过度复杂。
- **事件命名**：采用“动作 + 具体值”的命名规则。例如更新某个值，应命名为 `update:value`（先说明动作，再说明具体值），语义更清晰。
- **样式隔离**：使用 **Scoped CSS** 等方式进行样式隔离，避免全局样式污染。
- **性能优化**：
  - 避免不必要的重复渲染。
  - 针对大型列表使用**虚拟滚动**（Virtual Scroll）技术。
  - 对非关键组件使用**延迟加载**（Lazy Load）。
