## 课程简介与大纲 *Content-[00:00]

本节课是 React 生态学习的最后一部分，主要讲解 React Router。掌握 React Router 后，结合 SSR（Server-Side Rendering）相关内容，即可系统化地开发中后台中控台等复杂工程。

**本节课主要包含以下几个部分：**
- React Router 详解及基础使用。
- React Router 相关的高级技巧。
- 手写一个 Router，熟悉 Hash 和 History 版本的实现原理。
- SSR 场景下的 React Router 相关核心知识点。
这些内容在日常工作和前端面试中都非常重要。

## React Router 版本与架构分层 *Content-[01:49]

### 版本说明
目前 React Router 主流版本为 V6 和 V7，两者差异不大，但与 V5 版本相比有较大的 API 和使用方式差异。本课程主要基于 V6 版本进行讲解（与 V7 基本一致）。

### 工程创建
可以通过 Vite 快速创建工程：
```bash
npm create vite@latest my-react-app -- --template react
```
然后安装对应版本的 `react-router-dom`（如 6.15.0）。

### 架构分层设计
React Router 底层针对不同宿主环境提供了不同的 NPM 包，采用了合理的架构分层设计：
- **`react-router`**：全路由核心包，包含路由的核心逻辑，其他环境包底层均依赖此包。
- **`react-router-dom`**：针对浏览器环境的顶层包。
- **`react-router-native`**：针对 React Native 环境的顶层包。
- **`react-router-server`**：针对服务端渲染（SSR）环境的包。因为服务端没有浏览器的 History API 能力，所以需要单独实现。

这种“上层抽象核心逻辑，底层由具体宿主环境实现”的架构设计思路非常值得学习。

## 路由的两种使用方式 *Content-[08:04]

在 React Router 中，路由的使用主要分为两种方式：

### 1. 组件式路由
- **特点**：在 V5 版本中较为常用。
- **用法**：直接在 JSX 中使用 `<Link>` 标签进行跳转，使用 `<Route>` 组件配置 `path` 和 `element`（匹配路径后渲染的组件）。
- **现状**：目前在 V6/V7 中较少使用。

### 2. 函数创建式路由（推荐）
- **特点**：V6/V7 版本推荐的方式，更加灵活。
- **用法**：通过调用 `createBrowserRouter` 等函数，传入路由配置对象来创建路由实例。
- **优势**：
  - 在处理权限管理、动态路由、路由权限等复杂场景时更加灵活。
  - 对 TypeScript (TS) 支持极好，提供良好的类型推导和类型安全保障。
  - 原生支持路由嵌套、数据加载（Data Loading）、错误边界（Error Boundaries）、重定向、懒加载以及 SSR 等高级特性。

## 常见的路由模式 Router Types *Content-[11:17]

React Router 提供了几种常见的路由创建模式，以适应不同的运行环境：

- **`createBrowserRouter`**
  - **环境**：浏览器环境。
  - **原理**：基于浏览器的 History API，通过该 API 管理和更新当前的 URL 以及地址堆栈。无论是 Vue Router 还是 React Router，BrowserRouter 都依赖此底层 API。

- **`createHashRouter`**
  - **环境**：浏览器环境。
  - **原理**：基于 URL 中的 Hash 值（`#` 锚点）进行路由管理。
  - **缺点**：URL 看起来不够美观。

- **`createMemoryRouter`**
  - **环境**：内存环境。
  - **原理**：基于内存中的堆栈进行管理，**不会操作或改变浏览器的 URL**。
  - **适用场景**：适合用于组件库的测试，或者移动端组件库的独立演示页面（在单一页面内通过点击切换查看不同组件效果）。

- **`createStaticRouter`**
  - **环境**：服务端环境。
  - **原理**：静态路由。
  - **适用场景**：主要用于 SSR（Server-Side Rendering）场景中创建和管理路由。

## React Router 基础使用演示 *Content-[13:34]

使用函数创建式路由（`createBrowserRouter`）的基础流程非常简单，主要分为以下三步：

1\. **创建路由配置与实例**
使用 `createBrowserRouter` 函数，传入一个包含路由规则的对象数组。每个规则需配置 `path`（匹配路径）和 `element`（对应的 React 组件）。
```javascript
import { createBrowserRouter } from 'react-router-dom';
import HomePage from './pages/HomePage';
import AboutPage from './pages/AboutPage';

const router = createBrowserRouter([
  {
    path: '/',
    element: <HomePage />
  },
  {
    path: '/about',
    element: <AboutPage />
  }
]);
```

2\. **在入口文件引入路由实例**
在项目的入口文件（如 `main.tsx` 或 `index.js`）中引入上一步创建好的 `router` 实例。

3\. **使用 RouterProvider 包裹根组件**
使用 `RouterProvider` 组件包裹整个应用，并将 `router` 实例通过 `router` 属性传入，从而提供路由上下文。
```javascript
import React from 'react';
import ReactDOM from 'react-dom/client';
import { RouterProvider } from 'react-router-dom';
import router from './router'; // 引入路由实例

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <RouterProvider router={router} />
  </React.StrictMode>
);
```
完成以上配置后，当访问根路径 `/` 时渲染 `HomePage`，访问 `/about` 时渲染 `AboutPage`，路由切换即可正常工作。
