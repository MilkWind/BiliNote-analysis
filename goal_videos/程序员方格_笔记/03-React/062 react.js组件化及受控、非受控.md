## 1. React 组件化概述 *Content-[00:10]
- **核心地位**：组件是 React 应用的核心构建模块。
- **版本演进**：
  - **React 16.8 之前**：主要使用 **Class（类组件）** 的形式进行开发。
  - **React 16.8 及以后**：引入了 **Hooks**，目前主要使用 **函数组件** 的思路进行开发。
- **组件的输入与输出**：组件可以接收对应的输入（**props**），并返回描述 UI 内容的 React 元素（**React Element**）。
- **核心作用**：
  1. **模块化**：将复杂的 UI 拆分为独立、可维护的单元。
  2. **复用性**：组件可以在不同的地方重复使用，从而提高整体的开发效率。
  3. **状态隔离**：每个组件管理自身的状态和逻辑，各个组件之间互不干扰。

## 2. 函数式组件 *Content-[01:57]
- **定义**：基于函数定义的组件，语法简洁易懂。
- **状态管理演进**：
  - **纯函数形式**：接收 **props** 作为输入，在 React 16.8 之前，函数组件只能是无状态的纯函数组件。
  - **支持 Hooks**：React 16.8 之后，函数组件支持使用 **Hooks** 进行状态管理及处理相关的副作用，从而成为有状态的组件。

## 3. 类组件 *Content-[03:24]
- **定义**：基于 ES6 Class 语法定义，需要继承 **React.Component**。
- **核心特性**：
  - **React.Component** 内部包含了针对组件基础的一些属性和方法。
  - 使用 **this.state** 来管理当前组件的状态。
  - 使用**生命周期方法**（Lifecycle methods）来处理副作用。
- **基本结构**：
  - 继承 `React.Component`。
  - 提供 `render` 方法来返回真正需要渲染的 UI 内容（例如返回 `Hello {this.props.name}`）。

## 4. 函数组件与类组件的对比 *Content-[04:08]
| 特性维度 | 函数组件 | 类组件 |
| --- | --- | --- |
| **语法复杂度** | 语法非常简洁 | 语法相对复杂 |
| **性能表现** | 性能更好 | 性能相对较差 |
| **状态管理** | 通过 **Hooks**（如 `useState`）监听数据变化 | 通过 **this.state** 和 `this.setState` 管理状态 |
| **副作用/生命周期** | 通过 **Hooks**（如 `useEffect`）处理更新和卸载逻辑，无需特别关注 mount、update 等具体生命周期 | 直接使用生命周期方法（如 `componentDidMount` 等） |
| **官方推荐度** | **强烈推荐**，尤其在业务工程中被广泛使用 | 不作为首选，但在特定场景下仍有使用价值 |

## 5. 类组件的使用场景 *Content-[06:18]
- 虽然目前主流开发推荐函数组件，但类组件并未被完全淘汰。
- **适用场景**：
  - 处理逻辑比较复杂的组件。
  - 编写**基础基类组件**（Base Components），并在此基础上衍生出不同形态和维度的子类组件，通过继承和复用的方式来应对复杂的逻辑场景。

## 6. 渲染组件 *Content-[07:10]
- **实现步骤**：
  1. 定义一个函数组件（如 `Hello`）。
  2. 创建 React 元素（React Element）调用该组件，并传入对应的 **props**（如传入 `name` 属性）。
  3. 调用 **ReactDOM.render()**，传入当前组件实例以及需要挂载的 DOM 节点，从而完成组件的渲染。

## 7. 受控组件 *Content-[08:02]
- **概念**：表单组件的状态由 **React** 控制。通过 **props** 传递数据，并通过事件处理函数来更改对应的数据。
- **优点**：易于控制、管理和调试当前的状态。
- **工作原理**：
  - 使用 `value`（或 `checked` 等）属性绑定 React 状态（如 `state` 中的变量）。
  - 通过 `onChange` 事件（如 `handleChange`）获取最新的 `event`，并更新 React 状态。
  - 状态变化触发重新渲染，`input` 的 `value` 随之更新，形成单向数据流。
- **特点**：`input` 里面的值完全由 React 状态所控制。

## 8. 非受控组件 *Content-[09:31]
- **概念**：表单数据不受 React 状态控制，而是由 DOM 元素自身（`input` 本身）内部管理和维护。
- **获取数据方式**：通过 **Ref**（如 `React.createRef` 或 `useRef`）获取 DOM 元素的引用，从而读取其值。
- **工作原理**：
  - 创建一个 `inputRef`。
  - 将 `inputRef` 传递给 `input` 的 `ref` 属性。
  - 在表单提交（`onSubmit`）阶段，通过 `inputRef.current.value` 直接获取表单数据。
- **特点**：`input` 的 `value` 没有被 React 状态绑定，由组件自身管理数据和更新，React 仅在需要时（如提交阶段）通过 Ref 获取值。
