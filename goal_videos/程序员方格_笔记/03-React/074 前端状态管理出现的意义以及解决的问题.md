## 1. 课程大纲与状态管理概述 *Content-[00:03]
- **状态管理的重要性**：对于中后台管理系统项目而言，Vue 状态管理是至关重要的一环。搭建中后台系统通常需要结合 Vue 全家桶，包括 Vue3、状态管理库（Vuex/Pinia）以及 Vue Router 等。
- **课程大纲**：
  - 状态管理的方式与相关手段。
  - Vuex 的基本使用、核心概念及辅助函数。
  - Pinia 的基本使用、核心概念及辅助函数（目前官方推荐）。

## 2. 状态管理手段：Composition API 与 provide/inject *Content-[01:25]
- **适用场景**：
  - 适合小型项目。
  - 适用于组件级别的状态共享。
  - 结合 `provide` 和 `inject` 可实现跨组件层级的状态共享。
- **典型应用场景**：
  - **换肤/主题切换**：在最外层（父组件）管理皮肤或主题状态，子孙组件通过 `inject` 获取最新状态并应用到界面。
  - **国际化（i18n）**：切换语言后，通过 `inject` 获取最新语言内容并匹配界面渲染。
- **代码实现逻辑**：
  - 父组件通过 `reactive` 维护 store（如 count、theme），使用 `provide` 将 store 暴露为全局状态。
  - 子组件通过 `inject` 获取 store，并在 template 中使用。
- **优缺点分析**：
  - **优点**：零依赖（无需第三方包）、零配置、简单快捷。
  - **缺点**：缺乏持久化支持和调试工具支持，仅适合状态管理不复杂的小型项目。

## 3. 集中式状态管理：Vuex 与 Pinia *Content-[05:11]
### Vuex
- **定位**：Vue2 项目的标准状态管理库，适合中大型项目。
- **核心特点**：
  - **集中式管理**：统一管理全局状态（如全局登录态等不适合分散放置的内容）。
  - **显式对象**：状态以显式对象存在，修改状态必须通过 `commit mutation` 的方式。
  - **支持插件**：具备完善的插件机制。
- **核心概念**：State（状态）、Getters（获取状态）、Mutations（同步改变状态）、Actions（处理异步模块）。
- **现状**：相比 Pinia 更为复杂。Vue3 可使用兼容版本 Vuex4，但官方目前更推荐使用 Pinia。

### Pinia
- **定位**：Vue3 项目官方推荐的首选状态管理库，同时兼容 Vue2。
- **核心特点**：
  - 支持 Options API 和 Composition API。
  - 轻量级且易用，API 设计更简洁（通过 `defineStore` 创建 store）。
  - 核心概念精简为三部分：State、Getters、Actions（去除了 Mutations）。
- **优势**：
  - **天然支持 TypeScript**：对 TS 支持度极好，类型推导完善。
  - **模块化与插件化设计**：便于开发和维护。
  - **开发体验现代化**：代码量少，整体开发体验优于 Vuex。

## 4. 状态管理手段：Event Bus *Content-[08:42]
- **适用场景**：小型项目中的特定场景。
- **实现原理**：通过事件总线（基于发布-订阅模式）进行组件之间的事件和状态传递。
- **缺点与局限**：
  - 不推荐用于全局状态管理。
  - 依赖关系不直观、不明确，难以追踪和维护。
- **建议**：优先使用集中式状态管理（Vuex/Pinia）来显式地明确依赖关系，从而更好地管理状态。

## 5. 项目创建与 `<script setup>` 语法 *Content-[09:47]
- **项目创建**：使用 `create vite` 命令创建基于 TypeScript 的 Vue 项目。
- **`<script setup>` 语法优势**：
  - 相比传统的 `defineComponent` + `setup` 函数写法，大幅减少模板代码。
  - 更好地支持 TypeScript，类型推导更自然。
  - 编译层面有性能优化。
  - 无需手动 `return` 暴露变量，定义的 props、变量和函数可直接在 template 中使用。

## 6. 代码实战：跨组件状态共享演示 *Content-[13:42]
### 父组件 (HelloWorld)
- 使用 `<script setup lang="ts">` 语法。
- 定义 props（如 `message`）和响应式变量 `count`。
- 引入并渲染子组件 `Child`，将 `count` 作为 props 传递给子组件。

### 子组件 (Child)
- 使用 `defineProps` 接收父组件传入的 `count`。
- 使用 `inject` 接收全局状态：主题（`theme`）和国际化 key（`i18nKey`）。
- 模板中根据 `i18nKey` 的值（如 'en' 或 'zh'）条件渲染不同的文本（Hello / 你好）。

### 根组件 (App.vue)
- **类型定义**：
  - 定义主题数组（如 `['light', 'dark']`），使用 `typeof` 和 `as const` 获取联合类型。
  - 同理定义 i18n key 的联合类型。
- **状态定义与注入**：
  - 使用 `ref` 定义响应式的 `theme` 和 `i18nKey` 状态。
  - 使用 `provide` 将 `theme` 和 `i18nKey` 注册为全局状态。
- **交互实现**：
  - 添加按钮用于切换主题和语言。
  - 演示状态在组件间的响应式更新效果。
