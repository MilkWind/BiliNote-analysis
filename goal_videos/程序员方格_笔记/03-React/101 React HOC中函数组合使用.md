## Redux 中间件与 compose 函数 *Content-[00:14]

- **中间件执行顺序**：在 Redux 中，中间件的执行顺序是**从右往左**。这是因为 Redux 底层使用了 `compose` 函数来组合中间件。
- **使用场景示例**：
  - 通过 `createStore` 传入 `reducer`。
  - 引入 `compose` 函数，并传入 `applyMiddleware`（应用中间件）和 `devTools`（Redux 开发者工具）。
  - 执行顺序：由于是从右往左执行，因此会先执行 `devTools`，然后再执行 `applyMiddleware`。每个中间件各自负责独立的功能。
- **`compose` 源码实现逻辑**：
  - 接收多个函数（`fns`）作为参数。
  - 如果函数数量 `length === 0`，则直接返回。
  - 如果函数数量 `length === 1`，则直接返回并执行第一个函数。
  - 如果函数数量 `length > 1`，则通过 `reduce` 方法，以**从右往左**的方式将多个函数组合执行。

## 数据处理的管道 (Pipeline) *Content-[01:12]

- **核心概念**：函数组合可以看作是一条数据处理流水线（Pipeline）。通过组合多个基础函数，每个函数只负责单一职责（Single Responsibility），层层处理数据，最终实现复杂功能。
- **基础函数示例**：
  - `trim`：去除字符串首尾的空格。
  - `toLowerCase`：将字符串全部转换为小写。
  - `removeSpace`：去除字符串中的所有空格。
- **函数组合与执行顺序**：
  - 组合代码示例：`const processString = compose(removeSpace, toLowerCase, trim);`
  - 传入测试数据：`" Hello World "`（包含首尾空格和中间空格，且为大写）。
  - **执行流程解析**（基于 `compose` 从右向左的特性）：
    1. 首先执行最右侧的 `trim`，去除首尾空格。
    2. 接着执行 `toLowerCase`，将所有字符转换为小写。
    3. 最后执行 `removeSpace`，去除中间的所有空格。
  - 最终输出结果：`"helloworld"`。
- **优势**：通过随意调整组合顺序，可以灵活生成不同的数据处理函数，极大提升了代码的复用性和可读性。

## React HOC 中的函数组合 *Content-[03:49]

- **痛点**：在 React 中，使用高阶组件（HOC）时，如果直接嵌套使用多个 HOC，会导致代码层级过深（嵌套地狱），难以维护。
- **解决方案**：使用 `compose` 函数将多个原子化的 HOC 组合成一个增强组件。
- **原子 HOC 示例**：
  - `withAuth`：权限管理组件。接收 `Component` 和 `props`，判断 `props` 中是否包含授权信息。若未授权，则返回 `Redirect` 进行重定向；若已授权，则渲染 `Component` 并透传 `props`。
  - `withLogger`：日志打印组件，用于处理相关的打印逻辑。
  - `withTheme`：主题处理组件，用于处理相关的主题样式逻辑。
- **组合方式**：
  - 代码示例：`const EnhancedComponent = compose(withAuth, withLogger, withTheme)(MyComponent);`
  - 通过 `compose` 传入三个 HOC，最终增强 `MyComponent`。
- **组件层级结构解析**：
  - 组合后的组件结构从外到内依次为：
    1. 最外层：`withAuth`（权限校验）
    2. 中间层：`withLogger`（日志打印）
    3. 内层：`withTheme`（主题处理）
    4. 最核心层：传入的基础组件 `MyComponent`
  - 这种扁平化的组合方式让组件的增强逻辑更加清晰直观。

## 函数式编程核心技巧总结 *Content-[07:14]

- **函数式编程思想**：强调函数的纯粹性、无副作用以及数据的不可变性。在面试中，需要深刻理解函数式编程与面向对象编程的对比及其核心特性。
- **三大常用技巧**：
  1. **柯里化 (Currying)**：将接收多个参数的函数转换成接收单一参数的函数，并返回接受余下参数的新函数。
  2. **函数复用**：通过提取公共逻辑，编写高内聚、低耦合的纯函数，提高代码复用率。
  3. **函数组合 (Compose)**：将多个简单的函数组合成一个复杂的函数，如 Redux 中间件和 React HOC 中的应用。
- **应用价值**：这些函数式编程技巧在现代前端基础库（如 Redux、React、Lodash 等）中被频繁且精巧地使用，是前端进阶和应对大厂面试的必考核心考点。
