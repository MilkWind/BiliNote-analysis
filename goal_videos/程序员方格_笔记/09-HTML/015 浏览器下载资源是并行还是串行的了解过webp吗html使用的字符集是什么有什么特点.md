## 浏览器下载资源是并行还是串行 *Content-[00:00]

- **下载机制**：浏览器在页面加载时下载资源（如 CSS、JS 等）实际上是**并行**的，而不是串行（一个一个）下载。
- **默认行为**：浏览器默认会同时发起多个下载请求，一起并行下载资源。
- **并发限制**：浏览器对同一域名下的并行下载数量有默认限制，最多支持同时并行下载 **6 个**资源。

## 了解过 WebP 吗 *Content-[00:20]

- **WebP 简介**：
  - WebP 是一种现代的图片格式。
  - 主要用于在 Web 上提供更好的**有损**和**无损**压缩图片。
- **核心优势**：
  - 核心在于**体积更小**。
  - 能够创建更小、更丰富的图片，从而显著提升网页的加载速度。
- **压缩效果**：
  - 对于无损图像，WebP 格式通常比 PNG 格式图像小 **26%**（这是一个通用结论，具体到每一张图片可能会有所浮动，但总体在这个数值左右）。
- **压缩原理（有损 WebP）**：
  - 使用**预测编码**对图像进行编码。
  - 这种方法与视频编解码器 **VP8** 压缩视频关键帧的方法相同。
  - **预测编码原理**：使用相邻的像素值来预测块中的值。简单来说，通过一套算法预测图片周围像素的颜色，从而达到压缩图片体积的效果。

## HTML 中使用的字符集及特点 *Content-[01:49]

- **HTML 默认字符集**：
  - 通常使用 **UTF-8**。
  - 在 VS Code 等编辑器中创建 HTML 模板时，`<head>` 标签内会默认包含 `<meta charset="UTF-8">`，用于告知浏览器识别并使用该编码。
- **字符集发展历史与原理**：
  - **ASCII 编码**：
    - 计算机诞生时最早的编码标准。
    - **特点**：只支持很少的字符，基本只能包含英文字母、阿拉伯数字及少量常用符号（如逗号）和计算机预留编码。
    - **局限**：仅支持 100 多个字符，无法兼容全球多种语言（如阿拉伯语、西班牙语、汉语等）。
  - **Unicode 编码**：
    - 为了兼容全球语言而产生的标准，能够识别全世界的语言。
    - **特点**：为世界上几乎所有的字符分配唯一的编码。例如，英文字母 A-F 可能对应 1-6，而汉字（如“老虎”）通常对应五位数编码（如“老”对应 2 万，“虎”对应 3 万）。
    - **局限**：比较原始，在计算机中比较占用内存。
  - **UTF-8**：
    - 是 **Unicode** 的一种实现方式（表达形式），用于表示 Unicode 中的那一串数字。
    - 视频讲师提到“使用 8 个字节去表示”（*注：此处为讲师口误，实际 UTF-8 中的“8”指的是 8 个**位 (bit)**，且 UTF-8 是变长编码，使用 1 到 4 个**字节 (Byte)** 来表示一个字符*）。
    - 除了 UTF-8，还有 **UTF-16**、**UTF-32**，它们都是用来表示 Unicode 的编码方式。
- **UTF-8 的核心特点**：
  - 因为 Unicode 包含世界上几乎所有字符，所以 UTF-8 也支持世界上几乎所有国家和地区的语言。
  - **常见面试误区**：UTF-8 只支持中文吗？
    - **答案**：不是。它几乎支持全球所有国家和地区的语言。
