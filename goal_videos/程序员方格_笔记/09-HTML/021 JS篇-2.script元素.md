## 1. script 标签的核心用途 *Content-[00:08]
- **核心职责**：`<script>` 标签是连接 HTML 和 JavaScript 的桥梁，用于将 JS 嵌入页面。
- **两个主要用途**：
  - **内部嵌入代码**：直接在 HTML 页面内部嵌入 JS 代码，包裹在 `<script>` 标签中的脚本可直接在浏览器执行。
  - **引入外部文件（更常用）**：通过 `src` 属性引入外部 JS 文件。这种方式能让代码结构更清晰，更易于维护。
- **执行机制**：浏览器在解析 HTML 文档时，一旦遇到 `<script>` 标签，就会开始下载并执行其中的脚本，这对页面加载性能有重大影响。

## 2. script 标签的重要属性 *Content-[01:45]
- **`src` 属性**：用于指定外部脚本的下载地址（路径）。
- **`type` 属性**：
  - 过去是必须的，但现在浏览器默认将 `<script>` 标签内的内容当作 JavaScript 处理，因此 `type="text/javascript"` 通常可以省略。
  - **例外情况**：如果需要加载 ES6 模块，则必须显式设置 `type="module"`，此时该属性不可省略。

## 3. 性能优化属性：async 与 defer *Content-[02:52]
- **默认行为**：浏览器遇到 `<script>` 标签时，会暂停解析 HTML，立即下载并执行脚本。执行完毕后才继续解析后续 HTML。若脚本较大，会导致页面长时间白屏。
- **`async`（异步模式）**：
  - **下载**：告诉浏览器继续解析 HTML，脚本下载与 HTML 解析并行进行。
  - **执行**：脚本下载完成后，浏览器会暂停 HTML 解析，立即执行该脚本。
  - **特点**：解决了下载阻塞问题，但多个 `async` 脚本的执行顺序无法保证（取决于下载完成的先后）。
  - **适用场景**：脚本之间没有依赖关系，需要尽快执行。
- **`defer`（延迟模式）**：
  - **下载**：同样是并行下载，不阻塞 HTML 解析。
  - **执行**：延迟到整个 HTML 文档解析完成之后才执行。
  - **特点**：多个 `defer` 脚本会严格按照它们在代码中出现的顺序执行。
  - **适用场景**：脚本之间有依赖关系，或者需要操作 DOM（文档对象模型），是更安全、可靠的选择。

## 4. 其他属性：安全、模块化与隐私 *Content-[04:49]
- **安全性属性**：
  - **`integrity`**：提供文件的哈希值。浏览器下载文件后会计算哈希值，若与提供的值不匹配，说明文件可能被篡改，浏览器将拒绝执行。
  - **`crossorigin`**：经常与 `integrity` 配合使用，用于配置跨域请求（如从公共 CDN 加载库）。
- **模块化降级属性**：
  - **`nomodule`**：现代浏览器支持 ES 模块（通过 `type="module"` 加载）。对于不支持模块的老旧浏览器，可提供一个带有 `nomodule` 属性的普通脚本作为备用方案。
  - **渐进增强策略**：支持模块的浏览器会忽略 `nomodule` 脚本；不支持的浏览器会忽略 `type="module"` 脚本，转而执行 `nomodule` 脚本。
- **隐私属性**：
  - **`referrerpolicy`**：用于控制 HTTP `Referer` 头的发送策略，以增强用户隐私保护。

## 5. 经典问题：脚本的放置位置 *Content-[07:17]
- **传统做法：放在 `<head>` 标签中**
  - **优点**：脚本逻辑可以先于页面内容执行。
  - **缺点**：严重阻塞浏览器解析 HTML。浏览器从上到下解析，遇到脚本必须等待下载和执行完毕，导致用户面对空白页面等待过久。
- **现代最佳实践：放在 `<body>` 元素末尾（`</body>` 前）**
  - **优点**：浏览器先完整渲染页面的结构和样式，让用户第一时间看到内容，然后再加载和执行脚本（进行事件绑定、数据获取等交互逻辑），极大改善加载性能和用户体验。
- **折中策略：配合 `defer` 放在 `<head>` 中**
  - 如果页面某些内容必须依赖 JS 才能显示，可以将脚本放在 `<head>` 中并加上 `defer` 属性。这样既不阻塞渲染，又能尽早开始下载脚本。

## 6. 课程总结 *Content-[09:15]
- `<script>` 标签是连接 HTML 和 JS 的核心桥梁，用于嵌入代码或引用外部文件。
- `async` 和 `defer` 是必须掌握的性能优化属性，可使脚本下载不阻塞页面解析。
- 在两者中，`defer` 能够保证执行顺序且在 DOM 渲染后执行，适用性更广，是大多数情况下的首选方案。
- 从实践角度，将脚本放到 `<body>` 标签底部是保证用户尽快看到页面内容的最简单、最有效的方法。
