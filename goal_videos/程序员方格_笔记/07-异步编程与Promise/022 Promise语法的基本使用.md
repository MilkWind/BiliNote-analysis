## 异步编程与回调地狱 *Content-[00:00]

- **异步编程的概念**：在异步代码执行之后，继续接续执行其他的功能代码。
- **同步与异步的执行顺序**：在 JavaScript 中，同步代码会先执行，执行完毕后才会去执行异步代码（涉及宏任务、微任务以及任务队列机制）。因此，无法使用同步代码的思维，通过直接返回返回值的方式去获取异步代码的结果。
- **传统解决方案：回调函数（Callback）**：由于异步代码执行时同步代码早已执行完毕，以前只能通过传入回调函数的方式，在异步代码执行完成后触发后续逻辑。
- **回调地狱（Callback Hell）**：如果需要在第一个异步操作的回调函数中，继续调用第二个异步代码，就会产生第二个回调函数；以此类推，会导致回调函数层层嵌套。当嵌套过深时，就会形成“回调地狱”，导致代码极难阅读和维护。

## Promise 的核心概念与常见误区 *Content-[02:47]

- **Promise 的定义**：Promise 是 ES6 引入的一种异步编程解决方案，主要用于解决回调地狱问题，让多个异步代码能够按顺序优雅地执行。
- **面试避坑指南（常见误区）**：
  - **错误回答**：Promise 是为了解决回调函数。
  - **正确回答**：Promise 解决的是**回调地狱**（即回调函数嵌套回调函数的问题），而不是消灭回调函数。
  - **深度解析**：回调函数本身依然广泛应用于事件监听等场景，Promise 并没有干掉回调函数。如果没有回调地狱问题，使用 Promise 或回调函数的区别不大，但在现代前端开发中，建议统一使用 Promise 来优化异步代码的结构。

## Promise 的基本语法与使用步骤 *Content-[06:39]

Promise 的基本使用分为以下几个核心步骤：

- **步骤 1：创建 Promise 对象**
  - 使用 `new Promise()` 创建一个 Promise 实例。
- **步骤 2：传入回调函数及参数**
  - 在 `new Promise()` 的构造函数中传入一个回调函数。
  - 该回调函数接收两个参数：`resolve` 和 `reject`（参数名可以自定义，但官方强烈建议使用这两个名称以保持代码规范）。
  - 在回调函数内部编写异步代码（如 `setTimeout`）。*注意：虽然内部可以写同步代码，但这完全失去了使用 Promise 解决异步问题的意义。*
- **步骤 3：状态改变与结果传递**
  - 当异步代码执行顺利并产生正确结果时，调用 `resolve()` 函数，并将正确结果作为参数传入。
  - 当异步代码执行出错并产生错误结果时，调用 `reject()` 函数，并将错误结果作为参数传入。
  - *注：代码执行正确或错误的判断逻辑由开发者自行编写（例如使用 `if` 条件判断），Promise 本身只负责提供这两个“接口”。*
- **步骤 4：使用 `then` 方法处理成功结果**
  - 使用 Promise 实例调用 `.then()` 方法。
  - `.then()` 接收一个回调函数，该回调函数的参数即为 `resolve()` 传递过来的正确结果。
  - **执行机制**：Promise 内部的异步代码执行完毕并调用 `resolve` 后，才会触发外部 `.then()` 中匹配的回调函数。如果不写 `.then()`，内部异步代码依然会正常执行，但外部无法获取和处理结果。
- **步骤 5：使用 `catch` 方法处理错误结果**
  - 使用 Promise 实例调用 `.catch()` 方法。
  - `.catch()` 接收一个回调函数，该回调函数的参数即为 `reject()` 传递过来的错误结果。
  - 当内部调用 `reject()` 时，会触发外部 `.catch()` 中匹配的回调函数，用于捕获和处理异常。

## Promise 实际案例：封装异步求和函数 *Content-[15:11]

通过一个实际需求来巩固 Promise 的语法应用。

- **需求说明**：
  - 封装一个函数，接收两个参数。
  - 使用定时器（模拟异步操作）进行两个参数的求和运算，并返回结果。
  - 如果任意一个参数不是数字格式，则判定为错误，匹配错误结果。
- **代码实现逻辑**：
  - 函数内部必须 `return new Promise(...)`。因为 Promise 对象需要在外部通过 `.then()` 和 `.catch()` 来匹配结果，如果不返回，外部将无法调用这些方法。
  - 在 Promise 内部使用 `setTimeout` 模拟 1 秒的异步延迟。
  - 使用 `typeof` 判断传入的两个参数是否均为 `number`。
  - 如果都是数字，计算求和结果，并调用 `resolve(result)` 传递正确结果。
  - 如果存在非数字，调用 `reject('参数错误')` 传递错误信息。
- **调用与测试**：
  - 调用函数并传入数字（如 `sum(1, 2)`），使用 `.then(res => console.log('计算结果:', res))` 接收并打印结果。
  - 使用 `.catch(err => console.log(err))` 接收并打印错误信息。
  - 当传入非数字（如 `sum('a', 2)`）时，会成功触发 `.catch()` 并输出“参数错误”。

## AI 总结 *Content-[22:43]

Promise 是 ES6 中解决异步编程回调地狱问题的核心方案。它通过 `new Promise()` 封装异步操作，并利用 `resolve` 和 `reject` 来传递执行结果。外部通过链式调用 `.then()` 处理成功状态，通过 `.catch()` 处理失败状态。在面试中，务必明确 Promise 解决的是“回调地狱”而非“回调函数”本身。掌握 Promise 的基本语法和状态流转机制，是进阶前端异步编程（如 `async/await`）的必经之路。
