## 1. mouseover 的使用场景与事件委托 *Content-[00:00]

### 案例：动态商品列表悬浮效果
- **场景描述**：页面中存在一个商品列表（如包含三个初始商品，且支持动态添加新商品）。当鼠标悬浮到单个商品上时，要求该商品显示橙色边框。
- **技术选择**：必须使用 `mouseover` 事件，而不能使用 `mouseenter`。

### 为什么必须使用 mouseover？
1. **动态元素的事件绑定需求**：因为商品列表是动态创建的，为了保证新添加的元素也能拥有悬浮事件，必须使用**事件委托**。
2. **事件委托的核心原理**：事件委托依赖于**事件冒泡**机制。
3. **事件冒泡的支持差异**：
   - `mouseover` 支持事件冒泡。
   - `mouseenter` 不支持事件冒泡。
4. **代码实现逻辑**：在代码中，事件被绑定在父元素（如 `goods-list`）上，而不是直接绑定在子元素（商品项）上。这就是典型的事件委托。
   - 如果使用 `mouseover`：子元素触发的事件会冒泡到父元素 `goods-list`，从而成功触发事件并添加橙色边框（无论是原有商品还是新增商品）。
   - 如果使用 `mouseenter`：由于不产生冒泡，父元素 `goods-list` 无法捕获到子元素的移入事件，导致事件无法触发，所有商品（包括原有的和新增的）都不会出现橙色边框。

**结论**：当业务场景涉及到**事件委托**（需要监听动态创建的子元素）时，必须使用支持冒泡的 `mouseover`。

## 2. mouseenter 的使用场景与防闪烁 *Content-[03:20]

### 案例一：京东左侧导航菜单
- **场景描述**：鼠标悬浮在左侧一级菜单上时，右侧会出现对应的二级菜单。布局上通常是一个大盒子（一级菜单区域）内部包含小盒子（二级菜单区域）。
- **交互需求**：鼠标进入一级菜单（大盒子）时触发显示二级菜单；当鼠标从一级菜单移入二级菜单（小盒子）时，**不希望再次触发事件**，即只希望触发一次。
- **技术选择**：必须使用 `mouseenter`。
- **错误使用的后果**：如果使用 `mouseover`，当鼠标从大盒子移入内部小盒子时，会再次触发事件，导致二级菜单在移入瞬间出现**闪烁**问题。`mouseenter` 不冒泡，进入子元素时不会重复触发父元素的事件，完美解决闪烁问题。

### 案例二：大盒子嵌套小盒子布局
- **场景描述**：通用的前端布局中，经常会有“大盒子套小盒子”的结构。
- **交互需求**：移入大盒子时触发某个效果，从大盒子移入小盒子时不再触发。
- **技术选择**：同样使用 `mouseenter`。使用 `mouseover` 会导致由大盒子移入小盒子时重复触发事件，引发 UI 闪烁。

**结论**：当业务场景是**嵌套结构**，且只需要监听父元素（大盒子）的移入/移出，不希望子元素（小盒子）的移入/移出重复触发事件时，必须使用不冒泡的 `mouseenter`。

## 3. mouseover 与 mouseenter 核心区别总结 *Content-[05:20]

以下是 `mouseover` 与 `mouseenter` 及其对应离开事件的核心维度对比：

| 对比维度 | mouseover / mouseout | mouseenter / mouseleave |
| :--- | :--- | :--- |
| **核心特性** | **支持**事件冒泡 | **不支持**事件冒泡 |
| **对应离开事件** | `mouseout` (支持冒泡) | `mouseleave` (不支持冒泡) |
| **触发场景** | 鼠标移入元素**本身及其子元素**都会触发 | 仅鼠标移入元素**本身**时触发（不冒泡） |
| **触发频率** | 移入/移出子元素时会**频繁触发** | 进入元素区域**仅触发一次** |
| **事件委托实用性**| **支持**事件委托（符合冒泡原理） | **不支持**事件委托（无法冒泡到父元素） |
| **性能表现** | 存在子元素时性能**稍差**（频繁触发） | 性能**更优**（触发次数少） |
| **适用场景** | 需监听子元素移入移出（如：批量商品列表项） | 仅监听父元素移入移出（如：导航菜单、嵌套盒子） |

## 4. 补充知识：relatedTarget 属性详解 *Content-[07:26]

在鼠标移入/移出事件中，事件对象提供了一个 `relatedTarget` 属性，用于获取与事件相关的另一个元素：

- **在鼠标移入事件中（如 `mouseover`）**：
  `relatedTarget` 指的是鼠标**离开的元素**（即从哪个元素移入当前元素的）。
- **在鼠标移出事件中（如 `mouseout`）**：
  `relatedTarget` 指的是鼠标**要去的元素**（即从当前元素移入到哪个元素）。
- **特殊情况**：
  如果鼠标是从浏览器窗口外部移入，或者移出到浏览器窗口外部，`relatedTarget` 的值将为 `null`。
