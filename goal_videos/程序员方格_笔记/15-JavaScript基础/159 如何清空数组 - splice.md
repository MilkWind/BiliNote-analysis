## 3. 方法一：使用 splice 清空数组 *Content-[02:19]
### 3.1 splice 方法简介
- `splice` 被称为数组的“万能修改器”。
- **主要功能**：可以删除、添加以及替换数组元素。

### 3.2 语法与用法
- **基本语法**：`array.splice(startIndex, deleteCount)`
  - 第一个参数：起始下标（`startIndex`）。
  - 第二个参数：删除个数（`deleteCount`）。
- **清空数组的实现**：
  - 起始下标设为 `0`。
  - 删除个数设为数组的长度 `arr.length`。
  - **代码示例**：`arr.splice(0, arr.length)`。

### 3.3 核心特点：引用关系
- **不断开引用关系**：使用 `splice` 清空数组时，不会断开数组的引用关系。
- **内存地址**：原数组和指向它的新数组引用的是同一个内存地址。
- **连带效应**：清空原数组的同时，所有指向该内存地址的变量（新数组）都会被同步清空。
  - *通俗比喻*：就像你和同桌共用一个文具盒，你把文具盒里的笔全拿走了，同桌打开文具盒时也是空空如也。

### 3.4 代码示例演示
```javascript
// 定义原数组
let arr = [1, 2, 3, 4, 5];

// 将 arr 赋值给 newArr（此时两者指向同一内存地址）
let newArr = arr;

// 使用 splice 清空原数组
arr.splice(0, arr.length);

// 打印结果
console.log(arr);    // 输出: [] (原数组被清空)
console.log(newArr); // 输出: [] (新数组也被同步清空)
```
