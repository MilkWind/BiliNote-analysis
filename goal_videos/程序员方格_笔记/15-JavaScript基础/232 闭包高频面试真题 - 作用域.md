## 核心基础：函数的作用域 *Content-[02:51]

要理解闭包，首先必须搞定**函数的作用域**，这是闭包存在的基础。

作用域相当于变量的使用范围。在 JS 中，变量有自己的使用范围，超出范围就不能使用。我们重点需要掌握以下两种作用域：

- **全局作用域**：在所有函数外面定义的变量。整个代码里都能使用，相当于“小区公共区域”，所有人都能用到。
- **局部作用域（函数作用域）**：在函数里面定义的变量。只有这个函数内部能使用，函数外面不能用，相当于“自己家”，只有自己能用。

## 作用域代码实战与规则总结 *Content-[04:52]

通过以下代码示例，可以清晰地验证作用域的核心规则：

```javascript
// 定义全局变量（全局作用域）
let globalNum = 100; 

function fn() {
    // 定义局部变量（局部作用域/函数作用域）
    let localNum = 200; 
    
    // 函数内部能访问全局变量（相当于自己家能用到小区公共区域的东西）
    console.log(globalNum); // 输出: 100 
    
    // 函数内部能访问自己的局部变量（相当于自己家能用到自己的东西）
    console.log(localNum);  // 输出: 200 
}

fn(); // 调用函数

// 全局环境中访问全局变量
console.log(globalNum); // 输出: 100 （没有问题）

// 全局环境中访问局部变量
console.log(localNum);  // 报错: localNum is not defined （不能访问邻居家的东西）
```

**作用域核心规则总结：**
- 函数内部**能**访问全局变量。
- 函数外部**不能**访问函数内部的局部变量。

牢记这句话，这是作用域的核心规则，也是后续理解闭包原理的前提。

## 全局变量与局部变量的痛点与闭包的诞生 *Content-[10:35]

在实际开发中，全局变量和局部变量都存在各自的缺点：

- **全局变量的缺点**：容易造成全局污染，而且不会被 GC（Garbage Collection，垃圾回收机制）所回收，长期占用内存。
- **局部变量的缺点**：无法共存，不能长久保存。函数执行完毕后，局部变量就会被销毁。

**闭包的引入：**
为了使变量既可以**共存、长久保存**，又**不会造成全局污染**，我们就可以使用**闭包**。闭包完美地解决了全局变量和局部变量的痛点，是 JS 中非常重要的特性。
