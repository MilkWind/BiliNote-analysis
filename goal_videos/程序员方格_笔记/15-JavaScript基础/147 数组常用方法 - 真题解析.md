## 1. 第一题：JS数组增删改查常用方法 *Content-[00:00]
- **核心考点**：列举 JS 数组增删改查的常用方法，说明每个方法是否修改原数组以及返回值是什么。
- **面试建议**：
  - 数组方法是高频必问的基础面试题，对于中大厂面试尤为重要。基础题答错会直接影响面试结果，而高阶题（如 WebSocket）不会则影响较小。
  - 不需要死记硬背所有方法，每类（增、删、改、查）记住 2-3 个即可，但必须清楚它们**是否修改原数组**以及**返回值是什么**。
- **常用方法总结**：
  - **增**：
    - `push`：修改原数组，返回新长度。
    - `unshift`：修改原数组，返回新长度。
  - **删**：
    - `pop` / `shift`：修改原数组，返回被删除的元素。
    - `splice`：修改原数组，返回被删除元素组成的数组。
  - **改**：
    - `splice`：修改原数组，返回被删除元素组成的数组。
  - **查**：
    - `concat`：不修改原数组，返回新数组。
    - `slice`：不修改原数组，返回新数组。

## 2. 第二题：splice 与 slice 的核心区别 *Content-[02:14]
- **核心区别**：是否修改原数组。`splice` 会修改原数组，而 `slice` 不会。
- **参数含义**：
  - `splice(start, deleteCount, item1, item2...)`：从 `start` 开始，删除 `deleteCount` 个元素，并可选择插入新元素。
  - `slice(start, end)`：截取从 `start` 到 `end` 的元素，**含头不含尾**。
- **返回值**：
  - `splice`：返回被删除元素组成的数组。
  - `slice`：返回截取后的新数组。
- **使用场景**：
  - `splice`：适用于需要修改原数组的增、删、改操作（如在任意位置添加、删除、修改元素）。
  - `slice`：适用于不需要修改原数组的截取操作，或用于数组的浅拷贝（如获取数组部分元素、复制数组）。

## 3. 第三题：forEach、map 与 filter 的区别 *Content-[03:14]
- **返回值与长度**：
  - `forEach`：返回 `undefined`。
  - `map`：返回新数组，新数组长度与原数组**一致**（一对一映射）。
  - `filter`：返回新数组，新数组长度**小于等于**原数组（根据条件筛选）。
- **用途**：
  - `forEach`：仅用于纯遍历执行操作。
  - `map`：用于数据格式化（如将数组元素统一乘以 2 或 3）。
  - `filter`：用于数据筛选（如找出所有偶数、奇数或大于 3 的数）。
- **为什么 forEach 没有返回值**：
  - 设计初衷就是纯遍历执行操作，而非返回新数据。如果需要返回新数据，应使用 `map` 或 `filter`。

## 4. 第四题：sort 方法的排序坑点与实现 *Content-[04:31]
- **默认排序坑点**：
  - `sort` 默认按字符串的 Unicode 码点进行排序。
  - 对数字排序会出现错误，例如 `12` 会排在 `2` 的前面（因为字符 `'1'` 的 Unicode 码小于 `'2'`）。
- **解决方法**：
  - 传入自定义排序的比较函数。
  - **正序（从小到大）**：`(a, b) => a - b`
  - **倒序（从大到小）**：`(a, b) => b - a`

## 5. 第五题：reduce 方法的参数、原理与应用 *Content-[05:09]
- **参数解析**：
  - `prev` (accumulator)：上次回调函数累计的结果。
  - `curr` (currentValue)：当前元素。
  - `index`：当前下标。
  - `initialValue`：累计初始值（可选，但**强烈建议必传**，因为它会影响初始状态和类型）。
- **底层原理**：
  - 遍历数组，将每个元素与 `prev` 进行累计计算，最终返回结果。支持任意类型的累积。
- **常见应用实现**：
  - **数组求和**：`prev + curr`。
  - **数组去重**：判断 `prev`（已 push 过的元素集合）中是否包含 `curr`（使用 `includes`）。如果不包含则 `push`，最后返回 `prev`。初始值设为空数组 `[]`。
  - **数组扁平化**：判断 `curr` 是否为数组（`Array.isArray(curr)`）。如果是，则递归调用 `reduce` 进行无限级打平；如果不是，则直接返回/拼接 `curr`。

## 6. 第六题：Array.of 与 new Array 的区别 *Content-[07:13]
- **核心区别（单个数字参数时）**：
  - `Array.of(7)`：返回包含一个元素 `7` 的数组 `[7]`。
  - `new Array(7)`：返回长度为 7 的空数组（坑点：单个数字参数表示数组长度，而非元素，易造成混淆）。
- **多参或无参时**：
  - 两者均返回由参数组成的数组或空数组。
- **弥补不足**：
  - `Array.of` 始终返回由参数组成的数组，行为统一，避免了 `new Array` 构造函数的参数坑点。
- **建议**：创建数组时，除了字面量 `[]`，推荐使用 `Array.of`。

## 7. 第七题：Array.from 的作用与转换对象 *Content-[08:06]
- **作用**：将伪数组或可迭代对象转为真正的数组，使其能够调用数组的所有方法。
- **可转换的对象**：
  - DOM 元素集合。
  - 函数的 `arguments` 对象。
  - 字符串。
  - `Set` 和 `Map` 数据结构。
  - 所有部署了 `Iterator` 接口的对象。

## 8. 第八题：some 与 every 的核心区别 *Content-[08:37]
- **返回值**：两者均返回布尔值（`true` 或 `false`）。
- **核心差异**：
  - `some`（一真即真）：数组中**至少有一个**元素符合条件就返回 `true`。具有短路特性，找到一个 true 后后续不再遍历。
  - `every`（一假即假）：数组中**所有元素**都符合条件才返回 `true`。具有短路特性，遇到一个 false 后后续不再遍历。

## 9. 第九题：数组扁平化与 flat 方法 *Content-[09:07]
- **简单实现**：直接使用 `flat()` 方法。
  - 传入 `Infinity` 可实现无限层级扁平化。
- **兼容写法**：
  - 若环境不支持 `flat`，可结合 `reduce` 和 `concat` 实现。
  - 注：现代开发中通常有构建工具处理兼容性，无需过度担忧，但需了解原理。
- **flat 用法**：
  - 传入展开深度，默认展开一层（`1`），传入 `Infinity` 展开所有层。
- **避坑点**：
  - `flat` 方法会**自动移除数组中的空项**（empty slots），开发中需特别注意。

## 10. 第十题：数组方法分类及查找方法对比 *Content-[10:07]
- **修改原数组 vs 不修改原数组**：
  - **修改原数组**：`push`, `pop`, `shift`, `unshift`, `splice`, `sort`, `reverse` 等（任选 5 个）。
  - **不修改原数组**：`concat`, `slice`, `map`, `filter`, `reduce`, `flat`, `join` 等（任选 5 个）。
- **indexOf 与 includes 的区别**：
  - `indexOf`：返回元素的下标，找不到返回 `-1`。适合需要查找下标的场景。
  - `includes`：返回布尔值（`true`/`false`）。语义更直观（“是否包含”），适合仅判断是否存在的场景。
- **find 与 findIndex 的区别**：
  - `find`：返回第一个匹配的元素**值**。
  - `findIndex`：返回第一个匹配元素的**下标**。
  - **共性**：均支持传入自定义条件函数，适合处理复杂数据类型（如从对象数组中查找特定对象）。

## 11. 第十一题：join 与 toString 的区别 *Content-[11:11]
- **核心区别**：
  - `join`：可自定义分隔符（如中划线 `-`、下划线 `_`、星号 `*` 等）。
  - `toString`：仅能返回以逗号 `,` 分隔的字符串。等价于 `join(',')`。
- **null 和 undefined 的处理**：
  - 在 `join` 和 `toString` 转换中，`null` 和 `undefined` 都会被转为**空字符串**（相当于被忽略/干掉了）。
