## 1. Set 简介与核心特性 *Content-[00:01]

`Set` 是 ES6 引入的核心数据结构，专门用于存储唯一值的集合。它在数组去重、成员检测以及集合运算等场景中具有不可替代的作用，能够使代码变得更加简洁高效。

**核心特性：**
1. **值的唯一性**：`Set` 不允许重复值。当尝试添加已存在的值时，该操作会被忽略。这一特性使其成为数组去重的最佳选择。
2. **保持插入顺序**：虽然 `Set` 不像数组那样有数字索引，但它严格保持元素的插入顺序。遍历时，元素会按照被添加的先后顺序依次取出。
3. **支持任意类型**：`Set` 可以存储基本数据类型和引用数据类型。

**基本使用示例：**
```javascript
const mySet = new Set();
mySet.add(1);
mySet.add(1); // 由于唯一性，第二次添加被忽略
mySet.add(2);
mySet.add(3);

console.log(mySet.size); // 输出 3，而不是 4
```
*注：通过 `size` 属性可以直接获取集合中元素的数量，这与 `Map` 的行为一致。*

## 2. Set 与 Array 的对比 *Content-[02:20]

为了更好地理解 `Set` 的价值，将其与最常用的 `Array` 进行对比：

| 特性 | Array (数组) | Set (集合) |
| :--- | :--- | :--- |
| **重复值处理** | 保留所有元素（包括重复项）。 | 自动过滤重复值，只保留唯一值。 |
| **元素访问** | 支持通过数字索引快速访问特定位置的元素。 | 不支持通过索引访问（本质是集合而非有序列表）。 |
| **成员检测** | 使用 `includes()` 方法，需遍历整个数组，时间复杂度为 $O(N)$，大数据量时效率较低。 | 使用 `has()` 方法，时间复杂度为 $O(1)$，无论集合多大，检测速度都极快。 |

## 3. Set 的核心 API 与操作 *Content-[03:50]

`Set` 的方法设计简洁且语义明确，主要包含以下操作方法和属性：

**操作方法：**
- `add(value)`：向集合中添加一个值。如果值已存在则被忽略。**返回 `Set` 实例本身**，因此支持链式调用。
- `has(value)`：检测某个值是否存在于集合中，返回布尔值。这是 `Set` 最常用且性能最好的方法之一（$O(1)$ 复杂度）。
- `delete(value)`：删除指定的值。删除成功返回 `true`，值不存在则返回 `false`。
- `clear()`：一次性清空整个集合。

**属性：**
- `size`：返回集合中元素的数量，时间复杂度为 $O(1)$。

**综合代码示例：**
```javascript
const colors = new Set();
// 链式调用添加元素
colors.add('red').add('green').add('blue');

console.log(colors.size); // 3
console.log(colors.has('red')); // true

colors.add('red'); // 重复添加被忽略
console.log(colors.size); // 仍为 3

colors.delete('blue'); // 删除成功
console.log(colors.size); // 2
console.log(colors.has('blue')); // false
```

## 4. Set 的遍历与迭代方法 *Content-[06:15]

`Set` 是一个可迭代对象，严格遵守插入顺序。它提供了多种便利的遍历方式：

1. **`values()` 方法**：返回一个包含 `Set` 所有值的迭代器，可直接在 `for...of` 循环中使用，输出顺序与添加顺序完全一致。
2. **`keys()` 方法**：由于 `Set` 不存在键值对的概念，`keys()` 返回的内容与 `values()` 完全相同。这种设计是为了让 `Set` 和 `Map` 的 API 保持一致性。
3. **`forEach()` 方法**：与数组的 `forEach` 非常相似，接受一个回调函数。在 `Set` 的 `forEach` 中，回调函数的第一个参数就是值本身。
4. **直接使用 `for...of`**：`Set` 默认的迭代器就是 `values` 迭代器，因此可以直接遍历 `Set` 实例，代码非常简洁优雅。

```javascript
const set = new Set([1, 2, 3]);

// 方式一：values()
for (const value of set.values()) {
  console.log(value);
}

// 方式二：直接 for...of (默认调用 values 迭代器)
for (const item of set) {
  console.log(item);
}

// 方式三：forEach
set.forEach((value) => {
  console.log(value);
});
```

## 5. Set 的典型应用场景 *Content-[07:55]

**1. 数组去重**
这是 `Set` 最经典的应用。通过 `new Set()` 将数组转换为 `Set` 实现自动去重，再用扩展操作符转回数组。
```javascript
const arr = [1, 2, 2, 3, 3, 4];
const uniqueArr = [...new Set(arr)]; // [1, 2, 3, 4]
```

**2. 字符串去重**
字符串是可迭代的，同样可以利用 `Set` 去除重复字符。
```javascript
const str = "hello";
const uniqueStr = [...new Set(str)].join(''); // "helo"
```

**3. 集合运算**
- **并集**：将两个 `Set` 展开到新数组中，再转为新的 `Set`。
  ```javascript
  const setA = new Set([1, 2, 3]);
  const setB = new Set([3, 4, 5]);
  const union = new Set([...setA, ...setB]); // Set(5) {1, 2, 3, 4, 5}
  ```
- **交集**：找出两个集合的共有元素。利用 `filter` 和 `has` 方法，性能极佳。
  ```javascript
  const intersection = new Set([...setA].filter(x => setB.has(x))); // Set(1) {3}
  ```
- **差集**：找出存在于 `setA` 但不存在于 `setB` 的元素。
  ```javascript
  const difference = new Set([...setA].filter(x => !setB.has(x))); // Set(2) {1, 2}
  ```

## 6. Set 与 Array 的转换及实用技巧 *Content-[10:22]

**Array 转 Set：**
直接将数组作为参数传给 `new Set()` 构造函数。
```javascript
const arr = [1, 2, 3];
const set = new Set(arr);
```

**Set 转 Array：**
1. **扩展操作符**（最常用、最简单）：
   ```javascript
   const arrFromSet = [...set];
   ```
2. **`Array.from()` 方法**：可将任何可迭代对象转换为数组。
   ```javascript
   const arrFromSet2 = Array.from(set);
   ```

**实用技巧：数组去重并排序**
结合 `Set` 去重和数组的 `sort()` 方法，通过链式调用实现优雅的数据处理：
```javascript
const messyArr = [3, 1, 2, 2, 3, 1];
const sortedUniqueArr = [...new Set(messyArr)].sort(); // [1, 2, 3]
```

## AI 总结 *Content-[11:46]

`Set` 是 JavaScript 中处理唯一值集合的强大工具。其核心优势在于**值的唯一性**和 **$O(1)$ 时间复杂度的成员检测（`has`）**，这使其在数组/字符串去重以及高频成员查找场景中远超传统 `Array`。虽然 `Set` 不支持索引访问，但其提供的 `add`、`delete`、`clear` 等 API 以及丰富的迭代方法（`values`、`forEach`、`for...of`）使其操作极为便捷。熟练掌握 `Set` 与 `Array` 之间的相互转换（扩展运算符、`Array.from`），并能灵活运用其进行并集、交集、差集等集合运算，是前端开发中提升代码质量与执行效率的关键技能。
