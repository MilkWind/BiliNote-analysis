## const 声明常量及报错解析 *Content-[00:01]
- **常量定义**：`const` 用于声明常量，常量的值是不可以改变的变量。
- **错误示例**：
  ```javascript
  const q = 99;
  q = 20; // 尝试重新赋值，会报错
  ```
- **报错信息解析**：控制台会提示 `Assignment to constant variable`。
  - `assignment`：赋值。
  - `assignment to`：给...赋值。
  - `constant variable`：常量变量。
  - **实际含义**：尝试给一个常量进行变量赋值，即将一个常量当做变量进行重新赋值，这是语法错误。

## const 的实际应用意义 *Content-[01:48]
- **防止篡改**：在程序中，有些关键数据（如内置的访问外部资源的网址）是不允许被篡改的。
- **安全保护**：使用 `const` 进行常量声明，可以防止恶意代码注入并修改这些关键变量，从而避免导致程序后续代码执行出现错误，保证程序的安全性。

## const 的使用注意点 *Content-[02:21]
`const` 的使用注意点与 `let` 完全一模一样，没有任何区别，同时增加了一条自身特有的属性：
- 不存在变量提升。
- 声明的变量即使在全局，也不会挂载到 `window` 对象上面。
- 在函数里面会形成暂时性死区（TDZ）。
- 不允许重复声明。
- **特有属性**：`const` 声明的变量值不可以被更改。

## const 的本质与引用数据类型 *Content-[02:50]
- **本质**：`const` 实际保证的并不是变量的值不可改动，而是**变量指向的那个内存地址所保存的数据不得改动**。
- **基本数据类型**：值直接保存在变量指向的内存地址中，因此值不可以被更改。
- **引用数据类型（对象、数组等复合类型）**：
  - 变量指向的内存地址保存的只是一个指向性的指针。
  - `const` 只能保证这个指针（内存地址）是固定的，但地址里面的数据是可以被更改的。
  - **代码示例**：
    ```javascript
    const pr = { name: '小黑', age: 16 };
    pr.name = '小飞机'; // 成功，修改了地址内部的内容
    console.log(pr);
    
    pr = { name: '新对象' }; // 报错，尝试修改内存地址
    ```
  - **生动比喻**：`const` 声明引用数据类型就像是被绑定在了房子里。你**不可以搬家**（内存地址不可变），但是**家里面的家具可以更换、结构可以改造**（地址内部的数据可变）。

## 面试题：JS 声明变量的方式 *Content-[04:58]
- **常见误区**：很多同学在面试时被问到“ES6/JS 声明变量的几种方式”，只能想到 `var`、`let`、`const`，最多多想一个 `function`。
- **完整答案**：在 JS（包含 ES6）中，声明变量的方式共有 6 种：
  1\. `var`
  2\. `let`
  3\. `const`
  4\. `function`
  5\. `import`
  6\. `class`
- **注意**：回答时一定要明确 JS 包含 ES6 规范，不要遗漏 `import` 和 `class`。
