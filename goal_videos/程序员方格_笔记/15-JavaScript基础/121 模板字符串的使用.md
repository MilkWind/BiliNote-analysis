## ES6 字符串扩展概述 *Content-[00:00]

## 传统字符串拼接方式及痛点 *Content-[01:00]
- **场景举例**：需要拼接一句话“我是[姓名]，我今天去[地点]买了[数量]个[礼物]作为我的生日礼物”。
- **变量定义与避坑**：
  - 定义变量 `name`、`address`、`num`、`gift`。
  - **注意**：避免使用 `location` 作为变量名，因为它是 `window` 对象的关键属性（`window.location`），在全局作用域下会产生冲突，建议改用 `address`。
- **传统拼接技巧**：观察字符串最外层是单引号还是双引号，采用“同引号断开加加”的方式（例如：`"我是" + name + "，我今天去" + address`）。
- **痛点分析**：
  - 当字符串很长（如一整篇文章）时，频繁的 `+` 号拼接会导致代码结构混乱。
  - 传统字符串不能直接回车换行。虽然部分 IDE（如 WebStorm）会自动帮你拼接换行符，但 VS Code 默认不会，导致代码可读性极差，维护困难。

## ES6 模板字符串基础语法与特性 *Content-[04:30]
- **语法定义**：使用**反引号**（`` ` ``，键盘数字 1 左侧、与波浪号 `~` 同键的按键）包裹字符串，因此也被称为反引号字符串。
- **核心特性**：
  1\. **支持多行换行**：可以在反引号内随意回车换行，且换行符会被原样记录并输出，无需手动拼接，代码排版更加规整。
  2\. **变量插值**：使用 `${变量名}` 的语法直接在字符串中插入变量，彻底告别 `+` 号拼接。
- **代码示例**：
  ```javascript
  let name = "小飞机";
  let address = "飞机场";
  let num = 15;
  let gift = "空客A380";

  let sStr = `我是${name}，
  我今天去${address}，
  买了${num}个${gift}作为我的生日礼物`;
  
  console.log(sStr); // 输出时会保留换行格式
  ```

## 模板字符串的实际应用场景 *Content-[09:30]
- **动态生成 DOM 结构**：在前端开发中，经常需要向页面动态插入 HTML 代码，这是模板字符串最能发挥魅力的场景。
- **场景举例**：获取页面中的 `div` 元素，并通过 `innerHTML` 插入包含动态变量的 HTML 内容。
- **优势体现**：当需要插入的 HTML 代码较多且包含动态变量时，使用模板字符串可以保持 HTML 标签结构的完整性，变量插入直观方便，极大提升了开发效率。
- **代码示例**：
  ```javascript
  let box = document.getElementById('box');
  
  box.innerHTML = `
    <h1>${name}</h1>
    <p>我今天去${address}买了${num}个${gift}</p>
  `;
  ```
