## DOM0 事件模型与行内绑定 *Content-[02:14]

`DOM0` 事件模型是 JavaScript 最早的事件模型。关于事件绑定，它主要分为两种方式：**行内绑定**和**动态绑定**。

- **行内绑定**：
  - 直接在 HTML 标签里写事件属性，将函数名作为属性值。
  - **示例**：在 `<button>` 元素上绑定 `click` 事件，直接将函数名放入 `onclick` 属性中，如 `<button onclick="fn()">点击</button>`。
  - 这种方式无需通过 JS 获取 DOM 元素，点击按钮即可触发 `alert` 等函数逻辑。

## 行内绑定的优缺点 *Content-[03:36]

- **优点**：
  - **简洁**：无需获取 DOM 元素。
  - **门槛低**：不用懂复杂的 JS 语法。
  - **适合快速测试**：非常适合用来快速测试事件是否绑定成功，或者测试一些简单的事件逻辑，操作方便。

- **缺点**：
  - **不符合 W3C 规范**：HTML（结构）和 JS（行为）没有分离，而是混在了一起。
  - **不方便维护**：如果 JS 中的函数名修改了（例如从 `fn` 改为 `fn1`），那么 HTML 中 `onclick` 的属性值也必须同步修改，增加了维护成本。

## DOM0 动态绑定 *Content-[05:03]

动态绑定需要先用 JS 找到 HTML 元素，然后再给该元素添加事件。

- **实现步骤**：
  1. 通过 JS 获取元素，例如使用 `document.getElementById('btn')`（除此之外还有 `querySelector` 等其他获取元素的方法）。
  2. 给获取到的元素添加点击事件或其他事件。
- **示例**：
  ```javascript
  const btn = document.getElementById('btn');
  btn.onclick = function() {
      // 事件处理逻辑
  };
  ```

## 动态绑定的优缺点与覆盖问题 *Content-[06:07]

- **优点**：
  - **符合 W3C 规范**：HTML 结构和 JS 行为完全分离。
  - **易于维护**：后期修改和维护更加方便。

- **缺点（覆盖问题）**：
  - **同一个元素只能绑定一个同类型的事件**：后面绑定的事件会覆盖前面绑定的事件。
  - **示例**：如果给同一个 `button` 元素动态绑定了两个 `onclick` 点击事件，最终只会保留最后一个执行，第一个绑定的事件会被直接覆盖掉。

## 如何移除 DOM0 事件 *Content-[07:31]

移除事件是指移除监听的事件，让浏览器的垃圾回收机制（GC）及时回收，从而提升页面性能。这是一个良好的编程习惯。

- **移除方式**：
  - 将元素的事件引用直接赋值为 `null`。
  - **示例**：`btn.onclick = null;`
  - 这种方式简单粗暴，在 `DOM0` 模型中必须掌握。执行该代码后，再次点击按钮将不再触发任何事件。

## 课后互动与思考 *Content-[08:44]

- **思考题**：`DOM0` 动态绑定多个 `click` 事件，最后会执行哪一个？
- **解析**：根据 `DOM0` 动态绑定的特性（覆盖问题），如果给同一个元素绑定了多个同类型的 `onclick` 事件，**最后只会执行最后一个**，前面的事件均会被覆盖。
