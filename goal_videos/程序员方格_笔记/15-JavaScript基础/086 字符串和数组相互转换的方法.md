## 字符串转数组：split 方法详解 *Content-[00:34]
- **核心概念**：`split` 方法用于将**字符串切割成数组**。需要注意，它不能用于切割原本就是数组的数据。
- **基本用法（按指定字符分割）**：
  - 示例：`let str = 'hello5Javascript';`
  - 操作：`str.split('5')`
  - 结果：根据指定的分隔符 `'5'` 将字符串切割成数组 `['hello', 'Javascript']`。
- **特殊用法（按每个字符分割）**：
  - 示例：`let str = 'hello world';`
  - 操作：`str.split('')` （传入空字符串）
  - 结果：将字符串的每一个字符进行切割，组成新数组 `['h', 'e', 'l', 'l', 'o', ' ', 'w', 'o', 'r', 'l', 'd']`。

## 数组转字符串：join 方法详解 *Content-[03:21]
- **核心概念**：`join` 方法用于将**数组转换成字符串**。
- **基本用法（默认逗号分隔）**：
  - 操作：`arr.join()` （不传参数）
  - 结果：默认以逗号 `,` 作为分隔符将数组元素连接成字符串。
  - **重要考点**：`arr.join()` 不传参的效果等同于 `arr.toString()`。事实上，数组的 `toString` 方法在源码底层默认调用的就是无参的 `join` 方法。
- **特殊用法（无分隔符）**：
  - 操作：`arr.join('')` （传入空字符串）
  - 结果：无分隔符的方式将数组元素直接拼接成字符串。
- **自定义用法（指定分隔符）**：
  - 操作：`arr.join('-')` （传入指定字符，如横杠）
  - 结果：以指定的横杠 `-` 作为分隔符将数组元素连接成字符串。

## 经典面试题：字符串翻转 *Content-[05:37]
- **问题背景**：在 JavaScript 中，数组拥有内置的翻转方法 `reverse()`，但**字符串没有** `reverse()` 方法，直接调用会报错。
- **解决思路**：不要重复造轮子（如使用 `for` 循环手动翻转），应利用数组的 `reverse()` 方法。结合字符串与数组的相互转换方法来实现。
- **实现步骤**：
  1. **字符串转数组**：使用 `split('')` 将字符串按每个字符切割成数组。
     - 代码：`str.split('')` （注意必须传入空字符串 `''` 才能按字符切割）。
  2. **数组翻转**：调用数组的 `reverse()` 方法将数组元素顺序颠倒。
     - 代码：`.reverse()`
  3. **数组转字符串**：使用 `join('')` 将翻转后的数组重新拼接成字符串。
     - 代码：`.join('')` （传入空字符串，确保无分隔符，还原为纯字符串）。
- **完整代码示例**：
  ```javascript
  let str = 'hello';
  let reversedStr = str.split('').reverse().join('');
  console.log(reversedStr); // 输出: 'olleh'
  ```
