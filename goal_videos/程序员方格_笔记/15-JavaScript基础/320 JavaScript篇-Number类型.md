## 课程概述与核心API介绍 *Content-[00:00]
- **核心主题**：探讨 JavaScript 中 `Number` 类型的实例方法。
- **业务场景**：在电商平台的价格显示、数据报表的统一度量等日常开发中，都离不开数字的格式化处理。
- **三大核心 API**：
  1. `toFixed`
  2. `toExponential`
  3. `toPrecision`
- **学习目标**：重点掌握这三个核心 API 的区别，并能够在合适的业务场景中运用合适的方法进行数字格式化。

## 自动装箱机制：原始类型调用方法的原理 *Content-[00:46]
- **现象**：在 JavaScript 中，像 `10` 这样的原始数值类型（primitive `number`）可以直接调用实例方法（如 `toFixed()`）。
- **底层原理**：JavaScript 引擎在后台执行了**自动装箱机制**（Auto-boxing）。
  - 引擎会临时创建一个 `Number` 对象实例。
  - 在该实例上调用相应的方法。
  - 调用完成后，立刻销毁该临时对象。
- **结果**：这种机制让开发者在使用时感觉不到原始类型和对象的区别。
- **实例方法的职责**：`Number` 的实例方法主要职责只有一个，就是将数字格式化，使其符合特定的业务规范。

## toFixed：定点表示法与小数格式化 *Content-[01:56]
- **核心功能**：将数值格式化为保留指定小数位数的字符串（定点表示法），是最常用的方法。
- **基本用法与参数**：
  - 接受一个参数，代表要保留的**小数位数**。
  - 规范要求：参数必须是 `0` 到 `20` 之间的整数（虽然部分浏览器支持更多位数，但标准开发应遵循此范围）。
- **格式化行为**：
  - **整数补零**：如果原数字是整数，会自动补零。例如：`10` 变为 `"10.00"`（假设保留2位）。
  - **小数四舍五入**：如果小数位数多于指定值，会进行四舍五入。例如：`10.005` 保留两位小数变为 `"10.01"`。
- **返回类型**：
  - 返回类型是 **`string`**，而不是 `number`。在后续进行数学计算时需特别注意，避免类型错误。
- **典型应用场景**：电商平台的价格显示、财务报表中的金额格式化等。

## toExponential：科学计数法与指数表示 *Content-[03:37]
- **核心功能**：将数值转换成指定的指数形式（科学计数法）。
- **参数含义**：参数代表**小数点后的位数**（即尾数部分的小数位数）。
- **格式化行为**：
  - **大数转换**：例如 `12345`，传入参数 `2`，结果为 `"1.23e+4"`（保留两位小数）。
  - **小数转换**：对于极小的数（如 `0.00123`），会自动转换成负指数形式，如 `"1.23e-3"`。
- **科学计数法解析**：
  - `e` 后面的数字代表 $10$ 的幂次（即 $10^n$）。
  - **正数**：表示小数点向右移动。
  - **负数**：表示小数点向左移动。
- **典型应用场景**：特定技术领域，如展示物理常数、处理 TB 级别的大数据、微米级别的极小距离等。让极大或极小的数值展示更加规范和简洁。

## toPrecision：有效数字与自动适配 *Content-[05:14]
- **核心功能**：三个方法中最灵活的一个，用于格式化有效数字。
- **参数含义**：参数代表**有效数字的总位数**（包含整数部分和小数部分）。
- **格式化行为与自动适配原理**：
  - 核心工作原理是**自动适配**：判断标准的定点表示法能否满足要求的有效数字位数，若不满足则自动切换为科学计数法。
  - **示例 1（标准格式）**：数值 `99`，要求 `2` 位有效数字，输出 `"99"`。
  - **示例 2（末尾补零）**：数值 `99`，要求 `3` 位有效数字，末尾补零变为 `"99.0"`。
  - **示例 3（切换科学计数法）**：数值 `99`，要求 `1` 位有效数字，无法用普通数字表示，自动切换为 `"1e+2"`。
  - **示例 4（大数转换）**：数值 `1234`，要求 `2` 位有效数字，因为无法用两位标准数字表示，被迫使用科学计数法，输出 `"1.2e+3"`。
- **典型应用场景**：对有效数字有严格要求的科学计算场景。

## AI 总结 *Content-[06:57]
本节课深入讲解了 JavaScript 中 `Number` 类型的三个核心实例方法：`toFixed`、`toExponential` 和 `toPrecision`。
1. **自动装箱机制**解释了原始类型为何能调用方法，引擎通过临时创建并销毁 `Number` 对象实例来实现。
2. **`toFixed`** 用于定点表示法，控制小数位数，返回字符串，常用于价格显示。
3. **`toExponential`** 用于科学计数法，控制小数点后的位数，适用于极大或极小数值的展示。
4. **`toPrecision`** 最为灵活，控制总有效数字位数，能根据数值大小自动在定点表示法和科学计数法之间切换，适用于严谨的科学计算。
掌握这三者的区别与适用场景，是前端处理复杂数据格式化和应对大厂面试的关键。
