## Object 静态方法概述与 Object.create *Content-[00:00]

在 JavaScript 中，成员分为静态成员和实例成员。实例成员是我们日常使用的对象属性和方法，而静态成员则是直接挂载在构造函数（如 `Object`）上的方法。在面试中，`Object` 提供的静态方法被问到的概率非常大。

- **Object.create**：用于实现对象继承，也可以理解为一种拷贝操作。
- **扩展知识点**：由此引申出 JS 对象的**浅拷贝**和**深拷贝**概念。这是后续面试课程的重点，建议提前查阅 MDN 或相关文档进行预习。

## Object.is 判断值相等 *Content-[01:43]

`Object.is(value1, value2)` 用于判断两个值是否为相同值，返回一个布尔值。

**判断为相同值的条件**：
- 两个值相同。
- 都是 `undefined` 或 `null`。
- 都是 `true` 或 `false`。
- 都是长度相同、字符相同、顺序相同的字符串。
- 都是同一个对象（引用地址相同）。
- 都是数字，且同为 `+0`、`-0`、`NaN`，或者除了 `+0` 和 `-0` 之外的其他相同数字。

**与 `==` 和 `===` 的核心区别**：
- `==`（双等号）：会进行隐式类型转换，可能导致非预期的行为。
- `Object.is`：比较时**不会**进行类型转换。
- `Object.is` 与 `===`（全等号）并不完全等价。唯一的区别在于处理带符号的零和 `NaN` 时：
  - `===` 将 `+0` 和 `-0` 视为相等，而 `Object.is` 认为 `+0` 和 `-0` **不相等**。
  - `===` 认为 `NaN` 不等于 `NaN`，而 `Object.is` 认为 `NaN` 等于 `NaN`。

## Object.assign 对象合并 *Content-[04:09]

`Object.assign(target, ...sources)` 用于将一个或多个源对象（原对象）的可枚举属性合并到目标对象中，并返回修改后的目标对象。

- **基本用法**：
  假设目标对象 `o = { name: '小欧', age: 16 }`，源对象 `p = { length: 18, width: 250 }`。
  执行 `Object.assign(o, p)` 后，`o` 对象会被修改，成功合并 `p` 中的属性。
- **属性冲突规则**：
  如果目标对象和源对象中存在**同名属性**，则源对象（原对象）的属性值会**覆盖**目标对象中对应的值。

## Object.keys、values 与 entries *Content-[07:21]

这三个方法是一套，用于提取和遍历对象的成员，返回值均为数组。

- **Object.keys(obj)**：将对象中所有成员的**键（属性名）** 取出，放入一个数组中返回。常用于判断对象有多少个属性（通过返回数组的 `length`）。
- **Object.values(obj)**：将对象中所有成员的**值**取出，放入一个数组中返回。
- **Object.entries(obj)**：将对象中每一个成员的**键值对**取出，放入一个小数组中（每个小数组长度为 2，即 `[key, value]`），然后将多个这样的小数组放入一个大数组中，返回一个**二维数组**。

## 对象冻结：Object.freeze 与 Object.isFrozen *Content-[11:53]

对象冻结意味着将对象“冻上”，使其状态不可变。

- **Object.isFrozen(obj)**：判断对象是否已被冻结，返回布尔值。
- **Object.freeze(obj)**：冻结指定对象。

**冻结后的限制**：
1. **无法新增属性**：尝试添加新属性会静默失败（严格模式下报错）。
2. **无法修改属性值**：尝试修改现有属性的值会失败。
3. **无法删除属性**：使用 `delete` 关键字删除属性会失败。

**关于 delete 关键字**：
- `delete obj.property` 用于删除对象属性。
- 对于**未冻结**的对象，删除成功会返回 `true`。
- 对于**已冻结**的对象，删除操作会失败，属性保留，并返回 `false`。

## 对象密封：Object.seal 与 Object.isSealed *Content-[17:00]

对象密封与对象冻结类似，但限制稍微宽松一些。

- **Object.isSealed(obj)**：判断对象是否已被密封，返回布尔值。
- **Object.seal(obj)**：密封指定对象。

**密封后的限制**：
1. **无法新增属性**：尝试添加新属性会失败。
2. **无法删除属性**：使用 `delete` 关键字删除属性会失败（返回 `false`）。
3. **可以修改属性值**：与冻结最大的区别在于，密封后的对象**允许修改**现有属性的值。
