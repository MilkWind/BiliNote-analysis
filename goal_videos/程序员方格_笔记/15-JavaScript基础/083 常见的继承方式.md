## 1. 对象混入式继承 *Content-[00:39]
在 JavaScript 中，实现继承的第一种常见方式是**对象混入式继承**（Object Mixin）。

- **核心思想**：通过遍历被继承对象的所有属性，并逐个绑定（拷贝）到新对象中。
- **实现细节**：
  - 创建一个空的目标对象 `p`（如 `let p = {}`）。
  - 使用 `for...in` 循环遍历源对象 `o` 的属性。
  - 将源对象的属性值赋给目标对象 `p` 的对应属性，即 `p[k] = o[k]`。
- **特点与局限性**：
  - 这种方式本质上属于**浅拷贝**。
  - 如果源对象 `o` 中的某个属性值仍然是对象类型，那么只会拷贝该属性的引用（即只拷贝第一层），而不会进行深层递归拷贝。

## 2. 原型替换 *Content-[01:56]
第二种继承方式是通过修改原型链来实现，称为**原型替换**。

- **核心思想**：直接将构造函数的 `prototype` 属性指向需要继承的父对象。
- **代码示例**：
  ```javascript
  function Person() {}
  Person.prototype = o; // 将原型直接指向被继承的对象 o
  let p = new Person(); // 实例化新对象
  ```
- **特点**：
  - 实现非常简单直接。
  - 新实例 `p` 可以通过原型链访问到对象 `o` 中的所有属性（如 `p.name`、`p.age` 等），这些属性都在原型链上。
  - 这种方法完全依赖于 JavaScript 的原型链机制来实现属性和方法的共享。

## 3. Object.create 与自定义封装 *Content-[02:40]
第三种方式是使用 ES5 提供的 `Object.create()` 方法，其本质依然是**原型替换**。

- **Object.create 方式**：
  - 直接调用 `let p = Object.create(o);` 即可创建一个新对象，该对象的原型指向 `o`。
- **自定义封装 create 函数**：
  - 为了理解底层原理，可以自己封装一个类似 `Object.create` 的函数。
  - **实现步骤**：
    1. 定义一个空的临时构造函数 `F`。
    2. 将 `F` 的 `prototype` 指向传入的对象 `o`。
    3. 返回 `new F()` 的实例。
  - **代码示例**：
    ```javascript
    function create(o) {
        function F() {}
        F.prototype = o;
        return new F();
    }
    let p = create(o);
    ```
  - 通过这种自定义封装，同样可以实现基于原型替换的继承效果，这也是 `Object.create` 的底层 Polyfill 实现原理。

## AI 总结 *Content-[04:02]
本次视频主要讲解了 JavaScript 中常见的几种继承实现方式：
1. **对象混入式继承**：通过 `for...in` 遍历并逐个赋值，属于浅拷贝，适用于简单的属性合并。
2. **原型替换**：直接将构造函数的 `prototype` 指向父对象，利用原型链实现继承。
3. **Object.create 及自定义封装**：ES5 提供的标准方法，本质仍是原型替换。通过自定义临时构造函数可以完美模拟其底层原理。

在实际开发和大厂面试中，理解这些继承方式的底层逻辑（尤其是原型链机制和浅拷贝/深拷贝的区别）是掌握 JavaScript 面向对象编程的关键。
