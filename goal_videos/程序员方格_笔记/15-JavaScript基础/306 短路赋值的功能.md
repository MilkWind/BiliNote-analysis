## 什么是短路赋值 *Content-[00:00]

短路赋值是 JavaScript 中一种为变量设置默认值的常见写法。
- **核心逻辑**：当变量的值为假值（falsy）时，给它赋予一个准备好的默认值；如果变量的值为真值（truthy），则保留其原有值。
- **本质**：提前准备好一个默认值，在变量为假时进行“短路”赋值，从而避免后续逻辑出错。

## 面试题解析：短路赋值的代码含义 *Content-[00:58]

在面试中，经常会遇到类似如下的代码考察：
```javascript
let a = b || 8;
// 或者
a = a || b;
```
- **代码含义**：这行代码考察的是应聘者对短路赋值的理解。`||`（逻辑或）结合赋值操作，意味着如果 `b` 为真值，`a` 就等于 `b`；如果 `b` 为假值，`a` 就会被赋值为默认值 `8`（或 `b` 的值）。
- **考察点**：看到这种赋值语句，需要立刻反应过来这是短路赋值的一种写法，并能准确解释其背后的逻辑。

## 为什么要使用短路赋值（优势） *Content-[04:11]

在早期的 JavaScript 开发中，这种写法被广泛使用，主要有以下两个原因：

1\. **为变量设置默认值**
- 常用于为变量提供默认值，有效避免 `undefined` 或 `null` 导致的程序错误。
- **示例**：在函数中接收 `name` 参数，如果未传递或为假值，则使用 `'guest'` 作为默认值。
```javascript
function greet(name) {
    name = name || 'guest';
    console.log(`Hello, ${name}`);
}
```

2\. **避免重复代码，更加简洁**
- 相比于使用三元运算符（`? :`），短路赋值的代码更加简单直接。
- 使用三元运算符需要判断多种不成立的条件（如不等于空、不等于 `0` 等），而 `||` 写法只需一行代码即可实现相同的默认值回退逻辑。

## 短路赋值的潜在问题 *Content-[07:55]

尽管短路赋值很简洁，但它存在一个明显的潜在问题：**无法区分 `0`、空字符串 `""` 和 `undefined` / `null`**。

- **问题解析**：在 JavaScript 中，`0` 和 `""` 也属于假值（falsy）。使用 `||` 时，它们会被误判为假值，从而被替换为默认值，这通常不符合业务预期。
- **错误示例**：
  - `let count = 0 || 10;`：结果 `count` 会变成 `10`，但业务上可能期望保留 `0`。
  - `let message = "" || "No message";`：结果 `message` 会变成 `"No message"`，但业务上可能期望保留空字符串 `""`。
- **结论**：我们真正想排查和拦截的通常是 `undefined` 或 `null`，而 `||` 会把所有 falsy 值一视同仁地替换掉。

## 现代替代方案：空值合并运算符 ?? *Content-[10:23]

为了解决短路赋值的潜在问题，ES2020 引入了**空值合并运算符** `??`（双问号）。

- **核心逻辑**：`??` 仅在左侧的变量为 `null` 或 `undefined` 时，才会使用右侧的默认值。
- **优势**：更加科学、安全，能够正确保留 `0`、`""` 等 falsy 值，避免意外覆盖。
- **正确示例**：
```javascript
let count = 0 ?? 10;       // 结果为 0，保留了 0
let message = "" ?? "No message"; // 结果为 ""，保留了空字符串
let user = null ?? "guest"; // 结果为 "guest"，触发了默认值
```
- **效果验证**：在函数参数传递中，传入 `0` 或 `""` 都能被正确保留，只有传入 `null` 或 `undefined` 时才会启动默认值。

## 面试总结与建议 *Content-[14:14]

在真实的面试过程中，建议按照以下思路进行全面解答：
1. **优先使用 `??`**：在现代浏览器支持的情况下，优先使用空值合并运算符 `??`，以避免意外覆盖 `0` 和空字符串。
2. **旧代码与简单场景**：如果习惯使用 `||`，需注意假值中是否包含需要保留的 `0` 和空字符串。如果有保留需求，则不能使用 `||`。
3. **回答结构**：结合短路赋值的**定义**、**代码含义**、**潜在问题**以及**现代替代方案（`??`）** 进行层层递进的分析，展现对 JavaScript 特性演进的深入理解。
