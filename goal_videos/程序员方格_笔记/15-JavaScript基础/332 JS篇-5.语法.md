## 区分大小写 *Content-[00:11]
- JavaScript 中**严格区分大小写**，这是最基础的语法要点。
- **变量名**：驼峰命名（如 `myVariable`）和全小写（如 `myvariable`）会被解析为两个完全独立的变量。
- **函数名**：例如 `myFunction` 中首字母大写的 `F` 和小写的 `f` 代表两个不同的函数。
- **操作符**：如 `typeof` 必须全小写才有效，若写成 `Typeof` 或 `TYPEOF`，JS 引擎将无法识别。
- **建议**：在编写代码时，必须养成严格区分大小写的习惯。

## 标识符 *Content-[01:05]
标识符是为变量、函数等起名字的名称，其命名需遵循以下硬性规定：
- **首字符限制**：必须是**字母**、**下划线 (`_`)** 或 **美元符号 (`$`)**。
- **后续字符限制**：从第二个字符开始，可以使用**字母**、**数字**、**下划线 (`_`)** 或 **美元符号 (`$`)**。
- **关键字限制**：绝对不能使用 JavaScript 预留的**关键字**或**保留字**（如 `for`、`if`、`while`、`true`、`false`、`null` 等）作为标识符。

**合法与非法示例**：
- **合法标识符**：`name_`、`_age`、`$price`、`user1`（符合首字符和后续字符规则）。
- **非法标识符**：
  - `1user`：以数字开头，违反首字符规则。
  - `for`、`true`：使用了语言内置的关键字或特殊值。

## 注释 *Content-[02:51]
注释对于提升代码的**可读性**和**可维护性**至关重要。JavaScript 沿用了 C 语言的注释风格，主要分为两种：
- **单行注释**：
  - 以两个斜杠 `//` 开始。
  - 从 `//` 到该行末尾的内容都会被 JS 引擎忽略。
  - **用法**：可用于注释一整行，或在代码末尾进行补充说明。
- **块注释**：
  - 以 `/*` 开头，以 `*/` 结束。
  - **用法**：可以跨越多个行，非常适合编写大段的说明文档，或者临时禁用（注释掉）一整段代码。

## 严格模式 *Content-[03:57]
严格模式（Strict Mode）是 ECMAScript 5 (ES5) 引入的特殊特性，为 JS 提供了更严格的执行环境。
- **为什么使用严格模式**：
  1. **提高安全性**：将一些静默错误转化为抛出异常，帮助开发者提前发现问题。
  2. **规范编程实践**：禁止一些不良的编程习惯（例如意外创建全局变量）。
  3. **面向未来**：为未来 JS 版本的新语法特性铺路，部分新特性可能强制要求在严格模式下使用。
- **使用方式**：
  - 在脚本文件的头部或函数体的第一行添加字符串字面量 `"use strict";`。
  - **全局启用**：在整个脚本文件顶部添加，对整个脚本生效。
  - **局部启用**：在特定函数内部的第一行添加，实现更细粒度的控制。
- **现状**：在现代前端开发中，使用脚手架创建的项目通常默认开启严格模式。

## 语句 *Content-[05:38]
语句是构成 JS 程序的基本单位，用于指示浏览器执行特定操作。
- **分号 (`;`)**：
  - 理论上，每个语句都应以分号结尾。
  - 虽然 JS 拥有**自动分号引入机制 (ASI)**，在大多数情况下不写分号代码也能正常运行，但为了避免潜在的解析问题和代码压缩时的错误，**强烈建议始终手动在语句末尾添加分号**，这是优秀的编码习惯。
- **代码块 (`{}`)**：
  - 使用一对花括号 `{}` 可以将多条语句组合成一个代码块。
  - **常见场景**：`if` 条件判断、循环结构、函数定义等。
  - **作用**：定义了一个**作用域**，将相关的语句组织在一起。例如，`if` 语句后的花括号内包含的多条语句共同构成一个条件执行的代码块。

## AI 总结
本次视频详细讲解了 JavaScript 的五大核心语法基础：
1. **区分大小写**：JS 对大小写敏感，变量、函数名及操作符（如 `typeof`）必须严格保持大小写一致。
2. **标识符命名规则**：首字符须为字母、下划线或 `$`，后续字符可包含数字，且严禁使用保留关键字。
3. **注释机制**：支持 C 语言风格的单行注释（`//`）和多行块注释（`/* */`），用于提升代码可读性。
4. **严格模式**：通过 `"use strict"` 开启，能捕获静默错误、规范代码并兼容未来特性，现代工程化项目通常默认开启。
5. **语句与代码块**：强调手动添加分号的重要性以规避 ASI 机制的隐患，并介绍了使用花括号 `{}` 构建代码块以管理作用域。
掌握这些基础语法是编写规范、健壮的前端代码的第一步，也是前端面试中的必考基石。
