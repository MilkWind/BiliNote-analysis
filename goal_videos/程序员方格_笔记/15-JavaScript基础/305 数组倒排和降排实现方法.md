## 面试题背景与考察点 *Content-[00:00]

- **题目描述**：在 JavaScript 中，如何实现对数字类型数组的倒排和降排效果。
- **概念解释**：
  - **倒排**：将数组元素的顺序反转。例如，将 `[1, 2, 3, 4]` 反转为 `[4, 3, 2, 1]`。
  - **降排（降序）**：将数组元素按从大到小的顺序进行排列。常用于商品价格、年龄、分数等需要比大小的业务场景。
- **考察核心**：
  - 考察候选人对现代浏览器及 ES6 数组操作方法的掌握程度。
  - 在 ES5 时代，实现数组排序或反转需要手动编写循环、比较并交换中间变量，代码繁琐且易错；而在 ES6 时代，利用内置方法可以极大地简化代码。
  - 重点考察候选人是否具备实际的数据操作经验，以及对数组方法底层逻辑（如是否修改原数组）的深入理解。

## 数组倒排（反转）的实现方法 *Content-[03:37]

针对数组的倒排（反转）需求，主要有以下两种实现方式：

1\. **方法一：创建副本后反转（推荐，不修改原数组）**
- **实现思路**：使用 ES6 的扩展运算符 `...` 提取原数组的所有成员，生成一个全新的数组，然后对新数组调用 `reverse()` 方法。
- **优点**：避免了直接修改原数组，保留了原始数据的顺序，是最高效且安全的最佳实践。
- **代码示例**：
  ```javascript
  const originalArr = [1, 2, 3, 4, 5, 6];
  // 使用扩展运算符创建副本，然后反转
  const reversedArr = [...originalArr].reverse(); 
  ```

2\. **方法二：直接反转原数组（会修改原数组）**
- **实现思路**：直接对原数组调用 `reverse()` 方法。
- **缺点**：会直接改变原数组的元素顺序。如果后续业务逻辑还需要依赖原数组的初始顺序，则不推荐使用此方法。
- **代码示例**：
  ```javascript
  const originalArr = [1, 2, 3, 4, 5, 6];
  originalArr.reverse(); // 原数组顺序被永久修改
  ```

## 数组降排（降序）的实现方法 *Content-[07:37]

针对数组的降序排列需求，同样有两种方式，核心在于 `sort()` 方法中比较函数的运用：

1\. **方法一：创建副本后降序排列（推荐，不修改原数组）**
- **实现思路**：使用扩展运算符 `...` 创建数组副本，然后调用 `sort()` 方法，并传入比较函数 `(A, B) => B - A`。
- **代码示例**：
  ```javascript
  const originalArr = [3, 1, 4, 1, 5, 9, 2, 6];
  // 创建副本并进行降序排序
  const sortedArr = [...originalArr].sort((A, B) => B - A);
  ```

2\. **`sort()` 比较函数原理解析**：
- `sort()` 方法接受一个比较函数，参数 `A` 和 `B` 代表数组中参与比较的两个元素。
- 当函数返回值 $B - A > 0$ 时，说明 $B > A$。此时 `sort()` 会将 `B` 排在 `A` 的前面，从而实现**降序**（从大到小）。
- 反之，如果返回值是 $A - B$，当 $A > B$ 时 `A` 排在 `B` 前面，则实现**升序**（从小到大）。

3\. **方法二：直接对原数组降序排列（会修改原数组）**
- **实现思路**：直接调用 `originalArr.sort((A, B) => B - A)`。
- **缺点**：与 `reverse()` 类似，这会打乱并修改原数组的初始顺序。

## 核心关键点总结与面试建议 *Content-[11:29]

在面试中回答此类问题时，除了写出代码，还需要向面试官展示你对底层机制的理解：

1\. **关键点一：防止原数组被污染（副作用管理）**
- `reverse()` 和 `sort()` 都会**直接修改原数组**（Mutating methods）。
- 在实际的前端工程化开发中，直接修改传入的数组可能会引发难以追踪的 Bug。因此，强烈建议先通过扩展运算符 `...` 或 `slice()` 方法创建一个数组副本，再对副本进行操作。主动提及这一点能体现你良好的编码习惯。

2\. **关键点二：深入理解 `sort()` 比较函数的数学逻辑**
- 很多开发者对 `sort((A, B) => ...)` 中的 `A` 和 `B` 的具体指向和返回值逻辑一知半解。
- 必须明确核心逻辑：**返回值大于 0 时，第二个参数（`B`）排在第一个参数（`A`）前面**。清晰解释 $B - A$（降序）和 $A - B$（升序）的本质区别，是面试中的重要加分项。

3\. **面试回答策略**
- 在真实面试场景中，建议采用“总-分-总”的结构：先给出基于 ES6 的最优解（创建副本），再补充直接修改原数组的写法及其适用场景，最后点出 `sort()` 比较函数的底层原理。这样能全方位展现你的技术深度和实战经验。
