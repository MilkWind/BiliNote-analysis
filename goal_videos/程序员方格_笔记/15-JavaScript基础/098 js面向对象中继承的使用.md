## 1. JS 面向对象特征概述 *Content-[00:01]

- **强类型语言的面向对象特征**：在强类型语言（如 Java、C++）中，面向对象编程通常具备三大核心特征：封装性、继承性、多态性。
- **JS 的面向对象特征**：JS 作为一门弱类型语言，只具备部分的面向对象特征：
  - **具备封装性**。
  - **具备一半的继承性**（基于对象的继承，而非模板/类的继承）。
  - **不具备多态性**。

## 2. JS 的封装性 *Content-[01:37]

- **概念**：将属性和方法封装到对象里面，然后进行调用，这就是封装性。
- **JS 对象的本质**：JS 的对象本质上是无数个键值对的集合。
- **成员构成**：键值对即为对象的成员，可以理解为属性和方法。对象将属性与方法封装，方法将过程封装，因此 JS 完全符合封装性的特征。

## 3. JS 的继承性：对象继承与模板继承 *Content-[02:19]

JS 的继承是**基于对象的继承**，而强类型语言中通常是**模板继承（类的继承）**。

- **对象继承（JS 的方式）**：
  - **案例**：买了一款电动车，看到别人的同款电动车加装了液晶屏、倒车雷达等配置。要个链接自己照着改装，除了车牌不一样，其他一模一样。
  - **特点**：继承只发生在当前对象与目标对象之间。
  - **优点**：当前对象简洁地实现了继承。
  - **缺点**：无法批量继承，其他人想用还得重新操作一遍。
- **模板继承（强类型语言的方式）**：
  - **案例**：电动车厂家在出厂图纸（模板/类）上就设计好高配版（自带液晶屏、倒车雷达等），只要加钱就能直接出厂自带。
  - **特点**：在出厂图纸（模板）上继承好。
  - **优点**：支持批量继承。
  - **缺点**：理解难度比 JS 的对象继承更高一层。

## 4. JS 缺乏多态性的原因 *Content-[04:39]

- **多态性概念**：指对象的多种状态，在强类型语言中通常表现为“声明父类，new 子类对象”。
- **JS 没有多态性的原因**：JS 是弱类型语言，无法自定义类型（如父类型、子类型）。因为没有自定义类型的概念，所以无法实现多态性。在面试中了解知道即可。

## 5. JS 继承方式一：对象混入式 *Content-[06:43]

- **原理**：通过遍历目标对象，将其属性和方法逐一绑定到新的空对象中。
- **代码逻辑**：
  ```javascript
  // 目标对象
  let o = { 
      name: '小哈皮', 
      age: 12, 
      sayHi: function() { console.log('您好'); },
      eat: function() { console.log('吃麻辣香锅'); },
      drink: function() { console.log('喝柠檬水'); }
  };
  
  // 新对象
  let p = {};
  
  // 遍历并混入
  for (let key in o) {
      p[key] = o[key];
  }
  
  console.log(p); // 成功继承所有属性和方法
  ```
- **特点**：简单粗暴，直接遍历复制。属性和方法直接绑定在对象本身。

## 6. JS 继承方式二：原型替换 *Content-[10:11]

- **原理**：直接将构造函数的 `prototype` 指向目标对象。
- **代码逻辑**：
  ```javascript
  let o = { /* 包含属性和方法 */ };
  
  function Person() {}
  Person.prototype = o; // 直接替换原型
  
  let p = new Person();
  // p 可以通过原型链调用 o 中的方法
  ```
- **特点**：
  - 适用于主要想继承**方法**的场景。
  - 如果直接需要属性，这种方式不太合适（因为属性在原型上，而非实例本身）。
  - 简单粗暴，直接替换原型。

## 7. JS 继承方式三：原型混入式 *Content-[11:15]

- **原理**：与对象混入式类似，但遍历后将属性和方法绑定到构造函数的 `prototype` 上，而非对象本身。
- **代码逻辑**：
  ```javascript
  let o = { /* 包含属性和方法 */ };
  
  function Person() {}
  
  // 遍历并混入到原型
  for (let key in o) {
      Person.prototype[key] = o[key];
  }
  
  let p = new Person();
  ```
- **特点**：
  - 本质还是混入式，只是绑定目标从对象本身变成了原型。
  - **好处**：通过该构造函数 `new` 出来的所有对象，都可以共享并调用这些继承来的属性和方法。

## 8. JS 继承方式四：自定义继承与 Object.create() *Content-[12:35]

- **自定义继承方法**：
  ```javascript
  function create(obj) {
      function F() {}      // 1. 创建一个空构造函数
      F.prototype = obj;   // 2. 将构造函数的原型指向目标对象（本质是原型替换）
      return new F();      // 3. 实例化并返回
  }
  
  let p = create(o);
  ```
  - **原理**：本质上是“原型替换”的封装，利用构造函数和原型的关系来实现继承。

- **系统提供的继承方法：`Object.create()`**
  ```javascript
  let p = Object.create(o);
  ```
  - **原理**：与自定义的 `create` 方法底层原理一模一样。
  - **区别**：`Object.create()` 创建的对象在控制台打印时，原型前面没有具体的类型名（如 `F`），但继承逻辑完全一致。这是系统封装好的标准继承方法。

## 9. JS 继承本质总结 *Content-[14:45]

- **本质分类**：JS 的继承方式变来变去，本质只有两种：
  1. **混入式**：包括对象混入式、原型混入式。
  2. **原型替换**：包括直接原型替换、自定义 `create` 函数、`Object.create()`。
- **核心原理**：利用原型（`prototype`）的特点。对象默认继承其构造函数原型中的内容。利用构造函数、原型、对象之间的“三角关系”，通过操作原型来最终实现继承。
