## Symbol 面试题概览 *Content-[00:00]

在实际开发中，`Symbol` 常用于解决合并对象时频繁出现的属性名冲突问题，以及实现 Class 中的真正私有属性（替代不严谨的下划线 `_` 伪私有约定）。然而，很多开发者在学习 ES6 时只关注了 `let`、`const` 和箭头函数，直接跳过了 `Symbol`，导致在面试中面对相关问题时哑口无言。

面试官关于 `Symbol` 的高频问题通常包括：

1\. **ES6 为什么要引入 `Symbol` 数据类型？它的核心特征是什么？**
2\. **`Symbol` 是基本数据类型还是引用数据类型？**
3\. **如何验证 `Symbol`？**
4\. **`Symbol.for` 和 `Symbol.keyFor` 的核心区别是什么？**
5\. **`Symbol` 类型能否进行运算？能否转化为其他数据类型？**
6\. **`JSON.stringify` 为什么会忽略 `Symbol` 类型的属性？如何获取对象中的 `Symbol` 类型属性？常规遍历（`for...in`、`for...of`、`Object.keys()`）能否获取？**
7\. **如何利用 `Symbol` 实现对象的真正私有属性？为什么下划线伪私有属性不严谨？**
8\. **`Symbol` 作为对象属性名的语法要求是什么？为什么必须用中括号？**
9\. **如何利用 `Symbol` 消除魔术字符串？**
10\. **`Symbol` 的 `description` 属性的作用是什么？和 `Symbol.keyFor` 有什么区别？**

## Symbol 的核心概念与唯一性 *Content-[02:40]

- **核心概念**：`Symbol` 是 ES6 引入的一种新的数据类型，表示**独一无二的值**。它在内存中独立存储，JS 引擎会确保每个 `Symbol` 的引用地址是唯一的。
- **参数描述**：`Symbol` 可以接收一个字符串作为参数，表示对该 `Symbol` 实例的描述。
  - **主要作用**：为了在控制台显示或转为字符串时，能够更容易地区分不同的 `Symbol` 实例。
  - **关键注意点**：即使两个 `Symbol` 接收了相同的参数（描述），它们的值依然是**不相等**的。
- **代码验证**：
  ```javascript
  const s1 = Symbol('name');
  const s2 = Symbol('name');
  
  console.log(s1 === s2); // 输出: false
  ```
  - 即使描述都是 `'name'`，`s1` 和 `s2` 也不相等。
  - 如果不加描述，打印出来都是 `Symbol()`，完全无法区分；加上描述后，控制台会显示 `Symbol(name)`，方便调试和区分。

## Symbol 的数据类型与基本数据类型回顾 *Content-[05:30]

- **数据类型验证**：可以通过 `typeof` 操作符来判断数据类型。
  ```javascript
  const s1 = Symbol('name');
  console.log(typeof s1); // 输出: "symbol"
  ```
- **基本数据类型回顾**：
  - 在学习 `Symbol` 之前，JavaScript 共有 6 种数据类型（5 种基本数据类型 + 1 种引用数据类型）：
    - 基本数据类型：`Number`、`String`、`Boolean`、`Undefined`、`Null`
    - 引用数据类型：`Object`
  - `Symbol` 是 ES6 新增的**第七种**数据类型，也是 ES6 中新增的**第一种**基本数据类型。
- **核心设计初衷**：
  - 生成独一无二的值。
  - 从根本上解决对象属性名的冲突问题。

## Symbol 的创建方式与语法要求 *Content-[07:10]

- **创建方式**：`Symbol` 是一个函数，但**绝对不能使用 `new` 命令**调用。
  - 如果使用 `new Symbol()` 会直接报错（`TypeError: Symbol is not a constructor`）。
  - **原因**：生成的 `Symbol` 是一个原始类型的值（基本数据类型），而不是对象，因此不能作为构造函数使用。
- **面试经验提示**：在实际面试中，很多有 5 年以上工作经验的候选人依然不清楚 `Symbol` 的创建方式，误以为可以使用 `new` 关键字，或者完全不知道如何创建。这反映出日常开发中理论基础不够扎实，只关注写代码而忽视了底层原理。
- **语法结构**：
  ```javascript
  Symbol([description])
  ```
  - `description`：可选参数，是一个字符串。
  - 作用：仅用于控制台显示或区分，**不影响其唯一性**。
- **返回值**：返回一个独一无二的 `Symbol` 值。
- **核心特性**：相同描述的 `Symbol` 值依然不相等（这是面试必考点）。

## Symbol 的核心特性：唯一性验证 *Content-[09:32]

- `Symbol` 的第一个核心特性就是**唯一性**。
- 每次调用 `Symbol()` 函数，都会返回一个全新的、独一无二的值。
- 即使传入完全相同的描述字符串，生成的 `Symbol` 值在内存中的引用地址也是不同的，因此它们互不相等（`===` 比较结果为 `false`）。
- 这一特性使其非常适合用作对象的唯一属性名，从而在开发中彻底避免属性名冲突的问题。
