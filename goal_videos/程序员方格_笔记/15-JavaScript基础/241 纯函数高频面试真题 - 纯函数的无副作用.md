## 什么是副作用与无副作用 *Content-[00:00]

**副作用**其实就是函数对外界造成的改变或影响。
- **通俗比喻**：就像你在房间里面吃东西，掉了一地的垃圾。因为你吃东西影响了地面的整洁干净，破坏了房间的原有状态，这就是“副作用”。
- **纯函数的无副作用**：纯函数就像你在房间里面吃东西，吃完后把垃圾都收拾干净，不影响房间的任何东西。
- **核心定义**：纯函数的无副作用，核心在于**函数内部只处理自己的参数和局部变量，绝对不碰外面的任何东西**。

## 纯函数禁止的副作用行为（面试必说） *Content-[00:53]

在面试中，关于纯函数的无副作用，必须牢记并准确说出以下具体禁止的行为：

1\. **不改变外部的变量**
   - 绝对不能修改在函数外部（如全局作用域）定义的变量。

2\. **不修改传入的引用类型参数**
   - 不能直接修改传入的对象（Object）、数组（Array）等引用数据类型。

3\. **不操作 DOM**
   - 不能修改页面内容、添加或删除 DOM 元素等。

4\. **不发送网络请求**
   - 不能执行异步的网络请求操作，例如使用 `XMLHttpRequest`、`axios` 或者是 `fetch` 等。

**补充说明（面试防坑）**：
- 使用 `console.log` 打印内容以及使用定时器（`setTimeout` / `setInterval`）**一般不算作副作用**。
- 它们通常不会影响纯函数的判断，面试时遇到纯函数判断问题不用在这些细节上过度纠结。

## 案例一：修改外部变量（有副作用） *Content-[02:24]

通过代码演示一个典型的**有副作用（非纯函数）** 的场景：修改函数外部的变量。

**代码逻辑**：
```javascript
// 第一步：定义一个函数外部的变量
let num = 10;

// 第二步：定义函数，在内部修改外部变量
function changeNum() {
    num = 20; // 产生副作用：修改了函数外面的变量
    return num;
}

// 第三步：调用函数并测试
changeNum();
console.log(num); // 输出结果：20
```

**案例分析**：
- 外部变量 `num` 的初始值是 `10`。
- 在 `changeNum` 函数内部，直接将 `num` 修改为了 `20`。
- 调用函数后，外部的 `num` 真的变成了 `20`。
- **结论**：函数内部改变了全局或函数外部的变量/数据，对外界造成了影响，产生了副作用，因此它**不是纯函数**。

## 案例二：修改入参对象（有副作用） *Content-[05:55]

这是前端开发中**最容易踩坑**的地方：认为只修改了参数，没修改外部变量，就不算副作用。

**代码逻辑**：
```javascript
// 第一步：定义一个外部用户对象
const user = {
    name: '小明',
    age: 18
};

// 第二步：定义函数，直接修改传入的对象参数
function updateAge(user) {
    user.age = 20; // 产生副作用：直接修改了传入的引用类型参数
    return user;
}

// 第三步：调用函数并测试原对象
updateAge(user);
console.log(user.age); // 输出结果：20 （原对象被修改了）
```

**案例分析与底层原理**：
- 原对象 `user` 的 `age` 初始为 `18`，调用函数后变成了 `20`，外界受到了影响。
- **核心坑点**：对象属于**引用数据类型**。在内存中，传入的参数和外部原对象指向的是同一块内存地址（就像“门牌号”和“具体房子”的关系）。
- 修改传入的对象参数，本质上就是修改了外部的原对象，这**一样属于副作用**。
- **结论**：有副作用，它**不是纯函数**。

## 案例三：不改变原对象返回新对象（无副作用纯函数） *Content-[10:26]

针对案例二的坑，我们需要掌握正确的实战写法：**断开引用，返回新对象**。

**代码逻辑**：
```javascript
// 外部用户对象
const user = {
    name: '小明',
    age: 18
};

// 正确的纯函数写法：不修改原对象，返回新对象
function updateAgePure(user) {
    // 使用展开运算符 (...) 复制原对象的所有属性，并覆盖 age 为 20
    return {
        ...user,
        age: 20
    };
}

// 调用函数并测试
const newUser = updateAgePure(user);

console.log(user.age);    // 输出结果：18 （原对象未被修改，外界未受影响）
console.log(newUser.age); // 输出结果：20 （新对象满足需求）
```

**案例分析与底层原理**：
- **核心操作**：使用 ES6 的**展开运算符（`...`）** 对原对象进行浅拷贝，生成一个全新的对象，然后在新对象上覆盖 `age` 属性。
- **内存变化**：新对象和原对象在内存中不再是同一块地址，成功断开了引用关系。
- **结论**：原对象保持不变（外界未受影响），相同输入得到了相同的输出，无副作用，这是一个**典型的纯函数**。

## AI 总结 *Content-[14:50]

纯函数的“无副作用”是前端面试中的高频核心考点。其本质要求函数在执行过程中**绝对不能“弄脏”外部环境**。
1. **理论层面**：禁止修改外部变量、禁止修改引用类型入参、禁止操作 DOM 和网络请求。
2. **实战层面**：在处理对象或数组等引用数据类型时，切忌直接修改原数据（Mutate）。必须遵循**不可变性（Immutability）** 原则，利用展开运算符（`...`）、`Object.assign` 或数组的 `map`/`filter` 等高阶方法，**返回一个全新的数据副本**。
3. **面试技巧**：回答时不仅要说出“不修改外部变量”，一定要主动补充“不修改传入的引用类型参数”，并点出“引用地址相同导致外部数据被污染”的底层原理，这是拿高分的关键。
