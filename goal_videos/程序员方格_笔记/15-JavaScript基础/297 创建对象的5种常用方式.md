## 1. 对象字面量 (Object Literal) *Content-[02:11]

**语法与方式**：
通过大括号 `{}` 定义对象，以键值对的形式编写对象的属性和方法。这是最常见、最简单的方式。

**特征与适用场景**：
- **简单直观**：代码可读性极高，适合创建单例对象或进行简单的配置。
- **独立性**：每次通过字面量创建的对象都是一个独立的全新对象，它不继承任何原型（Prototype）。

**优缺点**：
- **优点**：语法最简单，最常用，适合完全独立且具有自身特点的对象。
- **缺点**：不适合批量创建结构相同的对象。如果需要创建多个一模一样的结构体，使用字面量会导致代码重复，每次都需要重新编写。

**代码示例**：
```javascript
const person = {
    name: 'Alice',
    age: 20,
    sayHi: function() {
        console.log('Hi, I am ' + this.name);
    }
};
person.sayHi();
```

## 2. 构造函数 (Constructor Function) *Content-[04:17]

**语法与方式**：
通过 `new` 关键字调用函数来创建对象。在函数内部使用 `this` 去绑定属性和方法。

**特征与适用场景**：
- **批量创建**：适合创建多个相似的对象（即类的实例）。通过实例化，可以不断复制出拥有相同属性和方法的新实例。
- **原型链继承**：遵循原型链继承机制，可以通过 `prototype` 属性来共享方法，从而提升代码复用效率。

**关键注意事项**：
- **避免使用箭头函数**：在构造函数中定义方法时，千万不要使用箭头函数（Arrow Function）。因为箭头函数没有自己的 `this`，它的 `this` 会指向上一级父级对象，导致绑定失效。必须使用传统的 `function` 关键字。

**代码示例**：
```javascript
function Person(name, age) {
    this.name = name;
    this.age = age;
}

// 通过 prototype 共享方法
Person.prototype.sayHi = function() {
    console.log('Hi, I am ' + this.name);
};

const p1 = new Person('Bob', 25);
p1.sayHi();
```

## 3. Object.create() 方法 *Content-[07:02]

**语法与方式**：
使用 `Object.create(proto)` 方法，以现有对象为原型去创建一个新对象。

**特征与适用场景**：
- **原型继承**：可以实现原型的继承，但需要显式地去指定到底继承哪一个原型对象。
- **特定场景**：适合需要继承特定对象属性的场景。
- **纯净对象**：它可以创建有原型的对象，也可以创建没有原型的纯净对象。

**两种使用模式**：
1. **有原型继承**：传入一个现有对象作为原型，新创建的对象将继承该原型的属性和方法。
2. **无原型纯净对象**：传入 `null` 作为参数。此时创建的对象没有任何原型链指向（`__proto__` 为 `undefined`），是一个绝对纯净的对象。

**代码示例**：
```javascript
const existingObj = {
    sayHi: function() { console.log('Hi'); }
};

// 1. 继承现有对象的原型
const newObj = Object.create(existingObj);
newObj.name = 'Charlie';
newObj.sayHi(); // 可以调用继承来的方法

// 2. 创建没有原型的纯净对象
const pureObj = Object.create(null);
console.log(pureObj.__proto__); // 输出 undefined
```

## 4. 工厂函数 (Factory Function) *Content-[09:25]

**语法与方式**：
通过一个普通函数返回一个新对象，**无需使用 `new` 关键字**。

**特征与适用场景**：
- **封装逻辑**：将对象的创建逻辑封装在函数内部，避免代码重复和外部混淆。
- **灵活生成**：适合需要灵活生成对象的场景（例如根据传入参数动态生成属性）。每次调用函数都会返回一个全新的对象。

**优缺点**：
- **优点**：无需使用 `new`，代码相对简单；封装性好，外部很难直接访问和修改内部的创建逻辑。
- **缺点**：与构造函数不同，工厂函数内部定义的方法在每次创建对象时都会被重复创建，无法像构造函数那样通过 `prototype` 实现方法共享。

**代码示例**：
```javascript
function createPerson(name, age) {
    // 封装创建逻辑并返回对象
    return {
        name: name,
        age: age,
        sayHi: function() {
            console.log('Hi, I am ' + this.name);
        }
    };
}

const p1 = createPerson('David', 30);
p1.sayHi();
```

## 5. 类 (ES6 Class) *Content-[12:03]

**语法与方式**：
通过 `class` 关键字定义类，使用 `constructor` 方法初始化对象属性。

**特征与适用场景**：
- **语法糖**：本质上是构造函数的一种语法糖（Syntactic Sugar），底层仍然是基于原型链来实现继承的。
- **贴近传统 OOP**：语法更加接近传统的面向对象编程语言（如 Java），支持继承（`extends`）、静态方法等高级特性。
- **主流推荐**：在 ES6 及以后的现代前端开发中，这是最推荐、最常见的面向对象写法。

**代码示例**：
```javascript
class Person {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }
    
    sayHi() {
        console.log('Hi, I am ' + this.name);
    }
}

const p1 = new Person('Eve', 28);
p1.sayHi();
```

## 五种创建对象方式的综合对比 *Content-[13:27]

| 创建方式 | 语法/方式 | 适用场景 | 核心特点 |
| :--- | :--- | :--- | :--- |
| **对象字面量** | `{ key: value }` | 单例对象、简单配置 | 简单直观，每次创建独立全新对象，不继承原型。 |
| **构造函数** | `new Function()` | 创建多个相似对象 | 需配合 `prototype` 优化方法共享，注意避免使用箭头函数。 |
| **Object.create()** | `Object.create(proto)` | 原型继承、构建纯净对象 | 显式控制原型链，传 `null` 可创建无原型的纯净对象。 |
| **工厂函数** | `return { ... }` | 灵活生成对象、封装逻辑 | 无需 `new`，避免代码重复，但方法可能会重复创建。 |
| **Class (类)** | `class` 关键字 | 面向对象编程、实现继承 | 构造函数的语法糖，底层基于原型链，语法接近 Java 等传统语言。 |
