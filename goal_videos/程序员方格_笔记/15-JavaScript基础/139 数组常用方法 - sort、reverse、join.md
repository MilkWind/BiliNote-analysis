## sort 方法详解 *Content-[00:00]

`sort` 方法用于对数组的元素进行排序。

### 基本语法与默认排序
- **语法**：`arr.sort()` 或 `arr.sort(compareFunction)`。
- **默认排序**：如果不传参数，`sort` 方法默认将数组元素转换为字符串，并按照字符串的 **Unicode 码位（code points）** 进行排序。
- **返回值**：返回排序后的数组。

### 默认排序的“坑点”与原理
- **数字排序错误示例**：
  - 对于数组 `[1, 2, 3, 4, 12]`，直接调用 `sort()` 后，结果会变成 `[1, 12, 2, 3, 4]`。
  - **原因**：元素被转为字符串后按字典顺序（Unicode 码位）排列。在比较 `'12'` 和 `'2'` 时，先比较第一位字符 `'1'` 和 `'2'`，因为 `'1'` 的 Unicode 码小于 `'2'`，所以 `'12'` 排在了 `'2'` 的前面。
- **字符串排序示例**：
  - 对于数组 `['apple', 'banana', 'pear']`，排序结果为 `['apple', 'banana', 'pear']`，严格按照首字母的 Unicode 顺序排列。
- **面试考点**：`sort` 默认排序的坑点在于它会把数字全部转为字符串，然后按照 Unicode 码进行排序，因此直接对纯数字数组排序会产生不正确的结果。

### 自定义排序（比较函数）
为了解决数字排序的问题，需要传入一个**比较函数**作为 `sort` 的参数。
- **比较函数原理**：接收两个值 `a` 和 `b`，根据返回值决定排序顺序：
  - 如果 `a > b`（第一个值比第二个值大），返回正数（如 `1`）。
  - 如果 `a == b`（两个值相等），返回 `0`。
  - 如果 `a < b`（第一个值比第二个值小），返回负数（如 `-1`）。
- **升序排列（从小到大）**：传入 `(a, b) => a - b`。
  - 示例：`[1, 2, 3, 4, 12].sort((a, b) => a - b)`，结果为 `[1, 2, 3, 4, 12]`。
- **降序排列（从大到小）**：传入 `(a, b) => b - a`。

### 是否改变原数组
- `sort` 方法**会改变原数组**，直接在原数组上进行排序操作。

## reverse 方法详解 *Content-[06:02]

`reverse` 方法用于将数组中的元素位置颠倒。

### 基本语法与作用
- **语法**：`arr.reverse()`，该方法没有参数。
- **作用**：将数组的第一个元素变成最后一个，最后一个元素变成第一个。它是一个简单的反转操作，**不包含任何排序逻辑**。
- **示例**：数组 `[1, 2, 3, 4]` 调用 `reverse()` 后，变为 `[4, 3, 2, 1]`。

### 返回值与是否改变原数组
- **返回值**：返回颠倒后的数组。
- **是否改变原数组**：**会改变原数组**。原数组的元素顺序会被直接反转。

## join 方法详解 *Content-[07:54]

`join` 方法用于将数组的所有元素连接成一个字符串，是前端开发中将数组转为字符串的常用方法。

### 基本语法与参数
- **语法**：`arr.join(separator)`。
- **参数 `separator`（分隔符）**：
  - 可选参数，指定一个字符串来分割数组的每一个元素。
  - **默认行为**：如果缺省该参数，数组元素默认使用**逗号 `,`** 进行分割。
  - **空字符串**：如果传入空字符串 `''`，则所有元素之间没有任何字符，直接拼接。
  - **自定义符号**：可以传入任意字符串（如 `'*'`、`'-'` 等）作为分隔符。

### 返回值与特殊情况
- **返回值**：返回一个由数组元素连接而成的字符串。
- **特殊情况处理**：
  - **数组长度为 0**：返回空字符串 `''`。
  - **数组只有一个元素**：直接返回该元素的字符串形式，**不使用分隔符**。

### 核心避坑指南（null 与 undefined）
- **关键细节**：如果数组中的元素为 `null` 或 `undefined`，在 `join` 方法中它们会被**转为空字符串**。
- **示例演示**：
  - 数组 `[1, 2, null, undefined]` 使用 `join('*')`。
  - 结果：`"1*2**"`。
  - **解析**：`null` 和 `undefined` 被转为空字符串，因此它们在 `*` 之间不占用任何字符位置，导致出现了连续的 `**`。在开发中需要特别注意这一特性。
