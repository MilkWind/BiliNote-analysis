## null 和 undefined 的相同点 *Content-[00:04]
1\. **布尔值转换**：在 `if` 条件判断中，两者都会被隐式转换为 `false`。
2\. **属性与方法限制**：两者都不能添加属性或方法（尝试为其添加属性会抛出错误）。
3\. **数据类型与存储**：都属于基本数据类型，在内存中存在于栈（Stack）中。
4\. **松散相等**：使用松散相等（`==`）进行比较时，返回结果为 `true`（即 `null == undefined` 为 `true`）。
5\. **序列化特殊处理**：在进行序列化（如 `JSON.stringify()`）时，`undefined` 和 `null` 都会被特殊处理（`undefined` 会被直接忽略，`null` 会被序列化为 `"null"`）。

## null 和 undefined 的差异点 *Content-[01:44]
1\. **数据类型不同**：
   - 使用 `typeof` 检测 `undefined`，返回的是 `"undefined"`。
   - 使用 `typeof` 检测 `null`，返回的是 `"object"`（这是 JavaScript 早期的一个历史遗留 Bug，但已成为语言标准）。
2\. **转为数值结果不同**：
   - `Number(null)` 转换为数值的结果是 `0`。
   - `Number(undefined)` 转换为数值的结果是 `NaN`。
3\. **严格比较**：
   - 使用严格相等（`===`）进行比较时，两者不相等（即 `null === undefined` 为 `false`），因为它们的数据类型不同。

- **null 的使用场景**：一共有 **5 个**常见的语义化使用场景（例如：作为对象原型链的终点、作为函数参数表示空对象、DOM 操作获取不到节点时的返回值等）。
