## 1. 基本数据类型的赋值与传值 *Content-[00:00]*

### 核心规则
基本数据类型（存储在栈内存 Stack 中）的赋值核心规则是：**赋值时，复制栈内存中的实际值给新的变量**。

### 内存机制
- 新变量和原变量在栈中拥有**独立**的内存空间。
- 修改其中一个变量，另一个**绝对不会**受到影响，因为它们在内存中是各自独立的。

### 通俗理解
- 相当于**复印文件**或**复制文件夹**。
- 原文件和复印出来的文件互不影响。修改复印件，原文件不受影响；修改原文件，复印件也不受影响。

### 代码示例与图解分析
这是一道非常高频经典的面试题，主要考察对栈内存的理解。

```javascript
let a = 10;
let b = a;
b = 20;
```

**内存变化步骤解析：**
1. **第一步 `let a = 10`**：系统自动在栈内存中开辟一块空间，存储变量 `a` 及其实际值 `10`。
2. **第二步 `let b = a`**：系统分配一块固定的栈内存给 `b`，同时将 `a` 的实际值 `10` 复制给 `b`。此时 `a` 和 `b` 在栈中拥有独立的内存空间，只是初始值相同。
3. **第三步 `b = 20`**：修改 `b` 的值为 `20`。由于两者的空间是独立的（相当于修改了复印件），`a` 的值不受任何影响。

**最终结果验证：**
- `a` 依旧是原来的 `10`（原文件不变）。
- `b` 变成了 `20`。
- 两人互不影响，各自拥有独立空间。

## 2. 引用数据类型的赋值与传值 *Content-[03:34]*

### 核心规则
引用数据类型的赋值核心规则是：**赋值是地址的传递**。复制栈内存中的地址指针给新的变量。

### 内存机制
- 引用类型的实际数据存储在**堆内存（Heap）** 中，而地址指针存储在**栈内存**中。
- 赋值后，新变量和原变量在栈中拥有**不同**的地址变量（指针），但它们指向的是**同一个**堆内存空间。
- 修改其中一个变量，另一个**也会**受到影响。

### 通俗理解
- 相当于**两个人拿着同一把钥匙打开同一个房间**。
- 其中一个人（原变量）在房间里放了东西（修改数据），另一个人（新变量）拿着钥匙进去，也能看到这个东西。

### 代码示例与图解分析
结合代码和内存图解，深入理解堆栈配合的机制。

```javascript
let a = { x: 10, y: 20 };
let b = a;
b.x = 100;
console.log(a); // 输出: { x: 100, y: 20 }
console.log(b); // 输出: { x: 100, y: 20 }
```

**内存变化步骤解析：**
1. **第一步 `let a = { x: 10, y: 20 }`**：
   - 系统在栈内存中开辟空间，存放变量 `a` 及其地址指针。
   - 在堆内存中开辟空间，存放实际的数据对象 `{ x: 10, y: 20 }`。
   - 栈中的指针 `a` 指向堆内存里的实际数据。
2. **第二步 `let b = a`**：
   - 将 `a` 的指针地址复制一份给 `b`。
   - 此时栈中有两个不同的地址变量（`a` 的地址和 `b` 的地址），但它们都指向堆内存中的同一块实际数据。
3. **第三步 `b.x = 100`**：
   - 通过 `b` 的指针找到堆内存中的实际数据，并将其 `x` 属性修改为 `100`。
4. **第四步 打印结果**：
   - 打印 `a` 时，`a` 的指针同样指向堆内存，此时堆里的 `x` 已经变成了 `100`，`y` 依然是 `20`。
   - 打印 `b` 时，结果同上。
   - 因为 `a` 和 `b` 指向同一块堆内存，所以它们的结果互相影响。

## 3. 核心总结与对比 *Content-[10:47]*

| 特性 | 基本数据类型 | 引用数据类型 |
| :--- | :--- | :--- |
| **存储位置** | 栈内存（Stack） | 栈内存（存指针） + 堆内存（存实际数据） |
| **传值方式** | **值的传递** | **地址的传递** |
| **赋值行为** | 复制实际值 | 复制地址指针 |
| **内存空间** | 独立空间 | 不同的栈地址，指向同一块堆内存 |
| **相互影响** | 修改其一，**不影响**另一个 | 修改其一，**会影响**另一个 |

## AI 总结
本视频详细讲解了前端面试中的高频核心考点“堆和栈在赋值时的区别”。核心在于区分基本数据类型和引用数据类型的底层传值机制：基本数据类型采用**值的传递**，在栈内存中复制实际值，变量间相互独立；引用数据类型采用**地址的传递**，在栈内存中复制指针，变量共同指向堆内存中的同一份数据，修改其一会影响其他引用。深刻理解这一内存机制，是解决 JavaScript 中对象引用、深浅拷贝、闭包等复杂问题的基础。
