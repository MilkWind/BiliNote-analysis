## bind 的预设参数功能 *Content-[00:00]

`bind` 方法除了改变 `this` 指向外，还可以使一个函数拥有**预设的初始参数**（类似于偏函数或柯里化思想）。

- **预设参数的位置**：预设参数作为 `bind` 的第二个及后续参数（跟在 `this` 后面），会被插入到目标函数的参数列表的**开始位置**。
- **后续参数排列**：后续传递给绑定函数的参数，会依次排列在预设参数之后。
- **经典应用场景**：将伪数组转为真数组。利用 `Array.prototype.slice.call(arguments)` 可以将函数内的伪数组 `arguments` 转换为真正的数组。

**代码演示**：
```javascript
function list() {
  // 将伪数组 arguments 转为真数组
  return Array.prototype.slice.call(arguments);
}

// 正常调用
const list1 = list(1, 2, 3); // 返回 [1, 2, 3]

// 使用 bind 预设初始参数 37
const leading = list.bind(null, 37);

// 调用返回的新函数
const list2 = leading(); // 返回 [37]
const list3 = leading(1, 2, 3); // 返回 [37, 1, 2, 3]，预设参数 37 始终在最前面
```

## bind 对 this 指向的永久绑定特性 *Content-[04:15]

- **临时 vs 永久**：`call` 和 `apply` 是**临时**改变函数的 `this` 指向；而 `bind` 会创建并返回一个**新函数**，该新函数的 `this` 会被**永久绑定**为 `bind` 的第一个参数。
- **核心面试题：多次绑定 `bind` 会改变 `this` 指向吗？**
  - **正确答案**：不会。`bind` 的 `this` 绑定**只生效一次**。无论后续如何再次对返回的新函数调用 `bind`，`this` 永远指向第一次绑定的对象，后续修改不再生效。

**代码演示**：
```javascript
function fn() {
  return this.a;
}

const obj = { a: 24 };

// 第一次绑定，this 永久指向 obj
const g = fn.bind(obj);
console.log(g()); // 输出 24

// 尝试第二次绑定，修改 this 指向新对象
const h = g.bind({ a: '老金' });

// 验证 this 指向
console.log(h()); // 依然输出 24，证明多次 bind 无法改变已绑定的 this 指向
```

## bind 在实际业务场景中的应用 *Content-[09:13]

在实际开发中，`bind` 的预设参数和返回新函数的特性可以灵活应用于各种业务场景。

- **场景 1：函数参数预设与求和**
  - 使用 `bind` 预设部分参数（如 `x` 和 `y`），返回新函数后再传入剩余参数或直接执行。
  - **注意事项**：在封装或自定义类似逻辑时，必须 `return` 返回的新函数，否则会导致函数执行后返回 `undefined`。

- **场景 2：工人发工资案例**
  - 使用 `bind` 为发工资函数预设基础参数（如员工姓名和基础薪资）。
  - **传参方式**：`bind` 的预设参数是**逐个传递**的，而不是像 `apply` 那样传递一个数组。
  - **参数追加**：在调用 `bind` 返回的新函数时，可以继续传入后续参数，这些参数会追加在预设参数之后。
  - **默认参数结合**：可以在 `bind` 时直接预设默认参数，后续调用时再传入动态参数，实现灵活的参数配置。

**代码逻辑示例**：
```javascript
// 使用 bind 预设部分参数，返回新函数
const payZhangSan = paySalary.bind(null, '张三', 8500);
const payLiSi = paySalary.bind(null, '李四', 8500);

// 调用新函数，可继续追加参数
payZhangSan(); // 仅使用预设参数
payLiSi(2500); // 在预设参数基础上追加 2500 的绩效/奖金
```

## AI 总结

本次视频深入讲解了 `bind` 方法在前端面试中的高频考点与核心特性：
1. **预设参数（偏函数）**：`bind` 可以预设初始参数，这些参数会插入到目标函数参数列表的头部，后续传入的参数则追加在后。
2. **永久绑定 `this`**：与 `call`/`apply` 的临时改变不同，`bind` 会返回一个新函数，并将 `this` 永久绑定到第一个参数。**多次调用 `bind` 无法改变已经绑定的 `this` 指向**。
3. **实际应用**：在业务中常用于参数复用、预设默认配置以及将伪数组转换为真数组等场景，掌握其传参顺序和返回值特性是解决复杂逻辑的关键。
