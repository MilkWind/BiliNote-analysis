## 1. 判断对象是否属于某个类 *Content-[00:07]

### 面试题背景
- **问题**：如何判断一个对象是否属于某个类？
- **语言差异**：
  - 在 Java 等强类型语言中，可以通过 `class` 关键字真正创建出一个类型（如 `Class Person`），并使用 `new` 实例化对象。
  - JavaScript 是弱类型语言，在 ES5 及之前并没有真正的“类”的概念。JS 通过**构造函数**来模拟类的创建。
- **类型检测的局限性**：使用 `typeof` 检测由构造函数创建的对象时，返回结果统一为 `object`，无法区分该对象具体属于哪个构造函数。

### ES6 提供的两种判断方式
为了解决上述问题，ES6 提供了以下两种方式来判断对象是否属于某个构造函数（类）：

1. **使用 `instanceof` 操作符**
   - **语法**：`对象 instanceof 构造函数名`
   - **作用**：判断对象是否属于该构造函数的实例。
   - **示例**：
     ```javascript
     function Person(name, age) { ... }
     function Animal() { ... }
     let p1 = new Person("小强", 13);
     
     console.log(p1 instanceof Person); // true
     console.log(p1 instanceof Animal); // false
     ```

2. **使用 `constructor` 属性**
   - **原理**：每个对象都可以通过原型链访问到其对应原型上的 `constructor` 属性，该属性指向构造函数本身。
   - **语法**：`对象.constructor === 构造函数名`
   - **原型关系比喻**：
     - 构造函数是“丈夫”，原型（`prototype`）是“妻子”。
     - `constructor` 属性就是“妻子的老公”，指向丈夫本身。
     - 因此，`原型.constructor === 构造函数本身` 是绝对成立的。
   - **示例**：
     ```javascript
     console.log(p1.constructor === Person); // true
     ```

## 2. `new` 操作符的四个核心作用 *Content-[07:17]

构造函数必须通过 `new` 关键字来调用（即构造函数调用）。`new` 关键字在执行时，底层会自动完成以下四个关键步骤（面试必背）：

1. **开辟内存空间**
   - 在内存中创建一个新的空对象，用于存储即将创建的新对象。
2. **绑定 `this` 指向**
   - 将构造函数内部的 `this` 指向这个新创建的对象，使其成为当前上下文。
3. **执行内部代码并绑定属性/方法**
   - 执行构造函数内部的代码，为新对象绑定属性和方法（例如 `this.name = name`）。如果不执行这一步，属性和方法就只是摆设。
4. **返回新创建的对象**
   - 自动返回这个新创建的对象。
   - **注意**：构造函数内部**不需要**手动写 `return`，`new` 关键字会自动帮你完成返回操作。

## 3. 构造函数中 `return` 关键字的使用规则 *Content-[09:48]

既然 `new` 会自动返回新对象，如果在构造函数中手动使用 `return` 关键字，会产生以下两种情况：

### 情况一：返回非对象类型（无效）
- **包含类型**：数字、布尔值、字符串、`undefined`、`null` 等基本数据类型。
- **执行结果**：**无效**。当使用 `new` 调用时，手动 `return` 的基本类型值会被忽略，依然返回新创建的对象。
- **示例**：
  ```javascript
  function Person(name) {
      this.name = name;
      return 99;       // 无效
      return true;     // 无效
      return "string"; // 无效
      return undefined;// 无效
      return null;     // 无效
  }
  let p1 = new Person("小强"); 
  // p1 依然是新创建的 Person 实例对象
  ```

### 情况二：返回对象类型（有效 / 寄生式对象）
- **包含类型**：普通对象、数组（数组也是对象）等引用数据类型。
- **执行结果**：**有效**。当使用 `new` 调用时，将不再返回新创建的对象，而是返回 `return` 指定的这个对象。
- **概念解析**：这被称为 **“寄生式对象”**。就像鸠占鹊巢一样，原本应该返回 `new` 创建的实例，结果被返回的自定义对象替代了。
- **示例**：
  ```javascript
  function Person(name) {
      this.name = name;
      return { name: "小黑", age: 99 }; // 返回对象类型
  }
  let p1 = new Person("小强"); 
  // p1 变成了 { name: "小黑", age: 99 }，而不是 Person 实例
  ```
- **开发建议**：在实际开发中，应**尽量避免**在构造函数中返回对象类型，以免造成逻辑混乱和类型误判。
