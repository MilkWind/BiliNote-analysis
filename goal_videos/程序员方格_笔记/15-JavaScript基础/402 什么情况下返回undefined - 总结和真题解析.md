## 知识点总结：返回 undefined 的八种情况 *Content-[00:00]

1\. **声明变量但未初始化**：使用 `let` 或 `var` 声明变量但未赋予初始值。
2\. **访问对象上不存在的属性**：尝试读取对象中未定义的键。
3\. **函数形参未传递实参**：函数定义时设置了形参，但调用时未传递对应的实参。
4\. **变量被手动赋值为 `undefined`**：虽然实际开发中意义不大，但为了知识点的完整性需要掌握。
5\. **函数没有 `return` 语句**：函数执行完毕但没有显式返回值。
6\. **函数写了 `return` 但未赋值**：有 `return` 关键字但后面没有跟具体的返回值。
7\. **访问数组超出界限的索引**：读取数组中不存在的索引位置。
8\. **访问稀疏数组的空插槽**：读取稀疏数组（存在空插槽/间隙）中未定义元素的位置。

**补充说明**：
- `undefined` 是 JavaScript 的原始数据类型，代表“未定义”。
- `undefined` 是被动默认值（系统自动赋予），而 `null` 是主动空值（开发者手动赋予）。

## 真题解析 *Content-[01:47]

### 1\. 题目一：什么情况下会返回 undefined 及补充答题加分点 *Content-[01:47]
- **基础回答**：即上述提到的八种情况。
- **加分点**：主动补充 `undefined` 是 JS 的原始数据类型，代表“未定义”，区别于 `null`。`undefined` 是被动默认值，`null` 是主动空值。如果面试官没问，可不主动说；若问及则详细展开。

### 2\. 题目二：undefined 和 null 的核心区别是什么 *Content-[02:17]
- **语义与赋值方式**：
  - `undefined`：被动的“未定义”，表示本该有值但未被赋值，是 JS 自动赋予的默认值（如声明变量未赋值、访问对象不存在的属性等）。
  - `null`：主动的“空值”，表示刻意为空，是开发者手动赋值给变量或属性的空值（如 `let a = null` 代表明确让该值为空）。
- **类型判断 (`typeof`)**：
  - `typeof undefined` 返回 `"undefined"`。
  - `typeof null` 返回 `"object"`（这是 JS 的历史遗留 bug，具体原因可参考数据类型相关课程）。
- **数值转换规则**：
  - 在数值转换（`Number()`）时，`undefined` 会转为 `NaN`。
  - `null` 会转为 `0`。

### 3\. 题目三：找出以下代码中的错误并修正，说明哪里会出现 undefined *Content-[03:19]
**代码中会出现 `undefined` 的地方及原因**：
1\. **变量未初始化**：`let num;` 声明了 `num` 但未初始化，此时 `num` 为 `undefined`。
2\. **访问对象不存在的属性**：访问 `person.weight`，但 `person` 对象上没有 `weight` 字段，返回 `undefined`。
3\. **函数形参缺省**：调用 `add(5)` 时，只传了参数 `a`，没有传参数 `b`，导致形参 `b` 为 `undefined`。
4\. **`return` 单独成行**：`return` 关键字单独成行，JS 会自动插入分号，相当于 `return;`，没有返回值，因此返回 `undefined`。
5\. **数组越界/稀疏数组**：访问 `arr[2]`，但数组只有两位（索引 0 和 1），没有索引 2，返回 `undefined`。结合短路表达式 `arr[2] || 0`，因为 `arr[2]` 是 `undefined`（假值），所以最终结果为 `0`。

**修正方法**：
- 给 `num` 赋初始值。
- 将 `return` 和返回值写在同一行，避免自动分号插入。
- 给函数参数 `b` 设置默认值（如 `function add(a, b = 0)`），未传参时走默认值 `0` 而不是 `undefined`。
- 使用短路表达式 `arr[2] || 0` 或可选链来处理数组越界问题，避免直接使用 `undefined` 导致后续报错。

### 4\. 题目四：为什么函数写了 return 却还是返回 undefined *Content-[06:24]
- **核心原因**：JavaScript 的**自动分号插入规则（ASI, Automatic Semicolon Insertion）**。
- **原理解析**：当 `return` 语句单独成行，且后面没有任何值并换行时，JS 解析器会自动在 `return` 后面添加分号，将代码解析为 `return;`。这表示函数没有明确的返回值。
- **结果**：根据 JS 规则，所有无明确返回值的函数默认返回 `undefined`。
- **避坑方法**：务必将 `return` 的返回值和 `return` 关键字写在同一行，避免触发 JS 的自动分号插入机制。

### 5\. 题目五：什么是稀疏数组？访问稀疏数组会有什么问题 *Content-[07:09]
- **稀疏数组定义**：JS 中一种特殊的数组，指数组中存在空插槽（间隙），部分索引没有定义对应的元素，数组元素不连续。例如 `[1, , 3]`，中间是一个空插槽。
- **对比密集数组**：密集数组是指元素连续无间隙、所有索引都有对应值的正常数组。
- **访问问题**：访问稀疏数组的空插槽索引时，会返回 `undefined`。如果开发中未做判断直接使用该值（如调用方法或进行数值计算），会导致后续代码报错。
- **避坑方法**：
  - 开发中尽量避免主动创建稀疏数组。
  - 如果需要创建固定长度的数组，请使用数组构造函数并结合 `fill()` 方法进行固定填充。例如：`new Array(3).fill(0)`，创建一个长度为 3 且每个元素都是 `0` 的密集数组，而不是包含 3 个空位的稀疏数组。

### 6\. 题目六：const 声明的变量会返回 undefined 吗 *Content-[08:29]
- **答案**：不会。
- **原因**：`const` 用于声明常量，其语法规则要求**声明时必须立即初始化**，不能只声明不赋值。
- **结果**：如果尝试 `const a;` 而不赋值，JS 引擎会直接抛出语法错误（`SyntaxError: Missing initializer in const declaration`），而不是返回 `undefined`。变量返回 `undefined` 的前提是“只声明未初始化”，而 `const` 无法做到只声明不赋值。

### 7\. 题目七：开发中如何安全访问对象的嵌套属性，避免 undefined 的报错 *Content-[09:01]
推荐三种做法：
1\. **逻辑与 (`&&`) 逐层判断**：
   - 逐层判断属性是否存在，存在则继续访问。利用短路特性，如果某一层为假（`undefined` 或 `null`），则停止向后访问。
   - 示例：`obj && obj.info && obj.info.phone`。
2\. **可选链操作符 (`?.`)**：
   - ES6+ 开发首选，简洁高效。
   - 属性不存在时直接返回 `undefined` 而不会抛出报错。
   - 示例：`obj?.info?.phone`。
3\. **逻辑或 (`||`) 设置默认值**：
   - 结合可选链使用，当属性不存在（返回 `undefined`）时，赋予一个默认值。
   - 示例：`obj?.info?.phone || '暂无电话'`。如果 `phone` 字段不存在，则显示“暂无电话”。
