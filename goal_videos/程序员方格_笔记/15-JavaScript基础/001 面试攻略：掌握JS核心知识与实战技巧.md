## 面试痛点与课程目标 *Content-[01:41]
- **常见面试痛点**：
  - **底层原理卡壳**：平时项目中 API 都会用，但面试官追问底层原理（如闭包的本质、Event Loop 的执行机制、原型链的查找过程）时突然卡壳，无法组织语言。
  - **手写代码薄弱**：倒在面试的手写代码或场景题上，如现场手写 Promise、实现防抖节流、深拷贝的完整实现等。
- **核心认知**：概念理解只是第一步，面试官更看重如何运用知识解决实际问题。“会用 JS”和“能讲清楚 JS 原理”之间隔着一道墙。面试是沟通的过程，清晰、有逻辑地传递理解是大厂非常看重的能力。
- **课程核心目标**：
  - 拒绝死记硬背八股文答案。
  - 帮助学习者在相对短的时间内，构建一套真正属于自己的、可迁移的、可结构化的 JavaScript 面试表达体系。
  - 学完后能像有经验的前端专家一样去思考问题、表达观点。

## 课程三大核心主线 *Content-[04:47]
1\. **主线一：夯实基础（从语法到原理的深度理解）**
   - 基础概念的掌握程度直接决定面试表现。
   - 面试官期待的不是背诵标准定义，而是结合具体代码示例，用自己的话把概念讲透彻。
   - **核心探讨内容**：JavaScript 数据类型及其内存存储方式、闭包的本质与精髓、原型和原型链的查找机制等。
2\. **主线二：实战导向（知道是什么，更要讲清楚怎么用）**
   - JavaScript 本质上是面向实践的编程语言，面试官更在意实际应用场景和“为什么要这样写”。
   - 答题不是背诵，而是用有条理、有重点的表达方式讲出理解，让面试官快速 get 到思路。
   - **实战表达示例**：用三句话讲清楚 Promise、async/await 的使用场景和注意事项；在十几秒内快速解释 Event Loop 中宏任务和微任务的执行顺序。
3\. **主线三：手写代码（必考环节与底层逻辑考察）**
   - 手写已成为 JS 面试的必考环节，用于筛选人才并考察对底层逻辑的理解。
   - **高频手写 API**：bind、call、apply、Promise 核心逻辑、防抖节流、深拷贝、各种输入方法模拟等。
   - 理解 API 背后的运行机制，能让相关问题的回答更有深度和说服力。

## 课程六大核心模块 *Content-[08:29]
课程将 JavaScript 面试中最常被考察的知识点浓缩为六个核心模块（共 50 多集精讲）：
- **模块一：基础语法与运行机制**
  - 深入讲解数据类型、变量声明、作用域、执行上下文、this 指向。
  - 这些看似基础的知识是面试官最爱追问的地方，也是区分初级和中级工程师的关键。
- **模块二：函数进阶**
  - 函数是 JavaScript 的一等公民。
  - 重点掌握闭包、高阶函数、柯里化、bind/call/apply，并包含大量手写实现以理解底层机制。
- **模块三：异步机制与事件循环**
  - 异步编程是核心特性与面试重中之重。
  - 学习路径：从 setTimeout 逐步深入到 Promise、async/await，最后到 Event Loop 的完整机制。
  - 包含大量场景分析和输出题考察。
- **模块四：原型继承与面向对象**
  - 彻底搞懂 JS 原型链机制。
  - 涵盖原型对象、继承方式、构造函数到 ES6 class 的演进，建立对面向对象编程的深刻理解。
- **模块五：高频手写题和实战模拟**
  - 最实战的部分，手写核心功能：Event Emitter、LRU、深拷贝、JSON.stringify 等。
  - 每一个实现都从需求分析开始，到完整的代码实现和边界处理一一呈现。
- **模块六：JavaScript 运行机制进阶及安全性**
  - 了解 JS 与浏览器的协作机制。
  - 进阶主题包括：单线程模型、事件委托、内存管理、安全防护等。
