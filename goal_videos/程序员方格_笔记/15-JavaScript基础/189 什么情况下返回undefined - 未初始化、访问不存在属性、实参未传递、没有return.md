## 函数定义形参但未传递实参 *Content-[00:00]

在 JavaScript 中，函数参数分为形参和实参，理解两者的区别是掌握此场景的基础：

- **形参（Formal Parameter）**：函数定义时括号里的参数，属于形式上的参数。例如在 `function fn(a)` 中，`a` 就是形参。
- **实参（Actual Parameter）**：函数调用时括号里实际传递的参数。例如在 `fn(1)` 中，`1` 就是实参。

**核心规则**：当函数调用时，如果没有传递对应的实参，JS 引擎会给该形参赋予默认值 `undefined`。简而言之：**有形参但没有对应的实参，该形参的值就是 `undefined`**。

## 代码案例与 JS 分号避坑指南 *Content-[01:57]

通过以下三个具体案例来验证上述规则，并学习相关的代码避坑技巧：

### 案例一：普通函数形参未传实参
```javascript
function fn(a) {
    console.log(a);
}
fn(); // 调用时不传参
```
- **结果**：输出 `undefined`。
- **原因**：形参 `a` 没有对应的实参传递。

### 案例二：自执行函数（IIFE）
```javascript
// 注意：如果上面有普通函数调用，这里必须加分号
;(function(a) {
    console.log(a);
})(); // 没有传递实参
```
- **结果**：输出 `undefined`。
- **原因**：同样没有传递实参。
- **⚠️ 避坑技巧（JS 分号问题）**：在 JS 中，分号通常是可选的，但在某些特定场景下**必须加分号**。例如：当上一行是函数调用，下一行紧接着是自执行函数时，两者之间必须加分号，否则会导致语法解析报错。如果上一行也是自执行函数，同样需要加分号。

### 案例三：多个参数部分传参或不传参
```javascript
function func(a, b, c) {
    console.log(a, b, c);
}
func(); // 一个实参都不传
```
- **结果**：输出三个 `undefined`（`undefined undefined undefined`）。
- **原因**：形参 `a`、`b`、`c` 均没有对应的实参传递。

## 开发避坑技巧：设置参数默认值 *Content-[05:08]

在实际开发中，为了避免形参出现 `undefined` 从而引发潜在 Bug，推荐使用 **ES6 语法**为函数形参设置默认值。

```javascript
function fn(a = 0) {
    console.log(a);
}

fn();    // 不传实参，输出 0（走默认值）
fn(10);  // 传递实参，输出 10（使用传递的值）
```
- **开发建议**：养成优良的编程习惯，在定义函数参数时，尽量根据业务逻辑赋予合理的默认值，从源头上减少 `undefined` 的出现。

## 变量被手动赋值为 undefined *Content-[06:21]

除了函数参数，变量本身也可能出现 `undefined` 的情况。

```javascript
let a = undefined;
console.log(a); // 输出 undefined
```

- **实际意义分析**：在 JS 中，变量声明但未赋值时，其默认值本身就是 `undefined`。因此，开发者主动手动将变量赋值为 `undefined` 在实际业务开发中**没有任何实际意义**。
- **面试考点**：虽然这种写法在实际开发中显得多此一举，但它确实属于变量值为 `undefined` 的场景之一。在面试时答出这一点，可以体现你对知识点掌握的**完整性**。

## 函数没有写 return 语句 *Content-[08:07]

函数的 `return` 语句用于指定函数调用后的返回值。如果函数体内没有编写 `return` 语句，JS 会默认让该函数返回 `undefined`。

### 案例一：无 return 的普通函数
```javascript
function sum(a, b) {
    let total = a + b;
    // 仅计算，没有 return
}

let res = sum(1, 2);
console.log(res); // 输出 undefined
```
- **结果**：`undefined`。
- **对比**：如果在函数末尾加上 `return total;`，则 `res` 的值会变为 `3`。

### 案例二：无 return 的数组遍历函数
```javascript
function getArrItem(arr) {
    arr.forEach(item => {
        console.log(item);
    });
    // 没有 return
}

let result = getArrItem([1, 2, 3]);
console.log(result); // 输出 undefined
```
- **结果**：控制台会先打印数组元素 `1`、`2`、`3`，但最后 `result` 变量的值为 `undefined`。
- **对比**：如果在函数末尾强行加上 `return 90;`，则 `result` 的值会变为 `90`。

### 核心结论
**所有的函数都有返回值**。
- 写了 `return`，则返回指定的值。
- 不写 `return`，则默认返回 `undefined`。
