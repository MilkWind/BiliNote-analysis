## 开发中常见的伪数组类型概述 *Content-[00:00]
- 伪数组（Array-like Object）在前端开发中无处不在，尤其在 DOM 操作和函数开发中极为常见。
- 掌握常见的伪数组类型及其特性是前端面试（尤其是大厂面试）中的高频考点和常见场景题。
- 本笔记将详细讲解开发中最常见的三种伪数组类型，并补充其他相关场景，帮助全面理解伪数组的本质。

## 第一种常见伪数组：DOM 集合 *Content-[00:17]
通过 DOM 方法获取的元素集合都属于伪数组。DOM 集合分为**动态集合**和**静态集合**，两者的区别是大厂面试的必考重点。

1\. **动态集合 (Dynamic Collection)**
- **获取方法**：`document.getElementsByTagName()`、`document.getElementsByClassName()`。
- **核心特性**：会随着 DOM 结构的变化（如元素的添加、删除等）自动更新。
- **代码演示**：
  ```javascript
  // 获取动态集合
  const aDivsDynamic = document.getElementsByTagName('div');
  console.log(aDivsDynamic.length); // 假设初始页面有 2 个 div，输出 2
  
  // 动态新增一个 div，改变 DOM 结构
  const newDiv = document.createElement('div');
  document.body.appendChild(newDiv);
  
  console.log(aDivsDynamic.length); // 自动更新为 3
  ```

2\. **静态集合 (Static Collection)**
- **获取方法**：`document.querySelectorAll()`、`document.childNodes`。
- **核心特性**：获取后即为固定结果，**不会**随着 DOM 结构的变化而自动更新。
- **代码演示**：
  ```javascript
  // 获取静态集合
  const aDivsStatic = document.querySelectorAll('div');
  console.log(aDivsStatic.length); // 假设初始页面有 2 个 div，输出 2
  
  // 动态新增一个 div，改变 DOM 结构
  const newDiv = document.createElement('div');
  document.body.appendChild(newDiv);
  
  console.log(aDivsStatic.length); // 保持不变，依旧为 2
  ```

3\. **验证 DOM 集合为伪数组**
- 无论是动态集合还是静态集合，本质上都是伪数组，不能直接调用真数组原型上的方法。
- **验证方法**：尝试调用数组的 `.map()` 方法。
  ```javascript
  aDivsDynamic.map(() => {}); // 报错：map is not a function
  aDivsStatic.map(() => {});  // 报错：map is not a function
  ```
- **结论**：报错证明它们不是真正的数组，而是伪数组。

## 第二种常见伪数组：arguments 对象 *Content-[07:20]
`arguments` 是函数内部的一个对象，用于存储传入的所有实参。
- **重要限制**：`arguments` 仅存在于**普通函数**中，**箭头函数**没有 `arguments` 对象。

1\. **普通函数中的 arguments**
- 具有 `length` 属性，表示传入实参的个数。
- **验证是否为真数组**：
  ```javascript
  function test(a, b) {
      console.log(arguments.length); // 输出：2
      console.log(Array.isArray(arguments)); // 输出：false，证明是伪数组
      
      // 尝试调用数组方法
      arguments.map(() => {}); // 报错：arguments.map is not a function
  }
  test(1, 2);
  ```

2\. **箭头函数中的 arguments**
- 在箭头函数中访问 `arguments` 会直接报错，因为它不存在于箭头函数的作用域中。
  ```javascript
  const fn1 = (a, b) => {
      console.log(arguments); // 报错：arguments is not defined
  };
  fn1(1, 2);
  ```

## 第三种常见伪数组：FileList 文件集合 *Content-[10:33]
在文件上传场景中，通过 `<input type="file">` 获取的文件集合 `FileList` 也是一种伪数组。它用于存储用户选择的所有文件，具有 `length` 属性和索引。单文件上传时通常取 `fileList[0]`。

- **代码演示与验证**：
  ```html
  <input type="file" id="fileInput" />
  ```
  ```javascript
  const fileInput = document.getElementById('fileInput');

  fileInput.onchange = function() {
      // this 指向 input 元素，this.files 即为 FileList
      const files = this.files; 
      
      console.log(files);       // 打印 FileList 对象
      console.log(files.length); // 输出选择的文件个数，例如 1
      
      // 验证是否为真数组
      console.log(Array.isArray(files)); // 输出：false，证明是伪数组
  };
  ```

## 补充：其他常见的伪数组场景 *Content-[14:44]
除了上述三种最常见的场景外，前端开发中还有以下几种伪数组：

1\. **jQuery 获取的 DOM 集合**
- 使用 `$()` 选择器获取的元素集合本质上也是伪数组。

2\. **字符串的类数组特性**
- 字符串具有 `length` 属性和数字索引，可以按数组方式进行遍历（如使用 `for` 循环），但其本质是基础数据类型，属于广义上的伪数组范畴。

3\. **自定义的伪数组对象**
- 只要对象满足伪数组的条件（具有 `length` 属性和数字索引），即可手动构造伪数组。
  ```javascript
  const likeArray = {
      0: 'a',
      1: 'b',
      length: 2
  };
  ```
