## for...of 循环基础特性 *Content-[00:00]

`for...of` 循环是 ES6 引入的一种遍历机制，具有以下核心特性：

1\. **遍历的是键值（元素本身）**：与 `for...in` 遍历键名（索引）不同，`for...of` 直接遍历集合的键值，可以直接拿到元素的本身。
2\. **过滤无用属性**：
   - 不会遍历原型链（prototype）上的属性。
   - 不会遍历对象自身的非迭代属性。
   - 简而言之，它只遍历对象自身“有用的”、可迭代的属性。
3\. **适用场景**：主要用于遍历**可迭代对象**（Iterable），例如：
   - 数组（Array）
   - 字符串（String）
   - Map 数据结构
   - Set 数据结构
4\. **面试避坑指南**：`for...of` **不能直接遍历普通对象**，这是面试中非常高频的考点和易错点。

## 案例一：使用 for...of 遍历数组 *Content-[00:39]

遍历数组是 `for...of` 最常用也是最推荐的场景。

**代码示例**：
```javascript
const arr = [10, 11, 12, 13];

for (let value of arr) {
    console.log('数组元素:', value);
}
```

**案例详解与核心要点**：
- **直接获取元素**：`for...of` 遍历数组时，直接拿到的是数组元素本身（如 10, 11, 12, 13），而不是索引（0, 1, 2, 3）。它比 `for...in` 先拿索引再取元素的方式更简单、直接且不易出错。
- **数据类型一致**：这里的 `value` 数据类型与数组元素的类型完全一致（例如是 Number 类型）。因此，可以直接对其进行数学运算，例如 `$value + 1$` 会得到 11，而不会像 `for...in` 那样因为拿到字符串索引而导致字符串拼接错误。
- **忽略自定义属性**：即使给数组添加了自定义属性（例如 `arr.index = 5`），`for...of` 也**不会**遍历到该自定义属性，它只遍历数组的数字索引对应的元素。

**`for...in` 与 `for...of` 遍历数组的核心区别总结**：
- `for...in`：拿到的是**索引**（键名）。
- `for...of`：直接拿到的是**元素**（键值）。

## 案例二：使用 for...of 遍历字符串 *Content-[04:01]

字符串在 JavaScript 中属于可迭代对象，因此可以使用 `for...of` 进行遍历。

**代码示例**：
```javascript
const str = '前端高频面试题';

for (let char of str) {
    console.log(char);
}
```

**案例详解**：
- 字符串是可迭代的，`for...of` 可以直接将其拆解，逐个遍历并打印出每一个字符（如“前”、“端”、“高”等）。
- 虽然这个场景在实际开发中不如遍历数组常用，但理解这一点有助于深刻掌握 `for...of` 的适用范围，在面试中能作为加分项。

## 案例三：使用 for...of 遍历普通对象及解决方案 *Content-[05:14]

**直接遍历普通对象会报错**：
```javascript
const obj = { name: '张三', age: 20 };

for (let value of obj) {
    console.log(value);
}
```
**运行结果**：抛出错误 `TypeError: obj is not iterable`。
**原因**：普通对象默认不是可迭代对象（not iterable），因此 `for...of` 无法直接遍历它。这是 `for...in` 和 `for...of` 的核心区别之一，属于面试必考题。

**解决方案**：
如果面试官问“如何让 `for...of` 遍历普通对象”，答案是：**将对象转换为可迭代的数组**。
可以使用 `Object.keys()` 或 `Object.values()` 等方法，具体取决于你的需求：

1\. **遍历键（Key）**：使用 `Object.keys()`
```javascript
const obj = { name: '张三', age: 20 };

// Object.keys(obj) 返回 ['name', 'age']，这是一个可迭代的数组
for (let key of Object.keys(obj)) {
    console.log(key); // 输出: name, age
    // 如果需要取值，可以通过 obj[key] 获取
    console.log(obj[key]); // 输出: 张三, 20
}
```

2\. **遍历值（Value）**：使用 `Object.values()`
```javascript
const obj = { name: '张三', age: 20 };

// Object.values(obj) 返回 ['张三', 20]
for (let value of Object.values(obj)) {
    console.log(value); // 输出: 张三, 20
}
```

## 验证：for...of 不遍历原型链属性 *Content-[09:19]

前面提到 `for...of` 不会遍历原型上的属性，下面通过代码进行验证。

**代码示例**：
```javascript
const obj = { name: '张三', age: 20 };

// 在对象的原型链上添加方法和属性
obj.__proto__.sayHello = function() {
    console.log('hello');
};
obj.__proto__.str = '金小';

// 使用 Object.keys() 结合 for...of 遍历
for (let key of Object.keys(obj)) {
    console.log(key, ':', obj[key]);
}
```

**运行结果与详解**：
- 控制台只会输出对象自身的属性：`name : 张三` 和 `age : 20`。
- 原型链上的 `sayHello` 方法和 `str` 属性**不会**被遍历到。
- 这进一步印证了 `for...of`（配合 `Object.keys()`）只遍历对象自身可枚举的、有用的属性，完美避开了原型链的干扰。

## 课堂互动与总结 *Content-[11:25]

**互动问题**：
下面哪些数据结构可以直接用 `for...of` 遍历？
1\. 数组
2\. 普通对象
3\. 字符串
4\. 数字

**答案解析**：
- **1\. 数组**：可以。数组是典型的可迭代对象。
- **2\. 普通对象**：不可以。普通对象不是可迭代对象，直接遍历会报错，必须借助 `Object.keys()` 等方法转换。
- **3\. 字符串**：可以。字符串在 JS 中是可迭代对象，可以逐个遍历字符。
- **4\. 数字**：不可以。数字（Number）不是可迭代对象，没有实现迭代器接口。

**正确答案**：1（数组）和 3（字符串）。
