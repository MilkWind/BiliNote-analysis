## 2. 阻止事件冒泡的方法 *Content-[02:35]

### 2.1 什么是事件冒泡
- **概念**：事件在触发后，会从触发元素开始向上传播，依次经过父元素、爷爷元素，甚至一直传播到 `document` 根元素或 `window` 对象。
- **现象示例**：假设有一个三层嵌套的 DOM 结构（孙子元素、父元素、爷爷元素），且三层都绑定了 `click` 单击事件。当点击孙子元素时，事件会像气泡一样向上升，导致父元素和爷爷元素的 `click` 事件也被依次触发。
- **影响**：如果不加干预，点击子元素会执行三次事件处理函数，这通常违背了开发者的初衷，因此需要阻止冒泡。

### 2.2 阻止冒泡的具体方法

- **方法一：`event.stopPropagation()`**
  - **作用**：立即停止事件在 DOM 树上的进一步传播。
  - **机制**：调用该方法后，事件将不再向上传递，无论是处于捕获阶段还是冒泡阶段，传播都会被立即终止。
  - **使用示例**：在子元素的点击事件处理函数中，获取事件对象并调用 `event.stopPropagation()`。此时点击子元素，只会执行子元素自身的事件，绑定在 `document` 或父元素上的同名事件不会被触发。

- **方法二：`event.stopImmediatePropagation()`**
  - **作用**：不仅阻止事件冒泡，还会阻止当前元素上**其他绑定事件监听器**的执行。
  - **区别与场景**：如果同一个元素上动态绑定了多个同类型的事件监听器（例如绑定了两个 `click` 事件），调用此方法后，不仅事件不会向上冒泡，当前元素上排在它后面的其他监听器也不会被执行。

## 3. 阻止默认事件的方法 *Content-[10:10]

### 3.1 什么是默认事件
- **概念**：浏览器对某些特定 DOM 元素操作的内置默认行为。
- **常见示例**：
  - 点击 `<a>` 标签导致的页面跳转。
  - 提交 `<form>` 表单导致的页面刷新。
  - 鼠标右键点击弹出的浏览器系统默认菜单。
- **目的**：在自定义交互逻辑时，需要阻止这些默认行为“捣乱”，以确保自定义的 JavaScript 逻辑能够正常执行。

### 3.2 阻止默认事件的具体方法

- **方法一：`event.preventDefault()`**
  - **作用**：取消事件的默认行为，但**不会**阻止事件冒泡。
  - **使用示例**：获取 `<a>` 标签元素并绑定 `click` 事件，在事件处理函数中调用 `event.preventDefault()`。
  - **效果**：点击链接时，不会发生页面跳转，但元素依然可以被点击，且事件会继续向父元素冒泡（如果父元素绑定了事件，父元素的事件仍会触发）。

- **方法二：`return false`**
  - **作用**：同时阻止默认行为和事件冒泡。
  - **限制条件**：此方法仅适用于 **jQuery** 事件处理或 **内联事件**（如 HTML 标签中的 `onclick="..."`）。在现代原生 JavaScript 的标准事件监听中，不推荐使用此方法来同时阻止两者。

## 4. 应用场景与注意事项 *Content-[13:37]

### 4.1 常见应用场景
1. **防止表单提交刷新**：在表单的 `submit` 事件中调用阻止方法，防止页面刷新，常用于实现 AJAX 异步数据提交。
2. **自定义右键菜单**：阻止浏览器默认的右键菜单弹出，从而在页面上显示开发者自定义的 UI 菜单。
3. **事件委托中的冒泡控制**：在使用事件委托时，有时需要阻止子元素的事件冒泡到父元素，防止父元素重复处理或错误解释该事件。

### 4.2 关键注意事项
1. **事件对象的显式接收**：所有阻止事件的方法（如 `stopPropagation`、`preventDefault`）都来源于**事件对象**。因此，必须在事件处理函数的参数中显式接收该对象（例如 `function(event) {}` 或 `(e) => {}`），否则无法调用这些方法。
2. **浏览器兼容性**：`preventDefault()` 和 `stopPropagation()` 是 W3C 标准方法，兼容所有现代浏览器以及 IE9 及以上版本。在实际开发中，应优先使用这些标准方法以确保代码的健壮性。
