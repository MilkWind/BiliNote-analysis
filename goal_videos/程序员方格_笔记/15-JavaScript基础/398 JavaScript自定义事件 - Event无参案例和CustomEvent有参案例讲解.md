## 1. Event 无参自定义事件实战案例 *Content-[00:00]

本章节主要讲解如何使用 `Event` 构造函数创建无参数的自定义事件，并实现点击元素时同时触发内置事件与自定义事件的需求。

### 核心三部曲
理解自定义事件的核心在于掌握以下三个步骤：
1. 创建自定义事件
2. 绑定自定义事件
3. 触发自定义事件

### 详细实现步骤

**第一步：获取 DOM 元素**
首先需要获取需要绑定事件的 DOM 元素（例如一个矩形盒子）。
```javascript
const elem = document.getElementById('outSeat');
```

**第二步：创建自定义事件**
使用 `new Event()` 构造函数来创建自定义事件。
```javascript
const myEvent = new Event('customEvent');
```
> **⚠️ 重点注意**：这里的 `'customEvent'` 是我们自定义的事件名称，**并不是**指 `CustomEvent` 构造函数。两者名字相似但完全是不同的东西，切勿混淆。

**第三步：绑定自定义事件**
使用 `addEventListener` 给元素绑定我们刚刚创建的自定义事件，并编写回调函数。
```javascript
elem.addEventListener('customEvent', function() {
    console.log('我是自定义事件');
});
```

**第四步：触发自定义事件**
给元素绑定原生的 `click` 点击事件，在回调函数中先触发内置事件逻辑，然后使用 `dispatchEvent` 方法手动触发自定义事件。
```javascript
elem.addEventListener('click', function() {
    console.log('我是内置事件');
    // 使用 dispatchEvent 触发自定义事件
    elem.dispatchEvent(myEvent); 
});
```

### 运行效果
点击灰色盒子后，控制台会依次打印出：
1. `我是内置事件`
2. `我是自定义事件`

## 2. CustomEvent 有参自定义事件实战案例 *Content-[05:29]

在实际开发中，99% 的场景都需要在自定义事件中传递参数。本章节讲解如何使用 `CustomEvent` 构造函数创建带参数的自定义事件，这是开发中最常用的写法。

### 核心传参机制
带参自定义事件的核心是通过事件对象上的 **`detail`** 属性来携带和传递参数，`detail` 属性可以传递任意类型的数据（如对象、数组、字符串等）。

### 详细实现步骤

**第一步：获取 DOM 元素**
与无参案例相同，获取目标元素。
```javascript
const elem = document.getElementById('outSeat');
```

**第二步：创建带参数的自定义事件**
使用 `new CustomEvent()` 构造函数，第二个参数是一个配置对象，通过 `detail` 属性传递数据。
```javascript
const myCustomEvent = new CustomEvent('customEvent', {
    detail: {
        name: '你好'
    }
});
```
> **⚠️ 重点注意**：
> - `CustomEvent` 是构造函数（首字母大写 C）。
> - `'customEvent'` 是自定义的事件名称（首字母小写 c）。
> - `detail` 是专门用于携带自定义数据的属性。

**第三步：绑定自定义事件并获取参数**
在事件回调函数中，通过事件对象 `e` 的 `e.detail` 来获取传递过来的参数。
```javascript
elem.addEventListener('customEvent', function(e) {
    console.log('我是自定义事件');
    
    // 获取传递的参数
    console.log('传递的参数是:', e.detail);
    
    // 或者获取具体的字段
    console.log('传递的参数name是:', e.detail.name);
});
```

> **🚨 避坑指南（关于对象打印）**：
> 在控制台打印时，**千万不要使用字符串拼接**（例如：`console.log('参数是' + e.detail)`）。因为对象在与字符串拼接时会被隐式转换为 `[object Object]`，导致无法查看真实数据。
> **正确做法**：要么单独打印 `e.detail`（如 `console.log('参数是:', e.detail)`），要么拼接具体的字段值（如 `e.detail.name`）。

**第四步：触发自定义事件**
同样在 `click` 事件中，使用 `dispatchEvent` 触发带参的自定义事件。
```javascript
elem.addEventListener('click', function() {
    console.log('我是内置事件');
    elem.dispatchEvent(myCustomEvent);
});
```

### 运行效果
点击橙色按钮后，控制台会依次打印出：
1. `我是内置事件`
2. `我是自定义事件`
3. `传递的参数是: {name: '你好'}` （或具体字段 `你好`）

## 3. AI 总结

本视频详细讲解了前端面试高频考点——**JavaScript 自定义事件**的实战应用，核心内容可总结为以下两点：

1. **无参自定义事件 (`Event`)**：掌握了自定义事件的“核心三部曲”（创建、绑定、触发）。使用 `new Event('eventName')` 创建事件，通过 `addEventListener` 绑定，最后利用 `dispatchEvent` 在特定时机（如点击事件回调中）手动触发。
2. **有参自定义事件 (`CustomEvent`)**：针对实际开发中需要传递数据的场景，使用 `new CustomEvent('eventName', { detail: data })` 来创建事件。核心在于利用 `detail` 属性携带任意类型的数据，并在回调函数中通过 `e.detail` 提取。同时强调了在控制台打印对象参数时，应避免字符串拼接导致的 `[object Object]` 问题。

掌握这两种自定义事件的用法，不仅能应对大厂前端面试中的八股文追问，也能在实际复杂组件通信（如跨组件状态传递）中灵活运用。
