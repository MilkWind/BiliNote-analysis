## slice 方法概述 *Content-[00:00]
- **核心作用**：用于截取数组中指定范围的元素。
- **主要特性**：
  - **不改变原数组**：`slice` 方法不会删除或修改原数组中的元素，它是通过浅拷贝的方式实现截取。
  - **返回新数组**：操作完成后，会返回一个全新的数组对象，原数组保持不变。
- **截取规则**：提取的元素范围由 `start` 和 `end` 两个参数决定，遵循 **“包含开始（start），但不包含结尾（end）”** 的原则（即含头不含尾）。

## 参数 start 详解与示例 *Content-[00:33]
`start` 是可选参数，表示提取起始处的索引，索引从 `0` 开始计算。

- **正数索引**：从该索引处开始提取原数组的元素。
  - **示例**：对于数组 `arr = [1, 2, 3, 4, 5]`，执行 `arr.slice(0, 1)`。
  - **解析**：从索引 `0` 开始提取，到索引 `1` 结束（不包含 `1`）。返回值是一个新数组 `[1]`。此时原数组 `arr` 依然是 `[1, 2, 3, 4, 5]`。如果将原数组索引 `0` 的元素改为 `100`，则返回的新数组中对应的元素就是 `100`，强调返回值提取的是具体下标对应的元素。
- **负数索引**：如果参数为负数，表示从原数组中的**倒数第几个元素**开始提取。
  - **示例**：`arr.slice(-2)`。
  - **解析**：`-2` 代表倒数第二个元素。对于 `[1, 2, 3, 4, 5]`，倒数第二个是 `4`，因此会提取 `4` 和 `5`，返回新数组 `[4, 5]`（包含最后一个元素）。
- **省略参数**：如果省略 `start`，则 `slice` 默认从索引 `0` 开始提取。
  - **示例**：`arr.slice()`。
  - **解析**：从头提取到尾，返回原数组的完整拷贝 `[1, 2, 3, 4, 5]`。
- **超出范围**：如果 `start` 的值超出了原数组的最大索引范围。
  - **示例**：`arr.slice(20)`（原数组最大索引为 `4`）。
  - **解析**：由于找不到起始位置，会直接返回一个**空数组** `[]`。

## 参数 end 详解与示例 *Content-[04:27]
`end` 是可选参数，表示提取终止处的索引，索引同样从 `0` 开始计算。

- **基本规则**：在该索引处结束提取，**包含 `start` 但不包含 `end`**。
  - **示例 1**：`arr.slice(0, 3)`。
  - **解析**：提取索引 `0, 1, 2` 的元素，不包含索引 `3` 的元素。返回 `[1, 2, 3]`。
  - **示例 2**：`arr.slice(1, 4)`。
  - **解析**：从索引 `1`（元素 `2`）开始，到索引 `4`（元素 `5`，但不包含）结束。提取了索引 `1, 2, 3` 的元素，返回 `[2, 3, 4]`。
- **负数索引**：如果 `end` 为负数，表示在原数组中的**倒数第几个元素结束抽取**（且**不包含**该倒数元素）。
  - **示例**：`arr.slice(-2, -1)`。
  - **解析**：`start` 为 `-2`（倒数第二个元素 `4`），`end` 为 `-1`（倒数第一个元素 `5`，但不包含）。因此截取范围只到 `4` 为止，最终返回新数组 `[4]`。
- **省略参数**：如果 `end` 被省略，则 `slice` 会一直提取到原数组的**末尾**。
  - **示例**：`arr.slice(0)` 或 `arr.slice(2)`，都会从指定位置一直提取到数组最后一个元素。
- **大于数组长度**：如果 `end` 的值大于数组的实际长度。
  - **解析**：`slice` 不会报错，而是会一直提取到原数组的**末尾**。例如 `arr.slice(0, 100)`，结果依然是 `[1, 2, 3, 4, 5]`。

## 注意事项与面试避坑 *Content-[08:43]
- **负数索引的理解**：在 JS 中，正向数组下标是从 `0` 开始的；但在使用负数作为 `slice` 参数时，负数可以理解为**从下标 `1` 开始倒数**（即 `-1` 代表最后一个，`-2` 代表倒数第二个）。面试时需清晰区分正向与负向索引的计算逻辑。
- **核心考点（面试必考）**：
  - `slice` 方法的截取规则严格遵循 **“含头不含尾”**（包含 `start` 索引，不包含 `end` 索引）。
  - **核心区别**：这是 `slice` 和 `splice` 方法的一个核心区别。`slice` 只读取不修改（返回新数组），而 `splice` 会直接改变原数组（用于删除、插入或替换元素），且两者的参数含义完全不同。

## AI 总结
`Array.prototype.slice()` 是前端开发中极其常用的数组方法，也是面试中的高频考点。其核心特性在于**不改变原数组**并**返回一个浅拷贝的新数组**，截取区间严格遵循 **“含头不含尾”** 的原则。在实际应用中，需要特别注意**负数参数**代表从后往前倒数的特殊逻辑，以及参数**省略或越界**时的默认容错行为（如省略 `start` 从头开始，省略 `end` 或越界则提取到末尾）。深刻理解 `slice` 的纯函数特性及其与 `splice` 的本质区别，是应对大厂前端面试的关键。
