## Set 与 Map 集合的遍历方法概述 *Content-[00:00]
- 本部分主要讲解 Set 集合和 Map 集合的统一遍历方式。
- Set 和 Map 集合都提供了四个相同方法名的遍历方法：`keys()`、`values()`、`entries()` 和 `forEach()`。
- 虽然方法名一致，且核心功能相似（都是用于遍历数据结构），但由于 Map 是基于键值对（key-value）的结构，而 Set 是基于单一值的结构，它们在具体返回的内容上会有所区别。

## 数组的统一遍历方式详解 *Content-[01:02]
- 为了更清晰地理解这些遍历方法，视频首先以数组（Array）为例进行演示，因为数组同样具备这四个统一的遍历方法。
- **`keys()` 方法**：
  - 返回一个迭代器对象，包含数组所有的索引值（即键名）。
  - 示例用法：通过 `let it = arr.keys()` 获取迭代器，然后结合 `while` 循环和 `it.next().value` 来遍历并打印出所有的索引值。
- **`values()` 方法**：
  - 返回一个迭代器对象，包含数组所有的元素内容（即键值）。
  - 示例用法：通过 `let it = arr.values()` 获取迭代器，遍历即可取出数组中的所有元素。
- **`entries()` 方法**：
  - 返回一个迭代器对象，同时包含数组所有的索引和元素内容。
  - 每一对键值会被封装成一个小数组，格式为 `[index, element]`。
- **`forEach()` 方法**：
  - 与前三个方法不同，`forEach()` 不返回迭代器对象，而是直接对数据结构进行遍历。
  - 示例用法：`arr.forEach((item, index) => { console.log(item, index) })`。
  - 它会遍历当前数据结构的所有成员，回调函数的参数依次接收元素值和索引。

## Set 集合的遍历特性 *Content-[06:33]
- Set 集合的核心特性是**没有传统意义上的“索引值”和“键值对”概念**，它的键和值都是元素本身。
- **`keys()` 和 `values()` 方法**：
  - 由于 Set 不分键值，这两个方法返回的迭代器中，取出的内容都是 Set 集合中的**元素本身**。
- **`entries()` 方法**：
  - 虽然 Set 没有键值对，但为了保持接口统一，`entries()` 依然会返回迭代器。
  - 返回的每一项是一个小数组，但数组内的键和值都是元素本身，即格式为 `[element, element]`。
- **`forEach()` 方法**：
  - 直接遍历 Set 集合。回调函数中的 `item` 和 `index` 实际上指向的都是同一个元素本身，因此在实际开发中通常只接收一个参数即可。

## Map 集合的遍历特性 *Content-[08:28]
- Map 集合是真正的键值对结构，因此这些遍历方法在 Map 上体现得最为完整和标准。
- **`keys()` 方法**：返回所有键名的遍历器对象（例如 `name`, `age`, `gender` 等）。
- **`values()` 方法**：返回所有键值的遍历器对象。
- **`entries()` 方法**：返回所有键值对的遍历器对象，每一对键值被封装成 `[key, value]` 格式的小数组。
- **`forEach()` 方法**：
  - 直接遍历 Map 集合的所有成员。
  - 回调函数的参数依次为 `value`（值）、`key`（键）以及 Map 对象本身，能够完整且清晰地取出所有的键和值。

## 数据结构统一遍历方式总结 *Content-[09:40]
- 针对 Array、Map、Set、NodeList、String 等具备迭代器接口的数据结构，其统一的遍历方式可以总结为以下 6 种：

1\. **系统默认自带的遍历器**：通过调用 `Symbol.iterator` 函数来获取默认的迭代器。
2\. **迭代器的简化写法**：使用 `for...of` 循环，这是遍历迭代器最简洁的语法。
3\. **`keys()` 函数**：返回包含所有键名的遍历器对象。
4\. **`values()` 函数**：返回包含所有键值的遍历器对象。
5\. **`entries()` 函数**：返回包含所有键值对的遍历器对象。
6\. **`forEach()` 函数**：直接遍历当前数据结构的所有成员（包括键和值），无需手动处理迭代器。

- **补充说明**：
  - 对于普通对象（Object），本身可以使用 `for...in` 循环来遍历其可枚举属性。
  - 对于数组，除了上述方法，依然可以使用最传统的 `for` 循环进行遍历。
