## DOM 0级绑定事件 *Content-[00:22]

### 行内绑定
- **缺点**：
  - 结构和行为没有分离。
  - 维护复杂，不易维护。
- **优点**：
  - 语法简单。
  - 无需获取元素节点。

### 动态绑定
- **优点**：
  - 结构和行为分离。
  - 方便维护。
- **缺点**：
  - 不能绑定同类型事件的多个处理函数，后面的绑定会覆盖前面的绑定。

## DOM 2级事件 *Content-[01:44]

- **核心优势**：
  - 相比于 DOM 0级事件，DOM 2级事件最大的提升和核心优势在于：可以绑定多个同类型事件，且不会相互覆盖。

## addEventListener 方法详解 *Content-[02:19]

### 参数说明
- **第一个参数**：事件类型。
- **第二个参数**：回调函数。
- **第三个参数**：事件流的传播顺序。
  - `false`（默认值）：表示在冒泡阶段触发。
  - `true`：表示在捕获阶段触发。

### 注意事项
- **事件类型**：无需加 `on` 前缀。
- **`this` 指向**：事件处理函数内部的 `this` 会指向触发事件的元素（实测打印 `this` 确实指向绑定的 DOM 元素）。
- **执行顺序**：可以绑定多个事件，按照绑定顺序执行，即先绑定的先执行，后绑定的后执行。
- **参数数量**：一共三个参数。
- **兼容性**：兼容现代浏览器。

## attachEvent 方法详解 *Content-[05:58]

### 参数说明
- **第一个参数**：事件类型。
- **第二个参数**：回调函数。
- **注意**：没有第三个参数。因为 IE 浏览器遵循的事件流机制只有冒泡，所以无需通过第三个参数来控制事件流是冒泡还是捕获。

### 注意事项
- **事件类型**：和 DOM 0级事件一样，绑定事件需要加 `on` 前缀。
- **`this` 指向**：事件处理函数内部的 `this` 指向的是 `window`（在 IE8 中实测打印 `this`，可以看到其属性均属于 `window` 对象）。
- **执行顺序**：可以绑定多个事件，但执行顺序与 `addEventListener` 正好相反，即先绑定的后执行，后绑定的先执行。
- **参数数量**：一共两个参数。
- **兼容性**：仅兼容 <= IE8 的浏览器。

## 移除事件注意事项 *Content-[09:07]

- **`addEventListener` 的移除**：
  - 使用 `removeEventListener` 方法移除事件。
  - **注意**：不能使用匿名函数进行绑定和移除。

- **`attachEvent` 的移除**：
  - 使用 `detachEvent` 方法移除事件。
  - **注意**：同样不能使用匿名函数进行绑定和移除。

## AI 总结

本节课详细总结了 JS 注册事件的几种主要方式及其核心区别：
1. **DOM 0级事件**：分为行内绑定和动态绑定。行内绑定语法简单但耦合度高；动态绑定实现了结构与行为分离，但同类型事件只能绑定一个，后者会覆盖前者。
2. **DOM 2级事件**：解决了 DOM 0级的覆盖问题，支持为同一个元素绑定多个同类型事件。
   - **标准浏览器**使用 `addEventListener`，支持捕获和冒泡（通过第三个参数控制），`this` 指向触发事件的元素，按绑定顺序执行。
   - **IE8及以下浏览器**使用 `attachEvent`，仅支持冒泡（无第三个参数），事件类型需加 `on`，`this` 指向 `window`，且执行顺序与绑定顺序相反。
3. **移除事件**：分别使用 `removeEventListener` 和 `detachEvent`，且两者在移除时都严格要求不能使用匿名函数。掌握这些异同是前端面试中处理事件兼容性和底层机制的关键。
