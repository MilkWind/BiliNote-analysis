## 题目解析与思路 *Content-[00:01]

本题是一道经典的前端字符串处理面试题，要求将带有横杠（`-`）的英文字符串转换为驼峰命名法（Camel Case）格式。

**核心思路**：
1. 首先需要去除字符串中的横杠，并将原字符串拆分成多个独立的单词。
2. JavaScript 提供了原生的字符串分割方法，可以非常便捷地完成拆分。
3. 拆分后得到一个字符串数组，接着遍历该数组，将每个单词的首字母转换为大写。
4. 最后将处理后的单词拼接成一个完整的新字符串并返回。

## 代码实现步骤 *Content-[00:14]

在实际编写代码时，可以按照以下步骤逐步实现（注：实际开发中建议在函数开头增加对参数是否为字符串的类型安全判断，本视频为聚焦核心逻辑暂省略此步骤）：

1. **定义函数**：创建一个名为 `change` 的函数，接收一个字符串参数 `str`。
2. **拆分字符串**：使用 `str.split('-')` 方法，以横杠为分隔符，将原字符串切割成数组。例如 `'a-b-c-d'` 会被拆分为 `['a', 'b', 'c', 'd']`。
3. **初始化变量**：定义一个空字符串 `let finalStr = ''`，用于存放最终拼接的结果。
4. **遍历数组**：使用 `for` 循环遍历拆分后的数组 `arr`，在循环内部对每个单词进行处理。

```javascript
function change(str) {
    let arr = str.split('-');
    let finalStr = '';
    for (let i = 0; i < arr.length; i++) {
        // 处理逻辑
    }
    return finalStr;
}
```

## 核心 API 详解 *Content-[02:17]

在 `for` 循环内部，需要对每个单词进行“首字母大写”和“截取剩余部分”的操作，这里涉及几个关键的 JavaScript 字符串 API：

- **获取当前单词**：通过 `let s = arr[i];` 获取当前遍历到的单词。
- **首字母转大写**：
  - 使用 `s.charAt(0)` 获取字符串的第一个字符（视频中也提及了 ES2022 新增的 `s.at(0)` 方法，两者在此场景下效果一致，但 `charAt` 兼容性更好）。
  - 调用 `.toUpperCase()` 方法将提取出的首字母转换为大写。
  - 组合代码：`s.charAt(0).toUpperCase()`
- **截取剩余部分**：
  - 使用 `slice` 方法截取首字母之后的字符串，起始索引设为 `1`。
  - **易错点提示**：关于结束索引，由于 `slice` 方法具有“包头不包尾”的特性，因此不需要画蛇添足地写成 `s.slice(1, s.length - 1)`，直接写 `s.slice(1)` 即可自动截取到字符串末尾。
  - 组合代码：`s.slice(1)`
- **拼接字符串**：将大写的首字母和剩余的字符串拼接，并累加到结果变量 `finalStr` 中。
  ```javascript
  finalStr += s.charAt(0).toUpperCase() + s.slice(1);
  ```

## 完整代码与总结 *Content-[04:04]

循环结束后，使用 `return finalStr;` 返回最终转换好的驼峰字符串。

**完整代码示例**：
```javascript
function change(str) {
    // 1. 按横杠拆分字符串为数组
    let arr = str.split('-');
    let finalStr = '';
    
    // 2. 遍历数组
    for (let i = 0; i < arr.length; i++) {
        let s = arr[i];
        // 3. 首字母转大写 + 拼接剩余部分
        finalStr += s.charAt(0).toUpperCase() + s.slice(1);
    }
    
    // 4. 返回最终结果
    return finalStr;
}
```

**知识点总结**：
本题主要考察对 JavaScript 字符串常用方法的综合运用能力。熟练掌握 `split`（分割）、`charAt`（获取字符）、`toUpperCase`（转大写）以及 `slice`（截取）等基础 API，能够大幅提升日常开发中的字符串处理效率，是前端面试中的必考基础八股文之一。
