## 2. JS 数据类型详细分类 *Content-[01:55]
JS 的数据类型按照存储方式和值的特性，主要分为**基本数据类型**和**引用数据类型**两大类。

### 基本数据类型（共 7 种）
基本数据类型包含了 JS 中最基础的值，具体包括：
- **ES5 及之前**：`Null`、`Undefined`、`Boolean`、`Number`、`String`。
- **ES6 新增**：`Symbol`（表示独一无二的值）。
- **ES10 (ES2020) 新增**：`BigInt`（视频中口述为 int，用于表示任意精度的整数）。

### 引用数据类型
引用数据类型的核心是 `Object`，但它包含了许多常用的子类型：
- **常见内置对象**：`Array`（数组）、`Date`（日期对象）、`RegExp`（正则表达式）。
- **ES6 新增数据结构**：`Map`、`Set` 等。
这些子类型在底层都属于 `Object` 的范畴。

## 3. 核心区别一：基本数据类型的存放位置 *Content-[03:33]
基本数据类型和引用数据类型的所有其他特性差异，几乎都源于它们在内存中**存储位置**的不同。

### 存储位置与规则
- **存储区域**：基本数据类型直接存储在**栈内存（Stack）** 中。
- **存储内容**：栈内存会为变量分配固定大小的空间，同时存储**变量名（标识符）** 和**实际值**。
- **内存回收**：基本数据类型用完即回收。回收过程由 JS 引擎的垃圾回收机制（Garbage Collection）自动完成，开发者无需手动干预。

### 代码示例与内存模型
```javascript
let name = '小漂亮';
let task = '玩耍';
```
**内存解析**：
在栈区中，直接包含了变量的标识符（`name`、`task`）以及它们对应的具体值（`'小漂亮'`、`'玩耍'`）。标识符和实际数据是紧密结合、共同存放在栈内存中的。

## 4. 核心区别一：引用数据类型的存放位置 *Content-[05:47]
与基本数据类型不同，引用数据类型的存储需要**栈区（Stack）** 和**堆区（Heap）** 配合来完成。

### 存储位置与规则
- **栈区保存**：变量标识符以及**指向堆内存的地址指针**。
- **堆区保存**：**真实的实际数据**。
- **数据获取机制**：当需要获取或操作引用类型的数据时，必须先从栈中拿到地址指针，然后再通过该指针去堆内存中寻址并获取实际数据。

### 代码示例与内存模型
```javascript
let o1 = {};
let o2 = {};
```
**内存解析**：
- **栈区**：存放标识符 `o1`、`o2`，以及它们各自指向堆内存的地址指针。
- **堆区**：存放这两个变量对应的真实对象数据 `{}`。
这种“栈中存指针，堆中存数据”的机制，是理解后续深浅拷贝、对象引用比较等高级概念的核心基础。

## AI 总结
本节详细解析了 JS 中基本数据类型与引用数据类型在**内存存放位置**上的根本区别。基本数据类型直接存储在栈内存中，包含标识符与实际值，具有固定大小且自动回收；而引用数据类型则采用“栈堆结合”的方式，栈内存存储标识符和指向堆内存的指针，真实数据存储在堆内存中。理解这一底层存储机制，是推导两者在值可变性、内存管理、以及对象比较（如 `===` 比较的是内存地址而非内容）等维度差异的前提，也是前端开发者排查内存泄漏和引用赋值 Bug 的必经之路。
