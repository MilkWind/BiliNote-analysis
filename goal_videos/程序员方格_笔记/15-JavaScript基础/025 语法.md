## 1. 区分大小写 *Content-[00:11]

在 JavaScript 的世界中，**区分大小写**是至关重要且最基础的语法规则。

- **变量名**：驼峰命名法（如 `myVariable`）和全小写（如 `myvariable`）会被解析为两个完全独立的变量。
- **函数名**：大写字母和小写字母代表不同的函数，例如 `myFunction` 和 `myfunction` 是两个不同的函数。
- **操作符**：内置操作符必须严格遵循大小写规则，例如 `typeof` 操作符必须全小写才有效，如果写成 `Typeof` 或 `TYPEOF`，JavaScript 引擎将无法识别。

**建议**：在编写代码时，必须养成严格区分大小写的习惯。

## 2. 标识符 *Content-[01:05]

标识符（Identifiers）是我们给变量、函数、属性等起的名字。JavaScript 对标识符的命名有严格的硬性规定：

- **首字符限制**：第一个字符必须是**字母**、**下划线 (`_`)** 或 **美元符号 (`$`)**。
- **后续字符限制**：从第二个字符开始，可以使用**字母**、**数字**、**下划线 (`_`)** 或 **美元符号 (`$`)**。
- **保留字限制**：绝对不能使用 JavaScript 预留的关键字或保留字作为标识符。例如：
  - 控制流关键字：`for`, `if`, `while` 等。
  - 特殊值/布尔值：`true`, `false`, `null` 等。

**命名示例**：
- **合法标识符**：`name`, `_age`, `$price`, `user1`（符合首字符和后续字符规则）。
- **非法标识符**：
  - `1user`：以数字开头，违反首字符规则。
  - `for`, `true`：使用了语言内置的关键字或特殊值。

## 3. 注释 *Content-[02:51]

注释对于提升代码的**可读性**和**可维护性**非常重要。JavaScript 沿用了 C 语言的注释风格，主要分为两种：

- **单行注释**：
  - 语法：以双斜杠 `//` 开始。
  - 作用范围：从 `//` 开始直到该行末尾的内容都会被 JavaScript 引擎忽略。
  - 使用场景：既可以用来注释掉一整行代码，也可以放在代码行末尾进行补充说明。
- **块注释（多行注释）**：
  - 语法：以 `/*` 开头，以 `*/` 结束。
  - 作用范围：可以跨越多个行。
  - 使用场景：非常适合用来编写大段的说明文档，或者在调试时临时禁用（注释掉）一整段代码。

## 4. 严格模式 *Content-[03:57]

**严格模式（Strict Mode）** 是在 ES5 中引入的一个特殊特性，它为 JavaScript 提供了一种更加严格的执行环境。

**使用严格模式的原因/优势**：
1. **更安全的运行环境**：能够将一些原本会静默失败的错误转化为抛出异常，帮助开发者提前发现和定位问题。
2. **禁止不良编程实践**：例如禁止意外创建全局变量，纠正不规范的代码写法。
3. **为未来版本铺路**：一些 JavaScript 未来的新语法特性可能会被要求必须在严格模式下才能使用。

**使用方式**：
- 语法：在脚本文件的头部，或者函数体的第一行，添加一个字符串字面量 `"use strict";`。
- **全局启用**：放在文件最顶部，对整个脚本生效。
- **局部启用**：放在函数体内部的第一行，仅对该函数内部生效，实现更细粒度的控制。

*注：在现代前端开发中，使用工程化脚手架（如 Webpack, Vite 等）构建的项目，严格模式通常是默认开启的。*

## 5. 语句 *Content-[05:42]

语句是构成 JavaScript 程序的基本单位，用于指示浏览器或执行环境去执行某个具体的操作。

- **分号的使用**：
  - 理论上，每个语句都应该以分号 `;` 结尾。
  - 虽然 JavaScript 拥有**自动分号插入机制（ASI, Automatic Semicolon Insertion）**，在大多数情况下不写分号代码也能正常运行，但这可能会引发难以察觉的潜在问题（如代码压缩或换行导致的解析错误）。
  - **强烈建议**：始终在每个语句的末尾手动添加分号，这是一个非常优秀且必要的编码习惯。
- **代码块（Block）**：
  - 语法：使用一对花括号 `{}` 将多条语句组合在一起。
  - 作用：定义了一个**作用域**，将相关的语句组织到一起。
  - 常见场景：在 `if` 条件判断、循环结构（如 `for`, `while`）或函数定义中非常常见。例如，`if` 语句后的花括号内包含的多条语句，共同构成了一个条件执行的代码块。
