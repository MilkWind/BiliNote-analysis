## 基本数据类型的比较方式 *Content-[00:00]

基本数据类型和引用数据类型在比较方式上存在本质差异。对于**基本数据类型**，比较的是其在内存中占用的**实际的值**（即实际数据）。只要实际的值相等，比较结果就为 `true`。

### `===` (全等) 与 `==` (双等) 的区别
在进行基本数据类型比较时，需要特别注意全等（`===`）和双等（`==`）的区别：
- **`===` (全等/三等)**：不仅比较**值**是否相等，还会同时比较**数据类型**是否相同。只有类型和值都相等，结果才为 `true`。
- **`==` (双等/两等)**：只比较**值**是否相等，不比较数据类型。在比较时，它会进行隐式类型转换（例如将字符串转换为数字），转换后如果值相等，结果就为 `true`。

### 代码示例分析
1. **相同类型的值比较**：
   ```javascript
   let m1 = 1;
   let m2 = 1;
   console.log(m1 === m2); // 结果为 true，因为基本类型比较实际的值，两者值均为 1。
   ```

2. **不同类型的值比较**：
   ```javascript
   console.log(1 === '1'); // 结果为 false。使用全等（===）时，数字 1 和字符串 '1' 数据类型不同，因此为 false。
   console.log(1 == '1');  // 结果为 true。使用双等（==）时，不比较类型，会将字符串 '1' 隐式转换为数字 1，值相等，因此为 true。
   ```

### 最佳实践建议
在实际开发中，如果没有特殊情况，**比较操作应全部使用 `===`（全等）**。这样更加严谨，能够有效避免因隐式类型转换带来的潜在 Bug，让程序更具健壮性。

## 引用数据类型的比较方式 *Content-[02:41]

与基本数据类型不同，**引用数据类型**比较的**不是**堆（Heap）内存当中的实际数据，而是它们在栈（Stack）内存中的**地址指针**（引用地址）。

### 核心原理
- 引用类型的数据实际存储在堆（Heap）中，而变量名和指向堆内存的地址指针存储在栈（Stack）中。
- 比较两个引用类型变量时，比较的是它们在栈区中保存的**指向堆内存的地址是否相同**。
- **结论**：即使堆中的真实数据完全相同，只要栈中的指针地址不同，比较结果就是 `false`。

### 代码示例分析
1. **对象比较**：
   ```javascript
   let o1 = {};
   let o2 = {};
   console.log(o1 === o2); // 结果为 false
   ```
   **解析**：虽然 `o1` 和 `o2` 看起来都是空对象（堆中数据相同），但它们在声明时分别在堆中开辟了两块不同的空间。它们在栈中的指针地址各不相同，因此比较结果为 `false`。

2. **数组比较**：
   ```javascript
   let arr1 = [2, 3];
   let arr2 = [2, 3];
   console.log(arr1 === arr2); // 结果为 false
   ```
   **解析**：数组同样属于引用数据类型。尽管两个数组的内容一模一样，但它们在栈中的指针地址不同（各是各的地址），因此比较结果依然为 `false`。

## 引用类型比较为 true 的特殊情况 *Content-[06:43]

引用数据类型想要比较结果为 `true`，必须满足一个核心条件：**两个变量必须指向堆中的同一块数据**。此时，它们在栈中的指针地址才是相同的。

### 代码示例分析
```javascript
let m1 = [1, 2, 3]; // 在堆中开辟一块空间存放数组，栈中的 m1 指向该地址
let m2 = m1;        // 将 m1 的指针地址赋值给 m2，而不是复制实际数据
console.log(m1 === m2); // 结果为 true
```
**解析**：
- 当执行 `let m2 = m1` 时，传递的是指针地址，而非堆中的实际数据。
- 此时，`m2` 获得了和 `m1` 完全相同的指针地址。
- 因为 `m1` 和 `m2` 在栈中的指针地址相同，且指向堆中的同一块数据，所以它们的比较结果为 `true`。

## AI 总结 *Content-[08:19]

本次视频详细讲解了前端面试中高频考点：**基本数据类型与引用数据类型的比较机制**。
1. **基本数据类型**：比较的是内存中的**实际值**。推荐使用 `===` 进行严格比较（同时校验类型和值），以保证代码的严谨性和健壮性。
2. **引用数据类型**：比较的是栈内存中的**指针地址**，而非堆内存中的真实数据。即使两个对象或数组的内容完全一致，只要它们指向不同的内存地址，比较结果即为 `false`。
3. **引用类型的相等条件**：只有当两个变量通过赋值操作（如 `b = a`）指向堆内存中的**同一块数据**（即栈中指针地址相同）时，引用类型的比较结果才会是 `true`。
