## 什么是函数 *Content-[01:50]

- **通俗定义**：函数就是封装好的一段代码，这段代码可以被重复使用。只要调用它，就会执行对应的操作或逻辑。
- **生活案例（榨汁机模型）**：
  - **参数**：放入的水果（如苹果、香蕉）。
  - **执行逻辑**：榨汁操作。
  - **返回值**：输出的果汁（如苹果汁）。
  - **复用性**：只要按要求放入水果，就能完成榨汁，且可以重复使用无数次。

## 创建函数的方式一：函数声明 *Content-[02:34]

- **定义**：使用 `function` 关键字开头，直接声明函数的名称、参数和代码体。格式非常固定，适合零基础快速上手。
- **代码示例**：
  ```javascript
  // 函数声明
  function add(a, b) {
      return a + b;
  }
  
  // 函数调用
  let res1 = add(1, 2); // 结果为 3
  let res2 = add(2, 3); // 结果为 5，可多次复用
  ```
- **格式解析**：
  - `function` 关键字。
  - **函数名**：如 `add`。
  - **参数**：放在小括号 `()` 内，如 `a` 和 `b`。
  - **函数体**：放在大括号 `{}` 内，实现具体的逻辑（如求和）。
- **调用方式**：通过 `函数名(参数值)` 进行调用，获取返回值。
- **核心特点：具有函数提升（预解析）**
  - 可以在函数定义之前进行调用，不会报错。这是因为在代码执行前，JavaScript 引擎会将函数声明提升到当前作用域的顶部。

## 创建函数的方式二：匿名函数表达式 *Content-[06:48]

- **定义**：将一个没有名字的函数（匿名函数）赋值给一个变量或常量。相当于给匿名函数起了一个别名。
- **代码示例**：
  ```javascript
  // 匿名函数表达式
  const isEven = function(a) {
      if (a % 2 === 0) {
          return true;
      } else {
          return false;
      }
  };
  
  // 函数调用
  const flag1 = isEven(4); // true (4是偶数)
  const flag2 = isEven(5); // false (5不是偶数)
  ```
- **格式解析**：
  - 使用 `const` 或 `let` 定义变量/常量。
  - 等号右侧是匿名函数体 `function(参数) { 代码体 }`，函数本身没有名字。
- **调用方式**：只能通过赋值的变量名（如 `isEven`）进行调用。
- **核心特点：没有函数提升**
  - 必须先定义，再调用。
  - 如果在初始化之前调用，使用 `const` 或 `let` 会报错（`Cannot access 'isEven' before initialization`），使用 `var` 则会返回 `undefined`。

## 创建函数的方式三：具名函数表达式 *Content-[11:33]

- **定义**：与匿名函数表达式类似，但函数本身有自己的名字（具名）。
- **代码示例**：
  ```javascript
  // 具名函数表达式（实现阶乘逻辑）
  const fn = function square(a) {
      if (a === 1) {
          return 1;
      } else {
          return a * square(a - 1); // 内部递归调用
      }
  };
  
  // 函数调用
  const res = fn(3); // 结果为 6 (3 * 2 * 1)
  ```
- **核心特点**：
  - **内部可用**：函数内部可以使用自己的名字（如 `square`）进行递归调用自身。
  - **外部不可用**：在函数外部调用该名字（如 `square()`）会报错（`square is not defined`）。外部只能通过变量名（如 `fn()`）来调用该函数。
- *(注：视频讲解中口误称该逻辑为“求平方”，但从代码逻辑 `a * square(a-1)` 及结果 `3*2*1=6` 来看，实际实现的是“求阶乘”功能。)*

## AI 总结

本视频详细讲解了 JavaScript 中创建函数的核心方式，重点对比了**函数声明**、**匿名函数表达式**和**具名函数表达式**三者的语法格式与核心差异。面试中最常考察的考点在于**函数提升（预解析）** 机制：函数声明具有提升特性，可先调用后定义；而函数表达式（无论匿名还是具名）均无提升特性，必须先定义后调用。此外，具名函数表达式的特殊之处在于其函数名仅在函数内部作用域有效，常用于内部递归调用，而在外部无法直接访问该函数名。掌握这些细节是应对大厂前端基础面试的关键。
