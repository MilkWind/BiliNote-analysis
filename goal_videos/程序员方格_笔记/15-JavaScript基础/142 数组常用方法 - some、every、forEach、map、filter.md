## 数组遍历方法通用特性 *Content-[00:00]

在 JavaScript 中，数组的常用遍历方法具有以下几个共同的核心特性：
- **不修改原数组**：这些方法在执行时，都不会改变原始数组的数据。
- **支持回调函数**：均接收一个回调函数作为参数。
- **回调函数参数统一**：
  1\. **item**：代表当前正在遍历的数组元素。
  2\. **index**：代表当前正在遍历的元素下标。
  3\. **array**：代表当前正在被遍历的整个数组。

## some 方法详解 *Content-[00:23]

`some` 方法用于测试数组中是否**至少有一个元素**通过了所提供函数的测试。

### 语法与参数
- **第一个参数**：回调函数，包含 `item`（当前值）、`index`（当前下标）、`array`（处理的数组）。
- **第二个参数**：`this` 指向，即执行回调函数时使用的 `this` 值。

### 返回值与特性
- **返回值**：布尔值（Boolean）。
  - 只要数组中**至少有一个元素**通过回调函数测试，就返回 `true`。
  - 如果**所有元素都没有**通过测试，则返回 `false`。
- **短路遍历**：一旦找到一个符合条件的元素，就会立即停止遍历，不会继续查找后续元素（“有一些”符合即可）。

### 代码示例
```javascript
const arr = [1, 2, 3, 4, 5];

// 判断数组中是否有大于 3 的数
const res = arr.some((item, index, array) => {
    return item > 3;
});

console.log(res); // 输出: true (因为 4 和 5 大于 3，找到 4 时即短路返回)

// 如果没有符合条件的（例如大于 30）
const res2 = arr.some(item => item > 30);
console.log(res2); // 输出: false
```

### 实战场景
- **判断列表中是否包含符合条件的项**：例如在电商平台购物车页面，判断是否有已选中的复选框。如果没有任何商品被选中，则“提交订单”按钮保持禁用状态；只要选中了任意一个商品（使用 `some` 判断为 `true`），提交按钮就会点亮。

## every 方法详解 *Content-[03:58]

`every` 方法用于测试数组内的**所有元素**是否都能通过某个指定函数的测试。

### 返回值与特性
- **返回值**：布尔值（Boolean）。
  - 如果**全部元素**都符合条件，返回 `true`。
  - 只要**有一个元素**不符合条件，就返回 `false`。
- **短路遍历**：一旦找到一个不符合条件的元素，直接停止遍历并返回 `false`（“一假则假”）。

### 代码示例
```javascript
const arr = [1, 2, 3, 4, 5];

// 判断是否全部大于 0
const res1 = arr.every(item => item > 0); 
console.log(res1); // 输出: true

// 判断是否全部大于 4
const res2 = arr.every(item => item > 4); 
console.log(res2); // 输出: false (1,2,3,4 都不符合，遇到 1 即短路)

// 判断是否全部大于 1
const res3 = arr.every(item => item > 1); 
console.log(res3); // 输出: false (只有 1 不符合)
```

### 核心区别与性能
- **some**：一真即真（有一个符合就返回 `true`）。
- **every**：一假则假（有一个不符合就返回 `false`）。
- **性能优势**：二者均为短路遍历，效率高于传统的 `for` 循环（`for` 循环即使已经得出了结论，也会把剩余元素全部遍历完）。

## forEach 方法详解 *Content-[06:09]

`forEach` 方法用于对数组的每个元素执行一次给定的函数。

### 特性与返回值
- **纯遍历**：仅用于执行操作，**没有返回值**。
- **返回值**：始终为 `undefined`。

### 代码示例
```javascript
const arr = [1, 2, 3, 4, 5];

const res = arr.forEach((item, index, array) => {
    console.log(item); // 依次打印 1, 2, 3, 4, 5
});

console.log(res); // 输出: undefined
```

### 核心避坑指南
1\. **不能用 `return` 中断遍历**：在 `forEach` 的回调函数中使用 `return` 只会跳出当前这一次循环，无法终止整个遍历过程。
2\. **不能返回新数组**：因为它本身返回的就是 `undefined`，如果需要生成新数组，请使用 `map` 或 `filter`。

## map 方法详解 *Content-[07:19]

`map` 方法用于创建一个新数组，该新数组由原数组中的每一个元素调用一次提供的函数后的返回值组成。

### 返回值与特性
- **返回值**：一个**新数组**。
- **长度**：新数组的长度与原数组**完全一致**。
- **组成**：新数组的每个元素是原数组对应元素执行回调函数后的结果。

### 代码示例
**示例 1：统一处理数组元素（求 2 的倍数）**
```javascript
const arr = [1, 2, 3, 4, 5];
const res = arr.map(item => item * 2);
console.log(res); // 输出: [2, 4, 6, 8, 10]
```

**示例 2：对象数组提取指定属性**
```javascript
const users = [
    { name: '张三', age: 20 },
    { name: '李四', age: 22 }
];

// 提取所有用户的 name 属性组成新数组
const res = users.map(item => item.name);
console.log(res); // 输出: ['张三', '李四']
```

### 实战场景
- **数据格式化**：对数组所有元素做统一的处理（如数学计算、状态转换）。
- **提取属性**：从对象数组中提取指定的 Key（属性值）组成新的纯值数组。

## filter 方法详解 *Content-[10:32]

`filter` 方法用于过滤数组，返回一个新数组，该新数组包含通过所提供函数测试的所有元素。

### 返回值与特性
- **返回值**：一个**新数组**。
- **长度**：新数组的长度**小于或等于**原数组（如果全部符合则等于，如果有不符合的则小于）。
- **空结果**：如果没有任何元素通过测试，则返回一个**空数组** `[]`。
- **语法简写**：如果使用 ES6 箭头函数且只有一行代码，可以省略大括号和 `return` 关键字。

### 代码示例
**示例 1：基础数值过滤**
```javascript
const arr = [1, 2, 3, 4, 5];

// 筛选大于 3 的元素
const newArr = arr.filter(item => item > 3);
console.log(newArr); // 输出: [4, 5]

// 筛选大于 10 的元素（无符合条件）
const emptyArr = arr.filter(item => item > 10);
console.log(emptyArr); // 输出: []
```

**示例 2：对象数组筛选**
```javascript
const users = [
    { name: '张三', age: 20 },
    { name: '李四', age: 16 },
    { name: '王五', age: 22 }
];

// 筛选年龄大于等于 18 岁的用户
const adults = users.filter(item => item.age >= 18);
console.log(adults); 
// 输出: [{ name: '张三', age: 20 }, { name: '王五', age: 22 }]
```

### 实战场景
- **数组筛选**：筛选列表中符合条件的项目。
- **数据清洗**：过滤掉无效数据、脏数据或不符合业务逻辑的数据项。`filter` 在实际开发中应用场景极多，是非常高效且好用的方法。

## AI 总结

本视频详细讲解了前端开发中 5 种最常用的数组遍历方法，它们均不修改原数组，但在返回值和用途上有显著区别：
1\. **some**：一真即真，用于判断数组中**是否存在**符合条件的元素（返回布尔值，短路遍历）。
2\. **every**：一假则假，用于判断数组中**是否所有元素都**符合条件（返回布尔值，短路遍历）。
3\. **forEach**：纯遍历工具，用于执行副作用操作，**无返回值**（返回 undefined），不能用 return 中断。
4\. **map**：映射工具，用于对数组进行**统一转换或提取**，返回与原数组**等长**的新数组。
5\. **filter**：过滤工具，用于**筛选**出符合条件的元素，返回长度**小于等于**原数组的新数组。

在面试和实际开发中，合理利用这些高阶函数（尤其是利用它们的短路特性）不仅能提升代码的可读性，还能有效提高程序的执行效率。
