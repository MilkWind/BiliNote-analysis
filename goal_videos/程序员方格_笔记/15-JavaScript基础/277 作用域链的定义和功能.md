## 作用域链的核心功能 *Content-[02:38]
- **决定变量访问方式**：作用域链决定了代码在执行时如何去访问变量。
- **重要性**：如果没有作用域链，开发者将无法确定变量在何处、何时被访问，代码执行将陷入混乱。有了它，就能明确多个变量在不同位置的访问规则，是 JavaScript 引擎执行代码的基石。

## 作用域与作用域链的概念 *Content-[03:38]
#### 1\. 什么是作用域 (Scope)
- **定义**：变量和函数的可访问范围（即“势力范围”）。在范围内可以访问变量或调用函数，在范围外则无法访问。
- **三种层次**：
  - 全局作用域 (Global Scope)
  - 函数作用域 (Function Scope)
  - 块级作用域 (Block Scope)

#### 2\. 什么是作用域链 (Scope Chain)
- **链状结构**：将不同的作用域连接起来形成的链式结构。
- **向上查找机制**：
  - 内部作用域可以访问外部作用域的变量（向上走）。
  - 外部作用域**无法**访问内部作用域的变量（不能向下访问）。
  - 例如：全局变量 `A`，函数内变量 `B`，块级作用域内变量 `C`。`C` 可以访问 `B` 和 `A`，`B` 可以访问 `A`，但外部无法访问 `B` 和 `C`。
- **核心目的**：由当前执行环境（函数体或代码块）的变量对象层层嵌套组成，用于**逐级向上查找变量**。

## 作用域链的组成部分 *Content-[08:20]
作用域链主要由以下三部分组成：
1. **当前执行环境的变量对象**：自身作用域内定义的变量（如 `C`）。
2. **外部环境的变量对象**：上一级函数或外部代码块中定义的变量（如 `B`）。
3. **全局变量对象**：最外层的全局作用域中定义的变量（如 `A`）。
- 函数定义时，其所在作用域的变量对象会形成这种链式结构。

## 代码实例与查找顺序 *Content-[09:05]
#### 实例分析
```javascript
let globalVar = "全局变量";

function outer() {
    let outerVar = "外层函数变量";
    
    function inner() {
        let innerVar = "内层函数变量";
        console.log(globalVar); // 访问全局变量
        console.log(outerVar);  // 访问外层函数变量
        console.log(innerVar);  // 访问内层函数变量
    }
    inner();
}
outer();
```
- **功能体现**：在 `inner` 函数中，能够成功输出三层变量，完全得益于作用域链的逐级向上查找机制。如果没有作用域链，这些变量将无法被访问，会输出 `undefined` 或报错。
- **查找顺序**：`inner` 函数的作用域链查找顺序严格为：
  1. `inner` 自身作用域
  2. 外围 `outer` 函数作用域
  3. 全局作用域
- **注意**：链式结构是一级一级嵌套的，不能跳过中间层级直接连接。

## 作用域链的创建时机与规则 *Content-[11:41]
#### 1\. 创建时机
- **函数定义时形成**：作用域链在函数**定义**的时候就已经确定，与函数**调用**的位置无关。
- **词法作用域 (静态作用域)**：作用域链受词法作用域影响，属于静态作用域。

#### 2\. 变量查找规则与实例
```javascript
let x = 1; // 全局变量

function foo() {
    let x = 2; // 函数作用域变量
    
    function bar() {
        console.log(x); 
    }
    bar();
}

let x = 3; // 即使外部有 x = 3
foo(); // 输出 2
```
- **规则**：变量查找从当前作用域开始，逐级向上查找，直到全局作用域。一旦找到匹配的变量，就会直接使用并停止查找（如上述代码输出 `2`，而不是 `3`）。

#### 3\. 闭包 (Closure) 与作用域链
- **保留引用**：函数执行时，会保留对其定义时作用域链的引用。
- **持久访问**：即使外部函数已执行完毕，内部函数（闭包）依然可以通过作用域链访问外部变量。
```javascript
function createCounter() {
    let count = 0; // 初始值为 0
    return function() {
        count++;
        console.log(count);
    };
}
const counter = createCounter();
counter(); // 输出 1。即使 createCounter 已执行完毕，count 变量依然被保留。
```

## 核心知识点总结 *Content-[14:31]
1. **静态特性**：作用域链是静态的，在函数定义时确定，主要用于变量查找。
2. **闭包依赖**：闭包依赖于作用域链，从而实现函数对外部变量的持久访问。没有作用域链，闭包将无法实现。
3. **理解意义**：深入理解作用域链有助于避免变量污染，并能更好地调试复杂的前端问题。
