## 函数的四种调用模式概述 *Content-[00:00]
在 JavaScript 中，函数的调用方式决定了函数内部 `this` 的指向。函数的四种调用模式分别为：
1. 函数调用模式 (Function Invocation)
2. 方法调用模式 (Method Invocation)
3. 构造函数调用模式 (Constructor Invocation)
4. 上下文调用模式 (Context Invocation)

## 1. 函数调用模式 *Content-[00:46]
- **语法**：`函数名()`
- **特点**：函数直接调用，不属于任何对象。
- **`this` 指向**：在非严格模式下，函数内部的 `this` 默认指向全局对象 `window`。

## 2. 方法调用模式 *Content-[01:12]
- **语法**：`对象.方法名()`
- **特点**：函数作为对象的属性存在，通过对象来调用该方法。
- **`this` 指向**：函数内部的 `this` 指向当前调用该方法的对象。

## 3. 构造函数调用模式 *Content-[01:51]
- **语法**：`new 构造函数名()`
- **特点**：通过 `new` 关键字进行调用。`new` 关键字的作用之一是执行函数内部代码，并为当前新创建的对象绑定属性和方法。
- **`this` 指向**：函数内部的 `this` 指向 `new` 关键字新创建的实例对象。

## 4. 上下文调用模式 *Content-[02:54]
- **语法**：`函数名.call()` 或 `函数名.apply()`
- **特点**：这种模式的核心目的是**修改函数内部 `this`（上下文对象）的指向**。
- **示例说明**：
  ```javascript
  let o = { name: '小欧', age: 16, gender: '女' };
  let p = { 
      name: '小P', 
      age: 12, 
      gender: '男', 
      show: function() { 
          console.log("我是" + this.name + "对象的show函数", this); 
      } 
  };
  ```
  - 默认调用 `p.show()` 时，`this` 指向 `p` 对象。
  - 使用 `p.show.call(o)` 或 `p.show.apply(o)`，可以强行将函数内部的 `this` 指向 `o` 对象。此时执行函数，打印出的 `this` 内容即为 `o` 对象的数据。

## call 与 apply 的参数传递区别 *Content-[05:47]
上下文调用模式通过 `call` 和 `apply` 实现，两者的基本语法如下：
- `函数名.call(this指向的新对象, 实参1, 实参2, ...)`
- `函数名.apply(this指向的新对象, [实参1, 实参2, ...])`

**核心区别仅在于传参格式**：
- **`call`**：从第二个参数开始，需要**逐个传递**实参（例如：`show.call(o, 99, 88)`）。
- **`apply`**：从第二个参数开始，需要传递一个**数组**，数组内的元素会作为实参传入（例如：`show.apply(o, [55, 66])`）。

除了传参格式不同外，两者的功能和执行效果完全一模一样。

## 上下文调用模式的实际应用场景 *Content-[11:06]
虽然修改 `this` 指向的功能在某些场景下使用，但 `call` 和 `apply` 的参数传递特性为开发者提供了很多新思路。

### 1. 求数组中的最大值
- **背景**：`Math.max()` 可以接收多个参数并求最大值，但无法直接接收数组作为参数。
- **巧用 `apply`**：
  ```javascript
  let arr = [10, 20, 95, 30];
  let max = Math.max.apply(null, arr); // 结果为 95
  ```
  - **原理**：`apply` 的第二个参数接收数组，它会将数组展开为多个实参传递给 `Math.max`。第一个参数传 `null`，此时 `this` 会默认指向 `window`（因为此处不需要修改 `this`，只是为了利用 `apply` 展开数组的特性）。
  - **补充细节**：如果 `call/apply` 的第一个参数传 `null`、`undefined`、字符串或非对象，`this` 都会被替换为 `window`；只有传入对象时，`this` 才会指向该对象。
- **现状**：ES6 引入了扩展运算符（`...`），现在可以直接使用 `Math.max(...arr)`。因此，`apply` 这种将数组展开为实参的“偏门”用法在实际开发中已较少使用。

### 2. 构造函数继承（借用构造函数）
- **背景**：在定义多个构造函数（如 `Student`、`Teacher`、`Driver`）时，它们都包含与 `Person` 相同的属性（如 `name`、`age`），导致代码大量重复。
- **解决方案**：使用 `call` 实现构造函数的借用（继承）。
  ```javascript
  function Person(name, age) {
      this.name = name;
      this.age = age;
  }

  function Student(name, age, book) {
      // 借用 Person 构造函数
      Person.call(this, name, age);
      this.book = book;
  }

  let s = new Student('小欧', 16, 'JS');
  console.log(s); // 输出包含 name, age, book 属性的对象
  ```
- **原理剖析**：
  1. 在 `new Student()` 时，`this` 指向新创建的 `Student` 实例对象。
  2. 执行 `Person.call(this, name, age)` 时，将 `Student` 的 `this`（即新实例）作为第一个参数传给 `call`。
  3. `Person` 函数内部的 `this` 被强制指向了 `Student` 的新实例。
  4. 因此，`Person` 内部执行的 `this.name = name` 和 `this.age = age`，实际上是给 `Student` 的新实例绑定了 `name` 和 `age` 属性。
  5. 这样就实现了属性的复用，避免了代码重复。无论是 `Teacher` 还是 `Driver`，只要是“人”，都可以使用这种方式复用 `Person` 的属性绑定逻辑。
