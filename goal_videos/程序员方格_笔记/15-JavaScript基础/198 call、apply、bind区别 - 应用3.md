## 扩充函数的作用域 *Content-[00:00]

`call`、`apply` 和 `bind` 真正强大的地方在于能够**扩充函数赖以运行的作用域**，而不仅仅是传递参数。

**基础示例代码**：
```javascript
window.name = '金小镇';
const obj = { name: '小I' };

function sayName() {
    console.log(this.name);
}
```

**不同调用方式下的 `this` 指向分析**：

1\. **直接调用 `sayName()`**：
   - 前面没有明确的调用者，默认由 `window` 对象调用（`this` 指向 `window`）。
   - 结果输出：`金小镇`。

2\. **使用 `sayName.call(this)`**：
   - 在全局 `script` 环境下，`this` 指向 `window`。
   - 结果输出：`金小镇`。

3\. **使用 `sayName.call(window)`**：
   - 显式将 `this` 指向 `window` 对象。
   - 结果输出：`金小镇`。

4\. **使用 `sayName.call(obj)`**：
   - 显式将 `this` 指向 `obj` 对象，改变了函数的执行环境。
   - 结果输出：`小I`。

**核心总结**：
- `sayName` 作为全局函数定义，在全局作用域中调用时，`this.name` 会转换为对 `window.name` 的求值。
- 当运行 `sayName.call(obj)` 时，函数体内的 `this` 对象被显式绑定到了 `obj`，因此输出了 `obj` 中的 `name` 属性值。这就是通过 `call`/`apply` 扩展函数作用域的具体体现。

## 对象与方法的解耦 *Content-[03:25]

使用 `call`/`apply` 来扩充作用域的最大好处是：**对象不需要与方法有任何的耦合关系**。

**解耦示例代码**：
```javascript
// 方法独立定义
function sayName() {
    console.log(this.name);
}

const obj = { name: '小I' };

// 将方法赋值给对象的属性（实现解耦调用）
obj.c = sayName; 
obj.c(); // 此时 this 指向 obj，输出 '小I'
```

**原理解析**：
- 当把 `sayName` 方法赋值给 `obj.c` 并调用 `obj.c()` 时，相当于在对象内部调用了该方法。
- 此时方法内部的 `this` 自然指向了调用它的对象 `obj`，因此输出 `小I`。
- **解耦的意义**：方法依然是独立的方法，对象依然是独立的对象，两者没有直接的代码级耦合，但可以通过 `this` 的指向在运行时动态结合。

## 在 setTimeout 中的应用 *Content-[05:41]

- **默认行为**：在使用 `window.setTimeout` 时，默认情况下回调函数中的 `this` 关键字会指向 `window` 对象。
- **应用场景**：当在类的方法中需要使用定时器，且希望回调函数中的 `this` 指向**类的实例**时，必须显式地绑定 `this`。
- **解决方案**：
  - 可以使用 `bind`（或 `call`/`apply`）将 `this` 显式绑定到回调函数中，防止在定时器执行时丢失对类实例的引用。
  - 示例思路：`setTimeout(this.myMethod.bind(this), 1000);`
