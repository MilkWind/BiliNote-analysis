## 1. 数组的基本特征 *Content-[00:04]
- **有序性**：数据按照索引顺序排列，索引从 0 开始。
- **混合数据类型**：JavaScript 数组不要求所有项为同一数据类型，可混合存储数字、字符串、对象等（这在强类型语言中通常不被允许，体现了 JS 的灵活性）。
- **动态性**：无需在创建时指定固定大小，数组会随着数据的添加自动增长。
- **本质**：从底层实现来看，JavaScript 数组本质上是一种特殊的对象。

## 2. 数组的创建方式 *Content-[01:49]
### 2.1 使用 Array 构造函数
- 使用 `new Array()` 创建空数组或传入参数。
- **陷阱**：当构造函数只接收一个参数且该参数为数字时，创建的不是包含该数字的数组，而是指定 `length` 属性的空数组。例如 `new Array(3)` 创建的是长度为 3 的空数组，而不是包含数字 3 的数组。

### 2.2 使用数组字面量（推荐）
- 使用方括号 `[]` 表示。
- **优点**：书写简洁，能直观定义混合类型或嵌套数组；代码量少；完全避免了构造函数处理单个数字参数时产生的歧义。实际开发中优先使用。

## 3. 核心静态方法 Array.from *Content-[03:10]
ES6 引入，核心作用是将**类数组结构**或**可迭代对象**转换成真正的数组实例。
- **典型场景**：
  1. **转换字符串**：字符串是可迭代的，`Array.from('hello')` 会将其拆解为字符数组 `['h', 'e', 'l', 'l', 'o']`。
  2. **数组去重**：结合 `Set`，`Array.from(new Set(array))` 可实现快速去重。
  3. **处理类数组对象**：只要对象拥有索引属性和 `length` 属性（如 DOM 的 `NodeList` 或函数的 `arguments` 对象），即可转换为真数组。
  4. **映射处理**：接收第二个参数作为映射函数，类似于数组的 `map` 方法，可在创建数组的同时对每个元素进行处理。

## 4. 核心静态方法 Array.of *Content-[04:34]
ES6 引入，用于解决 `Array` 构造函数处理单个参数时的歧义问题。
- **行为统一**：无论传入一个还是多个参数，都会创建一个包含这些参数的新数组。
  - `Array.of(3)` 创建包含数字 3 的数组 `[3]`。
  - `Array.of(1, 2)` 创建包含 1 和 2 的数组 `[1, 2]`。

## 5. 数组空位 *Content-[06:10]
- **概念**：在字面量中使用连续逗号创建数组时会产生空位，如 `[1, , , 4]`。该数组长度为 4，但中间两个位置为空。
- **特性**：访问空位（如 `arr[1]`）会返回 `undefined`，但该索引在数组中实际不存在（使用 `in` 操作符检测返回 `false`）。
- **处理差异**：
  - ES6 之前的方法（如 `map`、`forEach`）通常会**跳过空位**，不执行回调。
  - ES6 新增的方法（如 `Array.from`、扩展运算符）倾向于将空位显式视为 `undefined`，可被正常遍历。
- **最佳实践**：开发中应**尽量避免创建包含空位的数组**。若需要占位符，必须显式使用 `undefined`（如 `[1, undefined, undefined, 4]`），以保证代码行为的一致性和可预测性。

## 6. 数组基础操作与 length 属性 *Content-[08:12]
### 6.1 索引操作
- **读取与修改**：使用方括号加索引值，如 `colors[1] = 'yellow'` 覆盖原值。
- **动态扩展**：若索引超出当前边界（如 `colors[3] = 'purple'`），数组会自动扩展长度并赋值。
- **越界访问**：访问不存在的索引不会报错，而是返回 `undefined`。

### 6.2 length 属性
- **可读写性**：`length` 并非只读计数器，修改它会直接影响数组内容。
- **截断数组**：将 `length` 设置为比当前长度小的值（如从 5 改为 3），数组会从末尾截断，多余元素被永久删除。
- **扩展数组**：将 `length` 设置为更大的值，数组会变长，新增部分为**空位**。
- **清空数组技巧**：通过设置 `arr.length = 0` 可快速清空数组。这比赋值新数组更彻底，因为它在原数组对象上操作，能保持原有的引用关系。

## 7. 如何判断变量是否为数组 *Content-[10:44]
- **不可靠的方法**：
  - `typeof`：对数组无效，`typeof []` 返回 `'object'`。
  - `instanceof Array`：在单一全局作用域下有效。但若网页包含多个框架（如 `iframe`），每个 `iframe` 有独立的全局执行环境，跨框架传递数组时 `instanceof` 会失效。
- **标准答案**：使用 ES6 提供的 `Array.isArray()` 方法。无论在哪个全局环境创建的数组，都能准确返回 `true`。
