## 题目解析与解题原则 *Content-[00:00]
在面对前端面试中的代码输出题时，核心解题原则如下：
* 遇到代码输出题，**一定一定要先进行变量提升（Hoisting）分析，再看输出结果**。
* 不要着急直接看输出，必须先把提升后的代码逻辑彻底搞清楚。
* 本题的最终输出结果为：`undefined`、`10`、`20`。

## 变量提升后的代码还原 *Content-[00:45]
分析本题涉及的代码逻辑，主要包含全局变量、立即执行函数（IIFE）以及局部变量的声明与赋值。
* **全局作用域**：
  * 存在全局变量 `var a = 10;`。
* **立即执行函数（IIFE）内部**：
  * 函数内部存在局部变量 `var a` 的声明与赋值。
  * 根据变量提升规则，局部变量 `var a` 的**声明**会被提升到当前局部作用域的第一行，但**赋值**操作保留在原位。
  * 此外，代码中涉及 `window.a`，用于明确指定调用全局变量。
* **提升后的代码结构示意**：
  ```javascript
  var a = 10; // 全局变量
  (function() {
      var a; // 局部变量声明提升至此
      console.log(a); // 第一次输出
      a = 5; // 局部变量赋值
      console.log(window.a); // 第二次输出
      a = 20; // 局部变量重新赋值
      console.log(a); // 第三次输出
  })();
  ```

## 逐行代码输出分析 *Content-[01:49]
在理清提升后的代码结构后，逐行分析输出结果：

1\. **第一次输出 `console.log(a)`**：
   * 此时局部变量 `a` 仅完成了声明，尚未赋值。
   * 因此，输出结果为 `undefined`。

2\. **局部变量赋值 `a = 5`**：
   * 将局部变量 `a` 的值修改为 `5`。

3\. **第二次输出 `console.log(window.a)`**：
   * 这里使用了 `window.a`，明确指定调用挂载在全局 `window` 对象下的全局变量 `a`。
   * 因为全局变量使用 `var` 声明时默认会挂载到 `window` 对象下，且全局 `a` 的初始值为 `10`，未被修改。
   * 因此，输出结果为 `10`。

4\. **局部变量重新赋值 `a = 20`**：
   * 将局部变量 `a` 的值重新修改为 `20`。

5\. **第三次输出 `console.log(a)`**：
   * 此处没有使用 `window.a` 进行明确指定，因此默认输出当前作用域下的局部变量 `a`。
   * 局部变量 `a` 的最新值为 `20`。
   * 因此，输出结果为 `20`。
