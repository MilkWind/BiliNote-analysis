## call、apply、bind 的区别 *Content-[00:00]

### 相同点 *Content-[00:03]
- 三者都可以改变函数的 `this` 指向。
- 第一个参数都是 `this` 要指向的对象（即指定的上下文）。
- 如果没有传递该参数，或者参数为 `undefined` / `null`，则默认指向全局对象 `window`（非严格模式下）。

### 不同点 *Content-[00:24]
1\. **函数是否立即执行**
- `call` 和 `apply`：在执行后会立即调用前面的函数。
- `bind`：不会立即调用函数，而是返回一个新的函数，可以在任何需要的时候手动进行调用。

2\. **参数的传递方式**
- `call` 和 `bind`：接收的参数形式相同。第一个参数表示将要改变的函数执行主体（`this` 指向），从第二个参数开始到最后一个参数，表示函数接收的参数（逐个传递）。
  - **注意**：`bind` 可以分两次或多次传入参数。在 `bind` 绑定时以参数列表形式传递一次，在调用返回的新函数时再传递一次，最终传递的参数会合并到一起传入函数内部。
- `apply`：第一个参数与 `call`、`bind` 相同。第二个参数是一个数组（或伪数组），表示接收的所有参数。
  - **注意**：如果第二个参数不是一个有效的数组或伪数组，则会抛出类型错误（TypeError）。`apply` 和 `call` 都是一次性传入所有参数。

## 应用1：将伪数组转为真数组 *Content-[01:48]

伪数组（Array-like）具有 `length` 属性，甚至可能有索引，但没有数组的原型方法（如 `push`、`pop` 等）。常见的伪数组包括 DOM 节点集合、函数的 `arguments` 对象以及含有 `length` 属性的自定义对象。

### 场景一：DOM 节点集合 *Content-[01:55]
- **问题描述**：通过 `document.getElementsByTagName('p')` 获取多个 `p` 标签，得到的是一个伪数组。如果直接调用 `push` 方法（如 `ap.push('新元素')`），会报错 `TypeError: push is not a function`，因为伪数组没有数组的方法。
- **解决方法1（循环遍历）**：定义一个新数组，使用 `for` 循环遍历伪数组，将元素逐个 `push` 到新数组中。这种方法比较繁琐。
- **解决方法2（借用 slice 方法 - 推荐）**：利用 `Array.prototype.slice.call(伪数组)`。通过 `call` 将数组的 `slice` 方法的 `this` 指向伪数组，从而返回一个真正的数组。
  ```javascript
  const pElements = document.getElementsByTagName('p');
  const trueArray = Array.prototype.slice.call(pElements);
  // 此时 trueArray 为真数组，可以使用 push 等数组方法
  ```

### 场景二：函数的 arguments 对象 *Content-[07:46]
- **问题描述**：在函数内部，`arguments` 对象也是一个伪数组，包含传入的所有参数，具有 `length` 属性，但无法使用数组方法（如 `arguments.push()` 会报错）。
- **解决方法**：同样使用 `Array.prototype.slice.call(arguments)` 将其转换为真数组。
  ```javascript
  function fn() {
      const argsArray = Array.prototype.slice.call(arguments);
      // argsArray 现在是真数组，可以进行数组操作
      argsArray.push(6); 
  }
  ```

### 场景三：含有 length 属性的自定义对象 *Content-[09:55]
- **问题描述**：自定义一个普通对象，包含数字索引属性和 `length` 属性，它同样符合伪数组的特征。
- **解决方法**：使用 `Array.prototype.slice.call(自定义对象)` 即可将其值提取到一个真正的数组中。
  ```javascript
  const obj = {
      0: 'item0',
      1: 'item1',
      2: 22,
      length: 3
  };
  const arr = Array.prototype.slice.call(obj);
  // arr 为 ['item0', 'item1', 22]
  ```

## 应用2：实现构造函数继承 *Content-[12:03]

- **场景描述**：在 ES5 中，可以通过构造函数来实现类的继承。假设有一个父类 `Parent` 和一个子类 `Child`。
- **实现方式**：在子类的构造函数中，使用 `call` 调用父类的构造函数，并将 `this` 指向子类的实例。
  ```javascript
  function Parent() {
      this.name = 'parent';
  }
  
  function Child() {
      Parent.call(this); // 继承父类属性
      this.type = 'child';
  }
  
  const childInstance = new Child();
  console.log(childInstance.name); // 输出: parent
  console.log(childInstance.type); // 输出: child
  ```
- **原理解析**：借助 `call` 方法，改变了父类构造函数执行时的 `this` 指向，使其指向当前子类的实例。这样父类构造函数中挂载在 `this` 上的属性，都会被添加到子类的实例上，从而实现属性的继承。
