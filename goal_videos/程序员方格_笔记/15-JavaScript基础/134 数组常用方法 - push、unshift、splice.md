## 3. push 方法详解与实战 *Content-[03:33]
- **基本作用**：将一个或多个元素添加到数组的末尾。
- **返回值**：返回调用该方法后，数组的**新长度**（`length`）。
- **是否修改原数组**：**会修改**原数组。
- **参数说明**：可以传入任意类型、数量不限的元素。
- **代码示例**：
  - 假设原数组为 `array = [1, 2, 3, 4, 5]`。
  - 执行 `array.push(6)` 后，原数组变为 `[1, 2, 3, 4, 5, 6]`。
  - 使用变量接收返回值 `let res = array.push(6)`，此时 `res` 的值为 `6`（即新数组的长度）。
- **实战场景**：常用于向接口返回的列表数据尾部追加新的数据。

## 4. unshift 方法详解与实战 *Content-[05:48]
- **基本作用**：将一个或多个元素添加到数组的开头。
- **返回值**：返回调用该方法后，数组的**新长度**。
- **是否修改原数组**：**会修改**原数组。
- **与 push 的对比**：`push` 是向数组末尾（往后）追加，而 `unshift` 是向数组开头（往前）追加。
- **代码示例**：
  - 假设原数组为 `array = [1, 2, 3, 4, 5]`。
  - 执行 `array.unshift(6)` 后，元素 `6` 会跑到原数组 `1` 的前面，原数组变为 `[6, 1, 2, 3, 4, 5]`。
  - 返回值 `res` 同样为 `6`（新数组的长度）。
- **实战场景**：向列表头部添加最新的数据。例如在微信聊天消息列表中，最新的消息需要显示在最前面。

## 5. splice 方法详解与多场景演示 *Content-[07:23]
- **基本作用**：通过删除、替换现有元素或原地添加新元素来修改数组。它是数组方法中非常核心且灵活的“万能方法”（增、删、改均可实现）。
- **返回值**：以**数组形式**返回被修改的内容（即由被删除的元素组成的数组）。如果只删除一个元素，返回包含该元素的数组；如果没有删除元素，返回空数组 `[]`。
- **是否修改原数组**：**会修改**原数组。
- **语法与参数详解**：`array.splice(start, deleteCount, item1, item2, ...)`
  - **start**：指定修改的开始位置（从 0 计数）。
    - 如果超出数组长度，则从数组末尾开始添加内容。
    - 如果是**负值**，表示从数组末位开始的第几位（**从 1 开始计数**，即 `-1` 代表倒数第 1 个元素，等价于 `array.length - 1`）。
    - 如果负数的绝对值大于数组长度，则开始位置视为第 0 位。
  - **deleteCount**（可选）：整数，表示要移除的元素个数。
    - 如果 `deleteCount` 大于 `start` 之后的元素总数，则 `start` 及其后面的所有元素都将被删除。
    - 如果省略 `deleteCount`，或者其值大于等于 `数组长度 - start`，则 `start` 之后的所有元素都会被删除。
    - 如果 `deleteCount` 是 0 或负数，则不移除元素（此时通常用于纯添加操作）。
  - **item**（可选）：要添加进数组的新元素，从 `start` 位置开始插入。如果不指定，则只执行删除操作。

- **多场景代码演示**（基于原数组 `[1, 2, 3, 4, 5]`）：
  - **场景 1：在任意位置添加元素（不删除）**
    - 执行 `array.splice(0, 0, '你好')`：从下标 0 开始，删除 0 个元素，添加 `'你好'`。
    - 结果：原数组变为 `['你好', 1, 2, 3, 4, 5]`，返回值为空数组 `[]`。
  - **场景 2：删除元素并获取返回值**
    - 执行 `array.splice(0, 1)`：从下标 0 开始，删除 1 个元素。
    - 结果：原数组中 `1` 被删除，返回值为 `[1]`。
  - **场景 3：start 参数为负数**
    - 执行 `array.splice(-2, 0, '你好')`：`-1` 是 `5`，`-2` 是 `4`（即下标 3 的位置）。从该位置删除 0 个元素，添加 `'你好'`。
    - 结果：原数组变为 `[1, 2, 3, '你好', 4, 5]`，返回值为空数组 `[]`。
  - **场景 4：deleteCount 大于剩余元素总数**
    - 执行 `array.splice(3, 10, '你好')`：从下标 3（元素 `4`）开始，删除 10 个元素（实际后面只有 `4` 和 `5` 两个），添加 `'你好'`。
    - 结果：`start` 及其后面的元素全被删除，原数组变为 `[1, 2, 3, '你好']`，返回值为被删除的元素组成的数组 `[4, 5]`。
