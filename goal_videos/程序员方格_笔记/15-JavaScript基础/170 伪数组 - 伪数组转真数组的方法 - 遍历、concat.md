## 遍历伪数组手动转换 *Content-[00:04]

### 核心作用与特点
- **作用**：通过 `for` 循环遍历伪数组，将每个元素手动添加到新创建的空数组中。
- **特点**：
  - 是最基础、最“笨”但也是最容易理解的方法。
  - 即使在面试或实际开发中忘记了其他高级方法，使用此方法也能作为**保底方案**。
  - 逻辑最简单，且**兼容所有伪数组**（包括自定义 `Symbol.iterator` 接口的伪数组），无任何限制。

### 语法与实现步骤
1. 创建一个空数组（作为接收元素的“空树洞”）。
2. 使用 `for` 循环遍历伪数组（例如：`let i = 0; i < likeArr.length; i++`）。
3. 在循环内部，使用 `push` 方法将伪数组的每一个元素依次添加到新数组中。

### 代码示例
```javascript
// 获取伪数组（例如获取页面上的 5 个 div 元素）
let likeArr = document.getElementsByTagName('div');

// 1. 定义一个空数组
let trueArr = [];

// 2. for 循环遍历伪数组
for (let i = 0; i < likeArr.length; i++) {
    // 3. 将每个元素 push 到真数组中
    trueArr.push(likeArr[i]);
}

// 验证是否转换为真数组
console.log(Array.isArray(trueArr)); // 输出 true
```

## 通过 concat 方法转换 *Content-[03:01]

### 核心作用与特点
- **作用**：利用数组构造函数原型链上的 `concat` 方法合并数组并返回新数组，通过 `apply` 将伪数组作为参数传入，从而实现转换。
- **语法**：`Array.prototype.concat.apply([], 伪数组)`

### 实现步骤
1. 获取伪数组（如 `document.getElementsByTagName('div')`）。
2. 调用 `Array.prototype.concat.apply`。
3. **第一个参数**：传入空数组 `[]`（作为 `this` 指向）。
4. **第二个参数**：传入需要转换的伪数组。

### 代码示例
```javascript
let likeArr = document.getElementsByTagName('div');

// 使用 concat 和 apply 进行转换
let trueArr = Array.prototype.concat.apply([], likeArr);

// 验证是否转换为真数组
console.log(Array.isArray(trueArr)); // 输出 true
```

### 原理解析
- **`apply` 方法的作用**：主要用于改变函数的 `this` 指向。在改变 `this` 指向的同时，它可以接收参数，并且**会将第二个参数当作数组（或类数组对象）来处理**，将其拆分为单个参数传入到目标函数中。
- **转换过程**：
  1. `apply` 的第一个参数是空数组 `[]`，指定了 `concat` 方法的 `this` 指向。
  2. 第二个参数是伪数组，`apply` 会将其拆分为单个元素，传入到 `concat` 方法中。
  3. `concat` 方法接收到这些分散的参数后，将它们合并为一个新数组，从而完成从伪数组到真数组的转换。

### MDN 官方关于 `apply` 的说明
- `apply` 方法会以给定的 `this` 值和作为数组（或类数组对象）提供的 `arguments` 调用该函数。
- **第一个参数**：类似 `this` 指向，调用函数时提供。此处指向一个空数组 `[]`。
- **第二个参数**：一个类数组对象，用于指定调用 function 时的参数。如果不需要向函数提供参数时则可为空。此处放入伪数组，`concat` 会将其逐个拼接，最终生成真数组。
