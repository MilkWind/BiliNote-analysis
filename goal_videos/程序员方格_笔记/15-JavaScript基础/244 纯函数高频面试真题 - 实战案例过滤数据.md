## 纯函数在数据处理中的应用 *Content-[00:00]

在处理前端数据时，我们经常需要面对数组和对象的数据处理场景，例如过滤数组、映射数组以及处理对象数据。

- **核心原则**：在进行这些数据处理操作时，**不修改原数组或对象，而是返回新的结果**，这种处理方式正是**纯函数**的典型应用。
- **知识关联**：这种处理逻辑与之前讲解的“引用数据类型”的处理原则是一致的。通过系统性的学习和实战，可以更好地理解纯函数在数据处理中的具体落地方式。

## 实战案例：过滤成年用户数据 *Content-[00:24]

为了具体说明纯函数在数据处理中的应用，我们来看一个具体的实战案例。

- **功能需求**：编写一个函数，接收一个用户数组，过滤出年龄大于等于 18 岁的成年用户。
- **核心约束**：必须使用**纯函数**的写法，即**绝对不能修改原数组**。

## 代码实现与测试验证 *Content-[00:58]

### 1. 函数定义与实现
我们定义一个过滤函数，利用 JavaScript 数组内置的高阶方法来实现纯函数逻辑：

```javascript
function filterAdult(users) {
    // 使用 filter 方法返回一个新数组，不修改原数组
    return users.filter(user => user.age >= 18);
}
```

- **方法解析**：使用数组的 `filter` 方法。该方法会遍历数组并返回一个符合条件的新数组，**不会修改原数组**。（注：如果对数组常用方法不熟悉，建议回顾相关的高频面试真题）。
- **纯函数特性**：相同的 `users` 数组输入，永远返回相同的过滤结果，并且没有任何副作用。

### 2. 测试数据准备
定义一个外部变量 `userList` 作为测试数据，包含三个用户对象：

```javascript
const userList = [
    { name: '小红', age: 17 },
    { name: '小刚', age: 20 },
    { name: '小李', age: 19 }
];
```
- 数据说明：小红 17 岁（未成年），小刚 20 岁（成年），小李 19 岁（成年）。预期结果应过滤出小刚和小李。

### 3. 函数调用与结果接收
调用定义好的过滤函数，并将返回的新数组保存到一个新的变量中：

```javascript
const newUserList = filterAdult(userList);
```

### 4. 测试验证
通过 `console.log` 打印原数组和新数组，验证纯函数的特性：

```javascript
// 验证原数组
console.log(userList); 
// 输出结果：原数组保持不变，依然包含 3 个用户对象（小红、小刚、小李）。

// 验证新数组
console.log(newUserList); 
// 输出结果：新数组只包含 2 个用户对象（小刚、小李），因为他们的 age >= 18。
```

**结论**：通过测试可以得出，原数组未被修改，新数组是过滤后的正确结果，这完全符合**纯函数**的定义。

## 纯函数的优势与实际开发建议 *Content-[05:01]

### 实际开发中的应用
在实际的前端开发中，过滤列表、处理数据是非常高频的操作。大家在实际项目中肯定写过类似的代码，只是可能没有刻意去留意或者不知道它在理论上被称为“纯函数”。

### 核心优势
将这种数据处理类型的函数写成纯函数，具有显著的优势：
- **安全性高**：写法非常安全，不会在不经意间修改原始数据（尤其是引用类型的数据）。
- **避免 Bug**：有效避免了因意外修改原数据而导致的难以排查的 Bug，提升了代码的健壮性。

### 开发者反思与避坑
- **互动思考**：在编写代码时，是否曾不小心修改过原数组或对象（引用类型）？
- **改进建议**：如果有过此类经历，下次在编写数据处理逻辑时，应刻意采用**纯函数**的写法（如使用 `filter`、`map` 等返回新数组的方法），从而有效避免此类踩坑问题。
