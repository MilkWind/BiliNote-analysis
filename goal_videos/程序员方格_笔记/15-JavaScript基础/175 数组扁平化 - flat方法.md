## 数组扁平化的核心定义 *Content-[02:01]

- **基本概念**：
  - **多维数组**：指数组内部又嵌套了数组（存在多层结构）。
  - **一维数组**：指只有一层结构，不存在数组嵌套的数组。
  - **数组扁平化（打平数组）**：就是将**多维数组**转换成**一维数组**的操作过程，消除所有的数组嵌套结构。
- **直观示例**：
  - **二维数组扁平化**：`[1, 2, [3, 4]]` 经过扁平化后变为 `[1, 2, 3, 4]`。
  - **多维数组扁平化**：`[1, 2, [3, [4, [5, 6]]]]` 经过无限深度扁平化后变为 `[1, 2, 3, 4, 5, 6]`。

## 方法一：使用 flat 方法实现扁平化 *Content-[04:31]

- **方法简介**：
  - `flat()` 是 **ES6** 新增的数组原生方法，专门用于数组扁平化。
  - 它是实际开发中的**首选方法**，使用最便捷。
  - 该方法会递归遍历数组，按照指定的深度将子数组元素合并到原数组中，最终返回一个新一维数组。

### flat 方法语法与参数 *Content-[05:27]

- **基本语法**：`const newArr = arr.flat([depth])`
- **参数说明**：
  - `depth`（可选）：指定扁平化的深度，类型为数字。
  - **默认值**：如果不传参，默认值为 `1`，即只展开一层嵌套。
  - **指定深度**：传入具体的数字（如 `2`），则展开对应的层数。
  - **无限深度**：传入特殊值 `Infinity`，代表无限深度。无论数组嵌套多少层，都会直接展开为完全的一维数组。
- **返回值**：返回一个扁平化后的**新数组**，**不会修改原数组**。

### flat 方法代码案例演示 *Content-[06:28]

- **案例 1：默认展开一层**
  ```javascript
  const arr1 = [1, 2, 3, [4, 5]];
  const res1 = arr1.flat(); // 不传参，默认 depth = 1
  console.log(res1); // 输出: [1, 2, 3, 4, 5]
  ```
- **案例 2：指定展开两层**
  ```javascript
  const arr2 = [1, 2, [3, [4, 5]]];
  const res2 = arr2.flat(2); // 指定 depth = 2
  console.log(res2); // 输出: [1, 2, 3, 4, 5]
  // 注意：如果这里不传参或传 1，[4, 5] 将无法完全展开。
  ```
- **案例 3：无限深度扁平化**
  ```javascript
  const arr3 = [1, 2, [3, [4, [5, [6, [7, [8, 9]]]]]]];
  const res3 = arr3.flat(Infinity); // 使用 Infinity 展开所有层级
  console.log(res3); // 输出: [1, 2, 3, 4, 5, 6, 7, 8, 9]
  ```
- **案例 4：自动移除数组空项（重要面试考点）**
  ```javascript
  const arr4 = [1, 2, , 3, , 4, 5, , 6]; // 数组中包含多个空项 (empty slots)
  const res4 = arr4.flat(); 
  console.log(res4); // 输出: [1, 2, 3, 4, 5, 6]
  // 结论：flat 方法在扁平化的同时，会自动移除数组中的空项。
  ```

### flat 方法的核心特点与注意事项 *Content-[11:21]

1\. **用法简单，开发首选**：
   - 语法直观，调用方便，是日常开发中处理数组扁平化的第一选择。
2\. **纯函数特性（不修改原数组）**：
   - `flat()` 方法执行后，原数组保持不变（包括原数组中的空项依然存在），而是返回一个全新的数组。
3\. **自动移除空项（核心区别）**：
   - 这是 `flat` 方法区别于其他手写扁平化方法（如 `reduce`、递归等）的一个**非常重要且常考的特性**。在面试中如果被问到细节，必须指出这一点。
4\. **兼容性问题**：
   - 原生支持 **ES6** 及以上环境，现代浏览器均完全兼容。
   - 对于需要兼容老版本浏览器的项目，无需过度担心，通常可以通过 **Webpack**、**Babel** 等构建工具将 ES6 代码转译为 ES5 或更低版本的 JS 代码。
