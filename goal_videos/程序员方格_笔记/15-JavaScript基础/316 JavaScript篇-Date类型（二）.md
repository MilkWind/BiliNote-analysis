## Date 对象继承与重写的方法 *Content-[00:30]

Date 作为引用类型，继承并重写了 `Object` 原型上的几个关键方法，以便更加合理地展示日期。

- **`toLocaleString()`**
  - 返回适应当前运行环境的日期字符串。
  - 在中文系统下会包含“下午”等中文描述，在英文系统下则显示为“AM/PM”。
  - **适用场景**：主要用于直接在 UI 上展示给用户看。
  - **注意事项**：不适合用于数据传输，因为其格式并不固定。

- **`toString()`**
  - 返回包含时区信息和详细格式的字符串（通常包含：日、星期、月、日、时间、时区）。
  - 比 `toLocaleString()` 更加通用，但在不同浏览器之间可能会存在细微的差异，依然有不固定的地方。

- **`valueOf()`**
  - 不直接返回字符串，而是返回底层的**毫秒数**（时间戳）。
  - **核心特性**：让日期的比较变得非常简单。当使用 `>` 或 `<` 比较两个 Date 对象时，JS 引擎会自动调用 `valueOf()`。
  - **示例**：比较 `date1` 和 `date2` 时，实际上是在比较两个数字，判断哪个时间更早时无需手动转换时间戳，代码非常直观。

## Date 对象自身的格式化方法 *Content-[02:59]

Date 对象提供了一系列专门用于格式化的方法，以满足不同的开发需求。

- **基本格式化方法**
  - `toDateString()`：只返回日期部分。
  - `toTimeString()`：只返回时间部分。
  - `toLocaleDateString()` / `toLocaleTimeString()`：分别返回本地化的日期和时间。
  - `toUTCString()`：将时间转换成 UTC 时间并以字符串形式返回，在处理 HTTP 头部信息时经常用到。

- **现代 Web 开发核心方法**
  - **`toISOString()`**：返回标准的 ISO 8601 格式字符串（如 `YYYY-MM-DDTHH:mm:ss.sssZ`）。
    - 其中的 `Z` 表示零时区（UTC）。
    - **优势**：没有歧义，国际通用。
  - **`toJSON()`**：通常返回与 `toISOString()` 相同的结果。其存在目的是让 `JSON.stringify()` 在序列化 Date 对象时，能够自动将其转换成字符串。

- **最佳实践建议**
  - **数据存储与传输**：在数据库存储时间或前后端传输数据时，**一定要使用时间戳或 ISO 字符串**。
  - **页面渲染**：只有在页面最终渲染给用户看时，才使用 `toLocale...` 系列方法。

## Date 对象的 Get 和 Set 方法 *Content-[05:23]

Date 对象允许开发者精确控制时间的每一个组成部分，通过一系列 Get 和 Set 方法进行操作。

- **Get 方法（获取时间组件）**
  - `getFullYear()`：获取四位年份。
  - `getMonth()`：获取月份。**注意**：返回值是 0~11，而不是 1~12，开发时需特别留意。
  - `getDate()`：获取日期（1~31）。
  - `getDay()`：获取星期几（0 表示星期日，1~6 表示星期一到星期六）。**极易混淆点**：它返回的是星期而不是日期。

- **Set 方法（设置时间组件）**
  - 可以单独设置年、月、日、小时等。
  - **多参数支持**：很多 Set 方法支持多参数，例如 `setFullYear()` 可以同时设置年、月、日，比分三次调用更加高效。

- **UTC 版本方法**
  - 上述列出的所有方法都是基于**本地时区**的。
  - 如果要操作 UTC 时间，每个方法都有对应的 UTC 版本（如 `getUTCFullYear()`、`setUTCMonth()` 等）。
  - **建议**：在处理国际化业务时，优先使用 UTC 版本的方法。

## Date 对象的实用技巧 *Content-[07:23]

在实际开发中，利用 Date 对象的特性可以高效解决许多常见问题。

- **技巧一：自动纠错（自动进位）**
  - 当设置一个超出合理范围的值时，Date 对象不会报错，而是会自动调整。
  - **示例**：5月只有31天，若将日期设置为35，会自动计算为6月4日；若将月份设置为13，会自动进位到下一年。
  - **应用场景**：非常适合做日期推算（如计算40天后是几号）。
  - **注意事项**：这种特性可能会产生一些 Bug，使用时需谨慎。

- **技巧二：计算时间差**
  - Date 对象相减会返回毫秒差，直接使用 `end - start` 即可得到间隔的毫秒数。
  - 计算相差天数的公式：将毫秒差除以一天的总毫秒数。
  - 一天的毫秒数计算：$1000 \times 60 \times 60 \times 24$（1000毫秒 $\times$ 60秒 $\times$ 60分钟 $\times$ 24小时）。

- **技巧三：获取某个月的最后一天（当月天数）**
  - **原理**：在 Date 的逻辑里，日期参数设置为 `0` 代表**上个月的最后一天**。
  - **示例**：想知道 2019 年 5 月有多少天。
    - 创建对象：`new Date(2019, 5, 0)`。
    - 解释：月份 `5` 代表 6 月，日期 `0` 代表 6 月的前一天，即 5 月的最后一天（5月31日）。
  - **操作**：直接对该对象调用 `getDate()`，即可简洁高效地得到当月的天数。
