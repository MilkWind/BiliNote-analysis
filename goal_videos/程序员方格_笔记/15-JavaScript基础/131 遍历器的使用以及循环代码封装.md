## 迭代器 (Iterator) 的概念与背景 *Content-[00:00]

在 ES6 之前，JavaScript 中表示集合的数据结构主要是数组（Array）和对象（Object）。ES6 新增了 `Map` 和 `Set`，使得数据集合的种类更加丰富。开发者还可以组合使用它们来定义自己的数据结构（例如数组的成员是 Map，Map 的成员是对象）。

**面临的痛点**：
随着数据结构的多样化，遍历方式变得非常混乱。不同的数据结构需要使用不同的遍历方式（如 `for` 循环、`for...in` 等），当数据结构相互嵌套时，遍历代码会变得极其复杂和难以维护。

**迭代器的诞生**：
为了解决这个问题，ES6 引入了**迭代器（Iterator）**。它是一种接口，旨在为各种不同的数据结构提供**统一的访问机制**。
- **接口的比喻**：就像电脑上的 USB 接口、Type-C 接口一样，只要遵循统一的规则（接口），就可以用统一的方式（数据线）去连接和操作。
- **核心作用**：任何数据结构只要部署了 `Iterator` 接口，就可以使用统一的遍历代码和原理来完成遍历操作，实现“一招鲜，吃遍天”。

## 默认具有 Iterator 接口的数据结构 *Content-[03:36]

JavaScript 引擎为以下原生数据结构默认部署了 `Iterator` 接口，这意味着它们可以直接使用迭代器进行遍历：
- **Array**（数组）
- **Map**（映射）
- **Set**（集合）
- **String**（字符串）
- **TypedArray**（类型化数组）
- **函数的 arguments 对象**
- **NodeList 对象**（DOM 节点列表）

## 迭代器的工作原理与核心 API *Content-[05:24]

以数组为例，深入了解迭代器的底层运行机制：

**1. 获取迭代器接口**
迭代器接口是通过 `Symbol.iterator` 获取的。`Symbol` 是一种永远不重复的数据类型，常被用作对象的属性名。
```javascript
let arr = ['张飞', '关羽', '刘备', '曹操'];
// 查看接口类型
console.log(typeof arr[Symbol.iterator]); // 输出: "function"
```

**2. 生成迭代器对象**
调用 `Symbol.iterator` 属性对应的函数，会返回一个**迭代器对象**（专门用于遍历当前数据结构的指针）。
```javascript
let it = arr[Symbol.iterator](); 
// it 即为数组迭代器对象 (Array Iterator)
```

**3. 调用 next() 方法**
迭代器对象包含一个 `next()` 方法。调用该方法会返回一个包含 `value` 和 `done` 两个属性的对象：
- `value`：当前遍历到的元素值。
- `done`：布尔值，表示遍历是否完成（`false` 表示未完成，`true` 表示已完成）。

**迭代器的“指针”特性**：
- 迭代器可以理解为一个**指针**，初始位置在第一个元素之前。
- 每次调用 `next()`，指针向前移动一步（走一步看一步）。
- **不可回退**：除非重新获取迭代器对象，否则指针只能单向向前移动。

## 手动封装迭代器循环 (While 循环) *Content-[11:22]

由于我们不知道数组的具体长度或元素何时遍历完毕（即不知道 `next()` 需要调用多少次），这属于**状态改变**的场景，因此适合使用 `while` 循环，而不是固定次数的 `for` 循环。

**基础实现方式**：
```javascript
let it = arr[Symbol.iterator]();
let item = it.next(); // 获取第一个元素

while (true) {
    if (item.done) {
        break; // 如果 done 为 true，说明遍历完成，跳出循环
    }
    console.log(item.value);
    item = it.next(); // 获取下一个元素
}
```

**关键注意点**：
在循环体内，**绝对不能**再次调用 `it.next()` 来打印或判断，否则会导致指针多走一步，从而跳过元素或产生逻辑错误。必须使用提前接收的 `item` 变量进行判断和输出。

## 循环代码的优化与精简 *Content-[14:46]

基础的 `while` 循环代码略显冗长，可以通过 JavaScript 的**赋值表达式特性**进行极致优化。

**优化后的代码**：
```javascript
let it = arr[Symbol.iterator]();
let item;

// 将 调用、赋值、判断 合并到 while 的条件中
while (!(item = it.next()).done) {
    console.log(item.value);
}
```

**原理解析**：
1. `item = it.next()` 是一个赋值表达式，它的返回值是赋值后的 `item` 对象本身。
2. `(item = it.next()).done` 获取了该对象的 `done` 属性。
3. 前面加上 `!`（非运算符），当 `done` 为 `false`（未完成）时，`!false` 为 `true`，循环继续；当 `done` 为 `true`（已完成）时，`!true` 为 `false`，循环终止。
4. 这种写法将**方法调用、变量赋值、状态判断**三步操作浓缩到了一句话中，代码更加简洁优雅。

## 迭代器在不同数据结构中的应用 *Content-[18:40]

迭代器的最大优势在于其**统一性**，相同的循环代码可以无缝应用于其他具有默认接口数据结构。

**1. 遍历 Set 集合**
```javascript
let s = new Set(['张飞', '关羽', '刘备', '曹操']);
let it = s[Symbol.iterator]();
let item;
while (!(item = it.next()).done) {
    console.log(item.value); // 直接输出 Set 中的值
}
```

**2. 遍历 Map 集合**
Map 集合的特殊之处在于，它的每一个元素都是一个键值对。因此，迭代器遍历出来的 `value` 是一个**包含键和值的小数组** `[key, value]`。
```javascript
let m = new Map();
m.set('city', '北京');
m.set('it', '巴黎');

let it = m[Symbol.iterator]();
let item;
while (!(item = it.next()).done) {
    console.log(item.value); // 输出: ['city', '北京'] 然后 ['it', '巴黎']
}
```

**3. 遍历 String 字符串**
字符串同样部署了迭代器接口，可以逐个字符进行遍历。
```javascript
let str = "iPhone18Pro";
let it = str[Symbol.iterator]();
let item;
while (!(item = it.next()).done) {
    console.log(item.value); // 逐个输出字符: 'i', 'P', 'h', 'o', 'n', 'e'...
}
```

## 引出 for...of 循环 *Content-[23:41]

虽然通过 `while` 循环配合 `next()` 方法可以统一遍历所有数据结构，且逻辑清晰，但在实际开发中**手动编写依然不够方便**。

为了解决这个痛点，ES6 借鉴了 C++、Java、C# 和 Python 等语言，引入了 **`for...of`** 循环。
- `for...of` 本质上是**迭代器的简便写法（语法糖）**。
- 只要一个数据结构部署了 `Symbol.iterator` 接口（即具有 Iterator 接口），就可以直接使用 `for...of` 进行遍历，底层会自动调用迭代器的 `next()` 方法并处理 `done` 状态，极大地简化了代码。
