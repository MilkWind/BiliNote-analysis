## 1. Symbol 不能作为构造函数 *Content-[00:00]
- **基本数据类型限制**：`Symbol` 属于基本数据类型，而不是对象，因此不能使用 `new` 操作符来创建实例。
- **错误用法**：如果尝试使用 `new Symbol()`，会直接抛出错误，控制台提示 `Symbol is not a constructor`（不是一个构造函数）。
- **正确用法**：直接调用 `Symbol()` 函数即可，无需使用 `new` 关键字。

## 2. Symbol 本身不能添加属性 *Content-[00:36]
- **自身不具备属性和方法**：因为 `Symbol` 是基本数据类型，它自身不具备属性，也不能直接添加属性或方法。
- **添加属性无效**：如果尝试给 `Symbol` 变量添加属性，该操作不会报错，但属性添加无效。访问该属性时会返回 `undefined`。
  - 示例：`let s = Symbol(); s.tt = 'javascript'; console.log(s.tt); // 输出 undefined`
- **添加方法并调用会报错**：如果尝试给 `Symbol` 添加一个方法并执行，由于方法实际上并未成功挂载，调用时会抛出错误（提示该函数不存在）。
  - 示例：`s.fn = function() {}; s.fn(); // 报错：s.fn is not a function`

## 3. Symbol 不能与其他类型进行运算 *Content-[03:07]
- **运算限制**：`Symbol` 值不能和字符串、数字、布尔值等任何其他类型进行算术运算或拼接运算，否则直接报错。
- **与数字相加**：`sy + 1` 会报错，提示 `Cannot convert a Symbol value to a number`。
- **与字符串拼接**：`sy + 'hello'` 会报错，提示 `Cannot convert a Symbol value to a string`。
- **与布尔值相加**：`sy + true` 会报错，提示 `Cannot convert a Symbol value to a number`。
  - **原因解析**：在算术运算中，布尔值 `true` 会优先被隐式转换为数字 `1`，因此引擎会尝试将 `Symbol` 转换为 `number` 类型以完成加法运算，从而触发报错，而不是将其转换为 `boolean`。

## 4. Symbol 有限的类型转换 *Content-[05:23]
- **转为数值（完全不可行）**：
  - `Symbol` 不能转为数值，无论是显式转换还是隐式转换都不行。
  - 显式转换示例：`Number(sy)` 会直接报错 `Cannot convert a Symbol value to a number`。
- **转为字符串（仅限显式）**：
  - `Symbol` 可以**显式**转为字符串，但**绝对不能隐式**转为字符串。
  - 显式转换方法：使用 `String(sy)` 或 `sy.toString()`。
  - 隐式转换测试：`sy + 'hello'` 会报错，证明不能通过拼接进行隐式字符串转换。
- **转为布尔值（显式与隐式均可）**：
  - `Symbol` 可以显式和隐式转为布尔值，且转换结果始终为 `true`。
  - 显式转换：`Boolean(sy)` 返回 `true`。
  - 隐式转换：在 `if (sy) { console.log('执行'); }` 条件判断中，`Symbol` 会被隐式转换为 `true`，代码块会正常执行。
