## 1. 字符串、数值与布尔值的解构赋值 *Content-[00:00]

### 字符串的解构赋值
- **按数组方式解构**：字符串的结构与数组非常相似，因此字符串的解构赋值是按照**数组解构**的方式进行的，即按照**元素的顺序**依次解构。
  - 示例：`let [a, b, c, d] = 'hello';`，此时 `a` 为 `'h'`，`b` 为 `'e'`，依此类推。
- **按对象方式解构**：如果强行按照对象解构的方式来解构字符串，由于字符串没有常规的属性名，**只能解构出 `length` 属性**，其他属性均无法解构。
  - 示例：`let {length} = 'hello';`，此时 `length` 的值为 5。

### 数值和布尔值的解构
- 数值和布尔值在进行解构赋值时，会自动转换为对应的**包装类对象**（Wrapper Object）。
- 转换为包装类后，就可以像解构普通对象一样，解构其包装类对象上的属性和方法。
- **注意**：这种用法在实际开发中比较少见，了解其底层转换机制即可。

## 2. 函数参数的解构赋值 *Content-[02:29]

函数的形参本质上相当于变量的声明，因此可以直接在形参位置使用解构赋值语法。

### 对象参数的解构
- 当函数预期接收一个对象时，可以在形参中直接使用对象解构语法，避免在函数体内反复使用 `对象.属性` 的写法。
- **传统写法**：
  ```javascript
  function show(p) {
      console.log(p.name, p.age, p.gender);
  }
  ```
- **解构写法**：
  ```javascript
  function show({name, age, gender}) {
      // 函数内部直接使用 name, age, gender 变量
      console.log(name, age, gender);
  }
  ```

### 数组参数的解构
- 如果函数预期接收的是数组，形参可以使用数组解构语法。
- 示例：
  ```javascript
  function show([a, b, c]) {
      console.log(a, b, c);
  }
  // 调用时传入数组：show(['张飞', '关羽', '刘备']);
  ```

### 重要注意事项
- **数据类型必须严格匹配**：并不是“调用时传什么，就按什么方式解构”，而是“**形参定义了哪种解构方式，调用时就必须传入对应的数据类型**”。如果形参写的是数组解构，调用时却传入了对象，会导致解构失败或报错。
- **默认值与圆括号**：函数参数解构可以结合默认值使用。此外，需要特别注意**圆括号的使用场景**（何时必须使用，何时不能使用，以避免语法解析歧义），这部分是易错点，需要课后重点复习和记忆。

## 3. 解构赋值的实际应用场景 *Content-[06:37]

解构赋值不仅是语法糖，还能在实际开发中解决具体痛点，大幅简化代码逻辑。

### 3.1 变量值交换
- **传统方式**：需要引入一个中间变量（如 `temp`）来进行交换，步骤繁琐。
- **解构方式**：利用数组解构赋值，可以极其简便地实现变量交换，无需中间变量。
  ```javascript
  let a = 10, b = 20;
  [a, b] = [b, a]; // 直接交换
  console.log(a, b); // 输出 20, 10
  ```
- **细节注意**：如果 `a` 和 `b` 是已经声明过的变量，在解构赋值等号左边**不需要**再写 `let`。同时，由于是数组解构，不存在与代码块混淆的问题，因此也**不需要**在左侧添加小括号。

### 3.2 函数返回值的解构
- **场景描述**：当一个函数返回一个包含多个属性的对象（如 `{name, age, gender, country}`）时。（注：视频中示例代码借助了阿里的“通义灵码”AI 插件快速生成）。
- **传统方式**：需要先用一个变量接收整个对象，然后再通过 `p.age`、`p.country` 逐个提取所需属性，代码冗余。
- **解构方式**：直接在接收返回值时使用对象解构，按需提取。
  ```javascript
  // 假设 show() 返回 {name: '...', age: 18, gender: '...', country: 'China'}
  let {age, country} = show(); 
  // 直接提取需要的变量，无需接收整个对象
  ```
- **优势**：只提取需要的变量，大大节省了代码体积，使代码更加精简。同理，如果函数返回的是数组，也可以直接使用数组解构的方式接收。

### 3.3 JSON 数据的提取
- 在处理后端返回的 JSON 数据时，解构赋值的用法与对象解构完全一致。
- 可以方便地从复杂的 JSON 嵌套结构中，直接提取出所需的特定字段，提升数据处理效率。
