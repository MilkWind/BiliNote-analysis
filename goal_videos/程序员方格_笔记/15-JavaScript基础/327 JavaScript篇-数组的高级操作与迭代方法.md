## 1. ES6 数组迭代器方法 *Content-[00:47]

ES6 为数组引入了三个迭代器方法。这些方法的特点是**不会直接返回一个数组**，而是返回一个**迭代器对象**。我们可以通过 `for...of` 循环去消费它，或者使用扩展运算符 `...` 将其内容展开到一个新数组中。

- **`keys()`**：返回一个包含数组中每个索引的迭代器。将其展开后，会得到一个由索引组成的数组（例如 `[0, 1, 2]`）。
- **`values()`**：返回一个包含数组中每个元素值的迭代器。将其展开后，会得到一个和原数组内容完全一样的数组。
- **`entries()`**：返回一个包含每个元素的索引和值对的迭代器。将其展开后，会得到一个二维数组，每个子数组中的第一个元素是索引，第二个是对应的值。当需要在遍历时同时访问索引和值，使用 `entries()` 非常方便。

## 2. 批量修改数组方法 *Content-[02:28]

这两个方法用于批量修改数组内容，**需要特别注意的是，它们都会直接修改原始数组**，而不是返回一个新数组。在实际使用中必须明确这一点，以避免产生意料之外的数据副作用。

- **`fill()`**：用一个静态值来填充数组。它接收三个参数：要填充的值、起始索引、结束索引（不包含结束位置）。
  - *常见场景*：指定一个长度创建一个新数组，并用默认值填满它，非常适合初始化数据的场景。
- **`copyWithin()`**：在数组内部进行自我复制，将指定位置的元素序列复制到另外一个指定位置。
  - *参数*：复制的目标位置、复制的起始位置、复制的结束位置。
  - *示例*：将索引 3~4 的元素复制到从索引 0 开始的位置，覆盖原有元素。

## 3. 扩展运算符的应用 *Content-[04:29]

扩展运算符（`...`）在处理数组时，能帮助我们把代码变得简洁且直观。

- **数组合并**：过去通常使用 `concat()` 连接多个数组，现在只需创建一个新数组，然后把需要合并的数组在其中依次展开即可，代码意图非常清晰。
- **数组复制**：通过扩展运算符可以非常方便地创建一个数组的浅拷贝副本。修改副本数组不会影响原数组。
- **处理可迭代对象**：扩展运算符不仅适用于数组，还适用于所有的可迭代对象（如字符串）。例如，可以直接将字符串展开为一个由单个字符组成的数组，这比使用 `split()` 方法更加简洁。

## 4. 模拟栈与队列数据结构 *Content-[06:13]

JavaScript 数组非常灵活，通过组合使用基本方法，可以轻松模拟两种经典的数据结构：

- **栈 (Stack)**：特点是**后进先出 (LIFO, Last In First Out)**。
  - 使用 `push()` 在数组末尾添加元素，模拟**入栈**。
  - 使用 `pop()` 从数组末尾移除元素，模拟**出栈**。最后入栈的元素会最先被弹出。
- **队列 (Queue)**：特点是**先进先出 (FIFO, First In First Out)**。
  - 使用 `push()` 在数组末尾添加元素，模拟**入队**。
  - 使用 `shift()` 从数组头部移除元素，模拟**出队**。最先进队的元素会最先被移出。

## 5. 数组重新排序方法 *Content-[07:45]

- **`reverse()`**：将数组中的元素顺序完全颠倒。**注意**：此方法会直接修改原数组。
- **`sort()`**：对数组元素进行排序。
  - **易错点**：当不带任何参数调用 `sort()` 时，它会默认把所有元素都转换成字符串，然后按照字符串的 Unicode 码点顺序进行排序。这会导致数字排序错乱（例如字符串 `"1000"` 会排在 `"25"` 前面）。
  - **正确用法**：必须向 `sort()` 内部传递一个**比较函数**。该函数接收两个参数（通常命名为 `a` 和 `b`）。
    - 升序排列：返回 `a - b`。
    - 降序排列：返回 `b - a`。
  - 通过返回值的正负，`sort()` 就能知道应该如何排列这两个元素。对数值数组排序时，**务必提供比较函数**。

## 6. 数组增删改查核心方法 *Content-[09:49]

- **`concat()`**：用于连接多个数组或将值添加到数组末尾。返回一个全新的数组，**不会修改原数组**。
- **`slice()`**：用于从现有数组中提取片段（切片），返回新数组。
  - 参数：起始索引、结束索引（**不包含**结束位置）。例如提取索引 1 和 2 的元素，需传入 `(1, 3)`。
  - 如果只传一个参数，则从该索引一直提取到末尾。**不会修改原数组**。
- **`splice()`**：非常强大的方法，集删除、插入、替换于一身。**注意**：它会**直接修改原数组**，应谨慎使用。
  - **删除**：`splice(起始索引, 删除个数)`。返回一个包含被删除元素的新数组。
  - **插入**：`splice(起始索引, 0, 插入项1, 插入项2...)`。将第二个参数（删除个数）设为 0，表示不删除元素，直接在指定位置插入后续参数。
  - **替换**：结合删除和插入，先删除指定数量的元素，再提供新元素填充被删除的位置。

## 7. 数组搜索与查找方法 *Content-[13:14]

- **基本类型搜索**：
  - **`indexOf()`**：从数组头部开始查找，返回元素第一次出现的索引。
  - **`lastIndexOf()`**：从数组末尾开始查找，返回元素最后一次出现的索引。
  - **`includes()`** (ES7)：只关心元素是否存在于数组中，返回布尔值 (`true` 或 `false`)，代码语义更加清晰。
- **对象/条件搜索**（适用于存放对象的数组）：
  - **`find()`**：接收一个回调函数作为参数，遍历数组并返回第一个使得回调函数返回 `true` 的**元素本身**。
  - **`findIndex()`**：与 `find()` 功能相似，唯一区别是它返回的是满足条件的**索引**，而不是元素本身。

## 8. 核心迭代与高阶函数 *Content-[15:39]

这五个核心高阶函数都接收一个回调函数作为参数，对数组的每一项进行处理：

- **`every()`**：像质检员一样，只有当数组中的**所有元素**都满足回调函数的条件时，才返回 `true`；只要有一个不满足，立即返回 `false`。
- **`some()`**：相对宽容，只要数组中**有任何一个元素**满足条件，就会返回 `true`。
- **`filter()`**：过滤方法。遍历整个数组，把所有满足条件的元素收集起来，组成并返回一个**新数组**。
- **`map()`**：映射方法。创建一个新数组，其元素是原数组每个元素经过回调函数处理后的结果。
- **`forEach()`**：最纯粹的遍历方法，为每个元素执行一次提供的回调函数。**特别注意**：`forEach()` **没有返回值**，通常用来执行不产生新值的操作（如打印日志）。

## 9. 数组归并方法 *Content-[17:43]

- **`reduce()`**：数组方法中的“瑞士军刀”，核心思想是归并或汇总。遍历数组中的所有元素，通过指定逻辑将它们最终合并成一个单一的值。
  - *参数*：回调函数（包含累加器 `acc` 和当前正在处理的元素 `cur`）、初始值。
  - *应用*：最经典的应用是数组求和，也可以用于求最大值等复杂逻辑。
- **`reduceRight()`**：工作原理与 `reduce()` 完全一样，唯一的区别是它的遍历方向是**从右到左**（`reduce` 为从左到右）。在某些特定场景（如字符串拼接）下，遍历方向会导致完全不同的输出结果。

## 10. ES2019 嵌套数组处理 *Content-[19:34]

- **`flat()`**：把嵌套数组展平，将子数组里的元素拿出来放到父数组里。
  - 默认情况下，`flat()` 只会展平**一层**。
  - 可以传入一个数字作为参数，指定要展平的深度（例如 `flat(2)` 处理两层嵌套）。
  - 如果不确定嵌套深度或想确保所有嵌套都被展开，可以直接传入 **`Infinity`**。
- **`flatMap()`**：`map()` 操作与 `flat(1)` 操作的组合。
  - 在实际开发中，如果先用 `map()` 处理数组，结果往往是一个嵌套的二维数组，还需要再用 `flat()` 展平。
  - `flatMap()` 可以在一步操作内完成映射并展平一层，直接返回包含所有元素的一维数组（例如将句子数组拆分为单词数组），比分开使用 `map()` 和 `split()` 更加简洁高效。
