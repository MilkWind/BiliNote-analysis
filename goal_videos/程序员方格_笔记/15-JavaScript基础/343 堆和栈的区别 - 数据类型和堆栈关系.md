## 基本数据类型与栈内存 *Content-[00:00]

### 1\. 七种基本数据类型
JavaScript 中的七种基本数据类型包括：
- `undefined`
- `null`
- `Boolean`
- `Number`
- `String`
- `Symbol`（ES6 新增）
- `BigInt`（ES2020 新增）

### 2\. 存储位置与内存管理
- **存储位置**：基本数据类型直接按值存放在**栈内存（Stack）** 中。
- **空间大小**：占用的空间大小是确定的。
- **内存分配与释放**：由系统自动分配和自动释放，全程无需开发者干预。
- **优势**：内存可以及时得到回收，相对于堆内存来说更加容易管理内存空间。

### 3\. 访问方式与示例
- **访问方式**：基本数据类型都是**按值访问**的，没有引用的概念。开发者可以直接操作存放在栈内存中的值。
- **代码示例**：
  ```javascript
  let num = 1;       // Number
  let str = 'hello'; // String
  let flag = true;   // Boolean
  ```
  在上述代码中，定义的三个基本类型变量，其变量名和对应的数据值全部存放在栈内存中。系统会自动分配存储空间，并在使用完毕后自动回收释放。

## 引用数据类型与堆栈内存 *Content-[03:25]

### 1\. 引用数据类型包含的类型
- 主要指由多个值构成的对象（`Object`）。
- 常见的子类型包括：`Function`、`Array`、`RegExp`、`Date` 等。

### 2\. 存储位置与内存管理
- **存储位置**：
  - **实际数据**存放在**堆内存（Heap）** 中。
  - **变量名（标识符）**和**堆内存的地址（指针）** 存放在**栈内存（Stack）** 中。
- **空间大小**：引用数据类型的值大小是不固定的。例如，数组可以随时 push 或删除元素，对象可以动态增加或删除属性。
- **为何不存放在栈中**：因为大小不固定，如果存放在栈中会降低变量查询的速度。

### 3\. 访问方式
- 在 JavaScript 中，不能直接访问堆内存中的值。
- **访问过程**：当需要访问堆中的数据时，首先从栈内存中获取该对象的引用地址（即指针），然后再通过该指针从堆内存中获取到需要的真实数据。

### 4\. 代码示例与结构解析
- **代码示例**：
  ```javascript
  let obj = { name: '张三', age: 20 };
  let arr = [1, 2, 3];
  ```
- **结构解析**：
  - 变量名 `obj` 和 `arr` 存放在**栈区**。
  - 栈区中保存着指向堆区实际数据的指针（内存地址）。
  - 堆区中存放着真实的数据（如 `name: '张三'`, `age: 20`）。
- **核心结论**：引用数据类型（又称复杂数据类型）的存储需要**堆和栈共同完成**。栈里面存的是引用数据类型的指针（指向堆区的地址），堆里面放的是真实的数据。

## AI 总结

本视频详细讲解了前端面试中高频的“堆和栈的区别”以及“数据类型与堆栈的关系”。核心要点如下：
1. **基本数据类型**（如 `Number`, `String`, `Boolean` 等 7 种）大小固定，直接按值存储在**栈内存**中，由系统自动管理内存，支持按值直接访问。
2. **引用数据类型**（如 `Object`, `Array`, `Function` 等）大小不固定，其**实际数据存储在堆内存**中，而**变量名和内存地址（指针）存储在栈内存**中。访问时需要通过栈中的指针去堆中获取真实数据。
3. 理解堆栈的存储机制是掌握 JavaScript 内存管理、深浅拷贝以及闭包等进阶概念的重要基础。
