## delete 运算符概述 *Content-[00:16]
- **基本概念**：`delete` 运算符可以删除数组指定下标的元素。
- **工作原理**：它只会删除元素的值，而不会删除数组的下标位置。
- **结果表现**：删除后会在原位置留下空位元素（empty slots），数组的 `length` 属性完全不变。
- **定性分析**：这属于**伪清空**。表面上看起来元素被清空了，但实际上空位依然占据着数组的长度。
- **面试评价**：在面试中如果直接提出使用此方法，通常会被面试官认为基础不扎实。

## 核心特点与弊端 *Content-[01:26]
使用 `delete` 运算符清空数组具有以下核心特点与弊端：
1\. **不会断开数组引用**：原数组和引用该数组的新变量，其空位元素会保持同步更新。
2\. **数组长度不变**：只是元素变成了空位（empty），并没有变成真正的空数组（`[]`）。
3\. **性能较差**：需要通过循环逐个删除元素，且会在内存中留下空位。
- **开发建议**：在实际开发和面试中**极不推荐**使用此方法。
- **面试策略**：如果在面试中提到了 `delete` 方法，**必须**主动补充说明它的弊端（性能差、循环删除、留下空位），展现对底层原理的全面理解。

## 基础代码实例演示 *Content-[02:43]
通过代码演示 `delete` 清空数组的具体表现：
```javascript
let arr2 = [1, 2, 3, 4, 5];
for (let i = 0; i < arr2.length; i++) {
  delete arr2[i]; // 逐个删除元素
}
console.log(arr2); 
```
- **输出结果**：控制台会输出类似 `[empty x 5]` 的结果。
- **对比构造函数**：这种表现与使用数组构造函数 `new Array(5)` 创建的结果非常相似（都会产生 5 个空位）。在之前的知识点中提到过，可以使用 `Array.of()` 来弥补构造函数直接传数字参数产生空位的弊端。
- **长度验证**：打印 `arr2.length`，结果依然是 `5`，直观证明其长度并未因 `delete` 操作而改变。

## 验证数组引用同步 *Content-[04:41]
验证 `delete` 操作是否会断开数组的引用关系：
```javascript
let arr = [1, 2, 3, 4, 5];
let newArr = arr; // 赋值引用

// 使用 delete 清空原数组
for (let i = 0; i < arr.length; i++) {
  delete arr[i];
}

console.log(arr);    // 输出空位
console.log(newArr); // 同样输出空位
```
- **结论**：修改原数组后，新数组 `newArr` 也同步变成了空位。这证明 `delete` 操作**不会断开数组的引用**，原数组和新数组的内存引用依然是同步的。

## 面试避坑指南 *Content-[05:45]
- **核心坑点**：当面试官提问“如何清空数组”时，如果回答使用 `delete` 操作符，**一定要补充说明**它是“伪清空”，并且“会留空位”。
- **强调重点**：必须明确指出在实际开发中不建议、不推荐使用该方法。
- **后果警告**：如果不说清楚 `delete` 的弊端，面试官会认为你只知其一不知其二，基础不扎实，从而导致面试扣分。一定要把该方法的特征和弊端完整、准确地表达出来以正视听。
