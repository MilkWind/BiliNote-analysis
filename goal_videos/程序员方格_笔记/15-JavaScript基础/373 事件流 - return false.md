## 1. 什么是默认行为及阻止方法 *Content-[00:00]

- **默认行为的定义**：
  默认行为是指元素自带的、无需添加 JS 代码就默认拥有的动作或行为。
  - 常见示例：`<a>` 标签的点击跳转、表单（`<form>`）提交时的页面刷新。

- **如何阻止默认行为**：
  - 通过事件对象（`event`）上的 `preventDefault()` 方法来阻止。

- **核心注意事项**：
  - `preventDefault()` **仅能**阻止默认行为。
  - 它**不会**涉及事件流，即不会影响事件的冒泡（Bubbling）和捕获（Capturing）。

- **示例：阻止 `<a>` 标签跳转**：
  - 如果不加 JS 干预，点击 `<a>` 标签必然会触发跳转（默认行为）。
  - 在点击事件的处理函数中调用 `e.preventDefault()`，即可阻止跳转。
  - **关键点**：阻止跳转后，事件依然会继续冒泡。如果需要根据需求同时阻止冒泡，需要额外调用 `e.stopPropagation()`；如果不需要，则无需处理。

## 2. 阻止表单提交刷新页面 *Content-[02:46]

- **常见场景**：
  在前端开发（如 Vue 项目）中，经常遇到点击表单提交按钮后，浏览器页面自动刷新的问题。这通常是因为忽略了表单的默认行为。

- **具体表现**：
  - 一个典型的 `<form>` 表单包含输入控件（如 `input type="text"`、`input type="password"`）和提交按钮。
  - 当点击登录/提交按钮时，浏览器会执行默认的表单提交动作，导致页面刷新。

- **解决方案**：
  - 在表单的提交事件或按钮的点击事件中，调用 `e.preventDefault()`。
  - 阻止默认行为后，页面将不再刷新，开发者可以通过 JS（如 AJAX/Axios）异步发送数据。

## 3. 阻止鼠标右键默认菜单 *Content-[04:24]

- **常见场景**：
  当需要在网页中实现自定义右键菜单时，首先需要屏蔽浏览器自带的默认右键菜单。

- **具体实现**：
  - 监听鼠标右键事件，事件名为 `contextmenu`。
  - 在事件处理函数中调用 `e.preventDefault()`。

- **效果**：
  - 触发右键时，浏览器默认的右键菜单将不会弹出。
  - 此时可以在控制台或代码中触发该事件，配合自定义的 UI 逻辑来实现个性化的右键菜单功能。

## 4. 易混淆点：return false 的作用 *Content-[05:36]

在 JS 中，`return false` 的作用会根据**事件绑定方式**的不同而产生巨大差异，这是面试中极易混淆的考点。

- **使用 `addEventListener` 绑定的事件**：
  - 如果在回调函数中使用 `return false`，**既无法**阻止事件冒泡（传播），**也无法**阻止默认行为。
  - 必须显式调用 `e.preventDefault()` 和 `e.stopPropagation()`。

- **使用 `onclick` (DOM0 级) 绑定的事件**：
  - 例如 `element.onclick = function() { ... }`。
  - 如果在回调函数中使用 `return false`：
    - **可以**阻止默认行为（例如 `<a>` 标签不会跳转）。
    - **无法**阻止事件传播（冒泡依然会发生）。

- **代码验证对比**：
  - **场景 A（`onclick` 绑定）**：给 `<a>` 标签绑定 `onclick` 事件并 `return false`。点击后，页面不跳转（默认行为被阻止），但事件会冒泡到父级元素。
  - **场景 B（`addEventListener` 绑定）**：将绑定方式改为 `addEventListener('click', ...)` 并 `return false`。点击后，页面依然会跳转（默认行为未被阻止），事件也会冒泡。
