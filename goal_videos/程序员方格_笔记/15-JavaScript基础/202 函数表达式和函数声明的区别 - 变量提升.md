## 变量提升核心概念 *Content-[00:00]

- **核心问题**：为什么函数声明能先调用后定义，而函数表达式却不行？其核心原因在于 **变量提升**（预解析）。
- **变量提升机制**：这是 JavaScript 的底层执行机制，也是前端面试的必考高频考点。JS 在执行代码之前，会先扫描一遍代码，将**变量声明**和**函数声明**提前到当前作用域的最前面。
- **形象比喻**：相当于提前准备好“容器”，但没有装东西。就像做饭前先把锅碗瓢盆（变量和函数声明）排好，但米和菜（赋值操作）还没拿出来，不能直接做饭。
- **关键点**：声明操作会提前，但**赋值操作不会提前**。

## 案例一：变量声明与预解析机制 *Content-[01:03]

- **代码示例**：
  ```javascript
  console.log(age); // 输出结果
  var age = 18;
  ```
- **执行结果**：输出 `undefined`，而不是报错，也不是 18。注意：`let` 和 `const` 不存在变量提升，此处主要讨论 `var`。
- **JavaScript 执行机制的三个阶段**：
  1. **语法阶段**：检查代码语法是否存在错误。
  2. **预解析阶段**：寻找 `var` 和 `function` 关键字。如果找到，将其声明提前到顶部，并默认赋值为 `undefined`。
  3. **执行阶段**：从上到下逐行执行代码。
- **案例详细拆解**：
  - **预解析**：扫描到 `var age`，将其提前到顶部，此时内存中 `age = undefined`。
  - **执行阶段**：
    - 执行 `console.log(age)`，此时 `age` 的值为 `undefined`，因此输出 `undefined`。
    - 执行 `age = 18`，完成赋值。
    - 如果在赋值后再次打印 `age`，结果则为 18。

## 案例二：函数声明的整体提升 *Content-[04:11]

- **代码示例**：
  ```javascript
  console.log(sayHi); 
  function sayHi() {
      console.log('hi');
  }
  sayHi(); 
  ```
- **执行结果**：第一次 `console.log(sayHi)` 输出的是**整个函数体代码**，不会报错；后续调用正常输出 `hi`。
- **案例详细拆解**：
  - **预解析**：扫描到 `function sayHi`，函数声明会**整体提升**（包括函数名和函数体）到当前作用域顶部。
  - **执行阶段**：
    - 执行 `console.log(sayHi)`，此时 `sayHi` 的值已经是完整的函数体，因此直接输出函数体代码。
    - 遇到函数声明代码块：不会改变已存在的值，直接跳过。
    - 执行 `sayHi()` 函数调用：函数调用会开启**新的局部预解析和执行代码**。函数内部没有 `var` 和 `function`，预解析为空，直接进入执行阶段，输出 `hi`。

## 案例三：函数表达式的部分提升 *Content-[08:32]

- **代码示例**：
  ```javascript
  console.log(sayHello); 
  var sayHello = function() {
      console.log('你好');
  };
  sayHello(); 
  ```
- **执行结果**：第一次 `console.log(sayHello)` 输出 `undefined`；后续调用正常输出 `你好`。
- **案例详细拆解**：
  - **预解析**：扫描到 `var sayHello`，将其提前到顶部并赋值为 `undefined`。**注意：等号右边的函数表达式不会被提升**。
  - **执行阶段**：
    - 执行 `console.log(sayHello)`，此时变量值为 `undefined`。
    - 执行到函数表达式赋值：`sayHello` 的值由 `undefined` 变为 `Function`。
    - 执行 `sayHello()`：此时函数已具备完整的值，正常调用并输出 `你好`。

## 核心总结：函数声明与函数表达式的区别 *Content-[11:43]

- **函数声明**：
  - **整体提升**：提前准备好整个函数（包含函数名和函数体）。
  - **特性**：可以**先调用后定义**，不会报错。
- **函数表达式**：
  - **部分提升**：只提升变量声明（`var`），不提升赋值（函数体）。
  - **特性**：提前准备好了变量，但变量里面没有函数（值为 `undefined`）。如果先调用该函数（如 `sayHello()`），会因为值为 `undefined` 而**报错**（`TypeError`）；如果是打印该变量，则输出 `undefined`。
