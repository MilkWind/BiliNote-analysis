## new 运算符的核心作用 *Content-[00:00]
- **核心定义**：`new` 运算符主要用于创建一个用户定义的对象类型的实例，或者创建一个具有构造函数的内置对象类型的实例。
- **使用方式**：通常通过 `new` 一个函数来获取当前实例对象。
- **学习建议**：在进行任何手写代码实现之前，必须先理清该操作符的核心功能与特性，然后再去推导和编写其内部机制。

## new 操作符的功能演示与特性分析 *Content-[01:16]
- **构造函数定义**：定义一个 `person` 构造函数，接收 `name` 和 `age` 参数。
- **原型扩展**：在 `person.prototype` 原型对象上新增属性（如 `hobby`）和方法（如 `sayYourName`）。
- **实例化与特性验证**：
  - 通过 `new person('张三', 18)` 获取实例。
  - **实例属性访问**：实例能够直接访问构造函数内部定义的属性（`name`, `age`）。
  - **原型链查找**：实例能够沿着 `__proto__` 原型链查找到原型对象（`prototype`）上定义的属性和方法（如 `sayYourName`, `toString` 等）。
  - **方法调用**：成功调用 `sayYourName` 方法并返回预期结果。

## 手写 new 操作符：第一版基础实现 *Content-[04:10]
由于 `new` 是语言关键字，我们需要通过定义一个普通函数（如 `myNew`）来模拟其功能。
- **步骤 1：获取构造函数**。通过 `arguments` 对象获取传入的第一个参数。可以使用数组的 `shift` 方法将其提取出来，赋值给 `constructor` 变量。
- **步骤 2：创建新对象**。创建一个空对象（如 `let obj = {}`）。
- **步骤 3：继承构造函数的原型**。将新对象的 `__proto__` 属性指向构造函数的 `prototype`，从而建立原型链，获取原型上的属性和方法。
- **步骤 4：执行构造函数**。使用 `apply` 方法执行构造函数，将 `this` 指向新创建的对象，并传入剩余的参数。
- **步骤 5：返回实例**。将执行后的对象 `return` 出去。
- **验证效果**：传入 `person` 及相关属性，成功获取包含 `name`、`age`、`hobby` 及原型层内容的对象，基础功能实现成功。

## 完善逻辑：处理构造函数中的 return 返回值 *Content-[08:02]
- **问题发现**：如果在构造函数中显式使用了 `return`，原生 `new` 和手写 `new` 的表现会存在差异。
- **原生 `new` 的返回规则**：
  - 如果 `return` 的是一个**对象**（如 `return { name, age }`），则返回该对象。
  - 如果 `return` 的是**基本数据类型**（如 `return name`）或者**没有 `return`**，则忽略该返回值，依然返回最初创建的新实例对象。
- **代码修正逻辑**：
  - 获取 `apply` 执行后的结果（如 `let result = constructor.apply(obj, args)`）。
  - 判断 `result` 的类型：如果 `typeof result === 'object'`（且需排除 `null`），则使用 `result` 作为最终返回值。
  - 否则，使用一开始创建的新对象 `obj` 作为返回值。

## 手写 new 操作符：第二版完整优化实现 *Content-[10:26]
在完整版实现中，需要增加类型校验并优化代码结构。
- **细节 1：校验构造函数**。获取构造函数后，必须判断其是否为 `function`。如果不是，需要抛出异常（`throw new Error(...)`），因为 `new` 只能处理函数类型的构造函数。
- **细节 2：优化对象创建与原型继承**。
  - 摒弃分两步走（先 `new Object()` 再修改 `__proto__`）的写法。
  - 直接使用 `Object.create(constructor.prototype)`。
  - **优势**：`Object.create` 可以直接返回一个新对象，并将其原型指向传入的参数。这样将“创建对象”和“继承原型”合二为一，代码更加简洁高效。
- **细节 3：执行与返回**。
  - 使用 `apply` 执行构造函数并传入参数，获取结果 `result`。
  - 判断 `result` 是否为对象实例（`typeof result === 'object' && result !== null`），如果是则返回 `result`，否则返回通过 `Object.create` 创建的对象。
