## 1. Symbol 数据类型简介与面试考察 *Content-[00:03]
- **基本概念**：`Symbol` 是 ES6 新增的数据类型，用来表示**独一无二**的值。
- **创建方式**：
  - 必须使用 `Symbol()` 函数进行创建（注意首字母 `S` 大写）。
  - **千万不要使用 `new` 关键字**（如 `new Symbol()` 是绝对错误的）。
- **核心用途**：主要用作**对象的属性**。
- **面试高频考察点与避坑指南**：
  - **基础错误**：很多候选人（甚至包括应聘讲师的候选人）会错误地使用 `new` 关键字来创建 `Symbol`，这会直接暴露其基础知识不扎实，即使前面回答得再好也会被扣分。
  - **面试官的“连环问”策略**：
    1. **第一问**：如何创建 `Symbol`？（考察基础理论，看过面试题基本不会错）。
    2. **第二问**：`Symbol` 什么时候使用？（考察应用场景，标准答案是“作为对象的属性”）。
    3. **第三问**：在你的简历项目中，具体在哪个地方用过 `Symbol`？（考察实际项目经验。这个问题能卡掉 80%~90% 只懂理论而没有实际使用经验的候选人）。
  - **大厂要求**：中大厂及中大型企业对基本功要求极高，不仅要求“知道理论”，更要求“知道怎么用”以及“在实际项目中哪里用过”。

## 2. Symbol 的创建与“独一无二”特性 *Content-[03:08]
- **创建示例与参数作用**：
  ```javascript
  const s1 = Symbol('K1');
  const s2 = Symbol('K2');
  ```
  - 传入的参数（如 `'K1'`、`'K2'`）仅作为**标识符**，目的是在控制台打印时方便区分不同的 `Symbol` 变量。
  - 参数不影响 `Symbol` 的唯一性，即使不传参数，或者传入完全相同的参数，生成的 `Symbol` 值也是不相等的。
- **验证“独一无二”特性**：
  - 使用 `===` 比较：`s1 === s2` 的结果为 `false`。
  - 即使去掉参数 `Symbol()`，比较结果依然是 `false`，这证明了其绝对的独一无二。
- **数据类型检测**：
  - 使用 `typeof s1` 进行检测，返回结果为字符串 `"symbol"`。

## 3. Symbol 的核心用途：作为对象属性 *Content-[04:36]
- **背景痛点**：在学习 `Symbol` 之前，对象的属性名通常使用字符串表示。由于对象属性具有唯一性，如果定义了两个同名的字符串属性，后定义的属性会**覆盖**先定义的属性。
- **Symbol 的优势**：因为 `Symbol` 值是独一无二的，使用它作为对象属性名可以完全避免属性名冲突和覆盖的问题。
- **代码演示**：
  ```javascript
  const s1 = Symbol('key1');
  const s2 = Symbol('key2');

  const obj = {};
  // 使用 Symbol 作为属性名赋值
  obj[s1] = '张三';
  obj[s2] = '李四';

  console.log(obj); 
  // 输出包含 Symbol 键值对的对象，不会发生覆盖

  // 访问 Symbol 属性
  console.log(obj[s1]); // 输出: 张三
  console.log(obj[s2]); // 输出: 李四
  ```
- **注意事项**：访问以 `Symbol` 为键的对象属性时，必须使用**方括号语法**（如 `obj[s1]`），不能使用点语法（如 `obj.s1` 是错误的）。

## AI 总结
`Symbol` 是 ES6 引入的重要数据类型，其核心特性是生成**独一无二的值**。在创建时，必须使用 `Symbol()` 函数，严禁使用 `new` 关键字。它的主要应用场景是作为**对象的属性名**，以解决传统字符串属性名可能引发的冲突和覆盖问题。在前端面试中，中大厂不仅考察候选人对 `Symbol` 基础语法的掌握，更会通过“连环问”深挖其在实际项目中的应用经验，因此候选人不仅要懂理论，更要具备在真实业务场景中运用 `Symbol` 的能力。
