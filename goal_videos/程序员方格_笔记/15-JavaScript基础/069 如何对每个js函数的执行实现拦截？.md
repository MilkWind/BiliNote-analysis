## 问题解析与核心思路 *Content-[00:00]

在前端面试中，**“如何对 JS 函数的执行实现拦截”** 是一道经典的场景题。该问题主要考察候选人对 JavaScript 函数执行机制的理解，以及如何通过代码手段感知并控制函数的执行过程。

针对这个问题，常用的解决手段主要分为以下两种：
- **手动包裹函数**：通过高阶函数（Higher-Order Function）的形式，在原始函数外层包裹一层逻辑。
- **代理对象方式**：通过 ES6 提供的 `Proxy` 特性，以代理对象的方式来拦截函数的调用。

## 方法一：使用高阶函数实现拦截 *Content-[01:35]

高阶函数是指将函数作为参数传入，或者返回一个新函数的函数。通过高阶函数，我们可以在执行原始函数之前和之后，插入自定义的拦截逻辑（如函数柯里化、代理函数等思想）。

### 实现逻辑
1. 定义一个 `intercept` 高阶函数，接收原始函数 `fn` 作为参数。
2. 该高阶函数返回一个新的函数，新函数接收任意参数（使用 rest 参数 `...args` 收集）。
3. 在新函数内部：
   - **拦截前**：执行打印操作，记录即将执行的参数。
   - **执行原函数**：使用 `fn.apply(this, args)` 调用原始函数，确保 `this` 上下文正确传递，并接收返回值。
   - **拦截后**：执行打印操作，记录函数执行的结果。
   - **返回结果**：将原函数的执行结果返回。

### 代码示例

```javascript
// 定义高阶拦截函数
function intercept(fn) {
  return function(...args) {
    console.log('拦截前，参数：', args);
    
    // 执行原始函数，并绑定正确的 this 上下文
    const result = fn.apply(this, args); 
    
    console.log('拦截后，结果：', result);
    
    // 返回原始函数的执行结果
    return result;
  }
}

// 原始函数
function add(a, b) {
  return a + b;
}

// 使用高阶函数包裹原始函数
const interceptedAdd = intercept(add);

// 调用被拦截的函数
interceptedAdd(1, 2);
```

### 运行效果
通过这种形式调用，除了得到 `add` 函数原本的计算结果 `3` 之外，还会额外输出拦截前后的相关参数和结果打印，从而完美实现了对函数执行的拦截。

## 方法二：使用 Proxy 代理对象实现拦截 *Content-[04:25]

`Proxy` 是 ES6 引入的强大特性，在 Vue3 等现代前端框架中被广泛用于拦截对象的操作。同样地，JavaScript 中的函数也是对象，因此我们完全可以使用 `Proxy` 来代理函数，并通过拦截 `apply` 操作来实现函数执行的拦截。

### 实现逻辑
1. 定义一个 `handler` 对象，在其中提供 `apply` 拦截器。
2. `apply` 方法会接收三个参数：
   - `target`：被代理的原始函数。
   - `thisArg`：函数调用时的 `this` 上下文。
   - `argumentsList`：函数调用时传入的参数列表（数组或类数组）。
3. 在 `apply` 内部：
   - **拦截前**：执行打印操作，记录参数。
   - **执行原函数**：推荐使用 `Reflect.apply(target, thisArg, argumentsList)` 来执行原始函数，这能确保默认行为被正确触发，并接收返回值。
   - **拦截后**：执行打印操作，记录结果。
   - **返回结果**：将结果返回。
4. 使用 `new Proxy(targetFn, handler)` 创建代理函数并调用。

### 代码示例

```javascript
// 原始函数
function add(a, b) {
  return a + b;
}

// 定义 Proxy 的 handler
const handler = {
  apply(target, thisArg, argumentsList) {
    console.log('拦截前，参数：', argumentsList);
    
    // 使用 Reflect.apply 执行原始函数
    const result = Reflect.apply(target, thisArg, argumentsList);
    
    console.log('拦截后，结果：', result);
    
    return result;
  }
};

// 创建 Proxy 代理对象
const proxyAdd = new Proxy(add, handler);

// 调用代理函数
proxyAdd(1, 2);
```

### 运行效果
利用 `Proxy` 方式，我们无需修改原函数的调用方式，只需将函数引用替换为代理后的引用，即可在底层无感拦截函数的调用，并输出拦截前后的信息。

## AI 总结 *Content-[06:35]

在 JS 中实现函数执行拦截主要有两种主流方案：
1. **高阶函数方案**：通过手动包裹函数实现，逻辑直观，兼容性好。但需要显式地用高阶函数去包裹原函数，具有一定的代码侵入性。
2. **Proxy 代理方案**：利用 ES6 的 `Proxy` 和 `Reflect` 特性，属于非侵入式拦截。调用方无需改变调用习惯，只需替换函数引用即可，代码更加优雅，也是目前现代前端框架（如 Vue3 响应式系统）的核心实现思路。

在面试中，建议先答出高阶函数的基础思路，随后引出 `Proxy` 方案作为进阶回答，这样能充分展现对 JavaScript 底层机制和现代 API 的掌握程度。
