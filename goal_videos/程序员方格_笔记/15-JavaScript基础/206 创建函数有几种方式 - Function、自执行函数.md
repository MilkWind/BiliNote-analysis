## 具名函数表达式的补充与调用规则 *Content-[00:00]

### 具名函数的两大好处
1. **调试更方便**：当代码报错时，错误信息会显示具体的函数名，帮助开发者快速定位问题。
2. **支持递归调用**：函数内部可以使用自身的名字进行调用，从而实现递归功能。这在实现简单算法（如求平方和、阶乘、斐波那契数列等）时非常方便。

### 核心调用规则（面试易踩坑点）
- **内部调用**：具名函数表达式**内部**能够使用自己的函数名进行递归或调用。
- **外部调用**：在函数**外部**，只能使用接收该函数的**变量名或常量名**，不能直接使用函数名。
  - *错误示例*：在外部直接调用函数名（如 `square`）会报错 `square is not defined`。
  - *正确做法*：使用赋值时的变量名（如 `const square = function squareFn() {...}`，外部只能用 `square`）。

## Function 构造函数详解 *Content-[02:03]

### 概念与格式
`Function` 构造函数是 JS 内置的用于动态创建函数的方式。在实际开发中极少使用，因为语法特殊且不够优雅。
- **基本格式**：`new Function('参数1', '参数2', '函数体代码')`
- **核心特点**：所有的参数和函数代码体**必须使用字符串形式**（即加上引号）。

### 代码示例
```javascript
// 使用 Function 构造函数创建两数相乘的函数
const mul = new Function('a', 'b', 'return a * b');

// 调用函数
const res = mul(4, 5); 
console.log(res); // 输出: 20
```

### 优缺点分析
- **优点**：可以**动态生成函数**。例如，从后端获取一段可执行的 JS 代码字符串，将其传入 `Function` 构造函数中动态执行。
- **缺点**：
  1. **可读性差**：代码逻辑被包裹在字符串中，难以阅读和维护。
  2. **安全隐患**：如果传入的字符串包含用户输入的内容，极易被注入恶意代码（类似 XSS 攻击）。
  3. **执行效率低**：每次执行都需要解析字符串，性能较差。
- **面试应对**：实际开发几乎不用，但面试时需准确说出其“参数必须是字符串”的特点以及上述优缺点。

## 自执行匿名函数 *Content-[06:59]

### 概念与应用场景
- **概念**：定义完函数后立即自动执行，无需手动调用。
- **应用场景**：常用于初始化代码，能够有效避免全局变量污染。

### 语法格式与注意事项
- **标准格式**：`(function(形参) { 代码体 })(实参)`
- **注意事项**：函数外部**必须包裹一层括号**，使其成为函数表达式。如果直接写 `function(){}()` 会导致语法错误。

### 代码示例
```javascript
// 初始化页面标题的自执行匿名函数
(function(title) {
    console.log('页面初始化标题:', title);
})('JS JavaScript 高频面试真题');
```

## 自执行具名函数 *Content-[09:00]

### 概念与核心区别
- **概念**：带有函数名的自执行函数。
- **与匿名自执行函数的核心区别**：
  - **具备函数名**：方便调试。如果代码出错，报错信息能直接显示函数名（如 `sayHi`），从而快速定位问题。
  - **应用场景**：实际开发中偶尔用于复杂的初始化场景。
  - **面试优势**：在面试中能主动提及并区分这两种自执行函数，可以展现更扎实的基础，增加竞争优势。

### 代码示例
```javascript
// 自执行具名函数
(function sayHi(name) {
    console.log('Hello, ' + name + ' 面试加油');
})('前端宝子');
```

## 六种创建函数方式总结 *Content-[11:21]

视频中完整梳理了 JavaScript 中创建函数的六种常见方式，面试时需熟练掌握：
1. **函数声明**（Function Declaration）
2. **匿名函数表达式**（Anonymous Function Expression）
3. **具名函数表达式**（Named Function Expression）
4. **`Function` 构造函数**（Function Constructor）
5. **自执行匿名函数**（Immediately Invoked Anonymous Function Expression / IIFE）
6. **自执行具名函数**（Immediately Invoked Named Function Expression）
