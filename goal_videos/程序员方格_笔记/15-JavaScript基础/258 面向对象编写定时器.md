## 1. 面试题背景与需求分析 *Content-[00:00]

- **面试背景**：面向对象编程（OOP）在前端开发中越来越常见，是大厂面试的高频考点。面试官通常不会直接让候选人写一道纯算法题，而是以具体的业务需求为例进行考察。
- **业务需求**：采用面向对象编程的方式，自定义一个倒计时计时器（Timer）。
  - **应用场景**：节假日活动、网站促销倒计时（如倒计时10秒、20秒后展示奖品）。
  - **功能要求**：
    1. 能够自定义控制倒计时的时间时长。
    2. 倒计时结束时，能够自动触发指定的事件（执行自定义的回调动作，如发放奖品、弹出提示等）。

## 2. 核心考察点与面向对象设计 *Content-[02:30]

- **常见误区**：仅仅使用普通的 `setTimeout` 或 `setInterval` 写一个全局定时器。这种写法代码冗余、缺乏封装，容易导致全局变量污染。
- **核心考察点**：考察候选人的**面向对象编程能力**和**组件化思维**。
  - 要求将所有与倒计时功能相关的属性和方法，封装在一个 Class（类）或 Object（对象）中。
  - 封装后的代码可以作为公司的公共组件库或公用代码，提高代码的复用性和可维护性，这也是企业非常看重的工程化能力。

## 3. 构造函数与属性设计 *Content-[04:00]

- **确定对象**：根据需求，核心对象是“倒计时器（Countdown Timer）”。
- **构造函数参数设计**：在实例化倒计时器时，需要由父组件或调用方动态传入以下必要参数：
  1. **显示载体（DOM Element）**：用于渲染倒计时数字的页面元素。它是动态的且必须的，因为不同的使用场景挂载的 DOM 节点不同。
  2. **结束回调函数（Callback Function）**：倒计时归零时需要执行的业务逻辑。具体执行什么代码由调用方决定，因此需要作为参数动态传入。
- **内部属性设计**：
  - `task`：用于保存定时器的任务 ID（如 `setInterval` 的返回值），以便后续清除定时器。
  - `targetTime`：目标时间戳。可以通过用户输入或点击“开始”按钮时计算得出。

## 4. 核心方法实现：时间格式化与状态更新 *Content-[08:50]

- **时间格式化方法（Format Time）**：
  - 将计算得出的时、分、秒格式化为标准的两位数（如 `09`、`05`）。
  - 使用冒号 `:` 将时、分、秒拼接起来（如 `00:10:00`），确保 UI 显示标准统一。
- **状态更新方法（Update Display）**：
  - 获取当前时间戳，计算剩余时间：`剩余时间 = 目标时间戳 - 当前时间戳`。
  - **判断是否结束**：
    - 如果 `剩余时间 <= 0`：
      - 停止定时器进程。
      - 将显示载体内容更新为 `00:00:00`。
      - 检查是否传入了结束回调函数，如果传入（且为 Function 类型），则自动执行该回调。
    - 如果 `剩余时间 > 0`：
      - 将剩余时间（毫秒）除以 1000 并向下取整，得到剩余总秒数。
      - 重新计算时、分、秒，调用格式化方法并更新 DOM 显示。

## 5. 核心方法实现：启动、停止与重置 *Content-[12:00]

- **启动方法（Start）**：
  - 获取并验证目标时间（`targetTime`）是否有效。
  - 防重复创建：检查 `task` 是否已存在，如果存在则先清除旧的定时器。
  - 立即执行一次更新方法，确保界面立刻响应。
  - 使用 `setInterval` 设置定时器，每隔 1 秒（1000ms）执行一次“状态更新方法”。
  - 将 `setInterval` 返回的 ID 赋值给 `task` 属性保存。
- **停止方法（Stop）**：
  - 检查 `task` 是否存在，若存在则调用 `clearInterval(task)` 清除定时器。
  - 将 `task` 属性置为空（`null` 或 `undefined`）。
- **重置方法（Reset）**：
  - 调用停止方法，清除当前定时器。
  - 将显示载体的内容重置为 `00:00:00`。
  - 清空目标时间（`targetTime`）等内部状态，恢复到初始未启动状态。

## 6. 面试总结 *Content-[14:01]

- 本题的核心在于**面向对象编程（OOP）能力**的展现。
- 优秀的回答需要做到：
  - 准确识别业务对象（倒计时器）。
  - 合理设计构造函数，区分“外部传入的动态依赖”（如 DOM、回调）和“内部维护的状态”（如 timer ID、target time）。
  - 将相关的方法（格式化、更新、启动、停止）封装在类中，并通过 `this` 将对象的属性贯穿关联起来，实现高内聚、低耦合的组件设计。
