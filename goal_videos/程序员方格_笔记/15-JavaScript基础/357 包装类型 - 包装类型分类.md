## 包装类型与装箱概念 *Content-[00:00]
- **装箱（Boxing）**：指将基本数据类型转换为对应的引用类型的操作。
- 在 JavaScript 中，对基本数据类型进行某些操作时，底层会自动进行装箱处理，将其转换为对应的包装类型对象。

## 隐式装箱与显式装箱的区别 *Content-[00:26]
装箱操作主要分为两种类型：
1\. **隐式装箱**：
   - 开发者没有实际去手动操作，JS 引擎在底层默默、悄悄地将基本类型转换为引用类型。
2\. **显式装箱**：
   - 开发者主动进行操作，通过基本包装类型对象对基本数据类型进行显式的转换操作。
- **最大区别**：是否需要开发者手动执行装箱操作。

## 隐式装箱详解与案例 *Content-[02:00]
- **触发条件**：
  - 当给基本数据类型（如 `String`、`Number`、`Boolean`）的基本值调用方法时，JS 引擎会自动触发隐式装箱。
- **核心特点**：
  - 临时实例对象仅存在于执行的瞬间。
  - 执行完毕之后立即销毁。
  - 无法直接在实例上自定义属性和方法（如果需要，必须在其原型 `prototype` 上定义）。
- **经典案例**：
  - 基本数据类型的值调用内置方法，例如：`'abc'.substring()`。
  - 布尔值调用方法，例如：`true.toString()`。
  - 这些操作都会发生隐式的装箱。

## 显式装箱详解与代码案例 *Content-[03:50]
- **触发条件**：
  - 开发者手动通过包装类型的构造函数创建实例。
  - 例如：`new String()`、`new Number()`、`new Boolean()`。
- **核心特点**：
  - 创建的实例是普通的引用类型。
  - 不会自动销毁，直到执行流离开作用域或者被手动置空（`null`）。
  - 可以自定义属性或方法。
- **代码案例演示**：
  ```javascript
  // 手动创建 String 包装类型实例
  let obj = new String('最编程');

  // 自定义属性
  obj.age = 20;

  // 自定义方法
  obj.sayHi = function() {
      // this 指向实例，valueOf() 获取原始参数值
      return this.valueOf(); 
  };

  // 访问自定义属性和方法
  console.log(obj.age); // 输出: 20
  console.log(obj.sayHi()); // 输出: 最编程
  ```

## 显式装箱实例的引用类型特性 *Content-[07:40]
- **引用类型比较**：
  - 显式装箱创建的实例是引用类型，比较时比较的是**地址指针**，而非**值**。
  - **案例**：
    ```javascript
    let strObj1 = new String('最编程');
    let strObj2 = new String('最编程');
    console.log(strObj1 === strObj2); // 输出: false
    ```
  - **原因**：两个实例在内存中是独立的空间，并不是同一个地址指针。
- **内存管理**：
  - 通过 `new` 操作符创建的是引用数据类型，可以随意添加属性和方法。
  - 在执行流离开当前作用域之前，该实例会一直保留在内存当中，不会马上销毁。

## 为隐式装箱的基本类型添加自定义方法 *Content-[09:28]
- **问题**：如何给隐式装箱的基本类型添加自定义方法或属性？
- **解决方案**：可以给它的**原型对象（prototype）** 上添加。
- **代码案例**：
  ```javascript
  let s1 = '最编程';

  // 在 String 构造函数的原型对象上添加自定义方法
  String.prototype.test = function() {
      return this.length;
  };

  // 基本类型字符串 s1 即可直接调用该方法
  console.log(s1.test()); // 输出: 3 (字符串长度)
  ```
- **总结**：隐式装箱要想添加自定义方法，需要添加到对应构造函数的原型对象上面。
