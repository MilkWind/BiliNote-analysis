## 面试常见问题引入 *Content-[00:00]

在前端面试中，只要涉及到数据类型的问题，必然会延伸到**包装类型（Wrapper Types）**。很多候选人对基本类型（如字符串、数字）能调用方法感到困惑，甚至误以为字符串是引用类型；或者在尝试给基本类型添加自定义属性后发现结果为 `undefined`，却不知道问题出在包装类型的“临时销毁”特性上。

面试官通常会通过以下 8 个高频问题来考察候选人对包装类型的理解：

1\. **什么是 JS 的包装类型？包含哪几种类型？**
2\. **已经有了基本数据类型了，为什么 JS 还要设计包装类型？**
3\. **什么是 JS 中的装箱操作？分为哪两种？二者的核心区别又是什么？**
4\. **为什么 `7.toString()` 方法会报错？写出至少两种修改后能正常执行的写法。**
5\. **为什么 `"2".toString()`、`true.toString()` 能正常调用方法，而 `undefined.toString()` 会报错呢？**
6\. **包装类型和普通的引用类型有什么核心区别？**
7\. **为什么不能直接给基本数据类型添加自定义属性和方法？请举例说明。**
8\. **如何给基本数据类型添加可复用的自定义方法？**

## JS 数据类型与包装类型概述 *Content-[01:45]

### 数据类型分类
在 JavaScript 中，数据类型主要分为两类：
- **基本数据类型（Primitive Types）**
- **引用数据类型（Reference Types）**

**包装类型**严格来说不属于上述两种类型中的任何一种，但它与这两者息息相关。

### 基本类型与引用类型的区别
- **引用类型**：可以有自己内置的方法，也可以自定义其他方法来操作数据。
- **基本类型**：默认情况下不能像引用类型那样拥有自己的内置方法和数据，因此不能直接进行复杂的逻辑操作。

### 7 种基本数据类型与包装类型的对应关系
按照最新的 JS 标准定义，基本数据类型共有 **7 种**，但**只有其中 3 种拥有包装类型**：

**拥有包装类型的 3 种基本类型：**
- `Boolean`
- `Number`
- `String`

**没有包装类型的 4 种基本类型：**
- `Undefined`
- `Null`
- `Symbol`
- `BigInt`

> **注意**：没有包装类型的这 4 种基本类型的值，无法调用任何方法，强行调用会直接报错（例如 `undefined.toString()` 会报错）。

## 包装类型的工作原理（装箱操作） *Content-[05:45]

基本包装类型和引用类型一样，拥有内置的方法，可以对数据进行额外的逻辑操作处理。

### 代码示例与疑惑
```javascript
let s1 = '前端编程';
let s2 = s1.substring(1); 
console.log(s2); // 输出: "端编程"
```
**疑惑**：`s1` 存储的是字符串 `'前端编程'`，属于基本数据类型。按照常理，基本类型不该有自己的方法，调用 `substring` 应该报错，但实际并没有报错。这是为什么？

### JS 引擎后台的 3 个步骤
虽然基本类型的值本身没有方法，但 JS 引擎在后台默默进行了“装箱”操作，具体分为以下三步：

1\. **创建临时实例**
使用对应的包装类型构造函数，创建一个**临时的引用类型实例对象**，并将基本类型的值传入到该实例中。
```javascript
// 后台等价操作：
let tempS1 = new String('前端编程'); // 创建临时实例对象
```

2\. **调用指定方法**
在这个临时实例对象上，调用指定的内置方法，并得到最终结果。
```javascript
// 后台等价操作：
let s2 = tempS1.substring(1); // 在临时实例上调用方法
```

3\. **销毁临时实例**
方法调用完成后，**立即销毁**这个临时的实例对象（被垃圾回收机制回收）。内存栈中依然只保留原来的基本类型的值，临时的引用类型实例不复存在。
```javascript
// 后台等价操作：
tempS1 = null; // 销毁临时实例，释放内存
```

## 包装类型的核心总结 *Content-[12:00]

通过上述原理解析，我们可以得出关于包装类型的核心结论：

- **主要目的/用处**：为了让我们操作基本数据类型（`Boolean`、`Number`、`String`）的值变得更加简单和便捷。虽然基本类型的值默认没有方法，但后台临时创建的构造函数实例对象上有内置方法，供我们进行逻辑操作。
- **适用范围**：只有 `Boolean`、`String`、`Number` 这三种基本数据类型拥有包装类型，其余四种（`Undefined`、`Null`、`Symbol`、`BigInt`）没有。
- **核心特性（临时性）**：包装类型的实例对象是**临时创建**的。当内置方法调用完成后，该临时实例会**马上被销毁**。这就是为什么不能直接给基本数据类型添加自定义属性或方法的原因（因为添加后实例就被销毁了，再次访问时又会创建一个新的临时实例，导致之前添加的属性丢失，结果为 `undefined`）。

## AI 总结

本视频详细讲解了前端面试中的高频考点——**JavaScript 包装类型（Wrapper Types）**。核心要点如下：
1. **概念与分类**：包装类型是为了方便操作基本数据类型而设计的。在 7 种基本数据类型中，仅有 `Boolean`、`Number` 和 `String` 拥有对应的包装类型，而 `Undefined`、`Null`、`Symbol` 和 `BigInt` 没有，调用方法会报错。
2. **工作原理（装箱机制）**：当对基本类型调用方法时，JS 引擎会在后台执行三步操作：创建临时包装对象 -> 调用指定方法 -> 立即销毁临时对象。
3. **面试避坑**：由于包装对象是“临时创建且用完即毁”的，因此无法直接给基本数据类型持久化地添加自定义属性或方法。理解这一“临时销毁”特性是解答相关面试题（如属性添加后为 `undefined`）的关键。
