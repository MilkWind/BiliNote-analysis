## 1. 数组合并方法 concat *Content-[00:00]

`concat` 方法主要用于合并两个或多个数组，或者在数组尾部追加元素。

### 核心特性
- **不改变原数组**：此方法不会修改调用它的原数组，而是返回一个新的数组实例。
- **语法**：`array.concat(value1, value2, ..., valueN)`。参数是可选的，可以传入无数个数组或值。
- **浅拷贝机制**：如果省略所有参数（即直接调用 `array.concat()`），该方法会返回调用此方法的现有数组的一个**浅拷贝**。
  - **浅拷贝概念**：仅复制引用地址。如果数组中包含引用类型的数据，修改新数组中的引用对象会影响到原数组中的对应对象，因为它们在内存中指向同一块地址。

### 示例演示
1. **常规合并**：
   - 原数组为 `[1, 2, 3, 4, 5]`。
   - 调用 `concat(6, 7)`。
   - **结果**：原数组保持不变，仍为 `[1, 2, 3, 4, 5]`；返回的新数组为 `[1, 2, 3, 4, 5, 6, 7]`。
2. **省略参数（浅拷贝）**：
   - 原数组为 `[1, 2, 3, 4, 5]`。
   - 调用 `concat()`，不传入任何参数。
   - **结果**：返回的新数组内容为 `[1, 2, 3, 4, 5]`。但需要注意，新数组与原数组在内存中存在地址引用关系（即浅拷贝）。

### 使用场景
- 适用于需要**合并多个接口返回的数组数据**，且**不需要修改原数组**的场景。

## 2. 数组尾部删除方法 pop *Content-[03:02]

`pop` 方法用于从数组中删除最后一个元素。

### 核心特性
- **改变原数组**：此方法会直接修改原数组，并更改数组的长度。
- **语法**：`array.pop()`，无参数。
- **返回值**：返回从数组中删除的那个元素。如果数组为空，则返回 `undefined`。

### 示例演示
- 原数组为 `[1, 2, 3, 4, 5]`。
- 调用 `pop()`。
- **结果**：原数组被修改为 `[1, 2, 3, 4]`（最后一个元素 `5` 被移除）；返回值为被删除的元素 `5`。

## 3. 数组头部删除方法 shift *Content-[04:20]

`shift` 方法用于从数组中删除第一个元素，与 `pop` 方法正好相反（`pop` 从后删除，`shift` 从前删除）。

### 核心特性
- **改变原数组**：此方法会直接修改原数组，并更改数组的长度。
- **语法**：`array.shift()`，无参数。
- **返回值**：返回从数组中删除的那个元素。如果数组为空，则返回 `undefined`。

### 示例演示
1. **常规删除**：
   - 原数组为 `[1, 2, 3, 4, 5]`。
   - 调用 `shift()`。
   - **结果**：原数组被修改为 `[2, 3, 4, 5]`（第一个元素 `1` 被移除）；返回值为被删除的元素 `1`。
2. **空数组测试**：
   - 对空数组调用 `shift()`。
   - **结果**：返回值为 `undefined`，与 `pop` 行为一致。

## 4. 数组任意位置删除方法 splice *Content-[06:03]

`splice` 方法功能非常强大，在删除场景下，它可以删除数组任意位置或任意个数的元素。

### 核心特性
- **改变原数组**：此方法会直接修改原数组。
- **语法**：`array.splice(start, deleteCount)`
  - `start`：删除的起始索引。如果传入负数，则表示从倒数第 N 个元素开始（注意：倒数是从 1 开始计算的，例如 `-1` 代表倒数第一个）。
  - `deleteCount`：要删除的元素个数。如果该值大于剩余元素的个数，则会删除从 `start` 开始的全部元素。
- **返回值**：返回一个由**被删除元素组成的新数组**。如果没有删除任何元素，则返回空数组。

### 示例演示
1. **常规删除**：
   - 原数组为 `[1, 2, 3, 4, 5]`。
   - 调用 `splice(0, 1)`：从索引 `0` 开始，删除 `1` 个元素。
   - **结果**：原数组变为 `[2, 3, 4, 5]`；返回值为 `[1]`（注意返回值是数组格式）。
2. **负数索引删除（倒数删除）**：
   - 原数组为 `[1, 2, 3, 4, 5]`。
   - 调用 `splice(-2, 1)`：从倒数第 2 个元素（即 `4`）开始，删除 `1` 个元素。
   - **结果**：原数组变为 `[1, 2, 3, 5]`（`4` 被移除）；返回值为 `[4]`。
3. **负数索引删除（末尾删除）**：
   - 原数组为 `[1, 2, 3, 4, 5]`。
   - 调用 `splice(-1, 1)`：从倒数第 1 个元素（即 `5`）开始，删除 `1` 个元素。
   - **结果**：原数组变为 `[1, 2, 3, 4]`（`5` 被移除）；返回值为 `[5]`。

## AI 总结

本次视频详细讲解了前端开发中四个常用的数组方法：`concat`、`pop`、`shift` 和 `splice`。
- **`concat`** 是唯一的非破坏性方法，用于合并数组且返回新数组，常用于需要保留原数据的场景；需特别注意其省略参数时的“浅拷贝”特性。
- **`pop`** 和 **`shift`** 是基础的破坏性方法，分别用于删除数组的尾部和头部元素，两者在空数组时均返回 `undefined`。
- **`splice`** 是最灵活的破坏性方法，支持通过正负索引定位并删除任意位置和数量的元素，其返回值是被删除元素组成的新数组。
掌握这些方法对原数组的影响、参数规则以及返回值类型，是应对前端面试和进行高效业务开发的核心基础。
