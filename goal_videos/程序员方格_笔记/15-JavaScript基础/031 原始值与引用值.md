## 原始值 (Primitive Values) *Content-[00:11]
- **基本概念**：原始值是 JavaScript 中最基础的数据单元。
- **存储位置**：它们的值直接存储在栈内存（Stack Memory）的变量位置上面。
- **数据类型**：包含 JavaScript 中的七种原始类型（如 `String`, `Number`, `Boolean`, `Null`, `Undefined`, `Symbol`, `BigInt`）。
- **访问方式**：因为值可以直接存储，所以对原始值的访问是**按值访问**。
- **核心特性**：
  - **不可变性**：原始值本身是不可变的，不能像对象那样动态地给它添加属性。
  - **按值复制**：当把一个原始值赋给另外一个变量时，计算机会给新变量分配一个新的存储空间，然后把原始值的一个完整副本复制过去。此后这两个变量完全独立，没有任何关系。
- **代码示例**：
  - 变量 `a` 的值为 `10`。
  - 执行 `let b = a` 时，`b` 得到了 `10` 这样一个全新的副本。
  - 修改 `b` 的值为 `20`，完全不会影响到 `a`，`a` 的值依然是 `10`。这就是按值复制的逻辑。

## 引用值 (Reference Values) *Content-[01:50]
- **基本概念**：引用值也就是我们常说的对象（Object）。与原始值不同，对象通常更加复杂，占用的空间也更大。
- **存储位置**：它们被存储在更加灵活的堆内存（Heap Memory）里面。
- **变量存储内容**：变量里存的不是对象本身，而是一个地址（指针/引用），这个地址指向堆内存中对象实际存储的位置。
- **复制行为（按引用复制）**：
  - 当将一个引用值赋给另外一个变量时，复制的仅仅是那个指针，而不是堆内存中的整个对象。
  - 结果是两个变量最终持有相同的指针，指向了堆内存中的同一个对象。
- **代码示例**：
  - `object1` 指向一个在堆内存中的对象。
  - 执行 `let object2 = object1` 时，`object2` 复制了 `object1` 的指针。
  - 此时 `object1` 和 `object2` 都指向了同一个对象。
  - 当通过 `object2` 修改 `name` 属性时，这个修改会立刻通过 `object1` 反映出来，因为它们操作的是同一个数据源。

## 函数参数传递机制 *Content-[03:48]
- **核心原则**：JavaScript 中**所有函数的参数都是按值传递的**。这句话对原始值和引用值都适用，只是表现不同。
- **传递原始值**：
  - 将变量 `count`（值为 `20`）传给 `addTen` 函数。
  - 函数内部的参数 `n` 得到的是 `20` 的一个副本。
  - 函数内部对 `n` 的所有操作都只是在操作这个副本，和外部的 `count` 没有任何关系。
  - 函数执行完之后，`count` 的值依然是 `20`。
- **传递引用值**：
  - 将 `person` 对象传给 `setName` 函数。
  - 函数内部的参数 `obj` 得到的是 `person` 变量中存的那个指针的一个副本。
  - 这个指针副本和原始指针指向的是同一个堆内存对象。
  - **修改属性**：通过 `obj.name` 去修改对象属性时，这个修改一定会影响到外部的 `person` 对象。
  - **重新赋值**：如果在函数内部给 `obj` 重新赋值一个新对象（例如 `obj = new Object()`），这仅仅是让 `obj` 这个内部指针指向了一个新的内存地址，从而切断了和外部 `person` 指针的联系。这并不会改变 `person` 原本的指向，后续的操作都不会再影响外部。

## 判断变量类型 *Content-[05:59]
判断变量具体类型主要有两个操作符：`typeof` 和 `instanceof`。

- **`typeof` 操作符**：
  - **作用**：判断原始类型的最佳工具，可以准确地返回像 `string`, `number` 这样的字符串。
  - **局限性**：对于 `null` 以及除函数以外的所有对象（如数组、自定义对象等），`typeof` 都会返回 `object`，没有办法做进一步的区分。

- **`instanceof` 操作符**：
  - **作用**：专门用来解决引用类型的判断问题。判断一个对象是不是某个特定构造函数创建出来的实例。
  - **工作原理**：检查对象的原型链（Prototype Chain）。
  - **局限性**：对所有原始值进行判断时都会返回 `false`，无法判断原始值。

- **示例对比**：
  - `typeof` 可以准确识别出字符串 `s`，但是对于对象 `obj` 和数组 `arr`，都只能给出比较模糊的 `object`。
  - `instanceof` 则可以清晰地告诉我们，`arr` 是 `Array` 对象的实例，而 `obj` 是 `Object` 对象的实例。
  - 对于原始字符串 `s`，`s instanceof String` 的结果是 `false`，说明 `instanceof` 没法判断原始值。

- **最终结论**：使用 `typeof` 去判断原始类型，使用 `instanceof` 判断引用类型。
