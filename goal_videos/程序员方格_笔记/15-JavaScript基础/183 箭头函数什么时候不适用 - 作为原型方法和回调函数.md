## 箭头函数作为对象原型方法 *Content-[00:00]

- **场景说明**：在对象的原型（`prototype`）上使用箭头函数定义方法。
- **错误写法示例**：
  ```javascript
  function Person(name) {
      this.name = name;
  }
  
  // 错误：在原型对象上使用箭头函数定义方法
  Person.prototype.sayName = () => {
      return this.name;
  }
  
  const p1 = new Person('静音小子');
  console.log(p1.sayName()); // 输出为空（undefined）
  ```
- **错误原因分析**：
  - 箭头函数没有自己的 `this`，其 `this` 继承自外层的词法作用域（即“他爹”的 `this`）。
  - `Person` 的原型对象定义在全局 `window` 环境中，因此箭头函数内的 `this` 继承自 `window`。
  - 当调用 `p1.sayName()` 时，`this` 指向 `window` 而非 `Person` 的实例 `p1`，导致无法访问实例的 `name` 属性。
- **正确写法**：
  - 将原型方法改为**普通函数**（使用 `function` 关键字）。
  ```javascript
  Person.prototype.sayName = function() {
      return this.name;
  }
  console.log(p1.sayName()); // 输出: 静音小子
  ```
- **核心原理**：
  - 原型上的普通函数被实例调用时，`this` 会动态指向调用它的实例对象（即 `p1`）。
  - 这符合原型链的调用逻辑，能够正常访问实例的属性和方法。

## 箭头函数作为 DOM 事件回调函数 *Content-[05:30]

- **背景知识**：
  - 在 JavaScript 中，`this` 是一个强大的特性，允许根据函数调用的方式动态更改上下文（通常上下文是指调用发生的目标对象，即“谁调用就指向谁”）。
  - 普通函数的 `this` 是**动态绑定**的，能解决约 80% 的场景。
  - 箭头函数在声明时**静态绑定**了上下文环境（继承自外层），不可动态修改。其好处是无需过多考虑 `this` 的词法作用域。
- **场景说明**：在客户端编程中，将事件侦听器附加到 DOM 元素是一项常见任务。事件处理函数通常需要将 `this` 作为目标元素。
- **错误写法示例**：
  ```html
  <button id="btn">点击我</button>
  ```
  ```javascript
  const oBtn = document.getElementById('btn');
  
  // 错误：事件回调使用箭头函数
  oBtn.addEventListener('click', () => {
      this.innerHTML = '点击成功';
  });
  ```
- **错误原因分析**：
  - 箭头函数定义在全局 `window` 环境中，`this` 继承自 `window`。
  - DOM 事件回调的预期是 `this` 指向触发该事件的 DOM 元素（如 `button`）。
  - 当发生点击事件时，浏览器尝试使用按钮上下文调用处理函数，但箭头函数不会更改其定义时的上下文。
  - 因此，`this` 依然指向 `window`，而 `window` 上没有 `innerHTML` 属性，导致修改按钮文本无效。
- **正确写法**：
  - 将事件回调改为**普通函数**，以解决动态改变 `this` 的问题。
  ```javascript
  oBtn.addEventListener('click', function() {
      this.innerHTML = '点击成功'; // 成功修改按钮文本
  });
  ```
- **核心原理**：
  - DOM 事件的普通函数回调中，`this` 会自动（动态）指向触发该事件的 DOM 元素（此处为 `button`）。
  - 因此可以成功获取并修改 `button` 的文本内容。

## AI 总结

- 箭头函数由于其 `this` 指向在定义时静态绑定的特性，在需要动态 `this` 上下文的场景中不适用。
- **不适用的核心场景**：
  1. **对象原型方法**：需要 `this` 指向调用该方法的实例对象，使用箭头函数会导致 `this` 错误地指向全局 `window`。
  2. **DOM 事件回调函数**：需要 `this` 指向触发事件的 DOM 元素，使用箭头函数同样会导致 `this` 指向全局 `window`，从而无法操作目标元素。
- **解决方案**：在这两类场景中，应始终使用**普通函数**（`function`），以确保 `this` 能够根据调用者动态绑定到正确的上下文（实例对象或 DOM 元素）。
