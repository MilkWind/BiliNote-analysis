## 1. call 的作用与优势总结 *Content-[00:01]

- **核心优势**：`call` 方法的主要作用是改变函数的 `this` 指向，从而实现工具方法的复用，有效减少重复代码。
- **场景示例**：以“发工资”为例，不需要为“张三”和“李四”分别定义独立的发工资函数。通过 `call` 改变 `this` 指向，张三和李四都可以复用同一个发工资的工具函数。

## 2. apply 的基本语法与核心区别 *Content-[00:31]

- **基本语法**：`函数.apply(this指向, 参数数组)`。
- **执行方式**：与 `call` 一样，`apply` 也是立即执行函数。
- **参数要求**：
  - **第一个参数**：`this` 指向的对象，规则与 `call` 完全一致。
  - **第二个参数**：必须是一个**数组**或**伪数组（类数组）**。参数会以数组的形式进行传递。
  - **异常处理**：如果传递的第二个参数不是有效的数组或伪数组，则会抛出类型异常（TypeError）。
  - **单参数处理**：即使只有一个参数，也必须将其放入数组中传递。
- **核心区别总结**：`call` 是逐个传递单个参数，而 `apply` 是传递数组参数，其余规则完全相同。

## 3. apply 传参演示：数组与伪数组 *Content-[02:27]

- **代码演示**：定义函数 `fn(a, b, c)`，内部打印 `a, b, c` 的值。创建一个空对象 `obj`。
- **使用数组传参**：
  - 调用 `fn.apply(obj, [1, 2, 3])`。
  - `this` 指向 `obj`，参数 `a, b, c` 分别接收数组中的 `1, 2, 3`。
- **使用伪数组传参**：
  - 调用 `fn.apply(obj, {0: 4, 1: 5, 2: 6, length: 3})`。
  - `this` 依然指向 `obj`，参数 `a, b, c` 分别接收伪数组中的 `4, 5, 6`。
- **结论**：`apply` 的第二个参数既支持真正的数组，也支持伪数组（类数组）。

## 4. 伪数组（类数组）的概念与特征 *Content-[04:01]

- **定义**：伪数组（类数组）是指具备与数组特征类似的对象。
- **核心特征**：
  1. 可以通过下标（索引）进行调用和访问。
  2. 具有 `length` 属性。
  3. 可以通过 `for` 循环或 `forEach` 等方法进行遍历。
- **代码示例**：
  ```javascript
  let arrayLike = {
      0: 'a',
      1: 'b',
      2: 'c',
      length: 3
  };
  ```
- **常见的伪数组应用场景**：
  - **DOM 节点集合**：通过 `querySelectorAll` 或 `getElementsByTagName` 获取的节点集合。
  - **函数参数对象**：函数内部的 `arguments` 对象（注意：箭头函数没有 `arguments`）。
- **注意事项**：类数组毕竟不是真正的数组，因此**无法使用** `push`、`pop`、`splice` 等数组原型链上的方法。

## 5. apply 的实际应用：函数复用与传参 *Content-[05:44]

- **求和函数复用**：定义 `add(x, y)` 函数，通过 `add.apply(this, [10, 20])` 调用，改变指向并传入数组参数，计算结果为 30。
- **发工资案例改造**：
  - 保持原有的 `sendSalary` 工具函数和员工对象不变。
  - 将调用方式从 `call` 改为 `apply`。
  - 将原本逐个传递的参数（如基本工资、绩效等）统一放入数组中传递。
  - 最终效果与 `call` 完全一致，仅传参方式不同。

## 6. 实战技巧：使用 apply 求数组最大值与最小值 *Content-[09:15]

- **痛点分析**：`Math.max()` 和 `Math.min()` 要求参数逐个传递（如 `Math.max(10, 20, 30)`），不支持直接传入数组。如果直接传入数组会导致返回 `NaN`。
- **解决方案**：利用 `apply` 支持传入数组的特性来巧妙解决。
- **代码实现**：
  ```javascript
  const arr = [10, 25, 30, 15, 5];
  
  // 求最大值
  // Math.max 本身不依赖特定的 this 指向，因此第一个参数传 null 或 undefined 均可
  const max = Math.max.apply(null, arr); 
  // 或者 Math.max.apply(undefined, arr);
  console.log(max); // 输出: 30
  
  // 求最小值
  const min = Math.min.apply(null, arr);
  console.log(min); // 输出: 5
  ```
- **技巧解析**：
  - `Math.max` 和 `Math.min` 是函数，因此可以调用 `apply` 方法。
  - 第一个参数（`this` 指向）传 `null` 或 `undefined`，因为求最值不涉及修改 `this` 指向，默认指向 `window`（非严格模式）或保持原样即可。
  - 第二个参数直接传入目标数组，完美解决了 `Math.max` 不支持数组传参的问题。
  - 这是实际开发中非常实用且高频的技巧，面试时也常被要求现场手写，务必熟练掌握。
