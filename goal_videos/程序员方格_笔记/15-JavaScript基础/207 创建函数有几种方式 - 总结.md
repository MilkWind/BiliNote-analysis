## 1. 函数声明 *Content-[00:23]
- **格式**：
  ```javascript
  function 函数名(参数) {
      函数体
  }
  ```
- **特点**：
  - 具有**函数提升**（Hoisting）特性，可以在声明之前提前调用。
- **适用场景**：
  - 适合复杂的、需要重复调用的**工具函数**。
  - 在日常开发中非常常用。

## 2. 匿名函数表达式 *Content-[01:18]
- **格式**：
  ```javascript
  const 变量名 = function(参数) {
      函数体
  }
  // 也可以使用 let 声明
  ```
- **特点**：
  - **无函数提升**，不能在声明之前提前调用。
- **适用场景**：
  - 动态赋值。
  - 回调函数（Callback）。
  - 临时使用的函数。

## 3. 具名函数表达式 *Content-[02:16]
- **格式**：
  ```javascript
  const 变量名 = function 函数名(参数) {
      函数体
  }
  ```
- **特点**：
  - **无函数提升**（只要是表达式形式，就不会有提升）。
  - **调试方便**：因为函数内部有名字，在调试时可以快速定位是哪个函数出了问题。
  - **内部可递归**：可以通过函数名在内部进行递归调用。
- **适用场景**：
  - 需要**递归**的场景。
  - 需要方便**调试**的场景。

## 4. Function 构造函数 *Content-[03:28]
- **格式**：
  ```javascript
  new Function('参数一', '参数二', '函数体（执行逻辑）')
  // 注意：所有的参数和函数体都必须使用引号包裹，作为字符串传入
  ```
- **特点**：
  - 参数和函数体均为**字符串**形式。
  - 存在**安全隐患**（类似于 `eval`，容易引发代码注入等问题）。
- **适用场景**：
  - 动态生成函数。
  - 实际开发中**比较少用**。

## 5. 自执行匿名函数 (IIFE) *Content-[04:34]
- **格式**：
  ```javascript
  (function(形参) {
      函数体
  })(实参);
  ```
- **特点**：
  - 定义后**立即执行**。
  - 形成独立的作用域，**避免全局变量**和**全局污染**。
- **适用场景**：
  - **页面初始化**：页面一加载进来就自动执行的逻辑。
  - **避免全局污染**：在早期没有模块化（如 ES6 Modules、CommonJS）时，常用于多人协作开发中规避命名冲突和变量污染问题，相对而言比较常用。

## 6. 自执行具名函数 *Content-[06:00]
- **格式**：
  ```javascript
  (function 函数名(形参) {
      函数体
  })(实参);
  ```
- **特点**：
  - 定义后**立即执行**。
  - **调试方便**：拥有函数名，便于在控制台中追踪。
  - **内部可递归/可调用**：与具名函数表达式类似，可以在函数内部通过名字调用自身。
- **适用场景**：
  - **复杂初始化**场景。
  - 需要**递归**的初始化场景。

## AI 总结
本节课详细总结了前端开发中创建函数的 6 种主要方式及其特点与适用场景：
1. **函数声明**：支持函数提升，最适合定义可复用的工具函数。
2. **匿名函数表达式**：无函数提升，常用于回调函数和动态赋值。
3. **具名函数表达式**：无函数提升，但具备内部递归和调试友好的特性。
4. **Function 构造函数**：通过字符串解析生成函数，存在安全隐患，极少使用。
5. **自执行匿名函数 (IIFE)**：定义即执行，能有效隔离作用域，防止全局污染，常用于页面初始化和早期的模块化模拟。
6. **自执行具名函数**：在 IIFE 的基础上增加了函数名，支持内部递归调用，适用于复杂的递归初始化场景。

掌握这 6 种创建函数的方式及其优缺点，有助于在实际开发中根据具体需求选择最合适的函数定义方法，这也是前端面试中的高频核心考点。
