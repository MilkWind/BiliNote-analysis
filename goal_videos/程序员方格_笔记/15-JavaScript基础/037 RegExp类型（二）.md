## RegExp 对象核心方法：exec *Content-[00:46]
- **基本用法与返回值**：
  - `exec` 的主要任务是在字符串中执行搜索，并提取详细的信息。
  - 接收一个字符串作为参数。
  - 如果没有找到匹配项，返回 `null`。
  - 如果找到了匹配项，返回一个数组。
- **返回数组的特殊属性**：
  - 需要注意，这不是一个普通的数组，它还挂载了额外的属性：
    - `index`：告诉我们匹配发生的位置（索引）。
    - `input`：原始字符串的引用。
  - 数组的第 0 项（`matches[0]`）始终是整个匹配到的字符串内容。
- **对捕获组（Capturing Groups）的强大支持**：
  - `exec` 真正的强大之处在于对捕获组的支持。
  - **捕获组定义**：在正则表达式中使用圆括号 `()` 即可定义捕获组。
  - **示例（日期解析）**：模式中有三组圆括号，分别对应年、月、日。执行 `exec` 之后，返回数组的第 1、2、3 项就依次对应了这三个括号内匹配到的具体内容。
  - **作用**：这使得我们能够非常高效地从复杂的字符串结构中提取出关键数据。

## exec 方法在全局模式下的行为差异 *Content-[02:50]
在使用 `exec` 时，必须理解全局标志 `g`（global）会对该方法的行为产生巨大影响。

- **不带 `g` 标志（无状态模式）**：
  - 在这种模式下，`exec` 是无状态的。
  - 不管调用多少次，它总是从字符串最开始的位置（也就是索引 0）进行搜索。
  - 连续两次调用返回的都是第一个匹配项（例如 `cat`）。
  - `lastIndex` 属性值始终保持为 0，不会更新。
- **带 `g` 标志（有状态模式）**：
  - 情况完全不同，`exec` 变成了有状态的方法。
  - 第一次调用时，它找到了匹配项（如 `cat`），并且 `lastIndex` 更新为 3（即 `cat` 结束的位置）。
  - 第二次调用时，它会直接从索引 3 开始向后搜索，于是跳过了 `cat`，找到了下一个匹配项（如 `bat`），并且再次更新 `lastIndex`。
  - **实战应用**：利用这个特性，我们可以使用 `while` 循环配合 `exec`，来遍历字符串中的所有匹配项。

## RegExp 对象常用方法：test *Content-[04:23]
- **基本功能**：
  - `test` 方法的目标非常单一，它只会回答“是”或“否”。
  - 返回的是简单的布尔类型（`true` 或 `false`）。
- **典型应用场景**：
  - 正因为返回的是简单的布尔类型，`test` 成为了表单验证的首选方法。
  - 典型场景包括：验证邮箱、验证手机号、验证 URL 协议等。
  - 在这些场景下，我们只关心输入是否合法，不需要提取具体的内容。
- **性能优化建议**：
  - 由于 `test` 不需要构建包含 `index`、`input` 和捕获组的复杂对象，所以它的执行开销会比 `exec` 要小。
  - **编码建议**：在代码编写时，如果你的逻辑只需要判断是否存在匹配，一定要优先使用 `test` 方法。

## String 对象支持正则的方法 *Content-[05:42]
除了正则对象自身的方法，JavaScript 的 `String` 对象上也挂载了几个支持正则的方法。在实际开发中，调用这些方法的频率甚至会比 `RegExp` 自身的方法还要高。

- **match 方法**：
  - `match` 的行为完全取决于是否设置了全局标志 `g`。
  - **不带 `g`**：它的返回值和 `exec` 几乎是一样的，包含捕获组和索引信息。
  - **带 `g`**：它会一次性返回所有匹配到的子字符串组成的简单数组，丢弃掉捕获组和索引信息。这是获取所有匹配项最快的方式。
- **search 方法**：
  - 这个方法类似于 `indexOf`，但是它支持正则表达式。
  - 它返回第一个匹配项的索引位置。如果没有找到，就会返回 `-1`；如果找到了，就会返回具体的索引值。
  - 主要用途：用来定位匹配项的位置。
- **replace 方法**：
  - `replace` 方法用来替换文本，在日常开发中使用非常广泛。
  - **注意事项**：如果第一个参数是普通字符串，它只会替换第一个找到的匹配项。
  - **全局替换**：如果我们想替换所有的匹配项，就必须使用带有全局标志 `g` 的正则表达式作为第一个参数。
