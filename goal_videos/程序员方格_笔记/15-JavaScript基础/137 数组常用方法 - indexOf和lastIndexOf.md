## 1. splice() 方法详解 *Content-[00:00]

`splice()` 方法用于修改数组，可以实现删除、替换和添加元素的功能。

### 核心特性
- **作用**：删除指定位置的元素，同时替换为新元素，实现修改的效果。支持批量删除和批量添加。
- **是否修改原数组**：**会修改**原数组。
- **返回值**：由被删除元素组成的新数组。如果没有删除任何元素，则返回空数组。

### 参数说明
语法：`arr.splice(start, deleteCount, newItem1, newItem2, ...)`
- `start`：起始位置（下标）。
- `deleteCount`：要删除的元素个数。修改/删除 1 个则为 1，修改/删除 N 个则为 N。
- `newItemN`：要添加/替换的新元素，可以传入多个。

### 示例演示
**示例 1：基础修改（删除 1 个，添加 1 个）**
- 原数组：`[1, 2, 3, 4, 5]`
- 操作：`arr.splice(2, 1, true)`
- 解析：从下标 2（即元素 3）开始，删除 1 个元素，并在该位置添加 `true`。
- 结果：原数组变为 `[1, 2, true, 4, 5]`。返回值为被删除元素组成的数组 `[3]`。

**示例 2：批量修改（删除多个，添加多个）**
- 原数组：`[1, 2, 3, 4, 5]`
- 操作：`arr.splice(1, 2, '你好', '卷耳')`
- 解析：从下标 1（即元素 2）开始，删除 2 个元素（2 和 3），并在该位置依次添加 `'你好'` 和 `'卷耳'`。
- 结果：原数组变为 `[1, '你好', '卷耳', 4, 5]`。返回值为被删除元素组成的数组 `[2, 3]`。

## 2. indexOf() 方法详解 *Content-[03:19]

`indexOf()` 方法用于在数组中查找指定元素，返回其索引位置。

### 核心特性
- **作用**：返回在数组中可以找到的给定元素的**第一个索引**。只能查找第一个匹配值，不会查找所有匹配项。
- **是否修改原数组**：**不改变**原数组。
- **返回值**：首个被找到的元素在数组中的索引位置。若没找到，则返回 `-1`。

### 参数说明
语法：`arr.indexOf(item, fromIndex)`
- `item`：要查找的元素。
- `fromIndex`：开始查找的位置（下标）。默认值为 `0`。

### fromIndex 的特殊规则
1. **大于或等于数组长度**：意味着不会在该数组里查找，直接返回 `-1`。
2. **负值**：将其作为数组末尾的一个抵消（例如 `-1` 表示从最后一个元素开始，`-2` 表示倒数第二个）。
   - **注意**：提供负值**并不改变其查找顺序**，查找顺序依旧是从前向后。
   - 如果抵消后的索引值小于等于 `0`，则整个数组都将会被查询。

### 示例演示
以数组 `[1, 2, 3, 4, 5]` 为例：
- **基础查找**：`arr.indexOf(3)`，找到 3，返回下标 `2`。原数组不变。
- **未找到**：`arr.indexOf(6)`，找不到 6，返回 `-1`。原数组不变。
- **fromIndex 大于等于长度**：`arr.indexOf(3, 6)`，数组最大索引为 4，没有下标 6，直接返回 `-1`。
- **fromIndex 为负值（正常抵消）**：`arr.indexOf(3, -3)`，从下标 2 开始找，找到 3，返回 `2`。（强调：即使传了负数，依然是**从前往后**查找）。
- **fromIndex 为负值（抵消后小于 0）**：`arr.indexOf(3, -6)`，抵消后仍为负数，整个数组被查询，返回 `2`。

### 实战场景
判断数组中是否包含了某个值：
```javascript
if (arr.indexOf(item) !== -1) {
    // 包含该值
}
```

## 3. lastIndexOf() 方法详解 *Content-[08:48]

`lastIndexOf()` 是 `indexOf()` 的兄弟方法，用于逆向查找元素。

### 核心特性
- **作用**：返回指定元素在数组中**最后一个**的索引。不是第一个找到的，而是最后一个。
- **查找顺序**：从数组**后面向前**（逆向，从右到左）查找。
- **是否修改原数组**：**不改变**原数组。
- **返回值**：值最后一次出现的索引。如未找到，返回 `-1`。

### 参数说明
语法：`arr.lastIndexOf(item, fromIndex)`
- `item`：要查找的元素。
- `fromIndex`：从此位置开始逆向查找。默认为数组的长度减一（即整个数组都被查找）。

### fromIndex 的特殊规则
1. **大于或等于数组的长度**：则整个数组会被查找。
2. **负值**：将其视为从数组的末尾向前的偏移。即使该值为负，数组仍然会被**从后向前**查找。
3. **负值且绝对值大于数组长度**：则方法返回 `-1`，即数组不会被查找。

### 示例演示
以数组 `[1, 2, 3, 4, 5]`（长度为 5）为例：
- **基础查找**：
  - `arr.lastIndexOf(3)` 返回 `2`。
  - `arr.lastIndexOf(4)` 返回 `3`。
  - `arr.lastIndexOf(2)` 返回 `1`。
- **未找到**：`arr.lastIndexOf(20)` 返回 `-1`。
- **fromIndex 大于等于长度**：`arr.lastIndexOf(3, 6)` 或 `arr.lastIndexOf(3, 5)`，大于等于长度 5，整个数组被查找，正常返回 `2`。
- **fromIndex 为负值**：
  - `arr.lastIndexOf(3, -2)`：从末尾向前偏移 2，仍从后往前查找，能找到 3。
  - `arr.lastIndexOf(3, -3)`：可以找到 3。
  - `arr.lastIndexOf(3, -4)`：找不到 3（因为偏移后起始位置在元素 3 之前，从后往前查找的区域不包含 3）。
- **fromIndex 负值绝对值大于长度**：`arr.lastIndexOf(3, -30)`，绝对值 30 大于数组长度 5，直接返回 `-1`，数组不会被查找。

## AI 总结

本视频详细讲解了前端面试中高频考察的数组修改与查找方法：
1. **splice()**：用于数组的增删改。它会**改变原数组**，返回被删除元素组成的新数组。面试中需重点关注其参数含义及批量操作的返回值。
2. **indexOf()**：用于**从前向后**查找元素的第一个索引。它**不改变原数组**，找不到返回 `-1`。核心考点在于 `fromIndex` 参数为负数时的抵消规则，以及负数**不改变从前往后**的查找顺序。
3. **lastIndexOf()**：用于**从后向前**查找元素的最后一个索引。它**不改变原数组**，找不到返回 `-1`。核心考点在于其查找方向是逆向的，以及 `fromIndex` 为负数且绝对值大于数组长度时直接返回 `-1` 的边界情况。

掌握这些方法的返回值、是否改变原数组以及参数边界条件，是应对前端大厂面试“八股文”的关键。
