## 1. 使用 Symbol 作为对象属性键 *Content-[00:01]
- **定义基础对象**：
  创建一个名为 `user` 的对象，包含常规字符串键值对：`name: '金小子'` 和 `age: 20`。
- **创建 Symbol 变量**：
  - `let idSymbol = Symbol('user id');` // 描述为用户 id
  - `let secretSymbol = Symbol('secret_key');` // 描述为密钥
- **添加 Symbol 属性**：
  - **核心关键点**：给对象添加以 Symbol 作为 key 的属性时，**必须使用中括号 `[]`**。
  - `user[idSymbol] = 'id_123456';`
  - `user[secretSymbol] = 'secret_value_abc';`
- **打印对象结果**：
  - 展开对象后可以看到共有 4 个属性：2 个字符串键（`name`, `age`）和 2 个 Symbol 键。
  - 此时明确了 Symbol 作为 key 值具有唯一性，后续会详细讲解其使用场景。

## 2. Symbol 的唯一性验证 *Content-[02:25]
- **创建描述相同的 Symbol**：
  - 为了避免变量名冲突（如使用 `let` 导致重名报错），使用新的变量名 `id2`。
  - `let id2 = Symbol('user id');` // 描述与 `idSymbol` 完全相同。
- **尝试访问属性**：
  - 使用 `console.log(user[id2]);` 尝试获取值。
- **结果与分析**：
  - 打印结果为 `undefined`。
  - **原因剖析**：`Symbol` 诞生的主要作用就是解决对象中 key 值的**唯一性**。即使两个 Symbol 的描述（description）长得一模一样，它们在内存中也是**不相等**的。
  - `id2` 和 `idSymbol` 根本不是同一个东西，因此无法通过 `id2` 访问到 `idSymbol` 对应的值。这完美体现了 Symbol 的唯一性保护机制。

## 3. 访问 Symbol 属性的正确与错误方式 *Content-[05:50]
- **错误方式一：使用点运算符 `.` 添加/访问**
  - 代码示例：`obj.mySymbol = 'hello';`
  - 结果：后续使用 `obj[mySymbol]` 访问时返回 `undefined`。
  - **原因**：点运算符 `.` 后面总是跟**字符串**。因此 `obj.mySymbol` 实际上创建了一个键名为字符串 `'mySymbol'` 的属性，而不是 Symbol 类型的键。
- **错误方式二：中括号内直接写字符串**
  - 代码示例：`user['idSymbol']`
  - 结果：返回 `undefined`。
  - **原因**：属性键是 Symbol 变量本身的值，而不是字符串 `'idSymbol'`。两者读取的根本不是同一个东西。
- **正确方式：使用中括号 `[]` 配合 Symbol 变量**
  - 访问常规字符串属性：`user.age` 或 `user['age']`（均可）。
  - 访问 Symbol 属性：**必须**使用 `user[idSymbol]` 和 `user[secretSymbol]`，通过变量本身去映射对应的值。

## 4. 对象内部定义 Symbol 属性及总结 *Content-[11:50]
- **在对象字面量内部定义 Symbol 属性/方法**：
  - 定义 Symbol：`let s = Symbol('method');`
  - 定义对象：
    ```javascript
    let obj = {
      [s]: function(arg) {
        console.log(arg);
      }
    }
    ```
  - **核心关键点**：在对象内部使用 Symbol 值定义属性时，Symbol 变量**必须放在方括号 `[]` 中**。如果不加方括号（如直接写 `s: function...`），该属性的键名就会变成字符串 `'s'`，而不是 `s` 所代表的 Symbol 值。
- **课堂互动总结**：
  - **问题**：Symbol 作为对象属性时能否用点语法？
  - **答案**：绝对不能。
  - **核心原因**：点语法会将变量解析为字符串，而对象里存储的是 Symbol 值，使用点语法会导致类型不匹配，无法正确读取或添加 Symbol 属性。

本视频详细讲解了 JavaScript 中 `Symbol` 作为对象属性键（key）时的核心特性——**唯一性**及**正确的语法使用规范**。
1. **唯一性保护**：即使描述（description）完全相同，每次调用 `Symbol()` 都会生成一个独一无二的值。这有效防止了对象属性键的冲突，是解决第三方库属性覆盖等问题的利器。
2. **语法规范**：无论是动态添加、访问还是在对象字面量内部定义 Symbol 属性，都**必须使用中括号 `[]`** 包裹 Symbol 变量。
3. **避坑指南**：严禁使用点运算符 `.` 或在中括号内直接写字符串来操作 Symbol 属性。因为点语法和字符串字面量会被解析为普通字符串键，从而导致操作失效（返回 `undefined`）。掌握这些底层逻辑和语法细节，是应对前端面试中 Symbol 相关考点的关键。
