## Symbol 简介 *Content-[00:00]
- **基本概念**：`Symbol` 在实际前端开发中使用相对较少。
- **主要作用**：主要用于解决“魔术字符串”问题，通常作为一个唯一的变量值来使用。

## Set 集合简介与特点 *Content-[00:21]
- **背景**：在 ES6 之前，数据集结构除了对象外只有数组。数组按元素顺序排列，无法满足所有数据需求，因此 ES6 推出了 `Set` 和 `Map` 两种新结构。
- **概念**：`Set` 可以理解为一种高级数组，也称为“集合”。
- **核心特点**：
  - **元素不允许重复**：集合中的每个元素都是唯一的。
  - **无索引值功能**：不能像数组那样通过索引（如 `s[3]`）来访问元素。
  - **元素无序**：与数组按放入顺序排序不同，`Set` 中的元素是没有顺序的。

## Set 集合的初始化方式 *Content-[01:41]
`Set` 本身是一个构造函数，用于生成 `Set` 数据结构。主要有两种初始化方式：
- **方式一：通过构造函数传入数组（推荐）**
  - 直接将数组传入 `new Set()`，会自动将数组的所有元素放入集合中。
  - 示例：`let s = new Set([1, 2, 3, 4, 5]);`
- **方式二：通过 `add` 方法逐个添加**
  - 先创建空集合，再使用 `add` 方法添加元素。
  - **ES5 写法**：使用 `forEach` 遍历数组，在回调函数中调用 `s.add(item)`。
  - **ES6 简化写法**：结合箭头函数，代码更加简洁。例如：`arr.forEach(item => s.add(item));`，如果只有一句代码，还可以进一步简写变量名。

## Set 集合的常用方法 *Content-[05:25]
`Set` 集合的实例方法非常简单实用，主要包括增、删、查、判等操作：
- **增加元素 (`add`)**：
  - 使用 `s.add(87)` 添加元素。可以添加字符串等，但建议保持集合内元素类型一致。
- **查看长度 (`size`)**：
  - 使用 `s.size` 属性获取集合中元素的数量（注意不是 `length`）。
- **删除元素 (`delete`)**：
  - 由于没有索引，只能**根据元素内容**进行删除，例如 `s.delete(5)`。
  - 该方法返回一个布尔值，表示删除是否成功。
  - **注意**：`Set` 没有直接修改元素的方法，如果需要修改，需先删除旧元素，再增加新元素。
- **清空集合 (`clear`)**：
  - 使用 `s.clear()` 清空所有元素，清空后 `s.size` 变为 0。
- **判断元素 (`has`)**：
  - 使用 `s.has(9)` 判断集合中是否拥有指定的元素，返回布尔值。

## Set 的核心特性：自动去重 *Content-[10:29]
- **自动去重机制**：`Set` 最奇特的地方在于其不允许重复的特性。当把包含重复元素的数组放入 `Set` 时，它会自动查重并去除重复项。
- **数组去重实战**：
  - 利用 `Set` 的自动去重特性，可以非常轻松地完成数组去重。
  - 结合扩展运算符 `...`，代码实现为：`[...new Set(arr)]`。
  - 原理：先通过 `new Set(arr)` 构建一个去重后的 `Set` 集合，再利用扩展运算符将其展开并重新放入数组中。

## ES2025 Set 新特性预告 *Content-[12:41]
- **集合运算方法**：ES2025 为 `Set` 结构添加了以下集合运算方法（属于较新特性，建议提前了解）：
  - 并集 (Union)
  - 差集 (Difference)
  - 对称集 (Symmetric Difference)
  - 判断是否为子集 (Is Subset Of)
  - 判断是否有超集 (Is Superset Of)

## WeakSet 简介与应用场景 *Content-[13:15]
`WeakSet` 与 `Set` 类似，也具有元素不重复的特点，但存在两个关键区别：
- **成员类型限制**：
  - `WeakSet` 的成员**只能是对象和 `Symbol` 值**，不能是字符串、数值等其他基本类型值。而普通的 `Set` 可以存放所有类型的元素。
- **弱引用机制**：
  - `WeakSet` 中的对象都是**弱引用**。
  - 垃圾回收器（GC）在回收内存时，**不会考虑** `WeakSet` 对该对象的引用。
  - **内存管理优势**：如果使用普通数组或 `Set` 存放缓存对象，只要集合不被回收，对象就会一直占用内存。而使用 `WeakSet`，如果其他地方不再引用该对象，垃圾回收器会自动回收其占用的内存，有效防止内存泄漏。
- **适用场景**：非常适合用来存储一组对象的缓存数据，避免长时间占用内存。
