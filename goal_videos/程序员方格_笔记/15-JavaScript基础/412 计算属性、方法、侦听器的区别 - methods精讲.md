## methods 核心概念与特性 *Content-[00:00]

- **定义位置**：方法定义在 Vue 实例的 `methods` 选项中。
- **调用方式**：需要**主动调用**，例如在点击按钮或页面渲染时触发。
- **执行机制**：每次调用都会**重新执行**函数体。
- **场景类比（奶茶店学徒）**：
  - 顾客点单后，学徒每一次都要重新计算订单总价。
  - 即使是**相同的订单**（例如：两杯珍珠奶茶 + 一杯果茶），也要重新计算一遍总价。
  - 相当于每次点单都重新做奶茶、重新算总价，**不管数据变没变，都要重新执行计算动作**。

## 代码案例：计算奶茶订单总价 *Content-[02:29]

- **需求**：计算奶茶订单总价，重点观察 `methods` 的**调用次数**。
- **页面结构 (Template)**：
  - 3 个 `<p>` 标签：用于展示订单总价，每个标签内调用 `getOrderTotal()` 方法（共调用 3 次）。
  - 1 个 `<button>` 按钮：绑定 `refresh` 方法，用于刷新页面。
- **数据定义 (Data)**：
  - `pearlMilkTeaPrice`：珍珠奶茶单价，15 元。
  - `fruitTeaPrice`：果茶单价，12 元。
  - `pearlMilkTeaNum`：珍珠奶茶数量，2 杯。
  - `fruitTeaNum`：果茶数量，1 杯。
- **方法定义 (Methods)**：
  - `getOrderTotal()`：计算订单总价。
    - 逻辑公式：$总价 = 珍珠奶茶单价 \times 珍珠奶茶数量 + 果茶单价 \times 果茶数量$ （即 $15 \times 2 + 12 \times 1$）。
    - 代码实现：`return this.pearlMilkTeaPrice * this.pearlMilkTeaNum + this.fruitTeaPrice * this.fruitTeaNum`。
    - 调试辅助：在函数内加入 `console.log('方法被调用了一次')` 以便观察执行次数。
  - `refresh()`：刷新页面方法。
    - 逻辑：调用 `this.$forceUpdate()`，强制让页面重新渲染（相当于刷新页面，但不改变订单数据）。

## 案例测试与结果分析 *Content-[08:01]

- **测试步骤与现象**：
  1. **页面初次渲染**：
     - 打开浏览器开发者工具（按 `F12`）查看控制台。
     - 因为模板中调用了 3 次 `getOrderTotal()`，控制台会**打印 3 次**“方法被调用了一次”。
  2. **点击“刷新页面”按钮**：
     - 此时**不改变任何订单信息**（底层数据未变）。
     - 触发 `$forceUpdate()` 强制重新渲染。
     - 控制台**再次打印 3 次**“方法被调用了一次”。
- **特性分析**：
  - `methods` 中的方法**没有缓存**机制。
  - 不管底层数据有没有发生变化，只要方法被调用，就会**重新执行**。
  - 就像“又笨又实在”的学徒，每次被问到订单总价，哪怕订单毫无变化，也要从头重新算一遍。

## 核心结论总结 *Content-[11:40]

- **核心结论**：`methods` 中的函数**调用一次，执行一次**，**没有任何缓存**。
- **面试考点**：即使计算结果没有变化，也会重新计算。这一特性在面试中常用于与 `computed`（计算属性）的缓存特性进行对比考察。

## AI 总结

本视频详细讲解了 Vue 中 `methods` 的核心特性：**无缓存、每次调用均重新执行**。通过“奶茶店学徒”的生动类比和具体的代码案例，验证了 `methods` 在页面初次渲染和强制重新渲染（`$forceUpdate`）时，即使依赖数据未发生改变，也会重复执行函数体的特点。掌握这一特性对于理解 Vue 的响应式机制以及在面试中区分 `methods` 与 `computed` 至关重要。
