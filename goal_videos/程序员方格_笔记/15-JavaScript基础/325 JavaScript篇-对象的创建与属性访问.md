## 1. 什么是 Object *Content-[00:22]
在 JavaScript (ES) 中，`Object` 是引用类型的基石，几乎我们处理的所有复杂数据结构本质上都是对象。

### 核心特点
- **无序的键值对集合**：这意味着不能依赖属性添加的顺序来作为访问顺序。
- **属性名类型严格限制**：对象的属性名严格来说只有两种类型：`String` 和 `Symbol`。如果使用其他类型作为 key，它们都会被自动转换。
- **属性值无限制**：属性值可以是基本类型，也可以是另外一个对象或者函数。

### 为什么理解 Object 如此重要？
在 JavaScript 中，`Array`、`Function`、`Date`、`RegExp`（正则表达式）等在底层都是基于 `Object` 来实现的。理解了 `Object` 的行为，也就掌握了这些衍生类型的共性。例如，函数之所以能拥有属性，就是因为它本质上也是一种对象。

## 2. 对象的创建方式 *Content-[01:41]
创建对象主要有以下两种方式：

- **`new Object()` 构造函数**：
  - 过程：首先实例化一个空对象，然后逐个添加属性。
  - 缺点：写法比较繁琐。
- **对象字面量 `{}`（强烈推荐）**：
  - 过程：使用一对花括号直接定义属性和值。
  - 优点：代码量更少，结构更加清晰，能够让人一眼看出对象包含的数据结构。
  - **最佳实践**：在实际开发中，强烈建议使用对象字面量方式。除非在特定的动态构建场景下，否则应尽量避免显式调用 `new Object()`。

## 3. 属性名的类型与细节 *Content-[02:41]
通过代码示例，我们可以更具体地理解属性名的类型规则：

- **普通字符串**：如 `name`，通常不需要加任何引号，系统会自动识别其为字符串。
- **包含特殊字符或空格**：如 `foo-bar`（包含连字符）或包含空格的属性名，此时必须显式加上引号（如 `"foo-bar"`）。
- **数字类型**：如 `123`，虽然代码中写的是数字，但对象内部会自动将其转换成字符串 `"123"`。
- **Symbol 类型**：
  - 通过引入 ES6 中的 `Symbol`，可以创建一个唯一的属性名。
  - 这个属性名不会与其他的任何属性发生冲突。
  - **应用场景**：在构建一些库或者框架时，用来定义私有的属性或者特殊行为非常有用。

## 4. 属性的访问方式 *Content-[04:03]
创建对象后，最重要的操作就是访问属性。主要有两种访问方式：

### 点表示法（`.`）
- **示例**：`user.name`
- **特点**：最常用、最简洁，可读性更强，符合大多数面向对象语言的习惯。
- **建议**：只要属性名符合规范，优先建议使用这种方式。

### 括号表示法（`[]`）
- **示例**：`user["name"]`
- **特点**：括号里面必须是一个字符串（或变量）。看起来稍微麻烦一点，但提供了极大的灵活性。

### 必须使用括号表示法的三种典型场景
1. **属性名包含空格或者特殊字符**：
   - 例如属性名为 `first name`（中间有空格）。如果使用点表示法，解释器读到空格时会报错，此时必须使用方括号 `user["first name"]`。
2. **属性名是关键字或者保留字**：
   - 例如属性名为 `class`。虽然现在的 JavaScript 引擎在很多情况下允许 `object.class`，但为了避免潜在的语法歧义及兼容性问题，使用 `object["class"]` 是更安全的做法。
3. **通过变量动态访问属性（极易出错场景）**：
   - 假设变量 `key = "name"`，若想取到对应的值，必须写 `user[key]`（括号内不加引号，因为 `key` 是变量）。
   - 如果误写成点表示法 `user.key`，JavaScript 引擎会去寻找对象中是否有一个属性名叫 `"key"` 的属性，而不是读取变量 `key` 的值，这会导致返回 `undefined`。

## 5. 动态属性访问实战 *Content-[06:43]
为了加深对动态访问的理解，我们来看一个实际的代码场景：

假设有一个 `student` 对象，包含常规属性和一个带空格的属性 `"favorite color"`。同时有一个数组 `props` 存储了需要读取的属性名列表（在实际开发中，这可能来自于用户的输入或者后端返回的配置字段）。

```javascript
const student = {
  name: "张三",
  age: 20,
  "favorite color": "blue"
};

const props = ["name", "age", "favorite color"];

props.forEach(prop => {
  // 必须使用括号表示法，才能在循环中动态把变量 prop 解析成属性名
  console.log(student[prop]); 
});
```

- **核心解析**：正是因为使用了括号表示法 `student[prop]`，我们才能在循环中动态地将 `name`、`age` 等字符串变量解析为对应的属性值。如果使用点表示法，这段代码将完全无法执行。这就是括号表示法最强大的功能：**在运行时进行动态访问**。

## 6. 课程总结 *Content-[07:53]
- **关于对象的创建**：虽然 `new Object()` 是合法的，但在现代开发中，**对象字面量**是标准且推荐的做法，因为它更加高效、易读。
- **关于属性的访问**：常规情况下首选**点表示法**，但必须熟练掌握**括号表示法**的特定应用场景（特殊字符、保留字、动态变量访问）。
