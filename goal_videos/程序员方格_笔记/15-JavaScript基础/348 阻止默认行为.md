## 什么是默认行为 *Content-[00:00]
- **核心定义**：默认行为是指 HTML 元素自身自带的、无需开发者通过 JavaScript 代码额外添加就会自动执行的交互动作。

## 默认行为的常见示例 *Content-[00:17]
- **具有默认行为的元素**：
  - `<a>` 标签：点击时默认会跳转到其 `href` 属性指定的超链接地址。
  - `<form>` 表单：点击提交按钮时，默认会提交表单数据并刷新当前页面。
- **不具有默认行为的元素**：
  - `<div>` 标签、`<p>` 标签等普通容器或文本标签，它们本身没有自带的交互动作，需要开发者手动绑定事件。

## 代码演示：A标签的默认行为 *Content-[00:51]
- **场景描述**：在纯 HTML 网页中编写一个 `<a>` 标签，设置超链接指向百度，文本内容为“去百度”。
- **预期行为**：点击“去百度”时，页面会跳转并打开百度的网页，这就是 `<a>` 标签的默认行为。
- **需求变更**：在实际开发中，有时我们希望点击 `<a>` 标签时，不执行页面跳转，而是仅仅执行绑定的 JavaScript 事件（例如在控制台打印日志）。
- **代码实现与问题**：
  - 首先获取 `<a>` 标签的 DOM 元素。
  - 为其添加点击事件监听器，在回调函数中执行 `console.log('触发了A标签的log');`。
  - **遇到问题**：点击后，控制台虽然成功打印了日志，但页面**同时发生了跳转**。这是因为点击事件触发后，浏览器依然执行了 `<a>` 标签的默认跳转行为。

## 如何阻止默认行为 *Content-[03:01]
- **解决方案**：通过事件对象（Event Object）上的 `preventDefault()` 方法来阻止元素的默认行为。
- **语法格式**：`event.preventDefault()` 或简写为 `e.preventDefault()`。
- **代码修正步骤**：
  - 在点击事件的回调函数中，接收事件对象参数（如 `e` 或 `event`）。
  - 在回调函数内部的第一行（或执行其他逻辑前）调用 `e.preventDefault();`。
- **效果验证**：保存代码并刷新页面后，再次点击 `<a>` 标签，控制台正常打印日志，且页面**不再跳转**，成功阻止了默认行为。

## 实际开发中的痛点：表单提交刷新 *Content-[04:13]
- **常见踩坑经历**：在前端开发中，新手经常会遇到“提交完表单后页面直接刷新，导致数据丢失或状态重置”的问题。
- **原因分析**：点击表单的 `submit` 按钮触发了 `<form>` 的默认提交行为，导致浏览器发起传统的表单提交请求并刷新页面，阻断了通过 Ajax 或 Fetch 进行的异步无刷新提交。
- **解决思路**：与 `<a>` 标签类似，需要在表单的 `submit` 事件回调中，调用 `e.preventDefault()` 来阻止表单的默认刷新行为，从而实现现代 Web 开发中常见的无刷新数据提交。

本节视频详细讲解了前端开发中“阻止默认行为”的核心概念与实现方法。默认行为是 HTML 元素自带的交互动作（如 `<a>` 标签跳转、`<form>` 表单提交刷新）。当开发者需要自定义这些元素的交互逻辑（如实现无刷新提交或单页应用路由跳转）时，必须通过事件对象的 `e.preventDefault()` 方法来阻止其默认行为。掌握这一 API 是处理表单提交、自定义链接跳转等高频前端场景的基础，也是前端面试中极易考察的八股文知识点。
