## 计算字符串字节数的基础知识 *Content-[00:07]
在计算字符串字节数之前，需要了解字符编码与字节占用的基本常识：
- **英文与英文符号**：在 ASCII 码表中，编码值在 $0 \sim 255$ 之间的字符均为英文字母和英文符号，每个字符占用 **1个字节**。
- **中文与中文符号**：Unicode 编码值大于 $255$ 的字符表示非英文字符（如中文及中文符号），每个字符占用 **2个字节**。

## 封装计算字节数的方法 *Content-[01:03]
为了计算字符串的字节数，可以封装一个名为 `getByteNumber` 的方法，接收一个字符串参数 `str`。
- **非空判断**：在计算前需要进行防御性编程，判断字符串是否为空或长度是否小于 1。
  ```javascript
  if (!str || str.length < 1) return;
  ```
- **初始化变量**：定义一个变量 `len` 用于记录总字节数，初始值为 `0`。
  ```javascript
  let len = 0;
  ```

## 核心逻辑与 charCodeAt 方法 *Content-[02:22]
计算字节数的核心在于遍历字符串并判断每个字符的 Unicode 编码值。
- **遍历字符串**：使用 `for` 循环遍历字符串的每一个字符。
  ```javascript
  for (let i = 0; i < str.length; i++) { ... }
  ```
- **获取字符的 Unicode 编码**：使用字符串的 `charCodeAt(index)` 方法。
  - **方法说明**：`charCodeAt()` 返回字符串中指定索引处字符的 Unicode 编码值，该值介于 $0 \sim 65535$ 之间。索引从 $0$ 开始。
  - **易混淆点区分**：注意与 `String.fromCharCode()` 区分，后者是通过 Unicode 编码值查找对应的字符，而 `charCodeAt()` 是返回字符对应的 Unicode 数值。
- **字节数累加逻辑**：
  - 判断当前字符的 Unicode 编码值：`str.charCodeAt(i)`。
  - 如果编码值 **大于 255**，说明是中文或中文符号，字节数加 2：`len += 2`。
  - 如果编码值 **小于等于 255**，说明是英文或英文符号，字节数加 1：`len += 1`。
- **返回结果**：循环结束后，返回计算得到的总字节数。
  ```javascript
  return len;
  ```
