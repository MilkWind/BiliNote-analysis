## 1. DOM0和DOM2事件模型的区别 *Content-[00:02]
- **绑定方式**：
  - **DOM0**：包含行内绑定和动态绑定（如 `onclick`）。动态绑定的缺点是后绑定的事件会覆盖前面绑定的同类型事件。
  - **DOM2**：使用 `addEventListener`（现代浏览器）或 `attachEvent`（IE <= 8）。优势在于内容与行为分离，且支持绑定多个同类型的事件处理函数；缺点是存在一定的兼容性问题（可通过封装方法解决）。
- **事件移除**：
  - **DOM0**：将事件属性赋值为 `null`（如 `element.onclick = null`）。
  - **DOM2**：使用 `removeEventListener` 或 `detachEvent` 进行移除。
- **兼容性**：
  - **DOM0**：所有浏览器均支持。
  - **DOM2**：`addEventListener` 兼容现代浏览器（IE >= 9）；`attachEvent` 兼容 IE <= 8。
- **事件传播**：
  - **DOM0**：不支持捕获，仅支持冒泡。
  - **DOM2**：`addEventListener` 既支持捕获也支持冒泡（通过第三个参数控制）；`attachEvent` 仅支持冒泡，且没有第三个参数。

## 2. addEventListener 与 attachEvent 的区别 *Content-[03:40]
- **事件名**：
  - `addEventListener`：不需要加 `on` 前缀（如 `click`）。
  - `attachEvent`：需要加 `on` 前缀（如 `onclick`）。
- **this 指向**：
  - `addEventListener`：指向触发事件的元素。
  - `attachEvent`：指向 `window`。
- **执行顺序**：
  - `addEventListener`：先绑定的先执行。
  - `attachEvent`：后绑定的先执行。
- **参数个数**：
  - `addEventListener`：包含 3 个参数。
  - `attachEvent`：包含 2 个参数。
- **兼容性**：
  - `addEventListener`：兼容 IE >= 9 以及现代浏览器。
  - `attachEvent`：仅兼容 IE <= 8。
- **相同点**：
  - 针对同一个元素，两者都可以绑定同类型的多个事件处理程序。
- **移除方式**：
  - `addEventListener` 绑定的事件需要用 `removeEventListener` 移除。
  - `attachEvent` 绑定的事件需要用 `detachEvent` 移除。
  - 移除时参数必须一一对应。

## 3. 绑定多个同类型事件的方法 *Content-[04:42]
- 使用原生 JS 给一个按钮绑定两个或多个事件：
  - 在标准浏览器下，使用 `addEventListener`。
  - 在 IE8 及以下浏览器中，使用 `attachEvent`。
  - **注意**：DOM0 级事件模型（如直接赋值 `onclick`）无法做到绑定多个同类型事件，因为会发生覆盖。

## 4. 事件三要素 *Content-[04:56]
- **事件源**：谁触发了事件（即具体的 DOM 元素）。
- **事件类型**：触发了什么事件（如 `click`、`focus`）。
- **事件处理程序**：触发事件后要执行的操作结果（即回调函数）。
- *注*：事件流（捕获或冒泡）不属于事件三要素。

## 5. 移除 DOM0 方式绑定的事件 *Content-[05:23]
- 直接将元素的事件类型属性置为 `null` 即可移除（例如 `btn.onclick = null`）。

## 6. DOM0 级事件模型的事件传播机制 *Content-[05:33]
- 事件触发后，仅执行绑定在当前元素的事件处理程序。
- **仅支持冒泡**，不支持捕获。

## 7. DOM0 方式绑定事件的 this 指向 *Content-[05:49]
- 事件处理函数内部的 `this` 指向**绑定事件的元素**。
- 遵循基础规则：“谁调用就指向谁”。例如在 `btn.onclick = fn` 中，`btn` 调用了 `fn`，因此 `this` 指向 `btn`。

## 8. addEventListener 方法的三个参数 *Content-[06:14]
1. **第一个参数（事件名）**：要绑定的事件类型，如 `click`、`focus`。
2. **第二个参数（事件处理程序）**：触发事件时要执行的回调函数。
3. **第三个参数（布尔值）**：控制事件流执行顺序。
   - `false`（默认值）：在冒泡阶段执行。此参数可省略，省略即代表冒泡。
   - `true`：在捕获阶段执行。
   - *注*：`attachEvent` 没有第三个参数。

## 9. DOM2 事件模型的事件传播控制 *Content-[06:49]
- DOM2 事件模型同时支持**冒泡**和**捕获**。
- 通过 `addEventListener` 的第三个参数来控制：
  - 传入 `true`：代表捕获。
  - 传入 `false`：代表冒泡。

## 10. DOM2 与 DOM0 事件处理函数的 this 指向 *Content-[07:03]
- **DOM2 (`addEventListener`)**：`this` 指向绑定的元素。
- **DOM0**：`this` 同样指向绑定的元素。两者**一致**。
- *讲师纠正口误*：`attachEvent` 事件处理函数内部的 `this` 才指向 `window`。DOM0 和 DOM2 (`addEventListener`) 的 `this` 都是指向绑定事件的元素。

## 11. 移除 addEventListener 绑定的事件及注意事项 *Content-[08:05]
- **移除方式**：使用 `removeEventListener` 移除，需要通过**函数引用**找到要移除的事件处理函数。
- **注意事项**：
  1. 匿名函数没有变量引用，无法被匹配到，因此**无法移除匿名函数**。
  2. 移除时的参数需与绑定时**完全一致**。
  3. 仅能移除用 `addEventListener` 绑定的事件。用 DOM0 级事件或 `attachEvent` 绑定的事件不能使用此方法移除。

## 12. DOM2 事件模型相比 DOM0 的优势 *Content-[08:46]
- 支持给同一个元素绑定多个同类型的事件，无覆盖问题。
- 支持事件传播（捕获和冒泡）的灵活控制。
- 可灵活移除指定事件（DOM0 仅能整体置空移除）。
