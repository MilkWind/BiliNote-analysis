## Array.from 方法概述与语法 *Content-[00:00]

`Array.from` 是数组转换的第五个常用方法，其核心作用是对一个类似数组（array-like）或可迭代对象（iterable object）创建一个新的浅拷贝的数组实例。简单来说，它就是用来将“伪数组”转换为“真数组”的。

**语法结构：**
`Array.from(arrayLike, mapFn, thisArg)`

- **`arrayLike`**：第一个参数，需要转换为数组的对象，也就是所谓的“伪数组”或可迭代对象。
- **`mapFn`**：第二个参数（可选），是一个回调函数，相当于对数组的每个元素调用 `map` 函数进行处理。
- **`thisArg`**：第三个参数（可选），执行回调函数时用作 `this` 的值。
- **返回值**：返回一个真正的新数组。

## Array.from 转换的两类对象 *Content-[00:57]

`Array.from` 方法主要用于将以下两类对象转换为真正的数组：

1\. **类似数组的对象（伪数组）**
这类对象具有数组的某些特征（如 `length` 属性），但没有数组的内置方法。常见的伪数组包括：
- 函数的参数对象 `arguments`。
- 通过 `querySelectorAll` 获取到的 DOM 元素节点集合（`NodeList`）。
- 通过 `getElementsByTagName` 获取到的 HTML 节点集合（`HTMLCollection`）。

2\. **可遍历（可迭代）的对象**
这类对象部署了 `iterator` 接口，可以被循环遍历。常见的可迭代对象包括：
- ES6 新增的数据结构 `Set` 和 `Map`。
- 字符串（`String`）。

## 实战示例：DOM 元素集合转换 *Content-[01:47]

在实际开发中，DOM 操作返回的集合通常是伪数组。

**伪数组的特性与报错：**
- 使用 `document.getElementsByTagName` 或 `document.querySelectorAll` 获取元素集合（例如页面上有 5 个 `div`）。
- 该集合具有 `length` 属性（此处 `length` 为 5），但它是一个 `HTMLCollection` 或 `NodeList`，并不是真正的数组。
- 如果尝试调用数组方法，例如 `aDiv.push(newElement)`，控制台会直接报错：`push is not a function`。这是因为 `push` 是数组原型上的方法，而伪数组没有继承 `Array.prototype`。

**使用 Array.from 转换：**
- 通过 `const arrDiv = Array.from(aDiv)` 可以将伪数组转换为真数组。
- 转换后，`arrDiv` 变成了真正的数组格式。
- 此时再调用 `arrDiv.push(newElement)` 就不会报错，并且能够成功将新元素追加到数组中，证明转换成功。

## 实战示例：函数 arguments 对象转换 *Content-[04:50]

函数内部的 `arguments` 对象也是一个典型的伪数组。

**伪数组的特性与报错：**
- 定义一个函数并传入参数（如 1, 2, 3, 4, 5），`arguments.length` 会正确返回 5。
- 但 `arguments` 同样没有数组的方法。如果执行 `arguments.push(6)`，会报错 `arguments.push is not a function`。

**使用 Array.from 转换：**
- 使用 `const argsArray = Array.from(arguments)` 将 `arguments` 转换为真数组。
- 转换后，`argsArray` 成为真正的数组。
- 此时执行 `argsArray.push(6)` 不会报错，并且能成功将 `6` 追加到数组末尾，最终打印出 `[1, 2, 3, 4, 5, 6]`。

## 实战示例：ES6 Set 数据结构转换 *Content-[06:52]

只要是部署了 `iterator` 接口的数据结构，`Array.from` 都能将其转为数组。ES6 的 `Set` 就是可迭代的。

**Set 的特性：**
- 使用 `new Set([1, 2, 3, 4, 5])` 创建一个 `Set` 实例。
- 直接打印 `Set` 实例，其输出格式并非数组格式，无法直接使用数组方法。

**使用 Array.from 转换：**
- 使用 `const res = Array.from(mySet)` 进行转换。
- 转换后，`res` 变成了一个真正的数组 `[1, 2, 3, 4, 5]`。
- 验证：在 `res` 上调用 `res.push(6)`，可以成功修改数组内容并返回新数组的长度，证明 `Set` 已成功转为真数组。

## 实战示例：字符串转换与总结 *Content-[09:21]

**字符串转换：**
- 字符串同样具有可遍历性（部署了 `iterator` 接口）。
- 使用 `Array.from('hello')` 可以直接将字符串拆分为包含单个字符的真数组：`['h', 'e', 'l', 'l', 'o']`。

**核心总结：**
- 在实际开发当中，处理 DOM 集合和 `arguments` 时，必须使用 `Array.from` 将其转变为真数组，才能安全地调用各种数组原型方法（如 `push`、`map`、`filter` 等）。
- 只要数据结构部署了 `iterator` 接口（即可被遍历/迭代），`Array.from` 都能将其完美转换为真正的数组。
