## 扩展运算符的基本概念 *Content-[00:00]

在 ES6 的数组扩展中，除了众多扩展方法外，**扩展运算符（Spread Operator）** 是一个需要重点掌握的核心知识点。

### 1\. 核心定义
扩展运算符表现为三个点（`...`），它是 **rest 参数**的逆运算。
- **通俗理解**：它能够将**可遍历结构（Iterable）** 进行展开，将其转换为**实参列表**的格式。
- **支持的数据类型**：数组、字符串、函数参数、`Arguments` 对象、`Set`、`Map`、`Generator`、`Promise`、`Symbol` 等。只要数据结构具备 `length` 属性和索引，或者实现了 Iterator 接口，就可以被扩展运算符展开。

## 扩展运算符的核心应用场景 *Content-[02:44]

扩展运算符的魅力在于其能够将数组或其他可遍历格式进行优雅展开，主要用于函数调用、数据转换等场景。以下是具体的实际应用案例：

### 1\. 函数调用时传递参数 *Content-[02:44]
在函数调用时，如果需要将数组的元素作为独立的参数传入，扩展运算符可以极大简化代码。

**需求**：有一个数组 `let arr = ['张飞', '刘备', '关羽'];`，需要将其元素作为参数传入函数 `function show(a, b, c)`。

- **ES5 传统写法**：
  需要逐个获取数组元素进行传递：`show(arr[0], arr[1], arr[2]);`。这种方式在参数较多时非常繁琐，且无法在传参位置使用 `for` 循环等逻辑语句。
- **ES6 扩展运算符写法**：
  直接使用 `show(...arr);`。扩展运算符会自动将数组展开为 `张飞, 刘备, 关羽` 的实参格式，完美匹配函数的参数列表。

**经典案例：求数组最大值**
`Math.max()` 方法要求传入的是独立的数字参数（实参列表），直接传入数组是无效的。
- **ES6 解法**：`Math.max(...arr)`。通过扩展运算符将数组展开，即可轻松求出数组中的最大值。

### 2\. 将伪数组转换为真正的数组 *Content-[05:41]
在 DOM 操作中，经常获取到伪数组（如 `NodeList`），扩展运算符可以将其快速转换为真正的数组，从而使用数组的高阶方法。

**需求**：获取页面中所有的 `<li>` 元素并转换为数组。
- **获取伪数组**：`let nodeList = document.querySelectorAll('li');` （此时 `nodeList` 是 `NodeList` 伪数组）。
- **ES6 转换方法**：`let arr = [...nodeList];`
- **原理**：只要伪数组具备 `length` 属性和索引值（即可遍历），扩展运算符就能将其元素展开并放入一个新的数组字面量 `[]` 中，从而生成真正的数组。

### 3\. 将字符串转换为数组 *Content-[06:52]
扩展运算符同样适用于字符串，可以将字符串的每个字符展开为数组元素。

**需求**：将字符串 `"Hello World"` 转换为字符数组。
- **ES5 传统写法**：`str.split('');`
- **ES6 扩展运算符写法**：`[...str]`。
- **优势**：语法更加简洁直观，直接利用扩展运算符将字符串展开为逗号分隔的字符，并包裹在数组中。

### 4\. 结合 Set 实现数组去重 *Content-[08:00]
扩展运算符结合 ES6 的 `Set` 数据结构，可以实现极其简便的数组去重功能。

**需求**：对包含重复元素的数组进行去重。
- **ES6 去重写法**：`let uniqueArr = [...new Set(arr)];`
- **原理解析**：
  1. `new Set(arr)`：将数组传入 `Set` 集合。`Set` 是一种高级数据结构，其特性是**自动去重**，放入的元素不会重复。
  2. `[... ]`：利用扩展运算符将去重后的 `Set` 集合再次展开，并放入新的数组中。
- **优势**：无需手动编写循环和判断逻辑，一键完成数组去重，充分体现了 ES6 语法糖（Syntactic Sugar）的便捷性。

## AI 总结

本视频详细讲解了前端 ES6 中的核心特性——**扩展运算符（`...`）**。扩展运算符本质上是 rest 参数的逆运算，能够将可遍历结构展开为实参列表。笔记重点总结了其四大高频应用场景：
1. **函数传参**：替代 ES5 繁琐的索引传参，轻松解决如 `Math.max()` 等需要独立参数的方法调用。
2. **伪数组转真数组**：通过 `[...nodeList]` 快速将 DOM 查询结果等伪数组转化为真数组。
3. **字符串转数组**：使用 `[...str]` 优雅地将字符串拆分为字符数组。
4. **数组去重**：结合 `Set` 数据结构，通过 `[...new Set(arr)]` 实现一行代码搞定数组去重。
掌握扩展运算符不仅能大幅提升代码的简洁度，也是前端大厂面试中考察 ES6 基础与实战能力的重要考点。
