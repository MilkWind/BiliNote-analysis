## 1. Set 与 Map 集合概述 *Content-[00:13]
在前端开发中，除了常用的数组（Array），在处理复杂遍历和数据存储条件时，经常会用到 `Set`、`Map`、`WeakSet` 和 `WeakMap` 等集合数据结构。掌握 `Set` 和 `Map` 的核心区别后，理解 `WeakSet` 和 `WeakMap` 就会容易很多。

- **Map 集合**：是一个无序的**键值对**（key-value）集合。数据是成对存在的，既有键（key）也有值（value）。
- **Set 集合**：是一个无序的**值**（元素）的存储集合。它没有键值对的概念，只有值（可以理解为只有元素和数据）。它类似于数组，但有着本质的区别。

## 2. Set 集合的核心特性 *Content-[01:00]
- **无序且无索引**：`Set` 是无序的，没有索引的概念。
  - **对比数组**：数组是有序的，可以通过索引（如 `arr[i]`）使用普通的 `for` 循环逐个遍历。
  - **对比 Set**：由于没有索引，不能像数组那样通过索引去遍历。
  - **生动比喻**：数组就像有学号的学生，可以按学号顺序点名；而 `Set` 就像联欢晚会上不同班级混坐的学生，大家随便坐，没有学号，因此无法按顺序点名。
- **非数组对象**：通过构造函数创建的 `Set` 是一个对象，不是数组。
  - 在浏览器控制台打印时，虽然会显示类似 `0, 1, 2, 3` 的数字，但这仅仅是浏览器为了标识清楚而做的视觉标识。
  - 不能通过 `set[0]` 这种中括号加索引的方式去获取元素，这样是取不出来的。

## 3. Set 的创建与去重机制 *Content-[02:55]
- **创建方式**：通过构造函数 `new Set()` 创建，构造函数内部可以传入一个数组作为初始数据。（可参考阮一峰的《ECMAScript 6 入门》文档了解更多转换和创建方式）。
  ```javascript
  let s = new Set([1, 2, 3]);
  ```
- **值的唯一性**：`Set` 集合中的值都是唯一的，不允许重复。
  - 数组允许重复元素（如 `let arr = [1, 1, 1]`），因为可以通过索引（0号、1号、2号）区分它们。
  - `Set` 没有索引，如果允许重复就失去了意义，因此它天生排斥重复值。
- **自动去重**：如果向 `Set` 的构造函数中传入包含重复元素的数组，系统会自动进行去重处理，重复的元素不会被放进去。
  ```javascript
  let s = new Set([1, 1, 2, 2, 3]);
  // 最终 s 中只包含 1, 2, 3，自动完成了去重
  ```

## 4. Set 的实际应用场景与性能优势 *Content-[05:50]
- **典型场景：高效查重**
  - **案例**：在游戏中生成随机名字并存储，需要确保新名字与已存在的名字不重复。
  - **数组的痛点**：如果使用数组存储，每次新增名字都需要遍历整个数组进行比对。当数据量较小（如10人）时没问题；但当数据量极大（如1万、10万甚至10亿人）时，每次新增都要遍历前面所有数据，效率极低，会导致严重的性能问题（如起名卡顿）。
  - **Set 的优势**：`Set` 底层采用了非常成熟且高效的查重机制。编程界讲究“不要重复造轮子”，既然官方提供了高效的工具，直接使用即可（后续有机会可深入研究 `Set` 的源码原理）。
- **如何使用 Set 进行查重**：
  - 将生成的名字存入 `Set` 集合。
  - 通过检查 `Set` 的 `size` 属性来判断是否重复。
  - **重要注意**：`size` 是一个**属性**，不是方法（函数），不需要加括号 `()`。
  - **判断逻辑**：存入名字后，观察 `size` 大小是否发生变化。如果 `size` 没变，说明名字重复了，拒绝该名字；如果 `size` 增加了，说明名字唯一，可以使用。

## AI 总结
`Set` 是 JavaScript 中一种非常重要的数据结构，其核心特点是**无序**、**无索引**以及**值的唯一性**。它不能像数组那样通过索引访问或遍历，但提供了强大的**自动去重**功能。在实际开发中，`Set` 最大的优势在于其底层实现带来的**高效查重性能**，非常适合用于需要频繁判断数据是否重复的场景（如标签去重、唯一ID校验等）。在使用时，需特别注意通过 `size` 属性（而非 `length`）来获取集合的元素个数。
