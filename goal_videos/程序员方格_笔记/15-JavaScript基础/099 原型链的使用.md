## 1. 原型链的概念与家庭比喻 *Content-[00:00]

- **原型的本质**：原型（Prototype）的本质是一个对象，相当于一个公共空间。它解决了传统构造函数中每个实例都重复创建方法导致浪费内存的问题。
- **原型链的形成**：既然原型是一个对象，那么它也会有自己的构造函数和对应的原型对象。对象的原型依然是对象，这就构成了一个链式结构，即**原型链（Prototype Chain）**。
- **家庭关系比喻**：
  - **构造函数** = 父亲
  - **原型对象** = 母亲
  - **实例对象**（`new` 出来的对象） = 孩子
  - 母亲（原型对象）在成为母亲之前，也是别人家的女儿，她有自己的父母（姥姥姥爷）。
  - 姥姥（原型对象的原型）的财产或方法会继承给母亲，进而继承给孩子。这就是原型链中属性和方法继承的生动体现。

## 2. 原型链的底层结构与代码验证 *Content-[03:47]

- **原型链的基本属性原则**：凡是对象就有原型，原型又是对象。给定一个对象，就能找到它的原型，原型还有原型，如此递进构成对象序列。
- **第一层原型链（实例对象 -> 原型对象）**：
  - 代码示例：`let p = new Person()`
  - 通过实例对象访问原型：`p.__proto__`
  - 验证关系：`p.__proto__ === Person.prototype`。实例对象的原型，就是其构造函数的 `prototype` 属性（孩子的母亲就是父亲的妻子）。
- **第二层原型链（原型对象 -> 顶级原型对象）**：
  - `Person.prototype` 本身是一个对象，通过 `typeof` 判断其类型为 `Object`。
  - 既然是 `Object` 类型的对象，说明它是由 `Object` 构造函数创建的（相当于 `new Object()`）。
  - 因此，它的原型指向 `Object` 构造函数的原型对象：`p.__proto__.__proto__ === Object.prototype`。
  - `Object.prototype` 包含了所有对象共用的顶级方法（如 `toString`, `valueOf` 等），这也是为什么所有对象都能调用这些方法的原因。
- **第三层原型链（终点）**：
  - `Object.prototype` 的原型是什么？
  - JavaScript 为了防止无限套娃，将 `Object.prototype.__proto__` 设置为 `null`。
  - `null` 标志着原型链的终点。

## 3. 不同数据类型的原型链结构 *Content-[12:16]

- **字面量对象 `{}` 的原型链**：
  - 代码示例：`let o = {}`
  - 第一层：`o.__proto__ === Object.prototype`
  - 第二层：`Object.prototype.__proto__ === null`
- **数组 `[]` 的原型链**：
  - 代码示例：`let arr = []`
  - 数组是由 `Array` 构造函数创建的，因此它的“父亲”是 `Array`。
  - 第一层：`arr.__proto__ === Array.prototype`。数组的常用方法（如 `push`, `pop`, `map`, `join`, `includes`, `sort`, `toString`, `splice`, `shift`, `slice` 等）都挂载在 `Array.prototype` 上。
  - 第二层：`Array.prototype` 本身也是一个对象，其原型指向 `Object.prototype`。即 `arr.__proto__.__proto__ === Object.prototype`。
  - 第三层：`Object.prototype.__proto__ === null`。

## 4. 原型链的作用与实际应用 *Content-[15:25]

- **核心意义：继承与发展**：
  - 就像人类历史和科技发展是几代人累积的结果一样，原型链体现了属性和方法的累积与继承。
  - 在原型链上绑定的方法和属性，其后代的所有对象都可以直接使用，功能随着原型链的累积越来越丰富。
- **实际应用示例**：
  - 如果想让 JS 中所有对象都具备某个新功能，可以直接在顶层原型上添加方法。
  - 代码示例：`Object.prototype.sayHi = function() { console.log('Hi'); }`
  - 验证：
    - 数组 `arr.sayHi()` -> 可以调用。
    - 字面量对象 `o.sayHi()` -> 可以调用。
    - 自定义实例 `p.sayHi()` -> 可以调用。
  - **注意事项**：虽然原理上可以通过修改 `Object.prototype` 来给所有对象添加方法（就像给人类祖先赋予飞行能力一样，后代全都会了），但在实际开发中**极不推荐**这种操作。这会污染全局原生对象，容易引发不可预知的冲突和错误。

## AI 总结

原型链是 JavaScript 中实现继承和属性查找的核心机制。每个对象都有一个 `__proto__` 属性，指向其构造函数的 `prototype`。当访问对象的某个属性或方法时，如果对象自身没有，引擎就会沿着 `__proto__` 链向上查找，直到找到该属性或到达原型链的终点 `null`。理解原型链不仅有助于深入掌握 JS 中不同数据类型（如数组、对象）内置方法的来源，更是理解面向对象编程中继承原理的基石。
