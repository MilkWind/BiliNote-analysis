## 1. JavaScript 数据类型概述 *Content-[01:06]
- 在 JavaScript 的世界中，所有的数据都归属于两大阵营：**原始类型（Primitive Types）** 和 **对象类型（Object Types）**。
- **原始类型（共 7 种）**：
  - `string`（字符串）
  - `number`（数字）
  - `boolean`（布尔值）
  - `null`（空值）
  - `undefined`（未定义）
  - `symbol`（ES6 引入的符号类型）
  - `bigint`（大整数类型）
- **对象类型**：
  - 除了上述 7 种原始类型之外，其他所有的数据都属于对象（Object），例如数组（Array）、函数（Function）、日期（Date）等。

## 2. typeof 操作符及基本用法 *Content-[01:52]
- `typeof` 是一个一元操作符，用法非常简单，只需放在一个变量或值的前面（如 `typeof operand`）。
- 它会返回一个字符串，告诉你该操作数的数据类型。
- **对原始类型的返回值**：
  - `typeof 'hello'` 返回 `'string'`
  - `typeof 123` 返回 `'number'`
  - `typeof true` 返回 `'boolean'`
  - `typeof Symbol()` 返回 `'symbol'`
  - `typeof 10n` (BigInt) 返回 `'bigint'`
  - `typeof undefined` 返回 `'undefined'`
- **对对象类型的返回值**：
  - 普通对象（如 `{a: 1}`）返回 `'object'`
  - 数组（如 `[1, 2]`）返回 `'object'`（**陷阱**：`typeof` 并不区分普通对象和数组）
  - 日期对象（如 `new Date()`）返回 `'object'`
  - **例外情况**：函数（Function）在 JavaScript 中本质也是一种特殊的对象，但 `typeof` 为它提供了一个专门的返回值 `'function'`，这在实际开发中非常方便。

## 3. typeof 的两大核心陷阱 *Content-[04:06]
- **陷阱一：`typeof null` 返回 `'object'`**
  - **现象**：在控制台打印 `typeof null`，你会发现它返回的不是 `'null'` 而是 `'object'`。
  - **原因**：这是一个在 JavaScript 最初版本就存在，且因为历史原因被保留至今的 Bug。
  - **底层原理**：在早期的 JS 实现中，内部使用“类型标签”来标识数据的类型，对象的标签是 `0`。而 `null` 值在底层的表示恰好是空指针，也就是全零（`0x00`）。`typeof` 的实现逻辑将这个全零的 `null` 错误地判断成了对象。
  - **为何保留**：由于该 Bug 涉及的范围太广，如果当时强行修复，可能会破坏大量现有的网站和代码，因此一直被保留了下来。
- **陷阱二：`typeof` 无法区分具体的对象类型**
  - **现象**：无论是数组字面量还是普通对象字面量，`typeof` 都一视同仁，统统返回 `'object'`。
  - **影响**：这意味着如果你想检查一个变量到底是不是数组，仅靠 `typeof` 是远远不够的。

## 4. 准确判断类型的最佳实践 *Content-[06:03]
- 既然 `typeof` 存在陷阱，社区总结了一些更健壮、更准确的类型判断最佳实践：
- **如何正确判断 `null`**：
  - 直接放弃 `typeof`。
  - 使用严格相等运算符 `===`（三个等号）。
  - 示例：`myVar === null`，可以 100% 准确地判断一个值是不是 `null`，这是最直接也是最可靠的方法。
- **如何正确判断数组**：
  - ES6 为我们提供了一个专门的工具方法：`Array.isArray()`。
  - 示例：`Array.isArray(arr)` 会返回一个布尔值，如果是数组则返回 `true`。
  - 注意：此时 `typeof arr` 依然是 `'object'`，所以判断数组请务必使用 `Array.isArray()` 方法。

## 5. 终极类型检测方案 *Content-[07:20]
- 如果想判断的类型更复杂（例如区分普通对象、日期对象、正则表达式等），有没有一种方法能够通杀所有类型？
- **终极武器**：`Object.prototype.toString.call()`
- **工作原理与返回值**：
  - 通过该方法的调用，可以获得一个格式非常统一的字符串：`[object Type]`。
  - **示例**：
    - 对于 `null`：准确返回 `'[object Null]'`
    - 对于数组：返回 `'[object Array]'`
    - 对于普通对象：返回 `'[object Object]'`
    - 对于原始类型同样有效：字符串返回 `'[object String]'`，数字返回 `'[object Number]'`。
- **优势**：该方法覆盖了所有数据类型，结果精确，是目前最可靠的通用类型检测方案。

## 6. typeof 的安全检查特性 *Content-[08:56]
- 尽管 `typeof` 有上述缺陷，但它还有一个值得一提的优点（特性）：
  - **安全检查未声明变量**：对于一个根本没有声明过的变量，使用 `typeof` 程序是不会报错的。
- **对比说明**：
  - 如果你直接访问一个从未定义过的变量（如 `su`），JavaScript 会立即抛出一个 `ReferenceError`，导致程序中断。
  - 但是，如果你对它使用 `typeof su`，你会得到一个安全的字符串 `'undefined'`，而不会导致程序崩溃。
- **应用场景**：在某些特定场景下，可以利用这个特性来安全地检查某个全局变量（或浏览器环境下的特定 API）是否存在。

## 7. 知识点回顾与总结 *Content-[09:58]
- **知识点一**：`typeof null` 返回 `'object'` 是一个公认的历史 Bug。判断 `null` 请直接使用严格相等运算符 `===`。
- **知识点二**：`typeof` 无法区分数组和普通对象。判断数组需要使用 `Array.isArray()` 方法。
- **知识点三**：如果需要一个能精确判断所有数据类型的终极方案，请使用 `Object.prototype.toString.call()`。
