## 1. 属性的简洁表示 *Content-[00:11]

在 ES6 中，对象的扩展之一是**属性的简洁表示**。ES6 允许在大括号里面直接写入变量名和函数，作为对象的属性和方法，从而使代码书写更加简洁。

### 核心规则
当**属性名跟变量名同名**时，可以直接将变量写入对象中作为简洁表示。此时：
- **属性名** 就是 **变量名**
- **属性值** 就是 **变量值**

### 代码示例对比
```javascript
let age = 16;
let show = function() { 
    console.log("我是show函数"); 
}

// 传统写法：需要显式指定键值对
let pr1 = {
    name: '张三',
    age: age,
    show: show
};

// ES6 简洁表示：同名变量直接写入
let pr2 = {
    name: '张三',
    age,
    show
};
```

## 2. 方法的简洁表示与函数返回值应用 *Content-[02:50]

方法的简洁表示与属性类似，可以直接在对象中写入外部定义的函数名。这种写法在**函数的返回值**场景中将会非常方便。

### 函数返回值中的应用
当函数需要返回一个包含多个同名变量的对象时，可以直接使用简洁表示法，无需再写重复的键值对。

### 结合解构赋值
取出的对象还可以结合**解构赋值**，使代码更加简洁。ES6 的各种语法相互结合后，会带来更多的便利和更简洁的表示方式。

### 代码示例
```javascript
function show() {
    let x = 99;
    let y = 108;
    
    // 直接返回包含 x 和 y 的对象，等同于 return { x: x, y: y };
    return { x, y }; 
}

let result = show();
console.log(result); // 输出对象 { x: 99, y: 108 }

// 结合解构赋值，进一步简化取值过程
let { x, y } = show();
console.log(x, y); // 输出 99 108
```

## 3. 属性取值器与打印对象的应用 *Content-[04:29]

### 属性的赋值与取值器（Getter/Setter）
在 CommonJS 等模块规范中处理变量时，属性的赋值、取值器（getter）和设值器（setter）同样可以使用这种简洁写法。

### 在打印对象时的帮助
在调试和打印对象时，简洁写法可以作为很好的标识，帮助开发者快速定位变量。
```javascript
let user = { name: '张三' };

// 打印时作为标识，属性变量名就是属性名，变量值就是属性值
// 输出结果会清晰显示 user 对象的内容
console.log({ user }); 
```

## 4. 属性名的表达式 *Content-[05:26]

除了属性值的简洁表示，ES6 还支持**属性名的表达式**。如果属性名不是一个固定的字符串，而是一个变量，或者通过变量拼接、计算得出，就需要使用表达式。

### 核心规则
- 如果属性名是一个变量，必须使用**中括号 `[]`** 进行绑定。
- 如果属性名是通过变量拼接或计算得出的，也需要在**中括号 `[]` 里面写表达式**。
- 在自定义对象（字面量表示）中，如果想把变量值作为属性名，同样必须在变量外加上中括号 `[]` 进行计算。

### 类型自动转换
需要注意的是，如果中括号内的变量是**非字符串类型**，系统会自动将其类型转换成字符串，并作为最终的属性名。

### 代码示例
```javascript
let propKey = 'abc';

let obj = {
    // 使用中括号将变量值 'abc' 作为属性名
    [propKey]: 'value1', 
    
    // 中括号内写表达式，拼接字符串 'hello' 作为属性名
    ['he' + 'llo']: 'value2', 
    
    // 数字类型会自动转为字符串 "123" 作为属性名
    [123]: 'value3' 
};
```

## 5. 其他扩展（name属性与super关键字） *Content-[06:42]

在对象的扩展中，还涉及以下两个重要概念：
- **name 属性**：函数的 `name` 属性用于获取函数的名称，这在之前的课程中已经详细讲解过。
- **super 关键字**：`super` 关键字主要用于指向当前对象的原型对象，在对象的方法中非常有用。这部分内容将在后续的课程中进行重点讲解。

## AI 总结

本视频主要讲解了 ES6 中关于对象的两个重要扩展：**属性的简洁表示**和**属性名的表达式**。
1. **简洁表示**：当变量名与对象属性名相同时，可直接在对象字面量中写入变量名，省略冒号和值；方法同理。这在函数返回对象和结合解构赋值时能极大提升代码简洁度。此外，在 `console.log` 打印对象时，这种写法也能作为清晰的调试标识。
2. **属性名表达式**：当需要使用变量的值或表达式的计算结果作为对象属性名时，必须使用方括号 `[]` 将其包裹。若表达式结果为非字符串类型，JS 引擎会自动将其转换为字符串。
