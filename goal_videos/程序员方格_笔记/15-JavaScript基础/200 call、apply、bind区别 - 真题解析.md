  - 主要目的是实现函数的复用。

## 2. call、apply、bind 的核心区别 *Content-[00:35]
- **区别一：执行方式不同**
  - `call` 和 `apply`：调用后会**立即执行**函数。
  - `bind`：调用后**不会立即执行**，只会返回一个绑定了 `this` 的新函数，需要后续手动调用这个新函数才会执行。
- **区别二：参数传递方式不同**
  - `call`：参数**逐个传递**。第一个参数是要指向的 `this` 对象，后面依次跟函数需要的参数。
  - `apply`：参数以**数组形式传递**。第一个参数是 `this` 对象，第二个参数是一个包含所有函数参数的数组。
  - `bind`：参数传递和 `call` 一样是**逐个传递**。此外，它还可以在调用返回的新函数时补充参数（支持预设参数和补充参数）。
- **区别三：`this` 指向的可修改性不同**
  - `call` 和 `apply`：每次调用都可以重新指定 `this` 的指向（例如第一次指向 A 对象，第二次可以指向 B 对象）。
  - `bind`：一旦绑定了 `this`，后续不管怎么调用，哪怕再用 `call` 或 `apply`，都**无法改变**其 `this` 指向，`this` 值会被**永久固定**。

## 3. 实际开发应用场景 *Content-[01:52]
- **`call`**：常用于**对象方法的复用**（例如借用其他对象的方法）。
- **`apply`**：常用于**求数字的最大值/最小值**（结合 `Math.max()` / `Math.min()` 处理数组参数）。
- **`bind`**：常用于需要**延迟执行**的场景，例如定时器（`setTimeout` / `setInterval`）和事件绑定。

## 4. 改变 this 指向的核心原理 *Content-[02:37]
- **核心原理**：
  - 函数的 `this` 指向本质是**谁调用它，它就指向谁**。
  - `call`、`apply`、`bind` 的底层逻辑是：**把函数挂载到目标对象上，让目标对象去调用这个函数**。这样函数的 `this` 就自然指向了目标对象，从而实现了 `this` 指向的改变。
- **案例说明**：
  - 假设有一个 `saySalary` 函数，全局调用时 `this` 指向 `window`。
  - 当使用 `张三` 这个对象调用时（通过 `call`/`apply`/`bind`），相当于把 `saySalary` 变成了 `张三` 的一个方法。
  - 让 `张三` 这个对象去调用该方法，此时 `this` 就指向了 `张三` 对象。
- **经典总结**：
  - **让目标对象成为函数的调用者，从而改变函数的 `this` 指向。**

## 5. 总结与回顾 *Content-[04:15]
- 三个方法的核心就是**改变 `this` 指向**。
- `call` 和 `apply` 会**立即执行**，主要区别在于参数传递方式不同。
- `bind` **不会立即执行**，返回新函数，且 `this` 会被**永久固定**。
- 牢记上述核心要点，即可从容应对所有相关的面试题。
