## 1. Set 简介与核心特性 *Content-[00:41]

`Set` 是在 ES6 中引入的核心数据结构，专门用于存储唯一值的集合。它在数组去重、成员检测以及集合运算等场景中具有不可替代的作用，能够使代码变得更加简洁高效。

`Set` 具有以下三个显著的核心特性：
- **值的唯一性**：这是最重要的一点。当尝试向 `Set` 中添加一个已经存在的值时，该操作会被忽略，不会产生任何效果。这使得 `Set` 成为数组去重的最佳选择。
- **保持插入顺序**：虽然 `Set` 不像数组那样有数字索引，但它严格保持了元素的插入顺序。遍历时，会按照元素被添加的先后顺序依次取出。
- **存储任意类型**：`Set` 可以存储任意类型的值，无论是基本数据类型还是引用数据类型，都可以作为 `Set` 的成员。

**代码示例**：
```javascript
const mySet = new Set();
mySet.add(1);
mySet.add(2);
mySet.add(3);
mySet.add(1); // 重复添加，会被忽略

console.log(mySet.size); // 输出 3，而不是 4
```
通过 `size` 属性可以直接获取集合中元素的数量，这与 `Map` 是一致的。

## 2. Set 与 Array 的对比 *Content-[02:20]

为了更好地理解 `Set` 的价值，将其与最常用的 `Array` 进行对比：

- **Array（数组）**：
  - **特点**：允许包含重复元素，所有元素都会被保留。
  - **优势**：可以通过数字索引快速访问特定位置的元素。
  - **劣势**：成员检测通常使用 `includes` 方法，该方法需要遍历整个数组，时间复杂度为 $O(n)$。在数组数据量很大时，效率较低。

- **Set（集合）**：
  - **特点**：自动过滤重复值，只保留唯一的元素。
  - **劣势**：不支持通过索引访问，因为它本质上是一个集合，而不是有序列表。
  - **优势**：成员检测使用 `has` 方法，时间复杂度为 $O(1)$。无论 `Set` 的规模有多大，检测速度都非常快。

## 3. Set 的核心 API *Content-[03:49]

`Set` 的方法设计非常简洁且语义明确，主要包含以下操作方法和属性：

- **`add(value)`**：向 `Set` 中添加一个值。如果值已存在则被忽略。该方法执行后会返回 `Set` 实例本身，因此支持**链式调用**。
- **`has(value)`**：检测某个值是否存在于 `Set` 中，返回布尔值。这是最常用且性能最好的方法之一。
- **`delete(value)`**：删除指定的值。如果删除成功返回 `true`，如果值不存在则返回 `false`。
- **`clear()`**：一次性清空整个集合。
- **`size` 属性**：直接返回 `Set` 中元素的数量，这是一个时间复杂度为 $O(1)$ 的操作。

**代码示例**：
```javascript
const colors = new Set();
// 链式调用添加多个值
colors.add('red').add('green').add('blue'); 

console.log(colors.size); // 输出 3
console.log(colors.has('red')); // 输出 true

colors.add('red'); // 重复添加被忽略
console.log(colors.size); // 仍为 3

colors.delete('blue'); // 删除成功
console.log(colors.size); // 输出 2
console.log(colors.has('blue')); // 输出 false
```

## 4. Set 的遍历与迭代 *Content-[06:15]

`Set` 是一个可迭代对象，严格遵守插入顺序。它提供了多种便利的遍历方法：

- **`values()`**：返回一个包含 `Set` 所有值的迭代器，可以在 `for...of` 循环中直接使用，输出顺序与添加顺序完全一致。
- **`keys()`**：由于 `Set` 不存在键值对的概念，`keys()` 方法返回的内容与 `values()` 完全相同。这种设计是为了让 `Set` 和 `Map` 的 API 保持一致性。
- **`forEach(callback)`**：与数组的 `forEach` 非常相似，接受一个回调函数。在 `Set` 的 `forEach` 中，回调函数的第一个参数就是值本身。
- **`for...of` 直接遍历**：`Set` 默认的迭代器就是 `values` 迭代器，因此可以直接在 `for...of` 循环中遍历 `Set` 实例，代码非常简洁优雅。

**代码示例**：
```javascript
const set = new Set([1, 2, 3]);

// 1. 使用 values()
for (const val of set.values()) {
  console.log(val);
}

// 2. 使用 keys() (结果与 values 相同)
for (const key of set.keys()) {
  console.log(key);
}

// 3. 使用 forEach
set.forEach(val => {
  console.log(val);
});

// 4. 直接使用 for...of 遍历
for (const val of set) {
  console.log(val);
}
```

## 5. Set 的典型应用场景 *Content-[07:53]

`Set` 在实际开发中有许多经典且实用的应用场景：

- **数组去重**：
  将数组转换为 `Set` 实现自动去重，再用扩展操作符转回数组，一行代码即可完成。
  ```javascript
  const arr = [1, 2, 2, 3, 3];
  const uniqueArr = [...new Set(arr)]; // [1, 2, 3]
  ```

- **字符串去重**：
  字符串也是可迭代的，利用 `Set` 去除重复字符后，再用 `join` 方法拼接回字符串。
  ```javascript
  const str = "hello";
  const uniqueStr = [...new Set(str)].join(''); // "helo"
  ```

- **集合运算**：
  - **并集**：使用扩展运算符将两个 `Set` 展开到新数组中，再创建新的 `Set`，重复元素会自动保留一个。
    ```javascript
    const setA = new Set([1, 2, 3]);
    const setB = new Set([3, 4, 5]);
    const union = new Set([...setA, ...setB]); // {1, 2, 3, 4, 5}
    ```
  - **交集**：将 `Set` 转为数组后使用 `filter` 方法，结合 `has` 方法（时间复杂度 $O(1)$）找出共有元素，最后转回 `Set`。
    ```javascript
    const intersection = new Set([...setA].filter(x => setB.has(x))); // {3}
    ```
  - **差集**：找出存在于 `setA` 但不存在于 `setB` 的元素，实现方式与交集类似，只需将 `filter` 的条件改为 `!setB.has(x)`。
    ```javascript
    const difference = new Set([...setA].filter(x => !setB.has(x))); // {1, 2}
    ```

## 6. Set 与 Array 的转换及实用技巧 *Content-[10:22]

在实际项目中，经常需要进行 `Set` 和 `Array` 之间的转换：

- **Array 转 Set**：
  直接将数组作为参数传给 `new Set()` 构造函数。
  ```javascript
  const arr = [1, 2, 2, 3];
  const set = new Set(arr);
  ```

- **Set 转 Array**：
  - **方式一**：使用扩展操作符 `...`，这是最简单的方式。
    ```javascript
    const arr1 = [...set];
    ```
  - **方式二**：使用 `Array.from()`，它可以将任何可迭代对象（包括 `Set`）转换为数组。
    ```javascript
    const arr2 = Array.from(set);
    ```

- **实用技巧：数组去重并排序**：
  结合 `Set` 去重、扩展运算符转数组以及 `sort` 方法排序，链式调用使代码非常优雅。
  ```javascript
  const arr = [3, 1, 2, 2, 1];
  const result = [...new Set(arr)].sort(); // [1, 2, 3]
  ```
