## 关键字 (Keywords) *Content-[00:07]*

- **定义**：关键字是 ECMAScript 规范中预定义好的、具有特殊用途的单词。
- **核心作用**：它们的用途非常明确，构成了 JavaScript 语言语法的骨架。
  - `if` 和 `else`：用于定义条件分支。
  - `for` 和 `while`：用于控制循环结构。
  - `function`：用于声明函数。
- **使用限制**：正是因为关键字具有特殊的语法含义，所以有一个非常重要的限制——**绝对不能**将关键字用作变量名、函数名或对象的属性名。
- **常见示例**：`break`、`case`、`if`、`let` 等都是日常编码中非常熟悉的关键字。
- **错误演示**：如果尝试使用关键字（例如 `if`）来声明一个变量，JavaScript 引擎会立刻抛出一个语法错误（Syntax Error）。

## 保留字 (Reserved Words) *Content-[01:23]*

- **定义**：保留字是一些目前在 JavaScript 中还没有具体功能，但被语法规范保留下来，可能在未来的某个版本中成为正式关键字的单词。
- **核心目的**：预留这些词是为了保证语言的**向前兼容性**。
  - **场景说明**：假设你现在使用 `enum` 作为变量名，如果未来的 ECMAScript 2026 版本将 `enum` 变成了一个新的正式关键字，那么你现在的代码在新的运行环境下就会立即报错。预留这些词汇就是为了避免这种破坏性的兼容问题。
- **使用限制**：与关键字一样，保留字也**不能**作为标识符（如变量名）使用。如果尝试用保留字作为变量名，同样会得到一个语法错误。
- **常见示例**：`enum`、`implements`、`package`、`private` 等。
- **延伸意义**：这些保留字在其他面向对象编程语言（如 Java 或 TypeScript）中是非常常见的关键字。JavaScript 保留这些词汇，也反映出了该语言在未来可能的发展方向。

## AI 总结 *Content-[02:57]*

本次视频主要讲解了 JavaScript 中的两个基础但极其重要的概念：**关键字**与**保留字**。
1. **关键字**是语言语法的核心骨架（如 `if`、`for`、`function`），具有明确的特殊用途，严禁用作变量名或标识符，否则会引发语法错误。
2. **保留字**则是为了保障语言向前兼容性而预留的词汇（如 `enum`、`private`），它们目前无具体功能，但未来可能升级为关键字。同样地，保留字也不能作为标识符使用。
理解并严格遵守这两类词汇的使用限制，是编写规范、无语法错误的 JavaScript 代码的基础，也是前端面试中考察 JS 基础扎实程度的常见考点。
