## 1. 课程介绍与核心概念概述 *Content-[00:00]

本节课深入探讨 JavaScript 中非常核心且面试必考的概念：**原型（Prototype）** 和 **原型链（Prototype Chain）**。

**学习目标：**
- 理解原型和原型链的本质。
- 解答为什么它们是 JavaScript 中实现继承的关键机制。
- 通过具体的代码示例学习并运用这一重要概念。

## 2. 原型与原型链的本质 *Content-[00:46]

### 原型 (Prototype)
- **定义**：JavaScript 中的一种核心机制。
- **作用**：通过原型，一个对象可以从其他对象那里继承属性和方法。其主要作用是**实现对象间代码的共享**，避免重复编写相同的逻辑。

### 原型链 (Prototype Chain)
- **定义**：由原型对象连接成的一个链式结构。
- **作用**：主要用于**属性的查找**。当试图访问一个对象的属性时，如果对象本身没有该属性，JavaScript 引擎就会沿着这条链向上查找。
- **意义**：实现了 JavaScript 基于原型的继承模式。

## 3. 为什么需要原型和原型链 *Content-[01:40]

原型和原型链的存在主要有以下三个核心原因：

1. **实现继承**
   - 通过原型链，一个对象可以轻松访问并使用其原型对象（父级或基类）上的属性和方法。
   - 大大减少了代码的重复，提高了代码的可维护性。

2. **节省内存**
   - 如果创建 100 个、1000 个甚至更多具有相同方法的对象，每个对象都存储一份方法副本会占用大量内存。
   - 原型机制允许这些对象实例**共享原型对象上的同一个方法**。所有实例只需要一个指向原型的引用即可，在处理大量相同类型对象时能极大节省内存开销。

3. **动态性**
   - 原型链是动态的，意味着可以在运行时修改一个原型对象。
   - 这种修改会立即影响所有继承自该原型对象的所有实例，为 JavaScript 的灵活编程提供了极大的可能性。

## 4. 原型相关的核心 API 与属性 *Content-[03:13]

在实际开发中，与原型打交道需要掌握以下几个关键的 API 和属性：

### `__proto__` 与 `prototype`
- **`prototype`**：函数的标准属性（特别是作为构造函数使用的函数）。定义函数时，JavaScript 会自动给它添加一个 `prototype` 属性，其值是一个对象。所有通过 `new` 关键字创建的实例，其 `__proto__` 都指向这个构造函数的 `prototype` 对象。
- **`__proto__`**：对象的内部属性（隐式指针），指向创建该对象的构造函数的 `prototype` 属性，是构成原型链的核心链接。它是一个非标准但广泛支持的属性，用来访问或设置对象的原型。

### `constructor.prototype`
- 这是实例和原型之间建立关联的方式。通过构造函数的 `prototype` 属性，可以将实例与原型对象连接起来。

### `Object.getPrototypeOf()`
- ES6 标准引入的方法，用于获取对象的原型。
- 相比直接使用 `__proto__`，这是目前**推荐的、更规范且更安全**的访问原型的方式。

### `Object.setPrototypeOf()`
- 用于设置一个对象的原型，让它指向一个全新的对象。
- **注意**：虽然提供了动态修改原型链的能力，但在性能敏感的代码中**频繁使用是不被推荐的**，因为它可能会对 JS 引擎的优化产生负面影响，导致性能下降。

### `Object.create()`
- 创建一个全新的对象，并允许指定这个新对象的原型。
- 第一个参数传入想要的原型对象；第二个参数（可选）用于为新对象定义自己的属性。
- 它是实现纯粹的、基于原型继承的一种强大方式。

## 5. 代码示例与原型链查找机制 *Content-[07:09]

### 示例 1：构造函数与原型方法
```javascript
function Person(name) {
    this.name = name;
}

// 在原型上定义方法
Person.prototype.sayHello = function() {
    console.log(this.name);
};

const person1 = new Person('Alex');
const person2 = new Person('Bob');

person1.sayHello(); // 输出: Alex
person2.sayHello(); // 输出: Bob
```
- **执行原理**：`person1` 和 `person2` 自身没有 `sayHello` 方法。JavaScript 引擎在实例自身找不到时，会顺着它们的 `__proto__` 指向 `Person.prototype` 去寻找并执行。
- 由于原型方法中的 `this` 指向调用方法的对象实例，因此分别打印出 'Alex' 和 'Bob'。

### 示例 2：验证原型链
```javascript
// 验证 person1 的原型是否等于 Person.prototype
console.log(Object.getPrototypeOf(person1) === Person.prototype); // true
```

### 示例 3：原型链的延伸与终点
```javascript
// Person.prototype 本身也是一个对象，它也有自己的原型
console.log(Object.getPrototypeOf(Person.prototype) === Object.prototype); // true

// 原型链的终点
console.log(Object.getPrototypeOf(Object.prototype)); // null
```
- **链条结构**：几乎所有在 JavaScript 中创建的对象，它们的原型链最终都会连接到 `Object.prototype`。这就解释了为什么自定义对象即使没有自己定义 `toString` 或 `hasOwnProperty` 等方法，也能直接调用它们（因为这些方法定义在 `Object.prototype` 上）。
- **查找终点**：当尝试获取 `Object.prototype` 的原型时，结果为 `null`。属性查找过程为：对象自身 -> 构造函数原型 -> `Object.prototype` -> `null`。

### 示例 4：`Object.create` 的用法
```javascript
const obj = Object.create({x: 1, y: 2});
console.log(obj.x); // 输出: 1 (obj 本身没有 x，去原型 {x:1, y:2} 上查找)

// 验证原型
console.log(Object.getPrototypeOf(obj)); // {x: 1, y: 2}
```
- 这种方式常用于实现灵活的、不依赖构造函数的原型继承。

## 6. 原型与原型链的关键注意事项 *Content-[11:53]

在理解和使用原型时，有几个关键点必须牢记：

1. **属性查找顺序**
   - 原型链的核心机制。访问对象属性时，先查找自身；如果没有，沿着 `__proto__` 指向的原型对象继续查找；如果还没有，继续向上查找，直到属性找到或到达原型链终点 `null`。
   - 如果整个链条上都找不到，则返回 `undefined`。

2. **`this` 的指向问题（常见面试考点）**
   - 尽管方法是定义在原型对象（如 `Person.prototype`）上的，但通过实例（如 `person1.sayHello()`）调用时，方法内部的 `this` **并不是指向原型对象**，而是指向**调用该方法的对象实例**（即 `person1`）。这是 JavaScript 函数调用时 `this` 绑定的重要规则。

3. **直接修改 `__proto__` 的性能限制**
   - 虽然语法上允许直接修改 `object.__proto__`，但在实际生产代码中**强烈不推荐**。
   - 直接修改会导致 JS 引擎难以优化代码的执行，带来潜在的性能问题。
   - ES6 提供的 `Object.setPrototypeOf` 是更规范的做法，但在热点代码路径中频繁使用仍需警惕性能开销。

4. **原型链的终点**
   - 绝大多数原型链向上追溯，最终都会到达 `Object.prototype`。
   - `Object.prototype` 包含许多内置方法，而 `Object.prototype.__proto__` 是 `null`。
   - 当查找属性到达 `null` 时，表示已经遍历了整个原型链，查找过程结束。

## 7. 课程总结与回顾 *Content-[15:20]

- **原型**是 JavaScript 实现继承的机制。
- **原型链**是由原型形成的链条，决定了属性的查找路径。
- 理解 `prototype` 和 `__proto__`，以及如何通过 `Object.getPrototypeOf` 与它们交互，是掌握原型的基础。
- 属性查找总是从对象自身沿着链条向上进行，直到找到或者到达原型链的终点 `null`。
- 推荐参考 MDN 关于原型链的文档以获取更权威和深入的解释。
- 原型和原型链是 JavaScript 面向对象和继承的基石，深入理解它们对于学习 JS 至关重要。
