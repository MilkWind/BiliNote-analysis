## JS 中创建函数的六种方式 *Content-[00:09]

JS 中创建函数共有六种常用方式，其中四种为核心必备，两种为延伸补充。

1\. **函数声明 (Function Declaration)**
- **定义**：使用 `function` 关键字直接声明。
- **特点**：具有**函数提升**（Hoisting）特性，可以在声明之前调用。
- **使用场景**：适合定义复杂、需要重复多次调用的工具函数（如求和、求平方等）。

2\. **匿名函数表达式 (Anonymous Function Expression)**
- **定义**：将匿名函数赋值给变量或常量。
- **特点**：**没有**函数提升，不能在赋值前调用。
- **使用场景**：适合动态赋值、回调函数（如数组的遍历 `map`, `forEach` 等）。

3\. **具名函数表达式 (Named Function Expression)**
- **定义**：将有名字的函数赋值给变量。
- **特点**：**没有**函数提升，函数名仅能在函数**内部**使用（常用于内部递归），外部只能通过变量名或常量名调用。调试时方便定位。
- **使用场景**：适合需要递归、调试频繁的场景。

4\. **Function 构造函数**
- **定义**：使用 `new Function()` 创建，参数和函数体均为字符串形式。
- **特点**：存在安全隐患，实际开发中几乎不用。
- **使用场景**：仅适合动态生成函数的特殊场景。

5\. **自执行匿名函数 (IIFE - Anonymous)**
- **定义**：定义后立即执行的匿名函数。
- **特点**：形成独立作用域，避免全局变量污染。
- **使用场景**：适合页面初始化代码。

6\. **自执行具名函数 (IIFE - Named)**
- **定义**：有名字的自执行函数。
- **特点**：调试方便。
- **使用场景**：适合复杂的初始化场景。

## 前三种创建方式的核心区别 *Content-[01:32]

函数声明、匿名函数表达式和具名函数表达式的核心区别主要体现在函数名、函数提升以及调用方式上：

- **函数声明**：
  - 有函数名。
  - **有**函数提升，可在声明前调用。
  - 外部可通过函数名直接调用。

- **匿名函数表达式**：
  - 没有函数名。
  - **无**函数提升，不可在赋值前调用。
  - 外部只能通过赋值的变量名或常量名去调用。

- **具名函数表达式**：
  - 有函数名。
  - **无**函数提升，不可在赋值前调用函数名。
  - 函数名**仅能在函数内部使用**（如递归），外部只能通过变量名或常量名去调用。

## 自执行函数详解与案例 *Content-[02:16]

- **什么是自执行函数**：函数在定义后立即被调用执行，通常用于创建独立的作用域，防止变量污染。
- **匿名形式案例**：`(function() { console.log('匿名自执行'); })();`
- **具名形式案例**：`(function namedIIFE() { console.log('具名自执行'); })();`

## Function 构造函数的特点与缺陷 *Content-[02:27]

使用 `new Function()` 创建函数的特点及实际开发中极少使用的原因：

**特点**：
- 参数和函数体代码都必须是**字符串**形式。
- 可动态生成函数。
- 支持全局作用域，不依赖当前作用域。

**很少使用的原因（缺陷）**：
1\. **可读性差**：字符串形式的代码不利于维护和调试。
2\. **安全隐患**：若字符串包含用户输入的内容，可能会注入恶意代码（类似 `eval` 的风险）。
3\. **执行效率低**：解析字符串生成函数的执行效率低于其他创建方式。

## 实战演练：计算两数之和 *Content-[02:58]

面试题要求：用三种不同的方式创建一个函数，实现计算两个数的和。

- **方式一（函数声明）**：`function sum(a, b) { return a + b; }`
- **方式二（匿名函数表达式）**：`const sum = function(a, b) { return a + b; };`
- **方式三（箭头函数）**：`const sum = (a, b) => a + b;` （注：箭头函数本质上是匿名函数表达式的简写形式，也是实际开发中最常用的方式之一）。
