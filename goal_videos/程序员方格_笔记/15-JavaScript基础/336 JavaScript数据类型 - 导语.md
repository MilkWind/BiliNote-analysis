## 引言：JavaScript 数据类型的重要性 *Content-[00:04]

- JavaScript 数据类型是 JS 入门的基石，也是前端面试中 100% 必考的基础面试题。
- 面试官的第一个问题大概率是：“请你说一说 JS 中有哪些数据类型”。如果答不上来，会直接暴露 JS 基础不扎实，连入门门槛都没达到。
- 很多学员在学习时跳过数据类型，导致后续写代码和面试时遇到诸多问题：
  - 分不清 `null` 和 `undefined`。
  - 分不清引用类型，导致对象复制后数据莫名被修改。
  - 类型判断时踩了 `typeof` 的坑。
  - 面试时被基础题问懵，直接影响后续面试问题的回答。
- JS 的变量、运算、函数、对象等所有知识点都基于数据类型。吃透数据类型是学好 JS 最关键的第一步，也是面试的敲门砖。

## 前端面试高频问题解析 *Content-[01:31]

面试官关于 JS 数据类型的高频问法主要集中在以下 5 个方面：

1\. **说说 JS 中有哪些数据类型，分别列举并说明。**
2\. **JS 的基本数据类型有哪些？新增的是哪两个？**
   - 注意面试官的不同叫法：基本数据类型、原始类型、值类型、简单类型，指的都是同一个概念。务必听懂面试官的提问意图。
3\. **JS 的引用数据类型有哪些？**
   - 别名：复杂数据类型。如果面试官问“复杂数据类型”，指的其实就是引用数据类型。
   - 延伸问题：`Object` 的常见子类型有哪些？
4\. **`BigInt` 数据类型解决了什么问题？它和 `Number` 的区别是什么？**
5\. **`null` 和 `undefined` 有什么区别？分别在什么场景下使用？**

## JavaScript 弱类型语言特性 *Content-[03:13]

- **弱类型语言定义**：
  - 不需要提前声明变量的类型。
  - 变量的数据类型在程序执行过程中会被自动确定。
  - 可以使用同一个变量保存不同类型的数据。
- **代码示例演示**：
  - `let a;` -> 打印 `a` 结果为 `undefined`（声明了但未赋值）。
  - `a = 123;` -> 打印 `a` 结果为 `123`，使用 `typeof a` 检测类型为 `number`。
  - `a = 'hello';` -> 打印 `a` 结果为 `hello`，使用 `typeof a` 检测类型为 `string`。
  - `a = true;` -> 打印 `a` 结果为 `true`，使用 `typeof a` 检测类型为 `boolean`。
- **核心结论**：在 JS 中，变量的数据类型是由其**值**来决定的，这就是弱类型语言的核心特点。

## JavaScript 基本数据类型详解 *Content-[06:05]

- **基本概念**：基本数据类型是不可拆分的最小数据单元。
- **种类总数**：一共有 **7 种**。
- **ES5 中包含的 5 种**：
  - `Undefined`
  - `Null` 
  - `Boolean`
  - `Number`
  - `String`
- **后续版本新增的 2 种**：
  - ES6 新增：`Symbol`
  - ES10 (ES2020) 新增：`BigInt`
