## 第二种清空数组的方法：length 属性赋值为 0 *Content-[00:00]
- 在 JavaScript 中，数组的 `length` 属性不仅可以用来读取数组的长度，还可以用来修改（设置）数组的长度。
- 当设置的 `length` 值小于原数组的长度时，数组会从末尾开始截断。
- 如果将 `length` 属性直接赋值为 `0`，数组会直接截断成一个空数组。
- 这是最简洁的清空数组的方法。

## 核心特点与优势 *Content-[01:08]
- **不断开引用关系**：不会断开数组的引用关系，原数组和引用该数组的新数组会同步清空。
- **支持 `const` 声明**：这是**唯一**能清空使用 `const` 声明的数组的方法（面试重点，后续常有真题解析）。
- **性能最优**：直接修改数组长度，没有额外的计算开销，在所有清空数组的方法中性能表现最好。

## 基础实例与引用关系测试 *Content-[02:07]
- **基础用法演示**：
  ```javascript
  let arr2 = [1, 2, 3, 4, 5];
  arr2.length = 0;
  console.log(arr2); // 输出: [] (成功清空为空数组)
  ```
- **引用关系同步测试**：
  - 如果将原数组通过赋值运算符分配给其他数组，例如 `let newArr = arr2;`。
  - 此时 `arr2` 和 `newArr` 指向同一个内存引用地址。
  - 当执行 `arr2.length = 0` 清空原数组时，`newArr` 也会同步被清空。
  - 这一特性与使用 `splice()` 方法清空数组的效果完全一致。
  - **适用场景**：如果需要更新对数组的任何现有引用，并保持多个变量之间的数据同步，推荐使用这种方法。

## 使用 const 声明数组的清空原理 *Content-[05:08]
- **实例演示**：
  ```javascript
  const arr2 = [1, 2, 3, 4, 5];
  arr2.length = 0;
  console.log(arr2); // 输出: [] (成功清空，且不报错)
  ```
- **底层原理解析**：
  - `const` 声明的变量，其**引用地址不能变**，但**数组的内容（元素）是可以变的**。
  - 修改 `length` 属性本质上是在修改数组内部的元素（内容），并没有改变数组在内存中的引用地址，因此不会触发 `const` 的重新赋值报错机制。
- **生动比喻**：
  - `const` 声明数组就像给你的**文具盒贴了一个标签**。
  - **引用不变**：你不能把这个文具盒换成一个新的文具盒（不能重新赋值改变引用）。
  - **内容可变**：但是你可以把文具盒里面的笔全部拿走（可以修改数组内部的元素，如通过修改 `length` 清空数组）。

## AI 总结
在 JavaScript 中，通过将数组的 `length` 属性赋值为 `0` 是清空数组最简洁且性能最优的方法。它的核心优势在于不会断开原有的引用关系（多个引用同一数组的变量会同步清空），并且是唯一能够直接清空由 `const` 声明的数组的方法。其底层原理在于 `const` 仅限制引用地址的修改，而不限制数组内部内容的变更，修改 `length` 恰好只改变了数组内容而未改变引用地址。
