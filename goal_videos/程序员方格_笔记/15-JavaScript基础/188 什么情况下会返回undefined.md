## 2. undefined 的定义及与 null 的核心区别 *Content-[01:22]

### 什么是 undefined
- `undefined` 是 JavaScript 的原始数据类型之一。
- 表示“未定义”。
- 简单来说，就是一个变量、属性或值本该有内容或数据，但实际没有被赋值，它是 JS 自动赋予的**默认空值**。

### undefined 与 null 的核心区别
- **`undefined` 是被动的**：变量或属性声明了但是没有赋值，JS 自动赋予的默认值。一句话总结：**没赋值的就是 `undefined`**。
- **`null` 是主动的**：开发者手动赋值为空值，表示刻意为空。一句话总结：**手动置空的就是 `null`**。

## 3. 场景一：声明变量但未初始化 *Content-[03:58]

### 概念解析
- **声明变量**：使用 `let`、`var` 或 `const` 告诉 JS 存在一个变量（如 `let xxx`）。
- **初始化变量**：给声明的变量赋值，告诉 JS 变量的具体值是多少。
- 如果只声明不赋值（未初始化），JS 会自动给变量赋一个默认值，即 `undefined`。

### 案例演示
1. **`let` 声明未初始化**：
   ```javascript
   let a;
   console.log(a); // 输出: undefined
   ```
   因为只声明了没有赋值，JS 给了默认值 `undefined`。

2. **`var` 声明未初始化**：
   ```javascript
   var b;
   console.log(b); // 输出: undefined
   ```
   结果与 `let` 一致，返回 `undefined`。

3. **`const` 声明未初始化（面试坑点）**：
   ```javascript
   const c; 
   // 直接报错：Missing initializer in const declaration
   ```
   **报错原因**：ES6 语法严格规定，使用 `const` 声明常量时**必须立即初始化（赋值）**，绝对不能只声明不赋值。

### 开发避坑技巧
在声明变量时，**尽量立即初始化**，避免后续使用时因为值为 `undefined` 而引发未知错误。

## 4. 场景二：访问对象中不存在的属性及避坑技巧 *Content-[08:09]

### 核心原理
对象的属性是以键值对（key-value）的形式存在的。当访问一个对象中**没有定义的 key** 时，JS 不会报错，而是直接返回 `undefined`。

### 案例演示
1. **简单对象访问**：
   ```javascript
   const obj = { name: 'xxx', age: 20 };
   console.log(obj.gender); // 输出: undefined
   ```
   因为 `obj` 对象中没有 `gender` 属性，所以返回 `undefined`。

2. **嵌套对象访问**：
   ```javascript
   const user = { info: { tell: '18001066666' } };
   console.log(user.info.name); // 输出: undefined
   ```
   因为 `info` 对象中没有 `name` 属性，同样返回 `undefined`。

### 开发避坑技巧（安全访问对象属性）
在访问对象属性前，必须先做判断，避免直接访问不存在的属性导致后续代码报错（如 `Cannot read properties of undefined`）。

**方法一：基础 `if` 判断**
```javascript
if (obj.gender) {
    console.log(obj.gender);
}
```
- **原理**：如果 `obj` 没有 `gender` 属性，其值为 `undefined`。在 `if` 条件中，`undefined` 会进行隐式类型转换，变为布尔值 `false`，从而不执行内部代码，安全避开报错。

**方法二：可选链操作符 `?.`（首选推荐）**
```javascript
console.log(obj?.gender); 
```
- **优势**：语法更加简洁，不需要啰嗦地写成 `if` 语句。如果 `obj` 没有 `gender` 属性，它会直接返回 `undefined` 而不会抛出错误。在实际开发中，**强烈建议使用可选链操作符**。
