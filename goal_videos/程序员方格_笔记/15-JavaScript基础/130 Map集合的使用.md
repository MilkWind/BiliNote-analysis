## Map 集合简介与特点 *Content-[00:00]

在了解了 `Set` 集合（无序、元素不允许重复、无索引、自动去重，底层类似散列存放）之后，我们来学习 `Map` 集合。

- **结构特点**：`Map` 集合不同于 `Set`，它的结构是**键值对（Key-Value）结构**，每一个元素都是一对键和值。
- **核心规则**：
  - 键不允许重复，如果键重复，则新的值会覆盖旧的值。
  - 根据键存值、根据键取值，**键是操作一切的核心**。
- **区别于传统对象（Object）**：
  - 传统对象也可以看作键值对（属性名与属性值），但传统对象的**属性名只能是字符串类型**。
  - 如果强行使用非字符串类型（如 DOM 对象）作为属性名，JavaScript 会自动将其转换为字符串。例如，将 `div` 元素作为属性名，它会被转换成 `[object HTMLDivElement]`，导致属性名变得极其复杂且难以使用。
  - **`Map` 集合的优势**：`Map` 的键可以是**任意类型**，完美解决了传统对象的这一弊端。

## Map 集合的初始化 *Content-[01:40]

`Map` 集合的初始化需要传入一个**二维数组**，数组中的每一个子数组代表一个键值对。

- **语法格式**：
  ```javascript
  let m = new Map([
      ["键1", "值1"],
      ["键2", "值2"],
      ["键3", "值3"]
  ]);
  ```
- **代码示例**：
  ```javascript
  let m = new Map([
      ["name", "张三"],
      ["age", 16]
  ]);
  ```
  *注意：由于是在数组中定义，字符串类型的键和值必须加上双引号。*
- **底层原理**：`Map` 集合没有索引（控制台显示的索引是假象），其底层依然是哈希（Hash）结构。`ES6` 提供的 `Map` 是一种语法糖，将其模拟成了键值对结构。

## Map 集合的基本使用（增删改查） *Content-[06:20]

`Map` 集合提供了一系列内置方法来实现数据的增删改查：

- **增加/修改（set）**：
  - 语法：`m.set(key, value)`
  - 示例：`m.set("city", "成都")` 增加新元素。
  - 覆盖：如果键已存在，则会修改对应的值。例如 `m.set("name", "小圆圆")` 会将 `name` 的值覆盖。
- **删除（delete）**：
  - 语法：`m.delete(key)`
  - 示例：`m.delete("city")` 根据键删除对应的元素。
  - 返回值：返回一个布尔值，表示是否删除成功。
- **查询（get）**：
  - 语法：`m.get(key)`
  - 示例：`m.get("age")` 根据键获取对应的值。

## Map 集合键为任意类型的深度解析 *Content-[08:40]

`Map` 最显著的特点就是**键可以是任意类型**，包括数值、字符串、布尔值、对象、数组甚至 DOM 元素。

- **多类型键示例**：
  ```javascript
  let m = new Map();
  m.set(5, "数值5");           // 数值作为键
  m.set(true, "布尔值true");   // 布尔值作为键
  
  let box = document.getElementById("box");
  m.set(box, "小盒子");        // DOM 元素作为键
  ```

- **⚠️ 核心避坑指南：对象作为键时的匿名对象问题**
  - 如果键是对象，**绝对要避免使用匿名对象（对象字面量）**，否则将无法二次取值。
  - **错误示范**：
    ```javascript
    m.set({name: "张三"}, "三国演义");
    console.log(m.get({name: "张三"})); // 输出 undefined
    ```
    *原因分析*：每次写 `{}` 都会在内存中创建一个全新的对象（相当于 `new` 一次）。两次写的匿名对象内存地址不同，因此 `Map` 认为它们是不同的键。
  - **正确做法**：将对象提取为变量（命名对象），保证内存地址一致。
    ```javascript
    let p = {name: "张三"};
    m.set(p, "三国演义");
    console.log(m.get(p)); // 正确输出 "三国演义"
    ```
    *数组作为键时同理，也必须使用变量保存引用。*

- **实际应用场景**：
  - 在进行页面 DOM 操作时，可以将每个 DOM 标签（如 `box`）直接作为 `Map` 的键，为其绑定对应的缓存数据。
  - 通过 DOM 对象直接获取其绑定的数据，无需在 DOM 上挂载自定义属性，非常优雅且高效。

## Map 的转换操作与 WeakMap 简介 *Content-[14:20]

- **其他常用方法**：
  - `m.clear()`：清空 `Map` 集合中的所有元素。
- **数据转换**：
  - `Map` 与数组可以相互转换。
  - `Map` 与传统对象的相互转换需要通过遍历（`for...of` 等）来实现。
  - `JSON` 与 `Map` 转换：由于 `JSON` 的键名默认都是字符串，可以通过 `JSON.parse()` 解析后，传入 `new Map()` 进行转换。
- **WeakMap 简介**：
  - `WeakMap` 与 `Map` 类似，但它的**键必须是对象**，且是一种**弱引用**。
  - **垃圾回收机制**：如果作为键的对象不再被其他地方使用（没有强引用），垃圾回收机制会立刻回收该对象，不会造成内存泄漏。
  - 其原理与 `WeakSet` 相似，适用于需要为对象绑定额外数据，但又不希望阻止对象被垃圾回收的场景。

本次视频详细讲解了前端 `ES6` 中 `Map` 集合的核心概念与使用方法。`Map` 作为一种键值对数据结构，突破了传统 `Object` 键名只能为字符串的限制，允许任意类型的数据作为键。在实际开发中，`Map` 的增删改查操作非常便捷，尤其在需要将 DOM 元素或复杂对象与数据绑定时，`Map` 展现出了极大的优势。同时，视频特别强调了使用对象作为键时必须使用变量引用，避免匿名对象导致的内存地址不一致问题。最后，简要介绍了 `WeakMap` 的弱引用特性及其在防止内存泄漏方面的应用。掌握 `Map` 及其相关特性，是应对前端大厂面试和解决实际工程问题的重要基础。
