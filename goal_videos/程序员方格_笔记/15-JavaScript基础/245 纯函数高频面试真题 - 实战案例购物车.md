## 购物车功能需求与纯函数概述 *Content-[00:00]
- **功能需求**：实现购物车逻辑，主要包括两个核心功能：
  1. 计算购物车中商品的总价。
  2. 新增商品（即往购物车中添加新的商品）。
- **核心要求**：上述两个功能的实现都必须基于**纯函数（Pure Function）**。

## 定义购物车原数据 *Content-[00:28]
- 首先定义购物车的初始数据，数据格式为包含商品对象的数组。
- 示例数据如下：
```javascript
const cart = [
  {
    id: 1,
    name: 'apple',
    price: 2,
    count: 3
  }
];
```
- **数据结构说明**：
  - `id`：商品唯一标识。
  - `name`：商品名称（如 `apple`）。
  - `price`：商品单价（如 2 元）。
  - `count`：商品数量（如 3 件）。

## 实现计算总价的纯函数 *Content-[01:27]
- 定义一个纯函数 `calculateTotal`，用于计算购物车中所有商品的总价，且**不会修改原购物车数据**。
- **函数参数**：接收一个数组参数 `cartItems`，数组的每个元素是一个商品对象。
- **实现逻辑**：使用数组的 `reduce` 方法遍历数组，累加每个商品的价格（`price`）乘以数量（`count`）。
- **代码实现**：
```javascript
function calculateTotal(cartItems) {
  return cartItems.reduce((total, item) => {
    return total + item.price * item.count;
  }, 0);
}
```
- **关键点**：`reduce` 方法的第二个参数 `0` 是累加的初始值。

## 验证计算总价纯函数的特性 *Content-[04:04]
- 调用 `calculateTotal` 函数并传入 `cart` 数组，打印结果验证。
```javascript
console.log(calculateTotal(cart)); // 输出结果应为 6 (2 * 3 = 6)
```
- **纯函数特性验证**：
  1. **无副作用（不修改外部变量）**：函数执行后，外部的 `cart` 数组结构和数据保持不变，依然是一个包含一个对象的数组。
  2. **相同输入产生相同输出**：只要传入相同的数据，每次计算的结果都固定为 6，不会发生改变。

## 实现添加商品的纯函数 *Content-[05:44]
- 定义一个纯函数 `addToCart`，用于向购物车中添加新商品，要求**返回一个新的购物车数组，且不会修改原数组**。
- **函数参数**：
  1. `cartItems`：原购物车商品数组（Array 类型）。
  2. `newItem`：要添加的新商品对象（Object 类型）。
- **实现逻辑**：断开引用关系，使用**展开运算符（Spread Operator）** 创建一个新数组，包含原购物车商品和新商品。
- **代码实现**：
```javascript
function addToCart(cartItems, newItem) {
  return [...cartItems, newItem];
}
```

## 验证添加商品纯函数的特性 *Content-[07:49]
- 调用 `addToCart` 函数，向购物车中添加一个新商品（如香蕉）。
```javascript
const newCart = addToCart(cart, {
  id: 2,
  name: 'banana',
  price: 1,
  count: 2
});
```
- **纯函数特性验证**：
  1. **验证原数组未被修改**：打印原数组 `cart`，确认其依然只包含 `apple` 对象，未被修改。如果被修改则违背了纯函数的定义。
  2. **验证新数组数据正确**：打印新数组 `newCart`，确认其包含了两个商品对象（`apple` 和 `banana`）。
- **结论**：通过展开运算符创建新数组，成功实现了不修改原数据的纯函数要求。
