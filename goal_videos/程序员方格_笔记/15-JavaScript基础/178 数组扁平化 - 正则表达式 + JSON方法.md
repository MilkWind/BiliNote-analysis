## 核心原理 *Content-[00:00]

本部分主要讲解使用 **正则表达式 + JSON 方法** 实现数组扁平化的核心思路。该方法逻辑简单，难点在于正则表达式的编写。

- **基本步骤**：
  1. 利用 `JSON.stringify()` 方法将多维数组转换为 JSON 字符串。
  2. 使用正则表达式匹配并替换掉字符串中的中括号 `[` 和 `]`，从而打破数组的嵌套结构。
  3. 最后通过 `JSON.parse()` 方法将处理后的字符串重新解析为数组，实现扁平化。
- **原理解析**：
  - JSON 字符串在转换时会保留数组的所有元素，仅去除数组的嵌套符号（即中括号）。
  - 去除中括号后，再将其还原成数组即可完成扁平化操作。

## 代码实现与优化 *Content-[01:55]

在实际代码编写中，经历了从初步实现到发现缺陷，再到最终优化的过程。

### 1. 初步实现思路
- **第一步：转换为 JSON 字符串**
  ```javascript
  let str = JSON.stringify(arr);
  ```
  - **注意点**：在此步骤中，数组里的空项（empty slots）和 `undefined` 会被自动转换为 `null`，需要特别留意。
- **第二步：正则替换与切割**
  - 使用正则表达式 `/\[|\]/g` 全局匹配并替换掉字符串中的左右中括号。
  - 替换完成后，使用 `split(',')` 方法通过逗号将字符串切割为数组。
  - **发现问题**：此时得到的是一个**字符串数组**，而原数组中的元素可能是数字或其他类型，直接切割会导致数据类型丢失，需要进一步处理。

### 2. 代码优化过程
- **尝试直接解析的误区**：
  - 如果尝试直接使用 `JSON.parse()` 解析 `split` 切割后的结果，会引发报错。因为直接解析普通的数组字符串不符合 JSON 对象的格式要求。
- **最终优化方案**：
  - 放弃使用 `split` 方法。
  - 直接使用正则表达式替换掉内部的中括号后，在字符串的**首尾手动拼接**上 `[` 和 `]`，使其重新成为一个合法的 JSON 数组字符串。
  - 最后直接使用 `JSON.parse()` 进行解析。
  ```javascript
  // 优化后的核心逻辑
  let str = JSON.stringify(arr);
  let flatStr = '[' + str.replace(/\[|\]/g, '') + ']';
  let res = JSON.parse(flatStr);
  ```
- **优化效果**：
  - 代码更加简洁，省去了不必要的中间步骤。
  - 能够完美处理包含对象等复杂数据类型的数组，保证数据还原时不丢失原有结构。

## 核心特点与面试技巧 *Content-[07:37]

在面试中，除了给出代码实现，清晰地阐述该方法的核心特点能够大幅提升面试官的评价。

- **核心特点**：
  1. **空项与 undefined 的副作用**：数组中的空项或 `undefined` 会被 `JSON.stringify()` 自动转换为 `null`。在实际业务开发中必须注意这一特性，避免引发数据错误。
  2. **数据类型保真**：除了上述的空项和 `undefined` 外，该方法支持任意类型的数组元素（如数字、字符串、对象等），数据不会失真。
- **面试技巧**：
  - 此方法属于**拓展解决方案**，思路非常巧妙。
  - 在面试时，如果能主动、清晰地说出上述特点（尤其是 `null` 转换的副作用），能充分展现你活跃的思维和对底层细节的掌握，**一定会获得加分**。
