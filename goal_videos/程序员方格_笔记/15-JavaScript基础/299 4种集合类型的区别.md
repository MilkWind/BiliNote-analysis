## 面试题引入与背景 *Content-[00:00]
- **面试题目**：介绍 `Set`、`Map`、`WeakSet`、`WeakMap` 这四种 ES6 新增集合类型之间的区别。
- **背景说明**：
  - 在 ES5 及更早版本中，前端主要的集合数据类型只有数组（Array）和对象（Object）。
  - ES6 诞生后，新增了多种集合类型，用于解决特定场景下的数据存储、去重和内存管理问题。
  - 掌握这四种集合类型的特征和适用场景，是前端面试中考察数据结构基础的重要环节。
- **答题思路**：要说明它们的区别，核心在于阐述各自独有的**特征**以及对应的**应用场景**，通过对比不同点来展现对数据结构的深入理解。

## 1. Set 集合详解 *Content-[02:31]
- **基本特征**：
  - **存储唯一值**：自动去除重复的值，只存储唯一的成员。
  - **键值一体**：可以理解为键和值是相同的（即值本身既是键也是值）。
  - **值类型多样**：存储的值可以是任意类型，包括原始值（Primitive）和引用类型（如对象）。
  - **支持迭代**：支持使用 `for...of`、`keys()`、`values()` 等方法进行遍历。
- **常用方法**：
  - `add()`：添加新元素。
  - `delete()`：删除指定元素。
  - `has()`：检查元素是否存在。
  - `clear()`：清空集合。
- **代码示例**：
  ```javascript
  const mySet = new Set([1, 2, 2, 3]);
  console.log(mySet); // 输出: Set(3) { 1, 2, 3 }，自动去重
  ```
- **应用场景**：
  - **数组去重**：利用其自动去重的特性，快速实现数组成员的去重，是日常开发中最常用的功能之一。
  - **检查元素是否存在**：使用 `has()` 方法检查元素是否存在，其底层基于哈希表，性能通常比数组的 `includes()` 方法更快。
  - **存储唯一标志**：例如存储唯一的用户 ID 集合，自动过滤重复数据，确保数据的唯一性。

## 2. Map 集合详解 *Content-[06:03]
- **基本特征**：
  - **键值对存储**：与 `Set` 不同，`Map` 存储的是“键-值”对（Key-Value）。
  - **键类型任意**：键可以是任意类型（包括对象、函数等），而普通对象的键只能是字符串或 `Symbol`。
  - **键的唯一性**：键必须是唯一的，如果添加重复的键，后面的值会覆盖前面的值。
  - **支持迭代与顺序保留**：支持 `for...of` 等迭代方式，并且会严格按照插入的顺序进行迭代。
- **常用方法**：
  - `set(key, value)`：添加或更新键值对。
  - `get(key)`：获取指定键对应的值。
  - `delete(key)`：删除指定键值对。
  - `clear()`：清空集合。
  - `size`：获取键值对的数量（注意是属性而非方法）。
- **代码示例**：
  ```javascript
  const myMap = new Map();
  const keyObj = {};
  myMap.set(keyObj, 'value');
  console.log(myMap.get(keyObj)); // 返回 'value'
  ```
- **应用场景**：
  - **需要复杂键的场景**：当需要使用对象或其他非字符串/`Symbol` 类型作为键时，`Map` 是最佳选择。
  - **保留插入顺序的键值对存储**：在需要严格依赖数据插入顺序的业务逻辑中（如渲染列表）。
  - **替代普通对象**：当普通对象的键可能不是字符串，或者需要频繁增删键值对且关注性能时，使用 `Map` 更为合适。

## 3. WeakSet 弱集合详解 *Content-[09:23]
- **基本特征**：
  - **仅存储对象**：成员必须是对象（引用类型），不能是原始值（如字符串、数字），否则会报错。
  - **弱引用（Weak Reference）**：对对象的引用是弱引用，不会阻止垃圾回收（Garbage Collection, GC）。如果对象在其他地方被销毁，`WeakSet` 中的引用也会自动消失。
  - **不可迭代**：没有 `keys()`、`values()` 等方法，无法直接遍历获取所有成员。
  - **无 size 属性**：无法获取集合的长度。
  - **自动去重**：继承了 `Set` 自动去重的特性，不会有重复的对象引用。
- **常用方法**：
  - `add()`、`delete()`、`has()`（注意：没有 `clear()` 方法）。
- **应用场景**：
  - **标记对象**：例如跟踪已处理的 DOM 元素，记录哪些元素已经被操作过，而不影响 DOM 元素的生命周期。
  - **避免内存泄漏**：当集合不需要长期持有对象引用时，使用 `WeakSet` 可以确保在 DOM 元素等对象被移除后，集合不会阻碍内存回收。

## 4. WeakMap 弱键值对集合详解 *Content-[12:11]
- **基本特征**：
  - **键必须是对象**：键只能是对象（弱引用），值可以是任意类型。
  - **键的弱引用**：键对象是弱引用，不会阻止垃圾回收。如果键对象被销毁，对应的键值对会自动从 `WeakMap` 中移除。
  - **不可迭代**：无法遍历，没有 `keys()`、`values()`、`entries()` 等方法。
  - **无 size 属性**：无法获取集合长度。
  - **键的唯一性**：与 `Map` 一样，键必须是唯一的。
- **常用方法**：
  - `set()`、`get()`、`delete()`、`has()`（注意：没有 `clear()` 方法）。
- **应用场景**：
  - **私有数据存储**：用于存储模块内部的状态，避免外部直接访问，实现数据封装。
  - **缓存数据**：当键对象可能被销毁时，对应的缓存值也会自动清理，有效避免内存泄漏。
  - **附加元素到对象**：例如为 DOM 元素记录额外的信息或元数据，当 DOM 元素被移除时，附加信息自动释放。

## 5. 四种集合类型对比总结 *Content-[14:16]
| 特性 | Set | Map | WeakSet | WeakMap |
| --- | --- | --- | --- | --- |
| **存储内容** | 唯一的值（任意类型） | 键值对（键任意类型，值任意类型） | 唯一的对象 | 键值对（键必须是对象，值任意类型） |
| **引用类型** | 强引用 | 强引用 | 弱引用（仅针对存储的对象） | 弱引用（仅针对键对象） |
| **是否可迭代** | 是 | 是 | 否 | 否 |
| **是否有 size** | 是 | 是 | 否 | 否 |
| **自动去重/键唯一**| 值自动去重 | 键唯一（重复键覆盖旧值） | 对象自动去重 | 键唯一（重复键覆盖旧值） |

## AI 总结
本次笔记详细解析了前端面试中高频考察的 ES6 四种集合类型：`Set`、`Map`、`WeakSet` 和 `WeakMap`。`Set` 和 `Map` 属于强引用集合，分别用于存储唯一值和任意类型的键值对，支持迭代且在日常开发中常用于数组去重和复杂键映射；而 `WeakSet` 和 `WeakMap` 属于弱引用集合，仅接受对象作为成员或键，其核心优势在于不会阻止垃圾回收，非常适合用于 DOM 元素标记、私有数据封装和缓存管理，以有效避免内存泄漏。理解它们的底层引用机制和迭代特性，是应对此类面试题的关键。
