## 纯函数的通俗定义与核心条件 *Content-[04:09]

### 通俗定义
纯函数就是**输入什么就输出什么，而且不会对外界造成任何影响**的函数。

### 两个必须同时满足的核心条件（铁律）
只要违反任意一条，该函数就不是纯函数：
1. **确定性**：相同的输入永远得到相同的输出。不管调用多少次，只要输入参数一样，结果就一定一样。
2. **无副作用**：函数内部只做计算、只处理数据，不会修改外部的任何东西，也不会对外界造成任何影响。

### 生活案例：榨汁机
- **确定性**：放入苹果，就输出苹果汁（可预测的输出）。不可能放入苹果却随机输出其他果汁。
- **无副作用**：不会改变放入的水果原数据，也不会偷偷影响厨房里的其他物品（比如把西瓜变了）。

## 核心条件一：确定性详解与代码实现 *Content-[06:30]

确定性意味着“一碗水端平”。
- **生活对比**：$1 + 1 = 2$ 永远成立，具有确定性；而抛硬币有时正面有时反面，没有确定性。

### 代码案例1：标准的纯函数 `add`
以下代码是一个满足确定性的标准纯函数：

```javascript
// 功能描述：接收两个数字参数，返回它们的和
function add(a, b) {
    // 函数内部只做一件事：计算 a 和 b 的和，不碰外部任何东西
    return a + b;
}

// 测试多次调用，看结果是否一致
console.log(add(1, 2)); // 第一次调用，输出: 3
console.log(add(1, 2)); // 第二次调用，输出: 3
console.log(add(1, 2)); // 第三次调用，输出: 3
```

**结论**：相同输入（$1$ 和 $2$）永远得到相同的输出（$3$），完美满足纯函数的**确定性**。

## 非纯函数案例分析：Math.random() *Content-[10:30]

通过对比非纯函数，可以更好地理解确定性的概念。

### 代码案例2：非纯函数 `getRandom`
以下代码是一个典型的非纯函数：

```javascript
// 功能描述：无参数，返回一个随机数
function getRandom() {
    // Math.random() 每一次调用返回的结果都不一样
    return Math.random();
}

// 测试多次调用
console.log(getRandom()); // 第一次调用，输出: 随机数 A
console.log(getRandom()); // 第二次调用，输出: 随机数 B
console.log(getRandom()); // 第三次调用，输出: 随机数 C
```

**分析**：
- **输入**：相同（无参数）。
- **输出**：不一样（每次都是不同的随机数）。

**结论**：因为输入相同但输出不同，它违反了**确定性**，因此**不是**一个纯函数。

## 互动测试：Math.floor() 是纯函数吗？ *Content-[13:46]

**测试代码**：`Math.floor(5.8)`

**答案解析**：
它是**纯函数**。

**原因**：
1. **满足确定性**：输入 $5.8$，不管调用多少次，`Math.floor(5.8)` 的结果永远是 $5$（相同输入相同输出）。
2. **满足无副作用**：它只是进行向下取整的数学计算，没有修改任何外部数据或产生副作用。

## AI 总结 *Content-[14:45]

本节课深入解析了前端高频面试题“纯函数”的核心概念。纯函数必须同时满足**确定性**（相同输入永远得到相同输出）和**无副作用**（不修改外部状态）两个核心条件。通过 `add` 函数的正例和 `Math.random()` 的反例对比，清晰展示了确定性的判断标准。此外，明确了像 `Math.floor()` 这样纯粹的数学计算方法也属于纯函数。掌握这些概念是应对大厂前端面试及编写高质量、可预测代码（如 Redux reducer）的基础。
