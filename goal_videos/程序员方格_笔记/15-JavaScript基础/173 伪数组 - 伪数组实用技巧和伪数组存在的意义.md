## 伪数组的实用技巧 *Content-[00:00]

在开发中，如果只是临时调用一次数组方法，无需将伪数组（如 `arguments`）转换为真数组。可以通过 `call` 或 `apply` 直接让数组方法的 `this` 指向伪数组，从而实现调用并节省性能。

### 1\. 语法原理
- 借用数组构造函数原型（`Array.prototype`）上的数组方法。
- 使用 `.call()` 方法，将第一个参数设置为伪数组，从而改变方法的 `this` 指向，使其指向伪数组，进而直接调用。

### 2\. 代码演示

#### 2.1 使用 `forEach` 遍历
```javascript
function get() {
    // arguments 是一个伪数组，注意 arguments 不能大写
    const likeArray = arguments; 
    
    // 可以通过 Array.isArray() 确认，它会返回 false，证明不是真数组
    // 直接调用 forEach 方法
    Array.prototype.forEach.call(likeArray, function(item) {
        console.log(item); // 打印数组里的每一项
    });
}
get(1, 2, 3, 4, 5);
```
- **解析**：`likeArray` 本质是伪数组，无法直接调用 `forEach`。通过 `Array.prototype.forEach.call` 将 `this` 指向 `likeArray`，即可成功遍历。

#### 2.2 使用 `map` 处理数据
```javascript
function get() {
    const likeArray = arguments;
    
    // 使用 map 处理数据，将每一项乘以 2
    const res = Array.prototype.map.call(likeArray, function(item) {
        return item * 2; // 注意这里必须有 return
    });
    
    console.log(res); // 输出: [2, 4, 6, 8, 10]
}
get(1, 2, 3, 4, 5);
```
- **解析**：通过 `map` 方法对伪数组中的每一项进行处理，并返回一个新的真数组结果。

#### 2.3 使用 `reduce` 累加数据
```javascript
function get() {
    const likeArray = arguments;
    
    // 使用 reduce 进行累加
    const res = Array.prototype.reduce.call(likeArray, function(prev, curr) {
        return prev + curr;
    }); 
    // 也可以传入第二个参数作为初始值，例如 Array.prototype.reduce.call(likeArray, callback, 0)
    
    console.log(res); // 输出: 15 (1+2+3+4+5)
}
get(1, 2, 3, 4, 5);
```
- **解析**：`reduce` 的第二个参数（初始值）是可选的。如果不传，`prev` 的初始值就是数组的第 0 项（即 1）；如果传入（如 `0`），则 `prev` 从该初始值开始累加。

### 3\. 技巧优势
- **无需创建新数组**：在转换前直接操作，避免了额外的内存开销。
- **高效**：在只需要临时调用一次数组方法时，这种“借用”方式比先转换（如使用 `Array.from` 或扩展运算符）再调用更加高效，是开发中的常用技巧。

## 伪数组存在的意义 *Content-[06:31]

在大厂面试中，经常会遇到拓展题：“为什么 JS 中要设计伪数组？直接用真数组不好吗？” 回答时可以从 **JS 设计的初衷** 和 **实际应用** 两个角度来阐述，以展现对语言底层的深入理解。

### 1\. 适配数组式遍历
- **降低开发成本**：浏览器或 JS 引擎设计伪数组，是为了让开发者能够使用熟悉的数组遍历方式（如 `for` 循环、`forEach` 等）来操作 DOM 集合、函数参数（`arguments`）等。
- **统一操作体验**：使得普通的对象也能正常使用数组的方法，提供了类似数组的操作体验。

### 2\. 性能优化
- **实时获取**：DOM 伪数组（如 `HTMLCollection`、`NodeList` 等动态集合）是实时获取 DOM 元素的。
- **节省内存**：无需提前创建真数组来存储这些元素，避免了不必要的内存占用，从而提升了页面的渲染和执行性能。

### 3\. 符合语言设计
- **灵活的对象结构**：在 JS 中，对象是最灵活的结构。伪数组的本质其实就是对象。
- **模拟数组**：利用对象的键值对特性（数字索引作为键，元素作为值，以及 `length` 属性）来模拟数组，这完全符合 JS “一切皆对象”的设计思想。

### 4\. 兼容历史代码
- **向后兼容**：伪数组的设计初衷之一是为了兼容早期的 JS 代码，保证历史项目能够正常运行。
- **核心原则**：这符合 JS 向后兼容的核心原则。类似于 `typeof null === 'object'` 这个著名的历史 Bug，都是为了保持向前兼容而保留的设计。
