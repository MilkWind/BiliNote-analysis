## 修改原型指向 (`__proto__`) *Content-[00:00]

- **核心原理**：
  将伪数组的 `__proto__` 直接指向数组构造函数的 `prototype`（即原型对象），从而让伪数组继承数组的所有方法。
- **本质解析**：
  这种方法本质上是修改对象的原型链。它并非创建了一个新数组，而是让原来的伪数组对象直接拥有了数组的方法。
- **语法示例**：
  ```javascript
  伪数组.__proto__ = Array.prototype;
  ```
- **具体演示**：
  1. 自定义一个伪数组对象。
  2. 执行 `伪数组.__proto__ = Array.prototype;` 修改其原型指向。
  3. 修改后，该对象即可调用数组上的方法（例如调用 `push` 方法不会报错）。
  4. 调用 `push` 添加元素后，对象的 `length` 属性也会正确更新（例如 push 一个元素后，`length` 变为对应的值）。
- **缺点与注意事项**：
  - **不推荐使用**：修改原型链会改变原对象的结构，容易引发未知的继承或原型链问题。
  - **适用场景**：仅作为面试拓展知识了解，实际开发中严禁使用，不要贸然修改对象的原型指向。

## 使用 ES6 Rest 参数替代 arguments *Content-[03:00]

- **核心原理**：
  这是一种针对性方法，专门用于处理函数中的 `arguments` 伪数组。通过 ES6 的 Rest 参数，直接将函数的实参转换为真数组，从而完美替代 `arguments`。
- **语法示例**：
  在函数参数中使用 `...` 展开，例如：
  ```javascript
  function fn(...args) {
      // args 即为真数组
  }
  ```
- **具体演示**：
  1. 定义函数 `function fn(...args) { console.log(args); console.log(Array.isArray(args)); }`。
  2. 调用函数并传入参数（如 `fn(5)`）。
  3. 打印结果显示 `args` 是一个真数组，且 `Array.isArray(args)` 验证返回 `true`。
  4. 作为真数组，可以正常使用所有的数组方法和属性。
- **核心优势**：
  - **完美兼容箭头函数**：箭头函数内部没有自己的 `arguments` 对象，使用 Rest 参数可以完美解决这一问题。
- **开发建议**：
  在实际开发中，**首选推荐**使用 Rest 参数来替代 `arguments`，既安全又高效。

## 面试常见问题解答 *Content-[05:44]

1\. **将伪数组转为真数组的 ES6 首选方法是什么？**
   - **答案**：`Array.from()`。这是 ES6 中转换伪数组最好、最标准的方法。

2\. **使用扩展运算符（`...`）将伪数组转为真数组的前提条件是什么？**
   - **答案**：该伪数组必须具备 `Iterator` 接口（即必须是可遍历/可迭代的）。

3\. **ES6 中如何替代 `arguments` 伪数组？**
   - **答案**：使用 **Rest 参数**（`...args`）。
