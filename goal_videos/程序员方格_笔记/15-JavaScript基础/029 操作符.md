## 一元操作符 *Content-[00:14]*
一元操作符是只作用于一个值的操作符，主要包括以下几类：
- **递增（`++`）与递减（`--`**：最常见的操作符，用于对数值进行加一或减一操作。
  - 示例：`let age = 29; age++;`，执行后 `age` 的值变为 `30`。
- **一元加号（`+`）与一元减号（`-`**：
  - 当它们作用于非数值类型的值前面时，会尝试将该值转换成数字。
  - 这是一种非常快捷的类型转换方式。
  - 示例：`+"25"`，会将字符串 `"25"` 快速转换为数字 `25`。

## 位操作符 *Content-[01:02]*
位操作符直接处理数值在内存中的二进制位，通常用于性能敏感或底层操作的场景（如特定算法、底层开发）。
- **逻辑位运算**：
  - 包括按位非（`~`）、按位与（`&`）、按位或（`|`）、按位异或（`^`）。
  - 它们会对两个数值的每一个二进制位进行逻辑运算。
- **移位运算**：
  - 包括左移（`<<`）和右移（`>>`），用于移动数值的所有二进制位。
- **代码示例**：
  - `25 & 3`（按位与）：将 25 和 3 转换为二进制后逐位进行与运算，结果为 `1`。
  - `25 | 3`（按位或）：逐位进行或运算，结果为 `27`。

## 布尔操作符 *Content-[03:11]*
布尔操作符用于处理逻辑运算，主要包括逻辑非、逻辑与和逻辑或。
- **逻辑非（`!`**：将一个值转换成布尔值后取反。
  - 示例：`!true` 的结果为 `false`。
- **逻辑与（`&&`）与逻辑或（`||`）的短路操作**：
  - **逻辑与短路**：如果第一个操作数（A）为 `false`，系统不会再评估第二个操作数（B），直接返回 `false`。
  - **逻辑或短路**：如果第一个操作数为 `true`，系统不会再评估第二个操作数，直接返回第一个操作数的值。
  - **应用场景**：短路特性经常被用来设置默认值或进行条件执行。

## 乘性与加性运算符 *Content-[04:28]*
- **乘性运算符**：
  - 包括常规的乘（`*`）、除（`/`）、取模（`%`）。
  - ES6 新增了幂运算符（`**`），用于计算一个数的多少次方。
- **加性运算符**：
  - **减法（`-`）**：比较直接，会尝试将操作数转换成数字后再相减。
    - 示例：`5 - "2"`，字符串 `"2"` 被转换为数字 `2`，进行数学减法后得到数字 `3`。
  - **加法（`+`）的特殊性**：
    - 如果两个操作数都是数字，则执行数学加法。示例：`5 + 5` 结果为 `10`。
    - 只要其中有一个操作数是字符串，就会将另一个操作数也转换成字符串，然后进行拼接。
    - 示例：`5 + "5"`，数字 `5` 被转换为字符串 `"5"`，拼接后得到字符串 `"55"`。

## 关系操作符与相等操作符 *Content-[06:20]*
- **关系操作符（`>`, `<`, `>=`, `<=`）**：
  - 用于比较两个值的大小。
  - 如果操作数不是数字，JavaScript 会尝试将它们转换成数字再进行比较。
  - 如果两个操作数都是字符串，则会逐位比较它们的字符编码值。
- **相等操作符**：
  - **相等（`==`）与不相等（`!=`）**：
    - 在比较之前，会先对不同类型的操作数进行**强制类型转换**，试图将它们变成同一类型再进行比较。
    - 示例：`"5" == 5` 结果为 `true`（字符串 `"5"` 被强制转换为数字 `5`）。
    - 示例：`null == undefined` 结果为 `true`。
    - 示例：`1 == true` 结果为 `true`（`true` 被转换为 `1`）。
  - **全等（`===`）与不全等（`!==`）**：
    - 判断非常严格，如果两个操作数的类型不相同，直接返回 `false`，**根本不会尝试做类型转换**。
    - 示例：`5 === "5"` 结果为 `false`。
    - 示例：`null === undefined` 结果为 `false`。
    - 示例：`1 === true` 结果为 `false`。
  - **最佳实践**：
    - 为了代码的健壮性和可预测性，**始终应该使用全等（`===`）和不全等（`!==`）**。
    - `==` 的隐式类型转换规则特别复杂且容易出错，是许多 Bug 的来源。使用 `===` 可以让代码意图更清晰，确保比较的是值和类型都完全一致的情况。

## 条件、空值合并与赋值操作符 *Content-[09:49]*
- **条件操作符（三元操作符）**：
  - 由问号（`?`）和冒号（`:`）组成，是 `if...else` 语句的紧凑形式，非常适合在简单的赋值场景中使用。
- **空值合并操作符（`??`）**：
  - ES2020 引入的新成员。
  - **逻辑**：如果左侧表达式的结果是 `null` 或 `undefined`，则整个表达式的结果为右边的值；否则为左边的值。
  - **与逻辑或（`||`）的区别**：
    - `||` 会对所有的假值（falsy values，如 `0`、空字符串 `""`、`false`、`null`、`undefined`）起作用。
    - `??` 只关心 `null` 或 `undefined`。
  - **优势**：在希望 `0` 或空字符串被视为有效值的场景下，使用 `??` 是更加优秀的选择。
- **赋值操作符**：
  - 最基础的是等号（`=`）。
  - **复合赋值操作符**：如 `+=`、`-=` 等，是将操作结果赋值给左边变量的简写形式，能让代码更加简洁。
  - 示例：`a += 5` 等同于 `a = a + 5`。
