## pop 方法简介与核心特点 *Content-[00:00]

- **方法作用**：`pop` 方法的主要作用是删除数组的最后一个元素，并返回被删除的元素。
- **执行限制**：每一次调用 `pop` 只能删除一个元素。如果想要通过该方法清空数组，需要借助循环一直执行，直到数组长度为零。
- **核心特点**：
  1. **不会断开数组的引用**：原数组和引用该数组的新变量会同步被清空。
  2. **性能极差**：原数组中的元素越多，需要执行的循环次数就越多。
  3. **重复计算长度**：每一次执行 `pop` 操作时，都会重新计算数组的长度。
  4. **不推荐使用**：在实际开发和面试中，均不推荐使用此方法来清空数组。
- **面试应对策略**：
  - 尽管不推荐，但 `pop` 清空数组确实是一个知识点。
  - 如果在面试中提及该方法，**必须完整答出**其“性能极差、元素越多循环次数越多、每次 `pop` 会重新计算数组长度”的特点。
  - 如果无法说全这些缺点，不如不提，这与面试中讨论 `delete` 运算符的策略是一样的。

## 基础示例与代码演示 *Content-[02:08]

- **测试数据准备**：使用数组 `[1, 2, 3, 4, 5]` 进行测试。
- **代码实现逻辑**：
  - 使用 `while` 循环，执行条件为数组长度大于 `0`（即 `arr.length > 0`）。
  - 在循环体内直接调用 `pop` 方法，逐个删除最后一个元素。
  - 由于每次删除后数组长度会自动减少，因此不需要在条件判断中手动递减长度。
- **代码示例**：
  ```javascript
  let arr = [1, 2, 3, 4, 5];
  let newArr = arr; // 保持引用关系

  // 当数组长度大于 0 时，一直执行 pop 方法
  while (arr.length > 0) {
      arr.pop(); // 逐个删除最后一个元素
  }
  ```
- **运行结果验证**：
  - 执行完毕后，原数组 `arr` 和新数组 `newArr` 均为空。
  - 这验证了 `pop` 方法“不会断开数组引用、同步清空”的特点。

## 性能分析与原理探讨 *Content-[03:40]

- **性能结论**：随着数组中元素数量的增加，使用 `pop` 方法清空数组会变得非常缓慢。在处理大量数据时，**绝对不要使用**该方法。
- **原理推断**：
  - 无需通过代码进行实际的性能测试，通过清空数组的底层原理即可推断出其性能较差。
  - **形象类比**：这就好比从箱子里拿球，每次只能拿最上面的（最后一个）一个球。箱子里的球越多，需要拿的次数就越多，整体效率自然就越低。通过这种逻辑推导，可以清晰地理解其性能瓶颈。
