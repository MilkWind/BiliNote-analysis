## 1. 文件上传的基本实现 *Content-[00:00]

在前端开发中，文件上传是一个非常基础且常见的功能。其核心实现思路如下：

*   **原生标签支持**：文件上传的核心是依赖浏览器原生的 `<input>` 标签，将其 `type` 属性设置为 `file`。此时该标签原生支持文件选择功能。
*   **获取文件对象**：当用户通过该标签选择文件后，可以通过事件监听获取到对应的文件对象（File 对象）。
*   **封装与上传**：获取到文件对象后，使用 `FormData` 对象将文件数据封装起来，最后通过 HTTP 请求（如 POST）将 `FormData` 发送到服务器，从而完成上传流程。

> **面试建议**：面试时无需死记硬背具体的代码细节，重点在于能够清晰、流畅地阐述上述核心思路和实现流程。

## 2. 分片上传的原理与实现 *Content-[01:17]

当面对超大文件（如几十 GB 的视频文件）时，一次性上传往往会面临超时或失败的风险，此时就需要使用**分片上传**技术。

### 分片上传的核心概念
将大文件分割成许多较小的片段（分片），然后逐片或并行上传到服务器。

### 分片上传的三大优点
1.  **支持大文件**：突破了浏览器或服务器对单次上传文件大小的限制。
2.  **提升上传速度**：支持多个分片并行上传，充分利用网络带宽。
3.  **支持断点续传**：如果网络波动导致某个分片上传失败，只需重新上传该失败的分片，而无需重新上传整个文件，极大提升了用户体验。

### 分片上传的实现思路
虽然实际生产环境中的分片上传逻辑非常复杂（需处理并发、重试、进度合并等），但其基本原理如下：
1.  通过 `<input type="file">` 获取 File 对象。
2.  定义每个分片的大小（例如 1MB，即 $1024 \times 1024$ 字节）。
3.  计算分片总数：`文件总大小 / 分片大小`。
4.  使用 `for` 循环遍历，每次计算当前切片的 `start` 和 `end` 索引。
5.  调用 File 对象的 `slice(start, end)` 方法，切分出当前分片（chunk）。
6.  将切分出的 chunk 放入新的 `FormData` 中。
7.  通过 POST 请求向后台上传该分片，循环执行直到所有分片上传完毕。

## 3. File 对象与 Blob 对象的区别 *Content-[03:45]

在面试中，File 对象和 Blob 对象的区别是一个高频考点。两者都表示一个二进制的数据块，且 File 对象继承自 Blob 对象。

### File 对象
*   **特点**：除了包含二进制数据外，还包含了文件的**元数据**（Metadata），例如文件名（name）、文件类型（type）、最后修改时间（lastModified）等。
*   **使用场景**：通常用于表示用户通过 `<input type="file">` 从本地文件系统选择的文件。

### Blob 对象
*   **特点**：表示一个与文件系统无关的、原始的二进制数据块，不包含文件系统的元数据信息。
*   **使用场景**：通常用于表示通过 Ajax/Fetch 请求获取的二进制数据，或者由代码动态生成的二进制数据（如 Canvas 导出的图片数据）。

### 总结
Blob 是更基础的对象，File 继承自 Blob 并扩展了文件相关的元数据属性。可以理解为 File 是 Blob 的特化子类。

## 4. Object.defineProperty 的作用 *Content-[05:05]

`Object.defineProperty` 是 ES5 引入的重要 API，主要用于精确地定义或修改对象上的属性。

*   **核心作用**：实现对**单个属性**的代理和拦截。
*   **属性描述符**：可以通过配置描述符来控制属性的多种特性：
    *   `value`：属性的值。
    *   `writable`：属性是否可写。
    *   `enumerable`：属性是否可枚举（如能否在 `for...in` 循环中遍历到）。
    *   `configurable`：属性是否可删除或修改其描述符。
*   **访问器属性**：支持配置 `get` 和 `set` 方法，从而在读取或设置属性值时执行自定义逻辑。这也是 Vue 2 实现数据响应式原理的核心基础。

## 5. Proxy 代理对象的作用 *Content-[05:34]

`Proxy` 是 ES6 引入的用于创建代理对象的 API，它解决了 `Object.defineProperty` 的一些局限性。

*   **核心作用**：创建一个代理对象，实现对**整个对象**的代理和拦截，而不仅仅是单个属性。
*   **与 defineProperty 的本质区别**：`defineProperty` 只能劫持对象的已知属性，对于新增属性无法拦截；而 `Proxy` 可以直接代理整个对象，拦截范围更广，支持属性查找、赋值、枚举、函数调用等多种操作的拦截。
*   **基本使用**：
    ```javascript
    const proxy = new Proxy(target, handler);
    ```
    *   `target`：要代理的目标对象。
    *   `handler`：一个对象，包含拦截各种操作的方法（如 `get`、`set` 等）。这也是 Vue 3 实现数据响应式原理的核心基础。

## 6. Reflect 的作用与使用 *Content-[06:21]

`Reflect` 是 ES6 引入的内置对象，提供了一系列拦截 JavaScript 操作的方法。

*   **核心作用**：通常与 `Proxy` 配合使用，用于在 Proxy 的拦截器中调用默认行为，保证代理对象内部的操作行为与原生行为保持一致。
*   **基本使用示例**：
    *   `Reflect.get(obj, 'x')`：等价于直接读取 `obj.x`。
    *   `Reflect.set(obj, 'x', value)`：等价于直接赋值 `obj.x = value`。
*   **功能丰富**：除了 `get` 和 `set`，`Reflect` 还提供了 `has`、`deleteProperty`、`apply` 等非常丰富的方法来操作对象，具体可查阅 MDN 官方文档。

## 7. ES6 中 super 与 static 的作用 *Content-[07:38]

在 ES6 的 `class` 语法中，`super` 和 `static` 是两个非常重要的关键字。

### super 的作用
*   在类的继承中，`super` 用于调用父类的构造函数 `constructor`。
*   子类必须在自己的 `constructor` 中调用 `super()`，然后才能使用 `this` 对象，否则会导致报错。

### static 的作用
*   用于在 `class` 中定义**静态方法**或**静态属性**。
*   静态成员属于类本身，而不属于类的实例对象。
*   **访问方式**：无需实例化（不需要使用 `new` 关键字），直接通过类名进行访问。例如，定义 `static name = 'jack'`，则直接通过 `App.name` 即可访问该静态属性。
