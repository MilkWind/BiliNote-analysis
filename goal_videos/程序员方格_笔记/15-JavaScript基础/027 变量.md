## 1. JavaScript 变量的松散类型 *Content-[00:01]
- **核心特点**：JavaScript 变量最显著的特点是**松散类型**（动态类型），这与 Java、C++ 等静态类型语言完全不同。
- **与静态类型的对比**：在 Java、C++ 等语言中，声明变量时必须指定类型，且之后不能更改；而在 JavaScript 中，变量的类型是动态的，在程序的不同执行阶段，可以用来保存不同类型的数据。
- **设计优势**：这种设计带来了极大的灵活性，声明变量时无需预先确定其存储的数据类型。
- **代码示例**：
  - 声明变量 `myVar` 并赋值为字符串 `"hello"`，使用 `typeof` 检测其类型为 `string`。
  - 将数字 `123` 赋值给 `myVar`，其类型动态变为 `number`。
  - 将布尔值 `true` 赋值给 `myVar`，其类型变为 `boolean`。
  - 整个过程完全合法，充分体现了 JavaScript 变量类型的松散性。

## 2. var 关键字及其特性 *Content-[01:33]
- **历史背景**：在 ES6 标准出现之前，`var` 是声明变量的唯一选择。
- **核心特点**：
  - **函数作用域**：用 `var` 声明的变量在其所在的整个函数内部都可以访问，无论声明语句在函数内的哪个位置。
  - **变量提升**：变量的声明部分会被引擎移动到函数体的最前面，但赋值部分保留在原位置。
  - **可重复声明**：可以在同一作用域内重复声明同一个变量而不会报错。
- **代码示例（变量提升）**：
  - 在 `testVar` 函数中，先使用 `console.log(myVar)` 打印，然后再声明并赋值 `var myVar = "hello"`。
  - 直觉上第一行可能会报错，但实际输出的是 `undefined`。
  - **原理解析**：JS 引擎在执行前，会将 `var myVar` 的声明操作提升到函数顶部。因此第一次打印时，`myVar` 已被声明但尚未赋值，故为 `undefined`；随后的赋值语句执行后，第二次打印才正确输出 `"hello"`。

## 3. let 关键字及其特性 *Content-[03:46]
- **引入背景**：由于 `var` 存在诸多问题，ES6 引入了 `let`，它是现代 JS 中声明变量的首选方式之一。
- **核心特点**：
  - **块作用域**：变量的生命周期被严格限制在声明时所在的花括号内（如 `if` 语句块、`for` 循环块或独立的花括号块）。
  - **无变量提升与暂时性死区（TDZ）**：`let` 不会像 `var` 那样发生变量提升。在块作用域中，从开始到 `let` 声明语句的这部分区域称为“暂时性死区”（Temporal Dead Zone）。在此期间，任何对该变量的访问都会导致错误。
  - **不允许重复声明**：不允许在同一个作用域内重复声明同一个变量，使代码更加严谨。
- **代码示例**：
  - **块作用域**：在 `if` 语句内，`myLet` 可以被正常访问；但一旦出了花括号，再次访问 `myLet` 就会直接报错，因为已超出块作用域。
  - **暂时性死区（TDZ）**：`console.log(myLet)` 位于 `let myLet` 声明之前，处于暂时性死区内。这行代码会立即抛出 `ReferenceError` 错误，而不是像 `var` 那样输出 `undefined`。

## 4. const 关键字及其特性 *Content-[05:59]
- **引入背景**：ES6 还提供了 `const` 声明方式，专门用来声明常量。
- **基础特性**：`const` 的大部分特性（如块作用域、无变量提升、暂时性死区）与 `let` 完全一样。
- **独特规定**：
  - **必须立即初始化**：声明时必须马上进行初始化赋值，否则会报错。
  - **值不可变**：
    - 对于**原始类型**（如数字、字符串），`const` 保证了其值本身不会被改变。
    - 对于**复杂类型**（如对象、数组），`const` 只是保证变量所指向的**内存地址**不会改变。因此，不能让该变量再指向另一个对象，但完全可以修改该对象的内部属性。
- **代码示例**：
  - 尝试修改 `const` 声明的原始类型变量 `pi`，会立即得到 `TypeError`（类型错误）。
  - 用 `const` 声明一个 `person` 对象，修改 `person.name` 属性是合法的，因为没有改变 `person` 变量指向的内存地址。
  - 如果尝试将一个全新的对象赋值给 `person`（试图改变其引用），则会立即报错。

## AI 总结 *Content-[08:04]
本节课详细讲解了 JavaScript 中变量声明的三种方式及其核心特性。首先介绍了 JS 变量松散（动态）类型的本质，随后对比了 `var`、`let` 和 `const` 的区别：`var` 具有函数作用域和变量提升特性，易引发作用域污染问题；`let` 引入了块级作用域和暂时性死区（TDZ），解决了变量提升带来的隐患，是现代开发的首选；`const` 则在 `let` 的基础上增加了不可重新赋值的限制，用于声明常量，但需注意其对引用类型仅保证内存地址不变的特性。掌握这三者的区别与作用域规则，是应对前端面试和编写严谨 JS 代码的基础。
