## 2. 什么是原型（Prototype） *Content-[02:07]
- **基本定义**：每一个 JavaScript 对象（注意：必须是对象，而非普通变量）都有一个隐藏的 `prototype` 属性。
- **访问方式**：通过 `对象.prototype` 的写法，可以指向该对象的原型对象。
- **本质特征**：
  - 原型对象本身也是一个普通的对象，内部包含属性和方法。
  - **核心区别**：原型对象中的属性和方法是可以被**所有实例共享**的，而不是仅供单个实例私有使用。

## 3. 原型的作用 *Content-[03:42]
- **避免重复定义**：因为原型中的属性和方法可以被共享，实例可以直接访问并使用原型上的方法，从而避免了在每个实例中重复定义相同的方法，节省内存。
- **实现继承关系**：通过原型链机制，可以实现对象之间的继承。如果没有原型，就无法形成原型链，自然也就无法实现继承关系。继承的诞生进一步省去了大量方法和属性的重复定义。

## 4. 原型代码示例解析 *Content-[05:08]
- **定义构造函数**：定义一个普通的构造函数 `Person`，接收 `name` 参数并赋值给实例属性。
- **给原型添加方法**：
  ```javascript
  Person.prototype.sayName = function() {
      console.log(this.name);
  };
  ```
- **实例化与调用**：
  ```javascript
  const p1 = new Person('张三');
  p1.sayName(); // 成功输出
  ```
- **执行原理**：实例 `p1` 自身并没有 `sayName` 方法，但通过 `prototype` 属性指向了 `Person` 的原型对象，从而成功调用并执行了原型上的方法。

## 5. 什么是原型链（Prototype Chain） *Content-[07:20]
- **查找机制**：当访问一个对象的属性或方法时，JavaScript 首先会在**对象自身**进行查找。
- **向上查找**：如果自身找不到，就会沿着 `prototype` 链**向上查找**。
- **终止条件**：一直向上查找，直到原型链的顶端出现 `null` 为止。如果直到 `null` 仍未找到，则返回 `undefined`。
- **核心意义**：这种链式的查找机制扩展了寻找属性和方法的渠道，被称为**原型链**。它使得对象能够访问其继承链上所有父级原型的属性和方法。

## 6. 原型链代码示例解析 *Content-[09:32]
- **定义父级原型**：定义 `Animal` 构造函数，并在其原型上添加 `eat` 方法。
  ```javascript
  function Animal() {}
  Animal.prototype.eat = function() {
      console.log('吃东西');
  };
  ```
- **实现继承**：定义 `Dog` 构造函数，并将 `Dog.prototype` 指向 `new Animal()`（即 Animal 的实例）。
  ```javascript
  function Dog() {}
  Dog.prototype = new Animal();
  ```
- **实例化与调用**：
  ```javascript
  const dog = new Dog();
  dog.eat(); // 成功输出
  ```
- **执行原理**：`dog` 自身和 `Dog.prototype` 都没有 `eat` 方法，但沿着原型链向上查找，找到了 `Animal.prototype` 上的 `eat` 方法并成功执行。所有的原型链最终都会指向 `null`，表示查找结束。

## 7. 原型与原型链的特点及注意事项 *Content-[12:46]
- **共享属性与方法（节省内存）**：原型上的属性和方法被所有实例共享，有效节省内存。
- **引用类型陷阱**：
  - 如果原型上的属性是**引用类型**，某个实例修改该属性时，会影响所有其他实例。
  - **建议**：与业务强相关、每个实例不同的属性不应放在原型上；原型上只放置常用且每个实例都会用到的共享方法。
- **动态修改影响全局**：
  - 即使实例已经创建完毕，动态修改原型上的方法或属性，也会立即影响所有已创建的实例（具有动态性）。
- **性能考量**：
  - 原型链查找比直接访问对象自身属性要**慢**。
  - **建议**：不要频繁通过原型链去查找属性，频繁访问的属性建议直接放在实例自身中，以提升代码执行性能。

## AI 总结
原型（Prototype）是 JavaScript 面向对象编程的核心，它允许对象共享属性和方法，从而避免重复定义并实现继承。原型链（Prototype Chain）则是 JavaScript 的属性查找机制，当对象自身找不到属性时，会沿着 `prototype` 向上逐级查找，直到 `null`。在面试和实际开发中，需深刻理解原型的共享特性及其带来的内存优势，同时警惕引用类型属性被意外修改的陷阱。此外，出于性能考虑，高频访问的属性应直接定义在实例自身，而非依赖原型链查找。
