## 面试题题目与输出结果 *Content-[00:01]
本视频讲解了一道经典的前端面试题，主要考察对 JavaScript 中对象引用和地址赋值的理解。

**题目代码：**
```javascript
let a = { n: 1 };
let b = a;
a.x = a = { n: 2 };
console.log(a.x); 
console.log(b.x); 
```

**输出结果：**
1\. **第一个结果**：`undefined`
2\. **第二个结果**：`{ n: 2 }` （即对象 `{n: 2}`）

## 核心概念：对象地址赋值原则 *Content-[00:32]
在拆解这道题之前，必须牢记一个核心概念，这也是贯穿整道题目的关键：
- 当**对象类型**相互赋值时，进行的都是**地址赋值**。
- 如果两个变量指向同一个地址，那么它们的内容是一样的，**一改全改**。
- 理解“地址”的概念是解开此类面试题的钥匙。

## 代码执行步骤详细拆解 *Content-[01:15]
我们将代码的执行过程拆解为多个步骤，通过追踪内存地址的变化来理解：

1\. **第一步：初始化变量 `a`**
- 代码：`a = { n: 1 }`
- 解析：在内存中开辟一块新空间（假设为**地址1**），内容为 `{ n: 1 }`。变量 `a` 指向**地址1**。

2\. **第二步：变量 `b` 赋值**
- 代码：`b = a`
- 解析：将 `a` 的地址赋值给 `b`。此时，变量 `b` 和变量 `a` 都指向同一块内存空间，即**地址1**。

3\. **第三步：连续赋值 `a.x = a = { n: 2 }` （核心难点）**
这句话包含了多个操作，需要分步拆解：
- **步骤 3.1**：计算左侧的引用 `a.x`。此时 `a` 依然指向**地址1**，因此这一步相当于给**地址1**的对象绑定了一个新属性 `x`。
- **步骤 3.2**：计算右侧的 `a = { n: 2 }`。这会将 `a` 重新赋值为一个新的对象。在内存中开辟新空间（假设为**地址2**），内容为 `{ n: 2 }`。此时，**变量 `a` 指向了地址2**。
- **步骤 3.3**：将右侧的结果（即**地址2**）赋值给步骤 3.1 中确定的引用位置（即**地址1**的 `x` 属性）。
- **结果状态**：
  - 变量 `a` 指向**地址2** `{ n: 2 }`。
  - **地址1**的内容变成了 `{ n: 1, x: 地址2 }` （相当于地址1里面嵌套了地址2，讲师比喻为“塑料袋里面套个塑料袋”）。

4\. **第四步：确认变量 `b` 的指向**
- 解析：在第三步中，只有变量 `a` 的指向被修改为了**地址2**。变量 `b` 并没有被重新赋值，因此 **`b` 依然指向地址1**。
- 此时，通过 `b` 看到的对象内容就是**地址1**被修改后的内容：`{ n: 1, x: 地址2 }`。

## 最终结果分析与原理解释 *Content-[05:34]
基于上述内存地址的变化，我们来分析最终的打印结果：

1\. **分析 `console.log(a.x)`**
- 此时变量 `a` 指向的是**地址2** `{ n: 2 }`。
- 在**地址2**的对象中寻找 `x` 属性。
- 因为**地址2**中只有 `n: 2`，没有 `x` 属性，所以返回 `undefined`。

2\. **分析 `console.log(b.x)`**
- 此时变量 `b` 指向的是**地址1**。
- **地址1**的内容是 `{ n: 1, x: 地址2 }`。
- 在**地址1**中寻找 `x` 属性，找到了 `x`，它的值是**地址2**（即 `{ n: 2 }`）。
- **关键细节**：在第三步中，地址1的 `x` 属性原本绑定的是当时的 `a`（即地址1自身），但由于 `a` 变量随后被重新赋值指向了地址2，因此地址1中嵌套的引用实际上变成了地址2。
- 所以，`b.x` 最终返回的是 `{ n: 2 }`。

## AI 总结 *Content-[07:40]
这道面试题的核心考点在于 **JavaScript 中对象的引用传递机制**以及**连续赋值语句的执行顺序**。
1. 对象赋值传递的是内存地址，而非值的拷贝。
2. 在 `a.x = a = { n: 2 }` 这样的连续赋值中，等号右侧先执行（`a` 被赋予新地址），但左侧的属性引用（`a.x`）在赋值前就已经确定（指向旧地址的 `x` 属性）。
3. 理清变量指向和内存地址的对应关系，是解决此类“一改全改”或“地址偏移”问题的关键。建议在复习时，多通过画内存地址图来辅助理解，细细捋清每一步的地址变化。
