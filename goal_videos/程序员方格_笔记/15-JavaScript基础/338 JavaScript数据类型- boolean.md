## 1. Boolean 数据类型概述 *Content-[00:00]
- **核心特点**：Boolean（布尔）类型只有两个值：
  - `true`：代表真值。
  - `false`：代表假值。
- **主要作用**：主要用于条件判断和逻辑运算，在日常前端开发中使用频次非常高。

## 2. 面试题：JS 中的假值 (Falsy Values) *Content-[00:44]
- **面试问题**：在 JavaScript 中，哪些值在隐式类型转换时会被视为假值？
- **核心结论**：JS 中一共有 **6 个**值会被转换为假值，其余所有值均为真值（`true`）。

### 2.1 第一个假值：`undefined` *Content-[01:12]
- **含义**：表示“未定义”（找不到值时出现）。
- **转换机制**：在逻辑运算和条件判断中，通过隐式类型转换，`undefined` 会被自动转为布尔值中的 `false`。
- **代码示例**：
  ```javascript
  let a = undefined; // 或者 let a; 默认也是 undefined
  if (a) {
      console.log('你好');
  }
  ```
- **执行结果**：条件不成立，`console.log` **不会执行**。

### 2.2 第二个假值：`null` *Content-[03:00]
- **含义**：代表“空”（与 `undefined` 的“未定义”有所区分）。
- **转换机制**：与 `undefined` 类似，`null` 经过隐式类型转换后也是 `false`。
- **执行结果**：在条件判断中条件不成立，代码块**不会执行**。

### 2.3 第三个假值：数字 `0` *Content-[04:31]
- **核心强调**：必须是**数字类型的 `0`**，而不是字符串 `"0"`。
- **转换机制**：数字 `0` 隐式类型转换为 `false`。
- **对比易错点**：
  - 数字 `0`：是假值，条件判断不执行。
  - 字符串 `"0"`：是**真值**！因为它不是空字符串，里面包含了字符 `0`，所以条件判断会执行。

### 2.4 第四个假值：`NaN` *Content-[05:42]
- **含义**：`NaN` 是 `Not a Number` 的缩写，表示“非数值”，通常在无法计算结果时出现（例如：数字与字符串相加等非法运算）。
- **类型陷阱**：虽然名字叫“不是数字”，但使用 `typeof NaN` 检测时，其返回结果依然是 **`number`** 类型。
- **转换机制**：`NaN` 隐式转换为 `false`，条件判断不执行。

## 3. 面试答题技巧：亲自验证代码 *Content-[07:27]
- **拒绝死记硬背**：对于非纯理论的面试题，一定要亲自写代码验证。
- **验证的意义**：
  - 验证后在面试沟通时，回答会更加**自信和笃定**。
  - 面对面试官的追问或质疑（如“真的是这样吗？”、“有没有其他情况？”），能够坚持正确答案，不被带偏，这在面试中是非常大的加分项。

### 3.1 第五个假值：空字符串 *Content-[08:45]
- **表现形式**：单引号 `''`、双引号 `""`、反引号 `` ` ``（键盘 ESC 键下方）中间什么都不写。
- **转换机制**：空字符串隐式转换为 `false`。
- **对比易错点**：
  - 空字符串 `""`：是假值，不执行。
  - 包含空格的字符串 `" "`：是**真值**！因为空格也是字符，字符串不为空，条件判断会执行。

### 3.2 第六个假值：`false` *Content-[10:41]
- **含义**：布尔值本身的 `false`。
- **转换机制**：直接赋值为 `false`，条件判断必然不成立，代码块不会执行。

## 4. 总结：JS 中的 6 大假值 *Content-[11:10]
在 JavaScript 中，隐式类型转换为布尔值 `false` 的情况仅有以下 6 种：
1. `undefined`
2. `null`
3. 数字 `0`
4. `NaN`
5. 空字符串 (`""`, `''`, `` ` ``)
6. `false`
