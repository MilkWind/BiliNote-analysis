## 1. 引言与 Object.defineProperty 概述 *Content-[00:00]
- **核心作用**：`Object.defineProperty` 是 JavaScript 中非常重要的一个静态方法，主要用于实现**对象的监听器**。
- **核心机制**：其内部包含两个关键概念——**存值器（Setter）** 和**取值器（Getter）**，通过它们可以拦截对对象属性的读取和赋值操作。

## 2. 权限控制的必要性与生活案例 *Content-[01:20]
- **直接赋值的隐患**：如果直接将核心数据对象暴露给外部，外部可以随意修改属性值（如 `o.name = '新名字'`），程序无法进行有效拦截。
- **权限控制的比喻**：
  - **烤肠店**：店主可以提供烤肠和配料，但不能让顾客自己控制烤炉，否则顾客可能会烤一些奇怪的东西（如签子、臭豆腐）。必须开放部分权限，但保留核心控制权。
  - **ATM 机**：银行取钱需要经过插卡、输密码、输金额等严格流程，而不是直接把一箱钱放在街边让人随便拿。
- **结论**：在程序中，我们需要通过特定的方法来控制属性的访问和修改权限，而不是完全开放。

## 3. 基本语法与 value 属性 *Content-[05:00]
- **方法签名**：`Object.defineProperty(obj, prop, descriptor)`
  - 第一个参数：目标对象（如 `o`）。
  - 第二个参数：属性名（如 `'gender'`，需加引号）。
  - 第三个参数：**属性描述符对象**（必须是一个对象，否则报错 `Property description must be an object`）。
- **value 属性**：
  - 用于设置属性的**初始默认值**。
  - 如果不传 `value`，属性的默认值为 `undefined`。
  - 示例：`{ value: '男' }` 表示新增 `gender` 属性时，其默认值为 `'男'`。

## 4. writable 属性：控制是否可修改 *Content-[08:15]
- **功能**：控制该属性是否可以被重新赋值修改。
- **类型与默认值**：布尔值，**默认值为 `false`**。
- **行为表现**：
  - 当 `writable: false` 时，尝试修改属性值（如 `o.gender = '女'`）将不会生效（严格模式下会报错，非严格模式下静默失败）。
  - 当 `writable: true` 时，属性值可以被正常修改。

## 5. configurable 属性：控制是否可删除 *Content-[11:15]
- **功能**：控制该属性是否可以被删除（使用 `delete` 操作符）。
- **类型与默认值**：布尔值，**默认值为 `false`**。
- **行为表现**：
  - 当 `configurable: false` 时，执行 `delete o.gender` 会返回 `false`，属性删除失败。
  - 当 `configurable: true` 时，属性可以被成功删除。

## 6. enumerable 属性：控制是否可枚举 *Content-[12:35]
- **功能**：控制该属性是否可以被枚举（遍历），即在 `for...in` 循环中是否可见。
- **类型与默认值**：布尔值，**默认值为 `false`**。
- **行为表现**：
  - 当 `enumerable: false` 时，使用 `for (let key in o)` 遍历时，该属性不会被遍历出来。
  - 当 `enumerable: true` 时，该属性会正常参与遍历。

## 7. 取值器函数 get 与动态属性 *Content-[14:15]
- **功能**：定义一个函数，当**获取**该属性的值时自动触发。
- **互斥规则**：如果定义了 `get`，则**不能**同时使用 `value` 和 `writable` 属性，否则会报错 `Invalid property descriptor. Cannot both specify accessors and a value or writable attribute`。
- **返回值**：`get` 函数的返回值决定了当前获取到的属性值。
- **动态属性示例**：
  - 可以通过 `get` 实现每次获取都返回不同值的动态属性。
  - 示例：返回 $0$ 到 $100$ 的随机整数，其数学范围为 $x \in [0, 100)$ 且 $x \in \mathbb{Z}$，代码实现为 `get() { return Math.floor(Math.random() * 100); }`。每次读取 `o.num` 都会得到一个新的随机数。

## 8. 存值器函数 set 与递归调用陷阱 *Content-[20:00]
- **功能**：定义一个函数，当**重新赋值**该属性时自动触发。
- **参数**：`set` 函数接收一个参数，即新赋给该属性的值（如 `set(val)`）。
- **递归调用陷阱（重点）**：
  - 如果在 `set` 函数内部，直接将新值赋给当前属性（如 `this.gender = val`），会再次触发 `set` 函数，导致**无限递归**。
  - 同样，如果在 `get` 函数内部尝试获取当前属性（如 `return this.gender`），也会触发 `get` 函数，导致无限递归。
  - **后果**：程序会抛出 `Maximum call stack size exceeded`（调用栈溢出）错误并崩溃。

## 9. 代理属性与敏感词拦截实现 *Content-[25:10]
- **解决递归问题**：
  - 引入一个**代理属性**（如 `_gender`）来存储真实的值。
  - 在 `get` 中返回 `this._gender`，在 `set` 中给 `this._gender` 赋值，从而避免直接操作原属性引发递归。
- **敏感词拦截实现**：
  - 在 `set` 函数中加入逻辑判断，实现数据拦截。
  - 示例：如果传入的值是敏感词（如 `'二傻子'`），则直接 `return` 不进行赋值；否则将值赋给代理属性 `_gender`。
- **“代理”概念解析**：
  - 代理属性就像银行柜台的小姐姐或直播间的“代聊抠脚大汉”，表面上你是在和原属性（主播/柜台）交互，实际上底层是由代理属性（后台系统/代聊）在处理核心逻辑。这种设计既保证了交互的顺畅，又实现了安全的权限控制。

## 10. 总结与扩展：Object.defineProperties 及 Vue2 原理 *Content-[30:30]
- **Object.defineProperties**：
  - 与 `Object.defineProperty` 类似，但可以一次性为对象定义或修改**多个**属性，传入包含多个属性描述符的对象。
- **Vue2 底层原理**：
  - Vue2 的响应式系统（观察者模式/数据监听）底层核心就是基于 `Object.defineProperty` 实现的。通过 `get` 收集依赖，通过 `set` 触发更新。
