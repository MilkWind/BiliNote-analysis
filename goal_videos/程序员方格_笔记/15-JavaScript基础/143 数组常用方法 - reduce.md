## 1. reduce 方法基础概念与参数解析 *Content-[00:00]

`reduce` 方法在数组常用方法中相对更加灵活。它接收两个主要参数：
1. **回调函数（Callback）**：用于处理数组中的每一个元素。
2. **初始值（Initial Value）**：可选参数，作为第一次调用回调函数时 `prev` 的值。

### 回调函数的四个参数
回调函数内部包含四个参数，其具体含义和取值规则如下：

1. **`prev` (previousValue)**：上一次调用 callback 时的返回值。
   - **第一次调用时**：如果指定了初始值，则 `prev` 为该初始值；如果未指定初始值，则 `prev` 为数组索引为 `0` 的元素。
2. **`cur` (currentValue)**：数组中正在处理的当前元素。
   - **第一次调用时**：如果指定了初始值，则 `cur` 为数组索引为 `0` 的元素；如果未指定初始值，则 `cur` 为数组索引为 `1` 的元素。
3. **`index`**：正在处理的当前元素的索引。
   - 如果指定了初始值，则索引从 `0` 开始；如果未指定初始值，则索引从 `1` 开始。
4. **`array`**：调用 `reduce` 方法的数组本身。

**返回值**：`reduce` 的最终返回值是回调函数遍历整个数组后累积计算的结果。

## 2. 示例一：不传初始值的累加推导 *Content-[02:43]

通过一个具体的累加示例来深入理解参数的变化。
- **目标数组**：`[1, 2, 3, 4, 5]`
- **操作**：`arr.reduce((prev, cur, index, array) => prev + cur)` （未传入初始值）

### 详细推导过程

由于未传入初始值，第一轮遍历时：
- `prev` 取数组索引 `0` 的元素，即 `1`。
- `cur` 取数组索引 `1` 的元素，即 `2`。
- `index` 从 `1` 开始。

| 轮次 | prev (上一次结果) | cur (当前值) | index (索引) | 返回值计算 (prev + cur) |
| :--- | :--- | :--- | :--- | :--- |
| **第一轮** | 1 (索引0元素) | 2 (索引1元素) | 1 | $1 + 2 = 3$ |
| **第二轮** | 3 (第一轮结果) | 3 (索引2元素) | 2 | $3 + 3 = 6$ |
| **第三轮** | 6 (第二轮结果) | 4 (索引3元素) | 3 | $6 + 4 = 10$ |
| **第四轮** | 10 (第三轮结果) | 5 (索引4元素) | 4 | $10 + 5 = 15$ |

**最终结果**：`15`。
**核心记忆点**：`prev` 始终代表**上一次回调函数执行完毕后的返回结果**。在求和场景中，即为“上一次的结果 + 当前值”。

## 3. 示例二：传入初始值的累加推导 *Content-[08:00]

接下来看传入初始值的情况，参数的起始状态会发生改变。
- **目标数组**：`[1, 2, 3, 4, 5]`
- **操作**：`arr.reduce((prev, cur, index, array) => prev + cur, 0)` （传入初始值 `0`）

### 详细推导过程

由于传入了初始值 `0`，第一轮遍历时：
- `prev` 直接取初始值 `0`。
- `cur` 取数组索引 `0` 的元素，即 `1`。
- `index` 从 `0` 开始。

| 轮次 | prev (上一次结果) | cur (当前值) | index (索引) | 返回值计算 (prev + cur) |
| :--- | :--- | :--- | :--- | :--- |
| **第一轮** | 0 (初始值) | 1 (索引0元素) | 0 | $0 + 1 = 1$ |
| **第二轮** | 1 (第一轮结果) | 2 (索引1元素) | 1 | $1 + 2 = 3$ |
| **第三轮** | 3 (第二轮结果) | 3 (索引2元素) | 2 | $3 + 3 = 6$ |
| **第四轮** | 6 (第三轮结果) | 4 (索引3元素) | 3 | $6 + 4 = 10$ |
| **第五轮** | 10 (第四轮结果) | 5 (索引4元素) | 4 | $10 + 5 = 15$ |

**最终结果**：`15`。
**对比结论**：无论是否传入初始值，只要逻辑正确，最终累加结果一致。但传入初始值可以明确控制 `prev` 的初始状态和 `cur` 的起始索引，这在处理复杂数据结构（如对象数组累加）时尤为重要。

## 4. reduceRight 方法简介 *Content-[10:54]

- **概念**：`reduceRight` 方法与 `reduce` 的用法和参数完全类似。
- **区别**：`reduce` 是从左往右（索引从小到大）遍历数组，而 `reduceRight` 是**从右往左**（索引从大到小）遍历数组。

## 5. reduce 的常见应用场景 *Content-[11:18]

`reduce` 的灵活性极强，除了基础的累加，还常用于以下场景：

### 场景一：数组求和
如上述示例所示，通过 `prev + cur` 即可轻松实现数组元素的累加求和。

### 场景二：求数组最大值
- **逻辑思路**：将 `prev`（上一轮的结果/当前最大值）与 `cur`（当前遍历到的值）进行比较。如果 `prev > cur`，则返回 `prev`；否则返回 `cur`。
- **代码实现**：
  ```javascript
  const arr = [1, 2, 3, 4, 5];
  const maxVal = arr.reduce((prev, cur) => {
      return prev > cur ? prev : cur;
      // 也可以简写为：return Math.max(prev, cur);
  });
  console.log(maxVal); // 输出: 5
  ```

### 场景三：数组去重（返回新数组）
- **逻辑思路**：利用 `reduce` 遍历原数组，将**初始值设为空数组 `[]`**。在回调函数中，判断上一次累积的结果（即去重后的新数组 `prev`）中是否包含当前元素 `cur`。如果不包含，则将其 `push` 进去。
- **代码实现**：
  ```javascript
  const arr = [1, 2, 1, 2, 3];
  const uniqueArr = arr.reduce((prev, cur) => {
      // 如果 prev 中不包含 cur，则将其加入 prev
      if (!prev.includes(cur)) {
          prev.push(cur);
      }
      return prev;
  }, []); // 初始值为空数组
  
  console.log(uniqueArr); // 输出: [1, 2, 3]
  ```

## AI 总结

本视频详细讲解了 JavaScript 数组高阶方法 `reduce` 的核心原理与实战应用。
1. **核心机制**：`reduce` 通过回调函数累积处理数组元素。其最关键的参数是 `prev`，它始终代表**上一次回调函数的返回值**。
2. **初始值的影响**：是否传入第二个参数（初始值）会直接影响第一轮遍历时 `prev`、`cur` 和 `index` 的取值。传入初始值能使 `cur` 从索引 `0` 开始，`index` 也从 `0` 开始，逻辑更加可控。
3. **实战场景**：`reduce` 不仅限于基础的**求和**，通过改变回调函数内的逻辑，还可以优雅地实现**求最大值**（利用条件判断或 `Math.max`）以及**数组去重**（结合 `includes` 和 `push`，以空数组为初始值）。
掌握 `reduce` 的关键在于理解其“状态累积”的思想，这在处理复杂数据转换和聚合计算时是不可或缺的强大工具。
