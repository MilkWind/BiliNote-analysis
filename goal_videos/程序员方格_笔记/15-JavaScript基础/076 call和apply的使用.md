## 1. JS 函数的四种调用模式 *Content-[00:30]

在 JavaScript 中，函数的调用模式主要分为以下四种，不同的调用模式决定了函数内部 `this` 的指向：

1\. **函数模式**
- **调用方式**：直接 `函数名()`。
- **说明**：无论是全局函数还是局部函数，直接通过函数名加括号调用。
- **this 指向**：在全局环境下直接调用，相当于 `window.函数名()`（`window.` 可以省略），因此 `this` 指向 `window` 对象。

2\. **方法模式（对象调用模式）**
- **调用方式**：`对象.方法名()` 或 `对象.函数名()`。
- **说明**：函数必须依托于对象，不能直接调用。例如 `p.show()`，其中 `show` 属于 `p` 对象。
- **this 指向**：`this` 指向调用该方法的对象（即 `p` 对象）。

3\. **构造函数模式**
- **调用方式**：`new 构造函数()`。
- **说明**：使用 `new` 关键字调用函数来创建实例对象。
- **`new` 关键字的四个核心作用**：
  1. 开辟内存空间，存储新创建的对象。
  2. 将函数内部的 `this` 指向当前新创建的对象。
  3. 执行函数内部代码，为当前对象绑定属性和方法。
  4. 返回当前新创建的对象。

4\. **上下文调用模式**
- **说明**：这是本节课的重点，专门用于处理函数内部 `this` 的指向问题，能够人为改变函数原本的 `this` 指向。

## 2. 上下文调用模式与 this 指向 *Content-[04:33]

上下文调用模式的核心作用是**改变函数内部的 `this` 指向**。

- **默认情况**：例如 `function demo() { console.log(this); }`，如果直接调用 `demo()`，`this` 默认指向 `window`。
- **上下文调用的目的**：通过特定的方法，强制让函数内部的 `this` 指向我们指定的新对象，实现“想让 `this` 指向谁，就指向谁”的效果。

## 3. call、apply、bind 的具体用法与区别 *Content-[05:44]

`call`、`apply` 和 `bind` 是上下文调用模式的三个核心方法，它们的功能都是改变 `this` 指向，但在用法和传参方式上有所区别。

### call 的用法
- **语法**：`函数名.call(this指向的新对象, 实参1, 实参2, ...)`
- **特点**：
  - 立即调用并执行该函数。
  - 参数传递方式为**逐个传递**（实参列表），与普通函数传参格式一致。
- **示例**：
  ```javascript
  let obj = { name: '小李', age: 15 };
  function demo() {
      console.log('我是demo函数，this指向：', this);
  }
  demo.call(obj); // 输出：我是demo函数，this指向：{name: '小李', age: 15}
  ```

### apply 的用法
- **语法**：`函数名.apply(this指向的新对象, [实参1, 实参2, ...])`
- **特点**：
  - 立即调用并执行该函数。
  - 参数传递方式为**数组传递**（将参数放在一个数组中）。
- **示例**：
  ```javascript
  function demo(a, b) {
      console.log(a, b);
  }
  demo.apply(obj, [99, 88]); // 输出：99 88
  ```

### call 与 apply 的性能对比
- **结论**：`call` 的性能略高于 `apply`。
- **原因**：`call` 是通过实参列表直接给形参赋值，格式与普通传参一致，更直接；而 `apply` 需要通过数组的方式拆解并赋值，多了一层处理。不过在现代 JS 引擎中，两者的性能差距微乎其微，面试时答出原因即可。

### bind 的用法
- **语法**：`let newFunc = 函数名.bind(this指向的新对象, 实参1, ...)`
- **特点**：
  - **不会立即执行函数**，而是返回一个 `this` 指向已经改变的新函数。
  - 需要**再次手动调用**这个新函数（`newFunc()`）才会触发代码执行。
  - 分为两步：第一步绑定 `this`，第二步调用新函数。
- **传参建议**：绑定时可以传参也可以不传。如果希望调用时再传参，绑定时可不传；如果是批量绑定且参数相同，可在绑定时直接传参。
- **示例**：
  ```javascript
  let newDemo = demo.bind(obj); // 仅绑定，不执行
  newDemo(65, 74); // 手动调用并传参，此时 this 指向 obj
  ```

## 4. 实际使用场景一：利用 apply 求数组最大值 *Content-[11:26]

在实际开发中，`call` 和 `apply` 常用于解决一些特定的参数格式问题。

- **场景需求**：求数组 `let arr = [12, 5, 7, 88, 34]` 中的最大值。
- **痛点**：`Math.max()` 方法要求传入的是**参数列表**（如 `Math.max(12, 5, 7)`），而不是数组。直接传入数组 `Math.max(arr)` 会返回 `NaN`。
- **解决方案（使用 apply）**：
  利用 `apply` 可以将数组转换为参数列表的特性，将数组 `arr` 作为第二个参数传入。
  ```javascript
  let maxVal = Math.max.apply(null, arr); 
  // this 指向 null 或 window 即可，重点是利用 apply 的数组展开功能
  console.log(maxVal); // 输出：88
  ```
- **ES6 替代方案**：
  在 ES6 中，可以使用扩展运算符（`...`）更优雅地实现相同效果，将数组元素展开为参数列表：
  ```javascript
  let maxValES6 = Math.max(...arr);
  ```

## 5. 实际使用场景二：利用 call 实现构造函数继承 *Content-[13:47]

`call` 在早期 ES5 开发中，是实现**构造函数继承**（借用构造函数）的核心手段。

- **场景需求**：
  定义一个 `Person` 构造函数（包含 `name`, `age`），以及 `Student`（包含 `name`, `age`, `book`）和 `Teacher`（包含 `name`, `age`, `skill`）构造函数。
- **痛点**：`Student` 和 `Teacher` 中都需要重复编写 `this.name = name` 和 `this.age = age` 的代码，代码冗余度高。
- **解决方案（使用 call）**：
  在子类构造函数中，通过 `call` 借用父类构造函数来初始化属性。
  ```javascript
  function Person(name, age) {
      this.name = name;
      this.age = age;
  }

  function Student(name, age, book) {
      // 借用 Person 构造函数，将 this 指向当前 Student 的实例
      Person.call(this, name, age); 
      this.book = book;
  }

  let stu = new Student('张小飞', 12, '段位书');
  console.log(stu); // 输出包含 name, age, book 的对象
  ```
- **原理剖析（借筐下蛋）**：
  1. `Person` 本质上是一个函数，内部包含属性赋值代码。
  2. 在 `Student` 内部执行 `Person.call(this, name, age)` 时，`call` 方法将 `Person` 函数内部的 `this` 强制指向了当前 `Student` 的实例对象。
  3. 当 `Person` 内部的代码（`this.name = name`）执行时，实际上是在给 `Student` 的实例绑定属性。
  4. 这样无论 `Person` 中有多少个属性，子类只需一句 `call` 代码即可完成继承，极大地减少了重复代码。
