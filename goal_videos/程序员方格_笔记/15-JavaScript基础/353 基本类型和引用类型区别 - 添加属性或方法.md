## 基本数据类型添加属性或方法 *Content-[00:00]

### 核心结论
- **基本数据类型不支持挂载属性和方法**。
- 基本数据类型仅仅能够存储实际的值，不支持动态添加属性或方法。即使强行添加，也无法获取到，最终访问时会返回 `undefined`。
- 这一特性再次印证了基本类型的值是**不可变的**。

### 代码示例与验证
我们可以通过以下代码来验证基本数据类型的这一特性：

```javascript
// 声明一个基本数据类型变量
let name = '小漂亮';

// 尝试给基本类型添加自定义属性和方法
name.job = '玩耍';
name.sayHello = function() {
    console.log('hello');
};

// 尝试访问添加的属性和方法
console.log(name.job);       // 返回 undefined
console.log(name.sayHello);  // 返回 undefined
```

**执行结果分析**：
- 访问 `name.job` 和 `name.sayHello` 时，结果均为 `undefined`。
- 这证明了基本数据类型不能添加属性，也不能添加方法。

## 引用数据类型添加属性或方法 *Content-[02:07]

### 核心结论
- **引用数据类型支持动态添加、修改和删除属性或方法**。
- 引用数据类型的实际数据存在于堆内存中，因此支持对属性和方法进行灵活的动态操作，这也体现了引用类型的值是**可变的**。

### 代码示例与验证
我们可以通过对对象（引用数据类型）的操作来验证其灵活性：

```javascript
// 声明一个引用数据类型（对象）
let obj = {};

// 1. 动态添加属性和方法
obj.name = '小漂亮';
obj.job = '玩耍';
obj.sayHello = function() {
    console.log('hello');
};
```
- **结果**：可以成功访问属性 `obj.name`、`obj.job`，并成功执行方法 `obj.sayHello()` 打印出 `hello`。

```javascript
// 2. 修改属性值
obj.name = '小美丽';
console.log(obj.name); // 返回 '小美丽'
```
- **结果**：属性值被成功修改，体现了引用类型可以改值。

```javascript
// 3. 删除属性
delete obj.name; 
console.log(obj.name); // 返回 undefined
```
- **结果**：使用 `delete` 关键字删除属性后，再次访问该不存在的属性，返回 `undefined`。

## AI 总结

本视频详细讲解了前端面试中基本数据类型与引用类型在“添加属性或方法”这一维度上的核心区别。基本数据类型仅存储实际值，具有不可变性，因此无法动态添加属性或方法，强行添加后访问会返回 `undefined`。相反，引用数据类型的数据存储在堆内存中，支持动态添加、修改和删除属性与方法，具有高度的可变性。掌握这一区别有助于深入理解 JavaScript 的内存管理机制和数据类型特性，是前端面试中的高频基础考点。
