## 核心概念：函数声明与函数表达式 *Content-[01:30]

在深入区别之前，需要先明确两者的本质：**它们都是定义函数的方式**。

- **生活类比**：就像买奶茶，到店里面点单相当于**函数声明**，外卖点单相当于**函数表达式**。无论哪种方式，最终都能拿到奶茶（得到函数的功能），只是获取的方式和流程不同。

## 函数声明详解 *Content-[02:24]

### 概念与类比
函数声明就像是小区门口固定的便利店，位置固定、招牌明显。不管你什么时候出门，只要需要就可以直接去店里买东西，不用提前预约，也不用等它开门。

### 语法结构
函数声明具有固定的格式，缺少任何一部分都不行：
- 必须以 `function` 关键字开头，告诉 JS 引擎正在定义一个函数。
- 必须有**函数名**（如 `sayHello`），相当于便利店的招牌，一眼就能认出。
- 包含**括号**用于传递形参（如 `name`），相当于输入条件。
- 包含**大括号 `{}`** 用于放置函数体，相当于店员执行拿东西、结账等操作。
- **不需要**赋值给任何变量，直接定义即可使用。

### 代码示例
```javascript
function sayHello(name) {
    console.log(`你好 ${name}，我是函数声明定义的函数`);
}
```

### 核心特权：可以先调用后定义
函数声明最大的特点是**支持先调用后定义**。即使调用代码写在函数声明的前面，也不会报错。

```javascript
// 先调用
sayHello('金小子'); 

// 后定义
function sayHello(name) {
    console.log(`你好 ${name}，我是函数声明定义的函数`);
}
```
*注：虽然支持先调用后定义，但在实际开发中，为了符合日常阅读和行为习惯，通常还是建议先定义再调用。*

## 函数表达式详解 *Content-[07:48]

### 概念与类比
函数表达式就像是外卖点奶茶。你不能直接去店里拿（不能先调用），必须先在手机上下单（先定义再赋值）。等外卖员送到（代码执行到赋值那一行），你才能拿到奶茶（调用函数）。如果没下单就去拿，肯定会报错。

### 语法结构
将函数当作一个值（就像数字 `123` 或字符串 `abc` 一样），赋值给一个变量或常量。
- 通常使用 `const` 或 `let` 声明变量/常量。
- 等号右侧是一个函数，通常是**匿名函数**（没有函数名），也可以是具名函数。
- 调用时，必须通过**变量名/常量名**来调用，而不是函数名（因为函数本身是匿名的）。

### 代码示例
```javascript
const sayHi = function(name) {
    console.log(`你好 ${name}，我是函数表达式定义的函数`);
};
```

### 核心特点：必须先定义后调用
函数表达式**必须先定义后调用**。如果在赋值之前尝试调用，JS 引擎会报错。

```javascript
// 先调用（报错）
sayHi('金小子'); 

// 后定义
const sayHi = function(name) {
    console.log(`你好 ${name}，我是函数表达式定义的函数`);
};
```
*报错信息：`Cannot access 'sayHi' before initialization`（不允许在初始化之前使用 sayHi）。*

## 函数表达式的变量提升与 let/var 区别 *Content-[10:14]

函数表达式在变量提升（预解析）的表现上，会根据声明变量的关键字（`var` vs `let/const`）有所不同，但**核心结论不变：必须先定义后调用**。

### 1. 使用 `var` 定义函数表达式
`var` 存在变量提升机制。
- **预解析第一步**：JS 引擎寻找 `var` 和 `function` 关键字。遇到 `var` 时，会将变量名 `sayHi` 提升到作用域顶部，并默认赋值为 `undefined`。
- **预解析第二步**：逐行执行代码。当执行到打印或调用时，由于还未走到赋值那一行，`sayHi` 的值依然是 `undefined`。

```javascript
console.log(sayHi); // 输出: undefined
sayHi('金小子');    // 报错: sayHi is not a function

var sayHi = function(name) {
    console.log(`你好 ${name}，我是函数表达式定义的函数`);
};
```

### 2. 使用 `let` 或 `const` 定义函数表达式
`let` 和 `const` **没有变量提升**（存在暂时性死区）。
- 在代码执行到声明并初始化该行之前，变量是不可访问的。
- 如果在初始化之前直接调用或访问，会直接抛出引用错误。

```javascript
sayHi('金小子'); // 报错: Cannot access 'sayHi' before initialization

let sayHi = function(name) {
    console.log(`你好 ${name}，我是函数表达式定义的函数`);
};
```

### 结论
无论使用 `var`、`let` 还是 `const` 来定义函数表达式，都**必须遵循先定义（赋值）后调用**的原则。

## AI 总结

本次课程详细解析了 JS 中**函数声明**与**函数表达式**的核心区别：
1. **语法形式**：函数声明以 `function` 关键字开头并带有函数名；函数表达式则是将匿名（或具名）函数赋值给变量。
2. **调用顺序**：函数声明由于**变量提升**机制，支持“先调用后定义”；函数表达式本质是变量赋值，必须“先定义后调用”。
3. **变量提升差异**：使用 `var` 声明的函数表达式会被提升为 `undefined`，调用时报 `not a function`；使用 `let/const` 声明则存在暂时性死区，提前调用会报 `initialization` 错误。
4. **开发建议**：在实际开发中，推荐使用 `const` 结合箭头函数或匿名函数（函数表达式）来定义函数，以避免变量提升带来的潜在问题，同时保持代码作用域的严谨性。
