## 1. 核心作用与基本概念 *Content-[00:12]
- **核心作用**：`call`、`apply`、`bind` 的核心作用都是**改变函数内部的 `this` 指向**。
- **借用方法实现复用**：
  - 这三个方法只有函数（方法）才能调用。
  - 通过改变 `this` 指向，可以借用其他对象的方法，从而实现代码复用并节省内存。
  - **示例**：如果不改变 `this` 指向，它默认指向 `window`；通过这三个方法改变后，可以让 `this` 指向指定的对象，这就是方法复用的体现。

## 2. call 方法详解 *Content-[01:02]
- **语法**：`fn.call(thisArg, arg1, arg2, ..., argN)`
- **参数传递**：第一个参数是 `this` 的指向，后续参数是参数列表，使用**逗号分割**。
- **执行特点**：**立即执行**。
- **适用场景**：
  - 参数个数确定的情况。
  - 借用方法。
  - 实现继承（如构造函数继承）。

## 3. apply 方法详解 *Content-[02:07]
- **语法**：`fn.apply(thisArg, [argsArray])`
- **参数传递**：第一个参数是 `this` 的指向，第二个参数必须是**数组或伪数组**。
- **执行特点**：**立即执行**。
- **适用场景**：
  - 与数组相关的操作。
  - **数学计算**：使用 `Math.max()` 求最大值、`Math.min()` 求最小值。
  - **数组操作**：合并数组、将伪数组转换为真数组。
  - **记忆技巧**：凡是用到数组的地方，都可以优先考虑使用 `apply` 方法，因为它支持第二个参数为数组或伪数组。

## 4. bind 方法详解 *Content-[03:08]
- **语法**：`fn.bind(thisArg, arg1, arg2, ..., argN)`
- **参数传递**：第一个参数是 `this` 的指向，后续参数是预设参数。
- **执行特点**：**不立即执行**，而是返回一个**新函数**。
- **参数合并机制**：可以预先设置一些参数，在调用返回的新函数时再传入后续参数，`bind` 会自动将预设参数和后传参数进行合并。
- **适用场景**：
  - 事件绑定。
  - 定时器（如 `setTimeout`）中的 `this` 指向修正。
  - React 框架中绑定 `this`。

## 5. 三者的区别与联系 *Content-[04:15]
- **相同点**：
  - 都能改变 `this` 指向。
  - 第一个参数都是 `this` 的指向。
- **不同点**：
  - **执行时机**：`call` 和 `apply` 是立即执行；`bind` 返回新函数，不立即执行。
  - **参数格式**：
    - `call`：参数使用逗号分割（参数列表）。
    - `apply`：参数必须是数组或伪数组。
    - `bind`：参数使用逗号分割，支持预设参数。

## 6. 扩展概念：函数柯里化与高阶函数 *Content-[05:11]
- **函数柯里化（Currying）**：
  - `bind` 可以预设参数，后续再传入剩余参数，这种机制体现了函数柯里化的思想。
  - 函数柯里化是前端面试中的高频考点。
- **相关扩展概念**：
  - **纯函数（Pure Function）**。
  - **高阶函数（Higher-order Function）**。
  - **闭包（Closure）**：超高频面试题，常与高阶函数结合考察。

## 7. 高频使用场景总结 *Content-[06:02]
- **伪数组转真数组**：虽然现在有 `Array.from()` 等更便捷的方法，但使用 `call` / `apply` 也是经典的实现方式。
- **求数组的最大值/最小值**：结合 `Math.max()` / `Math.min()` 与 `apply` 实现。
- **实现继承**：如构造函数继承（注：实际开发中较少单独使用，存在一定弊端，但面试需掌握其原理）。
- **定时器 this 修正**：使用 `bind` 修正 `setTimeout` 中的 `this` 指向问题。
- **判断数据类型**：例如使用 `Object.prototype.toString.call()` 来精准验证数据类型（如验证是否为数组）。
