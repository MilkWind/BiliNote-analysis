## 面试题背景与需求分析 *Content-[00:00]
- **题目要求**：实现一个字符串匹配算法，在长度为 $N$ 的源字符串 `s` 中查找是否存在长度为 $M$ 的目标字符串 `t`。
- **功能目标**：若存在，返回目标字符串首字母所在的索引位置；若不存在，则返回 `-1`。
- **限制条件**：不能直接使用 JavaScript 原生的 `indexOf` 方法，需要手动编写底层逻辑来实现该功能。

## 函数封装与前置边界判断 *Content-[00:29]
- **函数命名规范**：定义函数 `findString(sStr, tStr)`。
  - **命名建议**：尽量避免使用 `find` 作为函数名，因为 `find` 容易与 JavaScript 中的关键字或数组原生方法（如 `Array.prototype.find`）重名。使用 `findString` 更加安全且语义明确。
- **前置边界判断（剪枝优化）**：
  - 在进入核心循环之前，首先进行长度校验。
  - 如果目标字符串 `tStr` 的长度大于源字符串 `sStr` 的长度（即 `tStr.length > sStr.length`），则绝对不可能匹配成功。
  - 此时直接 `return -1`，避免执行无意义的 `for` 循环，有效提升代码执行效率。

## 核心逻辑：循环遍历与字符串截取 *Content-[01:52]
- **循环遍历**：使用 `for` 循环遍历源字符串 `sStr`。
  - 初始化索引：`let i = 0`。
  - 循环条件：`i < sStr.length`。
  - 步长递增：`i++`。
- **字符串截取与比对**：
  - 在循环内部，需要判断从当前索引 `i` 开始，截取与目标字符串 `tStr` 等长的子串，是否与 `tStr` 完全相等。
  - **截取方法**：使用字符串的 `slice` 方法。
  - **参数传递**：`sStr.slice(i, i + tStr.length)`。
    - 第一个参数是起始位置 `i`。
    - 第二个参数是结束位置（包头不包尾），即起始位置加上目标字符串的长度 `i + tStr.length`。
  - **条件判断**：如果 `sStr.slice(i, i + tStr.length) === tStr`，说明找到了匹配项，直接 `return i` 返回当前索引。
- **未找到处理**：如果 `for` 循环正常结束仍未触发 `return`，说明未找到匹配字符串，在函数末尾 `return -1`。

## 代码调试与 slice 方法纠错 *Content-[03:43]
- **常见错误分析**：在初步编写代码时，开发者容易在字符串截取方法上犯错，需要特别注意以下两点：
- **错误点 1：混淆 `slice` 与 `splice`**
  - 字符串对象没有 `splice` 方法，`splice` 是数组（Array）的专属方法。因此不能使用 `sStr.splice()` 进行截取。
- **错误点 2：误解 `slice` 的第二个参数**
  - 错误写法：误以为 `slice` 的第二个参数是“截取长度”，错误地写成 `sStr.slice(i, tStr.length)`。
  - 正确理解：`slice(start, end)` 的第二个参数是**结束位置的索引**，而不是截取的长度。
  - 修正方案：必须将结束位置计算为起始索引加上截取长度，即正确写法为 `i + tStr.length`。
