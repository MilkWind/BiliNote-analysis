## 2. 核心语义区别：为什么JS有两个表示“无”的值 *Content-[02:46]

JS 设计 null 和 undefined 的核心目的，是为了区分 **“主动为空”** 和 **“被动的空”**。

- **undefined（被动的、原始的空）**
  - **语义**：表示“本该有值，但是还没有被定义”。
  - **来源**：是 JS 引擎自动生成的，不是开发者手动操作的结果。
  - **生活类比**：就像快递柜刚安装好，从来没有放过快递，也没有人操作过，是原始的空状态。

- **null（主动的、人为的空）**
  - **语义**：表示“主动的、人为的空”。
  - **来源**：是开发者手动赋值的，明确表示这个值现在是空的（例如原本应该是个对象，但现在被清空了）。
  - **生活类比**：就像快递柜里的快递被主人手动取走了，现在柜子是空的，这是人为操作的结果。

**总结**：两者虽然都是空，但空的原因截然不同。undefined 是系统默认的“无”，而 null 是开发者主动赋予的“无”。

## 3. null与undefined的五大相同点 *Content-[05:33]

作为 JS 中两个表示“无”的特殊值，它们有五个核心的共同点，这也是开发者容易混淆的原因：

### 3.1 在 if 语句中都会被自动转为 false
- 二者都是假值（falsy values）。
- 在条件判断中直接使用，结果都是 false。
- **代码验证**：`if (null)` 和 `if (undefined)` 内部的逻辑都不会执行；只有加上取反操作符（如 `if (!null)`）时，内部的 `console.log` 才会执行。

### 3.2 都没有属性和方法，无法调用
- 二者都是完全不可变的特殊值。
- 既没有内置的属性和方法，也不能手动给其添加属性或方法。
- **代码验证**：
  - 调用方法（如 `null.toString()` 或 `undefined.toString()`）会直接触发 `Error`（Cannot read properties of null / undefined）。
  - 尝试添加属性（如 `null.name = 'test'` 或 `undefined.is = true`）也会抛出错误（Cannot set properties of null / undefined）。

### 3.3 都属于基本数据类型
- 很多学员因为 `typeof null === 'object'` 误以为 null 是引用类型，这是错误的。
- **明确结论**：null 和 undefined 都是 JS 的基本类型值，都存储在栈内存当中。
- `typeof` 的误判是 JS 早期的历史遗留问题，不影响 null 作为基本类型的本质属性。

### 3.4 松散相等（==）
- 使用双等号（`==`）进行松散比较时，`null == undefined` 返回 `true`。
- **原因**：双等号会自动进行隐式类型转换，二者都表示“无”，转化后值相等，因此返回 true。而三等号（`===`）不进行类型转换，由于两者类型不同，返回 `false`。

### 3.5 JSON 数据格式不支持 undefined
- JSON 数据格式只支持 null，不支持 undefined。
- **序列化表现**：如果对象属性值是 undefined，使用 `JSON.stringify()` 序列化时，会直接忽略该属性；如果属性值是 null，则会保留该属性并赋值为 null。
- **代码验证**：
  ```javascript
  const obj = { a: undefined, b: null, c: 1 };
  JSON.stringify(obj); 
  // 输出结果为: '{"b":null,"c":1}'
  // 属性 a 因为值为 undefined 被直接忽略
  ```

## AI 总结

null 和 undefined 是 JavaScript 中表示“无”的两个特殊值，核心区别在于语义：**undefined 表示被动的、原始的未定义状态**（系统默认），而 **null 表示主动的、人为设置的空值**（开发者意图）。在实际开发中，应遵循“语义化”原则：初始化对象变量或清空引用时使用 null，而让 JS 引擎在变量未赋值、函数未传参或对象属性不存在时自动返回 undefined。此外，两者在条件判断中均为假值，属于基本数据类型，且在松散相等（`==`）时返回 true，但在 JSON 序列化时，undefined 会被忽略而 null 会被保留。理解这些底层差异，能有效避免代码语义混乱和隐藏 Bug，提升代码的健壮性。
