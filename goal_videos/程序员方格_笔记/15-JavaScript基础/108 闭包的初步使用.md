## 1. 闭包的基本概念 *Content-[00:02]
- **字面含义**：闭包（Closure）从字面上理解，就是“闭合包起来的一个空间”、包裹结构或空间。
- **在 JavaScript 中的体现**：在 JS 中，函数就可以形成闭包。
- **作用域与闭包的关系**：
  - 函数能够形成局部作用域，这个局部作用域是不对外公开的。
  - 外部无法直接访问函数内部的数据，因此函数本身就是一个闭包结构。
- **作用域规则**：
  - 只允许函数（内部）访问外部数据。
  - 外部无法访问函数内部数据。

## 2. 为什么需要闭包：突破作用域限制 *Content-[01:19]
- **核心疑问**：既然已经学过了作用域，知道内部不允许外部访问，为什么还要专门学习闭包？
- **学习目的**：为了解决“访问函数内部数据”的问题。
- **需求场景**：
  - 假设在函数 `show` 内部定义了一个变量 `let a = 10`。
  - 我们希望在函数外部能够获取到这个值 `10`，甚至获取到变量 `a` 本身，而不仅仅是它的一个副本。

## 3. 普通返回值的局限性：值复制与内存开辟 *Content-[02:44]
- **尝试使用 `return` 获取基本数据类型**：
  - 如果在函数内部 `return a`，外部确实能拿到 `10`。
  - **局限性**：拿到的只是一个“镜像数据”（值复制），而不是变量 `a` 本身。
  - **原理**：当基本数据类型作为传参、返回值或相互赋值时，都是将值复制一份，而不是直接传递变量引用。
- **尝试使用 `return` 获取引用数据类型**：
  - 在函数内定义对象 `let p = { name: '小强', age: 16 }` 并 `return p`。
  - 外部进行两次调用：`let o1 = show()` 和 `let o2 = show()`。
  - **结果分析**：`o1 === o2` 的结果是 `false`。
  - **底层原理**：
    - 每次调用函数并执行到对象字面量 `{}` 时，相当于执行了 `new Object`。
    - `new` 关键字的核心作用之一是“开辟内存空间存储新创建的对象”。
    - 因此，两次调用开辟了两次内存空间，创建了两个内容相同但内存地址不同的对象。
    - 修改 `o1` 的属性（如 `o1.name = '呵呵'`）不会影响 `o2`，因为它们的地址不同。
- **结论**：普通的 `return` 无法实现“不管调用多少次，拿到的始终是内部同一个数据”的需求。这正是学习闭包要解决的核心痛点。

## 4. 生活案例：如何间接访问受限资源 *Content-[06:04]
- **案例背景**：
  - 邻居老张（代表上级/外部作用域）家里比较富裕，买了 PS5、游戏电脑、大屏以及哈曼卡顿环绕音箱等。其中 PS5 游戏机代表内部私有数据。
  - 老张不慷慨，不借给我（代表全局/外部无法直接访问局部/内部数据，这是 JS 的死规则，无法打破）。
- **破局思路**：
  - 老张的儿子小张（代表下级作用域/内部函数）每天在家里玩 PS5，他可以合法接触到这台游戏机。
  - 我通过给小张买盲盒抽卡、火影忍者卡片等方式贿赂他，建立良好关系。
- **间接访问过程**：
  - 我邀请小张带着 PS5 到我家来玩（通过内部函数将内部数据带出来给外部使用）。
  - 这样既没有打破“老张不借”的规则（没有违反作用域规则），又通过小张（内部函数）实现了我玩 PS5（访问内部数据）的目的。

## 5. 闭包的代码实现与核心原理 *Content-[09:39]
- **代码实现步骤**：
  - 在外部函数 `show` 内部定义变量 `p`（引用数据类型）。
  - 在 `show` 内部定义一个子函数 `fn`。根据作用域链规则，子函数 `fn` 可以访问父函数 `show` 内部的变量 `p`。
  - 将子函数 `fn` 作为 `show` 函数的返回值返回（注意：是 `return fn`，返回函数本身，而不是 `return fn()` 调用它）。
  - 外部接收这个返回的函数：`let fnOut = show()`。此时 `fnOut` 就拿到了内部的子函数 `fn`。
  - 外部调用该函数：`let o1 = fnOut()`，`let o2 = fnOut()`。
- **结果验证**：
  - 打印 `o1` 和 `o2`，内容都是 `{ name: '小强', age: 16 }`。
  - 判断 `o1 === o2`，结果为 `true`。
  - 无论外部调用多少次（`o3`, `o4` 等），得到的始终是同一个对象。
- **核心原理总结**：
  - 闭包的本质：在下级作用域（内部函数）中返回一个函数给外部作用域。
  - 外部作用域拿到这个函数后，就可以间接地访问下级作用域（父函数）内部的数据，并且保证多次访问的是同一份数据。
