## for...of 循环简介与优势 *Content-[00:00]
- **背景**：直接使用迭代器调用并自己封装循环的过程比较繁琐。为了解决这个问题，ES6 官方推出了 `for...of` 循环。
- **适用范围**：只要是具有迭代器接口（Iterator 接口）的数据结构，都可以使用 `for...of` 循环。
- **核心优势**：
  - `for...of` 是针对迭代器接口的封装，操作更加简单便捷。
  - 功能比 `for...in` 更强大，覆盖面更全面。在实际开发中，有了 `for...of` 之后，可以暂时忘掉 `for...in`。

## for...of 与 for...in 的核心区别 *Content-[01:11]
- **获取内容的差异**：
  - `for...in`：只能获取对象的键名（对于数组而言是索引值），不能直接获取键对应的值。
  - `for...of`：允许直接遍历并获得键值（即元素内容本身）。
- **代码示例（数组遍历）**：
  ```javascript
  let arr = ['a', 'b', 'c'];
  for (let i of arr) {
      console.log(i); // 直接打印每个元素的值，而非索引
  }
  ```
- **获取索引的方法**：
  - `for...of` 默认直接获取元素内容，不能直接获取索引。
  - 如果需要通过 `for...of` 获取数组索引，可以借助数组实例的 `entries()` 和 `keys()` 方法来配合实现。
- **对附加属性的处理**：
  - `for...in`：会返回数组的附加属性（包括单独绑定的自定义属性）。
  - `for...of`：调用迭代接口时，数组的迭代接口只返回具有数字索引的属性，**不会**返回附加属性。它只返回宿主元素内容本身，这也是 `for...of` 更加高级和严谨的体现。

## for...of 遍历常见数据结构 *Content-[03:43]
- **基本语法结构**：
  ```javascript
  let 变量 of 数据结构 {
      // 变量直接取每个元素的内容（值）
  }
  ```
- **遍历 Set 集合**：
  - 语法非常简单，直接遍历即可获取集合中的每个元素。
  ```javascript
  let s = new Set(['a', 'b', 'c']);
  for (let i of s) {
      console.log(i);
  }
  ```
- **遍历 Map 集合**：
  - `for...of` 遍历 `Map` 时，每次循环拿到的元素是一个包含键值对的数组（即 `[key, value]`）。
  - 可以通过中括号索引（如 `[0]` 获取键，`[1]` 获取值）来分别取值。
  ```javascript
  let m = new Map([['name', 'Alice'], ['age', 25]]);
  for (let k of m) {
      console.log(k); // 输出 ['name', 'Alice'] 等键值对数组
      console.log(k[0], k[1]); // 分别输出键和值
  }
  ```
- **底层本质**：
  - `for...of` 最终拿到的其实就是迭代器对象每次迭代返回的 `value` 属性值。
- **遍历字符串**：
  - `for...of` 同样支持遍历字符串，可以逐个获取字符串中的字符。

## 结合迭代器拓展数据结构的遍历方式 *Content-[05:41]
- 结合迭代器打底和 `for...of` 循环，可以重新审视 `Set` 和 `Map` 集合的遍历方法。
- `Set` 和 `Map` 集合原生提供以下四个遍历方法（它们返回的都是迭代器对象）：
  - `keys()`
  - `values()`
  - `entries()`
  - `forEach()`
- **面试答题技巧**：
  - 加上 `for...of` 和直接使用迭代器，每个数据结构至少拥有 **6 种**遍历方式。
  - 如果算上 `for...in`，甚至可以答出 **7 种**遍历方式。在面试中能够全面、有条理地列举这些遍历方式，能充分展现扎实的前端基础。
