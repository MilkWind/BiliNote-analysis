## 知识点总结 *Content-[00:00]

本节课主要对 JavaScript 预解析（Hoisting）的核心知识点进行了全面总结，并强调了实战案例与 JS 引擎执行机制的重要性。

### 1\. 适用范围
- **变量提升**：仅适用于使用 `var` 关键字定义的变量。
- **函数提升**：仅适用于**函数声明式**（Function Declaration）。
- **不适用场景**：预解析机制**不适用**于 `let` 和 `const` 声明的变量与函数，这一点在面试中需要特别明确。

### 2\. 变量提升机制
- **提前声明**：变量在代码执行前会被提前声明，其默认初始值为 `undefined`。
- **不提升赋值**：需要特别注意，**赋值操作是不会被提升的**，仅仅是提前了声明步骤。

### 3\. 函数提升机制
- **整体提升**：函数提升会将**整个函数**（包括函数名和函数体）提前声明。
- **优先级**：函数提升的优先级**大于**变量提升。当同名变量和函数同时存在时，函数会覆盖变量。

### 4\. 易错点与注意事项
- **函数表达式**：使用函数表达式（如 `var fn = function() {}`）定义的函数**不会**进行函数提升，这是面试中的高频易错点。
- **作用域隔离**：局部变量不会影响全局变量，在分析预解析时需严格区分全局作用域与局部作用域。

### 5\. 核心学习建议与 JS 引擎机制
- **掌握 JS 引擎执行机制**：理解代码的运行必须搞透 JavaScript 引擎执行的三个核心阶段：
  1\. **语法检查阶段**（Syntax Parsing）
  2\. **预解析阶段**（Pre-parsing / Hoisting）
  3\. **代码执行阶段**（Code Execution）
- **重视实战案例**：本节课的核心重点在于实战。必须将课程中讲解的 **20个常见实例** 完全搞清楚，这是掌握预解析的关键。
