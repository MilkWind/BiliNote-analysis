## 课程概览与数组方法分类 *Content-[00:05]
数组的常用方法是前端面试中的高频话题，虽然平时开发中经常使用，但其中隐藏着许多“魔鬼细节”。深入学习这些方法不仅能帮助我们写出更高效、简洁的声明式代码（替代繁琐的 `for` 循环），还能有效避免副作用（分清哪些方法会修改原数组是许多 Bug 的源头），同时也能向面试官证明扎实的 JavaScript 基本功。

我们可以将数组方法粗略分为以下三类：
1\. **迭代方法**：如 `forEach` 和 `map`，主要作用是遍历数组。
2\. **修改原数组的方法（Mutator methods）**：如 `push`、`pop` 以及后文重点讲解的 `splice`，这类方法会直接改变原数组数据。
3\. **返回新数组的方法**：如 `slice`、`map`、`filter`，它们不会触碰原数据，而是返回一个全新的数组。

## map 方法详解：转换与创建 *Content-[02:55]
`map` 的核心功能是对数组进行一次转换，并基于转换逻辑创建一个新数组。
- **核心特性**：不会修改原数组，属于安全方法。
- **使用示例**：假设有一个原始数字数组 `numbers`，调用 `map` 方法并传入一个箭头函数 `(number) => number * 2`。`map` 会遍历 `numbers` 中的每一个元素执行该函数，将每次返回的结果收集起来组成新数组 `doubles`。执行后，`doubles` 的值为 `[2, 4, 6, 8, 18]`（假设原数组为 `[1, 2, 3, 4, 9]`），而原始的 `numbers` 数组完好无损。

## filter 方法详解：条件筛选 *Content-[04:19]
`filter` 的核心功能是筛选，它会创建一个新数组，但新数组只包含那些通过了指定测试的元素。
- **核心特性**：不会修改原数组（Non-mutating）。
- **使用示例**：假设有一个单词数组，调用 `filter` 方法传入测试函数 `(word) => word.length > 6`。如果函数返回 `true`，该单词保留到新数组；返回 `false` 则被抛弃。最终结果数组中只包含长度大于 6 的单词。
- **注意**：与 `map` 不同，`filter` 返回的新数组长度通常会小于或等于原数组。

## reduce 方法详解：汇总与累加 *Content-[05:38]
`reduce` 是三兄弟中最强大的一个，核心思想是“汇总”或“累加”。它遍历整个数组，最终只返回一个单一的汇总值，就像把整个数组浓缩成一个精华结果。它同样是一个不改变原数组的安全方法。

- **API 结构**：`arr.reduce(callback, initialValue)`
  - `callback`：执行汇总逻辑的回调函数，接收 4 个参数，但通常只关注前两个：
    - `accumulator`（累加器）：存储上次回调执行后的返回值。
    - `currentValue`（当前值）：数组中正在被处理的当前元素。
  - `initialValue`：可选的初始值，非常关键。

- **执行过程示例（求和）**：
  数组为 `[1, 2, 3, 4]`，提供初始值 `initialValue = 0`。
  - 第 1 次循环：`accumulator` 为 0，`currentValue` 为 1，返回 `0 + 1 = 1`。
  - 第 2 次循环：`accumulator` 为 1，`currentValue` 为 2，返回 `1 + 2 = 3`。
  - 第 3 次循环：`accumulator` 为 3，`currentValue` 为 3，返回 `3 + 3 = 6`。
  - 第 4 次循环：`accumulator` 为 6，`currentValue` 为 4，返回 `6 + 4 = 10`。
  遍历结束，`reduce` 返回最终结果 10。

## splice 方法详解：数组的“手术刀” *Content-[08:23]
`splice` 是一个极其强大但也非常“危险”的方法，被称为数组的“手术刀”。
- **核心特性**：原地修改数组（Mutator 方法），可实现增加、删除、替换。**必须格外小心使用**。
- **返回值**：返回的是一个由被删除元素组成的新数组。

- **功能 1：插入元素**
  假设月份数组漏了 2 月，调用 `splice(1, 0, 'February')`。
  - 参数 1（起始索引）：`1`，在索引 1 的位置操作。
  - 参数 2（删除个数）：`0`，不删除任何元素。
  - 参数 3 及之后（插入元素）：`'February'`。
  执行后，`'February'` 成功插入，原数组被直接修改。

- **功能 2：删除元素**
  接着删除 `'April'`，调用 `splice(3, 1)`。
  - 参数 1：`3`，`'April'` 的索引。
  - 参数 2：`1`，删除 1 个元素。
  执行后，原数组被修改，且 `splice` 的返回值为 `['April']`，这个特性在某些场景下非常有用。

## 面试高频点：map 与 forEach 的核心区别 *Content-[11:07]
面试官常通过此问题考察对数组方法本质的理解，核心区别有三点：
1\. **返回值**：`map` 会返回一个全新的数组；而 `forEach` 执行后返回的是 `undefined`。
2\. **用途**：需要基于数组进行数据转换、生成新数据时使用 `map`；如果只想对数组每一项执行某个操作（如打印到控制台、发送请求），不关心返回值，则使用 `forEach`。
3\. **链式调用**：因为 `map` 返回新数组，所以可以方便地进行链式调用（如 `.map().filter()`）；而 `forEach` 返回 `undefined`，后续无法再接收任何数组方法。

## 面试高频点：reduce 的初始值陷阱 *Content-[12:31]
提供和不提供 `initialValue` 会导致 `reduce` 的行为发生显著变化：
- **提供初始值**：累加器的初始值即为传入的值，遍历从数组的第一个元素（索引 0）开始。
- **不提供初始值**：`reduce` 会默认把数组的第一个元素作为 `accumulator` 的初始值，然后从数组的第二个元素（索引 1）开始遍历。

**致命陷阱**：如果对一个**空数组**调用 `reduce` 且没有提供初始值，程序会直接抛出 `TypeError`。因为 `reduce` 既找不到 `accumulator` 的初始值，也找不到 `currentValue`。
**最佳实践**：始终给 `reduce` 提供一个明确的初始值，让代码更加健壮。

## 核心考点：数组的可变性与 React 状态管理 *Content-[13:57]
可变性（Mutability）是指哪些方法会原地修改数组，这在现代前端开发（尤其是 React）中至关重要。

- **危险的 Mutator 方法**：除了 `push`、`pop`、`splice`，还包括 `sort` 和 `reverse`。
- **React 黄金原则**：**永远不要直接修改 state**。如果直接在 React 的 state 数组上调用上述修改方法，会破坏 React 的状态更新机制，导致组件无法正常重新渲染。
- **安全做法**：使用不修改原数组的方法（如 `map`、`filter`、`reduce`、`slice`、`concat` 等），它们会返回一个全新的数据副本。在 React 中，正确的状态更新方式是**基于旧的 state 创建一个全新的 state 数组来替换它**。

## 面试高频点：slice 与 splice 的辨析 *Content-[15:42]
这对方法名字仅差一个字母 `p`，但行为截然相反：
- **slice（切片）**：从现有数组中切出一段，返回一个浅拷贝的片段。**没有任何副作用，绝对不会修改原数组**。用于安全的读取和复制。
- **splice（手术刀）**：用于添加、删除或替换元素。**这是一个有副作用的操作，会直接修改调用它的原数组**。用于修改和操作。

## 课程核心总结 *Content-[16:44]
1\. **分清数组方法的可变性**：`splice` 会修改原数组，而 `slice`、`map`、`filter` 会返回新数组。这是在 React 等框架中保证数据不可变的关键。
2\. **`map` 和 `forEach` 的核心区别**：在于返回值和用途。需要数据转换和链式调用就用 `map`，只需要执行操作就用 `forEach`。
3\. **使用 `reduce` 时注意初始值**：特别注意 `initialValue` 参数，提供该参数可以避免对空数组操作时抛出异常，提升代码健壮性。
