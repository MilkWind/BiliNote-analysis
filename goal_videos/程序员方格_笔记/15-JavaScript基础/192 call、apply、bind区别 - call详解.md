## 1. call 方法的语法与调用限制 *Content-[00:00]

- **基本语法**：`function.call(thisArg, arg1, arg2, ...)`
  - `function`：需要被调用的目标函数。
  - `thisArg`：函数运行时内部 `this` 的指向对象。你想让 `this` 指向哪个对象，就将其作为第一个参数传入。
  - `arg1, arg2, ...`：传递给目标函数的参数列表，可以接收多个参数。
- **调用限制**：
  - 调用 `call` 方法的主体**必须是一个函数**。
  - 如果使用普通对象（如 `obj.call()`）来调用，会抛出类型错误：`TypeError: obj.call is not a function`。因为普通对象的原型链上并没有 `call` 方法，只有函数对象才具备。

## 2. call 的第一个参数：this 指向 *Content-[01:49]

- `call` 的第一个参数用于显式指定函数执行时的 `this` 指向。
- **默认指向规则**：
  - 如果不传递第一个参数，或者传递的值为 `null` / `undefined`，`this` 会默认指向全局对象（在浏览器环境中即为 `window`）。
- **代码验证**：
  ```javascript
  function fn() {
      console.log(this);
  }
  fn.call(undefined); // 输出 Window 对象
  fn.call(null);      // 输出 Window 对象
  ```

## 3. call 的传参机制与注意事项 *Content-[03:15]

- **参数按位映射**：从第二个参数开始，`call` 可以接收任意多个参数。这些参数会按照位置顺序，依次映射到目标函数对应的形参上。
- **数组传参陷阱**：
  - 如果将多个参数作为一个数组整体传入（例如 `fn.call(obj, [1, 2, 3])`），这个数组会被视为一个单一的整体，仅仅映射到目标函数的**第一个形参**上。
  - 目标函数的后续形参因为没有接收到对应的实参，其值将为 `undefined`。
  - **正确做法**：参数必须逐个平铺传入（如 `fn.call(obj, 1, 2, 3)`）。将数组作为整体传入是 `apply` 方法的特性，而非 `call`。

## 4. 基础类型参数与 this 包装类型 *Content-[05:30]

- 当 `call` 的第一个参数传递字符串、数值或布尔类型等**基础数据类型**时，函数内部的 `this` 不会直接指向该基础值，而是自动转换为指向其对应的**包装类型对象**。
- **示例说明**：
  - 传入数字 `1`，`this` 指向 `Number` 包装类型对象。
  - 传入布尔值 `true`，`this` 指向 `Boolean` 包装类型对象。
  - 传入字符串，`this` 指向 `String` 包装类型对象。

## 5. call 的立即执行特性 *Content-[06:46]

- `call` 方法在改变 `this` 指向并传入参数后，会**立即执行**该函数。
- 与 `bind` 方法（返回一个新函数，不立即执行）不同，调用 `call` 的瞬间，目标函数体内的代码（如 `console.log` 或计算逻辑）就会立刻运行。

## 6. 案例一：使用 call 借用函数计算能力 *Content-[07:18]

- **场景描述**：定义一个具备计算能力的 `add` 函数，和一个自身不具备计算能力的 `myAddCall` 函数。通过 `call` 让 `myAddCall` 借用 `add` 的计算逻辑。
- **代码实现**：
  ```javascript
  // 具备计算能力的函数
  function add(x, y) {
      return x + y;
  }

  // 自身不具备计算能力的函数
  function myAddCall(x, y) {
      // 调用 add 函数的 call 方法，将 this 指向当前 myAddCall，并传入参数 x 和 y
      // 注意：实际开发中建议加上 return 以获取返回值
      return add.call(this, x, y); 
  }

  // 执行测试
  console.log(myAddCall(10, 20)); // 输出 30
  ```
- **原理解析**：
  - `myAddCall` 函数本身没有 `x + y` 的运算逻辑。
  - 通过 `add.call(this, x, y)`，将 `add` 函数的执行上下文绑定到 `myAddCall`，并传入参数。
  - 这样 `myAddCall` 就间接“继承”了 `add` 函数的求和能力，实现了代码逻辑的复用。

## 7. 案例二：使用 call 实现发工资工具函数 *Content-[10:54]

- **场景描述**：定义一个通用的发工资工具函数，让不同的员工对象调用该函数来计算并打印自己的总薪资。
- **代码实现**：
  ```javascript
  // 1. 定义发工资的工具函数
  function sendSalary(salary, bonus) {
      console.log(`${this.name} 的工资是 ${salary} 元，奖金是 ${bonus} 元，总薪资是 ${salary + bonus} 元`);
  }

  // 2. 定义员工对象
  const zhangSan = {
      name: '张三',
      department: '前端'
  };

  const liSi = {
      name: '李四',
      department: '后端'
  };

  // 3. 使用 call 改变 this 指向并传参
  // 张三调用，传入基本工资 8000，奖金 2000
  sendSalary.call(zhangSan, 8000, 2000); 
  // 输出：张三 的工资是 8000 元，奖金是 2000 元，总薪资是 10000 元

  // 李四调用，传入基本工资 8500，奖金 2500
  sendSalary.call(liSi, 8500, 2500); 
  // 输出：李四 的工资是 8500 元，奖金是 2500 元，总薪资是 11000 元
  ```
- **原理解析**：
  - `sendSalary` 是一个公共工具函数，内部通过 `this.name` 动态获取员工姓名。
  - 通过 `call` 方法，将 `sendSalary` 内部的 `this` 分别指向 `zhangSan` 和 `liSi` 对象。
  - 这样就能正确读取到对应员工的 `name` 属性，并结合传入的薪资参数完成个性化计算。这充分体现了 `call` 在复用函数逻辑、解耦数据与行为方面的强大作用。
