## JavaScript 数据类型概述 *Content-[00:00]
- 在 ECMAScript 标准中，JavaScript 的数据类型被严格分为两大类：**原始类型**（Primitive types）和**复杂类型**（Complex/Reference types）。
- **原始类型**：
  - 共有 7 种，分别是 `undefined`、`null`、`Boolean`、`Number`、`BigInt`、`String` 和 `Symbol`。
  - 这些值直接存储在**栈内存**（Stack memory）中。
  - 它们是构建程序数据的基础。
- **复杂类型**：
  - 有且只有一种，即 `Object`（对象）。
  - 在 JavaScript 中，数组（Array）、函数（Function）、日期（Date）等本质上都是对象。

## 类型判断：typeof 操作符 *Content-[00:39]
- 判断一个变量是什么类型，最常用的方法是 `typeof` 操作符。
- `typeof` 可以准确返回 `number`、`string`、`boolean` 等对应的字符串。
- **历史遗留特例**：
  - `typeof null` 返回的是 `"object"`。
  - 这是因为 `null` 在底层被表示为一个空对象指针，这是从 JavaScript 诞生之初就存在的历史遗留问题，只需牢记此特例即可。
- 对于 ES6 新增的 `Symbol` 和 ES2020 新增的 `BigInt`，`typeof` 也能够正确识别（分别返回 `"symbol"` 和 `"bigint"`）。

## 原始类型详解：undefined 与 null *Content-[01:50]
这两个类型都代表某种形式的“空”或“没有”，但它们的语境和用法有本质区别。

- **undefined**：
  - 该类型只有一个值，即 `undefined`。
  - 它通常是一种**被动状态**。当使用 `let` 或 `var` 声明了一个变量但没有赋予初始值时，该变量的默认值就是 `undefined`。
  - 语义上代表“未定义”或“不存在”的状态。
- **null**：
  - 该类型也只有一个值，即 `null`。
  - 与 `undefined` 的被动性不同，`null` 通常是**主动赋值**的。
  - 语义上表示一个“空对象指针”。如果想明确表示一个变量当前不指向任何对象，或者想清空一个对象的引用，就应该给它赋值为 `null`。
- **比较操作差异**：
  - 使用相等操作符 `==` 比较 `null` 和 `undefined` 时，结果为 `true`（因为在宽松比较时它们都会被转换为 `false`）。
  - 使用全等操作符 `===` 比较时，结果为 `false`，因为它们的类型完全不同。
  - **结论**：这也是为什么在实际开发中始终推荐使用全等 `===` 的重要原因之一。

## 原始类型详解：Boolean、Number 与 BigInt *Content-[03:44]
- **Boolean（布尔类型）**：
  - 非常简单，只有 `true` 和 `false` 两个值，通常用于逻辑判断中。
  - **隐式转换规则**：JavaScript 中任何类型的值都可以被转换成布尔值。
    - 会被转换为 `false` 的值（假值）：`false`、`0`、`""`（空字符串）、`null`、`undefined` 和 `NaN`。
    - 其他所有的值都会被转换为 `true`。
- **Number（数字类型）**：
  - 用来表示所有数字，包括整数和浮点数。
  - **特殊值 NaN (Not a Number)**：
    - 意思是“非数字”，例如算式 `0 / 0` 的结果就是 `NaN`。
    - **奇特属性**：`NaN` 不等于任何东西，甚至不等于它自己（`NaN === NaN` 为 `false`）。
    - **判断方法**：不能使用相等操作符判断，必须使用 `isNaN()` 函数来判断一个值是不是 `NaN`。
  - **类型转换函数**：经常使用 `Number()`、`parseInt()`、`parseFloat()` 这三个函数来把其他类型的值转换成数字。
- **BigInt（大整数类型）**：
  - ES2020 新增的类型，主要为了解决 JavaScript 中 `Number` 类型无法精确表示超大整数的问题。
  - 可以表示任意大的整数，其字面量后面必须跟一个 `n`（例如 `123n`）。
  - **注意事项**：`BigInt` 和 `Number` 是两种不同的类型，不能直接把它们进行混合运算，否则程序会报错。

## 原始类型详解：String 与模板字面量 *Content-[06:19]
- **String（字符串类型）**：
  - 用来表示文本数据。
  - **核心特性：不可变性**。意味着一个字符串一旦被创建，其内部的字符序列就是固定的，无法直接修改。
  - 我们平时使用的 `toUpperCase()` 或 `substring()` 等方法，看似在修改字符串，实际上并没有修改原始字符串，而是创建并且返回了一个全新的字符串。
  - **类型转换**：通常使用 `toString()` 或 `String()` 函数将其他类型的值转换成字符串。
- **ES6 模板字面量（Template Literals）**：
  - ES6 之前拼接字符串（特别是包含各种变量时）需要写一堆 `+` 号，非常繁琐。
  - 模板字符串使用**反引号**（`` ` ``）定义，彻底改变了这一痛点。
  - **字符串插值**：支持使用 `${}` 语法，非常方便地把变量或者表达式的值嵌入到字符串里面，可读性比传统的 `+` 拼接高得多。
  - **多行字符串**：天然支持多行字符串，不需要再用 `\n` 这样的方法去手动换行，在长文本书写或 HTML 模板场景中非常方便。

## 原始类型详解：Symbol *Content-[08:47]
- **Symbol** 是 ES6 引入的一个全新的原始数据类型。
- **核心任务**：创建一个**独一无二**的值。
- **主要用途**：
  - 最常见的用途是作为对象的属性 key。因为 `Symbol` 的值是唯一的，用它做 key 可以保证绝对不会与其他任何的属性名发生冲突。
  - 在定义一些需要隐藏或者内部使用的对象属性时特别有用。
  - JavaScript 内部也使用了很多内置的 `Symbol`，例如 `Symbol.iterator` 用来定义对象的某些底层行为。
- **创建与使用细节**：
  - 创建方式非常简单，直接调用 `Symbol()` 函数即可。
  - **唯一性验证**：每次调用 `Symbol()` 函数，即便传入相同的描述符，返回的都是一个全新且不相等的值（例如 `Symbol('foo') !== Symbol('foo')`）。
  - **作为对象 key**：必须把它放到方括号 `[]` 里面（这被称为**计算属性名**），然后就可以通过这个 `Symbol` 变量来访问对应的属性值了。

## 复杂类型详解：Object *Content-[10:43]
- **Object（对象）** 是 JavaScript 中最重要的数据结构，可以被看作是一系列属性的集合。
- **核心特性**：
  - **键值对集合**：每个属性都由一个 key 和一个 value 组成，使用花括号 `{}` 来创建对象字面量。
  - **引用类型**：这是与原始类型最根本的区别。当把对象赋值给一个变量时，变量里面存储的并不是对象本身，而是它在内存中的**地址**。
    - 如果把这个变量再赋给另外一个变量，这两个变量实际上指向的是同一个内存地址。因此，修改其中一个就会影响到另外一个。
  - **Key 的类型**：对象的属性名（key）可以是 `String`，也可以是 `Symbol`。
  - **动态性**：可以在程序运行的任何时候，给它添加新的属性，或者修改、删除已有的属性。
    - 例如，可以随时用点操作符 `.` 访问和修改属性，或者随时添加一个新的 `city` 属性。这种动态性给编程带来了极大的灵活性。
