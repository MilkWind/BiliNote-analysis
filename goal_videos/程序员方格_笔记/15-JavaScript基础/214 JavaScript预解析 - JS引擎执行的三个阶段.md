## 1. 预解析面试题解析与重要性 *Content-[00:00]
- **面试核心门槛**：预解析是面试官筛选候选人基础是否扎实的第一道门槛，直接关系到能否拿到大厂 offer 和顺利就业。很多学员写代码没问题，但面试被问到预解析时答不上来或颠三倒四，容易被直接 pass。
- **考察重点**：面试官不仅看重代码的输出结果，更看重候选人对执行过程、底层原因和 JS 执行机制的理解。仅仅蒙对答案而没有过程推导是毫无意义的。
- **五道大厂真实高频面试题**（近一年学员反馈原题）：
  1. 写出代码的输出结果，并说明原因是什么。
  2. 写出代码的输出结果，并解释执行过程。
  3. 判断代码是否报错；若不报错，输出结果是什么及为什么。
  4. 写出代码的输出结果，重点说明预解析的作用。
  5. 大厂高频压轴题：写出输出结果并详细说明每一步的执行过程（典型考察预解析结合作用域）。

## 2. 什么是预解析及JS引擎执行的三个阶段 *Content-[02:15]
- **预解析的定义**：预解析是 JS 引擎在执行代码之前先做的准备工作。就像做饭前需要先把菜洗好、切好、调料准备好再开火炒菜一样，JS 执行代码也是先做准备再执行，这个准备工作就是预解析。
- **JS 引擎执行的三个阶段**：
  1. 语法分析阶段
  2. 预编译阶段（即预解析阶段）
  3. 执行阶段

## 3. JS代码块的加载与执行顺序 *Content-[02:51]
- **加载与执行机制**：浏览器首先按照顺序加载由 `<script>` 标签分隔的 JS 代码块。加载完毕后，立即进入上述的三个阶段。执行完成后，再按顺序查找下一个代码块，继续执行以上三个阶段。
- **脚本类型**：无论是外部脚本文件还是内部脚本代码块，执行原理都是一样的。
- **作用域**：所有的代码块都在同一个全局作用域中执行。

## 4. 第一阶段：语法分析阶段 *Content-[03:30]
- **触发时机**：JS 脚本代码加载完毕后，首先进入语法分析阶段。
- **主要作用**：分析该 JS 脚本代码块的语法是否正确。
- **处理逻辑**：
  - **语法错误**：如果语法不正确，会向外抛出语法错误（如 `SyntaxError`），停止该 JS 代码块的执行，然后继续查找并加载下一个代码块。
  - **语法正确**：如果语法检查通过，则进入第二个阶段（预编译阶段）。
- **示例说明**：如果编写 `function fn() { alert('你好')` （故意漏掉右大括号），在调用 `fn()` 时会直接报语法错误。此时代码停留在语法检查阶段，无法进入后续的预解析和执行阶段。

## 5. 第二阶段：预编译（预解析）阶段 *Content-[05:02]
- **触发时机**：JS 代码块通过了语法分析阶段后进入。
- **核心机制**：在当前作用域中，JS 代码执行之前，浏览器会默认将所有带 `var` 和 `function` 声明的变量和函数进行提前的声明或定义，这就是常说的**变量提升**。
- **关键细节（面试常考）**：
  - `let` 和 `const` 声明的变量**不参与**预解析（不存在变量提升）。
  - 通过 `var` 和 `function` 声明的变量/函数会被提前放到内存中（声明提前）。
  - `var` 声明的变量初始值会被赋为 `undefined`。
  - 变量的**赋值操作**不会提前，仍然在执行阶段的原位置进行。

## 6. 第三阶段：执行阶段与作用域链 *Content-[05:58]
- **核心机制**：逐行解读代码。
- **执行细节**：
  - 遇到表达式时，会改变原来“预解析仓库”（预解析阶段生成的内存空间）中的内容，即进行变量的实际赋值。
  - 遇到函数调用时，会开启一个新的作用域，并**重新开始**上述的三个阶段（语法分析、预解析、执行），逐行解读函数内部的代码。
- **作用域链（Scope Chain）机制**：
  - 如果在函数作用域内部，没有通过 `var` 或 `function` 找到所需的变量，就会返回到父级作用域继续查找。
  - 这就是作用域链的形成过程：当前作用域找不到变量时，会向上级（父级）作用域逐层查找，直到全局作用域。

## AI 总结
本视频详细讲解了 JavaScript 预解析的核心概念及其在面试中的重要性。预解析是 JS 引擎执行代码前的准备工作，整个过程分为语法分析、预编译（预解析）和执行三个阶段。在预编译阶段，`var` 和 `function` 声明的变量和函数会被提前声明（变量提升），而 `let` 和 `const` 则不参与此过程。在执行阶段，代码逐行运行并进行赋值，遇到函数调用时会开启新作用域并重新执行三个阶段，同时结合作用域链机制向上查找变量。掌握这一底层执行机制，是解答前端高频面试题、通过大厂面试的关键。
