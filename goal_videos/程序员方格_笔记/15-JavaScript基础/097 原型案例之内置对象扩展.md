## 引入与原型回顾 *Content-[00:00]

在之前的课程中，我们已经系统学习了 JavaScript 中的原型（Prototype）机制。回顾核心知识点包括：
1\. **原型的概念**：理解原型在 JavaScript 中的基础定义。
2\. **原型的使用与作用**：掌握如何利用原型实现属性和方法的共享。
3\. **原型的替换**：学习如何替换构造函数的默认原型对象。
4\. **访问原型的两种方式**：掌握通过 `__proto__` 和 `constructor.prototype` 等方式访问原型链。

今天将通过一个实际的内置对象扩展案例，深入探讨原型在实际开发中的高级应用。

## 案例需求：为数组扩展求和方法 *Content-[00:25]

JavaScript 提供了许多内置对象（如 `Array`、`Number`、`String` 等）。本案例以 `Array`（数组）为例，探讨如何进行内置对象的方法扩展。

**需求描述**：
我们知道数组自带许多方法，例如 `reverse`（数组反转）。现在的需求是：为数组增加一个自定义的求和方法 `sum`。
期望的使用方式如下：
```javascript
let arr = [1, 2, 3, 4, 5];
// 期望能够直接调用 arr.sum() 得到数组元素的总和
```

## 错误做法一：直接在数组实例上绑定方法 *Content-[03:14]

最直观的想法是直接在具体的数组实例上添加 `sum` 方法。

**代码实现**：
```javascript
let arr1 = [1, 2, 3];
arr1.sum = function() {
    let a = 0;
    for (let i = 0; i < this.length; i++) {
        a += this[i];
    }
    return a;
};

console.log(arr1.sum()); // 输出 6，求和成功
```

**存在的问题**：
这种方法虽然能让 `arr1` 成功调用 `sum`，但它**仅仅给 `arr1` 这一个特定实例绑定了该方法**。
如果创建了其他数组实例（如 `arr2`、`arr3` 等），它们依然无法调用 `sum` 方法。这违背了“让所有数组对象共享同一个 `sum` 方法”的初衷，因此这种做法是不可取的。

## 错误做法二：直接修改内置对象原型（污染全局） *Content-[04:25]

既然需要让所有数组共享方法，自然会想到通过修改数组的构造函数原型来实现。

**代码实现**：
```javascript
// 数组对象的构造函数是 Array
Array.prototype.sum = function() {
    let a = 0;
    for (let i = 0; i < this.length; i++) {
        a += this[i];
    }
    return a;
};

let arr1 = [1, 2, 3];
let arr2 = [4, 5, 6];
console.log(arr1.sum()); // 输出 6
console.log(arr2.sum()); // 输出 15
```

**存在的问题（极其危险）**：
虽然这种做法完美实现了需求，但在实际开发中是**非常危险的操作**。
1\. **污染全局环境**：这相当于直接在系统自带的内置对象上进行了修改，会影响全局所有的代码。
2\. **生动比喻**：就像你觉得公共空间的路灯太亮，直接上去把路灯砸了。公共空间的设施是不能随意破坏的。
3\. **覆盖原生方法的风险**：如果不仅新增方法，还不小心覆盖了原生方法，会导致灾难性后果。例如：
   ```javascript
   Array.prototype.reverse = function() {
       // 写了一段不翻转的代码
   };
   ```
   一旦执行，项目中所有调用 `reverse()` 的地方都会失效，导致整个系统崩溃。因此，**绝对不要直接修改系统内置对象的原型**。

## 正确做法：自定义构造函数与原型替换 *Content-[07:15]

既然不能直接修改系统的路灯，我们可以“自己造一个路灯”。即：不修改系统自带的 `Array`，而是克隆或自定义一个高仿的数组系统，然后在这个自定义系统上扩展方法。

**实现步骤**：

1\. **定义自定义构造函数**：
   ```javascript
   function MyArray() {
       // 自定义数组构造函数
   }
   ```

2\. **进行原型替换**：
   将 `MyArray` 的原型替换为一个空的数组实例 `[]`。
   ```javascript
   MyArray.prototype = [];
   ```
   *原理说明*：原型的本质是对象，而数组本身也是对象。将原型替换为数组对象后，`MyArray` 实例化出来的对象就可以直接继承并调用数组的所有原生方法（如 `push`、`reverse` 等）。

3\. **在自定义原型上扩展方法**：
   ```javascript
   MyArray.prototype.sum = function() {
       let a = 0;
       for (let i = 0; i < this.length; i++) {
           a += this[i];
       }
       return a;
   };
   ```

4\. **实例化并使用**：
   注意，由于是我们自定义的构造函数，不能使用数组字面量 `[]` 创建实例，需要使用传统的方式。
   ```javascript
   let my1 = new MyArray();
   my1.push(0, "张飞", 1, "刘备", 2, "关羽"); 
   // 注：视频中演示了 push 元素，实际求和时通常 push 数字
   
   // 测试原生方法
   my1.reverse(); 
   console.log(my1); // 数组成功反转，证明继承了 Array 的方法
   
   // 测试自定义方法
   let my2 = new MyArray();
   my2.push(1, 3, 8);
   console.log(my2.sum()); // 成功输出 12
   ```

**优势**：
通过这种方式，针对 `MyArray` 原型的所有修改和扩展，都只作用于 `MyArray` 的实例，**完全不会影响系统原本自带的 `Array` 内置对象**，保证了代码的安全性和全局的稳定性。

## 总结与最佳实践 *Content-[12:10]

在进行内置对象扩展时，必须遵循以下最佳实践：
1\. **严禁直接修改原生内置对象**（如 `Array.prototype`、`Object.prototype`），以防止全局污染和原生方法被覆盖的致命风险。
2\. **采用“高仿”策略**：通过自定义构造函数，并利用**原型替换**技术（将自定义构造函数的 `prototype` 指向一个原生内置对象的实例，如 `[]`），来继承原生对象的所有能力。
3\. **在自定义原型上扩展**：将需要新增的业务方法挂载到自定义构造函数的原型上，实现方法的共享与安全隔离。

建议大家课后将这个“自定义数组并扩展方法”的案例亲自敲一遍，深入理解原型替换的精髓。
