## 面试题介绍与实现思路 *Content-[00:00]
- **题目要求**：实现字符串的大小写翻转，即原来的大写字母转换为小写，原来的小写字母转换为大写。注意，这并非简单的全部转为大写或全转为小写。
- **实现思路**：视频中将分别使用两种不同的方式来实现该功能，以展示不同的编程思维与代码实现技巧。

## 方法一：使用 for 循环遍历 *Content-[00:16]
- **函数封装**：定义一个函数 `changeStr(str)`，接收需要转换的字符串作为参数。
- **初始化变量**：定义一个空字符串 `let result = ''` 用于存放转换后的结果。
- **遍历字符串**：使用普通的 `for` 循环遍历字符串的每一个字符。
  ```javascript
  for (let i = 0; i < str.length; i++) {
      // 处理逻辑
  }
  ```
- **判断大小写的巧妙方法**：
  - 不使用 ASCII 码值进行判断。
  - 利用字符串内置方法：判断 `str[i] === str[i].toUpperCase()`。
  - **原理**：如果当前字符转为大写后与自身相等，说明它原本就是大写字母（数字和特殊字符转换后也是本身，在此逻辑中统一归为非小写处理）；如果不相等，则说明它是小写字母。
- **拼接转换结果**：
  - 如果判断为大写（或非字符），则将其转为小写并拼接：`result += str[i].toLowerCase()`。
  - 否则（小写），将其转为大写并拼接：`result += str[i].toUpperCase()`。
- **返回结果**：循环结束后，直接返回拼接好的 `result` 字符串。

## 方法二：使用 split 与 map 方法 *Content-[05:25]
- **字符串转数组**：使用 `split('')` 方法将字符串拆分成由单个字符组成的数组。
  ```javascript
  let arr = str.split('');
  ```
- **使用 map 遍历与转换**：
  - 利用数组的 `map` 方法遍历每个元素，并结合**三元表达式**进行大小写判断和转换。
  ```javascript
  let newArr = arr.map(item => {
      return item === item.toUpperCase() ? item.toLowerCase() : item.toUpperCase();
  });
  ```
  - **逻辑**：如果 `item` 等于它的大写形式，说明是大写，返回其小写形式；否则返回其大写形式。
- **数组转回字符串**：
  - `map` 方法返回的是一个新数组，不能直接返回数组。
  - 需要使用 `join('')` 方法将数组重新拼接成字符串。
  ```javascript
  return newArr.join('');
  ```

## 两种方法对比与总结 *Content-[07:55]
- **方法一（for 循环）**：
  - **优点**：逻辑最为直观，容易理解，通常是遇到该问题时的第一反应。
  - **优化**：在 `for` 循环内部，也可以将 `if-else` 语句替换为三元表达式来简化代码，但务必注意 `result` 变量必须在循环外部定义，并在循环内部进行拼接。
- **方法二（split + map）**：
  - **优点**：代码更加简短、优雅，充分利用了 JavaScript 数组的高阶函数特性。
  - **特点**：需要稍加思考转换思路，但实现起来非常简洁。

## AI 总结 *Content-[08:18]
本次视频详细讲解了前端面试中常见的“字符串大小写翻转”问题。核心难点在于如何优雅地判断字符的大小写。视频提供了两种主流解法：
1. **传统 for 循环法**：通过对比字符与其大写形式是否相等来判断大小写，逻辑清晰直观。
2. **数组高阶函数法**：结合 `split`、`map` 和 `join`，并辅以三元表达式，使代码更加简洁优雅。
