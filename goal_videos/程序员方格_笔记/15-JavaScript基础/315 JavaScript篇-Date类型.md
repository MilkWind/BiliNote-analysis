## 1. Date 类型基础概念与存储机制 *Content-[00:32]
- **整体认知**：`Date` 类型是 JavaScript 中专门用来处理日期和时间的引用类型，提供了一整套获取和操作日期时间的 API。
- **设计渊源**：早期设计时很大程度上借鉴了 Java 中的 `java.util.Date` 类。
- **时间基准**：基于 UTC 时间 1970 年 1 月 1 日 0 点（UNIX 纪元）作为基准时间进行计算。UNIX 操作系统诞生之初选择了此节点，后随 Linux 普及成为计算机系统时间表示的事实标准。
- **底层存储机制**：
  - 内部并非以字符串或结构体形式存储，而是存储为一个**整数**。
  - 该整数代表从基准时间（1970-01-01 00:00:00）开始所经过的**毫秒数**。
  - 这种设计使得日期存储非常紧凑，且方便进行数学计算。
- **时间范围**：基于毫秒数存储机制，`Date` 类型可以表示的时间范围非常广，大约是基准时间前后各 28 万年，满足绝大多数应用场景。

## 2. 创建 Date 对象的常见方式 *Content-[02:46]
使用 `new Date()` 构造函数创建日期对象，主要有以下三种方式：
- **不传递参数**：
  - 新创建的对象会自动保存当前的日期和时间。
  - 适用场景：记录用户操作时间、生成当前时间戳。
- **传入一个数字（时间戳）**：
  - 数字代表距离 1970 年 1 月 1 日的毫秒数。
  - 适用场景：处理后端接口返回的数据（底层操作系统通常存储整数时间戳）。
- **传入日期字符串**：
  - 构造函数会尝试解析字符串并创建对应对象，支持多种格式（如美式 `May 23, 2019` 或 `2019-05-23`）。
  - **注意事项**：不同浏览器对标准/非标准格式的解析支持程度不同。为保证跨环境表现一致，**推荐尽量使用时间戳格式或标准的 ISO 格式**进行初始化。

## 3. Date.parse() 方法详解 *Content-[04:50]
- **功能**：`Date.parse()` 是一个静态方法，接收一个日期字符串，尝试将其解析并转换为毫秒数。
- **支持的格式**：
  - 斜杠分割的月/日/年。
  - 英文描述的月 日, 年。
  - 包含时区信息的完整格式。
- **推荐标准格式**：最标准且在各浏览器解析最可靠的是 **ISO 8601 扩展格式**，即 `YYYY-MM-DD` 形式。
- **与构造函数的关系**：
  - 可以直接调用 `Date.parse()` 获取毫秒数，再传给 `new Date()`。
  - 实际上，当直接向 `new Date()` 传入字符串时，构造函数内部会在后台自动调用 `Date.parse()`，两者在功能上完全等价。
- **错误处理**：如果传入的字符串格式无法识别，`Date.parse()` 会返回 `NaN`，这会导致后续的日期处理出现错误。

## 4. Date.UTC() 方法与本地时间区别 *Content-[06:44]
- **功能**：`Date.UTC()` 接收一组数值参数，并返回对应的 UTC 时间戳。
- **参数顺序**：年、月、日、时、分、秒、毫秒。
- **核心易错点（月份从 0 开始）**：
  - 月份参数是从零开始计数的：`0` 代表 1 月，`1` 代表 2 月，以此类推，`11` 代表 12 月。
  - 例如：表示 5 月份必须传入数字 `4`。
- **默认值**：除了年和月是必须的，后面的参数如果不传，默认都是 `0` 或 `1`（日默认为 1）。
- **与 `new Date()` 传参的关键区别（时区问题）**：
  - `Date.UTC()` 将传入的参数视为 **UTC 时间**（格林威治标准时间）。
  - 直接向 `new Date()` 传入年月日参数时，浏览器会将其视为**本地时间**。
  - **示例**：在中国（东八区），`new Date(2000, 0)` 创建的是北京时间 2000 年 1 月 1 日，但在 UTC 时间上实际上是前一天的下午 4 点。
  - **建议**：在处理跨时区业务时，务必清楚区分这两者的时区差异。

## 5. Date.now() 方法与性能分析 *Content-[09:00]
- **功能**：ES5 引入的实用方法，返回代码执行那一刻的毫秒数时间戳。
- **优势**：
  - 相比于早期的 `new Date().getTime()`，代码更加简洁。
  - 不需要创建一个完整的 `Date` 对象实例，**性能开销更小**。
- **经典应用场景（性能分析）**：
  - 用于测量一段代码的执行耗时。
  - 在执行前调用 `Date.now()` 记录开始时间，执行后记录结束时间，两者相减即可得到耗时。
- **高精度场景补充**：
  - 对于日常开发，`Date.now()` 已经足够。
  - 但在进行高精度动画或专业性能调优时，现代浏览器提供了 `performance.now()` 方法。
  - `performance.now()` 能提供亚毫秒级的浮点数精度，比 `Date.now()` 更加精确。
