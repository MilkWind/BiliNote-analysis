## 如何精准判断真伪数组 *Content-[00:00]
在前端开发中，不能仅凭对象“长得像数组”（例如具有 `length` 属性和索引）就判断它是数组。必须使用精准的方法来进行判断。接下来将详细介绍两种核心的判断方法。

## 方法一：Array.isArray() *Content-[00:40]
这是开发中的首选方法，根据场景作答时最常用。

### 1\. 方法概述
- **来源**：ES6 新增的数组静态方法。
- **作用**：专门用于判断目标是否为真数组，返回布尔值（`true` 或 `false`）。
- **语法**：`Array.isArray(目标对象)`

### 2\. 代码示例
```javascript
// 1. 自定义伪数组
let likeArr = {
    0: 1,
    1: 2,
    length: 2
};
console.log(Array.isArray(likeArr)); // 返回 false，因为它是伪数组

// 2. 真数组
let realArr = [];
console.log(Array.isArray(realArr)); // 返回 true
```

### 3\. 方法优势
- **简单直接**：专门针对数组进行判断，没有歧义。
- **开发首选**：在日常开发中是最常用、最便捷的方式。

## 方法二：Object.prototype.toString.call() *Content-[02:47]
这是 JS 中最精准的类型判断方法，属于“万能判断方法”，能够返回对象的原始类型，覆盖所有数据类型。这是大厂面试必问的知识点，回答时提及此方法可以直接加分。

### 1\. 方法概述
- **语法**：`Object.prototype.toString.call(目标对象)`
- **判断标准**：
  - **真数组**：返回 `[object Array]`。
  - **伪数组**：返回非 `Array` 的类型，如 `[object Object]`、`[object Arguments]`、`[object NodeList]`、`[object HTMLCollection]`、`[object FileList]` 等。

### 2\. 代码示例与具体场景
```javascript
// 场景 1：自定义伪数组
let likeArr = { 0: 1, 1: 2, length: 2 };
console.log(Object.prototype.toString.call(likeArr)); 
// 返回: [object Object]

// 场景 2：获取 DOM 节点集合
let arrDiv = document.getElementsByTagName('div');
console.log(Object.prototype.toString.call(arrDiv)); 
// 返回: [object HTMLCollection]

// 场景 3：函数的 arguments 对象
function testFn() {
    console.log(Object.prototype.toString.call(arguments)); 
    // 返回: [object Arguments]
}
testFn(1, 2, 3, 4, 5);

// 场景 4：input 上传的文件列表 (FileList)
// HTML: <input type="file" id="fileInput">
let fileInput = document.getElementById('fileInput');
fileInput.onchange = function() {
    let files = this.files;
    console.log(Object.prototype.toString.call(files)); 
    // 返回: [object FileList]
};
```

### 3\. 面试回答技巧
- 在面试时，**不需要**死记硬背所有返回的具体节点类型（如 `HTMLCollection`、`FileList` 等）。
- **核心表达**：只需说明使用 `Object.prototype.toString.call()` 方法可以精准区分真伪数组。如果是真数组，返回结果包含 `Array`；如果是伪数组，返回结果则不是 `Array`。

### 4\. 方法优势
- **精准区分**：能够准确区分伪数组的具体底层类型（如 `Arguments`、`FileList` 等）。
- **更全面**：相比于 `Array.isArray()` 只能返回 `true/false`，该方法能提供更详细的类型信息，覆盖面更广。

本视频详细讲解了前端开发中精准判断真伪数组的两种核心方法。第一种是 ES6 的 `Array.isArray()`，它简单直接，是日常开发的首选；第二种是 `Object.prototype.toString.call()`，作为 JS 中最精准的类型判断方法，它不仅能区分真伪数组，还能精准识别伪数组的具体底层类型（如 `Arguments`、`HTMLCollection`、`FileList` 等），是应对大厂面试的加分利器。掌握这两种方法的适用场景与底层原理，能够有效提升代码的严谨性与面试表现。
