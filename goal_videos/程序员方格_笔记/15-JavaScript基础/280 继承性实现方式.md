## 引言与继承的核心机制 *Content-[00:00]
- **面试常见问题**：在 JavaScript 中如何实现继承？其底层原理是什么？
- **回答重点**：应聘者需要了解 JavaScript 继承特性的演进过程（从早期的实现方式到现代的语法糖），并掌握其底层原理。
- **核心机制**：JavaScript 中的继承是通过**原型链（Prototype Chain）** 来实现的，这是实现面向对象编程的核心机制之一。两个模块（对象）之间的继承，本质上是通过原型链的交集与指向来完成的。

## 原型链底层原理与示例 *Content-[03:05]
- **隐藏属性**：每个对象都有一个隐藏的 `__proto__` 属性，通过该属性形成链状结构，指向其原型对象。
- **属性与方法查找机制**：
  - 当访问对象的属性或方法时，如果对象自身没有，引擎会沿着 `__proto__` 原型链向上查找。
  - 如果在原型链上找到，则直接使用；如果一直查找到原型链顶端（`null`）仍未找到，则返回 `undefined`。
- **继承的本质**：将子对象的原型链指向父对象。当子对象自身没有某方法时，通过原型链访问到父对象的方法，从而实现继承。
- **代码示例解析**：
  - 定义 `Animal` 构造函数，并在其 `prototype` 上添加 `speak` 方法。
  - 实例化 `dog` 对象，此时 `dog.__proto__ === Animal.prototype` 为 `true`，说明它们共用同一个原型对象。
  - `dog` 实例可以直接调用 `speak` 方法，成功实现方法级别的继承。

## 继承方式一：原型链继承 *Content-[07:05]
- **实现方式**：将子类的 `prototype` 直接指向父类的实例化对象。
- **代码实现**：
  - 让子类原型指向父类实例：`Cat.prototype = new Animal()`。
  - 修复 `constructor` 指向：`Cat.prototype.constructor = Cat`，防止子类自身的独立属性丢失。
- **缺点与问题**：
  - **共享引用属性**：所有子类实例会共享父类实例中的引用类型属性。
  - **属性冗余**：父类实例化对象中的所有属性都会被继承，即使子类并不需要。
  - **意外修改**：任何一个实例修改了共享的引用属性，都会影响其他所有实例。
- **结论**：这是最经典的早期继承方式，但由于上述缺陷，并非最优方案。

## 继承方式二：组合继承 *Content-[10:01]
- **背景**：在 ES6 出现之前，这是使用最广泛、最成熟的继承方案。
- **核心思想**：结合**构造函数继承属性**和**原型链继承方法**，将两者分开处理。
- **代码实现**：
  - **继承属性**：在子类构造函数中调用父类构造函数 `Animal.call(this, name)`。这种方式具有针对性，需要哪个属性就继承哪个，实现了属性的独立。
  - **继承方法**：使用 `Object.create(Animal.prototype)` 创建父类原型的副本，并将其赋值给子类的 `prototype`。这样避免了直接实例化父类，同时实现了方法的复用。
  - **修复指向**：重新修复子类的 `constructor` 指向，确保自身拥有独立属性。
- **优点**：属性独立，方法复用，解决了原型链继承中引用属性共享的问题。
- **缺点**：在实现过程中，调用了两次父类的构造函数，存在一定的性能损耗。

## 继承方式三：ES6 Class 继承 *Content-[13:12]
- **背景**：ES6 引入了 `class` 和 `extends` 关键字，提供了语法糖级别的继承方式。
- **底层本质**：虽然写法直观，但其底层仍然是基于原型链实现的继承。
- **代码实现**：
  - 使用 `class` 定义父类 `Animal`，包含 `constructor(name)` 和 `speak()` 方法。
  - 使用 `class Dog extends Animal` 定义子类，`extends` 表示继承关系。
  - 在子类的 `constructor` 中，必须调用 `super(name)` 来继承父类的属性并初始化 `this`。
  - 子类可自由添加自身的属性和方法。
- **优点**：语法简洁、通俗易懂，符合传统的面向对象编程思维，是目前最推荐的写法。

## 三种继承方式对比总结 *Content-[14:24]
1\. **原型链继承**：实现简单，但会共享引用属性，容易导致意外修改，不推荐用于复杂场景。
2\. **组合继承**：实现了属性独立与方法复用，是 ES6 之前的主流方案，但存在调用两次父类构造函数的性能问题。
3\. **ES6 Class 继承**：语法简洁直观，本质仍是原型链继承，综合体验最佳，是现代前端开发的标准实践。
