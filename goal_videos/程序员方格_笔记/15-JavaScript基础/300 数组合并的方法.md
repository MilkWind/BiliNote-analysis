## 基础合并方法 *Content-[02:00]
### 1\. `concat` 方法
- **用法**：`array1.concat(array2)`，将两个数组连接起来。
- **特点**：
  - **不修改原数组**：原数组保持不变，返回一个全新的合并后的数组。
  - **兼容性好**：作为早期就存在的方法，所有浏览器均支持。
- **评价**：最基础、第一时间能想到的方法。能说出来说明有实际使用经验，但在 ES6 时代显得不够“先进”。

### 2\. ES6 扩展运算符（Spread Operator `...`）
- **用法**：`const newArray = [...array1, ...array2]`，将数组成员展开并放入新数组中。
- **特点**：
  - **ES6 语法**：代码更加简洁、现代化。
  - **支持多数组合并**：不仅可以合并两个数组，还可以轻松合并三个、四个或更多数组（如 `[...arr1, ...arr2, ...arr3]`）。
- **评价**：比 `concat` 更进一步，是目前日常开发中最常用的基础合并方式。

## 进阶合并需求（带条件合并） *Content-[05:10]
除了简单的拼接，实际开发中常有附带条件的合并需求，掌握这些能大幅提升面试表现。

### 1\. 合并后去重
- **场景**：合并两个数组，且要求结果中不能有重复元素。
- **实现方法**：利用 ES6 的 `Set` 数据结构。`Set` 内部的成员是不允许重复的，自带去重功能。
- **代码示例思路**：`const uniqueArray = [...new Set([...array1, ...array2])]`。
- **解析**：先用扩展运算符合并两个数组，再用 `Set` 进行去重，最后使用扩展运算符将 `Set` 展开回数组格式。

### 2\. 交叉合并（交替合并）
- **场景**：希望两个数组交叉/交替合并，例如数组 `['A', 'B', 'C']` 和 `[1, 2, 3]` 合并为 `['A', 1, 'B', 2, 'C', 3]`，而不是简单的追加。
- **实现方法**：使用数组的 `flatMap` 方法。
- **代码示例思路**：
  ```javascript
  const arr1 = ['A', 'B', 'C'];
  const arr2 = [1, 2, 3];
  const result = arr1.flatMap((item, index) => [item, arr2[index]]);
  ```
- **解析**：`flatMap` 相当于先执行 `map` 操作，将每个元素映射为一个包含自身和对应另一个数组元素的子数组，然后再执行 `flat`（降维）操作，最终得到交替合并的扁平数组。

## 合并时的注意事项 *Content-[08:30]
在面试中主动提出注意事项，能体现对底层原理和性能优化的深入理解。

### 1\. 引用类型的处理（浅拷贝问题）
- **核心概念**：当合并的是**对象数组**（数组成员是对象）时，新数组仍然包含对原对象的**引用**。
- **具体表现**：
  - 合并操作（无论是 `concat` 还是扩展运算符）产生的是一个新数组，但数组内部的对象元素依然是对原内存地址的引用（浅拷贝）。
  - 如果修改新数组中某个对象的属性值，原数组中对应的对象属性值也会随之改变，因为它们指向同一个对象引用。
- **应对策略**：如果需要完全独立的对象，需要在合并时进行**深拷贝**处理。

### 2\. 超大数组合并的性能问题
- **场景**：当需要合并超大数组（例如百万级数据量的数组）时。
- **性能对比**：
  - **扩展运算符**：虽然代码简洁，但在处理海量数据时，底层引擎的处理性能不及传统的循环。
  - **`for` 循环**：使用最原生的 `for` 循环进行遍历和赋值，性能表现最好。
- **建议**：在面试中提及，对于常规数据量使用扩展运算符即可；但对于百万级以上的超大数组合并，推荐使用 `for` 循环以保证性能。
- **代码示例思路**：
  ```javascript
  for (let i = 0; i < arr2.length; i++) {
      arr1.push(arr2[i]); // 或者根据需求进行直接赋值
  }
  ```
