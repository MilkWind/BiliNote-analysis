## 2. String 类型的底层核心特性 *Content-[00:46]
在正式介绍 API 之前，需要理解 `String` 类型的两个底层核心特性，这决定了我们如何使用它：

- **字符串的不可变性**
  - 在 JavaScript 的内存模型中，字符串一旦被创建，其内容就是固定的。
  - 尝试通过索引直接修改字符串的某个字符（如在 C 语言中可能行得通的操作）在 JavaScript 中是无效的，原字符串会保持不变。
  - 这意味着所有的字符串操作方法（截取、替换、转换大小写等）都不会改变原有的字符串数据，而是开辟新的内存空间并返回一个新的字符串。
  - **注意**：在进行大量字符串操作时，需要特别留意内存开销。

- **编码格式**
  - JavaScript 引擎内部使用的是 **UTF-16** 编码。
  - 基本的存储单元是**码元（Code Unit）**，占两个字节（16位）。
  - 对于绝大多数常用字符，一个字符恰好对应一个码元，此时 `length` 属性符合我们的预期。
  - 对于像 emoji 或某些生僻汉字等超出基本多文种平面（BMP）的字符，需要两个码元（即四个字节）来表示。
  - **潜在 Bug**：这会导致一个 emoji 的 `length` 属性返回 2。在处理国际化内容或计算字数时，容易引发潜在的问题。

## 3. 基础操作：访问特定字符 *Content-[03:03]
- **`charAt(index)` 方法**
  - 接收一个从 0 开始的索引值，返回对应位置的字符。
  - **特点**：容错性好。当传入的索引超过字符串的实际长度时，它会返回一个**空字符串**，而不会抛出错误。

- **中括号 `[]` 访问（ES5+）**
  - 从 ES5 开始，可以使用更加简洁的中括号语法去访问字符，形式上与访问数组元素完全一致。
  - **注意**：与 `charAt` 有细微区别。当索引超出范围时，中括号访问会返回 **`undefined`** 而不是空字符串。在进行逻辑判断时，这个差异可能会影响代码的执行路径。

- **`charCodeAt(index)` 方法**
  - 用于获取字符在 UTF-16 编码下的数值，返回该位置字符的 16 位码元的值。
  - 例如：小写字母 `h` 对应的十进制是 104。
  - **应用场景**：在处理字符编码转换、简单的加密算法，或者比较字符大小时比较有用。

## 4. 特殊字符处理与 ES6 新 API *Content-[05:03]
- **传统方法的局限性**
  - 如果字符串中包含一个 emoji（直观上是 1 个字符），`length` 属性可能会返回 2。
  - 使用 `charAt` 访问该 emoji 时，得到的并不是完整的 emoji，而是它的高位代理部分，表现为乱码。
  - `charCodeAt` 也只能读取前半部分的编码值。
  - 在处理现代 Web 应用中用户的昵称或评论时，这是一个常见的数据截断风险点。

- **ES6 引入的新 API**
  - **`codePointAt(index)`**：能够识别并正确解析四字节字符，返回完整的 Unicode 编码点值，而不是被截断的码点值。
  - **`String.fromCodePoint()`**：可以通过码点的数值来还原对应的字符。

- **正确计算包含 emoji 的字符串长度**
  - 使用 ES6 的**迭代器机制**。
  - 通过扩展运算符 `[...str]` 或 `Array.from(str)` 将字符串转换成数组。
  - 在这个过程中，迭代器会正确识别代理对，把四字节的 emoji 视为一个元素，从而得到一个准确的字符长度。

## 5. 字符串的组装与拼接 *Content-[06:59]
- **`concat()` 方法**
  - `String` 原型链上提供的方法，可以接收任意多个参数，并把它们依次拼接到原字符串的末尾。
  - **遵循不可变性**：原字符串不会发生任何变化，拼接的结果通过返回值提供。

- **实际开发中的最佳实践**
  - 虽然 `concat` 是标准方法，但在实际开发中，我们有更加高效或具有可读性的方案：
  - **加号 `+` 操作符**：在处理简单的字符串拼接时，使用加号非常直观。
  - **ES6 模板字符串（`` ` ``）**：对于包含变量的动态拼接，模板字符串是目前的最佳实践。它不仅解决了变量嵌入的问题，还支持多行文本，极大提升了代码的可读性。
  - **数组的 `join()` 方法**：如果需要把一个数组中的多个片段组合起来，使用数组的 `join` 方法会比循环拼接性能更好，逻辑也更加清晰。

- **场景总结**
  - 简单场景：使用加号 `+`。
  - 复杂动态场景：使用模板字符串。
  - 数组场景：使用 `join()`。
