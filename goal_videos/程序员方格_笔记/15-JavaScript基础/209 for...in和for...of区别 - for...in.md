## 大厂面试真题预览 *Content-[00:46]

在深入学习知识点之前，先了解大厂面试官通常会如何考察 `for...in` 和 `for...of` 的区别。以下是 5 道高频面试真题：

1\. **问题一**：请说一说 JS 中 `for...in` 和 `for...of` 循环的区别，分别适用于什么样的场景？
2\. **问题二**：为什么不建议用 `for...in` 遍历数组？用 `for...in` 遍历数组会出现什么问题？
3\. **问题三**：`for...in` 能遍历到对象的哪些属性？如何避免遍历到原型上的属性？
4\. **问题四**：有一个数组 `[10, 20, 30, 40]`，一个对象，请用 `for...in` 和 `for...of` 分别遍历它们，写出运行结果并说明原因。
5\. **问题五**：`for...of` 为什么不能遍历普通对象？如果想让 `for...of` 遍历普通对象，该怎么做？

## 核心概念：for...in 与 for...of 的区别 *Content-[02:00]

`for...in` 和 `for...of` 都是 JavaScript 的循环语句，目的是帮助开发者依次获取集合中的每个元素。但它们的遍历目标、遍历结果和适用场景完全不同。

- **`for...in` 的核心定义**：遍历的是集合的**键名**（如对象的属性名、数组的索引），而不是直接遍历值。
- **重要特点**：`for...in` 会遍历到原型链上的属性。
- **适用场景**：主要用来遍历**普通对象**（这是最常用的场景）；它也能遍历数组，但**极其不推荐**。

## 实战案例一：for...in 遍历普通对象 *Content-[03:00]

通过一个具体的代码示例来理解 `for...in` 如何遍历普通对象。

**代码示例**：
```javascript
// 1. 定义一个普通对象
const obj = {
  name: '李四',
  age: 22,
  major: '前端开发'
};

// 2. 使用 for...in 遍历对象
for (let key in obj) {
  console.log('键名:', key);
  console.log('键值:', obj[key]); // 等价于 obj.key
}
```

**运行结果**：
- 依次打印键名：`name`, `age`, `major`
- 依次打印对应的键值：`李四`, `22`, `前端开发`

**案例详解**：
- `for...in` 循环会依次获取 `obj` 对象里的每一个键名，并将其赋值给变量 `key`。
- 在循环体内部，通过 `obj[key]`（中括号语法）或 `obj.key`（点语法）来获取键名对应的键值。这两种取值写法是等价的。

## 实战案例二：for...in 遍历数组的隐患 *Content-[07:04]

虽然 `for...in` 可以遍历数组，但在实际开发中会引发两个严重的问题。

**代码示例**：
```javascript
const arr = [10, 20, 30, 40];

for (let index in arr) {
  console.log('索引:', index);
  console.log('元素:', arr[index]);
  console.log('索引的类型:', typeof index);
}
```

**核心问题 1：索引是字符串类型**
- 数组的键名就是它的索引（`0`, `1`, `2`, `3`）。因此 `for...in` 遍历数组时，拿到的是索引，而不是直接的元素。
- **关键陷阱**：拿到的索引 `index` 是**字符串类型**（如 `"0"`, `"1"`），而不是数字类型。
- **运算错误**：如果尝试用索引进行数学运算（例如 `let res = index + 1`），由于 `index` 是字符串，JavaScript 会触发隐式类型转换，优先进行字符串拼接。
  - **预期结果**：`1`, `2`, `3`, `4`
  - **实际结果**：`"01"`, `"11"`, `"21"`, `"31"`（全部变成了字符串拼接）。

**核心问题 2：会遍历自定义属性**
- 如果给数组添加了自定义属性（例如 `arr.name = '天气有点凉'` 或 `arr[4] = 22`），`for...in` 会把这些自定义属性也一并遍历出来。
- 这会导致遍历结果中混入非数组索引的内容，造成数据出错。

**结论**：
由于“索引为字符串导致运算出错”和“会遍历自定义属性”这两个严重缺陷，**绝对不推荐使用 `for...in` 来遍历数组**。

## AI 总结

本节课深入剖析了前端高频面试题中关于 `for...in` 的核心机制。`for...in` 本质上是用于遍历对象**键名**的循环语句，并且会遍历原型链上的属性。它最适合用于遍历普通对象。当用于遍历数组时，会暴露出两个致命缺陷：一是获取的索引为字符串类型，导致数学运算退化为字符串拼接；二是会遍历出数组的自定义属性。因此，在实际开发和面试中，必须明确 `for...in` 不适用于数组遍历，这也是区分前端基础扎实与否的关键考点。
