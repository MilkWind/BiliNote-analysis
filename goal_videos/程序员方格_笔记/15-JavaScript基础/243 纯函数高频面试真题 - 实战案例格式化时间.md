## 实战案例：格式化时间函数 *Content-[00:51]
- **功能需求**：接收一个时间戳（timestamp），返回 `YYYY-MM-DD`（年月日）格式的字符串，中间使用连字符（中划线）连接。
- **核心要求**：无副作用，保证相同输入产生相同输出。
- **实现步骤**：
  1\. **创建日期对象**：使用传入的时间戳创建 `Date` 对象。
     ```javascript
     const date = new Date(timestamp);
     ```
  2\. **获取年、月、日并进行补零处理**：
     - **获取年份**：
       ```javascript
       const year = date.getFullYear();
       ```
     - **获取月份并补零**：注意 `getMonth()` 返回值从 0 开始，需要加 1。使用 `toString()` 和 `padStart(2, '0')` 进行补零。
       ```javascript
       const month = (date.getMonth() + 1).toString().padStart(2, '0');
       ```
     - **获取日期并补零**：同样使用 `toString()` 和 `padStart(2, '0')` 进行补零。
       ```javascript
       const day = date.getDate().toString().padStart(2, '0');
       ```
  3\. **返回格式化后的字符串**：不修改任何外部变量，直接返回拼接好的字符串。
     ```javascript
     return `${year}-${month}-${day}`;
     ```

## 代码测试与验证 *Content-[05:13]
- **测试目的**：验证纯函数的特性，即“相同的输入返回相同的结果（相同的输出）”。
- **测试过程**：
  - 传入一个特定的时间戳（如 `1712889600000`），观察输出结果（如 `1975-06-06`）。
  - 再次传入完全相同的时间戳，确认输出结果保持一致。
- **测试结论**：
  - 函数没有修改任何外部变量，无副作用。
  - 输出结果完全可预测，符合纯函数的定义。

  - 相同的时间戳永远返回相同的格式化结果。
  - 不修改任何外部变量，没有副作用。
  - 这是一个标准的纯函数实现。
- **实际开发应用**：
  - 在实际开发中，格式化时间、格式化金额等工具函数通常都会采用纯函数的写法。
