## 1. 获取数组的最大值与最小值 *Content-[00:01]

在 JavaScript 中，`Math` 对象提供了 `max` 和 `min` 方法来获取最大值和最小值，但这两个方法的参数不能直接接收数组，必须逐个传入参数，这在处理数组时非常繁琐。

- **借助 `apply` 解决**：`apply` 方法的第二个参数支持传入数组，可以将数组展开为独立的参数传递给目标函数。
- **`this` 指向处理**：由于我们只是单纯调用 `Math.max`，不需要改变其 `this` 指向，因此第一个参数可以传入 `null` 或 `undefined`，让其默认指向 `window` 即可。

**示例代码**：
```javascript
const arr = [12, 63, 14, 30, 22, 43];

// 获取最大值
// 注：视频中口误称最大值为 43，实际数组中最大值为 63
const maxVal = Math.max.apply(null, arr); 
console.log(maxVal); // 输出 63

// 获取最小值
const minVal = Math.min.apply(null, arr);
console.log(minVal); // 输出 12
```

## 2. 数组合并的应用 *Content-[01:51]

除了使用数组自带的 `concat` 方法合并数组外，还可以利用 `apply` 的特性来实现数组合并，这在某些特定场景下非常实用。

- **传统方法**：使用 `arr1.concat(arr2)`，该方法会返回一个**新数组**，不会修改原数组。
- **`apply` 方法**：利用 `Array.prototype.push.apply(arr1, arr2)`。`push` 方法可以接收多个参数，通过 `apply` 将 `arr2` 作为参数数组传入，从而将 `arr2` 的元素逐个推入 `arr1` 中。此方法会**直接修改原数组** `arr1`。

**示例代码**：
```javascript
const arr1 = [1, 2, 3, { id: 1 }, { name: '熊大' }];
const arr2 = ['乐迪', 4, 5, 6, [7, 8, 9]];

// 将 arr2 的元素合并到 arr1 中
Array.prototype.push.apply(arr1, arr2);

// push 方法返回的是新数组的长度，因此直接打印 arr1 即可
console.log(arr1); 
// 输出: [1, 2, 3, {id: 1}, {name: '熊大'}, '乐迪', 4, 5, 6, [7, 8, 9]]
console.log(arr2); // arr2 保持不变
```

## 3. this 的硬绑定与回调函数中的 this 指向 *Content-[04:42]

在对象的方法中使用异步回调（如 `setTimeout`）时，经常会遇到 `this` 指向丢失的问题。回调函数内部的 `this` 默认指向全局对象（如 `window`），导致无法访问对象自身的属性。

**问题场景**：
```javascript
const obj = {
  a: 1,
  fn: function() {
    setTimeout(function() {
      console.log(this.a); // 输出 undefined，因为此时 this 指向 window，而 window 上没有属性 a
    }, 0);
  }
};
obj.fn();
```

- **传统解决方案**：在外部使用一个变量（如 `_this` 或 `that`）保存当前对象的 `this` 引用，在回调函数中通过闭包访问该变量。
  ```javascript
  const _this = this;
  setTimeout(function() {
    console.log(_this.a); // 输出 1
  }, 0);
  ```

- **优化解决方案（使用 `bind`）**：使用 `bind` 方法强制且永久性地绑定 `this` 指向。这种方式代码更优雅，也是面试中常考的“硬绑定”概念。
  ```javascript
  setTimeout(function() {
    console.log(this.a); // 输出 1，this 被 bind 强制指向 obj
  }.bind(this), 0);
  ```

## 4. 精确判断数据类型（区分数组与对象） *Content-[09:23]

面试中经常遇到如何精确区分一个变量是数组还是对象的问题。虽然 `typeof` 可以判断基本类型，但对于引用类型（如数组、对象、null）都会返回 `"object"`。

- **万能判断方法**：使用 `Object.prototype.toString.call()`。
- **原理**：`toString` 方法可以返回对象的内部类型标签。通过 `call` 方法改变 `toString` 的 `this` 指向到目标变量上，从而获取其真实的类型字符串。
- **注意事项**：必须使用 `Object.prototype` 上的 `toString` 方法，因为数组或对象自身可能重写了 `toString` 方法，导致结果不准确。

**示例代码**：
```javascript
const arr = [1, 2, 3];
const str = 'hello';
const obj = { name: '熊二' };

function isArray(target) {
  // 判断返回值是否严格等于 '[object Array]'
  return Object.prototype.toString.call(target) === '[object Array]';
}

console.log(isArray(arr)); // true
console.log(isArray(str)); // false
console.log(isArray(obj)); // false
```
此方法不仅适用于判断数组，还可以用于精确判断其他所有数据类型（如 `Date`、`RegExp`、`Function` 等）。
