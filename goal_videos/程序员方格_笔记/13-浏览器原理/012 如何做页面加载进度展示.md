## 背景与意义 *Content-[00:00]
页面加载进度条是提升用户体验的重要手段，其核心价值和应用场景如下：
- **减少焦虑感**：明确告知用户“正在加载，请稍后”，提供时间感知，使等待时间感觉更短。
- **提供操作反馈**：让用户知道页面操作正在进行中，增加交互的反馈感与专业度。
- **提升品牌形象**：专业的加载体验能有效提升网站的整体品牌形象。

**常见应用场景**：
- 页面首次加载与资源加载进度。
- 路由切换（如 SPA 单页面应用的页面切换）。
- 文件上传、下载及文件传输进度。
- 数据请求与接口加载时间。
- 长时间操作（如数据导出、批量操作等）。

## 方法一：基于定时器的顶部进度条模拟实现 *Content-[01:09]
这是一种通过定时器模拟进度增长的常见封装方案。

### 1\. UI 与 DOM 设置
- **定位方式**：使用全局 `fixed` 定位，置于页面最顶部。
- **视觉效果**：由左到右展示进度，包含相应的动画效果；加载完成时完全消失（淡出）。

### 2\. 核心逻辑封装
- **初始化**：获取进度条 DOM，设置初始进度为 0，初始化计时器（`timer`）状态，样式宽度为 0%。
- **开启加载**：移除隐藏属性，展示进度条，从零开始增长。

### 3\. 增长算法（`increase` 函数）
- **定时增长**：每 100ms 增长一部分。
- **非线性增长逻辑**：越接近 100%，增长越慢。
  - 剩余进度 = $100\% - 当前百分比$
  - 增长量 = $剩余进度 \times 0.05$
  - 由于剩余量在不断减少，增长比例也会越来越小，呈现线性减少的视觉效果，看起来自然且有规律。
- **上限控制**：进度最高只增长到 95%，最后的 5% 需要等待实际加载完成后人工触发。达到 95% 时停止计时器。

### 4\. 完成逻辑（`finished`）
- 清除计时器。
- 进度直接设置为 100%，并更新对应样式。
- 添加淡出动画样式，完成初始化隐藏。

### 5\. 触发方式
- 实例化对象后，可通过监听 `window.onload` 事件判断页面完全加载，触发 `finish` 方法。
- 也支持在业务代码中手动调用控制。

## 方法二：基于静态资源监听的精准进度计算 *Content-[04:41]
这是一种更科学、更精准的实现方式，通过监听页面中所有静态资源的加载状态来计算真实进度。

### 1\. 初始化与资源收集
在初始化过程中，需要收集并监听页面中的各类资源，计算总资源数：
- **图片**：通过 `document.images` 收集。
- **样式表**：通过 `document.styleSheets` 收集。
- **脚本**：收集页面中的 `<script>` 标签。

### 2\. 资源监听与计数逻辑
- **图片监听**：
  - 判断 `complete` 属性，若为 `true` 说明已加载完成。
  - 否则监听 `load` 和 `error` 事件，触发后均进行计数。
- **样式表监听**：
  - 遍历样式表并判断 CSS 规则。
  - 注意：跨域样式表无法访问会抛出异常，在捕获异常的情况下也需要进行计数，防止进度卡死。
- **脚本监听**：
  - 监听 `<script>` 标签的 `load` 和 `error` 事件，触发后进行计数。

### 3\. 进度计算与回调
- **计算公式**：$当前进度 = \lfloor \frac{当前已加载数量}{总资源数量} \times 100 \rfloor$ （结果四舍五入取整）。
- **状态更新**：每次资源加载完成（递增计数）后，更新进度并触发回调。
- **完成提示**：当进度达到 100% 时，判定为所有资源加载完成，可给用户相应提示。

### 4\. 使用方式
实例化对象后，通过 `onProgress` 方法监听当前百分比，进而动态修改 DOM 进度条的宽度属性。

## 方法三：使用第三方库 NProgress 与 Pace.js *Content-[07:24]
在实际开发中，通常直接使用成熟的第三方库来简化开发。

### 1\. NProgress
提供细粒度的 API 和配置项。
- **配置项**：可配置是否展示右侧圆点（Spinner）、动画速度、最小百分比（`minimum`）、增长幅度等。
- **核心方法**：
  - `NProgress.start()`：开始加载。
  - `NProgress.set(0.4)`：设置具体进度。
  - `NProgress.inc()`：增加一点进度。
  - `NProgress.done()`：完成加载。
- **在 Vue 中的集成**：
  - 通常在路由守卫（如 `router.beforeEach`）中处理。
  - 进入页面时调用 `start()`，可设置 300ms 的延迟以避免闪烁；路由加载完成后调用 `done()`。

### 2\. Pace.js
主打“自动检测”，使用更为简单，无需手动控制进度。
- **引入方式**：引入对应的 JS 和 CSS 文件。
- **配置参数**：
  - 监控 Ajax 请求。
  - 监控文档加载。
  - 可选择是否监控时间延迟。
  - 监控特定的 DOM 元素加载。

3\. **第三方库法**：推荐使用 `NProgress`（适合路由切换和手动控制）或 `Pace.js`（适合全自动无感监控），以大幅提升开发效率。
