## 引言与核心概念 *Content-[00:00]
- 探讨 TypeScript (TS) 最基础且最重要的概念：三种原始类型（Primitive Types）。
- 三种原始类型分别为：`string`、`number` 和 `boolean`。
- 无论未来构建多么复杂的应用程序，最终都是由这些基本类型构成的，因此需要深刻理解它们的工作方式。

## TypeScript 的核心转变：从动态到静态 *Content-[00:25]
- JavaScript (JS) 是一门动态类型语言，这意味着变量在程序运行时的类型可以随时改变（例如一个变量开始是数字，后来可以被赋值成字符串）。
- 动态类型在小型项目中提供了灵活性，但在大型项目中会引入意想不到的错误。
- TS 的解决方案是引入**类型注解（Type Annotation）**，让我们能够明确地告诉编译器这个变量应该是什么类型。
- 通过类型注解，类型的确定时机从“运行时”提前到了“编译时”，编译器可以在代码运行前检测出潜在的类型不匹配问题。

## 类型注解语法与价值 *Content-[01:28]
- **语法规范**：在变量名（标识符 identifier）后面加上冒号 `:`，然后跟上期望的类型（type）。
- 一旦类型确定，该变量就只能被赋予相应类型的值。如果尝试赋予不兼容类型的值，TS 编译器会发现并发出警告或报错。
- **核心价值**：这种机制能够将大量原本可能在用户浏览器中才会暴露出来的运行时 Bug，提前拦截在开发阶段，从而显著提升代码质量。

## 三种原始类型概述 *Content-[02:20]
- `string`：用来表示一切的文本内容，如文章标题、用户姓名等。
- `number`：用来表示所有的数值。
- `boolean`：在逻辑上代表真和假，只有 `true` 和 `false` 两个值。
- 这三种类型虽然简单，但它们是接下来学习所有复杂类型（如 Array 数组、Object 对象、Tuple 元组等）的基础概念。

## string 类型详解 *Content-[03:13]
- 在定义字符串变量时，无论使用双引号 `""` 还是单引号 `''`，TS 都能正确识别其为 `string` 类型。
- **项目中的应用场景**：
  - 界面上显示的文本。
  - 需要打印的日志。
  - API 返回的文本数据。

## number 类型详解 *Content-[03:45]
- **重要特性**：与一些后端语言不同，TS **不区分整数和浮点数**。所有的数字（无论是整数还是小数）都统一使用 `number` 进行注解，这让类型定义变得更加简单直接。
- **代码示例**：
  - `version`（浮点数）和 `articleCount`（整数）都正确使用了 `number` 类型。
- **类型检查能力**：
  - 如果将 `followers` 定义为 `number` 类型并赋值为 `100`，是正确的。
  - 但如果将字符串 `"100k"` 赋值给它，TS 就会报错。
  - 这种类型检查能够有效避免 JS 中常见的由于隐式错误转换导致的计算问题。

## boolean 类型详解 *Content-[04:48]
- **特性**：类型非常纯粹，只有两个可能的值：`true` 和 `false`。
- **核心用途**：
  - **定义状态**：用于定义像 `isLoading` 这样的布尔变量，来表示组件的状态。
  - **控制流程**：是程序控制流程的核心。通过 `if` 语句等判断程序走向。
  - 布尔值是所有逻辑判断和控制流程的最小单元。

## 总结与后续课程展望 *Content-[05:27]
- **回顾**：`string`、`number`、`boolean` 构成了 TS 最基础的基本单元，必须熟练掌握。
- 未来接触的各种复杂类型都是由这些原始类型构成的。正是有了这些明确的基本类型定义，TS 才能发挥其强大的类型推断能力和错误检测能力。
- **下节课预告**：探讨如何使用这些基础类型构建更加复杂的数据结构（如 Array 数组和 Object 对象），以及如何将它们组合起来创建更强大的自定义对象。
