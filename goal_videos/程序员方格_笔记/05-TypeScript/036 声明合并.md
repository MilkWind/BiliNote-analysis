## 声明合并的概念与设计目的 *Content-[00:00]

- **核心概念**：声明合并（Declaration Merging）是 TypeScript 编译器的一种机制。当编译器遇到多个名称完全相同的声明时，它不会抛出重复定义的错误，而是尝试将这些声明的内容合并到同一个定义中。
- **设计目的**：
  - **兼容 JavaScript 编程模式**：在 JS 中，函数本身也是对象，可以拥有自己的属性。声明合并为这种“函数即对象”的模式提供了类型安全的实现方法。
  - **增强类型系统的可扩展性**：允许开发者事后为已存在的类型补充新的成员，而无需修改其原始定义。
- **核心思想**：信息的叠加。编辑器会将多个分散的、关于同一个目标的局部描述，组合成一个更完整的全局描述，从而使代码组织更加灵活。

## 接口合并 (Interface Merging) *Content-[02:11]

- **基本机制**：当声明两个同名的 `interface` 时，TypeScript 会自动将它们的成员进行合并。
- **代码示例**：
  ```typescript
  interface Box {
    height: number;
    width: number;
  }
  
  interface Box {
    scale: number;
  }
  
  // 合并后的 Box 接口同时包含 height、width 和 scale
  let box: Box = { height: 10, width: 20, scale: 1.5 };
  ```
- **成员自动合并特性**：
  - 所有的非函数成员都会被收集起来，形成一个更大的接口。
  - 当创建该类型的变量时，初始化对象必须满足合并后所有属性的要求，否则 TS 会报错。
  - **注意**：如果出现同名但类型不同的非函数成员，则会发生编译错误。

## 扩展全局类型 (Augmenting Global Types) *Content-[03:28]

- **应用场景**：在前端开发中，经常需要给全局的 `window` 对象添加自定义属性（如应用配置信息）。直接赋值会导致 TS 报错，因为 TS 不认识这些新属性。
- **解决方案**：利用接口合并特性与 `declare global` 关键字。
- **代码示例**：
  ```typescript
  declare global {
    interface Window {
      myAppConfig: {
        apiUrl: string;
        version: string;
      };
    }
  }
  
  // 导出使其成为模块，确保 declare global 生效
  export {};
  ```
- **效果**：通过这种方法，将自定义属性安全地扩展到全局类型中。之后在代码中访问 `window.myAppConfig` 时，TypeScript 不仅不会报错，还会提供完整的类型检查和代码提示。

## 命名空间合并 (Namespace Merging) *Content-[04:39]

- **跨文件合并**：`namespace`（命名空间）同样支持声明合并，甚至可以跨文件进行。
- **代码示例**：
  ```typescript
  // 文件 1: animal.ts
  namespace Animals {
    export class Zebra {}
  }
  
  // 文件 2: animals.extension.ts
  namespace Animals {
    export interface Lion {}
  }
  ```
- **机制**：当 TypeScript 处理这两个文件时，会识别出两个同名的 `Animals` 命名空间，并将它们导出的成员进行合并。最终得到一个统一的 `Animals` 命名空间，开发者可以访问这两个文件中的所有导出属性。

## 命名空间与类、函数或枚举的合并 *Content-[05:31]

- **双重身份**：命名空间可以与同名的类、函数或枚举进行合并，这是一种非常有趣的合并形式。
- **代码示例**：
  ```typescript
  class Album {
    label: string;
  }
  
  namespace Album {
    export type AlbumType = { id: number };
    export function create() {
      // 静态工厂方法
    }
  }
  ```
- **机制与效果**：
  - 命名空间里导出的成员会作为**静态成员**附加到 `Album` 类对象上。
  - `Album` 获得了双重身份：既可以通过 `new Album()` 实例化的类，也是一个包含了静态工具函数和相关类型的容器对象（如 `Album.create()`）。
  - 这种能力使得 TypeScript 能够非常精确地为 JavaScript 中“函数即对象”的常见模式提供类型支持，让代码在保持灵活性的同时具备类型安全。

## 核心内容总结 *Content-[07:07]

- **核心概念回顾**：声明合并是 TypeScript 将多个同名声明自动融合成一个单一、更完整定义的机制。
- **主要应用场景**：
  - 接口与接口之间的合并（最基础、最常用）。
  - 命名空间与命名空间之间的合并（支持跨文件）。
  - 命名空间与类、函数或枚举的组合合并（实现双重身份）。
- **核心价值**：这些特性极大地增强了 TypeScript 类型系统的灵活性和可扩展性。正确运用声明合并，能够帮助开发者编写出更加灵活、健壮且易于维护的 TS 代码。
