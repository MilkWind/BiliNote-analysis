## 课程简介与核心概念 *Content-[00:00]

本节课主要探讨 TypeScript（简称 TS）中最基础但也最重要的概念：**三种原始类型**（string、number、boolean）。
- 无论未来构建多么复杂的应用程序，最终都是由这些基本的类型构成的。
- 深刻理解它们的工作方式，是掌握 TS 高级特性的前提。

## TypeScript 的核心转变与类型注解 *Content-[00:25]

### 从动态类型到静态类型
- **JS 的动态类型特性**：JavaScript 是一门动态类型语言，意味着变量在程序运行时的类型可以随时被改变（例如一个变量开始是数字，后来可以被赋值成字符串）。
- **动态类型的优缺点**：这种特性在小型项目中非常灵活，但在大型项目中会引入许多意想不到的错误。
- **TS 的解决方案**：引入**类型注解（Type Annotation）**，让我们能够明确地告诉编译器某个变量应该是什么类型。
- **核心转变**：类型的确定从“运行时”提前到了“编译时”。编译器可以在代码运行之前，检测出潜在的类型不匹配问题。

### 类型注解的语法与价值
- **具体语法**：在变量名（标识符 identifier）后面加上一个冒号 `:`，然后跟上期望的类型 type（例如 `let name: string`）。
- **类型约束**：一旦类型确定，该变量就只能被赋予相应类型的值。如果试图将不兼容类型的值赋给它，TS 编译器会发现并发出警告。
- **核心价值**：
  - 将大量原本可能在用户浏览器中才会暴露出来的**运行时 bug** 提前拦截在开发阶段。
  - 有效避免 JS 中常见的由于隐式错误转换导致的计算问题，大幅提升代码质量。

## TypeScript 的三大基础原始类型概述 *Content-[02:17]

在理解了类型注解的基本语法后，我们来看 TS 的三个基本原始类型。它们是后续学习复杂类型（如 array、对象、元组等）的基础概念：
- **string**：用来表示一切的文本内容，如文章标题、用户姓名等。
- **number**：用来表示所有的数值，不管是整数还是浮点数，在 TS 中都统一用 number 表示。
- **boolean**：在逻辑上代表真和假，只有 `true` 和 `false` 两个值。

## 详解 String 类型 *Content-[03:13]

- **语法识别**：在代码中定义字符串变量时，无论是使用双引号 `""` 还是单引号 `''`，TS 都能正确识别其为 string 类型。
- **应用场景**：string 在项目中的应用非常广泛，包括但不限于：
  - 界面上显示的文本内容。
  - 需要打印的日志信息。
  - API 返回的文本数据。

## 详解 Number 类型 *Content-[03:45]

- **核心特点**：和一些后端语言不同，TS **并不区分整数和浮点数**。所有的数字（无论是整数还是小数）都统一用 `number` 进行注解，这让类型定义变得更加简单直接。
- **代码示例**：
  - `version`（浮点数）和 `articleCount`（整数）都正确使用了 number 类型。
- **类型检查能力**：
  - 假设有一个 `followers` 变量被声明为 number 类型并赋值为 `100`。
  - 如果尝试将 `"100k"` 这样的字符串赋值给它，TS 就会报错。
  - 这种严格的类型检查能够有效避免 JS 中常见的隐式类型转换导致的计算错误。

## 详解 Boolean 类型 *Content-[04:48]

- **核心特点**：类型非常纯粹，只有两个可能的值：`true` 和 `false`。
- **主要用途**：
  - **状态定义**：用于定义像 `isLoading` 这样的布尔变量，用来表示组件的加载状态。
  - **控制流程**：boolean 是程序控制流程的核心。例如 `if` 语句就是通过 boolean 值来判断程序走向哪一块逻辑分支。
- **重要地位**：可以说，布尔值是所有逻辑判断和控制流程的**最小单元**。

## 课程总结与后续预告 *Content-[05:27]

- **知识回顾**：string、number、boolean 这三种原始类型构成了 TS 的最基础单元。必须熟练掌握它们，因为未来接触到的各种复杂类型都是由这些原始类型构成的。
- **TS 的能力基础**：正是有了这些明确的基本类型定义，TS 才能发挥其强大的**类型推断能力**和**错误检测能力**。
- **后续预告**：接下来的课程将探讨如何使用这些基础类型来构建更加复杂的数据结构，例如**数组（array）**和**对象（object）**，以及如何将它们组合起来创建更强大的自定义对象。
