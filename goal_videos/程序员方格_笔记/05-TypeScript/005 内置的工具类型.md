## 内置工具类型概述 *Content-[00:01]
在 TypeScript 中，内置的工具类型（Utility Types）数量众多，它们能够帮助我们灵活地转换和组合已有的类型。本次内容将重点讲解前端面试和日常开发中最核心、最高频的几个内置工具类型，剖析它们的底层原理与实际应用场景。

## Partial：可选属性 *Content-[00:09]
- **核心作用**：将类型 `T` 中的所有属性都转换为可选（Optional）属性。
- **底层原理**：本质上是通过映射类型（Mapped Types），遍历类型 `T` 的所有键，并为每个属性添加 `?` 可选修饰符。
- **代码示例**：
  ```typescript
  interface Person {
    name: string;
    age: number;
  }
  
  // 使用 Partial 后，name 和 age 都变成可选属性
  type PartialPerson = Partial<Person>; 
  // 等价于 { name?: string | undefined; age?: number | undefined; }
  ```

## Readonly：只读属性 *Content-[01:06]
- **核心作用**：将类型 `T` 中的所有属性都转换为只读（Readonly）属性，防止属性被重新赋值。
- **底层原理**：与 `Partial` 类似，通过遍历类型 `T`，为每个属性添加 `readonly` 修饰符。
- **应用场景**：常用于需要保证数据不可变性的场景，如 Redux 的 state 或配置对象。

## Record：键值对构造 *Content-[01:23]
- **核心作用**：构造一个对象类型，用于定义键值对（Key-Value）结构。
- **语法结构**：`Record<K, T>`，接收两个泛型参数。`K` 代表属性的键（Key），`T` 代表属性的值（Value）。
- **底层原理**：约束 `K extends keyof any`，然后遍历 `K` 并将每个键的值类型映射为 `T`。
- **代码示例**：
  ```typescript
  // 定义一个对象，键必须是 'name' 或 'age'，值必须是 string
  type PersonRecord = Record<'name' | 'age', string>;
  
  // 等价于 { name: string; age: string; }
  ```

## Pick：属性挑选 *Content-[02:09]
- **核心作用**：从类型 `T` 中挑选（Pick）出一组指定的属性键，构造一个新的类型。
- **语法结构**：`Pick<T, K>`。`T` 是原类型，`K` 是要挑选的属性键集合。
- **类型约束**：`K` 必须满足 `extends keyof T`，即挑选的键必须是原类型 `T` 中真实存在的键。
- **底层原理**：遍历传入的键集合 `K`，从原类型 `T` 中提取对应的属性。
- **代码示例**：
  ```typescript
  interface Person {
    name: string;
    age: number;
    city: string;
  }
  
  // 只挑选 name 和 age 属性
  type PickedPerson = Pick<Person, 'name' | 'age'>;
  // 等价于 { name: string; age: number; }
  ```

## Omit：属性剔除 *Content-[03:06]
- **核心作用**：与 `Pick` 的作用完全相反，从类型 `T` 中剔除（Omit）一组指定的属性键，保留剩下的属性构造新类型。
- **语法结构**：`Omit<T, K>`。`K` 是要剔除的属性键集合，`K extends keyof any`。
- **底层原理**：内部结合了 `Pick` 和 `Exclude`。首先使用 `Exclude<keyof T, K>` 排除掉需要剔除的键，然后再用 `Pick` 挑选出剩余的键。
- **代码示例**：
  ```typescript
  interface Person {
    name: string;
    age: number;
    city: string;
  }
  
  // 剔除 city 属性，保留 name 和 age
  type OmittedPerson = Omit<Person, 'city'>;
  // 等价于 { name: string; age: number; }
  ```
