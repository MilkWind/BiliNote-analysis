## 什么是类型层级 *Content-[00:05]

在 TypeScript (TS) 中，**类型层级**（Type Hierarchy）是一个核心概念，它决定了不同类型之间的兼容性和可赋值性。

- **核心定义**：类型层级主要解决“什么样的类型可以赋值给什么样的类型”这一问题。
- **前置知识回顾**：在理解类型层级前，需要熟悉 TS 中的基本类型以及特殊类型，特别是 `any`、`unknown` 和 `never`。这些特殊类型在类型层级中占据着极端且重要的位置。

## TS 类型层级划分 *Content-[00:34]

TypeScript 的类型层级从上到下可以划分为四个主要层级，层级越高，包容性越强；层级越低，类型越具体。

1\. **最高层级（顶级类型 / Top Type）**
   - 包含 `any` 和 `unknown`。
   - **特性**：所有其他类型都可以赋值给这两个顶级类型。
   - **安全性区分**：`unknown` 是**安全**的顶级类型（使用前必须进行类型收窄），而 `any` 是**非安全**的顶级类型（会跳过类型检查）。

2\. **第二层级（Object 与包装类型）**
   - 包含所有的**对象类型**，例如：`Array`、`Function`、`Date` 等。
   - 包含基本数据类型的**包装对象类型**，例如：`String`、`Number`、`Boolean` 等。

3\. **第三层级（基本类型 / Primitives）**
   - 包含基础的数据类型，例如：`string`、`number`、`boolean`、`null`、`undefined`。

4\. **最底层级（底层类型 / Bottom Type）**
   - 包含 `never` 类型。
   - **特性**：处于类型层级的最底端，没有任何类型可以赋值给 `never`（除了 `never` 自身）。

## 类型赋值规则与示例 *Content-[02:40]

理解类型层级后，需要掌握其对应的**可赋值性规则**。核心原则是：**低层级类型可以赋值给高层级类型**（即子类型可以赋值给父类型），反之则不行。

### 赋值规则详解
- **高层级变量接收低层级赋值**：由 `any` 或 `unknown` 定义的变量，可以接收下面所有层级类型的赋值。
- **底层级变量的限制**：由 `never` 定义的变量，**不能**接收任何上面层级的类型赋值。`never` 只能作为子类型赋值给其他类型，而不能作为父类型被赋值。

### 代码示例解析
- **示例 1：`never` 与 `string` 的赋值**
  ```typescript
  let a: never;
  let b: string = "hello";
  a = b; // 报错！string（第三层级）不能赋值给 never（最底层级）。
  ```
- **示例 2：基本类型的赋值**
  ```typescript
  let c: number = 10;
  // 基本类型之间的赋值需要遵循严格的类型匹配或兼容性规则。
  ```
- **示例 3：`string` 赋值给 `object`**
  ```typescript
  let obj: object;
  let str: string = "test";
  obj = str; // 合法！
  ```
  **原理解析**：`string` 属于第三层级（基本类型），而 `object` 属于第二层级。因为 `object` 的层级高于 `string`，所以 `string` 类型的值可以合法地赋值给 `object` 类型的变量。

## AI 总结 *Content-[05:32]

本视频详细讲解了 TypeScript 中的类型层级概念及其赋值规则。TS 类型层级从上到下分为：顶级类型（`any`/`unknown`）、对象与包装类型（`object`/`String`/`Number`等）、基本类型（`string`/`number`等）以及最底层的 `never` 类型。掌握这一层级关系的核心在于理解“低层级可向高层级赋值”的规则，这对于编写类型安全、避免 TS 编译报错以及应对前端面试中的类型体操和场景题至关重要。
