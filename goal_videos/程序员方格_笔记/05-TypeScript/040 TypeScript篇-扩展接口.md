## 1. 接口扩展的核心概念 *Content-[00:00]*
- **什么是接口扩展**：在 TypeScript 中，`interface` 的核心作用是定义对象的结构，规定一个对象应该包含哪些属性和方法。接口扩展允许我们在一个已经存在的接口基础上，创建一个新的接口。
- **继承机制**：新接口（子接口）会继承父接口的所有成员，并且可以自己添加独有的新成员。这本质上是一种在现有类型之上构建新类型的机制。
- **核心特点**：
  - 使用 `extends` 关键字来实现接口的继承。
  - **避免重复**：将通用的属性抽离到父接口，子接口直接继承即可，无需重复编写。
  - **类型分层设计与复用**：建立从通用到专用的类型层次，让代码结构更加清晰。
  - **高级特性基础**：从更深层次来看，接口扩展是 TypeScript 类型系统中实现多态（Polymorphism）和组合（Composition）等重要概念的基础。

## 2. 核心语法与 DRY 原则 *Content-[01:53]*
- **基本语法示例**：
  - 定义一个基础的 `Person` 接口，包含 `name` 和 `age` 两个属性。
  - 定义一个员工接口 `Employee`。因为员工首先是一个人，所以使用 `extends Person` 让 `Employee` 接口继承 `Person` 接口，自动获取 `name` 和 `age` 属性。
  - 在 `Employee` 接口内部，只需定义其独有的属性（如员工的 `id` 和 `department`）即可。
- **DRY 原则 (Don't Repeat Yourself)**：
  - 接口扩展完美体现了软件工程中的 DRY 原则（不要重复你自己），这是编写可维护代码时应遵循的核心原则。
  - 如果没有 `extends`，在定义 `Employee` 时不得不把 `name` 和 `age` 重新写一遍。通过接口扩展，将多个类型共有的属性抽离到通用的基础接口中，子接口只需专注于自身独有的扩展属性，使每个接口的职责更加单一和明确。
- **维护优势**：极大减少了代码的维护成本。如果将来需要为所有“人”相关的类型增加新属性，只需修改公共的父接口，所有继承它的子接口都会自动更新，无需逐一修改。

## 3. 类型兼容性与多态 (Polymorphism) *Content-[04:08]*
- **类型兼容性示例**：
  - 定义一个函数 `greetPerson`，接受一个类型为 `Person` 的参数，功能是打印传入对象的 `name` 属性。
  - 创建一个类型为 `Employee` 的常量对象（注意：`Employee` 接口比 `Person` 接口多两个属性）。
  - 将 `Employee` 类型的对象传入 `greetPerson` 函数，TypeScript 认为这行代码是完全合法的。
- **原理解析**：
  - 当 `Employee` 扩展了 `Person` 之后，两者之间形成了一种“IS-A”关系（一个雇员是一个人，`Employee` 是一种特殊的 `Person`）。
  - 任何需要 `Person` 类型的地方，都可以安全地传入 `Employee` 类型的对象，因为 `Employee` 对象必然包含了 `Person` 接口所有的属性（如 `name`），TypeScript 类型系统保证了这种操作的安全性。
- **多态 (Polymorphism) 的体现**：
  - 这种能够将子类型对象赋值给父类型引用的能力，就是面向对象编程中多态的基础概念。
  - **优势**：让函数更加泛化。`greetPerson` 并不需要知道具体的子类型（如 `Employee`、`Manager` 或其他任何扩展自 `Person` 的类型），它只依赖 `Person` 这个通用的接口。这样代码的耦合度更低，复用性更强。

## 4. 多接口扩展与组合模式 *Content-[06:13]*
- **多接口扩展语法**：
  - TypeScript 的接口扩展具备更灵活的能力：可以同时扩展多个接口。
  - 示例：定义两个独立的接口 `Clickable`（包含 `onClick` 方法）和 `Draggable`（包含 `onDrag` 方法），分别代表两种行为或能力。
  - 创建一个 `Button` 接口，除了自身的 `label` 文本属性外，还希望它是可点击且可拖拽的。此时可以在 `extends` 关键字后用逗号分隔，列举出所有需要继承的父接口：`extends Clickable, Draggable`。
- **组合模式 (Composition)**：
  - 任何 `Button` 类型的对象都必须同时实现 `onClick` 和 `onDrag` 方法，并且必须携带 `label` 属性。
  - 通过这种方式，`Button` 成功组合了“可点击”和“可拖拽”这两种不同的行为。这是一种非常强大的组合模式，允许将不同的行为和能力灵活地混合到一个类型中。

## 5. 核心知识点回顾 *Content-[07:25]*
- **核心语法**：掌握了 `extends` 关键字，一个接口可以扩展单个接口或多个接口。
- **DRY 原则**：通过抽离通用属性到父接口，减少代码的重复性，降低维护成本。
- **类型层次**：通过接口扩展，建立起层次分明、结构清晰的类型体系。
- **组合模式**：利用扩展多个接口的能力，将不同的行为和能力灵活混合，实现强大的类型组合。
