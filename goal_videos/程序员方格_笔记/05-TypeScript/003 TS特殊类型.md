## any 类型 *Content-[00:07]

`any` 是 TypeScript 中最宽松的类型，它会完全关闭类型检查机制。

### 核心特点
- **赋值规则**：`any` 类型的值可以赋值给任何类型，同时任何类型的值也可以赋值给 `any`。
- **开发模式**：使用 `any` 相当于切回了纯 JavaScript 的开发模式，完全失去了 TypeScript 类型检查的优势。
- **使用建议**：极不推荐在代码中大量使用 `any`。应尽量慎用，确保当前定义的类型是安全的。

### 示例说明
- **任意赋值**：定义一个 `any` 类型的变量，可以将其赋值为 `string`（如 `"hello"`）、`number`（如 `42`）或 `boolean`（如 `true`），重新赋值为其他类型也不会有任何编译问题。
- **属性访问**：可以访问该变量的任意属性（例如 `val.foo.bar`），但在运行时可能会因为属性不存在而报错。
- **函数调用**：可以将其当作函数来调用（例如 `val()`），同样在运行时可能会报错。

## unknown 类型 *Content-[02:50]

`unknown` 是 TypeScript 中比 `any` 更安全的类型，用于在不确定具体类型时提供类型安全保障。

### 核心特点
- **赋值规则**：`unknown` 可以赋值给 `any` 和 `unknown` 类型，但**不能**直接赋值给其他具体类型。
- **操作限制**：不能直接访问属性或调用方法，必须进行**类型断言**（Type Assertion）或**类型缩小**（Type Narrowing）后才能进行操作。
- **使用建议**：强烈推荐在无法确定具体类型时使用 `unknown` 来替代 `any`，以提供更好的类型安全性。

### 示例说明
- **基础赋值**：可以赋值为 `42` 或 `true`，但如果直接访问属性（如 `val.foo`）或调用方法，编译器会直接报错，因为它不具备专业性。
- **函数调用**：直接通过函数方式调用（如 `val()`）也会报错，必须先断言它是一个函数。

### 类型缩小与断言
- **使用 `typeof` 进行类型缩小**：
  ```typescript
  if (typeof val === 'string') {
      console.log(val.length);
      console.log(val.toUpperCase());
  }
  ```
- **使用类型断言**：
  ```typescript
  const str = val as string;
  console.log(str.toLowerCase());
  ```

### `tsconfig.json` 配置建议
为了获得更合理的类型检查效果，建议在配置文件中开启以下严格模式选项：
- `strict`: 开启所有严格类型检查。
- `strictNullChecks`: 开启严格的 null/undefined 检查。
- `noImplicitAny`: 禁止隐式的 any 类型。

## never 类型 *Content-[07:12]

`never` 表示**永远不会有值**的类型，它的用途相对有限，但却是高级类型编程中不可或缺的一部分。

### 核心特点
- **赋值规则**：`never` 不能赋值给任何其他类型（包括 `any` 和 `unknown`），同时任何类型也不能赋值给 `never`（除了 `never` 本身）。
- **主要用途**：主要用于**类型保护**（Type Guards）和**控制流分析**。

### 常见场景与示例
- **抛出异常的函数**：总是抛出错误的函数没有正常的返回值，其返回类型为 `never`。
  ```typescript
  function throwError(): never {
      throw new Error("Something went wrong!");
  }
  ```
- **无限循环**：没有固定输出且永远不会返回值的无限循环，类型也是 `never`。
  ```typescript
  function infiniteLoop(): never {
      while (true) {}
  }
  ```
- **类型保护（处理不可能的情况）**：
  在处理联合类型时，用于确保所有可能的分支都被处理。
  ```typescript
  function handleValue(val: string | number) {
      if (typeof val === 'string') {
          // 处理 string
      } else if (typeof val === 'number') {
          // 处理 number
      } else {
          // 此时 val 的类型被推导为 never
          // 如果未来联合类型新增了成员但未在此处理，这里会报错，从而实现类型保护
          const check: never = val; 
      }
  }
  ```
- **空数组**：
  表示数组中永远不会有元素。
  ```typescript
  const emptyArray: never[] = [];
  emptyArray.push(1); // 报错：Argument of type 'number' is not assignable to parameter of type 'never'
  ```

## void 类型 *Content-[10:16]

`void` 表示**没有任何类型**，通常与函数的返回值相关。

### 核心特点
- **赋值规则**：只能赋值给 `undefined` 或 `unknown`（在严格模式下）。不能赋值给其他具体类型。
- **主要用途**：着重用于**函数没有返回值**的场景。

### 示例说明
- **无返回值的函数**：
  ```typescript
  function logMessage(msg: string): void {
      console.log(msg);
  }
  ```
  该函数只完成打印 `message` 的操作，没有任何返回值，因此其返回类型被声明为 `void`。

## AI 总结

本视频详细讲解了 TypeScript 中的四种特殊类型：`any`、`unknown`、`never` 和 `void`。
1. **`any`** 是最宽松的类型，会关闭类型检查，相当于退回纯 JS 模式，应尽量避免使用。
2. **`unknown`** 是 `any` 的安全替代品，它要求在使用前必须进行类型断言或类型缩小，从而保证了类型安全性。
3. **`never`** 表示永远不会有值的类型，常用于抛出异常或无限循环的函数返回值，在控制流分析和类型保护中发挥着关键作用。
4. **`void`** 表示没有类型，主要用于声明没有返回值的函数。
掌握这些特殊类型的区别和适用场景，是编写健壮、类型安全的 TypeScript 代码的重要基础。
