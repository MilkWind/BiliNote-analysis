## 联合类型基础概念 *Content-[00:18]
- **基本定义**：在 TypeScript (TS) 中，联合类型使用竖线 `|` 分割多个类型。它表示一个变量的值可以是这几种类型中的任意一种。
- **代码示例**：
  - 声明变量 `let value: string | number;`。
  - 合法赋值：可以赋值为字符串（如 `"hello"`）或数字（如 `42`）。
  - 非法赋值：如果尝试赋值为布尔值，TS 编译器会立即报错，因为它不属于预先定义的类型集合。
- **本质与作用**：允许一个变量同时拥有多种类型的能力。在处理多样化数据来源的场景下，既提供了极大的灵活性，又保障了基础的类型安全。

## 联合类型的实际应用场景 *Content-[01:35]
- **业务场景**：在处理用户 ID 时，ID 可能是纯数字，也可能是一串 UID 字符串。
- **代码示例**：定义一个函数 `function processId(id: string | number)`。
- **核心优势**：
  1. 支持多种 ID 的表示方式，函数可以同时处理数字和字符串。
  2. 在保持类型灵活性的同时，没有牺牲类型安全。如果传入对象或数组等非法类型，TS 会在编译阶段直接报错，从而在开发阶段捕获类型错误。
- **重要注意事项**：联合类型不能是 `any` 类型。`any` 意味着放弃任何类型检查，而联合类型则是将值的类型严格约束在一个明确的集合里面。

## 联合类型的访问限制 *Content-[02:58]
- **核心规则**：为了保证类型安全，TS 设定了一个重要规则——对于一个联合类型的变量，**只能访问该联合类型中所有成员共有的属性或方法**。
- **代码示例**：假设参数 `value` 的类型是 `string | number`。
  - 调用 `value.toUpperCase()`：TS 会报错。因为 `toUpperCase` 仅存在于 `string` 类型上，`number` 类型并没有该方法。
  - 调用 `value.toString()`：代码合法。因为 `string` 和 `number` 的原型上都有 `toString` 方法。
- **底层原因**：在编译阶段，TS 无法百分之百确定运行时 `value` 的具体类型究竟是数字还是字符串。为了避免潜在的运行时错误，TS 会禁止这种不确定的操作。

## 类型收窄（Type Narrowing）概念 *Content-[04:13]
- **问题引入**：如果确实需要根据具体类型执行不同的操作（例如必须调用 `toUpperCase`），直接操作联合类型是受限的，此时需要引入“类型收窄”。
- **基本定义**：类型收窄是指把一个宽泛的联合类型，通过逻辑判断收窄到一个更加具体、更加明确的类型的过程。
- **工作原理**：TS 编译器非常智能，能够理解代码中的逻辑判断（如 `if` 判断或 `switch` 语句）。一旦在某个代码块内确认了变量的具体类型，TS 就会在该代码块内部允许安全地访问该类型特有的属性和方法。

## 类型收窄方法一：typeof 操作符 *Content-[05:09]
- **适用场景**：最直接的方法，主要用于处理 JavaScript 的基础类型（如 `string`, `number`, `boolean` 等）。
- **代码示例**：
  ```typescript
  function processId(id: string | number) {
      if (typeof id === 'string') {
          // TS 自动将 id 收窄为 string 类型
          // 可以安全使用字符串特有的方法，如 id.toUpperCase()
      } else {
          // 否则 id 被收窄为 number 类型
          // 可以安全使用数字特有的逻辑
      }
  }
  ```
- **核心机制**：TS 能够理解 `typeof` 判断的含义，并在对应的逻辑分支里自动把变量收窄，从而允许执行特定的类型操作。

## 类型收窄方法二：in 操作符 *Content-[05:58]
- **适用场景**：当处理的是复杂的对象类型联合时，`typeof` 不再适用，此时 `in` 操作符派上用场。
- **代码示例**：
  ```typescript
  interface Admin {
      name: string;
      privilege: string; // Admin 独有属性
  }
  interface Customer {
      name: string;
      credit: number; // Customer 独有属性
  }
  type User = Admin | Customer;

  function printUser(user: User) {
      if ('privilege' in user) {
          // TS 推断 user 的类型一定是 Admin
          // 可以安全访问 user.privilege
      } else {
          // TS 推断 user 的类型被收窄为 Customer
          // 可以安全访问 user.credit
      }
  }
  ```
- **核心机制**：`in` 操作符用于检测对象上是否存在某个特定的属性。TS 能够理解 `in` 操作符的逻辑，并在对应的分支中自动完成类型的收窄，帮助区分不同对象的类型。

## 类型收窄方法三：可辨识联合（Discriminated Unions） *Content-[07:28]
- **地位**：这是处理联合类型**最推荐**的一种高级模式。
- **数据结构设计**：需要对数据结构做特殊处理，为每个成员类型定义一个独特的**字面量类型**公共属性。
- **代码示例**：
  ```typescript
  interface Circle {
      kind: 'circle'; // 字符串字面量类型
      radius: number;
  }
  interface Square {
      kind: 'square'; // 字符串字面量类型
      sideLength: number;
  }
  type Shape = Circle | Square;
  ```
- **核心机制**：
  - 公共属性（如 `kind`）的作用类似于每个对象的 ID 或标签，能够唯一标识出对象的具体类型。
  - 因为每个成员类型都有独特的字面量属性，TS 获得了极强的能力：可以通过检查该属性的值（如 `shape.kind === 'circle'`），精确地推断出变量当前的类型。
  - 通常配合 `switch` 语句和 `never` 类型检查使用，可以构建出极易于维护的类型安全代码。

## 课程总结 *Content-[08:36]
1\. **联合类型**：通过 `|` 符号定义，允许变量持有多种类型中的任意一种，提供灵活的多态能力。
2\. **访问受限与类型收窄**：直接操作联合类型是受限的（只能访问共有属性），必须通过类型收窄来保证安全。
3\. **收窄技术**：学习了 `typeof` 和 `in` 等类型收窄技术，帮助 TS 在特定代码块中推断出更具体的类型。
4\. **可辨识联合**：通过为公共属性设置不同的字面量类型，配合 `switch` 和 `never` 类型检查，是处理复杂联合类型的最佳实践。
