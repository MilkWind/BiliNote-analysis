## 联合类型基础概念 *Content-[00:18]
- **定义**：在 TypeScript 中，联合类型（Union Types）使用竖线 `|` 分割多个类型，表示一个变量的值可以是这些类型集合中的任意一种。
- **代码示例**：
  ```typescript
  let value: string | number;
  
  value = "hello"; // 合法，赋值为字符串
  value = 42;      // 合法，赋值为数字
  value = true;    // 编译报错，布尔值不属于预定义的类型集合
  ```
- **核心本质**：允许一个变量同时拥有多种类型的能力（如同时具备字符串或数字的特性）。在处理多样化数据来源的场景下，它既提供了极大的灵活性，又保障了基础的类型安全。

## 联合类型的实际应用场景 *Content-[01:35]
- **场景描述**：在实际业务中，用户的 ID 可能是纯数字，也可能是一串 UID 字符串。使用联合类型可以让函数同时兼容这两种数据格式。
- **代码示例**：
  ```typescript
  function processUserId(id: string | number) {
      // 函数内部可同时处理数字和字符串类型的 id
  }
  ```
- **核心优势**：
  - 支持多种 ID 表示方式，保持代码灵活性。
  - 在不牺牲类型安全的前提下，TS 会在编译阶段拦截非法传入（如传入对象或数组），从而在开发阶段提前捕获类型错误。
- **重要注意事项**：联合类型不能是 `any` 类型。`any` 意味着完全放弃类型检查，而联合类型则是将值的类型严格约束在一个明确的、有限的集合之内。

## 联合类型的访问限制与类型收窄概念 *Content-[02:58]
- **访问限制规则**：为了保证类型安全，TS 规定对于一个联合类型的变量，**只能访问所有成员类型共有的属性或方法**。
- **示例说明**：
  ```typescript
  function processValue(value: string | number) {
      value.toUpperCase(); // 报错：toUpperCase 仅存在于 string 类型上
      value.toString();    // 合法：string 和 number 原型上均存在 toString 方法
  }
  ```
- **报错原因**：在编译阶段，TS 无法百分之百确定运行时 `value` 的具体类型。为了避免潜在的运行时错误，TS 会禁止调用不确定的、非共有的方法。
- **解决方案：类型收窄（Type Narrowing）**：
  - **概念**：通过逻辑判断，将一个宽泛的联合类型“收窄”到一个更加具体、明确的类型。
  - **工作原理**：TS 编译器非常智能，能够理解 `if` 判断或 `switch` 语句等代码逻辑。一旦在某个代码块中确认了变量的具体类型，TS 就会在该代码块内部自动完成类型收窄，允许开发者安全地访问该类型特有的属性和方法。

## 类型收窄方法一：typeof 操作符 *Content-[04:13]
- **适用场景**：主要用于处理 JavaScript 的基础数据类型（如 `string`、`number`、`boolean` 等）。
- **工作原理**：使用 `typeof` 进行类型守卫（Type Guard），TS 能够理解 `typeof` 判断的含义，并在对应的逻辑分支中自动将变量收窄到具体类型。
- **代码示例**：
  ```typescript
  function processId(id: string | number) {
      if (typeof id === "string") {
          // 此处 id 被自动收窄为 string 类型
          console.log(id.toUpperCase());
      } else {
          // 此处 id 被自动收窄为 number 类型
          console.log(id.toFixed(2));
      }
  }
  ```

## 类型收窄方法二：in 操作符 *Content-[05:58]
- **适用场景**：主要用于处理复杂的对象类型联合。
- **工作原理**：使用 `in` 操作符检查对象上是否存在某个特定的属性。TS 会根据属性的存在与否，在对应的分支中自动完成对象类型的收窄。
- **代码示例**：
  ```typescript
  interface Admin {
      name: string;
      privilege: string; // Admin 独有属性
  }
  
  interface Customer {
      name: string;
      credit: number;    // Customer 独有属性
  }
  
  type User = Admin | Customer;
  
  function printUserInfo(user: User) {
      if ("privilege" in user) {
          // 此处 user 被收窄为 Admin 类型
          console.log(user.privilege);
      } else {
          // 此处 user 被收窄为 Customer 类型
          console.log(user.credit);
      }
  }
  ```

## 类型收窄方法三：可辨识联合 (Discriminated Unions) *Content-[07:27]
- **概念**：这是处理联合类型**最推荐**的一种高级模式。它要求对数据结构进行特殊处理，为联合类型中的每个成员定义一个共同的、类型为“字符串字面量”的属性（通常称为“标签”或“标识”）。
- **工作原理**：这个公共属性就像是每个对象的唯一 ID。TS 通过检查这个属性的值，能够极其精确地推断出变量当前的具体类型。
- **代码示例**：
  ```typescript
  interface Circle {
      kind: "circle";    // 字符串字面量类型，作为标识
      radius: number;
  }
  
  interface Square {
      kind: "square";    // 字符串字面量类型，作为标识
      sideLength: number;
  }
  
  type Shape = Circle | Square;
  
  function getArea(shape: Shape) {
      switch (shape.kind) {
          case "circle":
              // shape 被精确收窄为 Circle 类型
              return Math.PI * shape.radius ** 2;
          case "square":
              // shape 被精确收窄为 Square 类型
              return shape.sideLength ** 2;
      }
  }
  ```
- **最佳实践**：在实际开发中，可辨识联合通常会配合 `switch` 语句以及 `never` 类型进行穷尽性检查（Exhaustiveness checking），从而构建出极其健壮且易于维护的类型安全代码。

## 课程总结 *Content-[08:36]
- **联合类型**：通过 `|` 符号定义，允许变量持有多种类型中的任意一种，为代码提供了灵活的多态能力。
- **访问限制与类型收窄**：直接操作联合类型是受限的（只能访问共有成员），必须通过类型收窄技术来保证类型安全。
- **三大收窄技术**：
  - `typeof`：适用于 JS 基础类型的判断。
  - `in`：适用于对象属性的存在性检查。
  - 可辨识联合：通过公共的字面量属性进行精确区分，是处理复杂对象联合的最优解。
