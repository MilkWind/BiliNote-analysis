## 什么是交叉类型 *Content-[00:26]

交叉类型是 TypeScript 中的一个重要特性，其背后蕴含了“**组合优于继承**”的设计思想。

- **核心概念**：交叉类型是将一个或多个现有的类型合并成一个新类型的方式。
- **基本语法**：使用 `&` (and) 符号连接不同的类型。
- **对象类型的交叉（成员并集）**：
  - 当对对象类型进行交叉操作时，它会进行属性的合并，做的是成员的并集，将所有属性聚合在一起。
  - **代码示例**：
    - 定义 `TypeA`，要求包含一个 `string` 类型的属性 `a`。
    - 定义 `TypeB`，要求包含一个 `number` 类型的属性 `b`。
    - 通过 `TypeA & TypeB` 创建一个新的交叉类型 `CombineType`。
  - **结果表现**：任何符合该交叉类型的变量，必须**同时满足** `TypeA` 和 `TypeB` 的要求。即声明的对象必须同时拥有 `string` 类型的 `a` 属性和 `number` 类型的 `b` 属性。对象最终具备了所有原类型的成员。

## 原始数据类型的交叉 *Content-[01:42]

当对原始数据类型（如 `string`、`number`）进行交叉操作时，会产生特殊的结果。

- **代码示例**：定义一个类型 `ImpossibleType = string & number`。
- **推断结果**：TypeScript 推断出来的结果为 `never`。
- **原理解析**：
  - 交叉类型的核心含义是“同时满足”。
  - 一个值不可能在同一时间既是一个字符串（`string`）又是一个数字（`number`），这是两种完全互斥的基本类型。
  - `never` 是 TypeScript 中的底层类型，表示**永远不会出现这种值的类型**。
  - 因此，`string & number` 准确地描述了一个无法被实现、不可能存在的类型，使用 `never` 来表示非常符合逻辑。

## 交叉类型与 extends 的区别 *Content-[02:36]

交叉类型（`&`）与 `extends` 关键字似乎都能表示类型的扩展，但它们在语义、适用场景和技术实现上有显著差异。

- **1. 语义差异**：
  - `extends`：表示**继承**关系。
  - `&` (交叉类型)：代表**组合**关系。例如，一个 UI 元素的类型可以既是“可拖拽”的，又是“可点击”的，这两种特性被组合在一起。
- **2. 适用场景**：
  - `extends`：更加适合构建明确的、具有层级分类的类型结构（如父子类关系）。
  - `&` (交叉类型)：非常适合用于 **Mixin（功能混入）** 操作，或者将不同维度的能力聚合到一起。
- **3. 技术实现**：
  - `extends`：只能用于**接口（interface）** 之间的扩展。
  - `&` (交叉类型)：灵活性更高，可以组合**任何类型**，包括类型别名（type alias）、接口（interface），甚至是字面量类型（literal types）。

## 总结与高级应用 *Content-[03:59]

- **核心回顾**：`&` 运算符在 TypeScript 中用于创建交叉类型，其作用是将多个类型的所有成员合并到一个新的类型中。
- **优势**：通过这种强大的组合能力，交叉类型能够极大地提升类型系统的灵活性和可扩展性。
- **高级应用**：
  - 交叉类型在众多高级编程模式中扮演着关键角色，例如 **Mixin（混入）** 模式以及 React 中常见的 **HOC（高阶组件，Higher-Order Components）**。
- **最佳实践建议**：
  - 当你需要为一个对象拼装来自不同方面的多个特征或者能力时，请**优先考虑使用交叉类型**。
