## 1. 联合类型与交叉类型概述 *Content-[00:04]*

在 TypeScript 中，联合类型（Union Types）和交叉类型（Intersection Types）是非常常用且核心的类型特性。
- **联合类型**：表示一个值可以是多种类型中的一种，使用竖线 `|` 进行分隔。它强调的是 **“或” (OR)** 的逻辑。
- **交叉类型**：表示一个值同时具备多种类型的特性，使用 `&` (and) 符号进行连接。它强调的是 **“与” (AND)** 的逻辑。

两者在逻辑表达上有本质的区别，理解这一点是掌握 TypeScript 类型系统的基础。

## 2. 联合类型 (Union Types) 基础与示例 *Content-[01:00]*

联合类型适用于变量可能有多种类型的场景。

**基础示例：**
定义一个 `printId` 函数，参数可以是 `number` 或 `string`：
```typescript
function printId(id: number | string) {
    console.log(id);
}
// 传入 number 或 string 都是合法的
```

**按钮尺寸示例：**
在组件开发中，按钮可能有多种尺寸状态。可以通过 `type` 定义类型别名：
```typescript
type Size = 'small' | 'medium' | 'large' | number;

function setSize(size: Size) {
    // size 可以是 'small', 'medium', 'large' 或任意数字
}
```
这种写法没有严格约束具体的枚举值，只要符合联合类型中的某一项即可。

## 3. 联合类型进阶：使用 `as const` 提取联合类型 *Content-[02:35]*

除了直接使用字面量联合类型，我们还可以通过常量数组结合 `as const` 来推导联合类型，这在需要同时维护“运行时数组”和“类型定义”时非常有用。

**步骤解析：**
1. **定义只读数组**：使用 `as const` 将数组断言为 `readonly` 只读类型，防止后续修改（如 `push` 操作会报错）。
```typescript
const sizes = ['small', 'medium', 'large'] as const;
// sizes 的类型变为 readonly ["small", "medium", "large"]
```
2. **提取联合类型**：通过 `typeof` 获取数组类型，再通过 `[number]` 索引访问提取出所有元素的联合类型。
```typescript
type SizeType = typeof sizes[number]; 
// 等价于 type SizeType = "small" | "medium" | "large"
```

**优势：**
这种方式与直接定义 `type Size = 'small' | ...` 有异曲同工之妙，但好处是**只需维护一处（常量数组）**。如果后续需要新增尺寸，只需修改数组，类型会自动更新，避免了类型和运行时数据不一致的问题。

其他常见场景如状态管理（`status: 'error' | 'loading' | 'success'`）等，也大量依赖联合类型。

## 4. 交叉类型 (Intersection Types) 基础与示例 *Content-[05:54]*

交叉类型用于将多个类型合并为一个类型，要求目标值必须同时满足所有被合并类型的约束。

**基础示例：**
```typescript
type A = { name: string };
type B = { age: number };
type C = A & B; // C 必须同时包含 name 和 age

const person: C = {
    name: 'Alice',
    age: 25 // 如果缺少 age，会报错 "age is missing"
};
```

**处理缺失属性报错：**
- 方法一：将属性设置为可选（`age?: number`）。
- 方法二：在赋值时提供默认值或补全所有必填属性。

## 5. 交叉类型使用场景：Mixin 模式与接口配合 *Content-[07:46]*

**1. 组合多个对象类型与 Mixin 模式**
交叉类型常用于组合多个对象类型，或者实现类似 Mixin（混入）的设计模式，将多个类的实例特性组合在一起。
```typescript
type Disposable = { dispose: () => void };
type Activatable = { activate: () => void };

// 组合两个类的实例类型
type SmartObject = Disposable & Activatable; 
```
在实现时，返回的对象必须同时具备 `dispose` 和 `activate` 方法，否则 TypeScript 会报错。

**2. 与 Interface 配合使用**
交叉类型不仅可以用于 `type` 别名，也可以用于合并 `interface`。
```typescript
interface ErrorHandling {
    success: boolean;
    error?: { message: string };
}

interface Data {
    data: any;
}

// 合并两个接口
type APIResponse = ErrorHandling & Data;

const response: APIResponse = {
    success: true,
    data: { id: 1 }
};
```

## 6. 交叉类型的特殊情况：类型冲突与兼容 *Content-[11:41]*

在使用交叉类型时，需要特别注意同名属性的类型冲突问题：

**1. 互斥类型交叉得到 `never`**
如果两个类型完全没有交集，交叉后的结果为 `never`。
```typescript
type Impossible = string & number; // 结果为 never，因为不存在既是 string 又是 number 的值
```

**2. 同名属性类型不兼容**
如果两个接口有同名属性，但类型不兼容（如 `number` 和 `string`），交叉后该属性会变为 `never`。
```typescript
interface X { x: number; y: string; }
interface Y { x: string; z: boolean; }
type Conflict = X & Y; 
// Conflict 中的 x 属性类型为 never (number & string)
```

**3. 同名属性类型兼容（子类型）**
如果同名属性的类型存在包含关系（子类型），交叉后会取更严格的子类型。
```typescript
interface A { x: number | string; }
interface B { x: number; }
type Compatible = A & B; 
// Compatible 中的 x 属性类型为 number (因为 number 是 number | string 的子类型)
```
**注意：** 尽量避免类型冲突导致 `never` 的情况发生，确保交叉类型的同名属性是兼容的。

## 7. 高级用法：结合条件类型与泛型 *Content-[15:07]*

联合类型和交叉类型可以与条件类型（`extends`）和泛型结合，实现高级的“类型体操”。

**1. 使用 `Extract` 提取联合类型**
`Extract<T, U>` 用于从联合类型 `T` 中提取出可以赋值给 `U` 的类型。
```typescript
type Mixed = string | number | boolean | 'hello';
type StringOnly = Extract<Mixed, string>; 
// 推导过程：
// string extends string -> string
// number extends string -> never
// boolean extends string -> never
// 'hello' extends string -> 'hello'
// 结果：string | 'hello'
```

**2. 从对象中提取特定类型的 Key**
通过遍历对象的 Key，并判断其 Value 的类型，提取出符合特定类型的 Key 组成的联合类型。
```typescript
type User = {
    id: number;
    name: string;
    email: string;
    age: number;
};

// 提取 User 中值为 string 类型的 key
type StringKeys<T> = {
    [K in keyof T]: T[K] extends string ? K : never;
}[keyof T];

type UserStringKeys = StringKeys<User>; 
// 结果为 "name" | "email"
```
这种模式在封装通用组件或工具函数时非常实用，可以动态约束传入的属性。

## 8. 实际应用场景：组合 Props 与 API 请求配置 *Content-[20:39]*

**1. 组合组件 Props**
在 React/Vue 等前端框架中，常通过交叉类型复用基础 Props。
```typescript
type BaseProps = {
    className?: string;
    style?: React.CSSProperties;
};

type ButtonProps = BaseProps & {
    onClick: () => void;
};

type InputProps = BaseProps & {
    value: string;
    onChange: (val: string) => void;
};
```
通过提取 `BaseProps`，避免了在每个组件中重复定义 `className` 和 `style`，思路类似于 `interface` 的继承。

**2. API 请求配置**
在封装 Axios 或 Fetch 请求时，可以抽取通用的请求配置，再通过交叉类型扩展不同 HTTP 方法的特有属性。
```typescript
type BaseRequest = {
    url: string;
    headers?: Record<string, string>;
};

type GetRequest = BaseRequest & {
    method: 'GET';
};

type PostRequest = BaseRequest & {
    method: 'POST';
    body?: any;
};
```
这种设计模式将通用内容抽取为“基类”，通过交叉类型组合差异点，使类型定义更加清晰和易于维护。

## 9. 核心知识点总结 *Content-[24:27]*

- **联合类型 (`|`)**：表示“或”的关系，值可以是多种可能类型中的一种。
- **交叉类型 (`&`)**：表示“与”的关系，将多个类型合并为一个，值必须同时具备所有类型的特性。
- **类型收窄**：在使用联合类型时，常结合类型守卫（Type Guards）来缩小类型范围，进行精确处理。
- **交叉类型兼容性**：交叉类型中的同名属性必须兼容，如果不兼容（如 `string & number`），该属性将退化为 `never` 类型。
