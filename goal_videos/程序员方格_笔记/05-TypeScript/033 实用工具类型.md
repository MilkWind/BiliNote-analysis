## 什么是实用工具类型 *Content-[00:01]
- **核心概念**：TypeScript 内置的一组类型工具函数。这里的“函数”是类型概念上的描述，意味着它们接收一个或多个类型作为输入，并返回一个新类型作为输出。
- **底层实现**：基于 TS 强大的泛型（Generics）、条件类型（Conditional Types）和映射类型（Mapped Types）等高级特性实现。
- **核心价值**：能够基于已有的类型自动地生成新的、有关联的类型变体，从而避免手动编写大量重复的类型定义。
- **常见场景**：在 TS 开发中，经常需要基于现有类型创建新类型，例如一个类型的可选版本、只读版本或只包含部分属性的版本。
- **本次聚焦的四个核心工具**：`Partial`、`Readonly`、`Pick` 和 `Omit`，它们分别解决了开发中最常遇到的四种类型转换需求。

## Partial：部分可选类型 *Content-[01:32]
- **基本作用**：接收一个类型泛型 `T`，返回一个新的类型。新类型拥有与 `T` 完全相同的属性，但**所有属性都变成了可选的**（属性名后面带上 `?`）。
- **典型应用场景**：处理部分更新的数据。
- **代码示例解析**：
  - 定义了一个 `User` 接口，包含三个必填字段。
  - 定义了一个 `updateUser` 函数，其第二个参数 `fields` 被定义为 `Partial<User>`。
  - 这意味着传递给该函数的对象可以包含 `User` 接口中的任意一个或多个字段，也可以一个都不包含。
  - 调用示例：可以只传 `username` 来更新用户名，或者只传 `email` 来更新邮箱，TS 的类型检查都会正常通过。
- **优势对比**：如果没有 `Partial`，就必须传入一个完整的新的 `User` 对象，这在实际业务中非常不灵活。`Partial` 自动完成了将所有属性加上 `?` 的转换过程。

## Readonly：只读类型 *Content-[03:09]
- **基本作用**：将类型 `T` 中**所有的属性都标记成只读**（`readonly`）。一旦对象被声明为这种类型，它的任何属性都不能被重新赋值。
- **典型应用场景**：处理需要保持不变的数据。例如全局配置对象，或在状态管理模式中确保状态是不可变的（immutable）。
- **代码示例解析**：
  - 定义了一个 `Config` 接口。
  - 声明了一个常量，并将其类型指定为 `Readonly<Config>`。
  - 当尝试修改该配置对象的属性（如 `config.setting`）时，TS 在编译阶段会立即报错，提示这是一个只读属性。
- **核心价值**：在代码运行之前（编译阶段）就提供了数据不可变性的保证，有效防止意外的副作用。

## Pick：属性挑选类型 *Content-[04:29]
- **基本作用**：`Pick<T, K>` 从一个已有的类型 `T` 中，**挑选出 `K` 所指定的那些属性**，然后组合成一个新的类型。这里的 `K` 通常是一个由属性名组成的联合类型（Union Type）。它主要用于改变类型的结构。
- **典型应用场景**：当需要从一个复杂的后端数据结构中，提取部分字段用来展示在前端界面时。
- **代码示例解析**：
  - 假设有一个完整的 `User` 接口，包含四个属性。
  - 如果用户列表只需要展示 `id` 和 `username`，可以使用 `Pick` 创建一个新类型 `UserPreview`：`Pick<User, 'id' | 'username'>`。
  - 此时 `UserPreview` 类型就只包含 `id` 和 `username`。
  - 创建 `listItem` 变量并指定为 `UserPreview` 类型时，它就必须且只能包含这两个属性。
- **优势**：自动生成了等价于 `{ id: number; username: string }` 的新类型，非常精确且高效。

## Omit：属性排除类型 *Content-[05:53]
- **基本作用**：`Omit<T, K>` 的作用与 `Pick` 完全相反。它接收一个类型 `T` 和一个属性名联合类型 `K`，创建一个**移除了 `K` 中所有指定属性**的新类型。
- **典型应用场景**：数据脱敏。例如，将包含敏感信息的用户对象返回给前端时，剔除掉不该暴露的字段（如密码）。
- **代码示例解析**：
  - 定义了一个 `UserWithPassword` 接口，里面包含了一个 `passwordHash` 字段。
  - 使用 `Omit<UserWithPassword, 'passwordHash'>` 将 `passwordHash` 排除在外。
  - 生成的新类型 `PublicUser` 是一个不包含密码字段的安全用户类型。
- **优势**：提供了一种简洁、类型安全的方法来过滤掉不需要的属性，确保数据在传输过程中的安全性。

## 延伸阅读：其他实用工具类型 *Content-[07:09]
除了上述四个核心工具，TS 还提供了许多强大的工具类型，以下为几个常见的延伸阅读方向：
- **Required**：`Partial` 的反向操作，能将一个类型中的所有可选属性变成必填属性。
- **Record**：非常适合用来定义键值结构明确的对象。例如，定义一个所有键都是字符串、所有值都是数字的类型：`Record<string, number>`。
- **Exclude**：作用于联合类型，用来从一个联合类型中排除指定的成员。
- **ReturnType**：非常实用的工具，可以自动获取一个函数类型的返回值类型。当想复用某个函数的返回结果类型时，使用它非常方便。
