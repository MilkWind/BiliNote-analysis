## 什么是类型别名 *Content-[00:01]
- TypeScript 中一个非常基础且强大的功能是**类型别名**（Type Alias）。
- 主要目标：使用类型别名来简化复杂的类型定义，最终让代码变得更加清晰、易于维护。

## 类型别名的基本语法与核心作用 *Content-[00:21]
- **核心概念**：类型别名并不会创建一个全新的、独立的类型。它的核心作用是为已经存在的类型取一个新名字，这是一种**引用**，而非创建新类型。
- **基本语法**：使用 `type` 关键字，后跟想要的新名字，等号右边是希望引用的类型。
  ```typescript
  type SomeType = string | number;
  ```
- **适用范围**：`SomeType` 的范围非常广，可以是：
  - 原始类型（如 `string`, `number`）
  - 对象类型
  - 联合类型
  - 另一个类型别名的组合
- **主要目的**：提升代码的**可读性**和**可维护性**。当类型变得复杂时，一个言简意赅的名字可以让代码意图一目了然。

## 应用场景一：简化联合类型 *Content-[01:29]
- **场景描述**：在多个函数中重复使用相同的联合类型。
- **示例代码**：
  - 假设有 `printId` 和 `getUser` 两个函数，它们的参数 `id` 类型都是 `string | number`。
  - 这种写法本身没有问题，但如果项目中有十几个函数都使用这个类型，代码会显得非常冗余。
- **使用类型别名优化**：
  ```typescript
  type ID = string | number;

  function printId(id: ID) { ... }
  function getUser(id: ID) { ... }
  ```
- **优势**：
  - **代码更简短**：直接使用大写的 `ID`，写法更短且能准确表达代码含义，一眼就能看出参数是一个 ID。
  - **提升可维护性**：假设未来需求变更，`id` 还需要支持 `bigint` 类型，只需修改 `ID` 这个别名定义的地方，所有用到 `ID` 的地方都会自动更新，做到一次修改，全局生效。

## 应用场景二：描述对象结构 *Content-[02:46]
- **场景描述**：使用类型别名来描述和复用对象的结构。
- **示例代码**：
  ```typescript
  type Point = {
    x: number;
    y: number;
  };

  function distance(p1: Point, p2: Point) {
    // 计算两个点之间的距离
  }
  ```
- **优势**：
  - **函数签名即文档**：任何调用 `distance` 函数的人都能立即明白，需要传入两个符合 `Point` 结构的对象。
  - **可复用单元**：`Point` 类型变成了一个可复用的单元，可以在项目的其他函数参数、变量声明等地方重复使用。
  - **保证一致性**：保证了整个应用对于 `Point` 这个概念的理解和数据结构的一致性。

## 应用场景三：类型别名与泛型结合 *Content-[03:47]
- **场景描述**：将类型别名与泛型（Generics）结合，创建可复用的类型模板。
- **示例代码**：
  ```typescript
  type Container<T> = {
    value: T;
  };

  let numberContainer: Container<number> = { value: 123 };
  let stringContainer: Container<string> = { value: "hello" };
  ```
- **原理解析**：
  - `Container<T>` 中的 `T` 是一个类型占位符。
  - 该类型描述了一个对象，包含一个 `value` 属性，其类型由使用时传入的 `T` 决定。
  - 在实例化时，如 `Container<number>`，TypeScript 就知道 `value` 必须是 `number` 类型；如果传入数字给 `Container<string>`，TypeScript 就会报错。
- **优势**：
  - 创建了一个**可复用的类型模板**，定义了数据结构。
  - 允许使用者在不牺牲**类型安全**的前提下，灵活地指定具体的数据类型。

## 核心内容总结 *Content-[04:58]
- **核心作用**：为复杂或重复的类型定义提供一个简洁、清晰的名称。
- **结合泛型**：类型别名可以与泛型结合使用，创建出灵活且类型安全的可复用类型模板。
- **开发建议**：在日常开发中，对类型进行合理的命名和抽象是非常有必要的。合理使用类型别名能够帮助开发者编写出高质量的 TypeScript 代码。
