## 1. 声明合并的概念与设计初衷 *Content-[00:00]
- **基本概念**：在 TypeScript 中，当多个同名的声明相遇时，TS 编译器并不会抛出错误，而是尝试将它们合并在一起。这在许多编程语言中通常会导致重复定义的编译错误，但 TS 刻意设计了这种机制。
- **设计目的**：
  1. **兼容 JS 动态特性**：更好地兼容 JavaScript 现有的编程模式。例如在 JS 中，一个函数同时也可以作为对象拥有自己的属性，声明合并为这种模式提供了类型安全的实现方法。
  2. **增强类型扩展性**：允许开发者事后为一个已经存在的类型补充新的成员，而不需要修改其原始的定义。

## 2. 声明合并的核心思想 *Content-[00:52]
- **信息叠加**：声明合并的核心思想可以理解为“信息的叠加”。
- **全局描述**：编译器会将多个分散的、关于同一个目标的局部描述，组合成一个更完整的全局描述。
- **代码组织**：这种机制使得代码的组织方式变得更加灵活，允许在不同地方对同一类型进行渐进式的完善。

## 3. 接口合并 (Interface Merging) *Content-[02:11]
- **基本用法**：当声明两个同名的 `interface`（例如 `Box`）时，TS 编译器会自动将这两个接口的成员进行合并。最终得到的 `Box` 接口会同时包含两次声明中的所有属性（如 `height`、`width` 以及后续添加的额外属性）。
- **实例化要求**：当创建一个类型为 `Box` 的变量时，其初始化对象必须同时满足合并后所有属性的要求，否则 TS 会报错。
- **合并规则**：
  - **自动收集**：所有的非函数成员都会被收集起来，形成一个更大的接口。
  - **冲突处理**：如果出现同名但类型不同的非函数成员，则会发生编译错误。

## 4. 扩展全局类型 *Content-[03:28]
- **应用场景**：在前端开发中，有时需要给全局的 `window` 对象添加自定义属性（如应用配置信息）。直接赋值会导致 TS 因为不认识新属性而报错。
- **解决方案**：利用接口合并特性来安全地扩展全局类型。
- **实现步骤**：
  1. 使用 `declare global` 关键字告诉 TypeScript 接下来要对全局作用域的类型进行修改。
  2. 在该代码块内部，再次声明 `interface Window`，并添加自定义属性（如 `myAppConfig`）。
- **最终效果**：通过这种方法，自定义属性被安全地扩展到了全局类型中。在代码中使用 `window.myAppConfig` 时，TypeScript 不仅不会报错，还会提供完整的类型检查和代码提示。

## 5. 命名空间合并 (Namespace Merging) *Content-[04:39]
- **跨文件合并**：`namespace`（命名空间）同样支持声明合并，甚至可以跨文件进行。
- **示例说明**：假设有两个文件 `animal.ts` 和 `animals` 的扩展文件。在第一个文件中定义了 `Animals` 命名空间并导出了 `Zebra` 类；在第二个文件中再次定义同名的 `Animals` 命名空间并导出其他接口。
- **合并结果**：当 TS 处理这两个文件时，会识别出同名的命名空间，并将它们导出的成员合并。最终得到一个统一的 `Animals` 命名空间，可以访问这两个文件中所有的导出属性。

## 6. 命名空间与类、函数或枚举的合并 *Content-[05:34]
- **双重身份**：这是一种非常有趣的合并形式。当定义了一个类（如 `Album`），同时又定义了一个同名的 `namespace Album` 时，命名空间里导出的成员会作为静态成员，被附加到 `Album` 这个类对象上面。
- **使用方式**：
  - 作为类使用：可以通过 `new Album()` 来实例化。
  - 作为容器使用：可以把它当作一个容器对象，调用其上的静态方法（如 `Album.create()`）或访问相关类型。
- **核心意义**：这种能力使得 TS 能够非常精确地为 JS 中的“函数即对象”常见模式提供类型支持。在 JS 中函数本身就是对象，可以拥有属性，声明合并让这种模式在 TS 中变得更加类型安全。

## 7. 核心内容总结 *Content-[07:07]
- **核心机制**：声明合并是 TS 的一种机制，能够将多个同名的声明自动融合成一个单一的、更完整的定义。
- **主要应用场景**：
  - 接口与接口之间的合并。
  - 接口与命名空间之间的合并。
  - 命名空间和类、函数或枚举的组合。
- **最终价值**：这些特性极大地增强了类型系统的灵活性。正确运用声明合并，可以帮助开发者写出更加灵活、健壮的 TypeScript 代码。

## AI 总结
TypeScript 的“声明合并”是一项旨在兼容 JavaScript 动态特性并增强类型扩展性的核心机制。它允许编译器将多个同名的声明（如 `interface`、`namespace`）自动合并为一个完整的定义。通过这一特性，开发者不仅可以轻松实现接口成员的自动扩充，还能利用 `declare global` 安全地扩展全局对象（如 `window`），甚至通过命名空间与类的合并来实现“函数即对象”的复杂类型建模。掌握声明合并能够显著提升代码的灵活性与类型安全性，是进阶 TypeScript 开发的必备技能。
