## 泛型的基本概念与函数应用 *Content-[00:01]
- **泛型的定义**：泛型是 TypeScript 中一种强大的特性。在定义函数、接口或类时，不预先指定具体的类型，而是使用一个占位符，由在使用时再去指定具体类型的机制。
- **泛型的本质**：可以理解为类型世界中的“参数”，类似于函数调用或类创建时的入参，允许提供各种不同的类型输入。
- **占位符约定**：通常使用 `T`、`U`、`V` 等大写字母作为占位符，表示未来可能的类型。
- **核心作用**：泛型是创建可重用组件的重要工具，能够兼容多种类型约束，而不是局限于单一类型，从而大幅提高类型的复用性。
- **泛型函数示例**：
  - 定义一个泛型函数 `identify<T>(arg: T): T`，约定入参和出参都是类型 `T`。
  - **使用与约束**：如果调用时传入 `string` 类型，则入参和返回值都必须是 `string`；如果传入 `string` 却期望返回 `number`，TS 会直接报错。
  - **类型推断**：TS 具备类型推断能力，当传入具体值（如字符串）时，会自动将 `T` 推断为 `string`，无需手动显式指定 `<string>`。

## 泛型接口与泛型类 *Content-[04:28]
- **泛型接口**：
  - 用于约束对象的结构，接口内部可以包含函数（约定入参和出参）以及数组。
  - **示例**：定义一个包含数组的泛型接口，当传入 `T` 为 `number` 时，数组中的每一项都必须是 `number` 类型。如果尝试放入 `string`，TS 会抛出异常。
- **泛型类**：
  - 在定义 `class` 时接收泛型，能够统一约束类内部的所有属性和方法。
  - **示例**：定义 `class MyClass<T>`，包含属性 `value: T` 和方法 `add(x: T, y: T): T`。
  - **实例化约束**：当实例化并传入 `number` 时，属性和方法参数都必须为 `number`（如 `add(5, 5)` 返回 `10`）；若传入 `string`，则相应地全部约束为 `string` 类型，体现了极高的灵活性。

## 类型体操核心工具：索引类型与映射类型 *Content-[08:32]
- **类型体操概述**：进行类型体操需要掌握几个核心关键字和概念，它们是构建复杂类型的“积木”。
- **索引类型查询 (`keyof`)**：
  - 用于获取对象中所有索引（键）组成的联合类型。
  - **示例**：对于 `Person` 接口（包含 `name` 和 `age`），`keyof Person` 会返回 `'name' | 'age'` 这样的联合类型。
- **索引访问 (`T[K]`)**：
  - 通过索引去访问并获取对应的值类型。
  - **示例**：`Person['name']` 获取 `name` 属性的类型（`string`），`Person['age']` 获取 `age` 属性的类型（`number`）。
- **映射类型 (`in`)**：
  - 用于遍历联合类型中的每个成员，并基于此生成新的类型。
  - **示例（实现 `ReadonlyPerson`）**：
    - 语法结构：`{ readonly [K in keyof T]: T[K] }`。
    - 原理：通过 `keyof T` 获取所有键，使用 `in` 遍历每个键 `K`，并通过 `T[K]` 获取对应的值类型，最后为每个属性添加 `readonly` 修饰符。
    - **优势**：当原类型（如 `Person`）新增属性（如 `city`）时，映射类型会自动联动更新，无需手动修改新类型，避免了冗余和不合理的手动维护。

## 类型体操核心工具：条件类型与类型推断 *Content-[12:33]
- **条件类型 (`T extends U ? X : Y`)**：
  - 类似于逻辑判断中的 `if-else`，是类型体操中的核心逻辑判断工具。
  - **判断条件**：当 `T` 和 `U` 是同类型、`T` 是 `U` 的子类型、或 `U` 的类型兼容 `T` 时，条件成立，返回 `X`，否则返回 `Y`。
  - **示例**：定义 `IsString<T> = T extends string ? true : false`。传入 `string` 返回 `true`；传入 `number` 时，由于两者不能互相赋值（不满足类型层级兼容），返回 `false`。
- **类型推断 (`infer`)**：
  - 在条件类型中允许进行类型推断，相当于一个占位符，用于从已有类型中提取出特定的类型信息。
  - **示例 1：提取函数返回值类型 (`ReturnType`)**
    - 语法：`T extends (...args: any[]) => infer R ? R : never`。
    - 原理：如果 `T` 满足函数签名，则使用 `infer R` 占位并推断出返回值类型 `R`，否则返回 `never`。传入返回 `boolean` 的函数，最终提取出 `boolean`。
  - **示例 2：提取数组元素类型 (`ArrayElementType`)**
    - 语法：`T extends Array<infer U> ? U : never`。
    - 原理：如果 `T` 是数组类型，推断其元素类型 `U`。传入 `number[]` 返回 `number`；传入 `string`（非数组）不满足条件，返回 `never`。
  - **示例 3：提取字符串模板中的特定内容 (`PickName`)**
    - 语法：`T extends \`hello: \${infer Name}\` ? Name : never`。
    - 原理：匹配字符串模板，传入 `'hello: 张三'`，`infer Name` 会占位并推断出 `Name` 为 `'张三'`，从而成功从字符串类型中提取出子串类型。
